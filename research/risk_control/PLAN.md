# 风险控制(R001)—— 事先约定

_写于 2026-10-08 上午(PDT),Opus 5.5 主会话;写在任何带风控的回测结果之前。_

用户 2026-10-08 的要求(原话大意):给 AlphaCube / Partura 加 risk control —— 不强制满仓、做组合优化、对看起来风险高的股票主动降权;
识别风险和因子失效;**在融合信号之前和之后两侧都做**;先提方法、去做、和不加风控的对比。

## 1. 对象与口径

- 信号:两个现成冠军(手写库冠军、挖掘冠军),延到 2026-09-16 的版本(`runs/_forward/signal_<名>_20260916.npy`);
  融合前那一侧用它们各自的 100 个族因子(成员面板在 `pools/_ext/<名>/panels`,族与族内 ridge 原样重建,族间权重只用训练段)。
- 标签:`open_vwap15`、可买入(`Label(buyable=True)`),与此前所有读数相同。信号第 t 行(收盘后可知)对标签第 t 行(t+1 开盘买、t+2 开盘卖)。
- **基线书** = 此前的纯多头书:平滑信号(半衰期固定为存档的:手写库 20、挖掘 10;指引 E12)前 10% 等权、满仓、每单位换手 15 bp。
- 段:样本内 2018-01 ~ 2023-08-07(**一切参数只在这里选**)/ 测试 2023-08-08 ~ 2025-12-31 / 前推 2026-01 ~ 09-16 / 合并样本外 = 后两段。
- 风控的输入必须因果:第 t 行的权重只能用到 t 日收盘为止的行情;已实现标签只能用到第 t−2 行(第 t−1 行的标签要到 t+1 开盘才实现)。
- 不满仓时现金收益记 0;仓位变化同样付 15 bp。

## 2. 报什么(因为不满仓,必须看全部收益)

每本书在每一段:全部收益的年化 / 波动 / 夏普 / 最大回撤(复利净值)/ Calmar;对全市场等权的净超额年化与夏普;平均仓位、换手、持股数、
最差 20 日收益;2024-01-16 ~ 02-06(微盘踩踏)那段的全部收益和超额。
对基线的成对量(同一天相减):全部收益差的年化与 t;**夏普差的成对区组自助法 90% 区间**(区组 20 天、2000 次);回撤差。

## 3. 方法清单(每个方法的网格都事先写死,见 `scripts/risk_control.py` 的 `GRID`)

### A 侧:融合之前(因子 / 族层面)
- **A1 族失效门控**:每个族过去 W 天(到第 t−2 行)的日度 rank IC 均值的 t 值 < 阈值 → 该族权重置 0(或减半);W ∈ {60, 120, 250},阈值 ∈ {0, −1}。
- **A2 族回撤止损**:族的十分位多空累计收益从高点回撤超过 k 倍其滚动日波动×√W → 停用直到收复这次回撤的一半;k ∈ {2, 3}。
- **A3 族波动倒数加权**:族间权重 × (目标波动 / 过去 60 天族多空收益波动),截到 [0.5, 2]。
- **A4 分歧惩罚**(逐股票的信号不确定性):得分 = 加权族均值 − λ × 该股票在各族 z 分数上的加权标准差;λ ∈ {0.25, 0.5, 1}。
- **A5 族因子先对风险暴露中性化再融合**:对每个族逐日截面回归掉 {行业} / {行业 + 对数流通市值} / {行业 + 市值 + 20 日波动 + 20 日成交额},取残差再按原权重融合。
- 尺子:族等权(不拟合族间权重)。
- 先验(写在前面):§16 的结论是滚动重拟合权重输给静态(漂的是噪声),A1–A3 很可能同样没有;A5 会拿掉市值暴露,K002 说这批超额大半是市值 → 预期超额明显下降、回撤改善。

### B 侧:融合之后(股票 / 组合 / 仓位层面)
- **B1 股票风险筛子 / 降权**(在前 10% 里):
  剔近 10 日涨停过的(按板块限幅,K002 的 `e_xlimup10`);剔 20 日波动最高的 q;剔总市值最小的 q;剔 20 日涨幅最高的 q;剔低价(收盘 < 2 元,退市风险的替身);
  剔近 5 日跌停过的;q ∈ {5%, 10%, 20%}(全市场分位)。降权版:权重 ∝ 1/20 日波动(截断)。
- **B2 组合优化**:候选 = 信号前 20%;每 5 天解一次
  max α'w − λ·w'Σw − κ·‖w − w_prev‖₁,约束 0 ≤ w ≤ 单票上限、Σw ≤ 1、行业相对全市场等权的偏离 ≤ δ、(可选)对数市值暴露下限;
  Σ = 因子风险模型(行业 + 市值 + 波动 + 流动性 + 市场,截面回归估因子收益,因子协方差 250 天、特质方差 60 天收缩)。
  λ ∈ {5, 20, 80},行业偏离 δ ∈ {无, 5%},市值下限 ∈ {无, 有}。最小方差化的尺子:λ→大。
  **修订(仍在任何结果之前,量纲核算后改)**:日频单位下 α ≈ 1e-3、组合日方差 ≈ 2.6e-4,允许留现金时仓位 ≈ α / (λσ²),λ = 20 / 80 只剩两成 / 半成仓,没有意义 →
  满仓(Σw = 1)λ ∈ {1, 5, 20, 80};可留现金(Σw ≤ 1)λ ∈ {2, 5, 10};各 × 行业偏离 {无, 5%},共 14 格。市值下限不做(格子太多)。
  α = 训练段市场日均收益 + 候选集内「超额 = a + s·z」的训练段回归;换手惩罚 = 15 bp / 10 天;单票上限 = 等权权重的 5 倍;每 5 天解一次,候选集外的持仓卖出。
- **B3 不满仓(仓位随风险状态变)**:
  (a) 目标波动:仓位 = min(1, σ* / 组合过去 20 天实现波动),σ* ∈ {15%, 20%, 25%};
  (b) 市场趋势:全市场等权指数在 N 日均线下 → 仓位 0.5;N ∈ {20, 60, 120};
  (c) 踩踏识别:过去 5 天「小市值最小五分之一 − 最大五分之一」收益 < −x 或昨日跌停家数占比 > y → 仓位 0.5,状态持续到条件解除后 5 天;
  (d) 组合自身回撤:净值从高点回撤 > d → 仓位 0.5,回到高点的 (1 − d/2) 才恢复;d ∈ {10%, 15%};
  (e) 截面离散度 / 波动状态:全市场截面收益标准差的 20 日均值处在自身过去 250 天的最高十分位 → 仓位 0.5。
- 组合:A 侧选中的 + B1 选中的 + B2/B3 选中的叠在一起。

## 4. 选择与判读规则

1. 每个方法族在自己的网格里**按样本内全部收益的 Calmar × 夏普的几何平均**选一个(并列取更保守的);只有这个被选中的格子的样本外读数算「按规则的读数」,其余格子的样本外只作敏感性列出。
2. 「风控有用」= 合并样本外上,相对基线:夏普差的自助区间下界 > 0,**或** 最大回撤改善 ≥ 四分之一且年化全部收益损失 ≤ 2 个点。两条都不满足 = 没有;
   夏普差区间跨 0 但回撤改善的,写「降风险换收益,比例是多少」,不写「更好」。
3. 样本内就不如基线的方法(样本内 Calmar 和夏普都更差)直接判没有,不看样本外。
4. 测试段和前推段对这两个冠军本身早已读过(不干净的是「冠军是谁」,不是风控参数);风控参数没有碰过样本外。读数记账 `runs/_forward/ledger.json`。
5. 多重比较:约十几个方法族,单个方法夏普差区间刚过 0 的只记候选。

## 5. 已知的局限(先写)
- 行业只有 2026-08/09 的申万一级快照,回填到全历史 = 行业归属有轻微前视(行业变更少)。
- 没有 ST 标记、没有真实指数与期货 → 对冲版不做;「不满仓」只是降仓位。
- 书是权重 × 标签的记账,不是 100 万真实撮合(最低佣金、整手);有用的方法再搬进 AlphaCube `tradable_backtest.py` 复核。
- 涨停买不进的持仓记 0(沿用旧口径),卖不出(跌停)没有建模 → 踩踏期的真实回撤比账面更深,风控的真实价值可能被低估也可能被高估(想卖卖不掉)。
