## 一句话
- **市场下跌预测**:按规则选中的那个(不拟合的合成分)没用;没被选中的逻辑回归在样本外把夏普从 1.0 抬到 1.3、回撤从 −37% 压到 −21%、年化还多 2.6 个点 ——
  **但全部增益来自 2024 年 1 ~ 2 月那一次**,其余每一年都是小亏,15 段下跌里它提前一天标出来的只有 3 段。是一个值得前推跟踪的候选,不是已证明的能力。
- **坏股票门控**:预测器很准(样本外 AUC 0.72),但用它门控是亏的 —— 冠军头部里「最可能大跌」的票恰恰是平均赚得最多的票(次日超额 +11.5 bp 对 +8.4 bp)。
  把波动因素去掉的不对称版(事后)方向对了,增益只有 +0.5 ~ +1.3 个点 / 年(t ≤ 1.3)。

逻辑回归那一格为什么不能算数:
1. **规则没选它**,而且它样本内窗口的 AUC 是 0.44(比瞎猜还差)、样本内账面不如基线(夏普 1.41 对 1.47)。2020 ~ 2021 年的预测只见过 2018 ~ 2019 一种行情。
2. 逐年对基线的差(手写库):2020 −2.8、2021 −0.4、2022 −1.9、2023 −6.4、**2024 +14.2**、2025 −5.9、2026 −1.6 个点。去掉 2024-01-16 ~ 02-08 这 17 天,样本外年化差是 −1.5 个点(夏普 1.56 对 1.42,略高,因为波动也降了)。
3. 样本外 15 段下跌(5 日 < −5%)里,前一天已被标记的 3 段(2024-01 下旬、2024-05 末、2024-12 末);2024-01-12 那段是开跌后才标上、接着标满了 1 月下旬的主跌段;
   2024-10-08(暴涨后的回落)、2025-04(关税)、2026-03、2026-06、2026-07 全没标。
4. 它标记的日子很多(2022 年 46%、2023 年 69%、2024 年 46%),更像「处在弱势环境」的指示,而不是崩盘预警;两个冠军共用同一个市场模型,两列数字不是两次独立验证。

## S:坏股票门控

| | 样本外 AUC(最差一成) | 组合里被预测最坏的五分之一 vs 其余:次日超额(bp) | 门控后对基线年化差(手写库 / 挖掘) |
|---|---|---|---|
| S:P(未来 1 天最差一成) | 0.72 / 0.73 | **+11.5 对 +8.4** / +13.0 对 +7.7(坏的反而更赚) | −1.1 ~ −5.1 / −1.2 ~ −5.1 |
| S:P(未来 5 天最差一成) | 0.73 / 0.73 | +9.5 对 +8.9 / +11.2 对 +8.0 | −0.1 ~ −3.4 / −1.0 ~ −4.7 |
| S2(事后):P(最差一成) − P(最好一成),5 天 | 0.64 / 0.61 | +5.3 对 +9.7 / +6.0 对 +9.0(方向对了) | 软 λ = 0.1:**+1.3(t 1.3)/ +0.5(t 0.5)**;硬门控 −0.2 ~ +0.4 |

- 模型最看重的特征:20 日内跌停 / 涨停次数、日内振幅、上市天数、特质波动、换手突增 —— 它学到的是「谁的尾巴肥」,而肥尾在冠军的头部是被补偿的。
  尺子也是这个意思:前 20% 里按预测对半分,「最坏」那一半超额 +18.0% / 夏普 2.71,「最好」那一半 +10.5% / 1.19。
- 不对称版把两侧尾巴相减之后才有一点门控价值,但量级在噪声里(夏普差区间 [−0.02, +0.07]),回撤没有改善(−38.7% 对 −37.3%)。
- 叠加(M 选中 + S 选中)、条件门控(只在被标记的日子门控)都不如基线。

## 结论与下一步
1. 只靠价量的内部状态,**极端下跌预测没有被证明**:唯一好看的一格靠一次事件。可以做的是把逻辑回归那一格原样冻结、从现在起前推记账(不再调),攒独立的样本。
2. 要真提高预测力,需要价量之外的信息:两融余额与强平线附近的密度、股指期货基差(IM / IC 贴水)、期权隐含波动与偏度、雪球 / DMA 的敲入规模、北向 / ETF 申赎(国家队)、政策日历。服务器上都没有。
3. 股票层面:不要按「尾部风险」门控。若要继续,方向是不对称目标(下行减上行)并且并进冠军的因子池让两层合成去定权重,而不是事后门控。

### 6.2 不对称坏股票预测并进因子池(`runs/_risk/asym_factor_study.json`,因子面板在服务器 `runs/_risk/asym_factor_h5.npy`)
因子 = 全市场前滚 LightGBM 的 `−[P(未来 5 天最差一成) − P(最好一成)]`,25 个风险特征,不用冠军信号。

| | 手写库冠军 | 挖掘冠军 |
|---|---|---|
| 101 族 − 同窗口重拟合的 100 族(事先定的主比较),合并样本外 | +3.2 个点(t 1.4);测试 +4.1(t 1.5)、前推 −0.2 | **+2.5 个点(t 2.0)**;测试 +2.6(t 1.8)、前推 +2.0(t 1.0) |
| 同窗口 100 族 − 现役冠军(拟合窗口缩短的代价) | −2.6(t −1.7) | −2.2(t −2.2) |
| 101 族 − 现役冠军 | +0.5(t 0.3);前推 −2.7 | +0.3(t 0.3);前推 −0.6 |
| 样本外超额夏普:现役 / 101 族 | 2.16 / 1.80 | 1.91 / 1.74 |
| 样本外全部收益回撤:现役 / 101 族 | −37.3% / −40.3% | −35.5% / −37.1% |

- 按事先的判据(合并段 t ≥ 2):挖掘冠军刚好到线、手写库没到 → **只记候选**。而且这个增量刚好被「拟合窗口从 2018 缩到 2020 起」的损失吃掉,对现役冠军的净效果是 0;超额夏普更低、回撤更深 —— **它不是风控,是又一个偏小票高波动的收益来源**。
- 副产品 1:这个因子单独就很强 —— 样本外 rank IC 0.063、纯多头净超额 +19.2% / 夏普 1.45(测试 +20.7% / 1.57,前推 +14.1% / 1.07)。25 个朴素风险特征 + 前滚树模型,收益和冠军同量级、稳定性差一截。
- 副产品 2:族间权重的拟合窗口少用 2018 ~ 2019 两年,样本外就少 2.2 ~ 2.6 个点(t −1.7 / −2.2)—— 拟合样本长度比多一个因子更值钱。
- 要让它干净地并池,得把因子的历史补到 2018(用更早的数据训练,服务器的分钟库从 2018 才有 → 做不到),或者等样本变长。

### 到这里为止的整体结论(R001 + R002)
在只有价量数据、只能做多的前提下:没有找到能显著提高全部收益夏普的风控;能确定的只有「趋势半仓拿收益换回撤」;「预测下跌」有一个冻结待验的候选;
「门控坏股票」方向是错的(头部的肥尾被补偿)。再往下走需要新的信息或新的工具(对冲),不是新的算法。
