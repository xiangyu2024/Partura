# C03:风格中性化奖励下,Partura v2 对 AlphaCube GP(事先约定)

写于 2026-10-28 01:20,在本实验的任何运行之前。提交之后不改;要改另写「修订」。

## 1. 问题与来由

C01、C02 都按事先约定判定「Partura 更差」。两个实验里测试段「有效」的 head,做风格中性化后几乎全部消失:
C01 两组 19 → 2、13 → 1;C02 两组 7 → 2、2 → 0。搜索器和 agent 都在一个会为风格暴露付钱的奖励上优化。
文献调研(`research/coldstart_C02/lit_review.md`)把「奖励改成风格中性化后的残差」列为第一优先,并建议用 16 个配对种子压住种子方差。

**C03 的问题:当奖励只为「去掉流动性、波动、反转与已知族之后剩下的东西」付钱时,Partura v2 能不能比 GP 在测试段找到更多有效、新的信号?**

## 2. 设计

与 C02 相同的部分:数据与时段;Partura v2 的流程(W1 写假设 → 直接检验 → W2 设计初始种群 → GP 精修);环境规则里的相关度拒绝(与已知族 |ρ| ≥ 0.5)和计算成本禁令(`ts_spearman`、`nt_*`);种子占初代上限 50%;磁盘守护与 180 分钟时限;两台服务器(同一种子的两组在同一台)。

改动:

| 项 | C02 | **C03** |
|---|---|---|
| 奖励 | `long` | **`long_neutral`**:信号先按方向与半衰期平滑,再取截面 z 排名,对每天的 [1, 流动性 `cross_mean(day_sum(Amt), 30)`, 波动 `cross_mean(day_std(Ret), 20)`, 20 日反转 `div(day_last(Close), ts_delay(day_last(Close), 20))`, 已知族 `cross_mean(day_std(Amt), 30)`](z 排名)做 OLS 取残差,用残差建十分位纯多头书,扣 15bp;score = train 与 valid 较差的 |
| 发现门槛 | 0.7 | **0.5**(残差书去掉了风格的 beta,夏普整体更低) |
| 种子 | 8(401–408) | **16(601–616)**,两台服务器各 8 个 |
| B 组 GP 预算 | 192 − ⌈64/8⌉ = 184 | 192 − ⌈64/16⌉ = **188** |
| Partura 可读的先验 | C01 样本内 | C01 + **C02 的样本内**材料(C02 的 PLAN、prior_c01、hypotheses、direct、design、beliefs、w1/w2 记录、episodes/c02* 两组证据) |
| 「新」 | 与 C01 heads \|ρ\| < 0.7 | 与 **C01 和 C02** 的 heads \|ρ\| < 0.7 |

实现(`partura/steer.py` 的 `neutral_basis` / `neutral_residual`,GPU 版在 `steer_fast.py`):每天对有全部控制变量的股票求 [1, 控制] 的正交基;
候选缺值的格子在投影时按平均排名(0)填,结果里仍是缺值;残差的截面离散小于浮点噪声的日子判为没有信号。这是一个近似,对两组完全相同。

## 3. 判读(写死)

- **发现**:score ≥ 0.5 且未被相关度拒绝;B 组含直接检验里的发现。
- **heads**:每组按 score 贪心去重。所有信号都取**残差**(奖励交易的就是它)。要求:与已知族 |ρ| < 0.5、与本组已收 head |ρ| < 0.7、与 C01 和 C02 的全部 head |ρ| < 0.7(先验 head 同样取残差后比较)。
- **有效**:测试段**残差书**年化净超额 > 0 且 t = 夏普 × √年数 ≥ 2.0。
- **主指标与判定**:每组有效 head 数;B − A ≥ 2 且 B ≥ 2 × max(A, 1) 为「Partura v2 有用」,A − B ≥ 2 为「更差」,其余「分不出」。
- **次指标**:16 对同种子配对(样本内 heads,符号检验);每组 heads 测试段残差夏普的均值;融合书;前推段;GPU 时间与 token。
- 台账 `runs/_c03/ledger.json`;测试段只读一次。

## 4. 已知局限

- 截面线性中性化只保证整体不相关,不保证前 10% 的暴露为零(合成数据上已见:非线性混合的信号,残差的头部仍可能带反向的风格暴露)。
- 控制变量里没有市值(数据里没有流通市值字段);流动性代理部分替代。
- 测试段与 C01、C02 相同,设计者看过它们的样本外结果;Partura 不得读(C01 / C02 的 RESULT.md、final*.json、ledger)。
- 幸存者偏差、A 股纯多头口径,同前。
