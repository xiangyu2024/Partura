# 种子 804 · P 组 · PI 笔记

## 第 1 轮

### 我目前对本种子 alpha 来源的信念

- **M 第 1 批的共性表基本不含 alpha 信息。** 117 个候选均值约 −1.1,0 个 head。表头的几行(`day_pos_ratio(Open)`、`cs_normalize(BoardCode)`、`LogFloatShares` 家族)都是慢变量或常数,它们的「提升」最可能来自换手低、扣费少,不是预测力(同意解剖员 §1.3)。
- **`day_pos_ratio(Open)` 很可能是常数面板**(价格在有限分钟上恒为正),被 `cs_last_high20` 的序数秩洗成股票列序。没有开它的 E。
- **新事实(本轮我自己量的):裸的 `ts_var(LogFloatShares, 10)` 不是「无事件 = 精确 0」。** 我用引擎在合成立方体上实测:股数不变的 10 日窗口里,约一半股票得到 3.6e-12 的 float32 舍入残差(CPU 上也是这样;所以解剖员 §1.6「位级相同 ⇒ 方差精确为 0」不成立)。真实事件的方差在 1e-8 以上,中间隔了三个数量级以上。所以 M 用过的那 5 个含裸核心的候选,很可能是按浮点位把股票分成两半;它的 +0.56 均值差我认为也是慢变量效应,不是事件效应。这个核心有用的部分要靠阈值 `is_gt(·, 1e-8)`(或 `sign(ts_delta(·))`)取出来。放在 `cs_last_*` 的筛位上,残差块是一整个并列块,本来就进不了 band;但用在算术里就是伪影。
- **我押的真来源**(都还没有证据,只有先验):
  1. 跨「昨收—今开」边界的结构(T+1 + 集合竞价):M 的共性表里完全没有这一类;
  2. 股本供给冲击(解禁、增发、送转),作为多头书的排除筛,外加修正以股数计量的量价变量被股本变动机械污染的问题;
  3. 换手冲击(短窗 / 长窗成交量比):这是 A 股已知的强慢因子,本轮放在 E 位的 y 里。

### 本轮的任务与事先预测

**位 a · E · 核心 `ts_var(LogFloatShares, 10)`**(阈值化 / 带符号后放在整块筛位上;y 是 −log 名义股价、股数计异常成交量、股数计换手,外加一年扩张 / 待解禁存量的第二道筛)
- 审计:预计通过。核心与 5 个控制的 |ρ| 都 < 0.3;核心本身在相关度表里会是「废品」(distinct 很低),这已在 hypothesis 里讲明。种子不会被控制列划掉,最高的大概是股数计换手那颗(与 liq / known 0.5–0.7)。
- 产出:**P(≥1 个 head) ≈ 30%。** 如果有,最可能是「异常成交量(5/60 或 10/60)+ 事件筛」,方向为负(近期相对放量的不买)。score 约 0.5–0.8,而且它和不加筛的同一个 y 的 ρ 会 ≥ 0.9:筛本身贡献 ≤ +0.1 夏普。−log 名义股价做 y 的那几颗,我预计过不了 min(train, valid)(2022–23 低价微盘行情会翻转方向)。GP 会把 y 往成交量比方向漂。
- 证伪:如果最好的候选是名义股价类且两段都 ≥ 0.5,说明我对低价股样本期翻转的判断错了。

**位 b · N · 隔夜与日内的拉锯**(G = 隔夜对数收益,I = 日内对数收益,F = 开盘分钟成交额份额;均值、差、相关、份额)
- 审计:预计通过。`cross_mean(abs_(G), 20)` 与 vol 控制可能到 0.6–0.75(不到 0.8,不划);G−I 价差与 rev 约 0.3–0.6。
- 产出:**P(≥1 个 head) ≈ 35%。** 最可能的是 `cross_corr(G, I, ·)` 或 G−I 价差,方向:隔夜相对日内越强的越跑输(标签从 T+1 开盘 VWAP 起算,正好吃到日内回吐那一段)。|G| 均值大概率被波动控制吃掉,score < 0。F 类(开盘竞价参与度)方向为负,可能是一个独立的弱信号(0.2–0.5)。
- 证伪:如果 G 的均值类最好、而且方向为正(隔夜强者继续强),那这里的机制就是隔夜动量 / 注意力延续,不是情绪反转;下一轮要改用延续的解释去配外围。
