### 1.2 轴 C(新):`day_kurt(Ret)` —— 本轮最值得买的东西

**(a) 算子读准(`alphacube/operators/dt_day.py:124` → `operators/common.py:411`)**

```
_kurt(x) = mean((x − mean)^4) / (mean(var))^2 − 3     # 超额峰度,m4 / m2² − 3
```

两条要点:

1. **它是无量纲的**,分母是方差的平方。所以它**不是**波动水平换个写法,规则 §4 陷阱 1 点名的
   「`day_durbin_watson` ≈ 已实现方差 + 凸变换」那条通道在这里不成立。这一点必须说清,否则审计会按陷阱 1 直接打合理度 1。
2. 但它是一个**饱和的集中度度量**:n 根 bar 里若有一根的平方收益远大于其余,m4/m2² → n(本立方体 n = 241);
   若日内收益分布均匀,它 ≈ 0(超额)。粗算:一根 bar 幅度 g、其余分钟标准差 s,
   g=1%、s=0.15% 时 kurt ≈ 5;g=3% 时 kurt ≈ 91。**它读的是「当天的价格变动有多集中在一根 bar 上」。**

**(b) 那根 bar 大半是 09:30 集合竞价。**
`alphacube/operators/dt_in.py:314` 的注释明确:**V2 的第 0 列是 09:30 集合竞价**(第 2 轮审计也核过这条,
`in_slice(Ret, 1, 237)` = 09:31–14:57)。竞价那根 bar 的收益按构造是日内任何一分钟的几倍到几十倍,
所以 `day_kurt(Ret)` 在绝大多数股票日上**就是「隔夜跳空 / 开盘竞价相对日内分钟波动的平方比」的饱和变换**。
→ 这是本轮最关键、也最便宜的一次区分:`day_kurt(in_slice(Ret, 1, 237))`(剥掉第 0 列)值多少。
**注意:这件事做不进 E 位的外围**,因为 E 要求候选原样含核心 `day_kurt(Ret)`,
而 `day_kurt(in_slice(Ret, 1, 237))` 不含(`c06_check.py:119-122` 按节点 key 比对)。只能用 R 变体或 N 种子买。

**(c) 为什么说它是 H3 的真载体(四条独立证据)**

**(d) 方向,以及和轴 B 的一个潜在矛盾**
H3 的 sign = +1,信号 = X − kurt → **多头腿是 kurt 最低的票**,即当天的波动平摊在 241 根 bar 上、没有一根独大:

3. **全天封板 ⇒ NaN**:m2 = 0 时 `div(0, 0)` = NaN(`operators/common.py:168` 是裸 `torch.divide`),

   **结论:轴 C 的实验便宜、确定能拿到数字,这是它比轴 B 适合投最后一轮的主要理由。**

### 1.4 必须撤回的判别式,以及 score 的脆弱性(本轮方法论的核心)

R 第 1 组 8 个变体,外壳完全不动,只换中间那一个部件。把实测的 **score** 和**与原 head 的交易残差 ρ**
(`R_prev.json` 的 `rho_head`,口径 = 加过 sign、按 hl 平滑、对 5 个控制取残差之后,train 每 5 天一天 —— 正是书真正交易的那个量)并排放:

| 变体(换掉的部件) | ρ(交易残差, 原 H2) | score | train | valid |
|---|---|---|---|---|
| `neg(day_zero_ratio(Ret))` 换掉原子 | **0.9452** | +0.7869 | 0.787 | 1.276 |
| `day_distinct_ratio(Close)` 换掉原子 | **0.9338** | +0.4559 | 0.456 | 0.916 |
| 再按 `day_std(Ret)` 配一层 | **0.9015** | +0.2641 | 0.264 | 0.493 |
| `cross_mean(·, 60)` 换掉 `ts_max∘ts_max` | **0.8918** | **−0.0627** | −0.063 | 0.304 |
| 再按 `sub(log(day_sum(Amt)), LogFloatCap)` 配一层 | **0.8767** | +0.1523 | 0.152 | 0.375 |
| 再按 `day_zero_ratio(Ret)` 配一层(= 新 H2) | 0.6428 | **+1.1606** | 1.161 | 1.456 |
| 再按 `div(day_sum(Amt), day_sum(Volume))` 配一层 | 0.175 | **−1.0258** | 0.124 | −1.026 |
| 价格 + 换手连配两层 | 0.1948 | −0.5489 | 0.754 | −0.549 |
| (原 H2) | 1.000 | +0.8156 | 0.816 | 1.363 |

**五个 ρ ∈ [0.88, 0.95] 的变体,score 从 −0.06 跨到 +0.79,跨度 0.85;valid 腿从 0.30 跨到 1.28。**

为什么会这样:奖励建的是**残差的十分位纯多头书**,只有最高那 10% 进书。
高斯近似的粗算(只定数量级):ρ = 0.95 时前 10% 重叠约 78%,ρ = 0.90 约 69%,ρ = 0.88 约 66%,ρ = 0.64 约 42%。
也就是说一个 ρ = 0.89 的变体换掉了多头书里约**三分之一**的名字,而分数掉了 0.88。

**三条推论(第 3 轮的一切判读都要按这个打折):**

1. **我第 2 轮写的判别式作废。** 「按 vol / liq 配对后掉到 0.3 以下 → 轴 B 是控制的非线性重写」——
   按字面读实测是掉了(0.2641 / 0.1523),但配完之后信号与原 head 还有 0.90 / 0.88 的残差相关,
   **内容基本没变**。能确定的只有一件事:**多头那一档里被换掉的三分之一名字,承担了几乎全部的多头夏普**。
   这与「低波动腿从线性中性化的缝里漏回来」是**相容的**(漏回来的东西按定义就藏在一个角落里,整体 ρ 看不出来:
   核心自己与 vol 的 ρ 只有 0.188,配掉之后 0.02,代价 0.55 的分数),但也与「真信号集中在这一角」相容。
   **这两种读法用 score 分不开。** 要分开,只能看那一角的名字是什么(本环境里买不到),或者看样本外。
2. **R 的 +0.1 门槛不是一道强门槛。** 同一机制的不同写法之间,score 的「噪声」量级就有 0.3–0.8。
   所以 R 替换成功**不等于**找到了更好的因子;本轮我们那次替换(+0.345)必须用独立证据复核(§0(C)、§4.2)。
3. **库里 head 的 score 排序不要太当真。** H1 +1.45 与 H3 +1.10 的差距,小于上面那张表里同一个信号两种写法的差距。
   给最终的样本外评估留一句话:**两条腿都舒服高过门槛的 head**(H1 1.47/1.45、H3 1.10/1.49、H2 1.16/1.46)
   比**靠 min 刚好交叉的 head**(H8 0.74/0.56、H4 0.85/0.79)结实;
   第 2 轮 §1.4 记过 H5 的窗口阶梯(1.40/0.40 → 0.74/0.77 → 0.35/0.75)就是 score = min(train, valid) 自带的选择偏差。

### 1.5 轴 A:本轮把它彻底钉死了

**(a) 五个单调变换各自成一行共性,效应几乎相同** —— 这是「一个因子的多种写法」最干净的证据:

## 4. 本轮候选

### 4.0 本轮的分工原则(先说这个,后面都从它推出来)

1. **库禁令现在是最紧的约束,不是闸门。** 库 = 8 个 head。任何候选与某个 head 的日度秩 ρ ≥ 0.7 会被
   `RankSimilarityBan` 打成 `fit = -inf`(`alphacube/mining/gp.py:459-471`)。
   注意它和 `c05_no_core` 不一样:**不含核心的候选是在打分之前被免费拒掉的**(`idea_search.py:396-402`,第 2 轮免费拒了 2582 个),
   **而库禁令是在算完面板和 IC 之后才打掉**。所以「核心离某个 head 太近」= 这个位把算力烧在禁令上。
2. **轴 C 的干净写法已经被 H3 自己堵住了。** H3 ≈ `−day_kurt(Ret)`,所以 `cross_mean(day_kurt(Ret), 20)` 这种干净水平
   与 H3 的残差 ρ 极可能 ≥ 0.7 → **GP 位里拿不到它**。
   **但 R 不受库禁令管**:`c05_locate.py` 的 direct 模式是直接评估,只在最后判替换 / 收录时看 ρ。
   → **R 买「干净的水平写法」,E 买「条件化 / 分段 / 差分的写法」。** 这两件事刚好也是科学上要分开的两件事。
3. **E 位的核心必须原样出现在每个候选里**(`c06_check.py:119-122`),所以凡是要**改核心内部**的实验
   (剥掉 09:30 那根 bar、换时段、换字段)都做不进 E 的外围,只能走 R 或 N。
4. **外围新颖性只看算子名的 frozenset,而且 SEEN 在开跑前就冻住了**(`idea_search.py:312-317`:
   `SEEN` 只从档案里「含该核心的候选」初始化,运行期间**不再更新**)。两条推论:
   (i) 只换窗口或只换字段**不产生新外围**(`_ops` 只数带操作数的节点,叶子和常数不算),
   所以 `cross_mean(day_kurt(Ret), 20)` 和 `cross_mean(day_kurt(Ret), 60)` 是同一个外围;
   (ii) 同一轮里**多颗种子可以共用一个外围**,不会互相挡 —— 只要它不在档案里出现过。
5. **两个并行位之间不去重**(第 2 轮已记)。所以两个位不要押同一个机制;如果押相邻机制,要在写法上人为分开。

### 4.3 N 的灵感

制度上本轮可以 E+E(§3.2)。但库里 8 个 head 有 5 个在同一条代理轴上,最终比的是整个库的样本外表现,
所以**第四条独立的轴仍然值一个位**。两个方案:

**N-1(推荐):开盘竞价 / 隔夜 vs 日内的方差分解。**
- 机制:§1.2(b) 说 `day_kurt(Ret)` 大半是「当天的变动有多集中在 09:30 那根 bar 上」。
  把它**显式写出来**,就是一个全新的输入:库里 8 个 head 没有一个用过第 0 列的值
  (第 2 轮唯一碰过时段的位是把它**切掉**),而第 0 列是全天唯一带隔夜信息的 bar。
- 算子:`day_first(x)` = 当天第一个有限值(`dt_day.py:132`,`day_open` 是它的别名),所以隔夜 / 竞价收益就是 `day_first(Ret)`。
  方差占比写成 `div(mul(day_first(Ret), day_first(Ret)), day_sum(mul(Ret, Ret)))` —— 在 [0,1]、无量纲、连续,**闸门必过**;
  日内那一半写成 `div(day_sum(mul(in_slice(Ret, 1, 237), in_slice(Ret, 1, 237))), day_sum(mul(Ret, Ret)))`;
  水平用 `cross_mean(·, 20/60)`,冲击用 `sub(cross_mean(·, 5), cross_mean(·, 60))`;
  去替身的条件版在波动 / 换手 / 停滞十分位内排序(`cs_bucket_rank`)。
- 要避开的坑:**不要用带符号的隔夜收益**(那是反转控制的换皮,第 2 轮 RSJ 两颗就是这么被划掉的,rev 0.59 / 0.49);

- 与 E 位的分工(两个并行位不去重,必须人为分开):**E 位只许用 `day_kurt(Ret)` 原样 + 条件化 / 分段 / 差分的外围,
  N 位独占第 0 列和时段切分。** 这样两个位的输入在构造上就不同。
- 文献:见 §5 的 Q2,都是 2023-08 之前的。

**N-2(次选):交易约束轴(`LimitWidth` / `BoardCode`)。**
三轮一次没跑过(唯一的载体第 1 轮被审计划掉)。真正独立,但载体弱:3–4 档的离散字段单独当因子必被闸门挡死,

**不建议**:再碰带符号三阶矩(§3.2 有共性证据,p 0.82);名义股价(三轮三次证伪);自由流通比例(大概率是规模的第四种写法)。
