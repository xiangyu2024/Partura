## 1. 先确立四条新的代码事实(本轮所有判断建在这上面)

r2 已经确立的三条(奖励流程 = 表达式 → 逐股 EMA → 截面平均秩 → 对 5 控制取残差 → 前 10% 等权纯多头;`_lexi` 家族只用两个参数的秩,
所以套在它参数位上的单调变换是死算子;一个「平坦块」+ 线性中性化 = 做多控制拟合值最低的那一端)继续有效。本轮再加四条。

**(4) 已知族控制与 `day_centroid` 是同一个日内剖面的两个矩。**
已知族 = `cross_mean(day_std(Amt), 30)`,即「分钟成交额在日内的离散度」的 30 日均值;`day_centroid(Amt)`(`ops_ext.py:155`)
= `Σ t·|x_t| / Σ|x| / (T−1)`,即同一条分钟成交额剖面的一阶矩。成交额剖面越偏向收盘(重心大),剖面越尖、`day_std(Amt)` 越大。
两者在结构上同源 ⇒ **任何「水平版」的成交时点因子都是已知族的非线性重写**,线性 |ρ| 只有 0.49 并不说明它干净,
这正是 r2 的 R 组测出 1.22 → 0.36 的原因。**推论:这一族的水平不能再碰;要碰只能碰「剖面形状被约掉」的量。**

**(5) `cs_stddev_full(X)` 是每日截面常数,减它是严格的死算子(只剩一个 EMA/缺失日的残差)。**
`nd_cs.py:185-203`:逐行(= 逐日跨股票)样本标准差,`std.expand_as(x)` 广播回原形。所以 `sub(X, cs_stddev_full(Y))` 当日对所有股票减同一个数,
`_zrank` 之后的截面秩与 `X` 完全一样。唯一的缝隙是 EMA:`ema_rows`(`metrics.py:215-234`)逐股递推、缺失日保持状态、首个有限值起始,
所以不同上市日 / 停牌模式的股票累计到的常数略有差别。head 11 的 hl = 20,这条缝隙就是它和 `day_q_stat_std(pow_1_5(Ret))`
之间那 0.04 分的全部来源。**r2b 的 26 个过线候选是 1 个信号 + 一层 ListAge/停牌伪影;26 个过线只收 1 个 head,正是库禁令在替我们说这件事。**

**(6) `pow_1_5` 对负数给 NaN —— 它把所有下跌分钟删掉。**
`common.py:209-218`:`pow_(x, e) = where(e ≤ 1, sign(x)·|x|^e, x**e)`。`e = 1.5 > 1` 走 `x**e` 这一支,
而 IEEE / torch 的 `pow(负数, 非整数)` = NaN。所以 `pow_1_5(Ret)` = 上涨分钟取 `Ret^1.5`、零收益分钟取 0、**下跌分钟全部变 NaN**。
(对照:`pow_05` / `pow_2_5(Amt)` / `pow_1_5(LogFloatShares)` 作用在正量上,不触发这条。)
**这一条我没能在本机执行验证(环境里没有 torch / numpy),它是源码 + IEEE 语义的读法,本轮必须用 R 变体去验(见 §3 R-B)。**

**(7) `day_q_stat_std` 用的是整行长度 T = 241,而不是真正有效的配对数 ⇒ 它读的是有效样本量,不是自相关。**
`dt_day.py:366-416`:对 k = 1..20 算 ρ̂_k(成对剔除 NaN),再 `Q_k = T(T+2)·cumsum(ρ̂²/(T−k))`,最后取 `std(Q_1..Q_20)`。
`T_t = float(T)` 是**整行的 241**,与该股票实际有多少个有效配对无关。在「没有真自相关」的零假设下 `E[ρ̂_k²] ≈ 1/n_pairs`,于是
`Q_20 ≈ 241·243·20/(231·n_pairs) ≈ 5.1e3 / n_pairs`,而单调递增序列的 std ≈ 0.3·Q_20,所以

> `day_q_stat_std(pow_1_5(Ret)) ≈ 1.5e3 / (可用的非负收益分钟配对数)`

这是一个**薄交易 / 零收益占比 / 价格离散度**的度量,由估计噪声主导,不是任何意义上的「日内收益可预测性」。方向 −1 = 做多该值低的、
即可用分钟多的那一端。同一支里的 `day_at_min_ratio(Open)`(当日等于最低价的分钟占比 —— 跌停封板 / 价格全天不动)
与 `day_ar1_coefficient(Open)`(日内价格水平的 AR(1) ≈ 1 − 噪声占比)是**同一类微观结构噪声度量**。
