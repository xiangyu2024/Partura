### 目前对本种子 alpha 来源的信念

- M 第 1 批只有一个 head:`inv(pow_3(pow_3(pow_3(LogFloatShares))))`,score +0.5001(train +0.50 / valid +0.79),压线过。
  四层算子在 LogFloatShares∈[16,27] 上是单调重参数化,日度截面秩与裸字段相同;它的三个充分性子树和敲除变体都是 +0.47 ~ +0.48,不过线。

  我给它是「真的低价股效应」60%,「残留的非线性规模暴露(陷阱 3)」30%,「EMA 时间凸性 × 中性化的管道假象」10%。

### 为什么本轮不开 E 位

- 定位输出里所有合法核心(head 的每个子树、共性表、核心卡)都是 LogFloatShares 的单调变换。
  按恒等式,LogFloatShares 与 LogFloatCap 控制的截面秩相关估计在 0.75–0.8(股本数量的截面离散远大于股价),远超 §3 的「E 位核心与每个控制 |ρ| < 0.5」——E 位几乎必然被判为「控制换个写法」,退成普通 GP。
  另外规则 §4 陷阱 3 把 LogFloatShares 列为市值字段,审计员很可能直接按陷阱给合理度 1。
- 解剖员 §4.1 推荐核心 1 的三条优势里,第 1 条(族中性化)是 C05 的奖励;C06 的 E 位**不**额外控制核心家族,这条不成立。第 2 条(塌缩子代被库禁令免费毙掉)仍成立,但这本身说明这个核心外面很难长出与 head |ρ| < 0.7 的东西。
- 所以本轮两个位都是 N(顺带把「3 轮至少 1 个 N 过审」提前满足),E 留给 M 后面几批出现的、不是控制换写法的核心。

### 本轮的选择,以及为什么不选别的

- **位 a = E,核心 `div(sub(day_wmean(Ret, Amt), day_mean(Ret)), day_std(Ret))`**(核心卡 15)。这是唯一干净的核心,本实验第一次给它开 E。
  - 关键约束我在 r1 没意识到:相关度表会划掉与任何 head 日度秩 |ρ| ≥ 0.7 的种子,GP 的库禁令也拒绝 ≥ 0.7 的后代。所以在这个核心外面只换平滑窗口的种子(cross_med、更长的 EMA、按流动性分桶排序之类)必然被划。13 个种子全部用差分、跨日协方差、逐股相关、交互和尾部,刻意离开「倾斜的水平」。
  - 外围五族的统一想法:水平里混着「股票固有的日内构成」(U 形 / 尾盘竞价占比,慢变)和「资金流信息」;相对自身历史、跨日加权、逐股信息性这几种外围把前者按构造扣掉。
- **位 b = N,隔夜与盘中的拉锯**(analysis §4.3 灵感 1,lit 题目 3 文献最厚)。控制里的 20 日反转是两段之和,切分按构造和它不重合;带符号的均值全部先除以自身波动(r1 被划的教训);再放 3 个 `cs_bucket_rank(·, 同期总收益)` 的种子,按构造与反转正交。
- **不选机械核心卡第 1 名**(B0 会取的 Σr³/(Σv³)²):分母就是已知族(0.58 ≥ 0.5)、分数来自凸度、数值溢出,在它外面长只会继续爬成交量的幂。改成 R 组 B 做剂量阶梯。
- **不碰任何含 `cs_state_rank` 的核心**(核心卡 2、7、14、17、18、19、21):陷阱 2,E 位合理度必为 1。
- **不碰 `LogFloatShares` 幂族**(核心卡 4–12):size |ρ| 0.78,E 位核心直接不过。
- **不做 analysis 建议的 R6a / R6b(纯列序斜坡的地板分)**:它是有意地评估一个陷阱 2 的构造,审计员大概率给这组合理度 1;若 ≥ +1.63 还会被 R 通道装进库,对样本外的库是纯损失。R4 / R1 / R3 这类「证死 artifact head」的变体也不做:R 通道不能删 head,它们改变不了库,只买信息,而源码 + 位等同已经给出了足够的证据。
  - **环境层面的建议**(写进报告):`cs_*` 的参数位应当拒绝截面常数(或 `cs_state_rank` 只允许出现在 `mul` / `add` 的权重位),否则 M 每一批都能用新的骨架重写同一条斜坡。
- **R 组 A(挂 +0.61,5 个)**:两个窗口 / 分母的小改动可能把它推过 +0.71 走替换;切片版是 U 形竞争解释的直接判别。**R 组 B(挂 +1.22,3 个)**:分母成交量幂 2 / 3 / 5 的阶梯。
