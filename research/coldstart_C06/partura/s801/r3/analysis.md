## 1. alpha 的来源

### 1.1 先说一个统一的机制:奖励对信号的单调变换**不不变**

奖励的口径是「信号先对 5 个控制做逐日截面**线性**中性化,用**残差**建十分位纯多头书」。
残差的单调变换 ≠ 单调变换的残差。所以 `f(X)` 与 `X`(f 严格单调)有**完全相同的逐日截面次序**,却可以有完全不同的分数。本轮的定位输出直接把这件事量出来了:

`day_durbin_watson(Close)` 恒为正(源码 `dt_day.py:273`:`Σ(Δx)²/Σx²`),`signedpower(x) = sign(x)·|x|^2`(`common.py:231`,默认 e=2),所以在正数上就是平方,**严格单调递增、保秩**:

| 表达式 | score | train | valid | 相对上一行 |
|---|---|---|---|---|
| `day_durbin_watson(Close)` | **−1.85** | −1.85 | −0.03 | — |
| `signedpower(day_durbin_watson(Close))` | **−0.21** | −0.21 | +1.92 | +1.64 |
| `signedpower(signedpower(day_durbin_watson(Close)))` | **+1.26** | +1.26 | +3.19 | +1.47 |
| `signedpower(signedpower(signedpower(day_durbin_watson(Close))))` | 不过门 | — | — | distinct 0.2934 |

三行的截面次序逐日逐股**完全一样**(DW > 0,平方保序),分数差 +3.11。第四行不是因为经济上不行,而是**float32 下溢**:分钟收益约 20 bp → DW ≈ 4e-6 → DW⁸ ≈ 6.6e-44,低于 float32 的最小正规数 1.18e-38,大部分股票被压成 0,distinct 掉到 0.29。凸度的阶梯是被数值精度截断的,不是被经济截断的。

同一个机制在外层再演一遍:head `+1.56` = `signedpower(Z)`,其中 `Z = ts_std(signedpower(signedpower(day_durbin_watson(Close))), 50) > 0`,所以 `signedpower` 在这里也**保秩**;定位里 `Z` 单独是 **+0.95**,套上这层保秩的平方变成 **+1.56**——**+0.61 分,零信息**。

这就是规则 §4.1 写的陷阱 1,只是这次有了一个把「次序固定住」的对照:**凸度买到的分数与信号本身无关,只与线性中性化被凸的尾部拉歪多少有关。**

同一个机制也解释了 r1 那个 head:`inv(pow_3(pow_3(pow_3(LogFloatShares))))`,`inv(x)=1/x`,在正区间 `1/x^27` 严格递减,逐日截面次序就是 `LogFloatShares` 的反序;r1 的 R 量过:裸 `LogFloatShares` **+0.4826**,四层包装 **+0.5001**。同样是保秩变换买分,只不过股本那条轴上的凸度弱(+0.02),波动这条轴上的凸度强(+3.11)——因为波动本身就是 5 个控制之一,凸的残余最值钱。

**所以 +1.56 / +1.44 / +0.67 / +1.22 / +0.50 这 5 个 head 是一件事**:对控制变量做单调(多数是凸)变换,从线性中性化的缝里把控制本身捞回来。

### 1.2 DW 波动凸度族(+1.56 / +1.44 / +0.67,M 第 3 批)

**这三个 head 的全部叶子只有 `Close` 一个,全部信息只有「日内已实现方差」一个量。**

- 源码:`day_durbin_watson(x) = Σ_t(x_t − x_{t−1})² / Σ_t x_t²`,分母不去均值。令 x = 分钟收盘价 P:
  `= E[(ΔP)²]/E[P²] ≈ E[P²·r²]/E[P²] ≈ E[r²]` = **当日分钟收益平方的均值 = 已实现方差 / T**。
  它对价格**水平**完全免疫(分子分母同为 P 的二次齐次),所以不是低价股代理;它就是波动,和控制 `cross_mean(day_std(Ret), 20)` 是同一个量,只差平滑。规则 §4.1 的第一句说的就是它。
- **共性**:`day_durbin_watson(Close)` 出现在 582 个已评分候选的 **46** 个里,含它 +0.408 / 不含 −0.975,均值差 **+1.38**,p 0.000;`signedpower(ts_stddev(day_durbin_watson(Close), 20))` 7 个候选,均值差 **+1.76**,p 0.000(共性表第 1 名)。M 第 3 批整批都压在这条轴上。
- **充分性**:见 §1.1 的阶梯。另一支:`ts_stddev(day_durbin_watson(Close), 20)` **+0.29** → `signedpower(ts_stddev(…, 20))` **+0.49** → 外面再套 `ts_std(·, 50)` **+1.44**。
- **必要性**:head `+1.44` 里敲掉 `signedpower` → `ts_std(ts_stddev(day_durbin_watson(Close), 20), 50)` **+1.13**(必要性 +0.31);敲掉 `ts_stddev(·,20)` → `ts_std(signedpower(day_durbin_watson(Close)), 50)` **+0.59**(必要性 +0.85)。head `+1.56` 里敲掉内两层 `signedpower` → **+0.75**(必要性 +0.81)。**两个零件都只是「平方」和「滚动标准差」,没有第三种成分。**
- **敏感性**:`Close→Vwap`:+1.56→**+1.39**、+1.44→**+1.33**。这不是「稳健」的好消息——分钟 Vwap 与分钟 Close 的已实现方差本来几乎相同,**这个换字段试验恰好证明读到的只有方差,没有任何 Close 特有的东西**。窗口:head `+1.56` 的 `ts_std@25/50/100 = +1.68 / +1.56 / +1.59`(平台,+0.12 是噪声);head `+1.44` 的 `@25/50/100 = +0.94 / +1.44 / +0.90`(50 是一个孤峰,高出两侧 0.5,**窗口拟合**)。
- 一个容易被当成「波动的波动」的误读要点破:`ts_std(·, d)` 作用在一个严格正、强右偏的量上时,标准差与均值近似成比例(尺度族),所以 `ts_std(DW⁴, 50) ∝ E[DW⁴] ∝ 波动^8`,外面再平方 ≈ 波动^16。**它不是 vol-of-vol,它是被抬到高次幂的波动水平。**
- `rho_known` 只有 0.21–0.26 所以过了已知族门槛——但已知族是 `cross_mean(day_std(Amt), 30)`(成交额离散),不是波动控制;波动控制只被**线性**扣掉,凸的那部分按 §4.1 留着。

**判:真来源 = 日内已实现方差的水平 + 保秩/凸变换。是陷阱 1,不是新信息。把握 90%。**
(剩下 10%:高次幂确实会把注意力挪到「极低波动」的那一端,如果低波动异象的多头腿在样本外还在,这三个 head 也许不会归零——但那也不是本组发现的东西。)

### 1.3 列序斜坡族(+1.53 / +0.75)与新的 +0.56

前两个 r2 已经定案(90% / 95% 是 artifact):`cs_state_rank(x, d)` 源码 `ops_ext.py:547` 明写 `r.unsqueeze(-1).expand_as(x)`——**每天对全市场输出同一个数**;喂进 `_pct_rank`(`ops_ext.py:231`,`torch.argsort(..., stable=True)`)之后,同值块按股票列序破平,出来的是一条静态列下标斜坡。定位里 `High→Low` 互换四位小数不变,就是位等同的证据。共性表里 `cs_last_high10(cs_state_rank(log(day_first(Open)), 50), log(day_first(Open)))`(y 位置整个是逐日常数)均值差 **+1.37**,`cs_state_rank(day_es_ratio_hi(High), 50)` 出现在 **28** 个候选里——M 在这条轴上也烧了不少。

**新的 `+0.56`:`cs_last_high10(LimitWidth, day_open(Open))`(M 第 3 批)。**
源码 `cs_last_high10(y, x) = _lexi(y, x, 0.9, 1.0, −1.0) = pct_rank(y) − 1·[x 的秩块落在 (0.9, 1.0]]`。逐项读:

- `y = LimitWidth` 是日频字段,截面上只有极少数取值(主板 / 创业板科创板 / ST 等几档),逐股几乎不随时间变;`_pct_rank` 对这种大面积同值块**完全按列序破平**,所以 `pct_rank(LimitWidth)` 就是「板块分档 + 每档内部的股票列下标」——**一条静态斜坡**,distinct 全靠破平凑出来。这正是规则 §4.2 描述的写法。
- 唯一随时间动的东西是那个 `−1` 的排除带:`day_open(Open)` 截面最高的 10%。`day_open = day_first`(`dt_day.py:139` 别名),价格是后复权的,所以这个带是「后复权开盘价最高的 10%」≈ 上市时价位 × 自基准日以来的累计总收益,和 `ListAge`、拆股次数高度混杂。
- 关键:**带宽恰好 10% = 一个十分位**。sign = −1 把符号翻过来,被压到底部的那一带正好变成最高的一档,所以**纯多头十分位书 ≈ 就是这 ~522 只「后复权开盘价最高」的股票**,带内部由 LimitWidth 和列序排序,而带内所有名字都整体进书,**内部次序对等权十分位书毫无影响**。`LimitWidth` 是纯装饰。
- 共性表也印证 M 一直在摸这条轴:`log(day_first(Open))` 出现在 **55/582** 个候选里(均值差 +0.71,p 0.000),`day_open(Open)` 8 个(+0.72)。

**判:70% 是「一个近乎静态的 522 名组合」+ 列序斜坡,30% 是真的长期累计价位效应(但它既不新,也不稳,而且在样本外就是一次性押注一个固定名单)。**
顺带一个结论:**这个 head 在 R 通道上是搬不动的**——它的书由排除带决定,带由 `day_open(Open)` 的前 10% 决定,换掉 `y` 位置的任何东西都几乎不改变成员名单,也就不可能高出 0.1。不要在它身上花评估。

### 1.5 本组自己的 5 个 head

#### (a) `+0.61` `cross_mean(cross_ema(div(sub(day_wmean(Ret, Amt), day_mean(Ret)), day_std(Ret)), 10), 15)` —— **本轮下调**

先把代数写清楚(r2 审计员断言过,这里给推导)。令 X = `div(sub(day_wmean(Ret, Amt), day_mean(Ret)), day_std(Ret))`,w = 分钟 Amt,r = 分钟 Ret,n = 分钟数:

```
Σ(w_i/W)·r_i − r̄ = (1/W)·Σ w_i (r_i − r̄) = cov(w, r) / w̄
X = cov(w, r) / (w̄ · sd(r)) = corr(w, r) · sd(w)/w̄ = day_corr(Ret, Amt) × CV(Amt)
```

(`day_wmean(x,w) = Σ|w|x/Σ|w|`,`ops_ext.py:109`;差一个 n/(n−1) 的常数。)
**X 恒等于「日内量价相关 × 日内成交额变异系数」**,后者是非流动性。这个恒等式是本轮几条判断的支点。

r2 的 R 组 A 五个变体(`r3/R_prev.json`),**全部低于原 head**:

| 变体 | score | train | valid | rho_head |
|---|---|---|---|---|
| `cross_ema@10→5, cross_mean@15→7` | +0.4357 | +0.44 | +2.39 | 0.947 |
| 分母 `day_std→day_wstd(Ret, Amt)` | +0.4180 | +0.42 | +2.19 | 0.754 |
| **切片 `in_slice(·, 31, 210)`(去掉头 31 / 尾 30 分钟)** | **−0.1348** | **−0.13** | +2.15 | 0.602 |
| wstd + 5/7 | +0.3352 | +0.34 | +2.83 | 0.859 |
| 切片 + 5/7 | −0.1891 | −0.19 | +2.15 | 0.667 |

三条读法:

1. **r2 的事先登记触发了**:「变体 3 ≤ +0.30 → head 改读成时段构成,下一轮不再在这个核心上开第二个 E」。实测 −0.13,远在门槛之下。
2. 但要诚实:**塌的只有 train,valid 还在 +2.15**。所以更准确的说法是——**在 train 上,这个 head 的 alpha 全部在开盘头 31 分钟和尾盘 30 分钟里;在 valid 上,中段也有。** 而 score = min(train, valid),train 恰恰是这个 head 的约束侧(+0.61 vs +2.61)。
3. 再看邻域:五个变体的 train 是 +0.44 / +0.42 / −0.13 / +0.34 / −0.19,原 head 是 **+0.61**——**它在 train 上是一个局部最高点,比最近的邻居(只把平滑从 10/15 改成 5/7)高出 0.17**。而 valid 侧这五个变体在 +2.15 ~ +2.83 之间乱飘,和 head 的 +2.61 没有可分辨的差别。**也就是说,+0.61 这个数里有相当一部分是 (10, 15) 这对平滑窗口在 train 上的选择收益。**

**修正后的读法**(r2 是「真资金流信息 55% / 开收盘时段构成 30% / 反转控制非线性残余 15%」):
**真资金流信息 30%、开收盘两段的时段构成 45%、平滑窗口在 train 上的选择 25%。**

#### (b) `+0.91` 与 `+0.51`(r2 a 位 E 的产出)

```
cross_corr(cross_delay(sub(sub(day_wmean(Ret, Amt), day_mean(Ret)), day_std(Ret)), 1),
           log(div(div(day_last(Close), ts_delay(sub(day_wmean(Ret, Amt), day_mean(Ret)), 1)),
                   ts_delay(div(sub(day_wmean(Ret, Amt), day_mean(Ret)), day_std(Ret)), 1))), 120)
```

读懂它需要两条源码事实:

1. **`log(x) = log(|x|)`**(`common.py:204`:`torch.where(|x|>EPS, log(|x|), NaN)`)。符号被**悄悄丢掉**,负数不会变 NaN。
2. 令 B = `sub(day_wmean(Ret, Amt), day_mean(Ret))`、s = `day_std(Ret)`、X = B/s。则 `div(div(Close, B), X) = Close·s/B²` —— 两个可正可负的因子乘成了 **B²**,所以这一支**恒为正**,coverage 0.9993。

于是(t 为当日,所有带 delay 的都是 t−1):

- y = log(Close_t) + log(s_{t−1}) − **2·log|B_{t−1}|**
- x = B_{t−1} − s_{t−1}
- head = 两者的 **120 日逐股滚动相关**。

`+0.51` 那个是同一台机器换了系数:y = log(C_t) − log|X_{t−1}| = log C − log|B| + log s,x = B/s²。**两个 head 近乎同义。**

证据怎么说:

- **充分性全线为负**:y 子树单独 **−2.22**、`div(div(Close,B),X)` **−1.42**、x 子树单独 **−4.41**、`div(Close, B_{t−1})` **−1.87**。没有任何一块单独能用,只有「两者的相关」能用。这可以是真的交互,也可以是拟合出来的形状统计量,证据本身不区分。
- **必要性**:敲掉 `log` → **−1.56**(train **+1.03** / valid −1.56,必要性 +2.47)——**`log` 在 valid 上是命门,在 train 上不是**;敲掉 `cross_delay` → −1.09(必要性 +2.00);敲掉 `div(day_last(Close), ts_delay(B,1))` → **+0.81,必要性只有 +0.09** —— **价格水平那一项基本是装饰**。
- **敏感性**:`Amt→Volume` → **+0.97(比原 head 还高 0.06)**;`Close→Vwap` → +0.91(分毫不差);窗口 `120→60/240` → +0.79 / **+0.99**。
  `Amt→Volume` 不掉分这一条很重要:**「资金流」的加权口径根本不是机制**;换成成交股数一样好(甚至更好)。
- 把装饰项扣掉,剩下的是 `cross_corr(B − s, log s − k·log|B|, 120)`。s 比 B 更持续、量级相当,所以主项是 `−corr(s, log s)` 这种近乎常数的东西,**真正在横截面上变动的是「成交活跃加权的收益偏离」的幅度随当日波动放大的弹性**,外加一个慢价格趋势项。

**判:不是「更干净的资金流倾斜」,而是一个逐股 120 日的「倾斜幅度 × 波动」耦合统计量。真来源(有独立经济内容)的把握 25%,代理 / 结构拟合的把握 75%。**
有利的一面要记下来:它的窗口阶梯单调(60 → 120 → 240 = 0.79 → 0.91 → 0.99)、换字段平坦、train 和 valid 同号——这不像数字游戏;不利的一面是,E 位想买的东西(把时段构成剥掉、留下资金流信息)**没买到**,GP 跑去做了另一件事。

#### (c) `+0.76` 与 `+0.65`(r2 b 位 N 的产出)—— **库里最健康的一支**

```
div(cross_stddev(log(div(day_first(Open), ts_delay(day_last(Close), 1))), 10),
    cross_stddev(cross_stddev(log(div(day_last(Close), day_first(Open))), 60), 60))
```

= **(10 日隔夜收益标准差) / (60 日平滑过的 60 日盘中收益标准差)**,sign +1、hl 20:多头 = 近期隔夜波动相对自身盘中波动基准偏高的名字。

- **充分性**:分子单独 −0.58、分母单独 −0.57、`r_on` 单独 −3.64、`cross_stddev(r_id,60)` 单独 −0.61。又是「只有比值能用」。
- **必要性**:敲掉分子的 `cross_stddev` → **−3.42**(必要性 +4.18,平滑是命门);敲掉分母外层那一层 `cross_stddev(·,60)` → **+0.65**(必要性只有 +0.12)——**而 +0.65 本身就是库里另一个 head**,所以这两个 head 实际上是一个东西的两个写法;敲掉分子的 `log` → **+0.80,必要性 −0.03**(去掉更好)。
- **敏感性**:`Open→Close` → +0.77(注意这个换法没有信息量:`day_first(Close)` 就是第一分钟的收盘价 ≈ 开盘价);`Close→Vwap` → +0.76;窗口 `10→5/10/20` = **+0.52 / +0.76 / +0.93 单调**。
- **没有局部孤峰**,窗口阶梯单调、必要性集中在一个说得清的部件上——这是库里**唯一**一个三项检查都健康的 head。

竞争解释要摆在台面上(r2 审计员提过,本轮看更像了):分子是**开盘集合竞价价格里的暂时性噪声**的直接度量(Roll 式非流动性),分母是连续竞价的波动;比值上升 = 开盘定价相对连续交易更「吵」。另一重:10 日 / 60 日 的比值本身是一个**波动期限比**,而控制只扣波动**水平**,不扣比值。

**判:真的隔夜 / 盘中波动结构信息 45%;开盘竞价暂时性噪声(Roll 式非流动性的非线性残余)35%;短长窗口比 = 波动趋势的残余 20%。**
这两条竞争解释都有**可做的判别试验**,见 §4.2 的 R-A5 / R-A4。

## 4. 本轮候选

### 4.1 值得深挖的核心(≤ 3)

#### 核心 1(**首选**):`day_corr(Ret, Amt)` —— 核心卡 32(均值差 +0.76,p 0.027,n=16);相关的 `cross_ema(day_corr(Ret, Amt), 10)` 是核心卡 31(+0.94,p 0.028,n=10)

**为什么是它。** §1.5(a) 的恒等式 `X = day_corr(Ret, Amt) × CV(Amt)` 把本组唯一一条经济线索切成了两半:一半是量价同期协变(知情交易 / 价格冲击不对称),一半是日内成交额变异系数(非流动性)。
- r2 的审计员把 a 位压在创新 3 的第一条理由,就是「凡是取 X 幅度或尾部的外围都会把 CV(Amt) 重新暴露出来」(种子 11 流动性 0.51 是证据)。**换成这个核心,这条批评按构造消失**:相关系数是尺度无关的,CV(Amt) 被整除掉。
- 它是**全新的核心**(整个实验 0 个 E 位用过),还有 2 个 E 位。
- 它已经见过的外围**极少**:r1 a 位种子 9 `cross_mean(day_corr(Ret, Amt), 20)`(被相关度表划掉,没评估过)、种子 10 `cross_ema(day_corr(Ret, Amt), 10)`(评估过)、r1 a 位第 4 名 `cross_mean(div(cross_ema(day_corr(Ret, Amt), 10), day_std(Ret)), 15)`(+0.4388);另有 16 个归档候选含它,形状不在定位输出里,由采样器的 `periphery_seen` 去重即可。**除了纯时间平滑,几乎一切都是新外围。**
- **train 侧的定量证据**(审计合理度 4 要的就是这个):平滑后的纯 `day_corr` 单独 ≤ **+0.44**(r1 a 位第 4 名,而且那一名还额外除了 `day_std`),平滑后的 X 是 **+0.61**。所以**量价相关这一半自己就拿到了 +0.61 里的约 70%,CV(Amt) 那一半至多贡献 +0.17**。这是「把烂部件切掉之后主体还在」的直接证据,也是整个种子里**最干净的判别实验**。
- 风险:(i) 稀疏股票的 `day_corr` 由少数几分钟决定,可能在**幅度**上和流动性挂钩——但带符号的水平与流动性的秩相关应当仍然低,相关度表会裁决;(ii) 核心自身强度弱(≤ +0.44),这一位可能颗粒无收。
- **不要**用 `cross_ema(day_corr(Ret, Amt), 10)` 当核心:它把平滑焊死在核心里,而且与 `+0.61` head 的 ρ 可能已经偏高,会把全部种子推到 0.7 的门槛边上。用裸的 `day_corr(Ret, Amt)`。

**建议的外围五族**(每族写成「做什么」,不押具体式子;下文 K = `day_corr(Ret, Amt)`):
1. **相对自身历史的带符号偏离**:`sub(cross_mean(K, 5), cross_mean(K, 60))`、`cross_zscore(K, 60)`。(这一族在另一个核心上见过,但在**这个**核心上没有。)

### 4.3 N 的灵感

**N1(推荐):日内时段结构 —— 开盘 30 分钟、尾盘 30 分钟(含收盘集合竞价)与中段的切分。**
- **为什么是它**:这一轮唯一一条「本组自己在 train 上拿到的新事实」就是切片塌陷(+0.61 → −0.13),它指向的机制在库里完全没有被读过:13 个 head 里没有一个用 `in_slice`、没有一个用 `in_index`,**日内时点这一维是空的**。而 r2 b 位的 N(隔夜 vs 全天盘中)只切到「日」这一级,这里切到「时段」一级,输入(`in_slice` / `in_index`)和机制(日内周期性、竞价段、尾盘机构流)都不同。
- **种子方向**(全部尺度无关,刻意避开成交额 / 波动的**水平**):
  1. 资金流重心时点:`cross_mean(day_wmean(in_index(Amt), Amt), 20)` —— 成交额加权的平均时点,∈[0,1],量纲完全消掉(`in_index(x) = t/(T−1)`,`ops_ext.py`)。
  2. 波动重心时点:`cross_mean(day_wmean(in_index(Ret), abs(Ret)), 20)`。
  3. 收益是不是后置:`cross_mean(day_corr(in_index(Ret), Ret), 20)`。
  4. 尾盘成交占比相对**自身** 60 日水平(不做截面比较,免得变成流动性):`sub(div(day_sum(in_slice(Amt, 211, 240)), day_sum(Amt)), cross_mean(div(day_sum(in_slice(Amt, 211, 240)), day_sum(Amt)), 60))`。
  5. 开盘段与其余时间的拉锯:`cross_corr(day_sum(in_slice(Ret, 0, 30)), day_sum(in_slice(Ret, 31, 240)), 60)`。
  6. 两段资金流倾斜之差(尾盘 − 开盘)。
  7. 两段量价相关之差:`cross_mean(sub(day_corr(in_slice(Ret, 211, 240), in_slice(Amt, 211, 240)), day_corr(in_slice(Ret, 0, 30), in_slice(Amt, 0, 30))), 20)`。
  8. 跳空在开盘半小时里被吃回多少:`cross_corr(log(div(day_first(Open), ts_delay(day_last(Close), 1))), day_sum(in_slice(Ret, 0, 30)), 60)` —— 与 r2 b 位衔接,但切分更细。
  9. 收盘集合竞价段(index 237–240)的收益相对自身波动:`div(cross_mean(day_sum(in_slice(Ret, 237, 240)), 20), cross_stddev(day_sum(in_slice(Ret, 237, 240)), 60))`。
- **制度依据**(让合理度够到 4):沪深两市的**收盘集合竞价**在 2018-08 落地,整个 train / valid 区间都在它之后;A 股的 T+1 与涨跌停制度让开盘半小时与尾盘半小时的委托构成与中段有系统性差别。这些都在 2023-08-08 之前,文献题目 2 去查。
- **失败模式(要写进假设)**:`day_sum(in_slice(Amt, …))` 这个零件会让 GP 往成交额的幂上爬(r1 b 位就是这么丢的)。对策:所有占比类种子一律减去**自身**的 60 日水平,不做截面水平;产出一律按陷阱 1/3 复核(查「这一层是不是保秩」和「分母是不是某个控制的幂」)。
- **预测**:产出 ≥ 1 个 head 的把握 **40%**;审计创新 4 的把握 55%、3 的把握 40%;合理 4 的把握 50%。**不预测方向,也不预测形式。**

**N2(次选):涨跌停板邻域的压力。** `LimitWidth` 给出了逐股的涨跌停幅度,`day_zero_ratio`、`day_flat_run_max`、`day_es_ratio_hi` 可以刻画「贴板」的形态;A 股的涨跌停-反转文献很厚,而且是制度特异的。**但风险高**:贴板事件集中在小盘高波动名字上,陷阱 3;`day_zero_ratio` 本身就是陈腐度 = 非流动性;而且 M 的 `+0.56` 已经把 `LimitWidth` 当装饰用过一次,审计员会盯得很紧。只在 N1 的相关度表崩掉时启用。

**N3(不建议):日内 vs 多日的方差比 / 价格发现效率。** 与 `+0.76` 家族和 DW 家族双重重叠,库禁令大概率把能挣钱的后代全挡在 0.7 以外。

### 4.4 几件事先说清楚,免得被 loc 的 R 候选带偏

定位输出的「比原 head 好的拆解变体(R 候选)」里有一行:
`signedpower(ts_std(signedpower(signedpower(day_durbin_watson(Close))), 25))`,**+1.6826,增益 +0.1222,ρ_head 0.996 → 按规则会触发替换。**
**不要做它。** 三条理由:(i) 窗口阶梯 25 / 50 / 100 = +1.68 / +1.56 / +1.59 是一个平台,+0.12 是噪声,照教训 3 应当预期它在任何别的区间上不再领先;(ii) 换进来的是**同一个陷阱 1 的产物**,库的规模不变、质量不变,样本外没有任何好处;(iii) 它会把库里这一行换成一个在 train 上**更极端的拟合点**,只会更糟。

同理,`+1.53` / `+0.75` / `+0.56` / `+1.22` 一律不做 R:要触发替换必须 ρ ≥ 0.5 且高出 0.1,而满足这个条件的几乎只能是同族的另一种陷阱写法。尤其 `+0.56`,它的书完全由 `day_open(Open)` 的前 10% 带决定(§1.3),换 `y` 位置的任何东西都不会改变成员名单。
**结论要写进报告**:这 8 个 artifact head 会原样带进样本外,R 通道搬不动它们。本组这一轮能做的只有两件事——不在它们身上花 E / N 位,以及把库里属于自己的那几个 head 做扎实。

## 6. 附:给环境的三条建议(写进报告,不属于本轮任务)

1. **奖励对信号的严格单调变换不不变**(§1.1)。`DW / DW² / DW⁴` 逐日截面次序完全相同,分数 −1.85 / −0.21 / +1.26;`signedpower(Z)` 对正的 Z 也是保秩的,却买到 +0.61。只要中性化是线性的、而且作用在原值上,任何 GP 都会把「单调包装」当成免费分数。**修法**:中性化前先把信号做截面秩变换,或者在控制的十分位桶内中性化(`cs_bucket_rank` 已有现成实现)。这一条能一次性关掉陷阱 1、陷阱 3 和 r1 那个股本幂族。
