## 1. alpha 的来源:逐个核心

### 1.1 `ts_reg_fvalue(day_std(Amt), day_centroid(Amt), 50)` —— 最强的家族,**尺度无关,但很可能在读「重心测得准不准」**

**(源码)** `ts_reg_fvalue(x, y, d)` 走 `rolling_ols(x, y, d)`,返回 `fvalue = ess/(mse + EPS)`。所以

* **它等于 `df·R²/(1−R²)`,df = 窗口内有效天数 − 2。(算术)** 本机在随机面板上验证:`F` 与 `48·c²/(1−c²)` 的最大相对误差 **8.0e-7**(c = `ts_corr(x,y,50)`)。
* **它对 x、y 的仿射变换完全不敏感。(算术)** 把 x 乘 1000、y 乘 7 再加 3,输出最大相对变化 **4.1e-6**;与 Amt 水平的秩相关 **−0.018**。
  ⇒ **它不是流动性水平的改写**,这一条很硬。**(定位)** 也对得上:`day_std(Amt)` 单独 score **−0.2721**、`rho_known` **+0.8523**(它就是已知族),而 F 的 `rho_known` 只有 **−0.2262**。
* **它是对称的。(算术)** `ts_reg_fvalue(x,y,50)` 与 `ts_reg_fvalue(y,x,50)` 相对误差 **8.0e-7**。
  ⇒ **「回归」是假象,里面没有方向,它只是 |相关系数| 的一个凸单调映射。** 计划里不要再写「把成交时点对成交离散回归」这种因果式的解读。
* **EPS 在这里不咬。(算术)** y = 重心 ∈ [0,1],50 天方差约 7e-3,比 EPS = 1e-9 大七个数量级。**这和 r2 §0 的 `ts_skew(DW)` 完全不同,这个家族不是浮点垃圾。**

**充分性 / 必要性 / 敏感性(全是定位的付费数)**

* **凸度不是来源。** 裸 F、`sqrt(F)`、`sub(sqrt(F), 重心)` 三者是逐日单调(或接近单调)的改写,score 分别 1.509 / 1.490 / 1.557,**差异全在噪声标尺附近**。
  规则 §4 陷阱 1 的指纹是「凸度越高分数越高」(r2 在 DW 家族上量到了 2→6→36 次齐次的阶梯)。**这个家族没有这个指纹**,这是它和 DW 家族的本质区别。
* **换字段稳**(Amt→Volume 仍 +1.17)、**换窗口稳**(10/20/40 都 ≥ 1.28)。

**但是:它在读什么?(算术,这是本轮最重要的一次本机验算)**

F = df·R²/(1−R²),而 R² 会被**任一侧的测量噪声**衰减。我构造了一个**每只股票的真实耦合 β 完全相同**的世界(1500 只、250 天,
x = 带个股水平的成交离散,y = 0.5 + β·z + 个股噪声),只让「重心的噪声」在截面上不同,结果:

```
rank corr(F, Amt 水平)       = −0.018
rank corr(F, 重心噪声)       = −0.795
```

> **在一个「耦合强度没有任何截面差异」的世界里,F 照样把股票排了出来,排的是「这只股票的成交时点测得准不准」。**

谁的重心测不准?成交分钟少、单笔大单主导的股票 —— 也就是 r1/r2 已经锁定的**同一条密度通道**。
所以我的权重:**F ≈ 密度/厚度的第三种写法 0.55;真的「成交离散与成交时点的结构性耦合」0.45。** 这是本轮唯一一个「最强家族还没定性」的位置,必须判(§4.2 的 R 第 3 组、§4.1 的核心 ①)。

**方向**:head #1 / #7 方向都是 +1 ⇒ **多头腿 = F 高 = 耦合紧 / 重心测得准**,和「厚、连续成交、不尖的那一端」是同一头,与 r1/r2 的峰度多头腿方向一致。这一点本身就是「同一通道」的间接证据。

### 1.3 `sub(day_centroid(Ret), day_centroid(Amt))` —— 库里唯一既不是 σ 也不是密度的通道

* **(源码)** `day_centroid` 内部先取 `abs()`,所以 `day_centroid(Ret)` ≡ `day_centroid(abs_(Ret))` = **价格在一天里什么时候动**;减去钱的重心 = **价先动还是钱先到**。
  两个 [0,1] 的时间指数相减,**无量纲、有界、不含任何 σ 的凸函数、不含 `cs_*` 分桶**,三个陷阱一个都不沾。
* **(定位)** head #10 `ts_decay_linear(sub(day_centroid(Ret), day_centroid(Amt)), 5)` = **+0.94(train 0.94 / valid 1.26)**;共性表 `sub(day_centroid(Ret), day_centroid(Amt))` 均值差 +0.82、p 0.048、n=7。
* **(表)** r2 的 20 日平均版:与 head 的原始 |ρ| ≤ 0.47,控制 liq 0.24 / vol 0.28 / rev 0.09 / known 0.27 / size 0.22 —— **全部 < 0.5,E 核心的门槛稳过**。
* **要诚实报的缺点**:r2 审计员指出 `day_centroid(Ret)` 的截面差异「主要由少数大幅移动的分钟落在什么时候决定,这正是峰度读的东西」,
  **(表)** 20 日平均版对 5 个控制取残差后与 `day_kurt` 族 head 的 |ρ| 是 **0.60–0.62**。所以这个通道有一只脚踩在密度/峰度族里,外围必须处理(§4.1 核心 ②)。

### 1.4 `|r|³ ÷ ListAge` 家族(Cr2b 的 7 个 head 里有 5 个)—— **陷阱 1 + 陷阱 3,已经可以结案**

**代数**:`mul(mul(Ret, Ret), abs_(Ret))` = `mul(mul(Ret, abs_(Ret)), Ret)` = **|r|³**(偶函数,σ 的 3 次齐次)。
**(定位)** 两个写法的付费数完全相同(score 0.8461 / train 0.8461 / valid 2.2658 / coverage 0.9993 / distinct 0.9977 / rho_known 0.1662),**确认是同一个量,GP 用两种写法占了库里两个位置**。
而 `mul(Ret, abs_(Ret))` = sign(r)·r²(奇函数)才是我们 r2 播的 RSJ 分子。

**(算术)** 2000 只股票、241 分钟、**所有股票的形状律完全相同**、只有 σ 不同:

```
rank corr(Σ|r|³, σ)        = +0.952      <- 偶矩就是波动排序
rank corr(Σ r|r|, σ)       = +0.049      <- 奇矩基本是符号噪声
rank corr(Σ|r|³/RV^1.5, σ) = +0.011      <- 无量纲版,σ 信息归零
rank corr(Σ r|r|/RV, σ)    = +0.032      <- 正经的 RSJ
```

**(定位)配上这一对付费对照,结论就封死了**:同一个骨架,分子换偶/奇两种写法 ——

* `div(cross_sum(day_sum(mul(mul(Ret,Ret),abs_(Ret))),3), cross_quantile_q50(ListAge,3))` = **+1.40**
* `div(cross_sum(day_sum(mul(Ret,abs_(Ret))),3), cross_quantile_q50(ListAge,3))`(head #11) = **+0.93**

> **偶的比奇的高 +0.47。赚分的是量级(σ³),不是符号构成。我们 r2 播下去的 RSJ 机制,是这个家族里最不值钱的那一半。**

**分母 `ListAge` 是什么?(定位 + 源码)** 两个 ListAge 子树单独评估都是**门槛废品**,原因不是覆盖率(0.9993)而是 **distinct = 0.0953 / 0.1025**
(`diagnose.distinct_fraction` = 每天「不同值个数 / 有值个数」的中位数;门槛 0.5)。
⇒ **ListAge 在截面上只有约 10% 的不同取值,是个粗分组的、近乎静态的字段。** 除以它,等于**把 σ³ 按一个粗年龄组做分组缩放**:
组内不改任何排序,组间把新股那一小撮推到一端。方向 −1 ⇒ **多头腿 = σ³ 最小 + 年龄最老的一端 = 「又老又安静」**。低波动 + 剔新股,两条都不是新东西。

必要性也对得上:`cross_quantile_q50(ListAge,3)` 换成 `cross_sum(ListAge,20)`,必要性只有 **+0.0072**(= 0);
窗口 3→2→6 给 +1.588 / +1.531 / +1.229(短窗更好,说明读的是**最近一两天的波动量级**)。

### 1.5 `ts_var(pow_2_5(cs_last_low40(day_q_stat_std(Volume), day_pos_ratio(Volume))), 50)` 家族 —— 密度 × 密度,外加一种新的作弊法:**用 NaN 做样本筛选**

这个结构在 462 个候选里出现 7 次(均值差 +1.36,p 0.002),自身 score **+0.8734**(train 0.8734 / valid 2.4782,rho_known −0.4278),是 4 个 head 的骨架。逐层读源码 + 验算:

1. **(源码)** `day_pos_ratio(Volume)` = 当天有成交的分钟占比 —— **这就是稀疏度本身**,r1/r2 锁定的那条通道的直接写法。
2. **(源码 + 算术)** `day_q_stat_std(Volume)` = Ljung-Box Q 统计量序列(滞后 1..20)的标准差,表面上是「成交量的日内持续性」。
   本机验算(800 只股票,活跃分钟数 20–241,U 型日内形状):**与活跃分钟数的秩相关 +0.862**;全密面板均值 124 vs 稀疏面板 41.6。
   ⇒ **它主要也是交易密度**,不是持续性。
3. **(源码)** `cs_last_low40(y, x)` 走 `_lexi`:输出 = `rank(y) ∈ (0,1]`,属于 x 最低 40%(按**整块并列**取,所以**不沾陷阱 2**)的股票 **减 1**。
4. **(源码 + 算术)** `pow_2_5` 走 `pow_(x, 2.5)`,指数 > 1 时是 `torch.pow(x, 2.5)` —— **对负底数返回 NaN**(本机确认:`pow(-0.5, 2.5) = nan`)。
   ⇒ **`pow_2_5(cs_last_low40(y, x))` 不是「把被筛掉的股票排到最后」,而是把它们整个删成 NaN。** 一道「排除」筛子被升级成了「从样本里删掉」。
   **(定位)直接的付费证据**:定位把 `ts_var` 敲掉之后,`div(cross_sum(pow_2_5(cs_last_low40(…)), 20), …)` 的 **coverage 掉到 0.8861**,门槛废品 —— 这 11% 正是连续 20 天都待在最稀疏 40% 里的那批名字。
   **(算术)** 我在 2000×120 的合成面板上复现了整条链:`pow_2_5` 之后 coverage **0.600**;经 `ts_var(·,50)` + `cross_sum(·,20)` 回到 1.000;
   而最终值与 **pos_ratio 水平的秩相关 +0.579**、与「NaN 天数」**−0.579**,**尽管在这个合成世界里被排序的 q 与 pos_ratio 毫无关系**。
   ⇒ **最终排序里有三分之一左右纯粹是「这只股票多久在筛子里」造出来的,不是信息。**
5. **(定位)** 把 `pow_2_5` 敲掉(筛子退回「排到最后」而不是删掉):score 1.4374 → **1.1685**(必要性 +0.2689),而且 valid 从 2.6753 塌到 **1.1967**、`rho_known` 从 −0.1754 翻成 **+0.4482**。
   **NaN 选择这一下,买到的大半是 valid 段的分数。**
6. **分数真正来自哪里:分母。(定位)** head #4 把分母 `cross_sum(day_sum(|r|³), 20)` 敲掉 → score **−0.1824**,**必要性 +1.6198**。

### 1.8 工程事实(写给 PI,免得重蹈)

* **(源码)** `pow_2_5 / pow_3 / pow_1_5` 对**负底数返回 NaN**(指数 > 1 走 `torch.pow`);`sqrt(x) = sqrt(|x|)`、`pow_05` 保号。
  **凡是可能取负值的量(时点之差、RSJ、`cs_last_*` 的输出、截面残差),套 `pow_2_5` 就等于做了一次样本删除。** 写种子时要么不用,要么先 `abs_`。
* **(源码 + 定位)** `distinct_fraction` 是「每天不同值个数 / 有值个数」的中位数,门槛 0.5。5000 只股票意味着**至少要 ~2500 个不同取值**。
  所以:**任何取值集合有限的量都会被判废品** —— `day_pos_ratio`(≤ 242 个值)、`day_zero_ratio`、`is_gt0` 的 n 日平均(n+1 个值)、`ListAge`(实测 0.095)。
  **解法是自带 `cross_mean(·, 20)` 以上的日平均**(20 个比例相加后取值组合数足够),r1 已踩过一次,这次不要再踩。
* **(源码)** `ts_var/ts_std/cross_*` 全是 nan-tolerant 的滚动归约(NaN 的那一天被**丢出窗口**,不是传染)。
  所以一个「中间层会产生 NaN」的表达式,**最外层的 coverage 看起来会是健康的**,被删掉的样本藏在里面。门槛查不出来,只有读源码能查出来。
* **(源码)** `ts_reg_fvalue` 对称;`cross_corr/ts_corr` 的分母是 `sqrt(var_x*var_y) + EPS`(绝对 EPS,但本家族量级安全)。
* **(源码)** `day_first` / `day_last` 都存在(`dt_day.py`),所以**日内收益 = `div(day_last(Close), day_first(Open))`、隔夜收益 = `div(day_first(Open), cross_delay(day_last(Close), 1))` 是可写的**(§4.3 的 N 用到)。
* **(源码)** `day_wmean(in_index(Amt), Amt)` ≡ `day_centroid(Amt)`(别重复写);而 `day_wstd(in_index(Amt), Amt)` 是**时间分布的第二矩**,库里没有。

**先说这一轮的目标函数。** 最终比的是**因子库的样本外表现**。库里已经有 6 个 σ 通道 head、6 个密度通道 head,

### 4.3 N 的灵感

**N-甲(首选)隔夜 / 日内收益的拆分。**

* **机制**:日收益 = 隔夜段 + 日内段。两段由**完全不同的参与者**完成(隔夜段是集合竞价与消息,日内段是连续竞价与流动性供给),
  文献里这是一个成熟的截面通道(「tug of war」)。**库里 17 个 head 没有一个碰过隔夜**;
  更关键的是:**5 个控制里的反转控制是 20 日的总收益,而「隔夜累计 − 日内累计」与总收益在构造上正交**(两段之和就是控制本身),
  **线性中性化吃不掉它,不是因为它凸,而是因为它本来就在控制的零空间里。** 这是本轮唯一一个「不靠陷阱也能躲过中性化」的机制。
* **写法(源码已确认 `day_first`/`day_last`/`cross_delay` 都在)**:
  * 隔夜:`sub(div(day_first(Open), cross_delay(day_last(Close), 1)), 1)`
  * 日内:`sub(div(day_last(Close), day_first(Open)), 1)`
  * 主因子:`sub(cross_sum(隔夜, 20), cross_sum(日内, 20))`,以及 5 日版、各自单独的版本、按流动性/密度十分位排序的版本。
* **要防的坑**:① 后复权价的**比值**是对的(复权因子在分子分母同一天抵消),跨天的 `cross_delay` 要求两天用同一套复权因子——
  生产库是后复权、整条序列同因子,所以可用;**不要用未复权价位去做这件事**。
  ② 涨停封板日的隔夜段会吃掉几乎全部日收益 ⇒ 这个因子会和「最近有没有封板」相关,**必须按 `LimitWidth` 或密度分桶,或先 `cs_winsor`**。
  ③ 停牌日 `day_first/day_last` 为 NaN ⇒ `cross_sum` 会跳过那天(nan-tolerant),可接受,但要在计划里写明。
  ④ **不要用 `is_gt0(隔夜)` 的 n 日平均当种子**:取值只有 n+1 个,distinct 门槛必废(§1.8)。
* **预测**:产 head 概率 **40%**;若产出,与所有 head 的 |ρ| < 0.3(机制与输入都不同),与反转控制 |ρ| < 0.25;
  方向我押**多头 = 隔夜强、日内弱**,但这一条我没把握,若方向相反说明 A 股的隔夜段主要是封板与打板。

**N-乙(备选)日内成交时间分布的第二矩。**

* **机制**:库里只有时间分布的**第一矩**(`day_centroid`)。`day_wstd(in_index(Amt), Amt)` 是**成交时点的离散度**:
  钱是摊在整个交易日,还是挤在很短的一段时间里。**(源码)** `day_wmean(in_index(Amt), Amt)` ≡ `day_centroid(Amt)`,所以第二矩是干净的新增;
  它无量纲、有界在 [0, 0.5]、不含 σ 的凸函数、不做 `cs_*` 分桶。
* **风险(必须在计划里写明并让表来裁)**:它和已知族(成交额的**日内离散**)可能撞车 —— 一只股票一天只有一笔大单,则时间离散度 ≈ 0 而金额离散度极大。
  **预测 |ρ|(known) 0.3–0.6**,所以主力种子应当是**已知族十分位内排序的版本**:`cs_bucket_rank(day_wstd(in_index(Amt), Amt), cross_mean(day_std(Amt), 30))`,
  裸版本只放 1–2 颗当对照。
* **搭配**:若 E 位选了核心 ①(F = 成交离散 × 成交时点的耦合),**N-乙 会被判成同一机制**,只能选 N-甲;
  N-甲 与核心 ①/② 都不重叠。

**搭配建议**:**E = 核心 ①(`ts_reg_fvalue(day_std(Amt), day_centroid(Amt), 50)`,外围做「密度条件化 + 有界化」)+ N = N-甲(隔夜/日内拆分)**。
若相关度表显示核心 ① 与流动性 |ρ| ≥ 0.5,**切到核心 ②(`sub(day_centroid(Ret), day_centroid(Amt))`,外围做「对峰度族正交化」)**,N 不变。
