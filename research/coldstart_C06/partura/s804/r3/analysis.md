## 1. 语义:本轮新核对的四条源码事实(后面的判断依赖它们)

r2 §1 已经钉住的口径不变(EMA 平滑 hl → `_zrank` 截面秩 → 对 5 个控制逐日线性投影取残差 → 选 sign → 残差**前 10%** 等权纯多头、扣 15bp;score = min(train, valid) 的长腿夏普)。本轮新核对出四条:

1. **中性化是对控制的 z-秩做线性投影**(`steer.py:403` `neutral_basis`:`zs = [dg._zrank(c) for c in controls]`,逐日 QR)。
   推论:**控制的任何单调变换的「秩」被完全拿掉,但「指示函数 / 带状 / U 型」这类对 z-秩非线性的暴露留得住。**
   这把规则 §4 陷阱 3 从一句话变成了可操作的判据:只要一个 head 的多头书是某个控制的**区块或带**,它就有拿不掉的残留。
2. **`_lexi` 的池是 x 的秩分块**(`ops_ext.py:339–353`,`_rank_block`)。推论:`cs_*` 的 **x 位上任何单调变换都是恒等**。
   这同时是结论 5 的来源,也意味着**只有 y 位上的变换才会改分数**。
3. **`long_neutral` 不套 untradable 掩码**(`steer.py:627`:掩码只对 `long_tradable` / `long_bucket` / `long_marginal` 生效)。
   但标签用的是 `label_buyable=True`(`scripts/c05_locate.py:113`;`label.py:16-21`:次日开盘窗口内全程封涨停的票,target 置 NaN,
   docstring 原话是「在普通标签上拟合会教组合去追正好这些票」)。
   **推论:r1 审计担心的「一字板接飞刀」那条漏在标签层已经关掉了**;剩下的只是这类票仍可能占着多头书的位子、带 NaN 收益 —— 那只是摊薄,不造假夏普。
   成交时点那一族还剩的真问题是**当日盘中封板**(封板后无量 ⇒ 成交前置),这类票次日开盘可买,收益算数。§5.1 外围 (b) 给了检验。
4. **`_es_ratio` 对 x 的正尺度变换不变**(`ops_ext.py:647`,比值),**且分位≈0 时整天置 NaN**(`good = (k > 0) & (v.abs() > 1e-8)`)。
   推论:head +0.568 里的 `add(Volume, Vwap)` 对「尾部形状」这个量**没有任何信息贡献**,它唯一的作用是把近零成交分钟抬起来、免掉 NaN ——
   也就是一个**价格量级的 epsilon**。`day_es_ratio_hi` 的 docstring 正好点名这个失效模式(手写 `erm_*` 用 `+1e-6`,因子于是读到「有没有封板日」而不是尾部形状)。见 §2.5。

读法:**(a) 「相对占比」而不是「成交额水平」是对的那一步 —— +3.17 是全库最大的单个部件必要性**;

(b) 平滑是第二个不可少的部件(+1.40 / +0.53)。(c) `neg` 是恒等装饰。

**敏感性(很稳)**:字段互换几乎不动 —— `Volume→Amt` +1.39 → +1.36(head +1.39)、`Amt→Volume` +1.30 → +1.31(head +1.30);

**`sqrt` 这一层是承重的,但承的是「合格」而不是「分数」**:
`neg(ts_mean(day_centroid(Amt), 20))`(无 sqrt)被相关度表划掉 —— **已知族 0.511**、liq 0.483、vol 0.421;
`neg(ts_mean(day_centroid(sqrt(Volume)), 20))` 则是 liq 0.32 / vol **0.41** / rev 0.19 / known 0.36 / size 0.03,过线。
机制说得通:`day_centroid(x) = Σt|x| / Σ|x|`,不开方时权重被开盘/收盘那几根巨量分钟独占 ⇒ 读到的就是**成交额的日内离散度**,也就是已知族 `cross_mean(day_std(Amt), 30)` 本身;
开方把权重压平,读到的才是「成交在整个交易时段里铺得偏早还是偏晚」。

**真来源还是代理?我的判断(以及唯一能分辨的实验)**

支持「真来源」的:两个不同测量独立同向、字段不敏感、窗口不敏感、valid/train 1.14(全库最低)、`div` 归一的必要性 +3.17 说明它确实不是成交额水平。

支持「代理」的三条,必须写进计划:
1. **vol 0.41 是这一族最大的控制相关**,比 liq / known 都高。质心对波动不是凸变换(它是序数时点量),所以不是陷阱 1;
   但「成交前置」与「隔夜信息驱动的开盘放量」是同一批票,这批票的波动天然高。
2. **赚钱的是持久水平,干净的是变化**:r2 的 slot b seed 13 `sub(ts_mean(day_centroid(Amt), 50), ts_mean(day_centroid(Amt), 5))`
   控制相关干净到几乎为零(liq 0.04 / vol 0.01 / rev 0.18 / known 0.03 / size 0.03),**却没有进 88 个候选的前 5**(18 个过线,前 5 名是 4 个质心水平版 + 1 个尾盘占比版)。
   我们只看得到前 5,所以这不是否证,但它的方向很明确:**把截面持久分量去掉之后,这条线就不那么赚了。**
3. **当日盘中封板会机械地造出「成交前置」**(封板后无量)。标签那条漏已关(§1.3),但这类票的次日收益算数,
   而 A 股盘中触板的票本身有延续性。这一条没有被任何现有证据排除。

**唯一能分辨的实验:控制桶内条件排序。** `cs_bucket_rank(y, x)` 的输出在 x 的每个十分位内均匀分布(`ops_ext.py:239`),
所以它的十分位书在每个 x 桶里取同样的份额 —— 比线性秩残差在尾部更干净。
若 `cs_bucket_rank(neg(ts_mean(day_centroid(sqrt(Volume)), 20)), cross_mean(day_std(Ret), 20))` 之类仍然 ≥ +0.8,**这一族就是真来源**;
若掉到 0.3 以下,它就是波动/流动性的非线性残留,最终库里必须这么标注。
**这个写法 r1、r2 两轮都写进过种子,GP 一次都没长出来过**(§4.1),所以它在 E 位里既是检验也是新外围。

### 2.2 真来源 B(维持 r2 判断):后复权价的**硬尾部区块**,不是那根连续的轴

本轮没有新增这一族的拆解结论,r2 §2.1 的判断全部成立:连续轴单独 **-1.15**(两个方向都亏),区块选择的必要性 +1.9 ~ +3.5,
`Open→Close` 完全不动(+1.6591 → +1.6582、+1.3290 → +1.3281),`ts_decay_linear` 窗口 10/20/40 → +1.70/+1.66/+1.65。
轴与 liq 0.46 / size 0.42,两端(最贵 10% 与最便宜 10%)都能拿 +1.2 以上 —— U 型非线性残留的样子。

**本轮补一条新的结构读数:head +1.03 已经退化成几乎纯粹的「最贵 10%」。**
`cs_last_low10(cs_last_low10(cs_last_high20(neg(P), ts_mean(ts_mean(day_skew(Ret), 20), 20)), day_mean(Open)), neg(P))`,hl **0**、sign -1。
按 `_lexi` 的语义逐层代入:最外层把 `neg(P)` 最低 10%(= P 最高 10% = 最贵)整块减 1,其余留在 (0, 1];
sign -1 的多头书取**残差**的最低十分位 ⇒ 中性化之前,这个十分位就**恰好是那个最贵 10% 区块本身**。
中间那层 `cs_last_low10(·, day_mean(Open))` 作用在最便宜 10% 上,与多头书是**互斥集合**;最内层的偏度筛只在区块**内部**重排。
hl=0 又没有 EMA 把「停留时长」算进来。所以这个 head 实际交易的就是「最贵 10%」加上中性化之后区块内部的次序。
**含义**:价格轴那一族里至少有一个 head 已经是区块本身的换皮;R 救不了它(去掉内层只会让它更像纯区块),最终库里应标注。

### 2.3 真来源 C(完全未拆解):`day_kurt(abs_(Ret))`,head +0.935

score +0.935 / train +0.94 / valid +1.43(valid/train 1.52)、sign **-1**、hl 20。来自 `c06s804Cr2b_Nb`,但**不在它的任何种子里** ——
和 r1 的 `cross_stddev(day_skew(Ret), 60)` 一样,是 GP 自己那一半随机树找到的。
**它没有被拆解、没有算过与控制的相关、也没有在共性表里出现**(共性表里没有任何 `day_kurt(abs_(Ret))` 行,说明含它的候选太少)。
这是库里信息量最少、同时又是第二高分的非价格轴 head。

**源码读出来的两种解释(方向相反,必须分开)**:
`_kurt(x) = E[(x-μ)^4] / E[(x-μ)^2]^2 - 3`(`common.py:411`),作用在 `abs_(Ret)` 上,是**尺度无关的形状量**,不是波动水平 —— 这一点是好的。
但:
- **解释 1(跳跃):** 分钟 |收益| 的峰度高 = 当天有几根特别大的分钟 = 跳跃 / 消息冲击。sign -1 ⇒ 多头 = **没有跳跃分钟**的票。
- **解释 2(价位粗细 / 零收益占比):** 名义价几元的票,分钟 `Ret` 近似只取 {0, ±1 个最小价位},`abs_(Ret)` 近似两点分布,
  超额峰度 = (1 − 6q(1−q)) / (q(1−q)),q = 非零分钟占比 ⇒ **它是 `day_zero_ratio(Ret)` 的单调函数**。
  q 小(冷清 / 价位粗)⇒ 峰度大 ⇒ sign -1 的多头端 = **非零分钟多 = 价位相对价格细 = 名义价高 / 活跃**。
  那就又绕回名义价与流动性这一头,和 r2 审计在偏度上点名过的是同一个混淆(「几元的票分钟收益近似三点分布」)。

**所以它要么是本种子第一条干净的跳跃因子,要么是流动性/价位粗细的换写,现有证据分不开。**
分辨它只要一步:在 `cross_mean(day_zero_ratio(Ret), 60)` 的桶内排序(`cs_bucket_rank`)。
**相关度表必须补这一行:`day_kurt(abs_(Ret))` 与 5 个控制、与每个 head 的 |ρ|。** 它是否能当 E 核心,完全取决于这一行(E 要求核心与每个控制 |ρ| < 0.5)。

### 2.4 降级:`cross_stddev(day_skew(Ret), 60)` 的两个 E 后代疑为「市值带」

核心本身仍然是干净的:实测 liq 0.10 / vol 0.18 / rev 0.01 / known 0.057 / **size 0.406**,head +0.667 的 valid/train 1.36。
但 r2 的 E 位长出来的两个 head 都把 `LogFloatCap` 抓进去了:

**head +0.834 `cs_last_low40(sub(cross_stddev(day_skew(Ret), 60), LogFloatCap), pow_2_5(LogFloatCap))`**,sign -1、hl 0。
三条证据指向「这是一条市值带」:
1. **实测的充分性递减**:`cross_stddev(day_skew(Ret), 60)` 单独 **+0.667** → `sub(cross_stddev(day_skew(Ret), 60), LogFloatCap)` 单独 **+0.386**。
   减掉 `LogFloatCap` 这一步让单独分数掉 **0.28**。(共性表里 `sub(...)` 是 +0.59 / n=24。)
2. **量纲不匹配**:`LogFloatCap` 是对数市值,截面散布约 1 个量级;60 日日内偏度标准差的截面散布小得多。
   两者直接相减,**这个「差」的秩主要由 `-LogFloatCap` 决定**,核心只是个小扰动。
   (它单独还能拿 +0.386 而不是 0,说明核心的信息没有被完全抹掉 —— 纯 `-LogFloatCap` 会被 z-秩中性化投影掉、接近 0。)
3. **池 = 最小 40% 市值**:`pow_2_5` 在 x 位上恒等(§1.2),`cs_last_low40` 把最小 40% 整块减 1;
   sign -1 的多头书取残差最低十分位 ⇒ 落在这个区块里 `rank(y)` 最低的那一段 = 区块内 `LogFloatCap` **最大**的约四分之一
   ⇒ **大约是市值 30–40 百分位的一条带**。带状暴露对 z-秩市值是强非线性的(§1.1),线性中性化拿不掉。

**head +0.615** 是同一骨架的放大版:池变量换成 `pow_2_5(day_quantile(Amt))`(同样恒等 ⇒ 池 = 最低 40% 的典型分钟成交额 = **最不活跃的 40%**),
外面再套 `cross_stddev(·, 60)` 与 `cs_last_high20`。valid/train = 2.09/0.61 = **3.40,全库第三高**。这一条我认为是流动性带 + 区块停留度,可信度最低。

**这两个 head 与 5 个控制的 |ρ| 从未算过,是相关度表第一该补的行。** 若 size |ρ| ≥ 0.5,按 R 的规则它们的任何变体都不合格;
即使 < 0.5(带状暴露的线性相关本来就可以不高),上面三条也足以在最终库里标注它们。

### 2.5 head +0.568 `inv(day_es_ratio_lo(add(Volume, Vwap)))`(M 第 3 批唯一的 head):单位不匹配的 epsilon

`_es_ratio` 对 x 的正尺度变换不变、分位≈0 时整天 NaN(§1.4)。所以 `add(Volume, Vwap)` 里的 `Vwap`
**对「左尾形状」这个量没有任何信息贡献**,它唯一的作用是把近零成交的分钟抬到 0 以上、免掉 NaN —— 一个**价格量级的 epsilon**。

`day_es_ratio_hi` 的 docstring 自己点名了这个失效模式(手写 `erm_*` 的 `+1e-6` 让因子读到「有没有封板日」而不是尾部形状)。

## 6. 文献题目(4 个,给文献员)

**题 1 —— 对准核心 ①、真来源 A:日内成交时点是「稳定的公司特征」还是「时变信号」?**
r1 的 lit 题 4 已经备好了日内成交量 U 型的理论源头与时段动量(Admati-Pfleiderer 1988、Heston-Korajczyk-Sadka 2010、Gao 等 2018、Blau 等 2009),**不用重复搜**。
本题要问的是下一层:文献里把「日内成交量时点分布」当**截面特征**用的时候,赚钱的是它的**长期水平**(跨年几乎不变的公司特征)还是它的**变化**?
方向是哪一边(成交偏早的票随后好还是差)?通常归因于什么 —— 散户 vs 机构的下单时点、被动 / 指数资金、执行算法、隔夜信息集中释放?
有没有把它解释成**投资者结构 / 股东基础**代理的文献(与机构持股比例、散户占比的相关有多高)?
