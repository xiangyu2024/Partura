## 第 1 轮

**材料(只看到第 1 个结构批 B085,13 个库因子,全是挖掘库的 `ts_std(day_mean(F))` 一族):** 全部是 A = day_mean(Amt)(日均分钟成交额)的 40 日标准差反复叠加,外加 ts_max / ts_mean(10) / ts_delay / ts_skew 的变体,另有 Volume 与 Vwap 各一条。新尺子(去掉 5 个控制和两个冠军)下没有一条过线;3 个「素材 head」是批内最好的三条,−0.03(train +0.15 / valid −0.03)/ −0.11 / −0.21,不是真 head。库里的原样读数:符号 −1(越稳越买),rank IC −0.024 ~ −0.041,原样净夏普 1.1 ~ 2.1,换手 0.02 ~ 0.05(很慢)。

**目前对这个种子 alpha 来源的信念(很弱):**
1. 原样的边际是流动性 / 规模 / 已知成交额族的暴露(raw 符号 −1 = 买成交额「稳」的小而清淡的票);尺子把这些剥掉之后,head 的方向翻成 +1,分数在 0 附近(−0.03 ~ −0.21)。所以我不认为这一批里有现成的 alpha,有的只是一个接近 0 的残渣。
2. 拆解表里唯一一致的规律:**纯叠 std 层数越多越好**(A −3.47 → 一层 −0.77 → 两层 −0.43 → 三层 −0.29,valid 多为正:两层 +0.56、head 1 的子树 +0.58),带 ts_max 的 head 2 / 3 是 −0.11 / −0.21(不再单调);外层窗口 40→80 不降反升(head 2 +0.10)。我的解释是:每多一层、每拉长窗口,成交额水平在方差里的占比下降、换手下降,而不是「读到了更好的东西」。
3. Amt→Volume 让三个 head 的 valid 掉到 −2.40 / −2.42 / −2.66。成交额 = 量 × 价;Amt 版的 C 除以 Volume 版的 C 约等于名义价格(加量价耦合的修正)。这说明承重的那一半是「价」,价位 / 规模一类水平暴露,不是活跃度本身。这一条是推理,没有读数核对。
4. 第二条推理(同样没有读数核对):三个 40 日窗口叠起来对新股的记忆约 120 个交易日,新股上市初期的一字板与开板放量使成交额变异极大,C 排名顶部可能集中着次新股。如果是,head 读到的是上市时间。E 位里放了一对 ListAge 方向相反的诊断种子来检验。
5. 核心 C = 三层 ts_std 与流动性 / 已知族的相关度我没法在本机量。别的流的相关度表里,同类的「两层 cross_stddev 套成交额分位数」是流动性 0.76、已知族 0.74,一层窗口 241 的是 0.83 / 0.80。所以我选了三层而不是流水线核心卡的两层(两层更接近水平,≥ 0.8 的风险更高)。E 位仍有约 15% 的概率因为核心与某个控制 ≥ 0.8 被划成普通 GP。

**本轮的任务与事先预测:**
- **槽 1(E)核心 `ts_std(ts_std(ts_std(day_mean(Amt), 40), 40), 40)`(三层):外围一律去水平 / 换手口径 / 截面处理 / 上市天数 / 动态 / 价格通道。** 15 个种子,全部原样带核心,骨架都不在库里。
  - **预测:出 head 的概率约 3%。** 种子里比值类、换手口径类和对水平回归取残差类在设计上不共享水平,与三个 head 的 |ρ| 预计 0.2 ~ 0.6(`cs_bucket_zscore` 那条最可能被相关度表划掉,风险 ~ 0.6 ~ 0.75);与流动性 / 已知族的 |ρ| 预计 < 0.5。**我预计多数种子比三个 head 更差**(−1.5 ~ −0.3),因为 head 的 −0.03 里有一部分来自水平残渣(符号是 +1 的那一小块),除掉水平后留下的更接近噪声;最好的一个落在 −0.5 ~ −0.1,最可能是 `C ÷ 二阶 ts_std`(种子 1)、`C ÷ 120 日成交额均值`(种子 2)或换手口径的 `log C − LogFloatCap`(种子 4)。
  - 上市天数的诊断对:`cs_last_low10(比值, ListAge)` 对 `cs_first_low20(比值, ListAge)`。我预期前者比同一个比值本身好 0 ~ 0.3(去次新股),后者更差(70%)。若后者更好,说明 alpha 在次新股而不在活跃度,第 2 轮的 E 核心要改。价格通道种子(Amt 版 C ÷ Volume 版 C)预计与名义价格高度相关,与规模控制 0.3 ~ 0.6,分数不会好。

  - **预测:** 变体与已知族的 |ρ| 会降到 0.5 以下(量纲被除掉),所以「比原 head 好 0.1」成为唯一的门;原 head 的分数低(−0.03 / −0.11 / −0.21),我预期 head 2 的组(5 个)里 1 ~ 2 个满足,另两组 0 ~ 1 个;满足的多半是「替换」(与原 head 的 ρ ≥ 0.5)。没有一个会到 0.5。如果全部比原 head 更差,我对「元量纲是烂部件」的信念作废,下一轮 E 核心应保留水平、只改窗口。

**目前对本种子 alpha 来源的信念:**
1. **六个 head 是同一个东西:嵌套成交额标准差水平的最低 10% 被沉到底部的阶跃(买最低一档),带内按「水平 / 市值更大的排前面」。** 拆解:y 整体的必要性 +1.45 / +1.44 / +2.19 / +0.97(把 y 换成 log(ts_std^4) 是 −0.10 / −0.35,去掉 −LogFloatCap 是 −1.19 / −0.14),而 y 里 log 里面的层数、窗口改变都不动分数(+1.35 逐位相同)。拆解表没动过 x(被标记集合)的定义和带宽。
2. **我同意总领 PROGRESS 里的怀疑:这很可能是尺子的盲区。** 尺子只去控制的 1 / 2 / 3 次秩多项式,最低一档(被忽视 / 休眠 / 小票)的阶跃指示去不掉;冠军本身已经有小盘 / 价位倾斜。我的先验:这些 head 是真正独立于冠军的新 alpha 的概率 ≤ 35%,更可能是同一个「小票尾部溢价」的几种写法。所以本轮 E 位 2 被设计成一个区分实验,而不是单纯的刷 head。
3. 两个解释:H_a 阶跃指示本身承重(被忽视效应),带内排序只是微调;H_b 带内位置承重(「安静但还在交易」的一档,最极端的休眠票是垃圾)。现有证据偏 H_b(y 的必要性 +1 ~ +2),但每个拆解的 y 都同时改了方向和内容,不能分开。
4. 量增长上下行半标准差一族(+0.41,库里 0 条)大概是「安静股」主题的连续、无阶跃版本(值 ≈ −log N241 + 小修正,没有读数核对)。
