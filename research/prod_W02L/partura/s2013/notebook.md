**目前对本种子 alpha 来源的信念(很弱):**
- |φ| 的水平没有 alpha:它是分钟成交的连续程度 = 流动性 / 成交额离散度 / 市值的函数,控制和冠军已经全吃了。拆解里「换窗口有用、换外壳 / 换字段没用」说明 -3 主要是水平暴露加成本,不是 φ 里没有别的信息。

**本轮的任务与事先预测:**

- **槽 2(N)成交量 - 波动 - 收益的名次耦合:** 16 个种子,四组:混合分布假说(成交量名次对波动 / 波幅名次的相关、斜率、t 值,以及 φ / day_gini 对波动的耦合)、对带符号收益与无符号波幅反应之差(追涨不对称)、量价跨日先后(含 Llorente 等 2002 的 c 系数,原始与名次居中两个版本)、波动里成交量解释不了的部分。窗口 60 ~ 120。预测:**出 head 的概率约 6%**,高于 E,因为库里没有这类量 - 波动 / 收益名次耦合的 60 日以上版本(最接近的是 3 ~ 20 日的手写式;手写库在尺子 B 下整体中位约 -2.5,见 PROGRESS.md 的第 0 步读数,我没有逐条看它们的分数),而且耦合强度与流动性水平不是函数关系。预期最好的分数落在 -1.2 ~ -0.3,可能是跨日先后类或不对称类(因为它们对流动性水平最不敏感);最可能的失败方式:(a) 120 日相关的估计误差(约 0.09)与截面离散度相当,名次大半是噪声;(b) 量 - 波动耦合在小盘股更强,与市值 / 流动性控制共享一部分(尺子会去掉线性、平方、立方暴露,但交互项去不掉)。

## 第 2 轮

**材料(这一轮看到 B037 + B038,以及本流第 1 轮三个任务的结果):** 快照里 10 个 head:6 个是素材(B037 / B038 的 |φ| 外壳,-1.97 ~ -3.31),4 个是真 head(第 1 轮 N 位出的,score +1.04 / +1.01 / +0.94 / +0.76,train 与 valid 同号同量级)。B038 是 B037 的同族:`sigmoid(pow_05(pow_05(day_ar1_coefficient(·))))` 的外壳,8 条,全是量额叶子;其中 `ts_quantile_q75(·, 50)` 两条与 `ts_decay_linear(·, 30)` 一条是仅有的未去控制 Sharpe > 2 的(rank IC -0.043 ~ -0.049,换手 0.03 ~ 0.04),去掉控制和冠军后仍是 -2 ~ -3。所以 B038 没有给出新的现象,它只是再次说明「φ 的水平慢一点就好一点、但仍是水平」。

**真 head 的形状(本轮一切的出发点):** 四个都是 `cross_regbeta(x, day_sum(Ret), 120)` —— 个股自己 120 日里「当日收益对一个成交活跃度量 x 的回归斜率」(cross_regbeta(x, y, d) 的第一个参数是回归元、第二个是被解释变量,y ~ alpha + beta * x,已核对 AlphaCube 的 rolling_ols)。x 是昨日成交额中位数 × 成交量名次(head 1、2),或成交额 / 成交量的水平 × 滞后的 60 日 z 分数(head 3、4)。拆解:15 个 knockout 里 14 个仍在 +0.34 ~ +0.99,唯一的例外是 head 1 拿掉 `cs_mask_top_replace_mean_neg`(valid -0.37),而 head 2 里同一部件拿掉几乎不变,所以那个部件是脆弱的装饰;最简版 `cross_regbeta(day_sum(Amt), day_sum(Ret), 120)` 是 +0.49(train +0.94);窗口 60 / 120 / 240 在 +0.56 ~ +1.08;Amt 对 Volume 同量级或略好(head 2:+1.11 对 +1.01,head 4:+0.86 对 +0.76)。这条线是**统计量(斜率)**起作用,不是某种乘积写法。

**上一轮预测对不对(第 1 轮):**
- E 位(核心 |φ|,16 个种子,预测出 head 概率约 4%、最好 -1.0 ~ -0.3):**0 个 head,方向对;最好比预测高**:103 次评估里最好 +0.12(train +0.66 / valid +0.12),是 `cross_autocorr(cross_regres(cs_mask_top_replace_mean(|φ|), φ, 60), 60, 1)` —— φ 当回归元 / 残差的自相关,不是 φ 的水平。我押的「beta 类 > 分桶类 > cs_rank 日轴统计类」:最好的既不是 beta 类也不是分桶类,是残差自相关类;`cross_hurst(cs_rank(...))` 类 -0.5 ~ -0.6。

- R 位(12 个变体,预测大部分比 head 好 0.1 以上、窗口 50 的好得多(-2.0 ~ -1.3)、全部达不到 0.5 的概率 > 95%):后一条对;「窗口 50 好得多」错 —— 6 个窗口 50 的变体在 -1.65 ~ -4.02,没有一个系统性好过窗口 5;「分桶最有效」也错:10 个分桶去均值的变体在 -2.21 ~ -4.02(4 个比原 head 更差),最好的两个是 `ts_min(cross_regres(cs_mean(·), ·, 60), 5 / 50)` = -1.05 / -1.65。教训:分桶边界的跳变增加换手,尺子对这个很苛刻;「回归掉全市场均值」有用。1 个替换进库(-2.21,ρ_head 0.89、ρ_known -0.21)。

**目前对本种子 alpha 来源的信念:**
1. 来源是「个股自己的、慢的(120 日)、收益对成交额类变量的斜率」。斜率 beta = corr(x, r) * sd(r) / sd(x) 同时带耦合方向(corr)与量纲 1 / sd(x);量纲因子是成交额水平的函数,尺子去掉的是对控制的线性 / 平方 / 立方暴露,去不掉交互项。**这轮最重要的未知量:alpha 里耦合方向占多少、量纲占多少。**两个 GP 位的设计都是为了回答它(无量纲回归元 vs 带水平的回归元)。
2. 去掉全市场共同部分有用(第 1 轮 R 位),分桶去均值没用。所以第 2 轮的 y 换成 cs_demean / 对市场回归残差。
3. φ 的水平是死的(第 1 轮两个任务的结论),但 φ 当回归元 / 残差是活的(E 位最好 +0.12,R 位最好 -1.05)。
4. 库里 5583 条:day_ar1_coefficient(Volume) 228 次,只有 6 次进入相关 / 协方差 / 回归,没有一次配收益;`day_sum(Ret)` 7 次、进入滚动回归 / 相关 / 协方差的 1 次;cross_zscore / day_gini / day_centroid / day_signed_ratio / day_zero_ratio / day_wmean 全是 0 次。
5. **GP 的库禁令(骨架 + 日度秩 |ρ| ≥ 0.7)会把 4 个 head 的邻居(换窗口、换字段 Volume ↔ Amt、拿掉部件)都挡掉**:骨架抽掉字段 / 常数 / 窗口,所以只换窗口或字段的候选与 head 的骨架相同。要出新 head,必须换算子结构(换 y、换统计量、换回归元的家族)。这也是本轮种子刻意每个骨架都不同(已逐个核对:16 + 16 个种子的骨架互不相同,与 5583 条和 10 个 head 都不相同)的原因。

**本轮的任务与事先预测:**
- **槽 1(E)核心 Z = `cross_zscore(day_sum(Volume), 60)`(今日成交量相对自己 60 日的 z 分数):** 16 个种子,回归元换成无量纲的惊奇(sd ≈ 1),所以 beta = corr * sd(r) —— 量纲因子没有了。外围:lag(1 / 2 / 滞后 5 日均 / 同日 / 60 日斜率再取 20 日均)、y(全天 / 下午段 / 成交额加权 / cs_demean / 对市场回归后的残差 / 秩空间 / 日内波动 / 净买入占比)、统计量(斜率 / 相关 / t 值)、sign 交互;另有 1 个带水平的对照(`mul(day_max(Amt), 滞后 Z)`)。核心与流动性控制的日度秩相关预计低(z 分数把水平拿掉了),不会被判成控制。**预测:出 head 的概率约 12%**(比第 1 轮的 E 高,因为这次的族是有证据的)。若有 head,最可能来自两个:y 去市场(种子 6、14)或相关 / t 值版本(种子 2、3)。纯斜率版(种子 1)我预计 -0.8 ~ +0.2,因为 head 里有一块可能来自量纲因子。预计最好分数 -0.6 ~ +0.5;被表划掉的种子 0 ~ 2 个(带水平的对照最危险,与 head 3 的 |ρ| 可能 ≥ 0.7)。最可能的失败方式:(a) 无量纲回归元的斜率换手高于 head(120 个观测的相关系数误差约 0.09),被 15 bp 吃掉;(b) 去掉量纲后 corr 部分本身没有 alpha(那就说明 head 的 alpha 在量纲,第 3 轮改去试「带不同量纲来源的」回归元)。判读:若种子 1 / 2 / 3 明显好于种子 11(带水平的对照),说明耦合方向是主因;反过来说明量纲是主因。
- **槽 2(N)成交构成与收益的斜率:** 16 个种子,两组。A 组(无量纲,12 个):回归元 = 昨日的 φ / gini / 成交额时间重心 / 净买入占比 / 无成交分钟占比 / Hurst / 成交额加权收益,y = 当日收益,统计量斜率 / 相关 / t 值,一个市场中性版,一个 Llorente 交互(滞后 φ × 滞后收益)。B 组(带水平,4 个):滞后成交额中位数(或当日成交额)× 滞后的 φ / gini / 重心 —— 头部最常见的水平部件配新乘子。**预测:出 head 的概率约 8%**(比第 1 轮的 6% 高,第 1 轮的教训是上调耦合类的先验,但这一次回归元不是活跃度水平,先验折一半)。最可能出 head 的是 B 组(水平部件仍在、乘子是新的),但 B 组也最可能被表划掉(与 head 1、2 的日度秩 |ρ| ≥ 0.7,估计一半被划)。A 组预计 -1.0 ~ 0;最可能的 A 组最好者是净买入占比的滞后斜率(种子 6)或 φ 的相关版本(种子 3)。这个位的审计应该能过(骨架和算子全新)。主要失败方式:构成量的单日噪声大于它对收益的耦合,斜率名次大半是噪声。
- **R(12 个变体,4 个 head):** head 2:Amt + 240 / Amt + y 去市场 / Amt + 180 / Amt + 去掉 mask;head 1:y 去市场 / 窗口 90 / Amt + 窗口 60;head 4:Amt + 240 / y 去市场 + 240 / 窗口 180;head 3:y 去市场 / z 分数窗口 120。**预测:至少 1 个变体比原 head 好 0.1 以上并被替换的概率约 40%**(最可能是 head 4 的 Amt + 240,它的两条单独改动都已经是正的 +0.21 / +0.10);被「收录」为新 head(与原 head ρ < 0.5 且比原 head 好 0.1)的概率约 3%。y 去市场的变体与原 head 的日度秩 ρ 我预计在 0.6 ~ 0.9,所以即使有增益也是替换而不是收录。

**给下一轮的备忘:**
