## 第 1 轮

**材料(第 1 个结构批 B118,`O:log(F)` 一带,25 条全是挖掘库成员,24 个已评分;共性表为空,拆解 5 次):** 3 个 heads 全是素材,没有真 head:`day_first(log(Amt))` −1.47(train −1.47 / valid −0.90,方向 +1,hl 20)、`day_mean(log(Volume))` −1.49(−1.43 / −1.49,方向 −1)、`add(day_min(log(Amt)), day_cov(Ret, log(Amt)))` −1.59(−1.59 / −1.41)。没有共性子树,没有比 head 好的拆解变体。

**本轮从材料里读到的事实:**
1. **拆解表:** head 2 把 Volume 换成 Amt 是 −2.82(差 1.33,ρ_known 0.88);head 3 的两个部件:`day_min(log(Amt))` 单独 −1.59(ρ_known −0.70)、`day_cov(Ret, log(Amt))` 单独 −3.10 / valid −1.84(ρ_known −0.04);head 3 的 Amt→Volume 是 −2.45(方向翻成 −1)。
2. **`add` 的量纲(我从算子读出来的):** `day_min(log(Amt))` 量级 5~12,`day_cov(Ret, log(Amt))` 量级 1e-4~1e-3,所以 head 3 实际就是 `day_min(log(Amt))`,协方差只打破并列。「单独 −1.59 = head −1.59」正是这个。
3. **换手(`struct/members.csv`,train 的原始日换手):** `day_first(log(Amt))` 0.53,`day_min(log(Amt))` 0.35,`day_mean(log(Volume))` 0.22。按 15 bp 估算,日换手 0.22 就是每年 6~8 个点的成本,与追踪误差同量级;三个 head 的 −1.5 差不多就是成本,**毛超额大概率 ≈ 0**(推断,没有毛收益数;同一个结论在 2001 / 2009 两条流里也出现过)。所以第一杠杆是「慢」,第二杠杆才是找到一个毛超额为正的读法。
4. **分钟轴(`research/coldstart_C03/design_r1.md`):** 241 根,第 0 根是 09:30 集合竞价(`Ret` ≡ 0、`Close` = `Open`、成交量极大)。`day_first(log(Amt))` 是本批唯一读开盘集合竞价这一根的 head,其余 head 读的是整日的量或最小值。
5. **价格水平:** log Amt = log Volume + log 价格。head 2 的 Volume 版比 Amt 版好 1.33,而 `day_min(log(Amt))` 在有一手(100 股)成交的分钟里就是 log(100 × 价格)。两处都指向「名义价格」这一维是本批里被量 / 额掩盖着的一个独立维度(控制里没有价格,只有市值;但冠军可能已经带了价位倾斜 —— PROGRESS 说 2028 的 head 就是低价位阶跃带,我不重复那一类)。
6. **库的盘点(`struct/members.csv`):** 34 条把 `day_first` 作用在 Volume / Amt 上,全是水平或时序形状;55 条 `day_cov(Ret, ·)`,外面是 `ts_std` / `ts_max`,窗口 ≤ 60;`cross_zscore` / `cs_bucket_*` 0 次。我的 16 + 13 个种子骨架逐个对照库的 5583 个骨架,0 个重合。

**目前对本种子 alpha 来源的信念(很弱):**
1. 这一批是「日内量额的日度聚合」,毛超额大概率 ≈ 0;新尺子扣掉流动性、已知族、市值、波动、反转和两个冠军之后,剩下的水平量只有噪声,−1.5 来自成本。所以光是「慢」就应该把分数从 −1.5 抬到 −0.5 ~ 0,这是 R 位的主要预测。
2. 要得到 ≥ 0.5 必须有毛超额。我能想到的独立来源只有三条,都已写进本轮:(a) 价量耦合的符号 × 近期收益(Llorente 等 2002 的条件延续 / 回吐;E 位);(b) 开盘集合竞价强度相对全天典型分钟(去水平,Berkman 等 2012 的开盘买入注意力、Lou 等 2019 的隔夜拉锯;N 位);(c) 名义价格直线(R 位组 2)。三条的先验概率都很低(各 2%~5%)。
3. 我不押的:`day_max / day_min / day_mean` 的 log 水平再套任何单调变换或窗口(本批 25 个成员已经把它们挖光了,而且全是水平);低价位阶跃带(`cs_first_low40` 一类:PROGRESS 记着 2028 的两个 head 就是它,我判断是尺子的盲区,不是新信号);对 `day_first` 去掉 log 的版本。
