# 种子 2021 笔记(PROD W02L,P 组)

## 第 1 轮

**材料(第 1 个结构批 B061,T08 主题,16 个成员):** 全部围绕 `pow_1_5(day_argmin(Amt))`——「当天成交额最低的那一分钟是第几分钟」——外面套 ts_quantile_q75 链、ts_var、加 `cross_max(day_cov(Close, Close), 15)` 等。其中 7 个成员属于冠军的族 22。新尺子(去掉 5 个控制和两个冠军)下没有一条为正;三个「素材 head」是批里分数最高的三条,不是真 head:−2.20 / −2.50 / −2.90(批的成员中位数在 −2.5 附近,所以三者之间的差只有 0.3–0.7,不是强证据)。

**目前对这个种子 alpha 来源的信念(很弱,只有拆解表里的三条线索):**
1. 三个 head 里最好的(−2.20)带两个价格水平项:`div(·, day_max(High))` 单独 −2.22 = 整个 head,`cross_max(day_cov(Close, Close), 15)` 单独 −2.41。后者的量纲是人民币平方,约等于后复权价² × 日内方差,跨股票的排序基本就是价格水平(尺度泄漏;lab/findings.yaml 里有一条说 `(当日最高价)³` 的多头书是低价书)。纯时钟(head 3,趾部分钟的方差)最差,−2.90。
2. 把 head 1 里的 `pow_1_5` 去掉(保留 `day_argmin(Amt)`)分数从 −2.20 到 −0.92(train −0.48 / valid −0.92),好 1.28;去掉 cov 项只变 +0.01,是乘客。解释:一个 add 里两项量纲不同,`pow_1_5` 把 0..240 的分钟指数拉得更开,argmin 项压倒价格项;去掉幂之后价格项才有话语权。
3. `day_argmin(Amt)` 的机制(我的推断,没验证):有零成交分钟的票(缺流动性)它是第一个空分钟,偏早;流动性好的票没有零,是真最小值,多在午前午后。所以它本质上是流动性的非线性函数,而且已经在冠军里(族 22),被新尺子去掉。
4. 我的信念:这一批里能成为 head 的东西,来源如果有,是**价格水平(后复权)的某个分量**,而不是时钟。后复权价 = 原始价 × 累计复权因子,所以它混着三样东西:原始名义价(低价效应)、累计分红送转史(派息)、上市以来的路径(长期反转 / 52 周高)。5 个控制 + 两个冠军里没有一个对准这三个分量(LogFloatCap 控制的是市值不是价格;价格 = 市值 / 股数)。

**本轮的任务与事先预测:**
- **槽 1(E)核心 `day_max(High)`(后复权日内最高价):** 外围全部是「把水平拆开」——对自身历史的比值 / 52 周高 / 年内位置 / z 分数 / 快慢 EMA / 12 个月变化 / Hurst(60、241 日窗口);用日频叶子拆出原始名义价(`LogFloatCap − LogFloatShares`)和对数复权因子(`log(High) − 原始对数价` = 累计派息送转史);在市值十分位内去均值 / 取排名;对成交额的相关。预测:**出 head 的概率约 8%**;预期最好分数从 −2.2 上移到 −1.5 ~ −0.3 之间;最可能的成功形态是「价格 / 复权因子 / 市值十分位内」这三类(慢变量,换手低,不被 20 日反转控制吃掉),其次是 241 日位置类。与已知族 |ρ| 预计 < 0.5。最可能的失败方式:(a) 去掉市值与流动性之后,价格水平的纯多头残差仍是负的(费用小,但没有 alpha);(b) 「train ≈ 0 / valid 正」的低价慢倾斜指纹(lab:2022–2023 的低价低流动性倾斜),score = min(train, valid) 会被压在 0 附近。若一个 head 都没有,这个槽的信息是「价格水平的分量里没有 alpha」,下一轮不再押这个核心(E 位用掉 1 个,至多再用 1 个)。
- **槽 2(N)隔夜 vs 日内(tug of war):** 隔夜收益 ON = `day_first(Open) / ts_delay(day_last(Close), 1) − 1`,日内 ID = `day_last(Close) / day_first(Open) − 1`;种子包括 20–50 日窗口里的 ON−ID(和、中位数)、ts_corr / ts_regbeta(gap 跟随 vs 回补)、同号频率、ON 的标准差占比与漂移一致性比、对总收益取截面残差(在表达式里去掉 20 日反转)、日内高低点先后顺序。预测:**出 head 的概率约 6%**,低于 E,因为这是全新的底,没有库里的证据;好处是它和 7 个控制的重叠最小(对总收益反转只有部分相关)、库里一个骨架都没有。最可能的失败方式:(a) 隔夜 − 日内的组合和 20 日反转控制太近,被吃掉;(b) 隔夜收益的信息被涨跌停与竞价撮合的极端值主导(用了 ts_med / 比率去稳健化,但没验证)。最可能的成功形态:gap 回补 / 跟随的相关与回归斜率(ts_corr、ts_regbeta),因为它们是无量纲、和总收益方向无关的结构量。
- **R(10 个变体,两个 head):**
  - head 1:把两项放到同一量纲(cs_rank 之和)、用原始价(`day_sum(Amt) / day_sum(Volume)`,Amt 与 Volume 都不复权)代替后复权 High、平滑 argmin、去掉时钟项、把 cov 项变无量纲。预测:这些变体里至少有 3–4 个比原 head(−2.20)好 0.1 以上(原 head 太差,任何把量纲摆平的东西都会比它好),与原 head 的 ρ 多半 ≥ 0.5,所以是**替换**,不是新收录;满足「ρ_known < 0.5 且分数 ≥ 0.5」的变体 0 个(概率 ≥ 95%)。
  - head 3:换成 level / spread、在市值或成交额十分位内去均值。预测:分数在 −2.9 ~ −2.0,没有变体到 0。

**本轮任务与事先预测:**
- **槽 1(E)核心 `signedpower(sub(day_at_max_ratio(Close), day_at_min_ratio(Close)), 2)`(该核心本实验第 1 个 E 位):** 外围 = 尾部均值、分位数链、对自身历史 z 分数、快慢差、对波动归一、市值桶内去均值、压掉最活跃端、乘日内符号、EMA 241。预测:出 head 的概率约 12%(比前两轮高,因为核心已有 +0.33 的 valid);最好分数 −0.3 ~ +0.3;最可能成功的外围是「对波动归一」与「尾部均值」(去掉对波动控制的暴露、只读极端日)。失败方式:train 一直为负(小盘题材期的封板读数方向相反),score 被 train 压在 −0.1 一带。
