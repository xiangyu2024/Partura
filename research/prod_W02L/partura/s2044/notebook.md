**我读到的、影响判断的外部材料(都只有 2025-12-31 以前的读数,没有碰 2026):**
1. 邻居流 2013 的第 1 轮:N 位出了 4 个 head(+0.76 ~ +1.04),全是 `cross_regbeta(x, day_sum(Ret), 120)`,x 是昨日成交额 / 成交量的某种水平乘积。即「个股自己 120 日里,当日收益对成交活跃度量的滚动回归斜率」。最简版 `cross_regbeta(day_sum(Amt), day_sum(Ret), 120)` 是 +0.49。它们现在是整波库禁令里的 head,我的种子和它们的 |ρ| 过 0.7 会被 GP 拒掉,所以我的 x 用有界的 c 与 f(日内同步度、符号化成交额失衡),不用成交额水平。
2. 邻居流 2029 / 2028 的 head 里有「阶跃带」(`cs_last_low10` / `cs_first_low40`),总领怀疑是尺子的盲区。我不写任何阶跃带种子。
3. GP 评分有「不同值 ≥ 50%」的闸门(`ParturaScorer.score`):取值档位少的离散信号(argmax / 计数 / 指示变量的均值)整个被挡。我因此放弃了 `ts_argmax` 与「高同步日占比」。

**目前对本种子 alpha 来源的信念(很弱,全是推理,没有读数核对):**
1. `ts_max(c, w) ≈ μ_i + σ_i · g(w)`:个股平均同步度 + c 逐日抖动 × 随窗口增大的极值系数。独立假设下一个 241 分钟相关系数的抽样噪声约 0.06。我的先验是 σ_i(估计噪声水平 / 成交连续性)比 μ_i 在截面上更分散,所以三个 head 读到的大概率主要是 σ_i,而 σ_i 与流动性、波动控制高度相关;窗口越长越好,是因为极值系数 g(w) 把 σ 的信息放大、同时换手变低,而不是读到了更好的东西。控制能去掉线性、平方、三次暴露,去不掉的残渣是 +0.2 ~ +0.5 的来源(我给「残渣」约 60%,「真有事件信息」约 25%,其余 15% 是别的)。
2. 如果真有事件 / 方向信息,它应该在 (a) c 对下一日收益的耦合(Llorente 等 2002),(b) 去掉 σ 之后的峰值形状,或 (c) 与价格趋势的交互里。这三类在本轮 E 位里各有种子,正好和「σ 残渣」的假设对立:如果 (a)(b)(c) 里的种子明显好于 (A) 的水平类、也好于 R 的窗口拉长,说明 alpha 不在噪声水平里。
3. 第二条独立的赌注放在 N 位(符号化成交额失衡 f 及其与价格的错位):用同一对原料(分钟收益与成交额),换一个不读相关系数的统计量,为的是避开 C 的 σ 残渣。
4. 不押的:`ts_max` 的窗口改写(与 head 的 |ρ| 约 0.7 ~ 0.9,库禁令会挡);C 的 `ts_min` / `ts_mean` / `ts_std` / `ts_quantile_q75` 写法(骨架在两个库里);`cs_bucket_rank(ts_max(C, 120), 控制)` 类分桶(与 head 的 |ρ| 会超 0.9;而且分桶边界的跳变会推高换手)。
