**目前对本种子 alpha 来源的信念(很弱,推断):**
1. C 的水平 = 流动性的变形(股数 ≈ 金额 ÷ 名义价)。Amt 版是已知族本身,Volume 版里剩下的主要是名义价,而这一块在新尺子里两段都亏。水平没有毛超额,不是成本问题(换手只有 2% 左右的原始读数),所以不会因为再套一层滤波而变好。
2. head 3 的 `abs_` 承重很可能承的是尺度:`day_cov(Close, Open)` 的单位是后复权价格的平方,残差绝对值的大小由价格尺度决定。R 组用无量纲化的版本检验这一点。
3. 能赢的只可能是「C 作为每只票自己的时间序列 / 关系」(异常放量、形状、量价耦合),或者「C 当阈值」(放量分钟里的价格动作)。两者都不含水平,都可以做成 241 日慢聚合。
4. 我不押的:C 的任何水平滤波(库里 7 个候选已经挖过 ts_max / ts_stddev / ts_min / ts_std / ts_decay_linear / ts_cov / ts_regres);q75 作用在价格上的水平(后复权价排序约等于累计收益,与控制重叠,富集都不显著)。

## 第 3 轮

**材料:** B069 一族(sigmoid(q75(F)))仍是水平量,没有新现象。真正的新读数在本流自己的任务里:r2 N 位出了本流唯一 head `cross_mean(day_wmean(Ret, log(log(abs_(Ret)))), 241)`,+0.64(train +0.64 / valid +1.16)。r2 E(核心 day_sum(Ret))最好 -0.51,0 个 head;r2 R 5 个变体全部比 head 差(-1.15 到 -2.4)。

**核实的事实:** log 是保护型 log|x|(|x|<=EPS 给 NaN),day_wmean 取 |w|,所以 w = ln ln(1/|Ret|),对 |Ret| 在 1e-4 到 1e-2 间只在 2.2 到 1.5 变化,零收益分钟被排除。因此 head ≈ 非零分钟近乎等权的平均收益(略偏小幅分钟)的 241 日均值。log(abs_) 版 +0.44、loglog 版 +0.64:越平越好。上一轮我在 hypothesis 里把权重说成「近似均匀」被审计员更正过,这次算清楚了。窗口 120 / 482 都掉到 +0.16 / +0.18(valid 仍 +0.86 / +1.03),train 偏弱。

**信念(推断):** alpha 来自「活跃分钟的平均漂移」,即 day_sum(Ret) / 非零分钟数 的慢平均,可能混着 tick 效应与活跃度项;也可能是长期累计收益(动量 / 反转)的一个以活跃度归一的变形。valid 比 train 强,可能有风格依赖。

**本轮任务与事先预测:**
- E,核心 C = day_wmean(Ret, log(log(abs_(Ret)))),14 个种子,全不改窗口:上涨日频率、信噪比、对市场的 beta / alpha / 残差、EMA / 中位数 / 线性衰减、减 day_mean(Ret)、减 log 权重版、除以日波动、长短窗口对比、自相关。预测:出 head(>=0.5)概率约 35%(核心本身已 +0.64,但新尺子下 head 与库禁令 ρ>=0.7 会拒掉不少近亲);最好的大概率是 EMA / 衰减 / 中位数一类(与 head 同源但外围不同,被禁令放过的少),以及 alpha / 残差类;对市场的 beta 类与波动控制重叠,预计最差。核心与 5 个控制 |ρ| < 0.8 的概率约 90%。
- N,小幅 / 大幅分桶与只读符号,14 个种子:预测出 head 约 12%,最好 -0.2 到 +0.5;小幅桶(种子 1、13)好于大幅桶(2)的概率约 65%;只读符号的种子(4、5、12)与 head 的 ρ 可能超过 0.7 被表划掉 1 到 3 个。种子 14(放量臂)预计 -1 以下。
- R,7 个变体:等权非零分钟(种子 1)预计 ρ 与 head 很高,分数在 +0.3 到 +0.7;至少一个变体好于 head 0.1 且与已知族 |ρ|<0.5 的概率约 20%。

**上一轮预测对不对:** E(day_sum(Ret) 核心)预测最好 -0.9 到 -0.3,实际 -0.51:对;出 head 3%:对(0)。N 预测出 head 约 8%:对(0 个 head 但 loglog 一族后来出了,来自 log 权重种子 15 的后代,最好 +0.64,高于我预测的 +0.5 上限;我押的 tick 假设没被分离,因为 loglog 比 log 更好说明偏向小幅的权重不是关键,更平更好)。R 预测至少一个好 0.1 以上 20%:对(0 个)。
