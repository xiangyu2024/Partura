# 种子 2060 笔记(PROD W02L,P 组)

## 第 1 轮

**材料(第 1 个结构批):** 3 个 heads 全是 `day_ar1_coefficient(Volume)`(分钟成交股数的日内一阶自回归)的单调 / 平滑包装,分数 -3.05 / -3.11 / -3.17(train 与 valid 同号都亏)。8 个已评分候选均值约 -3.3。Volume→Amt、窗口 2 / 5 / 10、去 cs_rank / sigmoid / pow_2 / ts_min,全部落在 -3.0 到 -3.3,各部件必要性 ≈ 0。

**目前对 alpha 来源的信念(很弱):** 核心有排序力(库里 `ts_mean(day_ar1_coefficient(..), 15)` 样本内秩 IC 约 -0.05,该库同族 net sharpe 约 +2 未去控制),但日度估计噪声 + 5 日窗口使换手高,成本吃光。head 们的壳全是单调变换,没有降换手。所以这一轮的赌注是「慢聚合 / 相对自己历史 / 十分位内去均值」,不是再套壳。另一个赌注:无符号量持续性被反复读取没有增量,换成带方向的成交流持续性。

**本轮事先预测:**
- **E(核心 `day_ar1_coefficient(Volume)`,14 个种子):** 出 head 概率约 10%。慢聚合版本最可能把分数从 -3 抬到 -1 到 0.3 附近;最可能的问题是慢版本与已知族 / 流动性控制或冠军信号残差后仍无增量,或与库里 ts_mean 版本太相近被库禁令拒。预计表划掉 0–2 个(cross_mean(.,60) 与 cross_ema(.,40) 彼此相近)。最可能的最好形态:(a) 慢聚合或 (b) 相对自己历史。
- **N(带符号成交流 sign(Ret)×Volume 的持续性,13 个种子):** 出 head 概率约 8%。新底、骨架库里没有;最可能的最好分数 -1 到 0.2。风险是方向由当日涨跌决定,与 20 日反转控制相关;(sub(ar1(S), ar1(Volume))) 的相关度最低。
- **R(8 个变体,对象 head 3):** 至少 1 个比原 head 好 0.1 以上且与已知族 |rho|<0.5 的概率约 70%(只需拉长窗口);但变体与原 head rho 多半 ≥ 0.5,所以是「替换」而不是新收录;到 0.5 的概率 < 3%。

**上一轮预测对不对:** 第 1 轮,还没有。

**给下一轮的备忘:** E 名额用掉 1(核心 `day_ar1_coefficient(Volume)`),至多再用 1。N 位要通过审计满足 3 轮至少 1 个 N 的要求。看 train / valid 分列:一段好一段差是风格切换,两段都差说明没有毛超额。

## 第 2 轮

**对 alpha 来源的信念(更新):** 第 1 轮结果:ar1(Volume) 的所有「水平 / 慢聚合 / 套壳」写法在 -3.1 到 -2.4,只有「相对自己历史」的写法明显更好(cross_zscore 120:-1.83,与原 head rho 0.04;快慢差 -2.36),带符号成交流 N 位没出过 -0.07 以上的东西。所以信息(如果有)在**变化**里而不是水平里。本流迄今最好是 GP 随机长出的 neg(cross_autocorr_s1(day_at_max_ratio(Open),15)) = -0.07(train -0.07 / valid +0.17),价格被钉住比例(涨停 / 报价档)的持续性。ar1(Volume) 核判为死核,不再用(E 名额已用 1,留 1 不用)。

**本轮事先预测:**
- **E(核心 day_at_max_ratio(Open),14 个种子):** 出 head 概率约 12%。最可能最好 -0.5 到 0.2;最有希望的是 cs_bucket_demean 版和与 min_ratio 的差(去掉水平与方向混淆)。主要风险:K 稀疏,窗口均值被少数涨停日主导,与波动 / 已知族控制相关;cross_zscore 在近常数票上给噪声。
- **N(量价耦合相对历史,14 个种子):** 出 head 概率约 8%。最可能 -1 到 -0.3;day_corr 对停牌票给 0 会让这类票聚在中间。最有希望 cross_zscore(day_corr(Volume,abs(Ret)),120)。
- **R(8 个变体,对象 head 5):** 至少 1 个比原 head 好 0.1 以上且已知族 |rho|<0.5 概率约 85%(cross_zscore 版已知 -1.83 对 -3.11);多半与原 head rho<0.5,所以可能是「收录」而不是替换,但要同时过库里所有 head |rho|<0.7;到 0.5 的概率 < 3%。

**上一轮预测对不对:** E:预测出 head 约 10%、最好 -1 到 0.3,实际 0 个过线、最好 -0.36(sub(ar1, q75(LogFloatCap))),大体对,但慢聚合版其实不是赢家,相对历史版才是。N:预测 -1 到 0.2、出 head 8%,实际 0 个且 N 位最好 -0.07 来自随机树而不是我的带符号流种子,带符号流假设没站住。R:预测至少 1 个好 0.1 且 rho<0.5、「替换」为主:cross_zscore 与快慢差好 1.3 / 0.8 且 rho≈0,对;但这两个与原 head rho 几乎 0,是「收录」候选,而没有越过 0.5 线,对。

**给下一轮的备忘:** E 名额:ar1(Volume) 用 1;day_at_max_ratio(Open) 用 1。N 位已有 2 个(第 2 轮 N 若通过则满足要求)。看 train/valid 反号情况。

## 第 3 轮

**对 alpha 来源的信念(更新):** 第 2 轮 E(day_at_max_ratio(Open))与 N(量价耦合相对历史)均 0 个过线;本流迄今最好是第 2 轮 N 位里 GP 长出的 ts_regbeta(sub(signedpower(day_cov(Vwap,Volume)), pow_2(day_mean(Amt))), ts_quantile_q75(day_skew(Volume),1), 10) = +0.33(train +0.69 / valid +0.33),第 3 批(M3)共性表里 C = sub(signedpower(day_cov(Vwap,Volume)), pow_2(day_mean(Amt))) 富集最强(+1.96,p 0.001)。信念:有料的是『两个日度微观结构量之间的滚动关系(回归斜率)』,而非任一方的水平;C 的水平被流动性吃掉,要读变化或残差。ar1(Volume) 与 day_at_max_ratio(Open) 两个核已判死,各用掉 1 个 E 名额。

**本轮事先预测:**
- **E(核心 C,14 个种子):** 出 head 概率约 20%(本流最高)。最可能最好 +0.1 到 +0.5;最有希望 ts_regres(C, day_mean(Amt), 20) 和 cross_zscore(C, 120)。风险:C 被 pow_2(day_mean(Amt)) 主导,与流动性控制过强相关,审计 / 库禁令可能划掉几个;外壳 ts_regbeta 已被占用(骨架禁令)。
- **N(day_cov(Amt,Ret) 对 day_skew(Volume) 的滚动回归斜率,14 个种子):** 出 head 概率约 12%。最可能 -0.5 到 +0.3;弹性可能被波动吃掉(种子里有 day_std(Ret) 对照)。
- **R(8 个变体,对象 M3 的 ar1 / DW 两个 head):** 至少 1 个比原 head 好 0.1 以上且已知族 |rho|<0.5 概率约 80%(窗口拉长已知 +0.44 / +0.36),但与原 head rho 多半 ≥ 0.5,是『替换』;到 0.5 概率 < 3%。

**上一轮预测对不对:** E(day_at_max_ratio(Open)):预测出 head 12%、最好 -0.5 到 0.2,实际 0 个过线、最好 -0.26,大体对。N(量价耦合相对历史):预测 -1 到 -0.3,实际最好 +0.33 来自 GP 在 C 上的 ts_regbeta,与我的种子无关(我的 day_corr 相对历史种子没站住)。R:预测至少 1 个好 0.1 且 rho<0.5,实际变体多落在 -1.8 到 -2.4 仍亏,未达 0.5。

**给下一轮的备忘:** 本轮之后本流结束;E 名额:ar1(Volume) 1,day_at_max_ratio(Open) 1,C 1。
