## 第 1 轮

**材料(只看到第 1 个结构批 B112,41 条挖掘库成员;loc 里 3 个「素材 head」,都是负分):**
- 批的共有结构是 `day_open(F)`(9:30 竞价分钟的第一个非缺失值)。价格叶子里 High / Low / Vwap / Open 在该分钟是同一个价:`day_open(Vwap)`、`day_open(High)`、`pow_2(day_open(Low))`、`neg(day_open(High))` 的库内 train 统计(秩 IC、换手、净夏普)逐位相同。所以批里的价格半边只有一个量:竞价价的后复权水平(规则 §4:约等于累计收益)。
- 量额半边:`day_open(Amt)` 是唯一富集的子树(5 个候选均值 −1.32,不含的 −3.19,p 0.001),但 C03 / W01 已经把「开盘竞价那一分钟的成交额 / 成交量」挖得很深(W01 的 head 有 `cross_corr(day_first(Amt), ·, 60)`、`ts_max(div(day_first(Amt), day_sum(Amt)), 40)`、`cross_max(cross_zscore(cs_mask_top_replace_mean_neg(day_first(Volume)), 30), …)` 一族),整波库禁令会拒绝与它们秩相关 ≥ 0.7 的候选,所以这一半我不再押。
- 3 个素材 head 的 B 分数:−0.43(train +0.11 / valid −0.43)、−1.14、−1.30。全负。

**目前对这个种子 alpha 来源的信念(很弱):**
1. head1 `ts_max(ts_max(log(cross_regbeta(day_last(Amt), day_open(Amt), 10)), 20), 50)` 的拆解里,回归是多余的:敲掉它只剩 `ts_max(ts_max(log(day_last(Amt)), 20), 50)`,分数相同(−0.43,train −0.43 / valid −0.28);`day_last(Amt)` 单独 −3.83。外层窗口 50 → 100 train 由 +0.11 升到 +0.38(valid −0.53)。所以这个 head 承重的是「最后一根 Amt 在长窗口里的峰值」,慢,而且 valid 比 train 差。
2. 要小心 AlphaCube 的 `log` 是 `log(|x|)`(|x| ≤ EPS 为缺失),所以 head1 读的是斜率绝对值的 70 日峰值;`cross_regbeta` 在 10 日窗口里除以最后一根 Amt 的方差,方差接近 0 时会爆点。我没有把它的斜率当 E 的核心(候选必须原样带着它),改写成 N。
3. 库里一个日频叶子都没有(`LogFloatCap`、`LogFloatShares`、`LogTotalCap`、`ListAge`、`LimitWidth`、`BoardCode`、`FloatCap` 在 5583 条里全是 0 次),长窗口的价格差分也 0 条(没有 `cross_delay(day_last(Close), ≥ 120)`、没有 `cross_max(day_last(Close), ·)`)。新尺子扣的是 5 个控制和两个冠军的 1 / 2 / 3 次秩,冠军就是这 5583 条的合成,所以库里没有的变量、以及交互项(同伴内相对量)是唯一可能剩下东西的地方。
4. 后复权价 ÷ 名义价(LogFloatCap − LogFloatShares)= 累计复权因子 F,只在除权除息日跳升。它是库里没有、而且 B112 批里「竞价价后复权水平」这个量的自然分解(水平 = 名义价 × F)。我押它的差分 = 窗内分红送转强度与净股东回报。
5. 慢是承重的(其它流第 1 轮的结果:窗口越长越接近 0,换手决定了 15 bp 下的净值),所以窗口都在 60 ~ 482 日。

**本轮的任务与事先预测:**
- **槽 1(N)累计复权因子 / 净股东回报(14 个种子):** 种子 1、2 是 `G` 的 10 日均值减窗内最小值(241 / 482 日窗口);3 是 F 的跳跃度(日差的 482 日 std);4、5 是减掉 / 单独读流通股增长(净发行);6 ~ 8、14 是时间平滑(120 日均值、EMA、截面秩均值);9、10、13 是 LogFloatCap 十分位同伴内;11 是除以 60 日分钟波动;12 是 G 水平本身(「寿命」口径)。
  - **预测:出 head 的概率约 6%。** 最好分数在 −0.9 ~ −0.2 之间,最可能在 −0.5 上下。最可能最好的是净口径(4、7、10、14)和同伴内相对(9、13),理由:纯现金分红强度和低波动 / 大市值 / 低换手重合,新尺子会把它吃掉大半,净口径加上摊薄(增发 / 解禁)这一半和波动控制无关;同伴内的相对量不在多项式扣除范围。预期 train 比 valid 差(2018 ~ 2021 年成长 / 题材风格不奖励高分红,2023-08 以后红利风格强),min(train, valid) 因此被 train 卡住。
  - **与控制的秩相关预期:** 种子 1 ~ 2 与 vol 0.2 ~ 0.4、size 0.2 ~ 0.4、liq 0.1 ~ 0.3;不会被 ≥ 0.8 划掉。与 3 个素材 head 的 |ρ| 预期 < 0.1,不会被库禁令挡。种子 1、2 同骨架(只差窗口),彼此秩相关 > 0.8。预计被相关度表自动划掉的种子 0 个。
  - **失败方式:** (a) FloatCap 的取价时点与后复权收盘不一致,G 带日内噪声,变量退化为噪声 → 所有种子 ≈ 0;(b) 分红股与非分红股之间的并列(241 日窗口里非分红股约 1/4 ~ 1/3)让离散度逼近 0.5 的闸门;(c) 最好的是 12(G 水平,「寿命」),说明读到的是累计收益 / 上市年龄而不是分红,那就放弃这条线。
- **槽 2(N)尾盘最后一根 Amt 的突发度(14 个种子):** 峰值 ÷ 常态(1、10)、z 分数 / MAD 单位的突发(2、14)、收盘占比的峰值减均值 / 上尾均值(3、4)、两端(收盘减开盘)峰值之差和同伴内去均值(5、6)、收盘端变化性 / 持续性 / 分布宽度(7 ~ 9)、head 里斜率的有界形式(11 ~ 13)。
  - **预测:出 head 的概率约 4%。** 最好分数在 −1.0 ~ −0.3,最可能在 −0.6。预计比值型(1、3、10)比水平型的差(5、6)好,因为水平型的差仍带流动性;预计 11、12(斜率的秩)最接近 head1(train 好、valid 差);7、8(变化性 / 自相关)最差。
  - **与 head1 的秩相关预期:** 种子 11、12 在 0.5 ~ 0.7,其余 < 0.4;可能被自动划掉 0 ~ 1 个。与控制:种子 6 的 size 去均值后 < 0.3;种子 7 的 known(成交额 std)0.4 ~ 0.6,但不到 0.8。
  - **失败方式:** (a) 比值化之后分数比 head 差,说明 head 读的是流动性水平,被控制吃掉,下一轮不再押收盘端;(b) valid 仍比 train 差,说明被动资金调整事件的效应在 2023 年以后变弱;(c) 如果好的反而是 11、12,说明承重的是斜率的爆点(最后一根 Amt 方差极小的冷门股),那就是市值 / 流动性的极端尾部,不是事件。
- **R(15 个变体,三组):** head1(7 个:回归窗口 20、cross_corr、对数弹性、先 5 日均值再 70 日最大、EMA 10、20 日最大的 50 日均值、上四分位尾部均值)、head2(5 个无量纲化)、head3(3 个)。
  - **预测:** 三个 head 的分数都很低(−0.43 / −1.14 / −1.30),+0.1 的门槛容易过。head2 / head3 的无量纲变体多半(8 个里 4 ~ 6 个)过门槛,被收为「替换」(与原 head 秩相关 ≥ 0.5),没有一个到 0.5;head1 的 7 个里 1 ~ 3 个过门槛,最可能是 EMA(5)和 5 日均值再取最大(4),它们降换手。收录(与原 head ρ < 0.5)几乎不会发生。

**目前对这个种子 alpha 来源的信念(仍弱):**
1. 本流唯一接近线的东西是「小流通股本段 × 收盘集合竞价成交额」。两段都为正(train +0.75 / valid +0.48);但它是阶跃,并且和已知族的 ρ 有 0.44,所以我认为有两种可能:(i) 真正有的是小股本 / 次新 / 高价这类供给结构的段效应(规模控制是 LogFloatCap,不是股本);(ii) 段内按 Amt 水平排序只是在挑流动性。种子 4 ~ 7、9、15 是为了把这两种分开。
2. 库里 5583 条没用过日频叶子、day_signed_ratio / day_wmean / cs_bucket_* / cs_first_* 一类算子,而控制和两个冠军又都来自库,所以「同伴内相对」与「段结构」是仅有的两处可能还有东西的地方。
3. 慢是承重的:第 1 轮 R 里的 EMA(5 / 10)、cross_mean(5) 平滑反而更差,但 cs_rank(regbeta) 的 EMA 60 / 241 把分数从 -0.43 拉到 -0.09 ~ -0.18;所以窗口在 20~120 日,不在 5~10 日。
