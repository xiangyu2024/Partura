机制:个股分钟收益的一阶自相关 a = day_ar1_coefficient(in_slice(Ret, 1, 210)) 刻画当天价格路径是「价差弹跳 / 回头」(a < 0,流动性提供者在赚钱的票)还是「顺势延续」(a > 0,知情 / 程序化拆单的票);把 a(或尾盘的 a)与「滞后几天的收益」做 241 日时间序列相关,读的是「前几天涨跌之后,今天的盘中价格路径是更趋于回头还是更趋于延续」,即库存风险 / 流动性提供的慢变状态(Campbell-Grossman-Wang 1993:库存风险使价格反转;Nagel 2012:短期反转是流动性提供者的补偿)。另一个来源是本流第 2 轮 E 位的唯一 head,尾盘 DW 对滞后 1 / 2 / 3 天收益的相关为 +0.19 / +0.51 / +0.36:滞后结构本身像是信号,所以种子 4、5 直接读「滞后 2 天相关 − 滞后 1 天相关」与「滞后 2 天相关 − 滞后 1、3 天的均值」,即反应曲线的形状,而不是某一个滞后的水平。

启发:B030 是 day_ar1_coefficient(F) 的裸对象批,价格水平字段(Vwap / Close / High / Low)的 AR(1) ≈ 1,读数是数值伪影,本位只用收益字段 Ret(AR(1) 取值在 ±0.3 内,量级正常),这是该批里唯一有意义的一类;快照 221 个已评分候选里「含 in_slice(Ret, 1, 210) 的日累计收益」的 45 个,均值 −1.56 对 −2.48(差 +0.92,p 0.000),而含 day_ar1_coefficient(Ret) 的候选一个都没有。

算子怎样实现:a 与 A / L1 / L3(滞后 2 / 1 / 3 天的 14:30 前收益)、尾盘收益 T、尾盘 DW(D)做 cross_corr / cross_regbeta(a 或 cs_rank(a) 做回归元,量级 1e-1 远大于 1e-9 的阈值)、sign 条件均值(种子 10)、cs_rank 双边版(种子 11,去掉大盘共同成分)、窗口 241 / 482 日。

为什么和库里已有的不同:库的 5583 条表达式中,day_ar1_coefficient 几乎全部作用在 Volume / High / Close 等水平或成交量字段,并外包 sigmoid / pow / ts_decay_linear 等保序包装;作用在 Ret 上并与滞后收益做时间序列相关的一条没有;「滞后相关的差」(反应曲线形状)也没有。种子骨架逐个对照过库的骨架。与 10 个 head 的区别:head 读价格水平字段 AR(1) / DW 的水平或离散度,这里读收益路径的自相关与跨日反应曲线。与五个控制的区别:20 日反转读收益的累计,这里是路径的自相关系数与滞后收益的耦合,水平与幅度已被相关去掉。

为什么样本外还会在:来源是流动性提供与库存风险这类持续的市场结构(价差、投资者结构),不是某段行情;窗口 241 ~ 482 日,名次几个月不变,换手低。风险:估计误差约 0.06;a 与波动 / 流动性水平的交互不会被尺子去掉;种子 4、5 是两个相关的差,噪声翻倍,可能比单个相关更差,但这是对「滞后结构是否真有形状」的直接检验。

数学检查:a 在收益平方和大于 1e-8 时才有定义(约 2e-4 的日内波动都满足),极少数停牌 / 涨跌停封死日为 NaN,是窄缺失;所有相关 / 斜率只在窗口内有有效对时有值;sign 条件均值只做乘法与均值,无除法;无前视:a 是 t 日 14:30 前 / 尾盘数据,滞后收益只用 cross_delay,t+1 才交易。
