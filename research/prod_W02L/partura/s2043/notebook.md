# 种子 2043 笔记(PROD W02L,P 组)

## 第 1 轮

**材料(只看到第 1 个结构批 B127,42 条,全部来自手写库;全部是「放量分钟收益」一族,手写库里叫 shine_ret):** 事件定义是 S = 第 31~210 分钟(另两套窗口 16~226 与 2~237)里成交量较上一分钟的增量 > 当天增量的均值 + 1 倍标准差,C = day_mean(S × Ret) = 放量分钟的平均收益。42 条是 C(及 day_max / day_std / day_product 换统计量)外面套 cs_demean、abs_、ts_mean、ts_stddev、add、in_sustain_stddev(放量后 5 分钟的波动)。3 个 head 不是真 head,只是素材,分数都是负的:−1.09(train −1.09 / valid −0.21)、−1.12(−1.12 / −0.76)、−1.35(−1.35 / −0.93),全是 ts_stddev(abs_(cs_demean(C)), 20) 的变形(head 3 是两项相加,第二项把 C 换成放量后 5 分钟的波动)。

**目前对本种子 alpha 来源的信念(很弱):**
1. **C 的水平没有 alpha:** C 单独 −2.83、cs_demean(C) −2.82、abs_(cs_demean(C)) −2.80;套上 ts_stddev 20 日才到 −1.09。`members.csv`(只含 train、未去控制)里同一族的 day_mean / day_max / day_std 水平类是 −5 ~ −11,ts_mean / ts_stddev / add 外壳是 +1.9 ~ +3.7;去掉 5 个控制和两个冠军之后外壳也变成 −1 ~ −3。也就是说手写库里这一族的正夏普来自「慢 + 水平(和波动 / 流动性共享)」,控制已经吃掉了。
2. **唯一的梯度是「慢」:** ts_stddev 窗口 10 / 20 / 40 日,head 1 train −1.79 / −1.09 / −0.84、valid −1.96 / −0.21 / +0.03;head 2 窗口 20 → 40:−1.12 → −0.78、valid −0.76 → +0.13;head 3 第一项 20 → 40:−1.35 → −0.90。单调变好,40 日还没到头。推断(没有毛收益数):毛超额约为 0 或很小,亏的是换手 × 15 bp。
3. **口径不重要:** Volume 换 Amt 分数基本不动(−1.07 / −1.12 / −1.33),说明信息(如果有)在「放量时刻的价格反应」,不在成交量口径,也说明这一族和已知成交额族不是同一个东西。
4. **cs_demean 是半个烂部件:** head 1 去掉它从 −1.09 到 −0.87(train)、valid −0.21 到 −0.29,两段较差者增益 +0.23;head 2 去掉几乎不变(−1.15 对 −1.12)。abs_ 有用(拆掉变差 0.11~0.31)。
5. **库里读放量事件只有两种读法:** 事件上的收益水平(C)和事件之后的波动(in_sustain_stddev,全库 121 次,head 3 第二项单独 −2.00)。放量之后价格路径的**带符号走向**(in_sustain_mean 全库 4 次、没有一次和事件分钟的收益配对)、C 与跨日收益的相关 / 斜率 / 自相关(cross_regbeta / cross_corr / cross_autocorr 配 C)都没有读过。我的赌注全在这两块「没读过的读法」上,并且全部做成 60~241 日的慢变量。
6. 邻居流(2013)在第 1 轮的发现支持这个方向:慢的、无量纲的跨日回归斜率(cross_regbeta(滞后活跃度量, 当日收益, 120))是目前新尺子下最像样的形态,GP 对取值档位少的离散信号有「不同值 ≥ 50%」的闸门(所以我把原来的「C 为正的天数占比」换成了 90 日中位数)。我没有碰 2026 年的任何读数。

**本轮的任务与事先预测:**
- **槽 1(E)核心 C = day_mean(mul(replace_small_with_nan(is_gt(ΔV, 均值 + 1 倍标准差)), Ret))(31~210 分钟),16 个种子:** 四组外围 —— (a)昨日 C 对当日(去市场)收益的 120~180 日回归斜率 / 相关 / t 值(Llorente 等 2002 的延续 / 回吐系数),(b)C 与当日 / 前一日收益的同日关系(60~120 日),(c)无量纲慢聚合:C ÷ 当天分钟收益标准差的 30 日 EMA、C 的 1 / 5 日自相关、C 去市场后的 90 日中位数 / 241 日均值、C 减全天平均分钟收益后的 60 日均值 / 40 日 EMA / 截面回归残差。全部不含 ts_stddev 与 abs_(库里已有的写法)。
  - 预测:**出 head 的概率约 6%**(C 的水平是死的,新写法的收益全押在「慢的跨日回归结构」这条邻居流刚验证的形态上,但这里的回归元 C 是 20~30 个事件分钟收益的均值,噪声比邻居的成交额类回归元大)。预期最好分数 −0.9 ~ +0.1;最可能的最好者是 (a) 组 120~180 日版本(种子 2、3、4),其次是 (c) 组的 C 自相关(种子 11)。与 3 个 head 的日度秩 |ρ| 预计都 < 0.5(head 是 |C| 的波动,这里是方向性的回归 / 相关),被表划掉 0~1 个;与控制 |ρ| < 0.3。最可能的失败方式:(i)60~180 日相关的估计误差约 0.1,大于截面离散度,名次近随机,换手把 15 bp 吃满;(ii)(b)(c) 组带当日收益,与 20 日反转控制有残余暴露(线性 / U / S 被去掉,交互项去不掉)。若全部种子都比 −1.09 还差,说明 C 的任何写法都救不了,第 2、3 轮不再用这个核心(它的第二个 E 名额也不用)。
- **槽 2(N)放量之后价格走向:延续还是回吐,13 个种子:** 事件内 imp(事件分钟收益)与 post5(之后 5 分钟平均收益,in_sustain_mean 的 start_offset = 1,不含事件分钟)的相关 day_corr 的 60 / 120 日均值 / 30 日 EMA(种子 1~3)、post10 版本(4)、带符号延续量 SC = day_mean(sign(imp) × post5)(5)及其占比 / 无量纲版(6、11)、日度均值的 120 日回归斜率 / 相关(7、8)、post5 − imp(9)、昨日 SC / 昨日事件相关对当日去市场收益的 120 日斜率(10、13)、换成成交量增量最大 10% 分钟的事件定义(12)。
  - 预测:**出 head 的概率约 8%**(比 E 高:库里没有任何事件内方向配对的写法;邻居流 2013 的教训是耦合类先验别给太低)。预期最好 −0.9 ~ +0.2,最可能是事件内相关的 120 日均值(种子 2、3)或 SC 的慢聚合(5、11);与 head 的 |ρ| 预计 < 0.4。最可能的失败方式:(i)买卖价差弹跳使 corr(imp, post5) 机械为负,低价股 / 价差大的股票更负 —— 新尺子去掉了对流动性与市值的线性 / U / S 暴露,但名义股价(最小报价单位相对股价)去不掉,若出 head,有一部分可能是这个代理;(ii)事件数少的股票相关取 ±1,被 60 日以上均值抹平但仍留噪声。这个位的审计应该能过(骨架全新、机制清楚)。这是满足「3 轮至少 1 个 N 通过审计」的位。
- **R(3 组 14 个变体):** head 1:ts_stddev 窗口 60 / 90 / 120 / 241 日,及去掉 cs_demean 叠加 40 / 60 日(6 个);head 2:窗口 60 / 90 / 120 / 241 日(4 个);head 3:两项同时放慢到 40 / 60 / 120 日,及第一项 40 日 + 第二项取日度水平(4 个)。
  - 预测:大部分变体(≥ 10 个)比原 head 好 0.1 以上;因为窗口变慢后与原 head 的日度秩 ρ 会在 0.5~0.9,所以是**替换**而不是收录;与已知族 |ρ| 预计 < 0.5。最好的在窗口 60~120 日附近(head 1 约 −0.6 ~ −0.2),241 日可能因为过慢而 valid 回落;任何一个 ≥ 0.5 的概率 < 3%。R 的作用是给第 2、3 轮换一个更好的起点,并回答「窗口的单调线在哪里到头」(这一条同时决定第 2 轮 E 位外围的窗口取多长)。

**上一轮预测对不对:** 第 1 轮,还没有。

## 第 2 轮

**看到的材料:** 第 2 批(M2)是 day_hurst(Open) / day_centroid(Volume) / ts_var(day_max(Volume)) 一类「极慢的日内形态统计」,富集最高的是 cross_sum(day_hurst(Open), 241);本流第 1 轮 N 位与 E 位的种子没有一个进前 5(最好 -1.47,来自随机骨架),所以「方向性的跨日回归 / 事件后走向」读法在这个尺子下没赢。

**信念更新:** alpha 的唯一线索是「慢」。R 里 31–211 窗口的 |cs_demean(C)| 的 ts_stddev 窗口 20→60→90→120→241 单调变好,241 日版 train 0.48 / valid 0.55(16–226 版 0.34 / 0.69),与原 head ρ 仅 0.3,已很接近 0.5 线。换手低是关键,C 的水平没 alpha。

**事先预测:**
- E(核心 K = abs_(cs_demean(C31)),16 个种子,聚合改为 CV / 分位 / 偏度峰度 / 自相关 / 赫斯特 / 对绝对日收益回归):出 head 概率约 25%。最可能的是 CV、0.8 分位、cross_med、cross_ema 120 与 241 日 ts_stddev 同族的版本(与已知 241 版 ρ 会较高,但库禁令按 head 算,241 版不是 head 所以不挡);分数预期 0.2~0.6。失败方式:新写法与 ts_stddev 241 实质同信号,被波动控制吞掉。
- N(慢的日内路径统计,hurst / ar1 / gini / centroid 的 241 日聚合):出 head 概率约 12%;最可能是 cross_mean(day_hurst(Open/Close),241) 与 cross_med;预期 -0.5~0.4。风险:名义股价 / 价差代理。
- R(窗口 360/480/720 与 CV 形式,共 10 个):预计 ≥ 6 个比原 head 好 0.1 以上;最好的 720 / 480 日约 0.3~0.6,有 ~30% 概率某个 ≥ 0.5;窗口 720 日热身期长,覆盖率下降是风险。

**上一轮预测对不对:** 第 1 轮 E / N 预测出 head 概率 6% / 8%,结果都没出,方向对;R 预测「大部分变体好 0.1 以上」基本对(14 个里 8 个好于原 head),「最好在 60~120 附近、241 会回落」错了,241 才是最好,线还没到头。

## 第 3 轮

**看到的材料:** 本流第 1~3 批全是同一族(放量分钟收益 C 的 ts_stddev 外壳)与 M2 的慢日内形态统计。已生效的 R 替换:ts_stddev(|C|,241)(无 cs_demean)train 0.39 / valid 0.63 成为最好 head;add 两项版 0.32。窗口 360/480:train 变差(-0.08/-0.2)但 valid 升到 0.73/0.79。r2 的 E(分位 / 偏度 / 自相关 / 回归读 K)和 N(241 日均值读 hurst / centroid / gini)都没出 head(最好 -2.69 级,与 head 差一大截)。

**信念:** alpha 来自「放量冲击幅度的跨年不稳定性」,慢、换手低;水平读法(均值 / 分位 / 回归)没用,二阶矩读法(std)有用。train 对长窗口敏感(热身期与 2018-19 行情),valid 一直好。没有碰 2026。

**本轮预测:**
- E(核心 A0 = |C|,15 个种子,读法改为长短 std 比、半标准差、截面排名 / 稳健 z / winsor 后再取 241 日 std、sqrt、差分 std、局部 std 均值、峰度等):出 head 概率约 20%。最可能是 ts_stddev(cs_rank(A0),241)、sqrt 版、半标准差(上行);预期最好分数 0.0~0.45,多数与 head ρ 在 0.6~0.9 会被库禁令挡掉(ts_stddev(sqrt(A0)) 风险最大)。
- N(日内形态量的 241 日 std,14 个):出 head 概率约 10%;最可能 day_centroid / day_hurst / day_gini 的 std 或其排名版;预期 -1.0~0.2;风险:名义股价 / 报价单位代理;GP 对 ts_stddev(day_*,241) 这个外壳的骨架若在库里已有会被拒。
- R(head1 8 个、head2 2 个):预计 2~3 个比原 head 好 0.1 以上(最可能 300 日、混合两套窗口、平滑后取 std);替换为主;出现 ≥ 0.5 概率约 10%。

**上一轮预测对不对:** 第 2 轮 E 预测出 head 25% — 没出(错,读法换成分位 / 高阶矩没用);N 预测 12% 没出;R 预测「≥ 6 个好于原 head」基本对(窗口越长越好,241 出了 head),「720 日 0.3~0.6」错(720 日 train -0.57)。
