**材料(本流只看到第 1 个结构批 B139,`day_min(F)` 一族,29 条,1 条手写库 + 28 条挖掘库):** 快照里 3 个 head 都是素材,不是真 head:`pow_3(cross_hurst(neg(day_min(Ret)), 15))` −1.34(train −1.34 / valid −1.19)、`cross_cov(day_min(High), day_mean(Amt), 30)` −1.60、`add(day_min(Ret), day_var(Open))` −2.35。批里 12 / 21 个已评分候选含 `day_min(Ret)`,富集差 −0.01(p 0.80)。拆解表里没有任何变体比原 head 好 0.1 以上(R 候选为空)。

**我这一轮读到的、影响判断的东西(都只有 2025-12-31 以前的读数,没有碰 2026,也没有用 W01 的前推段读数):**
1. `struct/members.csv`(只含 train、不去控制)里,B139 原始读数最好的是日内低 / 高价的**水平**(`cross_cov(day_min(High), day_mean(Amt), 30)` 1.10;`ts_max(day_min(Close), 5)`、`inv(day_min(High))`、`cs_normalize(day_min(Low))` 0.51 ~ 0.57,换手 0.01),去掉控制和冠军之后全部不高于 −2.35。后复权价格水平 ≈ 累计复权收益 + 名义价格,这就是被控制和冠军吃掉的那一块。`day_min(Ret)` 本身原始换手 0.68、净夏普 −6.39。B140(20 条)是同一个 `day_min(Ret)` 外裹 sigmoid / log / pow 的单调壳,原始读数全是 −6.39,没有新现象;B141(17 条)里除了 `pow_2(sigmoid(day_min(High)))`(原始 1.40,换手 0.01,又是价格水平)也都是 `day_min(Ret)` 的壳。第 2、3 轮的批预计给不出新材料。
2. 别的流第 1 轮的结果(读 `partura/s20xx/r2/loc.md`、笔记):唯一出真 head 的几类是 (a) 2013 的 `cross_regbeta(滞后的成交额类量, day_sum(Ret), 120)`(+0.76 ~ +1.04,120 日滚动的「收益对活跃度的斜率」);(b) 2029 的 `cs_last_low10(y, 嵌套成交额波动)` 阶跃带(+0.65 ~ +1.35);(c) 2028 的 `cs_first_low40(LogTotalCap, day_close(Low)) ÷ day_kurt(Volume)`(+0.73)。别的流的共同教训:慢才承重(120 ~ 241 日窗口),分桶 / 阶跃边界抬高换手,取值档位少的离散信号过不了「不同值 ≥ 50%」的闸门。总领 PROGRESS 的怀疑(阶跃带可能是尺子的盲区:只扣控制排名的 1 / 2 / 3 次项,扣不掉组别阶跃)我同意,所以这一轮不碰阶跃 / 筛子,而是写连续、无量纲、慢的读数。
3. **`cross_hurst` 的内核行为(我自己读源码 + 8 日窗口小张量核对,没有用市场数据):** 窗口里一旦有缺失日,累计偏差在缺失日之后全是缺失,R 只用缺失日之前的前缀,S 用全部有限点,H 被系统性压低;缺失恰在窗口第 2 天时 R = 0,H = −inf。引擎把停牌日置空,所以 head 1 的名次里很可能有一块是「近 15 日没停牌」。`neg` 与 `pow_3` 是空操作(拆解表里拿掉 neg 逐位相同)。这条我在 R 组里做了对照。
4. **数值自检(我自己的核对,不是评分):** 用 AlphaCube 合成立方体(80 只 × 420 日 × 241 分钟,含停牌与未上市)把 32 个种子 + 13 个 R 变体全算了一遍:全部能算、无 inf、覆盖率 0.97、截面取值离散度 1.0。再加 102 个一字板日(价格全天恒定、Ret 全 0)的版本:最初的种子 12(成交额加权价在区间里的位置)出了 2311 个 inf,原因是加权价与 L 有浮点舍入差而区间恰为 0;改成 `log(加权价 ÷ L) ÷ σ̄` 后全部无 inf。同样的原因,下探深度全部用 σ̄ = `cross_mean(day_std(Ret), 20)` 当分母,不用当日 `day_std(Ret)`(一字板日为 0、分子为 gap 下探时会除出 ±inf)。
5. 所有种子的算子骨架已对照 `members.csv` 的 5583 个骨架:32 个全是新骨架(R 变体不受骨架禁令限制)。库里含 `day_min(Ret)` 的 69 条里进入 cross_corr / cross_cov / cross_autocorr / cross_mean / cross_zscore / cs_mean 的是 0 条;CLV、`day_at_*_ratio`、`day_wmean`、带滞后回归元的 `cross_reg*` 在库里各为 0 条。

**目前对本种子 alpha 来源的信念(很弱):**
- `day_min(Ret)` 的水平没有 alpha:它是名义价格 / 波动水平 / 换手的函数(换手 0.68,控制和冠军吃掉水平),B140、B141 的壳也只是同一个水平。日内低 / 高价的水平是累计复权收益 + 名义价格,同样被吃掉。
- 剩下的只有两种赌注:(i) 尖刺序列的**动力学 / 关系**(持续、形状、对次日的反应、与市场尖刺的耦合),依据是 B139 里关系型 / 动力学型比水平好 0.8 ~ 1.9 且越慢越好,但 head 1 的优势可能是停牌标记;(ii) 日内最低价当**位置**用(收盘位置、下探深度、承接),依据是同一个原子写成比值才有水平以外的信息。两者我都只给低概率。
- 我不认为这个批里有真 alpha:3 个素材 head 都是 −1.3 以下,B139 的 29 条没有一条过线。这一轮的价值主要是给第 2、3 轮换一个更好的起点,并回答 head 1 的 Hurst 是不是停牌标记。

**本轮的任务与事先预测:**
