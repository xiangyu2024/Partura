## 第 1 轮

### 目前对本种子 alpha 来源的信念

材料只有第 1 个结构批 B007(`ts_mean(mul(log(add(mul(log(add(day_q_stat_std(F), day_std(F))), ts_hurst(div(day_last(F), day_max(F))...` 一族,11 条,全部来自挖掘库,10 条已评分)。三个「素材 head」是 −1.23 / −1.49 / −1.57(train −1.11 / −1.30 / −1.56;valid 与 train 同量级),不是真 head;拆解表 36 次评估没有一个高于 −1.0。10 个候选均分约 −2.0。

1. **同一条 GP 谱系:** 全是 `ts_mean(mul(log(add(mul(log(add(Q, S)), H), S)), H), 50)`,Q = day_q_stat_std(Vwap | Volume),S = day_std(Vwap | Volume | Low),H = ts_hurst(尾盘一分钟量 / 价, 20)。H 这个对象与隔壁流 2002(B004)读的是同一个,2002 的 E 位以 `div(day_last(Volume), day_max(Low))` 为核心。**所以我没有再围着 H 做 E / N**,否则两条流在同一个假设上重复花预算。
2. **Q 是什么(我用合成价格路径核实,没用市场数据):** 纯随机游走下 Q ≈ 1000 ± 300,与当天相对极差相关约 0.82,与 |总涨跌| / σ 相关 0.64;价格乘 3、波动放大 10 倍都不变(无量纲);加分钟噪声下降(噪声 0.4% / 分钟时约 390);叠加 3% 趋势上升(约 1460);常数路径(一字板)= 0;价格取整到 1 分(名义价 3 元)几乎不变(约 960)。结论:Q = 日内低频摆动 / 分钟噪声的比值(价格发现信噪比),不是波动率、不是价格水平。
3. **head 里 Q 几乎没有截面方差(按量级估计,没数据):** log Q ≈ 7 ± 0.5 → 再 log ≈ 1.9 ± 0.07,而 H 在 0.5–1(相对 ±14%),所以三个 head 的次序主要由 H 决定;拆解表里去掉最外层 ×H,head 2 掉 0.49、head 3 掉 0.13,和这个读法一致。含 Volume 叶子的候选 raw 训练夏普高(0.85–1.36),价格叶子(Low / Open / Vwap)的 raw 是 −0.3 左右(`struct/members.csv`):前者是 `day_std(Volume)` 的水平(已知成交额族),被尺子剥掉后就是 −1.5。另外 B007 有 4 条是冠军族成员(挖掘冠军的族 18、87、71,都是带 Volume 叶子的版本:`day_q_stat_std(Volume)`、`day_std(Volume)` 或 `day_max(Volume)`),它们的信息已经在冠军控制里,这是批里 head 全负的又一个原因;价格叶子的成员不在冠军里,但 raw 就没有收益。
4. **库里读过 Q 的方式只有水平类:** `ts_mean(log(add(Q, S)), 50)` raw 训练夏普 1.87(rank IC 0.011,换手 0.073)、`ts_std(log(add(Q, S)), 40)`(方向 −1)1.71、`ts_quantile_q75(Q, 50)` 0.46;但它们在新尺子下的分数我看不到,批里所有已评分候选都是负的,我的推断是它们的 raw 夏普来自流动性 + 名义价 + 波动状态(5 个控制和两个冠军)。没有一条读 Q「相对自己的常态」「与方向的关系」「在同价位 / 同流动性档内的相对位置」。这是 E 位的空白,也是我唯一的押注点。
5. **N 位押注的是尾盘「价」:** 批里的 head 都读尾盘一分钟的「量」;手写库里 Close − 成交均价只在 2 条表达式里出现(短窗口截面排名乘积),挖掘库里 `day_last(Volume)` 出现 115 次、全是量。把同一个时点搬到价格一侧(收盘相对当天均价的偏离 G、隔夜缺口 GAP、尾盘放量 V),读它们的慢变均值、联动、以及前一日偏离在次日开盘的回吐。
6. **先验很弱:** 这一批没有任何迹象说里面有冠军之外的 alpha。每个任务位出 head(score ≥ 0.5 且 |ρ_known| < 0.5)的概率我只给 4–6%。要靠的是「别人没试过的读法」,不是批里的结构本身。我有意不用市值 / 价位「阶跃带」算子(cs_first_* / cs_last_*):它们复现的是冠军已有的小盘 / 价位档倾斜,对 C(L ∪ X ∪ W02L) − C(L ∪ X) 没有增量。

### 目前对本种子 alpha 来源的信念

1. **B007 里承重的是 `ts_hurst(div(day_last(Volume), day_max(Low)), 20)`,Q 和 day_std 都是装饰。** R 的读数:去 Q 的 `ts_mean(H, 25)` 与带 Q 的差 < 0.05;拆解里去掉 Hurst 掉 0.42,去掉 day_max(Low) 只变 0.09;窗口 25 → 50 好 0.18,但 train 一直停在约 −1.0(−0.96 → −1.00),好的只是 valid。这说明在尺子下它没有毛超额(train 一直是负的 ~ −1),只是 valid 的负得少一点。我对「尾盘量的 Hurst 有 alpha」的信念很低,理由是 train 两种速度都 ≈ −1.0。
2. **Q 与成交特征的耦合(cross_corr(Q, 成交统计量, d))是这个种子里目前最好的读数,方向 −1,−0.8 ~ −1.0 的量级。** 这个量级不是「分数被成本压到 −2.5」的那一档,比随机的快速表达式好 1.5 左右,所以我相信里面有毛信号,但被成本吃光;15–60 日窗口的相关系数标准误 0.13 ~ 0.26,排名每天抖动。本轮 E 位要检验的就是这一点:同一类耦合读数慢化 4 ~ 8 倍(套 60–241 日的均值 / EMA)以后,分数是升到 −0.3 以上,还是不动。
3. **B008(MAX / 彩票效应)是冠军的一部分,没有增量。** 这一批的 head 就是 −2.70(train −2.10),拿冠军当控制后只剩快速换手的残差。我把它只留给 R 做一次「慢化 + 相对波动」的检验,不押 GP 位。
4. **新维度。** 两个库的 5583 条表达式一次都没读过 6 个日频字段(我对 members.csv 的叶子逐个计数,全是 0),冠军也是由这两个库合成的。股本结构(限售占比、流通 / 总股本的变化)是慢变量,换手近零,在这把苛刻的成本尺子下是唯一能「不被成本吃掉」的结构性来源;本轮 N 位押这个。先验仍然很弱:出 head 的概率几个百分点,押它是因为它与现有的所有读数都不相关,不是因为我知道它有效。

### 目前对本种子 alpha 来源的信念

1. **本流目前没有任何 alpha 的证据。** 最好的读数 −0.22(train −0.14 / valid −0.22)在 SE 量级内:5.6 年 train 的净夏普标准误约 0.42,2.4 年 valid 约 0.65,所以邻居之间 0.3~0.4 以内的差(Low→High、Amt、去分母、Hurst 窗口)都是噪声,不是结构信息。唯一稳健的模式是外层窗口越慢 train 越好(−1.00 → −0.77 → −0.66 → −0.14),与别的流一致。要成为 head 需要两段都 ≥ 0.5,离现在最好的还差 0.6~0.7。
2. **「慢」是前提,但慢不是 alpha。** 同样的慢化对 Q 耦合没有用(train 停在 −0.8),对 H 有用;所以我对 H 的信念只提高到「近似为零而不是明显为负」。H241 读的是尾盘量水平的长记忆,第 2 轮 R 里换成总量分母(份额而不是水平)掉到 −2.31,说明承重的是成交「水平」的持续性,与流动性控制(尺子已去掉多项式部分)是近亲。
3. **尺子下的 train 段是主要障碍:** 几乎所有 B009 / Q 耦合 / H 的读数 valid 比 train 好或持平(B009 head 2:train −1.17 / valid +0.02),说明 2018~2023-08 里这些信号的「毛超额 − 成本」不够,而 2023-08 以后的行情更友好。我不对 valid 做挑选(只有 2.4 年)。
4. **在这条流里还没有被读过的维度:** 个股与全市场的联动(同步性 / 下行联动 / 价格延迟 / 流动性共性)与日价格路径的形状(自相关 / 方差比 / 路径效率 / 好坏波动)。库里 5583 条没有这两类(字符串检索:个股 vs 全市场均值的滚动相关 0 条;`cross_semistd_*` 0 条;日收益的 `cross_autocorr` 0 条),冠军也就没有读过;它们是无量纲、一年窗口、换手近 0,正好是这把尺子下「慢」的前提。先验仍然很弱,理由是「没人读过 + 与所有已有读数无关」,不是「我知道它有效」。
5. **用户 2026-11-09 的提示(「如果全部算相关度太慢,就用聪明一点的 shrink」)在本轮落实在两处:** (a) 联动用「个股 vs 一条市场序列」的单指数收缩(`cs_mean` 做市场因子),不写 `ts_pearson` 那种与全市场每只股票同期窗口的相关(O(S²));(b) 短窗口相关 / 自相关 / 方差比乘 有效天数 / 241 向 0(或 1)收缩,把新上市 / 长停牌的几天窗口噪声压掉。
