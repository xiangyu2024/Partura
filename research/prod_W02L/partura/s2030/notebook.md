# 种子 2030 笔记(PROD W02L,P 组)

## 第 1 轮

**材料(只看到第 1 个结构批 B088,8 个库因子,全是挖掘库的同一条链):** 8 条全是原子 R = `cs_demean(sub(day_mean(Ret), 常数))`(盘中分钟收益均值相对全市场;常数在 cs_demean 下是空操作)外面套 `ts_max` 嵌套 + `pow_2`。库自己的读数:原样秩 IC −0.039 ~ −0.058(近期最大的相对涨幅越高、未来收益越低,即 MAX 效应),换手 0.02 ~ 0.15(很慢),原样净夏普 2.2 ~ 3.2。新尺子(去掉 5 个控制和两个冠军)下没有一条过线;3 个「素材 head」是批内最好的三条,−0.19(train −0.19 / valid +0.06)/ −0.40 / −0.43,不是真 head,方向翻成 +1。

**目前对这个种子 alpha 来源的信念(很弱,约 4% 的把握能在 3 轮里出一个真 head):**
1. 原样的边际是波动 / 规模 / 流动性 / 彩票偏好(低波动异常的另一面),尺子把它们剥掉后残渣在 0 附近。方向翻成 +1 说明残差里「同波动同规模下最近大涨过的」反而略好,但没有强到能扣成本。
2. 拆解表唯一一致的规律:**分数随记忆长度单调变好**,R 本身 train / valid −4.33 / −3.69 → 一层 ts_max(40) −1.41 → 嵌套两层 −0.42 → 外层 30→60 −0.12(valid +0.01)。外层 30→15 退到 −0.52 ~ −0.62。而与已知族的 ρ 一直在 −0.3 ~ −0.45。我的读法:这条链里决定分数的主要是**换手**(越慢越好),不是「读到了更好的信息」;R 的路径里有信息(原样秩 IC),但库里只用硬最大值读它。
3. 内层 `pow_2` 的敲除几乎不变分(+0.01),`sub` 常数的敲除也不变(+0.00,+0.03):承重的是嵌套最大的总窗口,不是这两个部件。
4. 一个没法核对的推理:ts_max 的值被板块涨跌幅宽度(LimitWidth 5% / 10% / 20% / 30%)和新股无涨跌停的前几天抬高,残差里可能混着「板块 / 次新」暴露。我没有在 E 位里直接检验它(E 位核心与 head 的 ρ ≥ 0.7 的外围会被库禁令拒绝,板块中性化后的 MAX 与 head 相关太高),留到第 2、3 轮如果出现用得上 LimitWidth 的核心卡再看。

**本轮的任务与事先预测:**
- **槽 1(E)核心 R = `cs_demean(sub(day_mean(Ret), 0.5))`(只用 1 个 E 位名额,同一核心至多还能用 1 次):** 12 个种子,外围一律是 R 的路径形状而不是硬最大值 —— cross_ema 漂移、嵌套 ts_min(下端对称)、上下极值之和、总和扣最大最小(修剪)、EMA 占比与信息离散度 ID、极值时点(argmax / argmin 的 EMA)、一阶自相关、盈亏比、跳跃 vs 漂移(cs_rank 之差)、极值新鲜度。窗口 60 ~ 120,骨架全部不在库里(本地用库的 skeleton_key 对过,35 条 R + N + R 变体全不在库里),35 条全部在合成立方体上算过:无 inf,取值离散度 0.7 ~ 1.0。
  - **预测:出 head 的概率约 3%。** 种子与三个 head 的 |ρ| 预计 0.05 ~ 0.5(最高的是「跳跃 vs 漂移」和「新鲜度」两条,0.4 ~ 0.6,因为含 120 日最大);与 5 个控制的 |ρ| 预计 < 0.5(嵌套 ts_min 与波动 / 已知族可能 0.4 ~ 0.6)。最可能最好的是慢的几条:`cross_ema(R, 60)`(漂移,符号预计 −1)、`cross_ema(is_gt(R,0), 60)`(占比)、盈亏比和嵌套 ts_min,分数预计 −0.6 ~ +0.1;自相关、时点、ID 这几条估计噪声大(排名每天抖),预计 −2 ~ −0.8。
  - 失败方式:(a) 所有种子都比三个 head 差,说明 head 里的「信息」其实就是窗口 + 嵌套带来的低换手,R 路径里的其它形状没有残差 alpha,第 2 轮就不再碰 R,转去批 B089(成交量分位数嵌套);(b) 若 `cross_ema(R,60)` 和占比最好且接近 0,说明慢的漂移是对的,第 2 轮核心改用同核心的「慢化版」再加外围。
- **槽 2(N)成交量状态下的「股票内部对比」:** 11 个种子,AV = day_sum(Amt) ÷ 自己 60 日均值(异常放量比),RC = 整日含隔夜的相对收益。放量日平均相对收益、缩量日平均、两者之差、上涨日成交额占比、AV 与 RC 的 120 日相关、量加权减等权相对收益、60 日最大异常放量、AV × RC 的 60 日最大 / 最小、缩量日最大涨幅、滞后一日 AV 与 RC 的相关。依据:Gervais–Kaniel–Mingelgrin(2001)、Llorente–Michaely–Saar–Wang(2002)。
  - **预测:出 head 的概率约 4%,略高于 E**,因为是库里的盲区(库里只有 5 日窗口的 `ts_corr(cs_rank(day_sum(Amt)), cs_rank(日收益))`),而且同股票内部对比天然去掉水平暴露。最可能最好的是放量日平均相对收益及其与缩量日之差、上涨日成交额占比,预期 −0.8 ~ −0.1;120 日窗口的相关类(种子 5、11)估计标准误约 0.09、噪声大,预期 −2 ~ −1;最大异常放量(种子 7)与流动性 / 已知族的 |ρ| 可能 0.4 ~ 0.6。
  - 相关度表预期:所有 N 种子对三个 head 的 |ρ| < 0.3,对控制 < 0.6,0 个被划。失败方式:上涨日成交额占比与 120 日相对收益高度相关,而尺子里的 20 日反转控制没有吃掉它,但半衰期没法把噪声压住 → 分数 −1 以下。
- **R(12 个变体,三组):** 烂部件 = 外层最大值的窗口太短 + 单点硬最大。把外层改 90 / 120 日(用 cross_max)、替换成上四分位均值 / 75% 分位数 / 120 日均值;head 3 另加「去掉中间多余的 cs_demean」。
  - **预测:** 窗口 90 / 120 的变体对原 head 的增益 +0.1 ~ +0.4(外层 30→60 本来就有 +0.25 ~ +0.28),约 70% 至少有一个过「比原 head 好 0.1」的线;上四分位均值 / 75% 分位数那几条更不确定(预期 0 ~ +0.3);120 日均值(检验极值本身是否烂)预期比原 head 差。过线的多半是「替换」(与原 head 的 ρ ≥ 0.5)。没有一个会到 0.5。
  - 若窗口越长越好一直延续到 120 日而 valid 转正,第 2 轮再加 241 日与更长的外层。

**上一轮预测对不对:** 第 1 轮,还没有。

## 第 2 轮

**信念更新:** 第 1 轮 E(R 的路径形状)与 R(窗口拉长)都没出 heads,验证了「R 链里的分数主要是换手而非信息」,放弃 R 核心。唯一接近正的是 N 位的成交量状态线(AV60×RC 的 60 日最大,最好 +0.09,train/valid +0.14/+0.09)。另一线索:B089 的 `abs_(ts_std(day_first(Amt),50))` 窗口拉到 100 日得分 +0.39(train/valid +0.39/+0.57),是本流迄今最近 0.5 的读数,但是水平量(随规模/流动性走)。两条合并的信念:alpha 来源在「成交额行为的无量纲二阶矩 / 联动」,不在价格极值。

**第 1 轮预测对不对:** E 预测最好 −0.6~+0.1、出 head 约 3%:对,E 最好 −0.13(预测偏悲观但方向对,出 head 0)。N 预测出 head 约 4%、最好 −0.8~−0.1:低估了,N 最好 +0.09,但仍没过 0.5;「放量日对比最好」没被验证,最好的是 cross_max(AV×RC),预测的是均值类,错。R 预测 70% 有变体比原 head 好 0.1:对(head 3 个 R 替换里有 2 个生效),但全部仍为负。

**本轮任务与事先预测:**
- 槽 1(E)核心 AV30 = div(day_sum(Amt), cross_mean(day_sum(Amt),30))(核心卡第 1 条,富集均值差 +1.91):12 个种子,外围从「极值」换成路径形状与联动(标准差 / 自相关 / 偏度 / 尾部均值 / argmax EMA / 与盘中相对收益的 cross_corr / 方向加权 / 高放量日占比)。预测:出 head 概率约 6%;最好的预计是 cross_corr(AV30,盘中收益,120) 与 cross_stddev(AV30,120),分数 −0.3~+0.3;最可能与已知族相关偏高的是 cross_stddev / 尾部均值(0.4~0.6)。失败方式:AV 相关类噪声大、半衰期压不住,−1 以下。
- 槽 2(N)开盘第一分钟成交额的无量纲二阶矩(开盘占比 OS 的标准差 / EMA / 自相关、变异系数、OR 的标准差 / 最大):12 个种子。预测:出 head 概率约 8%(本流最高),最可能是 CV 与 cross_stddev(OS,100);预计 −0.3~+0.4;若 CV 与已知族 |ρ| ≥ 0.5(与 day_std(Amt) 相关)则被判不合格。失败方式:去掉规模后读数消失,说明 +0.39 只是规模暴露。
- R:本轮没有(拆解表无比原 head 好的变体)。
- 第 3 轮备忘:B090(手写库分钟成交量结构 in_sustain_stddev)。若本轮 N 的 CV 类有效,第 3 轮用其做 E 核心。

## 第 3 轮

**信念更新:** 前两轮 6 个任务位只有 1 个 head(+0.22,train +0.57 / valid +0.22,仍未过 0.5):`cross_autocorr_s1(sub(day_ar1_coefficient(Amt), day_first(Volume)), 60)`。价格极值链(R)与 AV 路径形状(E)都是负分。目前的信念:alpha 的残差来源在「日内成交额 / 成交量分钟形状的日间持续性」(谁在交易:拆单机构 vs 事件散户),不在价格极值也不在成交额水平。head 的 sub 项里 day_first(Volume) 是量级,几乎主导排序,所以那条的 +0.22 很可能一半来自首分钟成交量的日间自相关;拆解表同族 ts_mean 版 Volume->Amt 改善 +0.5,说明水平项是烂的。把握:本轮出一个 ≥0.5 的 head 约 5%。

**上一轮预测对不对:** 第 2 轮预测 E(AV30 路径形状)出 head 6%、最好 −0.3~+0.3:E 最好 −0.27,偏乐观,方向对(没出 head)。N(开盘占比二阶矩)预测出 head 8%、−0.3~+0.4:N 位的结果在本轮快照里没有 heads,说明没过线,和「去掉规模后读数消失」的失败方式一致,没有给出强证据。

**本轮任务与事先预测:**
- 槽 1(E)核心 `day_ar1_coefficient(Amt)`:12 个种子,纯接力度的二阶矩 / 变化 / 与收益及开盘占比的联动 / 与 Volume 版之差。预测:出 head 约 5%;最好的是 `cross_autocorr_s1(ar1,60)` 与 `cross_ema(ar1(Amt)-ar1(Volume),60)`、`cross_corr(ar1, 盘中收益,100)`,分数 −0.5~+0.3;与已知族 |ρ| 低(<0.4),与 head 的 |ρ| 在 0.3~0.7(自相关那条可能被库禁令挡);失败方式:去掉 day_first(Volume) 后 ar1 读数消失(−3 级),说明原 head 的信息全在首分钟成交量。
- 槽 2(N)日内量形状统计量(峰度 / 偏度 / 量价同步 / 领先滞后 / 峰值时点 / Q 统计 / DW)的日间 EMA 与标准差:12 个种子。预测:出 head 约 5%;最可能好的是 `day_kurt(Volume)` EMA 与 `day_corr(Volume,|Ret|)` EMA,分数 −0.8~+0.2;与流动性 / 波动控制 |ρ| 可能 0.4~0.7(量与波动同步度),`day_argmax` 类噪声大、预期 −2 以下。
- R(8 个变体,head = +0.22 那条):去水平项 / 换无量纲项 / 窗口拉长。预测:约 50% 至少一个比原 head 好 0.1 且与已知族 |ρ|<0.5;去水平项(种子 1)最可能是 −3 级的垃圾(单用 ar1 是 −3.4),也是对「信息在水平项」的检验;窗口 100/120 更可能小幅改善。
