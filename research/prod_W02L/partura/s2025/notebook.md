**这一轮读到的事实(都已核对,给下一轮 PI,不用再查):**
1. `in_topk_masked(x, y, p, largest)` 的定义(`alphacube/operators/dt_in.py:684`):每天对 x 取最大(或最小)的 `(有效分钟数 + 1) // p` 个分钟,返回这些分钟里的 y,其余为 NaN。所以 `day_std(in_topk_masked(Volume, Ret, 10))` = 放量前 10% 分钟的收益的标准差;`True/False` 是放量腿 / 静默腿。
2. 拆解表:只留放量腿 −4.06(train −4.06 / valid −3.84)、只留静默腿 −2.49;两腿之差(head 1)−2.26,比任何一条腿都好;`Volume→Amt` 几乎不变(−2.19、−2.50、−2.47);`ts_stddev` 窗口 10 / 20 / 40 = −3.21 / −2.42 / −1.37(train 与 valid 同时单调变好,窗口 40 是唯一的 R 候选,+1.05)。
3. `members.csv`(只含 train 的未去控制统计):单日读数全被换手压垮(`day_std` 日换手 0.62、库口径夏普 −5.0;`day_mean` 0.85、−7.9);20 日平滑后的 `ts_mean(day_std(·))` / `ts_stddev(day_std(·))` 日换手 0.06 / 0.09、夏普 +1.3 / +2.3,rank IC 约 −0.05。方向类(`day_mean`)在批里从来没有被平滑过。

6. 数学:放量腿的 std ≤ √10 × 全天 std(10% 子集围绕自己均值的方差不会超过围绕全体均值的方差的 10 倍),所以 `div(C, σ全天)` 有界(≲ 3.2),不会爆点。静默腿 std 的不同值占比 0.878(约 12% 的格子并列,多半是 0:静默分钟全是零收益)。

**本轮读到的事实(都已核对,给下一轮 PI,不用再查):**
1. **第 1 轮三个任务全没出 head。** E 位(核心 σT − σB)评分 91、最好 −0.25(train −0.25 / valid −0.11);前 5 名全是 GP 自己长出的 `cross_max(…, 241)` 外壳(−0.25 / −0.31 / −0.33 / −0.40 / −0.45),我写的种子(z 分数 / 回归残差 / 相关 / 桶内标准化 / 尾部均值 / 慢 EMA)没有一个进前 5。N 位评分 84、最好 −0.43(`cross_mean(day_skew(放量腿) − day_skew(静默腿), 241)`,train −0.43 / valid +0.48),其次 −0.50(聪明钱 Q 的变体,train +0.49 / valid −0.50)、两个 −0.72(Q 的 Volume 权重版,train +0.20 / valid −0.72)、−0.79。R 的 16 个变体:窗口 80 替换了第 1 轮编号的 head 2(`ts_stddev(σT, 20)`,−2.42 → −0.72),`ts_mean(·, 40)` 替换了第 1 轮的 head 1(σT − σB,−2.26 → −1.69),收录 0 个。**我只看得到每个任务的前 5 名,看不到自己种子的分数。**
2. **R 的教训(本轮设计的依据):** 对 σ放量的「变异性」`ts_stddev` 窗口 60 / 80 / 120 / 160 / 241 = −0.98 / −0.72 / −0.27 / −0.29 / −0.30(120 以后走平,ρ_known −0.04 ~ −0.11);变异系数版(除以均值)更差(−1.16 / −0.55);对「水平」做慢均值反而更差:σ静默 `ts_mean(·, 60 / 120)` = −3.42 / −4.14(ρ_known −0.56 / −0.54,越过 0.5 线),核心差 `ts_mean(·, 120 / 241)` = −2.56 / −2.39(方向翻成 +1)。**水平被流动性 / 已知族吃掉、慢化只是加强了对控制的暴露;变异性、不对称和耦合没有这个问题,越慢越好。**
3. **尺子的读法(`partura/steer.py: reward`):** 方向与半衰期只用 train 选;score = 纯多头十分位书(扣 15 bp)对「有信号有标签的等权」的超额夏普,取 train 与 valid 中较差的。所以 `train −0.43 / valid +0.48` 的意思是:train 里最好的那个方向也只有 −0.43,但同一个方向在 valid 里是 +0.48。
4. **GP 的种子规则(`mining/gp.py: _seeded_population`):初代只从种子里按适应度挑至多一半(16 个),「同一骨架只要一个」。** 骨架抽掉字段、常数、窗口,所以只差窗口或字段的种子会互相挤掉,有效种子数 = 不同骨架数。本轮每个种子的骨架互不相同(已逐个核对:E 14 个 / N 15 个都是 14 / 15 个不同骨架,都不在 members.csv 的 5583 个骨架里)。第 1 轮我没有注意这一条。
5. **算子事实(用本机解析器试出来的):** `cs_mean(x)` 要求 x 每股票每天一个值,所以不能对分钟序列做截面均值(`day_corr(Ret, cs_mean(Ret))` 解析报错:`cs_mean(Ret)` 被当成日频的收盘到收盘收益,collapsed operand);只能对 `day_*` 的结果取 `cs_mean`,例如 `cs_mean(day_sum(Ret))` 是大盘当日开盘到收盘的等权收益、`cs_mean(C)` 是全市场当日平均的某个日度读数。`cross_semistd_neg/pos` 只接受正的序列(取 log 变化),不能直接用在收益上。`day_wmean` 权重取 |w|。`cross_regbeta(x, y, d)` 是 y 对 x 的斜率。
6. **别的流在本波的读数(只取 train / valid,来自 `partura/s20xx/r2|r3/loc.md`,规则 §5 允许):** 已出的 head(≥ 0.5)有三类来源,都不是「慢特质」:2029 `cs_last_low10(·, 多层 ts_std(day_mean(Amt)))`(+1.35)、2028 `cs_first_low40(LogTotalCap, day_close(Low))`(+0.73)这两条是「阶跃带」,PROGRESS 已记为尺子盲区嫌疑;2013 `cross_regbeta(滞后一日的成交额量纲 × 成交量名次, day_sum(Ret), 120)`(+1.04,train +1.15 / valid +1.04)是带量纲回归元的斜率,量纲项使它近似 Amihud 型水平。慢特质(`cross_corr(·, ·, 241)` 一类)在别的流里的最好读数只有 −0.3 ~ +0.13(2010 的 +0.13:晚盘 DW 与早盘收益的 241 日相关;2018 的 +0.10;2020 的 +0.10;2009 的 +0.07)。**所以我对「慢特质能到 0.5」的先验很低(每个位几个百分点),本轮不去复制阶跃带 / 量纲斜率,而是押两个不同的变异性 / 耦合方向。**
7. 第 1 轮审计员指出的事实,本轮已改:`cross_*` / `ts_*` 窗口没满时是扩张窗口(对可得天数取统计量),不是 NaN;2018 年最前面 d−1 天里 `cross_corr` 在样本很少时会是 ±1。
