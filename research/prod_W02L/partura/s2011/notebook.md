# 种子 2011 笔记(PROD W02L,P 组;流 2011 = 批 B031 / B032 / B033,T04 主题:day_ar1_coefficient 一族)

## 第 1 轮

**材料(第 1 个结构批 B031,20 条成员,`pow_05(day_ar1_coefficient(F))` 一族,全是挖掘库 X):** 18 条已评分。新尺子(去 5 个控制 + 两个冠军)下没有一条为正,三个「素材 head」是 −1.80 / −1.98 / −2.11,不是真 head(train 与 valid 的分数几乎一样,−1.4 ~ −2.0)。

**目前对这个种子 alpha 来源的信念(很弱):**
1. 三个 head 都是 C0 = `day_ar1_coefficient(Volume)`(分钟成交量的日内一阶 OLS 自回归系数)的**水平**平滑。拆解表:窗口 25 / 50 / 100 是 −2.57 / −1.98 / −1.65(越慢越好);Volume 换 Amt 不变(−2.04 / −2.13);去 pow_05 不变(必要性 +0.00 ~ +0.04);C0 自己不平滑是 −3.44;只有 head 3 里 `ts_quantile_q75` 被去掉时分数掉 1.30(= 平滑承重,不是 sigmoid / decay 承重)。
2. 水平和已知成交额族的 ρ 是 −0.51(C0)到 −0.76(q75 平滑后):它主要是「成交笔数 / 流动性」的代理(笔数多 → 噪声小 → 日内 U 形占主导 → AR1 高)。新尺子把这一块剪掉,剩下的是「没有信息 + 换手成本」,分数落在 −1.8 ~ −2.1。
3. 一个重要的推断(不是事实,只是我从三个 head、窗口和 Amt 互换都一样平推出来的):在新尺子下,**没有信息的残差信号会稳定地得 −1.7 ~ −2.0 左右(成本拖累)**。所以 ≥ 0.5 要求的是「超出成本拖累之外还有约 2.5 个夏普单位的毛收益」,而且要慢。库里 1360 条已评分的一条都没过,与此一致。慢变量(窗口长)得分高,但越慢越和已知族重合(−0.76)被禁令挡住,这是这一流的核心张力。
4. 唯一与已知族几乎无关的是 `cross_autocorr_s1(pow_05(C0), 30)`(ρ −0.03 ~ −0.08),分数 −1.80(train −1.36 / valid −1.80),也没有信息,只是「正交 + 吵」。
5. 别处的线索(只看 train / valid 的读数,没有碰 2026):W01 的 head 里 `cross_corr(日内统计 A, 日内统计 B, 60 / 120)` 这种「两个日度序列的滚动耦合」是出分最多的一种外围(无量纲、不含水平、慢);W02L 的 PROGRESS 里唯一为正的是 B015 批的「成交额方差的波动」(二阶慢变量)。所以我押:**把 C0 当探针做耦合 / 二阶量,而不是做水平**;并且换一种测量,读订单流符号持续性而不是成交量平滑。

**本轮的任务与事先预测:**
- **槽 1(E)核心 `day_ar1_coefficient(Volume)`:** 外围全是时间序列耦合(与当日涨跌 / 昨日涨跌 / |收益| / 隔夜跳空 / 成交额变化的 60–120 日滚动相关或斜率,领先减跟随,z 分数,耦合 × 状态),加 C0 的 100 日标准差 / 四分位距,再加 1 个市值门槛探针(种子 15)。预测:**出 head 的概率 ~ 3%**;最好的候选分数落在 −1.2 ~ −2.0;种子 15(带门槛)最可能是这一位里分数最高的,而且如果它是,来源多半是门槛而不是耦合(W01 里 `cs_first_low20(LogFloatCap, LogFloatCap)` 单独就是 1.8,尺子剪不到门槛函数)。耦合类种子与已知族的 ρ 预计 < 0.3,与三个 head < 0.3,不会被禁令挡;标准差 / 四分位距两个种子(13、14)与 head 的 ρ 可能到 0.5 ~ 0.7,有被表划掉的风险。最可能的失败方式:耦合被涨停日(一字板的成交量路径极平、收益 +10%)主导,变成「涨停次数」,与波动 / 反转控制重合。
- **槽 2(N)订单流符号持续性:** 带符号流 `mul(sign(Ret), Volume)` 的日内 AR1、对数差分 AR1、减同分钟 20 日均值后的 AR1,外面是 60–120 日的均值 / 分位数 / EMA;加相减(带符号 − 不带符号)、桶内排序、市值门槛探针(种子 10)、持续性 × 近 20 日收益方向(种子 15)。预测:**出 head 的概率 ~ 3 ~ 5%**,略高于 E,因为这是新的底、骨架都不在库里;最好的候选在 −1.0 ~ −2.0。最可能的失败方式:带符号流在价格不动的分钟为 0,对薄票零值多,仍然读成交频率(与已知族 ρ 超过 0.5,不算 head);种子 5(相减)和 11(桶内排序)是对这一点的补救。若有 head,最可能来自种子 5 / 11 / 15。
- **R(13 个变体,head 1 的 6 个 + head 2 的 7 个):** head 1 的问题是估计量吵、源头被 U 形污染(水平不是问题);head 2 的问题是水平与已知族重合(−0.76)。预测:**没有一个变体满足「比原 head 好 0.1 且与已知族 |ρ| < 0.5」同时又进库(≥ 0.5)**;满足「+0.1 且 ρ < 0.5」的可能有 0 ~ 3 个(多半是 head 1 的慢速版本,从 −1.80 到 −1.5 左右,仍远低于 0.5),所以 R 的作用只是直接读 13 个手写变体的分数。

**上一轮预测对不对:** 第 1 轮,还没有。

**给下一轮的备忘:**
- 第 2 轮会看到 B032(`pow_2(day_ar1_coefficient(F))` 一族,18 条,全是 X,其中 1 条冠军族),第 3 轮 B033(`ts_decay_linear(sigmoid(pow_2(pow_05(day_ar1_coefficient(F)))))` 一族,14 条)。核心 `day_ar1_coefficient(Volume)` 的 E 位这一轮用掉 1 个,整个实验至多再用 1 个。N 位这一轮要通过审计,这样 3 轮至少 1 个 N 位的要求就满足了。
- 要看的:耦合类 / 带符号流类的最好分数是否好过水平类(−1.65);种子 15 与种子 10(门槛探针)是否领先;若门槛领先,下一轮拆解把门槛去掉,看分数还剩多少(这是对「分数来自市值门槛的非多项式暴露」的检验)。
- 想验证(需要服务器数据,本角色不跑):带符号流 AR1 与已知成交额族 / 流动性控制的日度秩相关到底多高(预计 0.3 ~ 0.6);涨停日对耦合量的贡献。

## 第 2 轮

**材料:** 第 2 个结构批 B032(`pow_2(day_ar1_coefficient(F))` 一族,18 条,全是 X;其中 `pow_2(day_ar1_coefficient(Close))` 是价格档的)。快照 6 个 head,全是负分(−1.70 ~ −2.66):均为 C0 = `day_ar1_coefficient(Volume)` 的水平平滑,和第 1 轮同一类东西;B032 的 train 读数里这一族原始净夏普 +2.1(对比去控制之后 −2.0),再次说明水平类就是已知成交额族。

**上一轮(第 1 轮)预测对不对:**
- E 位(核心 C0,耦合外围):预测 head 概率 ~3%、最好 −1.2 ~ −2.0。结果 0 个 head,最好 **−0.72**(`cross_corr(cross_delay(C0, 1), day_sum(Ret), 120)`,train −0.59 / valid −0.72),前 5 名里 4 个是「C0 与涨跌 / 成交额变化的 60 ~ 120 日滚动相关」。**比预测好**:耦合类确实好于水平类(−1.7 ~ −2.7)约 1 个夏普。我押的「种子 15(市值门槛)最可能领先」**错了**:领先的是纯耦合,门槛没有出现在前 5。
- N 位(带符号订单流):预测 head ~3 ~ 5%、最好 −1.0 ~ −2.0、可能来自种子 5 / 11 / 15。结果 0 个 head,最好 **−1.79**(`sub(cross_mean(L1, 20), cross_mean(L1, 120))`,L1 = `day_ar1_coefficient(in_logchg(Volume, 1))`),其余前 5 名是 GP 自己的单特征树(`day_es_ratio_hi(Ret)`,−2.19)。**偏弱端**;带符号流那一套(Lillo–Farmer 故事)没有得到任何支持,分数最好的 N 候选恰恰是 L1,不是带符号的。
- R(13 个变体):预测没有一个同时满足「比原 head 好 0.1 且 ρ_known < 0.5」。结果有 2 个(`cs_bucket_demean(q75@100, 成交额族)` +0.28 替换了 head 1;`cross_autocorr_s1(L1, 60)` +1.16,ρ_known −0.20、ρ_head 0.08,但 −0.64 仍 < 0.5,没进 head)。「最好约 −1.5」**错得很大**:L1 的自相关是 −0.64(train −0.12)。五种「换源头」(L1 / 减同分钟均值 / 带符号 / z 分数 / 仅加平滑)里只有 L1 动了基线(−1.7 ~ −2.5),其余四个全在基线上。

**目前对本种子 alpha 来源的信念(第 1 轮之后更新):**
1. **水平类全是已知成交额族的换皮**(去控制后 −1.7 ~ −2.7),本流不再押水平。新尺子下「没有信息的信号」的基线是 −1.7 ~ −2.1,主要是换手成本;≥ 0.5 要求毛收益比基线多约 2.2 ~ 2.6 个夏普单位,所以**慢**(换手低)和**有毛收益**两件事缺一不可。
2. **L1 是这两批里唯一有迹象的底**。机制猜测:L1 ≈ −0.5 × 分钟成交量对数路径里瞬时噪声的占比,日度 L1 序列的一阶自相关高 = 这只股票的成交结构在一段时间里单向漂移(参与者结构切换);L1 自相关的 train −0.12 说明毛收益不小。但它的 valid −0.64,train / valid 不对称,而且有两种非 alpha 解释我还没排除:(a)薄票有效分钟对少,L1 估计噪声大,自相关其实是流动性(R 位实测与已知族 |ρ| 0.20,不高);(b)次新股成交结构单调漂移。
3. **耦合(与涨跌的滚动相关)是第 1 轮唯一整族好于水平的外围**,但 E 位核心固定为 C0,分不开「承重的是 AR1 还是耦合」,这是本轮 N 位要拆的。
4. **慢是最大的杠杆**:head 1 的 q75 窗口 50 → 100 → 200 是 −2.00 → −1.70 → −1.08(valid −0.13)。这个变体与已知族 ρ 仍只有 −0.04。本轮 R 位继续往 241 / EMA 120 走。train 比 valid 差(−1.08 vs −0.13)是个异常,原因不明(可能是 2018 ~ 2019 年的热身与行情结构),先不解释。

**本轮的任务与事先预测:**
- **槽 1(E)核心 L1 = `day_ar1_coefficient(in_logchg(Volume, 1))`(15 个种子):** 外围全是二阶量(EMA 包自相关、241 日自相关减 60 日、60 日 Hurst、月滞后相关、差分自相关、z 分数)和 L1 与涨跌 / |涨跌| / 成交额变化 / C0 的一年窗口耦合,加三个探针(排除次新 ListAge、成交额族十分位内排序、减去 C0 的自相关)。预测:**出 head 的概率 ~4%**;最好的候选在 −0.3 ~ −1.0;最可能领先的是种子 1(EMA 包自相关)、2、5、6;探针种子 12 / 14 若与种子 1 差 < 0.2,则来源不是次新 / 流动性;若种子 12 明显掉下去,则 L1 自相关主要是次新股。最可能的失败方式:241 日窗口的相关系数标准误 ~0.065,截面差异被估计噪声淹没,所有种子都落在 −1.2 ~ −1.8 的基线;其次是耦合种子被涨停日支配。
- **槽 2(N)个股量价动态耦合(Llorente–Michaely–Saar–Wang 的交互项思路,不含 AR1)(12 个种子):** 对象是「昨日成交额冲击 / 昨日买卖失衡 / 昨日 涨跌 × 成交额冲击」与今日涨跌的 241 日滚动相关,加 3 个对照(失衡水平 EMA、带符号放量均值、桶内排序)。预测:**出 head 的概率 ~4%**;最好的候选在 −0.4 ~ −1.2(把窗口从 60 ~ 120 放到 241 应当再抬高 0.2 ~ 0.5);最可能领先的是种子 1 / 2 / 5 / 11;若水平对照(种子 6、7)与耦合种子分数相当,说明承重的不是耦合,是「慢」。若 N 位的耦合种子明显差于 E 位里 C0 / L1 的耦合种子,说明 AR1 才是承重的;反之(≈ −0.7)则 AR1 是乘客。最可能的失败方式:同期失衡与日收益共线(种子里只放了领先版本)、一字涨停日支配耦合。
- **R(12 个变体,4 个 head):**
  - head 1(分桶去均值的 q75@100):5 个,窗口 200 / 241 / 241 日均值 / EMA 120 / 源头换 L1。预测:**200 / 241 的变体 score 在 −0.8 ~ −1.2**(train 仍是短板,−0.9 ~ −1.1,valid ~ 0),替换 head 1,不会过 0.5;没有一个变体进 head。
  - head 2(`cross_autocorr_s1(pow_05(C0), 30)`):3 个,L1 的 120 / 241 日自相关、EMA 包的 60 日。预测:**120 / 241 日比上一轮 60 日的 −0.64 好 0.1 ~ 0.4**(换手更低),最好的约 −0.3 ~ −0.5;有 ~5% 的机会 ≥ 0.5(这是本轮 R 里唯一有机会的)。
  - head 3(q75@50 的 pow_2 版):1 个(200 日 + 分桶去均值),预测 −1.0 ~ −1.4。
  - head 5(`pow_2(day_ar1_coefficient(Close))`):3 个(EMA 60 / 120、源头换成价格对数变化的 AR1)。预测:EMA 变体 −1.8 ~ −2.4(价格水平 AR1 与波动 / 价位有关,只是少付成本);价格对数变化 AR1(Roll 弹跳)最不确定(−1.5 ~ −3.0),可能与流动性族 |ρ| > 0.5 被判不合格。

**给下一轮的备忘:**
- 第 3 轮会看到 B033(`ts_decay_linear(sigmoid(pow_2(pow_05(AR1(F)))))` 一族,14 条,全是 X,几乎全是 AR1(Volume) 的水平平滑 + sigmoid / decay 嵌套)。这一批对水平类不会有新东西,估计 heads 全是负分;第 3 轮应该用 N 位 / E 位沿本轮最好的那一条线(L1 自相关或耦合)再走一步,而不是用 B033 的外围。
- 核心用量:C0 = `day_ar1_coefficient(Volume)` 已用 1 个 E 位(上限 2);L1 本轮用 1 个(上限 2);`day_sum(Ret)` 还没用过。
- 本轮读数出来以后要先做的:(1)L1 的 241 日自相关 vs 120 日 vs 60 日(窗口斜率),看是不是「越慢越好」;(2)探针种子 12(排除 ListAge)与种子 1 的差,判断是不是次新股;(3)N 位耦合种子与水平对照的差;(4)head 1 的 241 日变体 train / valid 是否继续收敛,train 的 −1.08 是否随窗口再改善。
- 想验证(需要服务器数据,本角色不跑):L1 日度序列与有效分钟对数(`in_logchg` 有效点数)的相关,以判断 L1 自相关是否只是「有效分钟数的自相关」;L1 自相关与 ListAge 的日度秩相关。

## 第 3 轮

**材料:** 第 3 个结构批 B033(`ts_decay_linear(sigmoid(pow_2(pow_05(AR1(F)))))` 一族)。快照 9 个 head,全负(−1.08 ~ −3.03),全是 AR1(Volume) 水平的平滑 / 嵌套,和前两轮同一类东西,批本身没有新东西。

**上一轮预测对不对:**
- E(核心 L1,预测 head ~4%、最好 −0.3 ~ −1.0):0 个 head,但最好 **+0.19**(`cross_regalpha(L1, 昨日收益, 241)`,train +0.19 / valid +0.71),**比预测好**,且是截距型而不是我押的二阶自相关(自相关外围在 −0.15 ~ −0.5)。
- N(昨日量冲击 × 收益耦合,预测最好 −0.4 ~ −1.2):0 个 head,最好 **+0.32**(`cross_regalpha(day_centroid(Amt), 2 日前收益, 241)`,+0.32 / +0.44)。**比预测好很多**,但承重的不是我写的 Llorente 耦合,是截距;我对「耦合」的机制猜测被证伪,对「窗口放到 241 日」的猜测被证实。
- R:head 1 的 200 / 241 日变体 −1.08(替换);R 里 `cross_autocorr_s1(L1, 241)` −0.16,好于 120 日(−0.52)、60 日(−0.64):越慢越好成立,但进不了 0.5。

**目前对本种子 alpha 来源的信念:** 水平类是已知族换皮,放弃。两个正分读数都是「241 日滚动回归截距」型(x = 某个日内统计量,y = 滞后收益)。截距 ≈ 剥掉 x 暴露后的一年平均收益,即特质慢动量 / 反转;换手低是它能越过成本基线的原因。我不知道承重的是 x(centroid / L1)还是截距本身 —— 本轮 N 位专门拆这个。

**本轮任务与事先预测:**
- **槽 1(E)核心 `day_centroid(Amt)`(15 个种子):** 外围 = 不同滞后(1 / 3 / 20)、斜率 / t 值、窗口 120 / 180、241 减 60、分桶去均值、EMA 20。预测:**出 head 概率 ~12%**(这是全流最接近 0.5 的读数,train / valid 同号);最好候选 +0.2 ~ +0.6;最可能领先的是种子 1(滞后 1)、9(EMA 平滑)、8(分桶去均值,若与已知族的重合是主要拖累);t 值 / 斜率种子预计弱(−0.5 ~ 0,斜率型没有截距那种慢)。失败方式:截距主要是一年平均收益,和 20 日反转 / 市值控制有残余重合,被尺子剪掉后就回到基线。
- **槽 2(N)截距型「基础漂移」换 x(14 个种子):** 预测:**出 head 概率 ~8%**;若 z 分数 / 日变化类(x 均值≈0,截距≈平均收益)种子与 day_std(Ret) / day_gini 类分数相当(都在 0 ~ +0.3),结论是承重的是一年平均收益(动量),不是 x,那么本流的 alpha 来源就是残差慢动量;若 centroid / L1 类明显好于其余,承重的是 x。最可能领先:种子 5(day_std(Ret),波动调整漂移)和种子 1(成交额冲击)。失败方式:截距主要等于 241 日平均收益,与已知族 / 反转控制的重合使残差被剪平。
- 没有写 R(上一轮 R 的最好读数仍 ≤ −0.16,没有可改进的烂部件)。没有 L1 的 E 位(它的核心已用过 1 次,正分读数 train / valid 不对称,E 位给 centroid);L1 作 y 的种子 12 放在 centroid E 位里做对照。

**给后面的备忘:** 若本轮出 head,下一步是拆截距 vs 斜率(种子 4、5 / 斜率版本)和一年平均收益对照;核心用量:C0 1 次、L1 1 次、centroid 1 次。
