## 第 1 轮

**材料(只看到第 1 个结构批 B100,`day_sum(F)` 一族,32 条,23 个已评分;3 个 heads 都不是真 head,只是素材):**
- `ts_decay_linear(ts_max(day_sum(Amt), 50), 50)` -0.80(train -0.80 / valid -0.66,方向 +1,半衰期 0);`ts_min(inv(ts_std(两层 50 日平滑的 Amt, 10)), 10)` -1.26(-1.26 / -0.10,方向 -1);`ts_decay_linear(day_sum(Volume), 5)` -1.34(-1.17 / -1.34,方向 -1,半衰期 5)。
- 富集表只有一行:含 `day_sum(Amt)` 的 12 个候选均值差 +0.46(p 0.22),不显著。23 个已评分候选均值约 -2.5 到 -2.9。
- 库里的原始读数(`struct/members.csv`,只含 train):32 条里 9 条是 `day_sum(Amt)` / `day_sum(Volume)` 的平滑 / 峰值 / 波动链,库自己尺子下净夏普 +0.9 到 +1.9,换手 1% 到 8%;短窗口排名 / 峰度 / argmax 版换手 25% 到 90%,净夏普 -4.8 到 -46(成本杀死)。

**目前对本种子 alpha 来源的信念(很弱):**
1. 成交额的水平就是控制的化身。拆解表里每一个 Amt 水平版与已知族 rho 都在 0.89 到 0.98(`day_sum(Amt)` 0.886、`ts_decay_linear(day_sum(Amt), 50)` 0.979、两层平滑 0.926),分数 -3.1 到 -3.5。库自己尺子下的 +1.5 到 +1.9 是流动性溢价,新尺子下(5 控制 + 2 冠军)一分不剩。换成 Volume 后 rho 降到 0.58 到 0.72,但那只是少了一点共享的水平、多了名义股价,分数 -1.4 到 -1.8,方向 -1,同样不是 alpha。
2. 唯一方向对得上的是峰值:`ts_max(day_sum(Amt), 50)` 方向 +1、半衰期 5,-0.50(train -0.50 / valid -0.34),是整个拆解表里最好的一行。外层 decay 窗口 100 / 50 / 25 对应 -1.36 / -0.80 / -0.34,单调:平滑越长越差。读法(推断,没有毛收益数):有内容的是「最近一个月放过多大的量」这件事本身,长平滑把水平加了回来。这对应高成交量溢价(Gervais 等 2001)与注意力(Barber 与 Odean 2008)。
3. 但 `ts_max(day_sum(Amt), 50)` 与已知族 rho = -0.93(窗口变体 -0.85 到 -0.91):尺子给我们的只是它的 7%。所以「峰值相对水平」要直接写进表达式(除以基线、对基线回归、桶内标准化),不能指望尺子去做。这是槽 1 的全部理由。
4. 第 2 个 head 的 valid 是 -0.10(train -1.26),是整个快照里最接近 0 的读数;`inv(ts_std(两层平滑, 10))` 单独 -1.09 / -0.23。train 差、valid 好,典型的风格切换,我不把 valid 当证据。它说明成交额水平的「漂移速度」在 2023 年以后有一点东西,但整段上看不出毛超额。去掉第二层平滑后 -0.71 / -0.32,所以第二层平滑是烂的(放进 R)。
5. 这一批所有成员都只读成交额的单变量时间序列,没有一条把当天的成交额与当天的价格变动联系起来。「量能不能推动价格」(弹性、相关、没有被价格解释的成交)是槽 2 的方向,依据是文献(Llorente 等 2002 的投机性与对冲性成交;Kyle 的 lambda;Amihud),不是本批的分数。
6. 我不押的:Amt 水平的任何平滑 / 分位数 / 峰值改写(库里 32 条成员已经挖过,rho 0.9 以上,GP 的骨架禁令会拒绝大部分);单日或 5 到 20 日的排名 / argmax / 峰度(换手 40% 到 90%,15 bp 吃光)。E 位:本轮没有合适的核心。所有 Amt 水平的子树(`day_sum(Amt)`、`ts_max(day_sum(Amt), 50)`、两层平滑)与已知族 |rho| >= 0.85,E 位要求核心对每个控制 |rho| < 0.8,过不了;Volume 版核心(`day_sum(Volume)`)虽过得了,但它读到的是名义股价,没有证据。所以本轮两个位都是 N,以后有 head 或共性子树再开 E。

**本轮的任务与事先预测:**
- **槽 1(N)近一个月放量尖峰、水平在表达式里去掉,16 个种子:** (i) 度量:峰值 / 上尾均值 / 75 分位 / 均值 / 指数均值 / 偏度;(ii) 去水平:对数差、除以 120 日均值或中位数、对自己 120 日历史的 cross_zscore、对 120 日对数均值的 cs_regres、流动性十分位 / 流通市值十分位 / 名义股价十分位内标准化;(iii) 方向条件:无条件、乘以日内收益的符号或大小。
  - 预测:**出 head(>= 0.5)的概率约 4%。** 最好分数大概率在 -0.6 到 0.0;我给「96 次评估里最好的一个两段都好于 head 1 的 -0.80」约 65%,给「好于 25 日窗口版的 -0.34」约 40%。去水平之后单调的水平成分没了,分数由尾部事件决定,换手也不是病(月度窗口)。
  - 最可能的最好:种子 3、6、8(峰值 z 分数 / 对基线回归 / 市值分桶后的峰值比);第二梯队 5、7、13。最可能的最差:16(`ts_skew`,60 日窗口的偏度估得太吵)、10(求和型的乘积,极值支配)、9。
  - 相关度表预测:与 3 个 head 的 |rho| 都 < 0.5,与已知族 / 流动性 / 市值控制 < 0.5(种子 7 在流动性十分位内标准化,可能与 head 1 接近 0.5 到 0.6;种子 2、1 的 50 日峰值对 120 日均值,与 head 1 约 0.3 到 0.5)。被表划掉 0 到 1 个;位通过。
  - 最可能的失败:放量与 20 日反转或波动控制同源(放量日常伴随大涨大跌),被尺子去掉。种子 9、10 用日内收益的符号 / 大小是为了看这块到底是方向还是纯放量。若 16 个种子的最好分数都比 -0.34 差,说明 head 1 在 25 日窗口上的 -0.34 就是水平的残余,峰值事件本身没有毛超额。
- **槽 2(N)成交额与价格变动的关系(量能不能推动价格),16 个种子:** (a) 投机性与对冲性成交:昨天的收益 × 昨天的相对成交额预测今天的收益(种子 1、2、12、16,窗口 120 日);(b) 没有被价格解释的成交:log 成交额对 log 日内波动的 60 日滚动回归残差的 10 到 30 日均值,乘以收益符号区分吸筹与派发,分桶(种子 5、6、7、8、13、14);(c) 价格冲击弹性与量价相关:斜率、相关、对数 Amihud 对 Amt 水平的截面残差(种子 3、4、9、10、11、15)。
  - 预测:**出 head 的概率约 3%。** 最好分数大概率在 -0.8 到 -0.1;我给「至少一个种子的两段都好于 -0.5」约 45%。
  - 最可能的最好:(b)(种子 5、13、14,没有被价格解释的成交,截距吸收了水平,与波动控制只有残差意义上的联系);(c) 的相关类(种子 3、11)方差大,我不押方向。最可能的最差:(a)(日度收益噪声大,120 日窗口里 120 个点,斜率估计的标准误与点估计同量级;种子 2 与 16 的斜率版比相关版更吵)。
  - 相关度表预测:这一位的种子读的是关系而不是水平,与 3 个 head 的 |rho| 预计 < 0.3;与波动控制 0.2 到 0.5(弹性与相关类偏高);被表划掉 0 个。位通过。
  - 最可能的失败:(1)日度收益噪声太大,所有关系类估计都被淹没,分数 -1 以下;(2)弹性 / 相关类只是波动控制或 20 日反转的另一种写法,尺子去掉之后没有剩下的;(3)毛超额为 0。如果 (b) 与 (c) 最好分数都在 -0.5 以下,下一轮不再押量价关系。

## 第 2 轮

**新材料:B101(`div(day_sum(in_topk_masked(Ret, Volume, 5)), day_sum(Volume))` 一族,24 条)。** 注意 `in_topk_masked(x, y, p)` 是「x 排名前 1/p 的分钟里取 y」:`in_topk_masked(Ret, Volume, 20)` = 收益最高 5% 的分钟里的成交量。快照里 3 个 B101 head(-1.88 / -2.14 / -2.35)全是「该量 ÷ 当天总量,再 20 日截面均值 / 标准差」。拆解:去掉分母后 -1.11 到 -1.28(分母是烂部件,必要性 -0.7 到 -1.2);Volume 换 Amt 基本不变;窗口 40 比 20 好 +0.17。R 生效一个(`cs_bucket_zscore(ts_max(ts_std(...)))`,-0.60,是第 1 轮的 R 替换)。

**信念更新:**
1. 第 1 轮两个 N 位全军覆没(最好 -0.02,Pr1a 是峰值比 / 回归的变体;Pr1b 的量价关系最好 -0.21,valid +0.50 / train -0.21 说明近期有一点东西)。R 对 head 1 去水平后 -0.59(train -0.49 / valid -0.59,rho_known -0.10),相对 -0.80 抬了 0.2,但没到 0。结论:去水平方向是对的(rho_known 全部降下来),但剩下的毛超额不够。成交额的单变量形态不再押。
2. B101 这条线的核心是「放量上冲」。它的所有 head 都带水平(Volume 含名义价格),并且单边。双边取差 / 相对自己基线是自然的下一步。

**本轮任务与事先预测:**
- **槽 1(E,核心 `day_sum(in_topk_masked(Ret, Volume, 20))`)**:外围换成双边差 / 对数差、60 到 120 日基线分母、z 分数、回归、分桶、与日收益的相关。预测:出 head(>= 0.5)概率约 3%;最好分数在 -0.8 到 -0.2,「好于 B101 的 -1.88」约 85%,「好于 -0.5」约 35%。最可能的最好:种子 3、4(对数差,天然无水平)、11(两个 z 分数差);最差:9、10(日收益的相关 / 回归,估计噪声大)。相关度表预测:与 B101 head |rho| 0.3 到 0.6(种子 5 单边 + 基线分母最像);与流动性控制 0.3 到 0.6;被划掉 0 到 2 个。风险:涨幅最大的分钟 = 波动大的分钟,被波动控制吃掉。
- **槽 2(N,重量分钟收益)**:`in_topk_masked(Volume, Ret, 5)` 的收益之和,减去轻量分钟的、除以波动、再平滑。预测:出 head 概率约 3%;最好分数 -0.9 到 -0.1。我不押方向(正反都有文献,Campbell-Grossman-Wang 的延续 vs 反转);最好的大概率是差分 + 20 日均值(种子 2、3)。风险:开盘 / 收盘集合竞价主导重量分钟,读到的是隔夜 / 尾盘行为;与 20 日反转同源。
- **R(12 个变体,3 个 head)**:对 B101 两个 head 去分母(基线分母、双边、z 分数)、对 head 1 去外层 ts_max。预测:B101 的两组至少一个比原 head(-2.14 / -2.35)好 0.1 以上的概率 ~90%(去分母已知好 +1),但分数仍为负,能 >= 0.5 的概率 < 2%;能「收录为新 head」需 rho_head < 0.5,且分数 >= 原 + 0.1,多半是替换。head 1 去 ts_max 的 4 个:变好 0.1 以上约 40%。

**上一轮预测对不对(第 1 轮):** 预测「出 head 概率 4% / 3%」:对(0 个)。预测槽 1 最好 -0.6 到 0.0:对(-0.02);槽 2 最好 -0.8 到 -0.1:对(-0.21),但最好的是相关类(种子 11 一族)而不是我押的残差类 (b),(b) 判错。R 对 head 1:预测至少 1 个好 0.1 以上且 rho_known < 0.5 概率 55%:对(-0.59 vs -0.80,rho_known -0.10),但没到收录线。预测最好 -0.6 到 -0.2:对。
