**读到的、影响判断的东西(只有 2025-12-31 以前的读数,没有碰 2026):**
1. **head 1 的拆解:** 阶跃 × 市值 `A = cs_first_low40(LogTotalCap, day_close(Low))` 单独 +0.02 / +0.56(train / valid),A 与分母 K = `day_kurt(Volume)` 缺一不可(拿掉 A:-4.89,K 单独:-4.93,`div(LogTotalCap, K)` 也是 -4.89);Low→High、Volume→Amt 几乎不变(+0.75 / +0.74)。方差分解(我的估算,不是读数):A 的方差里约 75% 是「价位档位」阶跃(0.24 对市值名次的 0.083),所以 A 基本是档位指示 + 弱市值名次。
2. **两个疑点,本轮都专门设了检验:** (a) 总领 PROGRESS.md 的疑点:阶跃把一组票整体抬到最前,尺子只扣控制排名的 1 / 2 / 3 次项,扣不掉档位阶跃 → 盲区。我另外读了别的流的 head:2029 的 `cs_last_low10(·, 成交额波动的波动)` 是「把成交额波动的波动最低的 10% 整体压到一端」,2013 的 `cs_mask_top_replace_mean_neg(day_sum(Volume))`,以及 1 / σ_Amt 的量纲斜率 —— 一个共同点:都是极端组(小盘 / 低流动性尾部)的倾斜。我的判断:这一波所有真 head 很可能都是尾部倾斜,尺子的多项式扣不掉组别尾部;所以本轮设计成「拆开看」,不是放大。(b) 数值疑点:K 是超额峰度(原始 - 3),可为负或接近 0,A / K 在这类票上翻号 / 爆点,sign -1 的多头书恰好取比值最低端 —— 这种票(成交摊得很平,例如一字板)在多头书里可能占比不高但分数可能由它们决定。R 组的 a(分母 K + 3)和 b(不做除法的 A - cs_rank(K))直接区分。
3. **B082 / B083 的现象与窗口杠杆:** 库里这一链读的是 day_mean(Ret)(盘中分钟收益均值,不含隔夜)的双层「相对当日市场的最大涨幅」,sign +1(近期相对涨幅最大的继续跑赢)。loc 的 R 候选:最外层 ts_max 30→60 = -0.19(train -0.19 / valid +0.09),比原 head 好 0.48;其他部件(去掉 pow_2、去掉内层 cs_demean、30→15)全是门槛废品;读 loc.json:head 2 自己的不同值比例只有 0.5016(闸门线 0.5),30→15 掉到 0.482 被挡,30→60 升到 0.528 —— 并列主要来自停牌 / 不动的票(整天无收益变动,cs_demean 后同值),窗口越长每只票越可能含一个非停牌日,所以长窗口还顺带把闸门问题解决了。所以「慢」是承重的 —— 沿窗口继续走是 R 组的事:GP 里换窗口的候选与库同骨架会被骨架禁令拒掉,R 不受这个限制。
4. **C04(coldstart_C04/direct_r1.md,旧尺子 A):** 日频字段的会计恒等式机制(净派现、除息回补、解禁回补、名义价格、连续信息)64 个变体 0 个 ≥ 0.5;最近的是 `neg(LogFloatShares)` +0.48(方向 -1 = 做多同市值下股数最多 = 名义价格最低)。所以本轮不再为股本结构单开 N 位(别的流 2014、2035、2038 在做)。
5. **别的流的经验:** 慢才承重(120 ~ 241 日窗口);分桶去均值边界跳变抬高换手(别的流 R 组里普遍变差 0.4 ~ 3),所以我只放 3 个分桶种子;E 位的初代有大量被「必须含核心」和骨架禁令拒掉的(2020 流第 1 轮 960 + 477 次),N 位只被拒 2 次;取值档位少的离散信号过不了「不同值 ≥ 50%」闸门;`cross_*` 在不满窗时是扩张窗口,数据首月所有票的耦合读数都是少量点估计。
6. **本轮的信念(仍然偏弱):** 我不知道 head 1 的 alpha 是 (i) 价位档位 × 小市值的组别倾斜(盲区),(ii) K 的符号翻转 / 近零爆点,还是 (iii) 真实的「同价位同伴里小市值 × 成交形状」交互。这三种在本轮各有一个检验:R 组 head 1 的 8 个变体(分母换原始峰度、不做除法、做慢、去阶跃、换 LogFloatCap、档位宽度、慢的原分母)分开 (ii) 与 (i)(iii);E 位 T(核心 `day_close(Low)`)的 16 个种子(阶跃 / 排除、连续乘积 / 残差 / 同伴内去均值、换掉市值)分开 (i) 与 (iii);E 位 K(核心 `day_kurt(Volume)`)的 16 个种子读 K 自己的时间序列行为(去水平、滞后耦合、同日共动、形状对形状),分开「K 本身有没有信息」。
