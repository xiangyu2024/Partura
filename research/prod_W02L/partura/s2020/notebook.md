**目前对本种子 alpha 来源的信念(很弱,几乎没有证据):**
1. `day_skew(Open)` 是路径形状的量:偏度对价格水平与尺度不变,读的是「一天里价格大部分时间在自己均值的上方还是下方」。它与已知族的 rho 全在 −0.03 ~ −0.02(拆解表),与控制天然正交;这是它唯一的优点,也是为什么值得试慢下来。
2. 它的毛超额在单日尺度上约为 0:两段都亏 3.1(−3.08 / −3.12),去掉 abs_ 只保留符号更差(−4.84 / −3.72),Open 换 Close 几乎不变(−2.87 / −3.25;同一条路径错一分钟)。这是推断(没有毛收益数):亏的是换手成本,不是反向的 alpha。所以单靠给核心套单调变换(abs_ / pow_2)没有用,快照里已经有 3 个同一信号。
3. 成交额口径的慢聚合(`ts_decay_linear(abs_(day_skew(Amt)), 20)`)原始是正的,但新尺子下没有进前三:说明成交额口径的慢信号被控制与两个冠军吃掉,价格口径是正交的却太快。这决定了本轮两个位的方向:E 位把价格路径形状变成慢的、个股层面的性质,并读它与别的日度量的 60 日滚动关系;N 位把形状从值轴挪到时间轴(价格运动的时点轮廓)。
4. 参考(不是证据):W01 的 head 里样本内最好的一类是「两个日度量的 60 日滚动关系」(cross_corr / cross_regbeta / cross_reg_fvalue)和成交额时点(day_centroid(Amt))的慢聚合 + 分桶。这两块在 W01 已被封,新的底(价格路径形状、价格运动时点)不被封。
5. 要避开的坑(来自读库):库里 `cross_mean(day_skew(F))`、`cross_stddev(day_skew(F))`、`ts_decay_linear(abs_(day_skew(F)))` 等原始算子的包法骨架全被禁;Partura 后加的 cross_ema / cross_zscore / cross_tail_mean / cs_bucket_zscore / day_centroid / day_gini 在 5583 个骨架里出现 0 次,所以这些算子是本轮的主要新处。`cross_shift` 与 `in_local_mean` 是前视算子,一个也没用;`cross_semistd_pos / neg` 只对正的 x 取对数收益,不能套在带符号的 day_skew 上,我没用。
6. 库里 `cross_corr(day_skew, ·)` 有 61 条(都是挖掘库的一串:搭档是价格 / 成交量的日均值、偏度及其乘积,10 日窗口),我的 E 位搭档(日收益、缺口、log 成交额、开盘第一根成交额、成交额重心、成交额偏度的残差)不在里面。

**目前对本种子 alpha 来源的信念(比第 1 轮强一点,仍然弱):**
1. 新尺子下分数几乎只由「换手 × 15 bp」决定;任何单日量 / 短窗口量都在 −1 ~ −3,出线的唯一方向是 120 ~ 241 日窗口的耦合 / 斜率 / 相关,且与水平无关(无量纲)。本流 241 日窗口的最好值 +0.10 / +0.38 离 0.5 还差 0.4,train 是短板。
2. 其他流出过 head 的机制里,与我的底最近的是「收益与成交的耦合」(2013:量价交互的 120 日回归斜率);另外两类(2029 的成交额多层波动的波动、2028 的规模 × 价格 / 峰度分桶)是水平族,与我的底无关;我的底是时点(重心 / 极值时钟)和方向(day_signed_ratio),它们与成交额水平不绑定,可以做同一种耦合,但不重复他们已封的写法。这是本轮两个位的共同押注:把耦合的两端换成本流的底。
3. 价格运动与成交在日内时钟上的同步(corr(P, A))是目前本流唯一在两段都不是负大数的对象,所以第一个位继续深挖它(更慢、斜率 / t 值、带方向、去开收盘、分桶);第二个位押「资金流的方向与时钟」(按时段拆开的净买入、价格冲击斜率、以成交时点为条件的 Llorente 式回归、极值时钟)。
4. 要避开的坑:day_argmax / day_argmin 在整天不动(一字板)时返回 0(并列取第一个),不是 NaN(第 1 轮审计员发现),所以时钟类种子的差(argmax − argmin)在这些票上是 0,不是爆点,只是中性;取值档位少的离散信号(cross_argmax / cross_argmin 距今天数)会被「不同值 ≥ 50%」闸门拒掉(流 2013 的发现),我没用。`cs_bucket_zscore(·, LogFloatCap)` 只能在有日度字段的真数据上跑(合成数据上报错),不是语法问题。
