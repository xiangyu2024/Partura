## 第 1 轮

**材料(只看到第 1 个结构批 B115):** 8 条挖掘库成员,全是 `ts_X(inv(ts_std(pow_05(day_autocorr_n1(F)), 10)), 10)` 一族(F = Close / Open / Ret);其中 2 条在冠军族 42 里(都是 Ret 链)。快照里 3 个 head 全是素材(-2.26 / -2.77 / -2.93,新尺子下 7 个已评分候选 0 个 > 0),21 次拆解评估。我读了 rules.md、loc.md / loc.json、`struct/members.csv` 与 `BATCHES.md` 里这批的库自带统计(只含 2018-01-02 ~ 2023-08-07)、同一波其他流(2009 / 2012 / 2028)的笔记与 PROGRESS.md 作校准、`ops_ext.py`、AlphaCube 的 `dt_day.py` / `nd_ts.py` / `common.py`。没有读、没有算任何 2026 年的数。

**读代码与定位表得到的事实(影响了设计):**
1. `pow_` 对指数 <= 1 是**保号开方**,不是 NaN 掩码,所以 `pow_05(x)` 对排名单调,sufficiency 里 `day_autocorr_n1(Close)` 与 head 同分(-2.2583)正是这个原因。我一开始以为 pow_05 会把负自相关日变成缺失,错了。
2. `day_autocorr` 的分母是 `sqrt(var_t * var_lag + 1e-8)`(`dt_day.py`),两个后果:(a) 价格全天不动(一字板)的日子 ρ 恰好 = 0,是整张表的最低值(正常日 Close 的 ρ 约 0.97 ~ 0.999);(b) Ret 的量级是 1e-3,低波动票的 ρ 被压缩。我用 AR(1) φ = 0.1 的合成序列量了(b):分钟波动 σ = 8e-4 时读数是真值的 0.84 倍,5e-4 时 0.52,3e-4 时 0.21,σ >= 1.3e-3 基本无影响。库里所有 `day_autocorr_n1(Ret)` 都带这个"低波动被压缩"的因子。
3. 库的骨架 = 抽掉字段、常数、窗口,所以 `cross_mean(day_autocorr_n1(F), d)`、`day_autocorr(Ret, 5)`(与 lag 1 同骨架)都会被 GP 拒绝;`cross_ema` / `ts_mean` / `cs_demean` / 乘常数去尺度的写法是新骨架。5583 条里 `in_pct`、`in_logchg`、`cross_ema`、`cross_zscore`、`cs_winsor`、`cross_tail_mean_*`、`day_flat_ratio` 都是 0 次;6 个日频叶子也是 0 次。
4. `nanstd_last` 在窗口只有 1 个有效点时返回 0,`inv` 之后是 inf:head 的 ts_std → inv 链在新股 / 长停牌时会出爆点(没有测,是读代码的判断)。
5. 本批的链 `ts_min(ts_min(inv(ts_std(·, 10)), 10), 10)` = 1 / (30 日内 10 日 ρ 标准差的最大值):读的是"ρ 的不稳定性"(跳跃 / 事件频率的代理)。拆解表:去掉 pow_05 好 0.94(-1.99,ρ_known -0.09,与原 head 的 ρ 0.83),ts_min 外窗 10 → 5 差 0.97、10 → 20 好 0.44,越慢越好;但 Ret 链已经有 2 条在冠军族 42,所以"链本身"在冠军里,尺子 B 吃掉的就是它。
6. 其他流的校准:整波里最好的 min(train, valid) 约 +0.07,没有一条 >= 0.1;好的几条都是 241 日窗口的慢统计,train 是被卡的一端;整波没有出过 >= 0.5。所以每个位出 head 的先验概率 <= 3%。

**目前对这个种子 alpha 来源的信念(很弱):**
1. 批里没有东西能在尺子 B 下直接活下来:Close / Open 的 ρ 是"走势效率"的日度读数,换手 0.76,是噪声;Ret 链被冠军族 42 吃掉。
2. 值得赌的有两个方向:(a) 把 ρ(Close) 当作个股的慢变常态(走势效率 ~ 机构拆单 / 算法对散户来回噪声的比例),并去掉一字板这个伪影;(b) 把"lag-1 自相关"推广到"多尺度方差比 / 跳跃占比 / 去尺度自相关",库里没有人读过。这两个都是"慢、无量纲"的东西,符合其他流学到的教训。
3. 如果两个位都只在 -1 ~ -0.5,结论是"批的现象在这把尺子上没有增量",不是"没读到结构"。

## 第 2 轮

**材料:** 本轮新增 B116(31 条挖掘库成员,`cross_sum(log(Amt), 3)` 加 `day_open / day_first / day_max / day_q75` 的日内汇总,Amt 叶子 87%)。快照 6 个 head 全是素材(score -1.07 ~ -2.21,没有一个 > 0)。第 1 轮 4 个任务(两个 M 批 + Ea + Nb)共评分 100 多个候选,0 过线,0 入 heads;R 3 个替换生效但不是新 head。Nb 最好 -0.50(`cross_corr(cross_decay_linear(day_at_max_ratio(High),10), abs_(abs_(day_distinct_ratio(High))), 60)`),train -0.32 / valid -0.50;Ea 最好 -1.48。读了 rules、loc.md、members.csv(grep 新算子在库里的出现次数)、ops_ext.py、dt_day / common 的 log / day_first 实现。没有读、没有算 2026 年的任何数。

**事实:** (1) `day_first` = 当天第一个非缺失分钟,`cross_sum` 是日轴上滚动 nansum(每个分钟位置跨 3 天加),`log` 对 |x|<=EPS 返回 NaN,所以开盘分钟无成交的日子不进和。(2) B116 的拆解:Amt -> Volume 变差(valid -2.33),窗口 3 -> 6 valid -0.74 -> -0.39,即承重的是金额而且越慢越好;`day_first` 与 `day_open` 同值。(3) 新增日内算子(day_centroid / day_gini / day_signed_ratio / day_wmean / day_wstd / day_topw_mean / day_es_ratio_hi / cs_bucket_* / cross_zscore / cross_ema)在两个库里的出现次数全是 0。

**对 alpha 来源的信念(仍然很弱):** 整个流目前最像"开盘金额的慢变读数 + 与流动性的差"。train 是被卡的一端的概率较大(valid 好于 train 的形状已在 B116 的 head 上出现)。对 Nb 的 -0.50 我读成:High 的日内价格水平数(`day_distinct_ratio`)的慢相关有一点东西,但不够。

**本轮任务与事先预测:**
- **E(核心 `day_first(cross_sum(log(Amt), 3))`,本核心第 1 个 E 位):** 15 个种子,外围三类:对自己(ema / zscore / 20 日差)、对当天(减均值 / q75 / 最后一分钟、cs_bucket_demean、ts_regres)、对价格(减 Volume 版)。预测:出 head 概率约 3%;最好 -0.8 ~ -0.2,最可能 -0.5;valid 比 train 好 0.3 ~ 0.6 的形状很可能延续;最好的预计是对当天去水平的三个(减均值 / cs_bucket_demean / ts_regres)或 20 日差;减 Volume 版(价位)预计与市值控制重合,分数 -1 左右。失败方式:(a) 去掉水平后只剩开盘分钟的噪声,所有种子 < -1;(b) 开盘分钟成交额的 3 日和本身有一部分是"集合竞价那一分钟的特殊撮合"伪影,去水平后消失。相关度表:种子与核心(它自己是 head)的 |ρ| 可能 0.5 ~ 0.8,被 0.7 线划掉 2 ~ 5 个,剩 10 个以上;对流动性控制 |ρ| 预计 0.2 ~ 0.6。
- **N(日内成交额的时点与方向):** 15 个种子。预测:出 head 概率约 3%;最好 -0.9 ~ -0.2,最可能 -0.6;押 day_centroid 的慢 ema / zscore(1 / 2 / 4 / 12)与 signed_ratio(5);day_es_ratio_hi(Amt)与 day_gini 可能被波动控制吃掉。失败方式:(a) 重心读数是上市年龄 / 板块代理;(b) 带符号占比是日收益的函数,被 20 日反转控制吃掉(最可能)。
- **R(10 个变体,2 组):** 组 1 把 head 1(`ts_regres(…,50)`)的窗口拉到 100 / 150 / 241(拆解表 100 已 -0.55,好 0.5):预测 150 / 241 再好 0.1 ~ 0.5,1 ~ 3 个比原 head 好 0.1 以上(替换概率大,与原 head 的 ρ 应 >= 0.5);组 2 把 `day_first(cross_sum(log(Amt),3))` 拉长窗口 / 加慢聚合:预测 10 / 20 日比 3 日好 0.1 左右,cross_ema 版与原 head 的 ρ >= 0.7(被库禁令当重复);出 >= 0.5 的概率 < 1%。

**上一轮预测对不对:** 第 1 轮预测 E 最好 -1.2 ~ -0.3(最可能 -0.7),实际最好 -1.48,比预测差,且"至少一个 > -0.5"没发生(预测 35%);N 预测最好 -1.0 ~ -0.2,实际 -0.50 在范围内,但出的是 High 价格水平数相关,不是我押的 VR / 跳跃占比(押错了对象,但量级对)。R:预测"越慢越好、全部好 0.1 以上",实际没有 R 变体成为新 head,R 3 个替换只是换壳,说明单纯拉慢对 Close / Ret 自相关没用;这次 R 只做有拆解表依据的窗口拉长。
