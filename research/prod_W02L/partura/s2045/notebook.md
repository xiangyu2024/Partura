**目前对本种子 alpha 来源的信念:**
1. **承重的是 C(二阶离散度),不是 X(水平)。** 拆解:C 单独 +0.47(train +0.47 / valid +1.26),q50 项单独 -3.15,X 本身 -4.19,只留 cross_stddev 一层 -0.03,Amt→Volume -2.02。q50 敲掉(留 X)得 +0.58,但这个变体没有进定位输出的 R 候选表,我推断是它对已知族的 |rho| 回到 0.5 以上(加回 X 把水平加回来了);也就是说 q50 项的作用是压低与已知族的相关,而不是贡献 alpha。
2. **机制(推断,没有读数核对):** X = Var_m(A_d) - Cov_m(A_d, A_{d-30}),是当日分钟成交额的日内方差减去与 30 日前同形状的协方差,对「成交被少数分钟垄断」的日子敏感;C = 对它的 60 日滚动 std 再取 50 日 std,读的是脉冲进出窗口造成的跳变,约等于「近 110 日有没有强度很大的成交分布突变」的衰减记忆。单位是 Amt^2,所以和一阶离散度(已知族)同向。
3. **方向:** 库里原样读数(`members.csv`)是 rank IC -0.032、原样净夏普 +2.17,即原样方向 -1(买成交分布稳定的票,这是已知族 / 流动性的暴露);新尺子下方向翻成 +1:在同一水平的一阶离散度下,**二阶离散度高的票更好**。这支持把 C 做成「相对一阶离散度」的读法。库里 B015 那条 `add(ts_quantile_q50(day_cov(Amt, Amt), 1), C0)`(C0 = 同样的二阶离散度但不带 ΔAmt)在新尺子下 0.62,但与已知族 |rho| 0.83,不算 head;本批 head 1 就是 ΔAmt 把相关压到 0.5 以下的版本。所以本流的主线是:二阶离散度 + 去掉一阶量级。
4. **valid(+1.26)好于 train(+0.47)** 是个好迹象,但 min(train, valid) 才是分数:瓶颈在 train 段(2018 到 2023-08),我不知道是哪几年拖后腿。
5. head 3 我不碰(价格侧,两段都亏,拆解里换字段 / 窗口都在 -1.1 左右),R 里也不放。
6. 这一批里别的流的发现对我的提示:2029 的 head 是成交额嵌套 std 的最低一档阶跃(尺子可能的盲区,它的 PI 也怀疑)。本流的 C 不靠阶跃,所以如果我的种子里出了 head,它更可能是「真的二阶离散度」;我没有在种子里放任何阶跃带(除了 cs_last_low20 一个流动性筛选,是排除而不是选取)。

**本轮的任务与事先预测:**
- **槽 1(E)核心 C,15 个种子:** (i) 相对量:C 除以一阶离散度的平方、除以自己一年的分钟成交额方差、除以不带 ΔAmt 的二阶离散度 C0;(ii) 非参数去量级:`cs_bucket_rank(C, ·)` 在已知族 / 流动性 / 市值 / 波动 / 20 日收益的十分位内取秩;(iii) `cs_regres(log C, log 一阶离散度 / log 流动性)`;(iv) 对自己历史:`cross_zscore(C, 60)`、C 除以 120 日前的 C;(v) 状态与筛选:乘 20 日收益秩、减一阶离散度的秩、排除流动性最低 20% 后按 C 排。
  - **预测:出 head(分数 ≥ 0.5、|rho_known| < 0.5、过库禁令)的概率约 35%。** 理由:核心自己是 +0.47,离 0.5 只差 0.03,种子是把 C 里与控制共享的量级换种办法拿掉,尺子本来就在拿;GP 的 96 次评估围着它的变异有 ±0.2 的波动,有机会跨过 0.5。最可能的最好分数在 +0.2 到 +0.6,train 段是瓶颈。
  - 最可能最好的种子:1(已知族十分位内的秩)、4(波动十分位内的秩)、6(除以一阶离散度的平方)、8(除以不带 ΔAmt 的 C0:把新旧部分分开);最可能最差:12(乘 20 日收益秩,和 20 日反转控制交互,分数可能掉到 -1)、13(排除最低 20% 只是 C 的微调,最接近 head 1)。
  - 相关度表预测:对 head 1 的日度秩 |rho| 最高的是种子 13(0.8 以上,可能被划)、种子 3(对市值分桶,0.7 左右,可能被划),其余 0.3 到 0.7;被表划掉 1 到 3 个,仍 ≥ 4 个,位通过。核心 C 与各控制的 |rho|:已知族和流动性我猜 0.6 到 0.75,有约 10% 的概率 ≥ 0.8(那样位被改成普通 GP)。
  - 最可能的失败方式:C 的 alpha 就在水平里(种子 1、4、6 这类彻底去掉量级的都 < 0,只有 13、15 这类保留量级的 > 0),说明新尺子的 +0.47 是量级的非线性残渣而不是二阶离散度。
- **槽 2(N)有界日内统计量的二阶离散度,12 个种子:** 同一个外壳 `ts_std(cross_stddev(·, 60), 50)`,底换成无量纲量:分钟成交额形状与滞后形状的相关(滞后 1 / 5 / 30 日)、与形状变化的相关(30 / 241)、先除以当日均值再做 head 1 的 day_cov、`day_kurt` / `day_gini` / `day_centroid`、成交额与 |Ret| / Ret 的日内相关,外加两条慢版。
  - **预测:出 head 的概率约 8%。** 理由:底是有界量,与 head 1 和控制的相关低,但 alpha 是否需要量级未知;一阶离散度类在这个尺子下一律没有分数,二阶的好处全部是推断。最好分数大概率在 -0.6 到 +0.2。
  - 最可能最好:种子 2 / 3(形状相关的稳定性)和种子 8(成交重心的稳定性);最可能最差:种子 9 / 10(量价耦合,与 20 日反转和波动控制相关),种子 6(`day_kurt` 被尖峰支配,外面套两层 std 也压不下去)。
  - 相关度表预测:所有种子对 head 的 |rho| < 0.4,对控制 < 0.6,被划掉 0 个,位通过(满足 3 轮至少 1 个 N 位通过)。
  - 最可能的失败方式:有界底的二阶离散度读到的是噪声 / 与成交额无关的东西,12 个种子都在 -1.5 到 -0.5。这个读数反过来是信息:它说明 head 1 的 alpha 需要 Amt^2 的量级。
- **R(13 个变体,head 1 与 head 2):** head 1:保留 q50 水平项(压相关)并把外壳放慢(外层 100;120 / 100),或去掉水平项只动外壳窗口 / 滞后(120 / 100、60 / 100、120 / 50、60 / 25;滞后 10 / 60 / 241);head 2:滞后 241 换 30、cross_stddev 241 换 120、head 1 的外壳套 head 2 的核心、cross_max 3 换 10。head 3 不放。
  - **预测:** 至少一个变体比其 head 好 0.1 以上且 |rho_known| < 0.5 的概率约 45%,几乎全来自 head 2 的 4 个变体(它的分数 -0.24 低,train 弱;换成 head 1 的短滞后 / 外壳最有可能抬 train);到 0.5(真正的新 head)的概率约 10%,来自 head 1 的外壳放慢。去掉水平项的变体有约 50% 的概率因与已知族 |rho| ≥ 0.5 被闸门挡掉(q50 项压相关的推断若成立)。
  - 信息量:head 1 的 6 个只动外壳的变体之间的差,告诉我外壳窗口(60 / 50)有没有调的空间;head 2 的变体与 head 1 的对比告诉我 train 段弱的原因是滞后(241 vs 30)还是 cross_max。

## 第 2 轮

**上一轮读数(第 1 轮):** E 位(核心 C)最好 +0.31,0 个 head;N 位(有界底的二阶外壳)0 个 head,最好 -1.11(只看到 loc 里 Pr1b 的前几名)。R:13 个变体里把 C 的外壳放慢的都有分数(带 q50 的 120/100 为 +0.91,train +0.91 / valid +1.45;纯 ts_std(S120,50) +0.80;ts_std(S120,100) +0.65),但与已知族的 rho 全在 -0.59 到 -0.78,没有一个能收录。滞后 241 版、cross_max 版 train 为负。

**预测对不对:** E 预测 35% 出 head:错(0 个,最好 0.31)——相对化(除以量级)没有把与已知族的共享部分干净拿掉,且并未保留 C 的 0.47。N 预测 8%:对,有界底没分数(这个读数的信息:alpha 需要 Amt^2 的信息)。R 预测『至少一个比 head 好 0.1 以上』:对(而且多个到 0.5 以上),『到 0.5 的新 head』约 10%:分数上对了,闸门(与已知族 |rho|)上错了——我低估了放慢外壳后与已知族的相关(0.62-0.78)。

**目前的信念:** 本种子的 alpha 在『S = cross_stddev(day_cov(Amt, cross_delta(Amt,30)), 60) 这一层的时间序列波动』,越慢越好(窗口 120 优于 60;valid 一贯好于 train),但它和已知族 cross_mean(day_std(Amt),30) 共享 Amt^2 量级(rho 0.6-0.78)。第 1 轮证明:有界底(丢掉 Amt^2 信息)没分数,C 外面除量级也没分数。第 2 轮的赌注:在 S 层,用时间序列上的尺度无关读法(log 外壳、变异系数、ts_max/ts_mean、ts_skew),保留 S 的相对涨落但丢掉绝对量级。

**本轮任务与事先预测:**
- 槽 1(E,核心 S,16 个种子:log 外壳 ts_std、变异系数、max/mean、log 路径长度、ts_skew / ts_kurt、cs_regres / 桶内秩对已知族):出 head 概率约 30%。理由:放慢外壳到 120 时分数已 +0.8,若 log 外壳能把与已知族的 rho 压到 0.5 以下并保留 0.5 以上的分数就是 head;风险是 log 外壳本质上还是『S 的波动』,rho 仍在 0.6 附近(这时它们会被库禁令 / 已知族闸门挡住,但仍可能有分数)。最可能最好:种子 1-3(ts_std(log S))、13/15(对已知族取残差);最可能最差:ts_skew / ts_kurt(S)(分布形状,无量级信息,同上一轮有界底)。
- 槽 2(N,S 与流动性水平的弹性 / 相关,12 个种子):出 head 概率约 10%。理由:ts_corr / ts_regbeta 是尺度无关的,与已知族 rho 低;但上一轮有界底全无分数,说明去量级可能连带去掉了信号。最可能最好:ts_regbeta(log S, log 水平, 120);最差:ts_corr(S, 20 日收益)。
- R(8 个变体,head 1 的放慢外壳 S120 上的去量级写法):至少一个比 head 1(+0.40)好 0.1 以上且与已知族 |rho| < 0.5 的概率约 30%;若发生,它与 head 1 的 rho 多半 ≥ 0.5(替换 head 1)。

**给下一轮的备忘:** 第 3 轮看到 B135 大概率几乎全是禁用算子(nt_cs_rank)。核心 C 的 E 名额已用 1,核心 S 本轮用 1。若 S 的 log 外壳有 head,第 3 轮的 E 位给它;N 位已在本轮提交,是否通过看审计。草稿在 r2/scratch/gen.py(生成 missions.yaml)。
