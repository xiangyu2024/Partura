
## 第 1 轮

信念:批 1 只有 3 个弱 head(score -2.7 ~ -2.9,全是日内「前 5 / 1 分钟绝对收益 与 成交量 / 额」的相关)。负分主要来自单日相关噪声大、换手高;延迟越长越好(5→10 +0.22)。alpha 来源假设为「波动先行、成交跟随」的信息传导速度。
任务与事先预测:
- E(核心 day_corr(abs_(in_delay(Ret,5)),Amt)):跨日平滑 / 分桶 / 去涨跌成分。预测:大概率仍产不出 ≥0.5 的 head(信号弱),最可能的好种子是 cross_mean 60 与 LogFloatCap 分桶版本,分数改善但不过线。
- N(量价领先-滞后不对称):预测小概率出 head,因为差分去掉了与控制重叠的部分,剩下的可能太弱;若出,会是平滑后的版本。
- R:延迟 15/20/30 与平滑变体;预测延迟变长继续改善但 gain≥0.1 且 |ρ|<0.5 对已知族不确定。
上一轮预测:无(第 1 轮)。

## 第 2 轮

信念:批 1/2 全是日内价量交叉相关 + 序列相关统计(DW、autocorr、q_stat)的弱 head(score -1.6 ~ -3.1)。第 1 轮证明:价量互相关(E 与 N)即使跨日平滑也只到 -0.6 ~ -1.5,过不了 0.5;跨日平滑确实有效(N 里 cross_mean 版最好 -0.59)。因此判断 alpha 来源不在价量交叉项,更可能在成交额自身的序列结构(DW / 自相关衰减),共性表里 DW(Amt/Volume) 富集 +1 且 p<=0.03。
本轮任务与事先预测:
- E(核心 day_durbin_watson(Amt)):偏离自身历史 / 与 DW(Volume) 之差 / 方向条件 / 市值分桶。预测:小概率出 head;最可能的好种子是 DW(Amt)-DW(Volume) 的 cross_mean 版和偏离 60 日均值版,分数改善到 -1 ~ -0.5 但大概率不过 0.5,因为 DW 与流动性控制有水平相关。
- N(成交额自相关衰减曲线,量的记忆减价的记忆):预测 30% 左右出 head;若出,会是 cross_mean/ema 平滑后的 15 分钟减 1 分钟自相关差,机制为隐蔽执行。
- R(q_stat 变体):High->Low 与长窗口叠加;预测至少一个 gain>=0.1(拆解已给 +0.57 / +0.37),但 score 仍远低于 0.5,不能成 head,只能记录改进。
上一轮预测对错:R1 预测 E「分数改善但不过线」对(最好 -1.42,0 过线);N「小概率出 head,若出是平滑版」对(最好 -0.59 平滑版,0 过线);R「延迟更长继续改善」错(15/20/30 全部比 5 更差,-2.79/-2.96/-3.44,拆解的 +0.22 不稳)。

## 第 3 轮

信念:本流 3 批全是价量交叉相关与序列相关统计(DW / autocorr / q_stat)的弱 head,没有一个过 0.5。唯一接近的是第 2 轮 cross_mean(DW(Amt)-DW(Volume),30),-0.29(valid +0.35);跨日平滑一贯有效,换核心无效。alpha 若存在,来源是成交额相对成交量的节奏(拆单连续性)的跨日稳定读数。
本轮任务与事先预测:
- E(核心 sub(DW(Amt),DW(Volume))):外围换成 ema / zscore / 动量差 / 信噪比 / 下尾 / 方向相乘 / 市值分桶。预测:约 35% 产出 ≥0.5 的 head(这是离阈值最近的核心);最可能是 ema 版或分桶版,因为 valid 已为正;失败的话是被库禁令(与 cross_mean 版 ρ≥0.7 的骨架)拒掉。
- N(上下半场 DW 之差 / 集中度 / 重心):预测 15% 出 head;半场 DW 单日噪声大,平滑后可能到 -0.5 附近;重心类与尾盘类控制有重叠。
- R(day_corr 价量两个 head 加跨日平滑):预测 gain>=0.1 几乎必然(-2.7 -> -1 左右),与原 head ρ>=0.5 所以是替换,不是新 head;不会过 0.5。
上一轮预测对错:R2 的 E「小概率出 head、最好是 DW 差的 cross_mean 版,-1~-0.5」基本对(最好 -0.29,更好一点,0 过线);N「30% 出 head」错(最好 -1.61,0 过线,自相关差 N 位远弱于预期);R「至少一个 gain>=0.1」对(60 窗 Low 版 +0.57 替换,但仍 -1.86)。
