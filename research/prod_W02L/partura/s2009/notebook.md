
# 种子 2009 笔记(PROD W02L,P 组)

## 第 1 轮

**材料(只看到第 1 个结构批 B025):** 14 个已评分候选,全是 `day_durbin_watson` 作用在 Volume / Vwap 上、外面套 `log(log(·))` 再做 ts_sum / cross_fangzheng。新尺子(去掉 5 个控制和两个冠军)下没有一条为正:最好的 3 个「素材 head」分数 −2.23 / −2.27 / −2.35,不是真 head。样本内 train 比 valid 好一点(−1.65 对 −2.23)。

**目前对这个种子 alpha 来源的信念(很弱):**
1. `day_durbin_watson` 不去均值,等于 2(1 − r1)(r1 为未中心化的一阶自相关),近似 2·CV²/(1+CV²):读的是当天分钟成交量「成团 / 不连续」的程度。Volume 换成 Amt 分数几乎不变(−2.25 / −2.25 / −2.31),Vwap 比 Volume 差(均值差 +0.93,p 0.04),窗口 5 / 10 / 20 差不多,所以承重的是核心 `log(log(day_durbin_watson(Volume)))` 的**水平**,不是平滑。
2. 这个水平和已知成交额离散度一族相关(核心 rho_known −0.52,加 ts_sum 后 −0.63 到 −0.73),是持久的个股属性(参与者构成、流动性),新尺子正是要把它吃掉。所以这一批里的东西多半就是已知族的亲戚,在 0.5 分的线上没有机会。
3. 单取一层 log 比两层 log 差 1.9 分(−4.21 对 −2.32)。取单调变换后的排名应该一样,唯一的差别是 `log(log(DW))` 在 DW ≤ 1 时是 NaN,所以这 1.9 分来自一个很窄的缺失模式(覆盖率 0.9995),不是来自更好的信号。我没法在本机验证它是什么状态(停牌 / 涨停封板 / 成交极度平滑的票?),只当作线索。
4. 我的信念:样本内能成为 head 的东西在这一批里不存在;值得赌的是两件事:(a) 去掉水平之后「相对自己常态的变化」;(b) DW 的底(原始分钟成交量)被日内 U 形污染,换一个干净的底可能读到不一样的东西。

**本轮的任务与事先预测:**
- **槽 1(E)核心 `log(log(day_durbin_watson(Volume)))`:** 外围全部是「去水平」:日轴 z 分数 / 稳健 z / 快慢 EMA 差 / 与当日收益的回归残差与滚动相关 / 与趋势方向的交互 / 市值与价格桶内去均值。预测:**多半不出 head**(概率约 5%)。预期最好的分数从 −2.3 上移到 −1.5 ~ −0.5 之间;种子里去水平的版本与三个 head 的 |rho| 会明显低于 0.7(不会被库禁令挡),与已知族 |rho| 预计 < 0.5。如果一个 head 都没有,这个 E 位的信息是「变化量也没有 alpha」,下一轮不再押这个核心。
- **槽 2(N)异常成交量路径(每分钟除以自己 20 日同分钟均量)的结构:** 粗糙度 DW、自相关(拆单的持续性)、带方向的版本(day_signed_ratio / day_wmean / 方向 × 持续性)、形状(skew / gini)、多尺度 DW 差 / 比、带符号 DW。预测:出 head 的概率约 10%,比 E 高,因为这是新的底、骨架全部不在库里、无量纲。最可能的失败方式:(a) 与手写库冠军里的「放量分钟」一族相关,被两个冠军控制吃掉;(b) 方向类种子被 20 日反转吃掉。最可能的成功形态:持续性 / 多尺度类(不带方向),因为方向类和反转太近。
- **R(13 个变体):** 以「与已知族共享水平」为烂部件:在已知族、市值、成交额的十分位内去均值,换掉被 U 形污染的底。预测:这些变体的 rho_known 会降到 0.5 以下(桶内去均值),但分数很可能只比原 head 好 0 ~ 0.3;满足「比原 head 好 0.1 且 |rho_known| < 0.5」的有 0 ~ 3 个,收录的可能性很小,更像是替换。

**上一轮预测对不对:** 第 1 轮,还没有。

**给下一轮的备忘:** 第 2 轮会看到 B026(`ts_max(day_durbin_watson(Close/High/Open), d)` 一族,DW 作用在价格上约等于已实现方差,多半是波动控制的亲戚),第 3 轮会看到 B027(`sigmoid(day_durbin_watson(Amt))` 与 cross_mean)。核心 `log(log(day_durbin_watson(Volume)))` 的 E 位这一轮用掉 1 个,至多再用 1 个。N 位这一轮要通过审计,这样 3 轮至少 1 个 N 的要求就满足了。

## 第 2 轮

**材料(第 1、2 个结构批 B025 + B026 与第 1 轮三个任务的结果):** 6 个 head 全是素材(−1.77 ~ −2.73):B026 的 `ts_max(day_durbin_watson(Close), 20/30/40)` 加上 B025 的三个 DW(Volume) 写法。140 个已评分候选里没有一条过线。

**本轮学到的(事实):**
1. 第 1 轮三个任务全没出 head,最好读数:E 位 −0.69(`cross_stddev(log(cross_mean(C0, 120)), 60)`,train −0.69 / valid −0.37;再套一层 stddev 为 −0.82,valid +0.34),N 位 **−0.025**(`cross_mean(cross_mean(day_wmean(Ret, div(Amt, cross_mean(Close, 20))), 20), 241)`,train −0.025 / valid +0.229,半衰期 0),−0.047(同外围、权重 `add(Amt, Amt)`),AV 权重的同外围 −0.38。R 的 13 个变体全部比原 head 更差(−2.0 ~ −5.2),0 个替换。
2. 第 1 轮 N 位的种子全是 `cross_mean(·, 20)`,GP 自己把它拉到 `cross_mean(·, 241)` 才得到 −0.03:**慢才是承重的**。拆解表里 `ts_max(DW(Close), d)` 的 d = 20 → 40 → 80 为 −2.73 → −1.77 → −0.92,30 → 60 为 −2.11 → −1.19,同样越慢越好(最可能是换手 / 成本在起作用,不是 alpha)。
3. R 的教训:`cs_bucket_demean(·, 已知族 / 市值 / 成交额)` 把 ρ_known 降到 −0.04,但分数 −2.6 ~ −5.2,比原 head 差 0.4 ~ 3:桶边界处的跳变增加了换手,尺子对成本很苛刻。我第 1 轮的预测(「桶内去均值只比原 head 好 0 ~ 0.3」)方向错了。
4. 算子事实(来自代码与旧研究文件,不是测的):`in_slice(x, a, b)` 右端点含在内;第 0 根是集合竞价,`Ret` 恒为 0(旧研究 C02 文件),所以 `day_wmean(Ret, ·)` 不含隔夜跳空;`day_wmean` 权重取绝对值;`cross_mean` / `cross_ema` 对缺失日取可用日;库里 `day_wmean`、`day_signed_ratio`、`day_topw_mean`、`cross_ema` 出现 0 次,最近的是 B074(前 20 / 50 分钟的成交量加权收益,20 日窗口)。

**目前对这个种子 alpha 来源的信念:**
- DW 的水平(Volume 与 Close 两个底)没有 alpha:价格底的 DW ≈ 每分钟已实现方差,Volume 底与已知族共享水平。唯一有一点生命的是「DW 慢均值的变化」(−0.69),我把它理解为参与者构成的体制切换,但没有被验证。
- 本种子里唯一接近 0 的是「慢的、按成交额加权的分钟收益」一族(−0.03,valid 为正)。我现在的最佳解释有三个,按先后顺序:(1) 慢趋势(一年的日内漂移),与 1 年动量有重叠,尺子只去 20 日反转;(2) 开收盘那几根的权重大(原始 Amt 权重 −0.03,AV 权重 −0.38),读数可能来自开盘 / 尾盘集合竞价附近的价格动作;(3) 放量时价格的动作(加权减等权),即信息性 vs 对冲性成交的类型偏向。第 2 轮的 N 位就是把这三个拆开。
- 判断:这个种子最终出 head(分数 ≥ 0.5、ρ_known < 0.5)的可能性很低(几个百分点),价值在于把「慢的钱加权收益」这条线弄清楚,并把 R 的长窗口结果变成第 3 轮更好的 E 核心。

**本轮的任务与事先预测:**
- **槽 1(E)核心 `day_wmean(Ret, div(Amt, cross_mean(Amt, 20)))`(AV 加权收益):** 外围不再只是 cross_mean,换成 cross_ema、减等权 / 减原始权重、241 减 21 跳月、漂移质量、正日占比、上下 25% 分位之差、排名均值、与日收益的 120 日相关、日度信噪比。预测:出 head 的概率约 2%;最好分数在 −0.4 ~ 0 之间;种子 1 / 3(减等权、减原始权重,只留 AV 倾斜部分)大概率比纯 W 的 −0.38 好,如果它们反而更差,说明 AV 倾斜部分才是噪声、第 1 轮的 +1.32 富集只是 DW 一族太差造成的对比;`cross_ema` 与「241 减 21」的种子 ρ 对 20 日反转应该降到 0.3 以下。最可能的失败方式:W 本身是 1 年趋势的代理,被尺子里没有的 1 年动量以外的东西(冠军)吃掉,或者 valid 好 train 差(第 1 轮就是这个形状,train 限制分数)。
- **槽 2(N)慢的钱加权收益 / 资金流 / 时段拆解:** 16 个种子分五类(钱加权本身 / 一年趋势 / 谁在买 / 哪个时段 / 先后顺序)。预测:出 head 的概率约 5%;最好读数 −0.3 ~ +0.2;最可能最好的是(d)时段类里的尾盘 30 分钟或「下午减上午」(如果上一轮 −0.03 的承重部分是尾盘权重),其次是(a)的「加权减等权」。若是(b)趋势类最好,说明就是 1 年动量代理,没有新信息。资金流类(day_signed_ratio)我预计与 20 日反转 / 流动性的 ρ 偏高、分数偏低。预计被相关度表划掉的种子很少(种子对 head 的 |ρ| 应该都很低,对控制 < 0.5)。
- **R(11 个变体):** 组 1(`ts_max(DW(Close), 40)` 的 80 ~ 241 日窗口,Close / Vwap):预测 100 ~ 160 日窗口仍比 80 日好 0.2 ~ 0.6,在 160 ~ 241 之间走平或下降,最好 −0.7 ~ −0.1,0 个 ≥ 0.5;比原 head(−1.77)好 0.1 以上的至少 5 个,是否满足 ρ_known < 0.5 我不知道(DW(Close) 是价格方差,与成交额离散度一族的关系未测),估计一半会满足。组 2(DW(Volume) 慢均值的变化):预期 3 个里有 2 个满足 ρ_known < 0.5,分数 −0.7 ~ −0.4,比原 head −2.23 好得多,多半是「替换」。

**上一轮预测对不对:**
- E 位:预测「多半不出 head(≈5%),最好分数从 −2.3 上移到 −1.5 ~ −0.5」:对,出 0 个,最好 −0.69,在区间里。「去水平版本与 head 的 |ρ| 明显低于 0.7」:对(0.07 ~ 0.65)。
- N 位:预测「出 head 概率约 10%,最可能成功的是持续性 / 多尺度类(不带方向)」:head 0 个,最接近的是带方向的 day_wmean 一族(−0.03),与我预测的「方向类被反转吃掉」相反——在 20 日窗口下确实被反转吃掉(ρ_rev 0.58),在 241 日窗口下分数没有被吃掉(但没量过它对反转的 ρ)。DW(AV) / autocorr(AV) 的审计预言被数据否定在先(与流动性 0.88 ~ 0.90),所以不出结果并不意外。
- R:预测「满足条件的 0 ~ 3 个」:0 个,而且方向全错(都更差)。

**给下一轮的备忘:** 第 3 轮看 B027(`sigmoid(day_durbin_watson(Amt))` 与 cross_mean),`log(log(DW(Volume)))` 的 E 位已用 1 个(最多再用 1 个);W 核心本轮用 1 个(最多再用 1 个)。N 位第 1 轮已通过审计,3 轮至少 1 个 N 的要求已满足(以审计结果为准)。第 3 轮的方向由本轮结果定:(1) 若钱加权的慢聚合(N 位或 E 位)有分数 ≥ −0.1 的候选,第 3 轮对它再做深挖(核心要用共性表 / head 里存在的子树);(2) 若 R 组 1 的长窗口把 DW(Close) 的 ts_max 推到 −0.3 以上,第 3 轮对它做 E(核心 `day_durbin_watson(Close)` 或替换后的 head);(3) 如果两边都 < −0.5,就承认这个种子没有 head,把余下预算花在最有信息量的拆解上。

## 第 3 轮

**材料(第 1、2、3 个结构批 B025 + B026 + B027,加本流前两轮六个任务的结果):** 9 个 head 全是素材,没有真 head:最好的是 R 替换进来的 `ts_max(day_durbin_watson(Close), 80)`(−0.92,train −0.45 / valid −0.92),M3 新增的三个是 −3.21 / −3.27 / −3.49(`sigmoid(day_durbin_watson(Amt / Low / Ret))` 外面套一堆 sigmoid / pow_2 / 3 日或 241 日均值)。231 个已评分候选 0 个过线。B027 拆解表:sigmoid / pow_2 层的 knockout 都在 ±0.25 以内,窗口 3 → 2 / 6 也不动,说明那几个 head 里的结构不承重,剩下的只是 DW 的水平。

**本轮学到的(事实):**
1. 第 2 轮 E 位(AV 加权收益核心)最好 −0.335(`cross_mean(sub(W_AV, day_mean(Ret)), 241)`,train −0.335 / valid −0.193);N 位(Amt 加权减等权)最好 **+0.066**(`cross_mean(sub(day_wmean(Ret, Amt), day_mean(Ret)), 241)`,train +0.066 / valid +0.399,hl 5)。这是本流迄今最好的读数,也是共性表里均值差最大的核心(`sub(day_wmean(Ret, Amt), day_mean(Ret))` 15 个候选均分 −0.98 对 −2.42)。该位另外 67 个已评分候选(其余种子与 GP 后代)没有一个更好:套 10 日 / 5 日的 cross_mean 只是同一水平(+0.056 / −0.036,valid 到 +0.589)。
2. **train 是被卡的一端,valid 常常很好:** 好的几条 valid 都在 +0.2 ~ +0.65,train 都在 −0.6 ~ +0.07。还有两条符号翻转型:`cross_mean(sub(W_AV, W_Amt), 241)` 方向 −1,train −0.60 / valid +0.62;`cross_mean(day_corr(div(Volume, cross_mean(Amt, 20)), Amt), 241)` 方向 −1,train −0.48 / valid +0.65。我没法在本机验证 train 为什么差(2018 ~ 2020 年体制?暴露混杂?),本轮 E 位的桶内去均值种子就是为了分开这两种解释。
3. **R 组 2 的教训修正:** 第 2 轮 R 组 2 里「去掉外层 log」的变体(`cross_stddev(cross_mean(C0, 120), 60)`)方向翻成 −1 且崩到 −3.41,而保留外层 log|·| 的两个变体是 −0.69 / −0.82。也就是说 DW(Volume) 一族「慢均值的变化」这条线(−0.69)很可能有一部分是 log|·| 在 120 日均值过零处的折叠造成的(审计员当时指出过),不是信号。我第 2 轮把它当成「唯一有一点生命的 DW 线」,现在降级。
4. **算子事实(从源码读的,没测):** `day_durbin_watson` = Σ(Δx)² / (Σx² + 1e-8),作用在价格水平(Close / Low)上 ≈ 每分钟收益平方的均值,量级 1e-6 ~ 1e-5;`sigmoid(x) ≈ 0.5 + x / 4`,float32 在 0.5 附近刻度约 6e-8,所以 `sigmoid(day_durbin_watson(Low))` 只剩几十档、多数并列。这是 B027 拆解表里「去掉 sigmoid(DW(Low)) 增益 +1.44」的最可能原因,不是信号。作用在 DW(Amt)(量级 1 ~ 3)上的 sigmoid 不会被量化。`div` 是裸 torch.divide,没有 EPS:所有比值种子的分母都要自己加下限。
5. 库里隔夜缺口(day_first(Open) / 上一日收盘)只在 B091 出现 3 条,都是 20 日窗口、`cross_delay` 写法;日内收益的 20 日均值在 B225,其 241 日版骨架在库里(`cross_mean(sub(div(day_last(Close), day_first(Open)), 1), 241)` 会被 GP 拒绝),所以 N 位里不放。
6. 共享的草稿目录(scratchpad)里别的 PI 也在写同名文件,我第一次的 skelcheck.py 被覆盖过,之后全放在 `scratchpad/pi2009_r3/` 子目录。

**目前对这个种子 alpha 来源的信念:**
- DW 一族(Volume / Close / Amt / Low / Ret 五个底)没有 alpha:水平量,与已知族 / 流动性 / 波动共线,慢聚合只是在省成本;唯一的「变化」线又有折叠嫌疑。这一族本轮只在 R 里各放一组收尾性的消融(不是押注)。
- 唯一有一点生命的是「慢的、按成交额加权的分钟收益减等权」(`C`)的 241 日均值:+0.07 / +0.40。我的解释顺序:(1) 它读的是放量时价格的方向(参与者类型的慢变偏向),(2) 它对波动有 0.39 的相关,可能是风格暴露在 valid 里碰巧好,(3) 它的 train 弱是体制问题。本轮 E 位用桶内去均值(日度输入上做,再 241 日均值)分开 (1) / (2)。
- 隔夜这一半从没测过:N 位押「隔夜 − 日内 / 缺口回补 / 方差拆分」,机制是散户注意力与机构集合竞价的拉锯,慢变的投资者结构属性。我对它的信心很低(出 head 约 3%),但它是这个种子唯一还没试过的、和已有失败都不同的方向。
- 判断:这个种子最终出 head(≥ 0.5 且 ρ_known < 0.5)的可能性还是几个百分点;价值是把 C 的读数拆清楚、把隔夜这半边测掉。

**本轮的任务与事先预测:**
- **槽 1(E)核心 `sub(day_wmean(Ret, Amt), day_mean(Ret))`(C)**,16 个种子分四类:桶内去均值后再 241 日平均(市值 / 波动 / 流动性 / 已知族 / 市值 + 已知族两次 / 桶内 z 分数 / 桶内百分位)、尺度与极端日(稳健 z、1% / 99% 截尾、除以当天分钟收益标准差得无量纲、秩的 482 日均值)、记忆(近 20 日对自己 241 日的 z 分数、半衰期 240 EMA、线性衰减 241、482 日 ts_mean)、市场状态(与全市场日内收益的 241 日协方差 / 相关)。
  - 出 head(≥ 0.5)的概率约 3%;至少一个种子或后代 min(train, valid) > +0.2 的概率约 20%。
  - 最好分数在 −0.2 ~ +0.2。
  - 桶内去均值的种子:相关度表里对波动的 |ρ| 应从 0.39 掉到 0.15 以下;分数我预测相对 +0.07 略差(−0.1 ~ −0.3),因为桶内相对强弱也丢掉了桶间可能真实的部分;如果其中有 train > +0.2,就说明 C 的 train 弱来自控制的暴露,方向是对的。

  - 慢聚合(482 日、EMA 240、线性衰减):train 比 +0.07 高 0 ~ 0.15,valid 比 +0.40 低 0.1 ~ 0.3,最后 min 变化不大。
  - 市场状态协方差 / 相关:不确定,我预计对波动的 ρ 在 0.2 ~ 0.3,分数 −1 ~ 0,最好的概率只有 10%。
  - 最可能的失败方式:所有变换都落在 −0.3 ~ +0.1,说明 C 的慢读数就是 +0.07 这个量级,没有处理能抬到 0.5。
- **槽 2(N)隔夜 / 日内:** 16 个种子五类(慢的水平 / 一致性 / 缺口回补系数 / 方差拆分 / 涨跌停幅度标尺)。
