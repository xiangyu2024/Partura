# 种子 2008 笔记(PROD W02L,P 组)

## 第 1 轮

**材料(第 1 个结构批 B022,19 条库因子,18 条有分数):** 全是 `day_durbin_watson`(DW)作用在 Vwap(14 条)/ Volume(4 条)上,外面是 `log` / `ts_sum 10` / 一到三层 `cross_fangzheng`(= 滚动 mean + std)/ `ts_std`。
原始尺子下它们的净夏普 1.2 ~ 1.6(rank IC ≈ −0.05,换手 0.02 ~ 0.09);新尺子(去掉 5 个控制和两个冠军的 1 / 2 / 3 次秩)下一个正分都没有。3 个「素材 head」是批内最好的三条:−1.35(train −1.35 / valid −1.19)、−2.50、−2.59,不是真 head。

**目前对这个种子 alpha 来源的信念(很弱):**
1. 未去均值的 DW = Σ(ΔVwap)² / ΣVwap²,等于当天分钟 VWAP 路径的相对已实现方差(价格尺度约掉),再加上 tick 量化和买卖价弹跳的噪声底(噪声底 ∝ (tick / 名义价格)²)。所以这一批的「水平」就是波动加一点噪声,被波动控制和两个冠军吃光是预料之中;批内中位 −3.2 ~ −3.4 也印证。
2. 拆解里唯一一致的信号是:**读它的离散度 / 拉长窗口比读水平好**。head3 拆掉内层 cross_fangzheng(mean + std)后 −2.59 → −1.69(+0.91),剩下 `ts_std(log DW, 40)`;head1 窗口拉到 241 是批内最好(−1.35),120 / 482 都差 0.6 ~ 0.7;窗口 20 / 80 的 train / valid 互相翻转,说明短窗口读的是噪声。批内得分高低主要由「多慢」(换手 / 成本)决定,不是由「读到了什么」决定。
3. Vwap→Close 互换对 head1 几乎无影响(−1.35 → −1.48),对 head3 变差(−2.59 → −3.40);含 Volume 版 DW 的候选均值比含 Vwap 版低 0.5(p 0.92,不显著)。价格路径本身有信息,但我分不开它是波动还是 tick 噪声。
4. 注意一个数值面的疑点(没法本机验证):DW 里的「是否常数」判据用 `E[x²] − E[x]²`(float32),后复权价水平很大时,低波动的名票可能被误判成常数而返回 NaN;这是核心就有的性质,覆盖率在评估里没被门槛挡掉,当线索记下来,不当结论。
5. 两个库一个日频叶子都没用过(LogFloatCap 只是控制,不在任何表达式里);而 W01 的结论是:新尺子的多项式只扣加性的 1 ~ 3 次秩,**交互项、门槛 / 同伴内相对量、两条路径的差**不在扣除范围(W01 大分的 head 多是 `cs_first_low20(·, LogFloatCap)`、`cs_last_low20(·, ListAge)`、`cross_corr(day_centroid(Amt), 隔夜跳空, 60)` 一类)。所以我押的不是水平,而是形状 / 协动 / 同伴内相对 / 噪声占比。
6. 整波禁令的后果:任何 `cs_last_low20(·, ListAge)`(排除最新 20%)的表达式与 W01 同类 head 的截面秩相关会因共享排除集高达 0.8 以上,GP 会拒绝;所以我只用 `cs_last_low10` / `cs_first_low20` 这类共享集合较小、与 W01 head 相关预计 0.5 ~ 0.65 的写法,且只放 3 ~ 4 个种子。

**本轮的任务与事先预测:**
- **槽 1(E)核心 `day_durbin_watson(Vwap)`:读这条状态变量的时间序列形状与协动,不读水平。** 种子 16 个:偏度 / 峰度 / 半方差不对称、自相关(持续性)、快慢 EMA 差、相对变异(std ÷ mean)、Hurst、与 log 成交额 / 日内收益 / |隔夜跳空| 的相关与 F 值、同市值同伴内去均值与 z 分数、小市值尾部与排除最新上市 10% 的两个变体。
  - 选最小的核心(单日 DW)是因为:它与波动控制的 |ρ| 应该最低(单日噪声大,核心 ρ < 0.8 的概率高),且让外围可以接 cross_semistd / cross_corr 这类要求正值或第二个日频序列的算子(带 log 的核心做不了半标准差)。
  - **预测:多半不出 head(概率约 5%)。** 最可能的情形是最好分数落在 −1.5 ~ −0.3,train 比 valid 好;「形状」类(偏度、自相关、不对称)与三个素材 head 的 |ρ| < 0.5,不会被库禁令挡;与成交额 / 跳空的协动类(W01 里这类是最强的族)最可能给出正分,但这时的分数很可能来自成交额 / 跳空那一半,不是 DW。同伴内去均值类最可能被「已知族 / 市值」类控制的残留吃掉。若全部落在 −1 以下,信息是「DW 的形状 / 协动也没有 alpha」,下一轮不再押这个核心。
- **槽 2(N)微观结构噪声底(弹跳强度 + 名义股价):** 种子 16 个:DW(Close) 对 DW(Vwap) 的 log 差(60 / 241 / EMA 40;换成 Open;比值版)、5 分钟对 1 分钟变化的方差比、名义价格 `LogFloatCap − LogFloatShares` 的直接读法、对价格回归 / 分桶去掉的超额粗糙度、粗糙度对价格的时间序列相关 / 回归斜率、弹跳强度在最低价 10% 之外 / 小市值尾部 / 市值桶内的版本。
  - **预测:出 head 的概率约 8%,高于 E,理由是它的底(两条价格路径的差、名义价格)是库里没有的,日频叶子是库的盲区。** 最可能成功的形态是名义价格相关的几条(直接价格、排除最低价 10% 的弹跳强度),因为它们换手低且与流动性 / 波动的交互项不在控制里;最可能的失败方式是 (a) 被流动性控制吃掉(弹跳强度本质是有效价差,可能与流动性秩相关 0.5 ~ 0.7,但应 < 0.8 不致被划掉);(b) 名义价格与 LogFloatCap 的秩相关高到把残差压成噪声;(c) 与别的流已出的日频叶子 head 撞上整波禁令。
  - 任一条若有正分,我预期半衰期取 20(慢变量),train 与 valid 同号但 valid 更差(2024 年初微盘行情的切换)。
- **R(13 个变体,三组):** 目的是便宜地分开「水平 / 离散度 / 窗口」三个因素,给第 2、3 轮定位用。head3:拆内层 fangzheng 并拉长窗口 40 / 120 / 241、EMA 平滑替代、以及 loc 已评分的两个邻居(窗口 20 / 80);head1:把 241 日窗口里的 mean 与 std 分开评分;head2:去掉被禁的 nt_ 分母和 ts_sum,拉长 Hurst 窗口。
  - **预测:** head3 组里 3 ~ 5 个变体 ≥ 原 head + 0.1(原 head −2.59 的门槛很低),被收为「替换」;没有一个会到 0.5(最好的约 −1.0 ~ −1.7);head1 组里 std-only 版会比 mean-only 版好 0.5 以上(离散度承重,水平被控制吃掉),这是本组最有信息量的读数,若相反则我对「离散度承重」的信念作废。收录(与原 head ρ < 0.5)的可能性很小,几乎都是替换。

**上一轮预测对不对:** 第 1 轮,还没有。

**给下一轮的备忘:** 第 2 轮会看到 B023(`cross_fangzheng(day_durbin_watson(F))` 一族,窗口 30 的 Vwap 版是最强成员),第 3 轮会看到 B024(`sigmoid(pow_2(day_durbin_watson(F)))`、`ts_var(pow_2(DW(Ret)),10)`,偏 Ret 的 DW)。
本轮 E 位用掉核心 `day_durbin_watson(Vwap)` 一次,最多再用一次;N 位本轮要通过审计,这样 3 轮至少 1 个 N 的要求就满足了。第 2 轮的决策规则:若 R 里 std-only 明显优于 mean-only,E 位改押「离散度」类核心(`cross_stddev(log(day_durbin_watson(Vwap)), 120)` 或其子树)的外围;若 N 位出了名义价格相关的正分,第 2 轮的 E 位核心改成那个子树深挖。

## 第 2 轮

**材料(第 1..2 个结构批 + 本流第 1 轮产出):** B022(19 条,DW(Vwap / Volume) 的水平外壳)、B023(17 条,全是 `cross_fangzheng(day_durbin_watson(F))` 一族,窗口 3 / 10 / 30 / 60 / 241 的 Vwap 版最强;原始尺子下净夏普 0.6 ~ 1.9、|秩 IC| 0.02 ~ 0.06,新尺子下全部是负分)。快照 4 个任务 + 2 个已生效的 R 替换,6 个 head 全是负的(-0.09 ~ -2.50),119 个已评分候选。整波目前的最好分是 +0.07(2009 流,`cross_mean(sub(day_wmean(Ret, Amt), day_mean(Ret)), 241)`),所以「本流最好 -0.06」不是落后,是在整波的最前面一档。

**第 1 轮的结果与我的预测对照:**
- E(核心 DW(Vwap),预测:出 head 5%;最好 -1.5 ~ -0.3;同伴内去均值类最可能被已知族 / 市值吃掉):**部分对。** 没出 head(对);最好 -0.06(比我预测的好);**同伴内标准化恰好是最好的写法**(cs_bucket_zscore(cross_stddev(log DW, 120), LogFloatCap) -0.73,两层嵌套 -0.06,train -0.06 / valid +0.04),所以「同伴内去均值会被吃掉」是错的;协动 / 成交额类没有进前 5。
- N(名义价格 / 弹跳噪声底,预测:出 head 8%,价格相关最可能成功,valid 比 train 差):**部分对。** 没出 head(对);最好 -0.67;共性表里含 `sub(LogFloatCap, LogFloatShares)` 的 20 个候选均值 -1.44 对 -2.25(p 0.000)说明价格这条路确实比没有好,但它本身没正分(最好的价格写法 `price - log DW` -0.78);valid 并没有更差(train -0.78 / valid -0.68)。
- R(预测:head3 组 3 ~ 5 个变体成替换;std-only 比 mean-only 好 0.5 以上):**对。** 3 个变体成替换;`cross_stddev(ts_sum(log DW, 10), 241)` -0.09 对 `cross_mean(...)` -2.61,差 2.5。预测「最好 -1.0 ~ -1.7」偏悲观:head1 从 -1.35 被替换成 -0.09。

**目前对这个种子 alpha 来源的信念(仍然弱,但比第 1 轮具体):**
1. 承重的是 **RV 序列的离散度(vol-of-vol)**,不是水平、不是价格路径(Close 换 Vwap 无损 -0.00)。证据:只留 std -0.09、只留 mean -2.61;ts_sum 10 拆掉掉 0.85;窗口 120 / 482 都变差(241 是峰);共性表 `cross_stddev(log DW, 120)` +0.64(p 0.051)。它对五个控制的 |ρ| 只有 0.04 ~ 0.34。
2. 它在 train / valid 都接近 0,我的解释是被「混进来的成分」稀释:价格档位 / 板块 / 上市批次的刻度差、全市场共同的波动起伏、成交量自己的突发、最近一个月的突发。第 1 轮唯一有用的外围(同市值分位内标准化)就是在扣第一类,所以这轮 E 位把这四类一个一个扣。
3. 整波的最好分都是 241 日量级的慢变量(2009 流、本流),换手承重;所以本轮种子窗口都在 120 ~ 241 日。
4. 日频叶子仍是库的盲区(0 / 5583),交互项 / 同伴内相对量 / 联动不在尺子的扣除范围,但「阶跃带」(2028 的 cs_first_low40 head)更像尺子的盲区而不是新信号,我不押那一类。
5. 一个我没法验证的数值疑点还在:近常数日(涨跌停锁死)的 log DW 很负,可能主导 std 的左尾;本轮 R 组用稳健离散度(IQR)直接检验它。

**本轮的任务与事先预测:**
- **槽 1(E)核心 `cross_stddev(log(day_durbin_watson(Vwap)), 120)`(vol-of-vol):15 个种子,四族:** (A) 同伴内标准化,同伴换成名义价格 / 流通比例 / 板块 / 基线 RV / 成交额 / 过去 120 日涨幅;(B) 回归扣除,扣 RV 基线、成交量突发、Close 路径突发、近 20 日突发、DW 下半偏差;(C) 市场状态翻转(波动状态、成交活跃状态);(D) 二阶 / 平滑。全部乘上市 > 120 日掩码。
  - **预测:出 head(≥ 0.5)的概率约 4%;出正分(min(train, valid) > 0)约 30%。** 最好的在 -0.4 ~ +0.1,最可能来自 (A) 里价格档位和基线 RV 同伴(种子 1、4)、(D) 两条、(B) 的成交量突发扣除(种子 6);train 与 valid 同号但很小。(C) 方差最大:要么是最好的(符号确实随状态变),要么是最差的 -2 ~ -4(状态是 241 日中位数二分,约一半的天数各占,符号翻错一半就是反向),我押后者。LimitWidth 分组(种子 3)是未知数。
  - 失败方式:全部在 -0.1 ~ -0.7 的一条线上(信息:扣掉混入成分之后 vol-of-vol 也没有 alpha,第 3 轮不再押这个核心);或 (B) 里的回归扣除被相关度表自动划掉(与某个 head |ρ| ≥ 0.7;我预计 0 ~ 2 个)。
- **槽 2(N)相对市场的 RV 结构:16 个种子。** 同步性 ts_corr(L, cs_mean(L), 241 / 120 日;中位数版)、同伴内版本、状态依赖(市场 RV 高 / 低日子里的相对 RV)、与市场收益的联动、相对自己历史再减市场、特质 RV 冲击、同样读法换到 Close 路径 / std(Ret) / 成交额上做对照、AHXZ 字面的 beta 1 条。全部乘上市 > 241 日掩码。
  - **预测:出 head 的概率约 3%;最好 -1.2 ~ -0.4。** 同步性类(种子 1 ~ 5、12 ~ 14)我预计与市值 / 流动性的 |ρ| 在 0.3 ~ 0.6(指数成分 / 大票同步性高),是风格代理,分数 -1.5 ~ -3;真正的赌注是状态依赖(种子 6)、相对自己历史再减市场(种子 9)、特质 RV 冲击(种子 10、11)和与市场收益的联动(种子 7、8)。种子 16(AHXZ 字面 beta)= 相关 × 总 std,我预计与 head1 的 |ρ| 在 0.5 ~ 0.75,可能被划掉。若好分数全部来自同步性类,结论是「联动就是风格」,第 3 轮放弃联动。
- **R(7 个变体,一组):** head `cross_stddev(ts_sum(log DW, 10), 241)`(-0.09)的最外层 std 换成 IQR(10 / 20 日和)、上 / 下半偏差、窗口 180 / 300、ts_sum 20。
  - **预测:** 至少 1 个变体达到 +0.01(原 head + 0.1)的概率约 20%;IQR 比 std 好 0.3 以上的概率约 30%(若成立,说明锁死日的极端值在主导 std);上半偏差(上冲)比下半偏差好 0.5 以上的概率约 60%;窗口 180 / 300 落在 -0.1 ~ -0.9,train / valid 符号互换(像 120 日那样),241 仍是峰。没有变体能到 0.5。
- **审计预期:** 两个位都过(创新度 4、合理度 4);种子被划掉 0 ~ 3 个;掩码写法是为了挡住「热身期决定结果」。

**上一轮预测对不对:** 见上。总体:方向判断(std 承重、不出 head)对,幅度和「同伴内去均值被吃掉」错。教训:我低估了「同伴内相对量」这一类,也低估了整波的最好分只有 ±0.1 左右这件事,所以这轮把「出 head」的概率压得更低,押「出正分」。

**给下一轮的备忘:** 第 3 轮会看到 B024(`sigmoid(pow_2(day_durbin_watson(F)))`、`ts_var(pow_2(DW(Ret)), 10)`,偏 Ret / Amt 的 DW;DW(Ret) ≈ 2 - 2 × 未去均值的分钟收益一阶自相关,是无量纲的弹跳 / 动量度量,和 DW(Vwap) 的「方差」读法不同)。核心使用:DW(Vwap) 用过 1 个 E 位,C = `cross_stddev(log(day_durbin_watson(Vwap)), 120)` 本轮 1 个;N 位第 1 轮已通过审计,3 轮至少 1 个 N 的要求已满足。第 3 轮的决策规则:(i) 若 E 位里同伴 / 回归类整体好于 -0.3 且有 train / valid 同号为正的,第 3 轮 E 位围绕分数最高的那个写法(取其整个 head 或子树做核心)做外围;(ii) 若 N 位只有同步性类好、状态依赖 / 特质冲击类不好,放弃联动;(iii) 若 R 的 IQR 变体优于 head1,以 IQR 为新核心;(iv) 若全部落在一条线上,第 3 轮改押 B024 的 DW(Ret) 一族(弹跳 / 自相关读法)作为 N。

## 第 3 轮

**材料:** 第 1..3 批(B024 偏 Ret / Amt 的 DW:`sigmoid(pow_2(DW))` 与 q75 / cross_mean 外壳)+ 前两轮产出。快照 9 个 head 全负(-0.09 ~ -3.28),最好的仍是 R 替换出的 `cross_stddev(ts_sum(log DW(Vwap), 10), 241)`(-0.09)。

**上一轮预测对不对:**
- E(核心 120 日 vol-of-vol,预测:最好 -0.4 ~ +0.1,出正分约 30%,出 head 4%):**部分对。** 没出 head(对);最好 -0.25(train -0.25 / valid +0.27),没有 train / valid 同号为正的,正分预测错;最好的写法是「同伴内标准化再嵌套 / 再平滑」,不是回归扣除(我押的 (A)(D) 对,(B)(C) 没进前 5,对)。
- N(同步性 / 市场联动):结果表里 N 位 0 个评分(快照记录采样为空),没有可对照的读数,预测无法判定。
- R(IQR / 半偏差 / 窗口 180、300 / ts_sum 20):**错。** 7 个变体全部比原 head(-0.09)差,最好 -0.33(窗口 180);预测「至少 1 个 +0.01」(20%)没发生;241 确是峰,IQR 没有比 std 好 0.3,说明锁死日极值并没有主导 std。

**目前对 alpha 来源的信念:**
1. 唯一有一点点的信号是 241 日量级的 DW(Vwap) vol-of-vol(-0.09,train / valid 同号都接近 0),任何换写法(窗口、稳健化、半偏差)都变差;它是「窄峰」,不像稳健的结构,多半是尺子下的噪声 0 点,而不是 alpha。
2. 同伴内标准化是唯一明确有用的外围(-0.06 / -0.25),但没有跨过 0.5;离正分差一截。
3. 本批 B024 的 head 全部 -2.8 ~ -3.3(DW(Ret) / DW(Amt) 的水平外壳),是被控制吃掉的水平;DW(Ret) ≈ 2 - 2ρ1 的无量纲属性没有被任何表达式用来做联动读法。

**本轮的任务与事先预测:**
