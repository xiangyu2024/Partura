# 两层合成用到别的因子池:结果(读到 2026-09-16)

规则见 `PLAN.md`(两个阶段的判读都写在出数之前)。本文件由 `scripts/two_level_report.py` 生成,数字全部来自
`runs/_batch_B01/two_level_stage1.json`、`runs/_forward/two_level_forward_20260916.json`、`two_level_check_20260916.json`、`two_level_hl_diag_20260916.json`。

尺子:全市场十分位书、扣单边 15bp;方向与半衰期只用样本内(到 2023-08-07)定;纯多头 = 每天等权买排名最好的 10%,净超额 = 减去当天有信号有标签的股票的等权收益。
样本内 = 2018-01 ~ 2023-08-07(权重在这段拟合,是拟合值);测试段 = 2023-08-08 ~ 2025-12-31;前推段 = 2026-01-05 ~ 2026-09-16(172 天);合并段 = 测试段 + 前推段。

## 结论

1. **把 Partura 的信号加进池子,没有让两层合成变好。** 主判据的三对(纯多头逐日净超额,同一天相减):
   - C_LQ − 手写库冠军:测试段 +4.1 个点(t +1.5)、前推段 -4.6(t -0.5)、合并段 +2.1(t +0.7) → **没有延续**。
   - C_MQ − 挖掘冠军:测试段 +1.7 个点(t +0.7)、前推段 -0.9(t -0.2)、合并段 +1.1(t +0.5) → **没有延续**。
   - C_LMQ − C_LM:测试段就是 -1.0 个点(t -0.4);C_LMQ 没过核对,按规则不读前推段(原因见下,是核对设计的毛病)。
2. **不含 Partura 的对照是同一个样子。** 把手写库和挖掘库并起来(C_LM):对手写库冠军 测试段 +2.2 个点(t +1.1)、前推段 -2.7(t -0.5)、合并段 +1.1(t +0.6);对挖掘冠军 测试段 +2.5 个点(t +1.0)、前推段 -2.4(t -0.7)、合并段 +1.4(t +0.7)。
   「池子并大一点,测试段好看两个点、前推段还回去」不是 Partura 特有的,所以测试段上那两个点不能当成增益。
3. **按训练段适应度选族,会偏向搜出来的池子。** C_LQ 的 100 族里有 67 族全是 Partura 的成员(手写库只占成员的 28%);C_LM 里有 71 族全是挖掘库的。
   这些池子本身就是在同一段时间(到 2023-08-07)上按表现筛出来的,训练段适应度天然偏高:样本内的拟合值跟着涨(手写库冠军 +20.7% / 5.11 → C_LQ +25.2% / 5.17),前推段反而低(手写库冠军 +16.9% / 1.99 → C_LQ +12.3% / 1.26)。这是解释,不是已经证明的因果。
4. **两个现成冠军在 2026 年站住了**(对它们来说前推段是干净的:选族和权重都只用到 2023-08-07):纯多头净超额 / 超额夏普,手写库冠军 测试段 +17.1% / 2.20 → 前推段 **+16.9% / 1.99**;挖掘冠军 +16.8% / 2.10 → **+16.6% / 1.49**。
   多空夏普降了:手写库冠军 4.77 → 2.78,挖掘冠军 4.95 → 2.44。2026 年(到 09-16)全部收益:手写库冠军 +5.8%、挖掘冠军 +5.6%,全市场等权 -5.4%。
5. **只用 Partura 的产出(C_Q)**:测试段和两个冠军差不多(+16.4% / 1.94,多空 4.72),前推段明显弱(+13.2% / 1.11,多空 1.83)。事先的预期是「单独不如两个冠军」,前推段上是这样。
6. **「最好的」没有实质换人。** 合并段上名义最高的是 C_LQ(多空夏普 4.43,纯多头净超额 +19.2%);它对手写库冠军的成对差只有 +2.1 个点(t +0.7),分不出高下,而且是从 6 个里挑的。
   纯多头超额夏普最高的仍是手写库冠军(2.16);只看 2026 年,手写库冠军在纯多头和多空上都是最高的。稳妥的说法:**手写库冠军和挖掘冠军并列,加料的版本没有超过它们。**

### 对「反向指引」意味着什么

- 不要指望「把搜出来的变体并进池子」带来增益;池子并大带来的测试段改善到前推段就没了(读到前推段的三个并集 C_LQ、C_MQ、C_LM 都是)。
- 一条还只是假设的评估规则:搜出来的池子的训练段适应度是被筛选抬高的,选族时应当对它打折,或给每个来源设配额。
  在样本内再留出一段来给族排序**解决不了**这件事 —— Partura 的变体是 train、valid 两段都好才留下的,挖掘库同理,两段都被筛过。
  干净的检验只能在前推段上做,而前推段现在只有 0.68 年,4 个点的差距 t 只有 0.5,功效太低。所以先记为假设,不排实验。
- 比较合成信号时要固定半衰期(或在打平的几个里取平均):样本内分不出高下的半衰期在样本外能差 1 ~ 3 个点,比我们想分辨的差距还大。
