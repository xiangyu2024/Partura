# C04:扩展信息集 + 市值控制 + 只做多头腿,Partura v2 对 AlphaCube GP(事先约定)

写于 2026-10-28 23:40,在本实验的任何运行之前。提交之后不改;要改另写「修订」。

## 1. 问题与来由

C01、C02 按事先约定判定「Partura 更差」,C03(奖励换成风格中性化后的残差书)判定「分不出」:测试段有效的新 head A 组 0 个、B 组 0 个。
C03 里两组在样本内都还能找到东西(heads A 36、B 10,融合书样本内夏普 2 以上),但测试段都留不住(heads 残差夏普均值 A 0.09、B 0.04)。
B 组的 head 更干净:全部复现、没有一个是旧族;A 组有 45 个发现是 C01 已知族的变体。但更干净不等于更好。
另外两点:同一 idea 的 8 次 B 运行初代种子完全相同,10 个 head 里 6 个来自 3 个种子(16 个种子不是 16 个独立样本);计数式的主指标在 0 对 0 时什么也分不出。

第二轮文献调研(`research/coldstart_C04/lit_review2.md`,49 篇)的三个判断:
1. 「有机制故事」本身不带来样本外溢价(Chen–Lopez-Lira–Zimmermann:挖出来的与发表的预测变量,样本期后都只保留约一半)。
2. 程序合成里 LLM 的贡献只经由「它提出的候选被评估器选中」这一条路进入结果。
3. 中性化之后 A 股价量异象大多消失是常态。Partura 要赢,得给搜索**它没有的东西**,而不是在同一个空间里再给一套先验。

**C04 的问题:当两组都能用同一批新的日频字段(市值、股本、涨跌停幅度、板块、上市天数),奖励再去掉市值暴露,Partura v2 设计的假设与初始种群,能不能让每个种子的样本外残差书比 GP 单独跑更好?**

两组用同一份信息,所以 B 组的任何增益不能归于「多了数据」(文献调研改动 1 里的 C 臂,在这里就是 A 组)。

## 2. 设计

与 C03 相同的部分:数据与时段;Partura v2 的流程(W1 写假设 → 直接检验 → W2 设计初始种群 → GP 精修);
环境规则里的相关度拒绝(与已知族 |ρ| ≥ 0.5)和计算成本禁令(`ts_spearman`、`nt_*`);发现门槛 0.5;种子占初代上限 50%;
16 个配对种子;磁盘守护与 180 分钟时限;两台服务器合作(同一种子的两组在同一台;判读统一在原服务器)。

改动:

| 项 | C03 | **C04** |
|---|---|---|
| 信息集 | 分钟价量 | 分钟价量 + **6 个日频字段**(两组相同):`LogFloatCap`、`LogTotalCap`、`LogFloatShares`、`LimitWidth`、`BoardCode`、`ListAge`;只能进 `cs_*` / `ts_*` / `cross_*` / 逐元素算子。GP 生成树时,每个「日聚合」叶子位置以 0.2 的概率改抽一个日频字段(两组相同) |
| 奖励 | `long_neutral`,控制 [流动性, 波动, 20 日反转, 已知族] | 同上,控制再加**市值 `LogFloatCap`** |
| 给 Partura 的规则 | — | **只做多头腿**:每个假设要说清楚它让哪些股票跑赢(文献:多数异象的利润在空头腿) |
| 种子 | 601–616 | **701–716**,两台服务器各 8 个 |
| idea 数 | 1–2 | **1、2 或 4**,16 个种子平均分(更多 idea = B 组更多互相独立的种子) |
| Partura 可读的先验 | C01 + C02 样本内 | C01 + C02 + **C03 的样本内**材料,以及两份文献调研 |
| 「新」 | 与 C01、C02 heads \|ρ\| < 0.7 | 与 **C01–C03** 的 heads \|ρ\| < 0.7 |
| **主指标** | 有效 head 计数 | **逐种子的连续量**(见 §3) |

实现:日频字段来自交易所公开的股本与市值(`daily_fields/`,两台服务器同一份,md5 相同);第 d 天的值是 d 日收盘可知的。
`PARTURA_DAILY_FIELDS`、`PARTURA_DAILY_LEAF_PROB`、`PARTURA_NEUTRAL_SIZE=1` 在两组的作业里相同,写进每个运行的 evidence。

## 3. 判读(写死)

- **发现**:score ≥ 0.5 且未被相关度拒绝;B 组含直接检验里的发现。
- **heads**:每组按 score 贪心去重,所有信号都取**残差**(五个控制变量)。要求:与已知族 |ρ| < 0.5、与本组已收 head |ρ| < 0.7、与 C01–C03 的全部 head |ρ| < 0.7。
- **主指标(新)**:每个种子把**本次运行自己的** heads(同样的去重规则)等权融合成一本残差书,读测试段(2023-08-08 ~ 2025-12-31)净夏普;没有 head 的种子记 0(持现金)。
  16 对同种子做 Wilcoxon 符号秩检验(单侧,α = 0.05):p(B > A) < 0.05 且中位差 > 0 为「Partura v2 有用」;p(B < A) < 0.05 且中位差 < 0 为「更差」;其余「分不出」。
  选这个指标的理由:C01、C02 的计数主指标对「一个种子撞进一个家族」极敏感(C02 的 A 组 7 个有效 head 全来自种子 406);连续、逐种子配对的量把种子当作样本单位。
  按 16 对,80% 功效下可检出的效应约 d ≈ 0.62(文献调研 §2.4)。
- **次指标**:有效 head 计数(测试段残差书年化净超额 > 0 且 t ≥ 2.0;沿用 C03 的判定式);每组 heads 的融合书;前推段(只报);
  样本内的同种子配对(符号检验);GPU 时间与 token。
- 台账 `runs/_c04/ledger.json`;测试段只读一次。
