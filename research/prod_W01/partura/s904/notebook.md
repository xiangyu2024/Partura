## 第 1 轮

### 我目前对本种子 alpha 来源的信念
- 证据只有 M 第 1 批的 124 个已评分候选和共性表;**0 个 head**,共性表里含子树的候选均值都是负的(最好的一组 -0.57,样本 4 个)。没有任何个体分数,所以所有判断只来自「含 / 不含某子树」的均值差。
- 新尺子 = 排名 → EMA → 对 5 个控制的 15 列取残差 → 十分位纯多头 → 扣 15 bp,取 train / valid 较差者。我的读法:这个尺子上换手是第一杀手(0 / 5 / 20 半衰期里本来就是慢的先活下来),再加上 valid 区间是弱市,纯多头想拿到 0.5 需要真正的超额。因此共性表里「更好」的子树,大部分可能只是「更慢」的代名词(ts_reg_tvalue(·, ListAge, 30)、ts_sum(·, 40)、cross_ema(·, 241) 都是平滑)。
- 对 ts_reg_tvalue(x, ListAge, 30) 的读法:rolling_ols(x, y) 里 y=ListAge 是 y,x 是重分钟收益;ListAge 逐交易日 +1(停牌也 +1,老股从 10000 起),所以它的 t 值等价于 x 与时间下标的相关系数的 t 值 —— 是 H 的「变化趋势」,不是 H 的水平。GP 在 H 上只试了趋势 / 绝对值 / 开方,没(从表里看)试水平、标度、对照和尾部。
- 一个猜想(未验证,只能靠评分印证):day_topw_mean(Ret, Amt) 选出的重分钟多数在开盘几分钟,它的 Ret 可能与隔夜缺口耦合;如果成立,第 1 批里 H 的优势一部分来自「开盘定价」。N 位就是把隔夜缺口和日内漂移直接拆开来读。
- 当前对 alpha 来源的排序(信念,不是结论):1) 重分钟方向的慢水平(标度过);2) 隔夜 / 日内拆分的慢变量;3) 其余未知。

### 本轮计划与事先预测
- **E(核心 `day_topw_mean(Ret, Amt)`)**:外围全换成「水平 + 长半衰期平滑 / 波动标度 / 对照整天 / 尾部 / 与日收益联动 / 条件化」。种子 16 个,均不用 ts_reg_tvalue(H, ListAge, 30) 的趋势写法。
  - 预测:会产出比第 1 批含 H 候选更好的个体(最好的在 -0.3 附近或更好);出 head(≥ 0.5)的概率我只给 ~15%。若出 head,最可能的形态是 cross_ema / cross_mean 窗口 ≥ 60 的 H,带波动标度(除以 60 日波动或 day_wstd),最佳半衰期是 20;方向大概率是「重分钟收益高 → 做多」或反向其一,我没有把握,尺子会自己选。
  - 失败预案:若全体都不如第 1 批(均值 ≤ -1.2),说明 H 的优势只是趋势 / 平滑带来的换手差,而不是「大单方向」,下一轮 E 位让给别的核心,不再深挖 H。
  - 风险:cs_flip_by_state 种子的状态变量是慢市场状态,但若状态翻转频繁会放大换手;ts_corr 联动型可能与控制 vol 高度相关被表里划掉。
- **N(隔夜缺口 G vs 日内漂移 I 的慢变量)**:G = log(day_first(Open) / 昨日 day_last(Close)),I = log(day_last(Close) / day_first(Open)),四组种子(慢水平 / 稳健 sign、winsor / 缺口后日内接力 / 标度与异常)。灵感来自 cross_ema(day_sum(Ret), 241) 只含日内那一半。
  - 预测:出 head 的概率 ~10%,比 E 低,因为纯多头在 valid 弱市里很难靠一个新方向就过 0.5;但它与 M 的候选相关最小,期望是「个体分数分布和 M 不同」,即使没有 head 也能给下一轮核心卡提供新的子树。若有 head,最可能是 G - I 的慢 EMA(60 – 241 日)或 sign 型接力(sign(G) * sign(I) 的 60 日均值)—— 文献上隔夜段有持续性、日内段相反。
  - 失败预案:若整体分数仍在 -1.5 附近,说明这个尺子下慢收益分量没有独立信息,第 2 轮 N 位转向「重分钟的时间位置」(day_topw_mean(in_index(Amt), Amt) 一类)或「价量联动」。
- R:快照没有 head,本轮没有 R。
- 上一轮预测:无(第 1 轮)。

### 我目前对本种子 alpha 来源的信念
- 证据:337 个已评分候选,**1 个 head**:`ts_regbeta(day_gini(Volume), day_kurt(Vwap), 50)`(M 第 2 批,sign +1,hl 5,train +0.97 / valid +0.92)。我自己两个任务位 164 次评估 0 个 head、最好 +0.29。
- H* = 这个 head 的读法:ts_regbeta(x, y, d) 是 y 对 x 的斜率,即 kurt(Vwap) 对 gini(Volume) 的 50 日斜率 = cov / var(gini)。两半单独都崩(-2.76 / -3.38,且 gini(Volume) 与已知族 ρ 0.67),只有耦合有效;Volume→Amt 不变(+0.88);Vwap→Close train 掉(+0.32)而 valid 仍 +1.02;窗口 25 崩(+0.04)、50 好、100 train +0.54 / valid +1.52。M 自己的 day_kurt(Open) 邻居 11 个平均 -1.12。→ 这是一条窄脊:耦合的**形式**有用,具体字段 / 窗口不能乱动。
- 我的猜想(未验证):封板日(涨跌停后价格被钉死)同时让 gini(Volume)(量堆在触板前几分钟)和 kurt(Vwap)(先动后钉死的尖峰)极端,50 日协方差因此由少数封板日主导,head 实际读的是「封板足迹」这个慢变特质(游资 / 题材交易的参与者结构)。证据只有消融的间接形状,不是检验;本轮 N 位就是直接检验它。
- 其余信念:(1) 价位项(`cs_robust_z(day_mean(Low)) / day_first(Open)`,后复权价格水平的 V 形函数,低价一侧值极大)是 GP 最偏爱的慢分量,但 train ≈ 0,不是独立的 alpha;(2) 重分钟收益 H_top 的慢 z 值是 valid-only;(3) 共性表里 day_gini(Volume) 的 36 次出现、day_kurt(Open) 的 34 次基本是 head 邻居的谱系,不能当独立证据。
- 把「慢」当成这把尺子的第一筛子没变:所有活下来的都是 50 日以上窗口或多层 EMA。

### 本轮计划与事先预测
- **E(核心 = 整个 head H)**:外围换成两类 —— (1) 与第 1 轮里「valid 强 train 弱」的慢伙伴(P1 H_top 慢 z 值、P2 缺口减价位项、P3 价位项取反)做秩混合 / 相乘,权重让伙伴占 0.65-0.7(等权混合与 H 的日度秩相关约 0.71,会撞库禁令);(2) cs_first_low/high40/20(H, X) 分段,X 取市值、上市年龄、60 日波动、已知族。16 个种子。
  - 预测:出 head 的概率约 40%,是本轮最高的一个位。若出,最可能是 add(mul(rank(H), 0.3-0.35), mul(rank(P1 或 P2), 0.65-0.7)) 一类,hl 5 或 20,score 0.5-0.8,与 H 的日度秩相关 0.5-0.69;限制它的是伙伴的 train(+0.1 到 +0.3),所以 train 会是 min 的那一边。分段种子(cs_first_*)我预测 -0.3 到 +0.4,不会出 head:段边界会把阶跃项带进长仓,新尺子的三次多项式只去掉一部分。mul(rank, rank) 我预测介于两者之间。
  - 失败信号:若所有混合 <= 0.3,说明 H 与这类伙伴不可加(H 的 alpha 窄、伙伴的 alpha 主要是 valid 区间的风格),第 3 轮不再做混合;若 16 个种子里 < 4 个活过相关度表,说明 H 与伙伴比我想的更相关。
  - 风险:这类 head 与 H 相关 0.5-0.7,多样性贡献有限;只是「H 加别的」,不是新机制。我把它当作稳健化,不当作发现。
- **N(涨跌停封板足迹,三组种子)**:(a) 直接度量封板频率 / 强度(day_at_max_ratio / at_min / flat_run_max 的慢均值、方向差、上四分位日、剔除最次新 5%);(b) 把 head 里的 kurt(Vwap) 换成明确的封板度量,x 位保持 gini(Volume);(c) 对照组:不含封板量的耦合(day_centroid(Amt) 对 day_sum(Ret) / day_signed_ratio,gini 对 AR(1) 的 t 值,ts_regres 的 EMA)。
  - 预测:出 head 的概率约 12%。(a) 组我预测 -1.0 到 +0.2:封板频率顶端是游资票,20 日反转 / 波动 / 流动性控制会吃掉一部分,剩下的多是 train 为负;(b) 组最接近 H,预测 -0.5 到 +0.5,最好的可能 +0.3 以上,但也可能与 H 的相关 >= 0.7 被划掉;(c) 组 -1.5 到 0。
  - 决定性信号:(b) 里 ts_regbeta(gini, at_max) / ts_regbeta(gini, flat_run_max) 若 >= 0.5 → head 的内容就是封板,第 3 轮 R / E 沿这条线深挖;(a) 若显著好于 (c) → 封板足迹本身有 alpha;(c) 若与 (b) 一样好而 (a) 差 → 耦合形式可迁移,第 3 轮改做更多变量对。三者都 < -1 → 猜想被否,封板不是 H 的内容。
- **R(head 的 16 个变体)**:烂的部件 = 单一的 50 日窗口 + beta 里的小方差日。变体:窗口 40 / 60 / 75 / 90 / 120 / 150,Amt 版 60 / 75,两个窗口 beta 求和,先 EMA(10 / 30),gini(V)+gini(A),kurt(Vwap)+kurt(Close),ts_corr / ts_reg_tvalue(60,去尺度项的诊断),skew 替换 kurt。
  - 预测:有变体 >= head + 0.1(即 train 和 valid 都 >= 1.02)的概率约 10%;若有,最可能是窗口 60-90 或两窗口求和(降噪),与 head 的 ρ >= 0.5 → 替换。诊断类(corr / tvalue / skew)我预测 < 0.5。窗口 40 我预测接近 25 的崩(< 0.3)。
  - 这组的主要价值是读结果:窗口 40-90 的曲线告诉第 3 轮 head 的窄脊有多宽。
