# 种子 912 笔记本(PI)

## 第 1 轮

### 对本种子 alpha 来源的信念(只依据 M 第 1 批的 1 个 head 和 112 个已评分候选)

- 唯一的 head:`cs_first_high40(ts_var(day_durbin_watson(Vwap), 1), ts_var(sqrt(day_durbin_watson(Vwap)), 10))`,sign -1,hl 5,train +0.58 / valid +1.66。
- 读源码后的事实:
  - `day_durbin_watson` 不去均值,是 sum(diff^2) / sum(x^2)(分母 +1e-8)。对价格 Vwap 就是 分钟 Vwap 变动均方 / 价格^2,
    即日内已实现方差的无量纲版本(含低价股的最小变动价位效应);sqrt 后是日内已实现波动率。
  - `ts_var(sqrt(DW), 10)` = 已实现波动率的 10 日方差 = vol-of-vol(记作 C)。
  - `ts_var(x, 1)`:`nanstd_last` 在窗口只有 1 个点或全是 NaN 时返回 0,所以 `ts_var(DW, 1)` 是整张常数 0 面板。
    `day_corr(Low, Low)`、`day_pos_ratio(Vwap)` 也几乎是常数(corr 自己对自己约 1,正比例约 1)。M 的 GP 把这类常数当作 并列全按列序打破 的键来用。
  - `cs_first_high40(y, x)` = rank(y) + 1(x 在前 40% 的整块并列内);y 常数 => rank(y) 就是股票列序。sign -1 => 做多的是 非高 vol-of-vol 带 里列序靠前的名字。
    列序对应交易所与板块(规则 §4 明说携带板块信息),具体是哪一段我不知道(若按代码排序,最靠前的大概是深市主板 / 中小板,但没有证据)。
  - 拆解印证:常数键换成 DW 本身 train 从 +0.58 掉到 -1.75;去 sqrt 或 Vwap 换 Close 变化不大(+0.40 / +0.24);窗口 1->2 掉到 -0.85;
    门槛自己单独作为信号(分子 ts_var(sqrt(DW),10)) train 只有 +0.07、valid +1.04。
- 信念:head 的 alpha 主要来自 板块 / 列序偏好 和 一个 low vol-of-vol 带的组合,vol-of-vol 的连续排序本身在 train 上几乎没有内容(+0.07),
  valid 上有(+1.04),两段不一致,所以不能直接相信它是稳定的 vol-of-vol 溢价。
  - 对 OOS 的担心:板块相对表现随行情轮动(2018-2021 与 2022-2023 的主板 / 创业板相对强弱不同),valid +1.66 比 train +0.58 高很多,可能含有这个成分。
- 富集结果里 C 的含有者均值差 +1.46(32 个候选),基本都是 带门槛 的写法,不能分开 门槛 与 vol-of-vol。

### 本轮三个任务与事先预测

1. **E 位,核心 C = `ts_var(sqrt(day_durbin_watson(Vwap)), 10)`**,12 个种子,全部是连续 rank 构造(水平中性 bucket_rank、rank 差、自身历史 rank 变化、Low 路径对照、BoardCode 板块优先、ListAge 排除),
   不含常数键与分位门槛。
   - 预测:产出 >= 1 个 head 的概率约 25%。
   - 若产出,最可能是 `add(cs_rank(C), BoardCode)` 或带 ListAge 的写法(它们保住了 板块 成分),sign -1,hl 5 或 20,valid 比 train 高;
     纯水平中性的写法(bucket_rank 对波动水平 / 市值 / 成交额,rank 差)在 train 上多半 < 0.5,因为我认为连续 vol-of-vol 排序自己没有稳定内容。
   - 若 E 全灭而 board 键的写法也不行:说明 head 的收益依赖 列序 而不是 BoardCode 能表达的板块,下一轮要想别的办法抓列序(例如 ListAge / LimitWidth 的并列块结构)。
2. **N 位,隔夜 / 盘中拆分**(Ov = log Open - log 前收,Id = log Close - log Open),13 个种子:水平、差、衔接(ts_corr / ts_regbeta / sign 乘积)、skew、方差占比、ListAge 排除。
   - 预测:产出 head 的概率约 12%,较有希望的是 sub(ts_mean(cs_rank Ov, 20), ts_mean(cs_rank Id, 20)) 一族,方向未知(文献主张隔夜持续、盘中反转,但 A 股可能相反)。
   - 主要失败模式:新股连板、涨跌停锁死的名字在两端占满;20 日总收益(反转控制)里 Ov + Id 的重叠;换手 / 流动性相关;
     ts_corr / ts_regbeta 在 40 日窗口不满时(上市 / 复牌后)退化。
   - 这是本种子第 1 个 N 位,必须让它至少有一个能通过审计;若审计没通过,第 2 轮另写一个 N(备选:把 vol-of-vol 推广到别的日内结构统计的跨日不稳定性,
     如 ts_std(day_gini(Amt), 20)、ts_std(day_centroid(Amt), 20)、ts_std(day_autocorr_n1(in_pct(Vwap, 1)), 20))。
3. **R 组,10 个变体**,把 head 里的常数键换成显式的 BoardCode / LimitWidth / ListAge(及其反向),并改窗口 / 带宽 / sqrt / Vwap->Close。
   - 预测:任何变体 score >= 0.68 并 替换 / 收录 的概率约 10%。
   - 更重要的是信息:BoardCode 版本 ≈ head(若不是,说明列序里有 BoardCode 表达不了的信息);neg(BoardCode) 版本大幅变差 => 偏好 主板;
     LimitWidth / ListAge 版本和 BoardCode 版本对比 => 板块的哪个维度(涨跌幅限制 / 上市年龄)有内容。

## 第 2 轮

### 对本种子 alpha 来源的信念(依据 M 第 1..2 批 + 第 1 轮三个任务的结果)

- 库里 6 个 head:5 个是 `C = ts_var(sqrt(day_durbin_watson(Vwap)), 10)`(vol-of-vol)加筛子(两层筛子 ListAge + 价格水平 / 单层 ListAge / BoardCode 列序 / 40 日动量十分位),
  1 个是 `ts_skew(Ov, 40)`(Ov = 隔夜缺口 log(day_first(Open)) - log 前收,sign +1,hl 20,train +1.12 / valid +0.56)。M 的第 2 批没有新 head。
- 第 1 轮的实证修正了我上一轮的信念:
  1. C 一族的内容是「低 vol-of-vol 且不是新股 / 垃圾名字」,不是「板块列序」。裸 C train +0.07,套 ListAge 筛子 +0.72,再加价格水平筛子 +1.12(去掉价格筛子 -0.44),窗口 10->20 再 +0.26。
     BoardCode 显式化的版本(+0.74)高于列序版本(+0.58),相关 0.81,neg(BoardCode) 版本 train +1.43 / valid -0.94:板块偏好的方向随行情翻转,是风格,不是稳定 alpha;
     ListAge 的正向版本 -1.04、neg(ListAge) +0.73,与「ListAge 在做新股排除」一致。
  2. 所有 C 一族 head 的 valid(+1.2 到 +2.7)远高于 train(+0.6 到 +1.1);偏度 head 反过来(train 1.12 / valid 0.56)。两族在两段上互补,能同时在两段站住的复合有机会,
     但库禁令(日度秩相关 < 0.7)逼着复合必须足够不同。
  3. 隔夜缺口:水平、与盘中的差、衔接、方差占比都没过线(第 1 轮 N 位偏度以外最好只有 +0.15),只有偏度过线 → 内容在形状不在水平;
     而且形状指标量纲无关,对水平类控制近似正交,这是它能过「新尺子」的合理解释。
  4. 读源码得到的实现事实(本轮种子据此设计):`nanstd_last / nanskew_last / nanvar_last` 没有最小样本数,新股和复牌后的窗口由少数几个点决定;
     `ts_kurt` 的 EPS=1e-9 加在 var^2 上,对收益量纲的输入(标准差 0.5% 时分母抬高 2.6 倍)有数值伪影,只在秩空间用;`ts_corr` 在 1 个点返回 0、2 个点恰为 ±1;
     `cs_first_* / cs_last_*` 的筛子以整块并列为单位,ListAge 的「老股」是一个巨大的并列块(加 10000 的哨兵),所以筛的是最年轻的若干个上市批次。
- 对 OOS 的担心:C 一族 valid 远高于 train,可能含 2022 到 2023 年主板 / 低波动占优的风格成分;偏度 head 相反。二者并存有自然对冲的味道,但不保证。
  BoardCode 一类的 head 风险最大(列序不是经济量)。

### 本轮三个任务与事先预测

1. **E 位,核心 Ov**(`sub(log(day_first(Open)), log(ts_delay(day_last(Close), 1)))`,14 个种子)。
   选 Ov 而不选整个偏度 head 作核心:整个 head 作核心时,任何只加筛子的写法与它的相关度都 > 0.9,会被库禁令整批划掉;核心取 Ov,偏度之外的统计量才有空间。
   种子四组:换矩 / 换窗口 / 换空间(秩空间偏度与峰度,慢窗口 250 日)、不对称的另外度量(正向缺口份额、极值秩差)、时序结构与同步度(缺口自相关、缺口对昨日盘中的回补、缺口对市场缺口的同步度)、
   与稳定波动筛子 C 的复合(cs_last_high20 / 40、cs_first_low20)和 session 差(隔夜偏度 - 1.5 倍盘中偏度)。
   - 预测:产出 >= 1 个新 head(分数 >= 0.5 且与 6 个 head 的相关 < 0.7)的概率约 35%。
   - 最可能的 head:秩空间偏度 / 峰度的慢窗口版本,或偏度配 C 筛子的复合。若是复合,valid 应该比偏度本身高(C 一族的 valid 特征被带过来),train 约 0.8 到 1.0;
     纯秩空间版本则预期保持 train > valid 的偏度特征(valid 0.5 左右,边缘)。
   - 审计后预期剩 8 到 11 个种子:最可能被相关表划掉的是 cs_first_low20(skew, C20)(合成数据上结构相关 0.69,贴线)、cs_last_high20 复合(0.66)、极值秩差(0.58)。
   - 若全灭:说明偏度 head 的内容就是 40 日原始偏度这一个具体写法,或库禁令把偏度附近的东西全部挡掉。下一轮就转向别的矩 / 别的输入,不再围着 Ov。
2. **N 位,日内时钟上的成交足迹与同步度**(16 个种子):开盘集合竞价份额(day_first(Volume) / day_sum(Volume))的水平和变化、成交额的时间重心 / 基尼系数、
   个股日收益对等权市场收益的 60 日相关(同步度)、收盘强度、两个交互;AUC 与同步度各写了两个方向的 ListAge 筛子,因为符号未知。

   - 若产出,最可能是 AUC 水平 / 变化(任一符号,带 ListAge 筛子的版本)或同步度的 ListAge 版本;预期 train 比 valid 弱(像 C 一族),因为这类比例量对风格轮动的暴露和 C 一族差不多。

3. **R 组,16 个变体**(5 个 head)。
   - 对库里 train 最高的 head:窗口 20 / 30 / 40(窗口 20 已知 +1.37)、第三层 LogFloatCap 筛子、Low 路径;对窗口 20 的那条几乎确定替换。

### 上一轮预测对不对

- **E(核心 C,预测 >= 1 个 head 的概率 25%)**:实际 103 次评分,10 个过线,入 heads 4 个(最高 +1.12)。概率估计偏低。具体的判断一半对一半错:
  「连续 rank 构造多半 train < 0.5」对了——过线的全是 GP 长出来的 ListAge / 价格水平筛子写法(其中 `cs_first_low20(C, ListAge)` 是我的种子 #11,其余是它的外围变形),
  我设计的水平中性、rank 差、自身历史变化那些连续构造没有一个进 heads;「BoardCode / ListAge 键保住的是板块成分」错了,ListAge 起的是新股排除作用。
- **N(隔夜 / 盘中拆分,预测 head 概率 12%,最看好 Ov - Id 的均值差一族)**:实际 1 个 head,是 `ts_skew(Ov, 40)`——我的种子 #10,事先没有点名;均值差一族没过线(最好 +0.15)。
  「隔夜有内容」的方向对了,具体形式猜错了。
- **R(预测任何变体 >= 0.68 并替换 / 收录的概率 10%)**:实际 10 个变体里 4 个达到「原 head + 0.1」并满足替换条件(BoardCode 版 +0.74、neg(ListAge) 版 +0.73、窗口 20 版 +0.76、high20 版 +0.71),
  最终生效 1 个替换(窗口 20 版 +0.7556)。预测明显偏低,因为 head 本身只有 +0.58,门槛不高。信息性预测:「BoardCode 版 ≈ head」对了(相关 0.81);「neg(BoardCode) 大幅变差 => 偏好主板」对了但更复杂——
  train 反而 +1.43、valid -0.94,方向随行情翻转。
