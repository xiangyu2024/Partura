## 第 1 轮

### 目前对本种子 alpha 来源的信念(只有 M 第 1 批:109 个已评分候选,0 个 head)
- 没有任何东西接近 0.5。不含 LogFloatShares 的候选均值 -0.96,含它的 -0.56。-0.96 的主因我判断是换手:奖励用「十分位纯多头 + 15bp x 双边换手」,分钟级日度量即使再做半衰期 <= 20 的 EMA,名单每天仍在变,毛超额被成本吃掉。所以「信息」和「可交易」要分开想:慢的构造(窗口 >= 20-60、个股相对自己历史的标准化)先天占便宜。
- 唯一富集的是 LogFloatShares(pow_2 / inv / pow_3 都是它的单调重写,排名后是同一个信号,最多差符号)。控制里有 LogFloatCap 的 1/2/3 次秩,而 LogFloatCap - LogFloatShares = log(FloatCap / FloatShares) = log(名义股价)(假设 FloatCap = 流通股本 x 当日名义收盘价,没验证)。所以残差化后 LogFloatShares 读到的主要是「同市值下的名义股价」。这个量几乎不动(零换手),它的负分不该来自成本,更像是毛超额为负,或 train 选定的方向到 valid 翻了(风格轮动)。这是推断,批 1 没给分期数字。
- 方向和半衰期只按 train 的净夏普选(steer.py reward),valid 不参与选择,score = min(train, valid):风格型水平量最容易死在符号翻转上。个股内标准化的冲击量对截面静态风格免疫,更不容易翻。

### 为什么这一轮两个位都用 N,不用 E
- 所有可选的 E 核心(loc.md 里 10 个子树 + 核心卡)都是 LogFloatShares 的单调重写,秩上同一个东西。它和控制 LogFloatCap 的日度秩 |ρ| 我估计在 0.75-0.85 之间(log 股本的离散度比 log 股价大),E 位要求核心与每个控制 |ρ| < 0.8,过不过是个硬币。过不了整个位退化成普通 GP,种子全废。
- 同一个想法写成 N(直接写名义股价 P = sub(LogFloatCap, LogFloatShares),再加同伴相对 / 状态加权 / 配对腿),没有核心门槛,只有逐个种子 |ρ| >= 0.8 才划掉。
- E 的两个名额没有用掉;之后有 head 了再对 head 的子树做 E。
- 没有 head,所以 R 为空。

### 目前对本种子 alpha 来源的信念
- 唯一的来源是 day_centroid(Amt)(成交额日内重心)。M 两批 312 个候选含它的 8 个均值 +0.09 对 -1.24。两个 head:pow_2_5(cross_mean(c, 3))=+0.80(train 1.48 / valid 0.80)、cross_zscore(cross_mean(c, 20), 120)=+0.66(0.66 / 0.78)。
- 拆解给出的形状很干净:日度 0.41 -> 2 / 3 / 6 日 0.69 / 0.80 / 0.85 -> 20 日 1.34(1.72 / 1.34);z-score 基线 60 / 120 / 240 = 0.09 / 0.66 / 0.90;对日度值直接 z-score = -1.16。结论:它是个股「长期稳定的成交时点水平」(参与者结构的特质),窗口越长越好,去水平越彻底越差。纯 20 日均值 1.34 过不了线只是因为 |ρ_known| 0.51(3 日 0.28、6 日 0.36)。所以 R 的主要工作是在 0.5 以内把窗口拉长或者把已知族的暴露减掉。
- 机制猜想(未验证):重心靠前 = 开盘集合竞价 / 早盘信息交易与机构执行,重心靠后 = 散户尾盘追涨与被动流量。推论:拆成分段份额(尾盘 30 分钟、开盘集合竞价、收盘集合竞价、午间低谷),各段与重心的关系不同,会有一些段携带重心之外的信息。
- 另一个可能:低重心 = 开盘即涨停封板的票(成交全挤在封板前)。如果是,那是打板 / 涨停动量,可交易性存疑。本轮不做区分(没有样本内手段分),但 R 与 E 的 (c) 类「带方向的时点」可以侧面看。
- r1 的信念大体对:慢构造先天占便宜;LogFloatShares 一族是风格暴露,不是 alpha(908 里对它取残差让重心的分数涨 0.4,是旁证)。
- 库禁令是这一位的主要约束:任何重心水平的平滑或单调包装,对 3 日 head 的日度秩 |ρ| 估计 0.8–0.9(20 日均值与 3 日均值,按个股特质占比 0.3–0.5 估),会被拒绝或被相关度表划掉。所以 GP 位都放在「改变截面入选集合 / 加一条独立腿 / 换度量」上,把「重心水平的升级」交给 R(R 不受库禁令约束,只要与原 head 秩 ≥ 0.5 就替换)。

### 目前对本种子 alpha 来源的信念
1. 来源仍是"一只票的钱习惯在一天的什么时候成交"(重心越靠前越好,方向 -1)。水平型已经有 9 个 head 里的 8 个。
2. r2 想不明白的一件事这一轮想通了:读 `_lexi` 源码——`cs_first_low20(y, ListAge)` 是 rank(y) + 1[ListAge 最低 20%],方向 -1 时多头取总分最低的一端,所以这个算子在方向 -1 下的意思是"y 越低越好,但最年轻的 20% 不得进多头"(一个排除筛选,不是"只在年轻票里选")。ListAge 筛选把重心的分数从 1.34(20 日均值)抬到 1.8-2.25,是把新股(开盘即涨停 / 连续一字板,成交全挤在开盘前,重心天然最小)挡在多头书之外:这些票重心最小、却不是好的多头。含这个子树的候选均值 +1.53,不含 -1.05(共性表第 1 行)。机制可信,样本内 train / valid 同号(2.52 / 1.80 等)。
3. 库禁令的一个后果,我 r2 没算:筛选型信号 s = rank(y) + 1[年轻 20%],块项占总方差约 2/3(0.16 / 0.24),所以两个都带同一道 ListAge 筛选的信号,不管 y 是什么,日度秩 |ρ| 先天约 0.66 + 0.34·ρ_y,ρ_y 只要 >= 0.12 就越过 0.7。结论:本种子里再往"水平 + ListAge"里长新东西,几乎都会被库禁令 / 相关度表挡掉(r2 E 位 25 个过线只入 5 个 head,另外 20 个多半是这个原因)。要新 head 必须换形式;R 不受库禁令约束,可以升级,但对没有筛选的 head 加 ListAge 会和 head 1 变成共享块、在最后去重时可能被丢,所以 R 不做这种加筛选。
4. 第二个 alpha 来源族:**个股内部的滚动耦合**(cross_corr / cross_reg_fvalue(时点量, 形态量或价格冲击, 60))。别的种子里这一族 train / valid 都在 1.2-2.4,与重心水平 head 的日度秩 |ρ| 0.1-0.3。本种子 M 的 3 批一次都没长出过它(含 cross_corr 的候选我没看到在共性表里),所以这是本种子库里的空白。我的先验:它读的是"参与者结构如何响应隔夜消息 / 尖峰日是不是开盘带起来的",是慢变量,不是水平型的变形。
5. 不确定:耦合型在别的种子里 valid 多半高于 train(1.45 -> 2.40, 0.92 -> 2.66 等),这可能是 2022-2023 年风格对它有利,而不是稳定的结构。min(train, valid) 的口径下它是 train 说了算,这里没问题;但样本外它也许不会 valid 那样好。
