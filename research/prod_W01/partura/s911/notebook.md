**我手里有什么**:M 的第 1 批,98 个已评分候选,0 个 head(没有一个 min(train, valid) 净夏普 ≥ 0.5);共性表里只有 3 个像样的子树:

`cross_scale(day_wstd(Low, Open), 241)`(+0.95,p 0.12,5 个)。日内统计量 day_centroid / day_pos_ratio / day_wstd 出现 7 到 12 次,没有富集。
全部候选平均 -1.5,所以这一批的主旋律是「15 bp 成本下换手把大多数候选吃光」,富集的都是慢变量。看不到每个候选的分数,只有这张共性表。

**我对本种子 alpha 来源的信念(第 1 轮,凭先验加这张表,尚无任何评估)**
1. 最可能的来源是上市龄(次新股)通道。`cross_scale(x, 241)` = x_t / 过去 241 日 x 之和(缺失日不计):上市不满 241 天的股票分母只有上市以来的几天,
   值 ≈ 1/上市天数,所以截面上「越新越靠前」;满 241 天的股票则是一年尺度的漂移比值。三个 cross_scale(·, 241) 子树里两个富集,与这条解释一致;
   cross_scale(day_centroid(Volume), 241) 却没富集(-0.07,5 个),这是反例,说明外围写法和 15 bp 的换手也在起作用,我对这条的把握只有五到六成。
2. 第二个来源:静态 / 极慢的股本结构(LogFloatShares、总股本与流通股本之比、股价水平)换手近 0,净 ≈ 毛。但 abs_(LogFloatShares) 与 LogFloatCap 的秩相关我估计在 0.8 上下,
   做 E 核心有「核心本身就是控制」(≥ 0.8 → 整个位不通过)的风险,所以这一轮不用它做核心。
3. 日内形状统计量(单日)在这个成本下大概率没救;要用只能做成 60 日以上的累积。
4. 规则没有明说夏普是绝对口径还是相对全市场的超额口径;全样本平均 -1.5 更像超额口径下被成本吃掉。若是超额口径,静态溢价的 Sharpe 取决于溢价大小与跟踪误差;train(2018–2021)与 valid(2022–2023.08)都要 ≥ 0.5,这是最硬的约束。

**本轮计划**
- 无 head,所以 R 为空。
- 位 1(E,核心 `cross_scale(LogFloatCap, 241)`):14 个种子,全部原样含核心,外围分四类:(a) ListAge 与「一字板冻结」排除屏(select_where / cs_last_high10);
  (b) 流动性十分位 / 市值十分位内排名(cs_bucket_rank);(c) 核心的秩与独立线索的秩相加减(低波动、金额加权上涨分钟占比、涨停停留时长、限售股占比 LogTotalCap - LogFloatCap);
  (d) cs_flip_by_state(市场活跃期与冷清期方向不同)。核心留给 GP 去长外围。
- 位 2(N):隔夜 vs 日内收益的客户群分解,60 到 120 日累积;13 个种子(均值 / 差 / EMA / 中位数 / 符号占比 / 下尾 / 与日内相关 / 市值分桶去均值)。
- 烟雾测试:在合成 cube(60 只 × 300 日)上 27 个种子全部能算出、有限比例 ≥ 0.97;is_gt 的符号版本会出现大量并列(靠列序打破),这是设计内的。

**事先预测(请下一轮对照)**
- 位 1(E):我预测产出 head 的概率约 35%。如果有,会是「核心 + 洗掉连板冻结 / 在分桶内排」这一类,score 在 0.5 到 0.9 之间,多半 train 好于 valid(次新股溢价在 2022 年之后收窄);
  半衰期会选 20(或 5)。反方向的风险:核心的头部含大量上市头几天的连板名字,若尺子不做可交易性处理,分数可能被不可买的收益抬高(那样 head 会出来但不真);
  若做了可交易性处理,核心的优势会缩水,可能 0 个 head。我最看好的两个种子:#2(冻结屏)和 #9(扣限售占比)。
- 位 2(N):产出 head 的概率约 20%。如果有,会是 60 到 120 日、隔夜与日内之差(或 ON 单边 / 符号占比)的慢版本,score 0.5 到 0.7,train 好于 valid 的可能性大;
  失败的主要路径是它和 20 日反转 / 波动控制的相关性被去掉后剩的信号太弱,或 2022 年的行情让两个分量的符号换向。
  最看好的种子:#2(ON-ID 60 日差)、#6(符号占比差,抗跳空事件)。
- 整轮:0 个 head 的概率约 55%;两个位都出 head 约 8%。

**我目前对本种子 alpha 来源的信念(第 2 轮,基于 M 的第 1..2 批 348 个已评分候选 + 本种子第 1 轮 171 个)**
1. 最强的信号:价格水平台阶 × 成交量。cs_last_low20(成交量量, 价格水平) 被两处独立发现(M2 head 1 +1.19、Pr1b head 2 +0.83),Pr1b 里连成交量都不用的纯价格兄弟(y = neg(day_quantile_q75(Low)),x = 收盘 / 开盘价)也有 train +0.2 / valid +2.0。
   拆解:Volume->Amt +0.27 / +0.04(轻微),Low->High、Close->Vwap、窗口 5/10/20 全是噪声级,说明起作用的是「价格水平最低 20%」这个断点,而不是具体价格或成交量。
   我对机制的推断(未测):y 也是价格时,秩(y) - 1[G] 是价格秩上的锯齿,极值落在 20% 分位两侧;所以读的是价格水平的非单调(带状)暴露,控制的低阶多项式拟合不了这个断点。把握约 35%;另一种可能是真正有用的是「断点 × 流动性」的交互(head 1 除以 A 使非 G 组按 1/A 倒排,G 组反向),
   此时纯价格的带状没用,要靠成交量腿。本轮 E 位两种都放了,表里谁活就说明是哪一种。
2. 第二个来源:开盘 / 收盘分钟的成交量构成(head 3)。head 3 的两项里 ID 收益项数量级估计比第一项小两到三个量级,实际起作用的应是 60 日均值的 首分钟量 / 前一日末分钟量 - 1;重尾,被分母极小的日子主导。
   这既可能是开盘 / 收盘撮合份额的构成(机构 vs 散户),也可能只是涨跌停封板日的计数;本轮用有界份额(分母 = 当日总额)与对照种子 cross_mean(day_at_max_ratio(Close), 60) 一起检验。把握 30% 是构成,25% 是封板计数,其余是别的(如分母近零的伪影)。
3. 上市龄 / 慢通道(cross_scale(LogFloatCap, 241))真实但弱(+0.31,两个时期都为正),本轮不再投入,也没有必要用掉它的第二个 E 位。
4. 所有 head 都是 valid >> train(2022 年之后更强);score 取较差者,所以 train(2018–2021)是真正的瓶颈。R 位优先动 train 的薄弱处。
5. 日内形状统计量单日版(day_centroid / day_pos_ratio / day_wstd)与收益型 ON / ID 种子全部无效,继续避开;成本下能活的是慢变量或台阶型的结构。

**本轮设计与选择理由**
- 没有用 pow_2_5(day_wmean(Volume, Volume)) 或 day_wmean(Volume, Volume) 做 E 核心:它们的共性表富集最高(+1.55),但股数成交量的秩与控制 liq(30 日 Amt 均值)、known(30 日 day_std(Amt) 均值)的相关估计在 0.8 上下,
  核心是控制换了写法的风险大(≥ 0.8 整个位作废,按规则 §3)。改用价格水平 P = ts_quantile_q75(day_close(Low), 10) 做核心:它是 head 1 的子树、共性表 +1.00(p 0.001)、与五个控制的秩相关估计 < 0.5。
- 位 1(E,核心 P):16 个种子,全部原样含 P;三组:(a) 纯价格带状 / 锯齿(V 形 c = 0.15 / 0.25 / 0.35;cs_last_low10 / 20 / 40(neg(P), P);EMA 平滑),(b) 与无水平的成交额集中度 H = day_wmean(Amt, Amt) / day_sum(Amt) 的交互
  (分桶内排名、乘积翻转、select_where 翻转、cs_last_low20(H, P)),(c) 对照 / 迁移(用 P 做垃圾屏的 20 日反转与低波动;带状在市值十分位内排名;10 日 vs 120 日价格水平之差)。
  风险:锯齿 / 交互类种子与 head 1、head 2 的日度秩相关可能 ≥ 0.7(被表划掉),预计会划掉 2 到 5 个。
- 位 2(N):开盘 / 收盘分钟成交额份额 O、C 与集中度 H 的 60 日累积,16 个种子里 15 个是份额型,1 个是对照(day_at_max_ratio 的 60 日均值)。
- R:共 16 个变体(上限):head 1 六个(Amt 化已测 +1.45、断点 10 / 40、分母幂 3、P 换 Open 40 日、Q75 嫁接),head 2 五个(Amt 化后动断点大小 / 断点价格 / y 的分位),head 3 五个(中位数、分母加常数、对数比、开盘份额、开盘减收盘份额)。
  R 要比原 head 高 0.1:head 1 需 ≥ 1.29,head 2 需 ≥ 0.93,head 3 需 ≥ 0.92。

**事先预测(请下一轮对照)**
- 位 1(E,P 带状 / 锯齿 / 交互):产出 head 的概率约 30%。若有,最可能是锯齿 / V 形带状(c = 0.15 到 0.25)或 cs_bucket_rank(·, P) 的变体,score 0.5 到 0.8,train 是瓶颈(valid 会在 +2 以上);
  半衰期 5 或 20。若纯价格带状是真的,三个 V 形种子里至少一个应 ≥ 0.3;若它们全部 < 0 而与 H 的交互种子活着,则说明起作用的是断点 × 成交量交互,价格带状的推断被否定。
  失败路径:种子被表划掉太多;或带状效应被市值 / 流动性的三次项吃掉,剩下的 < 0.3。
- 位 2(N,开盘 / 收盘份额):产出 head 的概率约 25%。若有,最可能是 O - C 的差、对数比、或在流动性十分位内排名的开盘份额(cs_bucket_rank 那个),score 0.5 到 0.7,train 好于或等于 valid 的可能性不大(又是 valid 更高)。
  对照种子 cross_mean(day_at_max_ratio(Close), 60):我预测它单独 < 0.3(涨停锁定名字买不到,尺子应当已处理可交易性),若它反而最高则 head 3 的来源是封板计数,而不是构成。
- R:head 1 至少一个变体 ≥ 1.29 的概率 90%(Amt 化已测 +1.45,会替换原 head);分母幂 3 与 P(Open, 40) 的变体各约 35% 超过 Amt 化版本;
  head 2 有变体 ≥ 0.93 的概率 35%;head 3 有变体 ≥ 0.92 的概率 25%(我预计中位数版最差,因为极端日正是信息所在,或者正是伪影所在,两者必居其一);
  有变体以 ρ < 0.5 被收录为新 head 的概率约 5%。
- 整轮:E / N 位至少一个出新 head 的概率约 45%;两个都出约 8%;原有 head 被替换(R)的概率 90%。
