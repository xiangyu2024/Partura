# Alpha 研究报告 — F109_erm_mag_gap_5m_tsm20

> 5 分钟收益的上尾 / 下尾超阈均值比之差的 20 日均值;分母上的 1e-6 把涨跌停封板日变成事件记忆

**数据**: 1942 个交易日 × 5220 只股票 (20180102–20251231) · 标签 `open_vwap15` h=1(可买入:剔除次日开盘封涨停) · 成本 15 bp/单位换手 · 前/后 10% · AlphaCube `1698296` · Partura `6c89c05560a5`

**数据段**: train 20180102–20211231 · valid 20220104–20230807 · utrain 20180102–20230807 · holdout 20230808–20251231 · full 20180102–20251231

> 决策用的数字:方向与 EMA 半衰期在 **train** 上定,在 valid 上确认。与用户表可比的数字:方向与半衰期在 **utrain**(用户的训练段)上定;holdout = 用户的测试段,只在最后读。

## 1. 原始表达式

```
ts_mean(sub(div(div(day_sum(select_where(is_gt(sub(div(Close, in_delay(Close, 5)), create_like(Close, 1)), day_quantile(Ret, 0.95)), sub(div(Close, in_delay(Close, 5)), create_like(Close, 1)), create_like(Close, 0))), add(day_sum(is_gt(sub(div(Close, in_delay(Close, 5)), create_like(Close, 1)), day_quantile(Ret, 0.95))), create_like(day_quantile(Ret, 0.95), 1e-06))), add(day_quantile(Ret, 0.95), create_like(day_quantile(Ret, 0.95), 1e-06))), div(div(day_sum(select_where(is_lt(sub(div(Close, in_delay(Close, 5)), create_like(Close, 1)), day_quantile(Ret, 0.05)), abs_(sub(div(Close, in_delay(Close, 5)), create_like(Close, 1))), create_like(Close, 0))), add(day_sum(is_lt(sub(div(Close, in_delay(Close, 5)), create_like(Close, 1)), day_quantile(Ret, 0.05))), create_like(day_quantile(Ret, 0.05), 1e-06))), add(abs_(day_quantile(Ret, 0.05)), create_like(day_quantile(Ret, 0.05), 1e-06)))), 20)
```

## 一句话

每天把 236 个 5 分钟收益分成上尾(> 当天 1 分钟收益 `Ret` 的 95% 分位)与下尾(< 5% 分位)两组,
各算「超阈均值 ÷ 该侧分位阈值」,两侧相减,再取 20 日均值。

## 关键的「名字骗人」之处

(照抄 `03_decomposition.md`,未重新推导)

- `in_delay(Close, 5)` 不跨日。
- 分位数阈值用的是 **1 分钟** `Ret`,而分子是 **5 分钟**收益(尺度错配)。
- `Ret` 首根恰好为 0 ⇒ 全天上涨分钟 ≤12 根时 `q95` **精确为 0** ⇒ 分母上的 `1e-6` 把涨跌停封板日炸成 10³~10⁵。
- `abs_` 只在下侧。
- 没有任何截面算子、不用量/额字段。

### 既往研究留下的先验

_(实验室里没有与这棵树相关的、来自**其他**研究的既往结论 —— 本研究自己的结论不算先验。)_

读源码(`study.sh src`,12 个算子逐个读过)时记下的、探针表里看不出来的事。凡是能量的都在 x1 里量过一次。

1. **`in_delay(Close, 5)` 不跨日**。内核按「每股票-日一行、241 列分钟」平移,每天的前 5 根是 NaN。所以 5 分钟收益
   `Close / in_delay(Close, 5) − 1` 每天只有 236 个值,开盘第一根不会和昨收比。
2. **`day_quantile(Ret, 0.95)` 是 `torch.nanquantile`(线性插值),但在这里没有插值**。`Ret` 的第一根恰好是 0
   (x1 实测:100% 的股票-日,等于首根收盘 / 首根开盘 − 1,**不含隔夜**),所以 241 根全有值,0.95 分位落在整数位置
   (0.95 × 240 = 228,即第 229 小的那一根)。它是一个顺序统计量:**只要全天上涨的分钟不超过 12 根,`q95` 就恰好是 0**;
   否则至少是一个 tick 的收益。x1 普查:`0 < q95 < 1e-4` 的股票-日占比是 0.0000。
3. **`is_gt` / `is_lt` 返回整型 0/1,NaN 参与比较得 0**。每天前 5 根(r5 为 NaN)既不进计数也不进求和;
   `select_where(mask, r5, 0)` 在 mask 为 0 的地方填 0,所以 `day_sum` 加的只是超阈分钟。
   `create_like(Close, 0)` / `create_like(Close, 1)` 的字面量是整数,生成的是 int64 张量,由 `torch.where` / 减法自动提升成浮点 —— 没有副作用。
4. **四个 `1e-06` 干的是两件不同的事**:
   - 计数分母上的两个(`add(day_sum(mask), 1e-06)`):只在「一次都没超过阈值」的日子起作用,把 0/0 变成 0。
     x1:这样的股票-日上侧 0.43%、下侧 0.61%,就是全天一个价的一字板。
   - 分位数分母上的两个(`add(q95, 1e-06)`、`add(abs_(q05), 1e-06)`):**这是整条因子的开关**。分位数恰为 0 时,
     这一侧的比值 = 超阈均值 / 1e-6,从 O(1) 跳到 10³~10⁵。
5. **阈值和分子不在同一个时间尺度上**。阈值、分母是 **1 分钟**收益的分位数,分子是 **5 分钟**收益超过这个阈值的部分的均值。
   它不是教科书里的 ES/VaR 比(那是同一个分布的尾部均值除以分位数):规则日每侧有约 34~37 根 5 分钟收益超阈(236 根里的 15%,而不是 5%),
   比值的中位数是 1.88 / 1.76(高斯随机游走下约 1.8)。
6. **`ts_mean(·, 20)` 与 `cross_mean(·, 20)` 是同一个内核**(`rolling_reduce` + `nanmean_last`,左侧补 NaN,因果)。
   nanmean 不截尾:窗口里有一个 10⁴ 量级的日子,它就占 Σ\|gap_d\| 的 99.9%(x1)。停牌日 `Ret` 全 NaN → 当日值 NaN,被 nanmean 跳过。
7. `abs_` 只出现在下侧:把下尾的 5 分钟收益和 `q05` 都翻成正的幅度,所以 `dn_ratio` 与 `up_ratio` 同为正数、可以相减。
   它不是空操作(去掉它下侧比值的分子分母都变号,比值不变,但 `add(q05, 1e-06)` 的 ε 方向会错)。

## 3. 数学分解

```
A = in_delay(Close, 5)
B = div(Close, A)
C = create_like(Close, 1)
D = sub(B, C)
E = day_quantile(Ret, 0.95)
F = is_gt(D, E)
G = create_like(Close, 0)
H = select_where(F, D, G)
I = day_sum(H)
J = day_sum(F)
K = create_like(E, 1e-06)
L = add(J, K)
M = div(I, L)
N = add(E, K)
O = div(M, N)
P = day_quantile(Ret, 0.05)
Q = is_lt(D, P)
R = abs_(D)
S = select_where(Q, R, G)
T = day_sum(S)
U = day_sum(Q)
V = create_like(P, 1e-06)
W = add(U, V)
X = div(T, W)
Y = abs_(P)
Z = add(Y, V)
AA = div(X, Z)
AB = sub(O, AA)
AC = ts_mean(AB, 20)
```

分解表里 29 个中间量,其实只有四个零件。记 `r5 = Close / in_delay(Close, 5) − 1`(5 分钟收益,每天 236 个),
`q95`、`q05` = 当天 **1 分钟**收益 `Ret` 的 95% / 5% 分位数:

```
up_mean  = Σ r5·1[r5 > q95]   / (#[r5 > q95] + 1e-6)        # 超过上阈的 5 分钟收益的均值
dn_mean  = Σ |r5|·1[r5 < q05] / (#[r5 < q05] + 1e-6)        # 低于下阈的 5 分钟收益的平均幅度
up_ratio = up_mean / (q95 + 1e-6)
dn_ratio = dn_mean / (|q05| + 1e-6)
gap_d    = up_ratio − dn_ratio                               # 逐日
因子     = nanmean(gap_d, 过去 20 个交易日)
```

容易被名字骗的三处:

1. **名字叫 `erm_mag_gap`(极端收益幅度之差),读起来像「上尾比下尾厚多少」**。在规则日上它确实是这个:`gap_d` 是 O(1),
   中位数 +0.11、四分位 −0.14 ~ +0.40。但在分位数恰为 0 的日子(涨跌停封板日,占股票-日的 0.8%)它是一个 10³~10⁵ 的数,
   符号由「哪一侧的分位数为 0」和「超阈的 5 分钟收益哪边大」决定 —— 那已经不是幅度之差,而是一个事件标记。
2. **爆炸的符号不区分涨停与跌停**。负向爆炸(`gap_d < −20`)的日子当日收益中位数是 +9.97%:它们是「一路爬升到涨停」的日子
   (下跌分钟不足 5% → `q05 = 0`;上涨分钟超过 5% → `q95 > 0`),只有下侧的比值爆掉。正向爆炸是「秒封」或开盘不久即封的日子
   (两个分位数都为 0,上涨的那几根 5 分钟收益远大于下跌的)。
3. **20 日均值不是平滑,是记忆**。对窗口里没有爆炸日的股票(92.8%),它是 20 个 O(1) 的数的平均;对有爆炸日的股票(7.2%),
   它就是那一天的值除以 20,并且在第 21 天断崖式掉回 O(1)。一棵树里有两种完全不同的统计对象。

规则日的解析基准(用来判断「比值高」意味着什么):1 分钟收益是方差 σ² 的高斯随机游走时,`q95 = 1.645σ`,5 分钟收益的标准差是 2.236σ,
`P(r5 > q95) = 23%`,`E[r5 | r5 > q95] = 2.95σ`,比值 1.79。实测超阈的分钟只有约 15%(34 / 236)、比值中位数 1.88:
真实的 1 分钟收益有大量恰为 0 的分钟(tick 离散)和厚尾。比值偏高的方向有三个来源 —— 1 分钟收益正自相关(趋势)、跳跃、
以及 1 分钟收益的中心更尖(零收益多,`q95` 相对 σ 更小)。前两个是「彩票 / 拉升」特征,第三个是低价 / 不活跃特征。

## 4. 结构语法

这棵树的语法是「阈值 → 超阈均值 → 除以阈值 → 上减下 → 日轴均值」,只有一个日轴算子:

```
分钟价 Close ──> 5 分钟收益 r5(日内平移,不跨日)
1 分钟收益 Ret ──> 当天的 95% / 5% 分位数 q95, q05          (每股票-日一个数;顺序统计量)
        ├─ 上侧:r5 超过 q95 的那些分钟 -> 均值 -> 除以 (q95 + 1e-6)      = up_ratio
        └─ 下侧:r5 低于 q05 的那些分钟 -> 平均幅度 -> 除以 (|q05| + 1e-6) = dn_ratio
                上侧 − 下侧                                              = gap_d(逐日)
                        -> 过去 20 个交易日的 nanmean                    = 因子
```

读这棵树要记住的结构性事实:

1. **全部在股票自己的时间序列里**:没有任何截面算子,没有成交量 / 成交额字段。它只看价格路径的形状。
   所以它和成交额水平家族没有结构上的通道(实测 rank 相关 −0.03)。
2. **每一侧都是「不带尺度的比值」**(分子分母都是收益,齐次度 0),于是整条因子对波动水平不敏感 —— 直到分母为 0。
   ε = 1e-6 把一个不带尺度的量变成了「分母是否为 0」的开关,而分母为 0 只发生在封板日。
3. **减法假设上、下两侧携带相反的信息**。x1 量到的是:两侧单独的方向相同(都是比值越高越跑输),
   两种符号的爆炸之后也都跑输。减法因此做了两件对多头腿不利的事:丢掉两侧共同的水平;把负向爆炸的票送到多头端。
4. **记忆在树里,而且已经很长**:20 日均值之外,多头口径选到的 EMA 半衰期还是上界 20 —— 信号越慢越好
   (rank IC 随预测期从 h1 的 0.0196 升到 h20 的 0.0445)。窗口从 5 换到 60,原式的两本书基本不变(x1)。

## 解读

1. **结构确实能把多头腿抬上来,但抬不到可交易。** 同一半衰期 hl 20 下,把 `sub` 换 `add` 值 +5.4 个点
   (−4.6% → +0.8%),把两个分位数分母整段换成 `day_std(Ret)` 值 +6.9 个点(−4.6% → **+2.3%**)。
   这是真的结构改进,不是平滑(所有数字都在同一半衰期上读)。但最好的那条绝对水平只有 +2.3%、纯多头夏普 **0.31**,
   而第二条基准(已知家族 `cross_mean(day_std(Amt),30)`)是 **+12.6% / 1.78**。**差了一个数量级,不是调参能补的。**
2. **而且那 +2.3% 是一年。** `a_sig` 在 train 的四年里是 +11.1% / +0.1% / −1.0% / −1.6% —— 2018 一年撑起了全部,
   另外三年是零。`a_sum` 更干脆:四年全部在 ±2% 以内,它在 valid 的 +9.6% 全部来自 2022–2023。
   (同期 `ctl_price` 自己 valid +11.3%、`ctl_turnrate` +8.2%、`ctl_dvol20` +0.6% —— 2022–23 是低价低波风格年,
   见 `S0_baseline` 的「控制变量自己当因子」表。)**这两条变体的多头腿没有一年是靠自己赚的。**
3. **ε 不是排序开关,只是幅度开关 —— 这一条推翻了 H1 的事前写法。** `a_eps3` 把封板日的 10³~10⁵ 压回 O(1),
   结果空头腿**更高**(+39.5% / +36.3% vs +34.4% / +28.4%),rIC **更高**(0.0394 / 0.0435 vs 0.0306 / 0.0298),
   与原式 rank 相关仍有 0.75。`a_sig` 连分位数分母都没有,空头腿 +40.4% / +44.1%,更高。
   → 爆炸的**幅度**无关紧要:封板日的票无论值是 10⁴ 还是 2,都排在截面的同一端。
   **起作用的是「哪一天被标成事件」这个集合,不是 ε 把它放大到多少。**
4. **「一路爬升到涨停」的票被减法送进多头端(H11)值 4~6 个点,但不是多头端翻转的全部原因。**
   `a_sum`(不减)把 Q10 从 −3.6% 抬到 +2.7%,量级与 x1 事前估的 5.5 点吻合;但 Q10 仍然低于 Q9(+9.9%)。
   `a_up`(整个下侧都不要了,负爆炸根本不存在)Q10 +1.4% 对 Q9 +11.2%,翻转照旧;`a_eps3`(没有爆炸)也照旧。
   → **翻转是这一族「尾部比值取极值」本身的性质**,不是减法造成的;修掉减法只拿回其中一部分。
5. **尺度错配不是缺陷,是必需品(H7)。** 把它改写成同尺度的标准 ES/VaR 比(`a_q5`)或 1 分钟版(`a_1m`),
   rIC 从 0.0306/0.0298 掉到 0.0191/0.0130 和 0.0188/0.0112(**砍一半**),多头腿反而比原式更差,
   valid 上双双转负。两者改变的都是「事件日集合」(5 分钟收益为 0 的分钟更少、1 分钟分子不再放大),
   → 又一次指向同一结论:**这棵树的全部信息是「哪些天发生了单边封板」,外面那层尾部比值只是探测器。**
6. **`a_evt` 把这件事说到极致。** 只数「过去 20 天里 q95=0 或 q05=0 的天数」—— 一个取值只有几档的整数计数
   (`dist` 0.0153,过不了用户的 0.5 门槛,只能当诊断)—— 扣费多空夏普 **+3.93**(train,原式 +2.55)、
   空头腿 **+44.9%**(原式 +34.4%),是全部十个变体里空头腿最高的。
   **原式那套 29 个中间量的分位数比值,在空头腿上不如一个封板计数器。**
7. **下侧是纯拖累。** `a_dn` 单独 rIC 0.0160/0.0169(最低)、空头腿 +21.7%(最低)、与原式相关仅 0.15;
   `a_up` 单独就有 rIC 0.0379/0.0382、空头腿 +41.1%。差值结构里下侧贡献的是噪声和那批被放错边的爬升型涨停票。
8. **越修越像已知家族。** `a_sig` 与 `b_skew5`(5 分钟收益偏度的 20 日均值)rank 相关 **+0.85**、
   与 `b_sig60`(它自己的 60 日版)+0.92、与 `b_skew1` +0.66、与 `b_max20`(20 日最大单日涨幅)+0.51;
   `a_eps3` 与 `b_skew5` +0.81。→ **H12 成立**(判据是 ≥ 0.5):把 ε 和分位数分母换掉之后,
   剩下的就是**已实现偏度**,一个两算子就能写出来的东西。这也省掉了原计划的 `S2_family` 整轮运行。
9. **条件 IC 直接回答了「对家族有没有增量」**:`a_sig | known_stdamt_mean30` 从低到高是
   0.0171 / 0.0149 / 0.0232 / 0.0332 / **0.0428**,`a_sum` 是 0.0115 / 0.0147 / 0.0251 / 0.0331 / **0.0415** ——
   都随家族值单调上升。而家族的方向是 `−`,**它的多头端在最低那一组**,恰恰是这两条变体最弱的地方
   (0.0171 / 0.0115)。和原式 `v_base | ctl_amt`(0.0056 → 0.0398)是同一个形状。
   → **这棵树住在活跃、波动大的票里;家族的多头腿住在最安静的票里。两者的多头书没有交集。**

## 这一阶段裁决了哪些假设

- **H1 改写**:两本书靠的是「事件日集合」的身份,不是 ε 放大的幅度,也不是尾部形状(证据 3、5、6)。
- **H11 改写**:机制成立(值 4~6 点),但修正后多头腿 +0.8%、夏普 0.13,**按事前判据(≥ +5% 算成立,< +3% 算修不出钱)判定为「修不出钱」**(证据 1、2、4)。
- **H7 成立**(并反向加强):尺度错配是必需的(证据 5)。
- **H12 成立**:规则部分 = 已实现偏度族,相关 0.85 / 0.92(证据 8)。
- **H4 扩展到多头腿**:见 `07_neutralise.md` —— `a_sig` 的毛多头腿 +4.3% 对 `ctl_amt` 取残差后 −0.5%、对 `ctl_dvol20` 后 −0.1%。
- **H9 支持**(证据 9):条件 IC 的形状说明它与家族的多头书不重叠,但重叠的方式是「它在家族不买的地方才有信息」。

出处:tag `S1_lvl` 的 `S2_level` 阶段(`b_lvl`、`b_lvlq`),结果卡 `results/R1.md` A 组第 1/2/5/8/9/11 项。

## 问题

x1(numpy)里多头腿最好看的一族不是差值而是**水平**:「规则日 up+dn」train/valid = +3.6% / +11.7%,
而 `ctl_price` 自己就是 +3.9% / +11.3% —— 几乎一模一样。

## 解读

1. **H13 的字面说法被否定:它不是低价股效应。** 与 `ctl_price` 的相关只有 −0.32 / −0.00,
   对价格中性化之后残差 rIC 几乎不掉(0.0240 → 0.0229;0.0368 → 0.0365)。
   x1 里「水平」与 `ctl_price` 数字撞车(+3.6%/+11.7% vs +3.9%/+11.3%)是**巧合**:
   valid 段上任何低价、低波、低换手的暴露都给 +8%~+12%,所以数字相像不等于是同一个东西。
   (条件 IC 倒是说它在高价股里失效:0.0246 → 0.0065。这是价格依赖,但不是「它就是低价因子」。)
2. **H13 改写为:水平的那点多头腿是低波 / 低活跃暴露,而那正是已知家族自己的轴。**
   `ctl_dvol20` 一个变量就吃掉 R² 0.286,残差 rIC 从 0.0240 掉到 **0.0012**(掉成零);
   全套控制 R² 0.460、残差 rIC 0.0005。与 `known_stdamt_mean30` 的相关 −0.40
   (家族方向是 `−`,所以这是两条**交易信号**同向 +0.40)。
   → 水平这条路通向的不是一条新因子,而是**已知家族的一个更差的写法**。
3. **按选拔口径它根本选不出来。** 方向与半衰期在 train 上定:`b_lvl` train 多头腿 **+0.1%**、纯多头夏普 **+0.02**;
   `b_lvlq` **−4.1% / −0.44**。valid 的 +12.0% / +8.7% 是 train 定好参数之后在 2022–23 风格年上的读数,
   逐年表把它拆开了:`b_lvl` 在 train 四年是 +6.2% / −4.2% / −7.4% / +5.6%(符号来回翻),
   全部的好看数字在 2022(+15.6%)。**这不是一条可以按 train 选出来再指望它继续工作的因子。**
4. **归一方式本身不重要(这是 `b_lvlq` 存在的理由)。** 两种归一(除 σ / 除分位数)的 rIC 和空头腿形状同级,
   `b_lvlq` 的 rIC 甚至是全部十个变体里最高的(0.0485 / 0.0686),但它的 train 多头腿是 −4.1%。
   → **rIC 高与多头腿能赚钱是两件事**,这条因子身上到处都是这个教训(`b_lvlq` rIC 最高、多头腿最差;
   `a_evt` rIC 中等、多空夏普最高、dist 门槛过不了)。
5. 顺带:`b_lvlq` 的**原始面板**对全套控制的 R² 是 **0.608** —— 平滑之前它有六成方差就是标准暴露。

## 裁决

- **H13 改写**(不是「低价股效应」,是「低波/低活跃暴露 = 已知家族的轴」),结论是一样的:**水平这条路关掉**。
  判据的两条腿分开落地了(相关 −0.32 < 0.5 不支持字面假设;残差毛多头腿 +0.3% ≤ +1% 支持「没有自己的东西」),
  所以我按**第二条腿**定,并把假设的名字改对 —— 证据在上面第 1、2 条。
- `b_lvl` / `b_lvlq` **不进推荐候选**;`b_lvl` 作为「valid 上多头腿最好看的一条」带进留出段当记录
  (判据写在 `10_distilled.md`:如果它在留出段上又给出 ≥ +10%,那我「这是风格不是信号」的解读就要写成未决)。

# 07_neutralise —— 中性化表怎么读,以及它说了什么

出处:`S1_lvl.json` 的 `diagnostics.neutralise`(`a_eps3`、`a_sum`、`a_sig`、`b_lvl`、`b_lvlq`,结果卡 R1 A 组第 8 项)

## 读这张表的硬规矩(digest 自己也印了这句话)

> 残差**不再平滑** → 残差换手更高,净值类指标可能只因成本而塌,alpha 还在不在看 **rIC / 毛超额**。

数字上这件事有多大:`b_lvlq` 未中性化换手 1.8%、对 `ctl_range` 取残差后 **43.4%**;净超额从 −4.1% 掉到 −34.2%。
那 −34.2% 里几乎全是交易成本,**不是** alpha 的消息。**所以下面只引毛多头腿(Lgross)和残差 rIC。**
(另外:这张表与 `x2_incremental` 里「残差当新因子重新定方向半衰期」的那张**不是同一件事**,不要互相对照,
见 `07x_2_incremental.md`。)

## 解读

1. **这棵树那点多头腿是活跃度 / 波动暴露,不是新东西(H4 从空头腿扩展到多头腿)。**
   最好的变体 `a_sig` 毛多头腿 +4.3%,对 `ctl_amt`(成交额水平)一个变量取残差后 **−0.5%**,
   对 `ctl_dvol20`(20 日日频波动)后 **−0.1%**,全套控制后 +0.7%、残差 rIC 从 0.0359 掉到 0.0137。
   **一个控制变量就能把它抹平** —— 这就是「它是不是已知暴露的另一种写法」的答案:在多头腿上是。
   (对照:空头腿这件事 x1 早就定了,全套控制 R² 0.169、空头腿 +17.3% → −0.5%。)
2. **`b_lvl` 更彻底**:`ctl_dvol20` 一个变量把残差 rIC 打到 **0.0012**(从 0.0240),全套控制打到 0.0005。
   它本质上就是一条低波暴露。
3. **唯一一个方向相反的读数:对 `ctl_cap` 取残差后毛多头腿反而大涨。**
   `a_sum` +2.1% → **+8.6%**(净 +0.8% → +7.3%,换手只从 1.8% 到 2.1%,LS +1.44 → +2.80);
   `a_sig` +4.3% → +6.3%;`a_eps3` +1.1% → +4.7%;`v_base` −3.5% → −1.0%。
   这一族的多头端有一个 **+0.26 ~ +0.32 的 log 流通市值正暴露**(大市值倾斜),去掉之后多头端换人、数字变好。
   **但我把它判为「合理但未坐实」,不追**,四条理由:
   - 这张表**只在 fit 段(train)算**,没有 valid 的对照数字 —— 一个单段读数;
   - **残差 rIC 几乎没变**(`a_sum` 0.0276 → 0.0285):排序质量没提高,变的只是十分位的成分,
     而这条因子的十分位本来就极不稳(`v_base` Q9 +5.0% / Q10 −3.6%);
   - `ctl_cap` 自己当因子在 train 上是 +0.6%(大市值几乎不输),所以「去掉逆风」解释不了 +6.5 个点,
     真正的解释只能是分组内选股的交互 —— 而这需要专门的实验,不是这张表能定的;
   - `ctl_cap` 是**外部控制变量**(`shared/log_float_cap.npy`),**写不进表达式**,
     所以即使成立也不是一条可直接交易的因子,而是「在规模分组内选股」的构造提示;而且 +7.3% 仍然低于家族的 +12.6%。
   → 写进 `12_next.md`:要追就是一次 exec,量「秩空间对 log 流通市值取残差之后,`a_sum`/`a_sig` 在 **train 和 valid** 上的
   多头腿,以及它与家族相加的配对差」。这一轮不花这次运行,理由是上面第四条(天花板低于基准)。
4. **`ctl_turnrate` / `ctl_range` / `ctl_ivol` 那几行的净超额不要引用**:残差换手 15%~43%,
   −10% 到 −34% 的净超额是成本,不是信息。

## 解读

1. **原式本身对家族是负增量,而且是显著的负。** 加 0.3 份原式,配对差 −2.0% / −2.4%(t −2.64 / −2.52);
   加 1 份 −4.4% / −3.3%。规则版 `REG` 一样(−1.8% / −2.4%)。
   两段同号、t 都过 2 —— **「加进去会把家族的多头腿拖坏」这件事是坐实的**,不是噪声。
   机制清楚:它的多头端本身是坏的(Q10 翻转),把它掺进家族的排序就是把坏名字换进前 10%。
2. **残差多头腿是零。** 对家族取残差后 `BASE` −0.3% / −0.0%、`REG` +0.5% / −0.7%。
   R² 只有 0.01~0.02(两者几乎正交,rank 相关 −0.03),所以残差 ≈ 原式自己 —— 而原式自己没有多头腿。
   **正交但没有多头腿 = 对纯多头的人没有价值。**(正交本身不是优点,这是本因子最该记住的一条。)
3. **唯一正向的一块是「事件记忆」,而且它的量级低于事前写死的门槛。**
   `FAM30 + 0.3·EVT` 是九个组合里唯一在 train 与 valid **同时**显著为正的:+1.0% / +0.8%,t +3.27 / +3.03。
   方向、量级两段几乎一样,这不是噪声。
   **但事前判据要的是「t ≥ 2 **且** 增量 ≥ +2 个点」,实测 +1.0% / +0.8% 只有门槛的一半 → 判据没过。**
   我按事前写死的判据执行:**H14 成立(增量在实质性门槛之下),这一块不升级为推荐、也不带进留出段。**
   (这是刻意的纪律选择,不是漏看。理由另见第 5 条;后续怎么追写在 `12_next.md`。)
4. **机制读得通,形状也对。** 家族的多头十分位里 1.94%~6.78% 的格子是近 20 日封过板的票,
   而这类票次日起年化跑输 −35% ~ −56%(x1 的事件研究)。把它们换掉:train +3.5%(t +2.68)、valid +0.6%(t +2.13)。
   `w` 的邻域是一个**驼峰**:w=0.1 太弱(+0.2%)、w=0.3 顶点(+1.0%)、w=1 又回到 0(+0.1%)——
   因为 `EVT` 自己的多头腿是 −3.5%,掺多了反而拖。驼峰是**理论预期的形状**,不是调参痕迹;
   但顶点只有 +1 个点,而两段的量级差 3.5 倍(占比 6.78% vs 1.94%,剔除收益 +3.5% vs +0.6%)——
   **增量的大小取决于那一段里封板票有多密**,这不是一个稳定的参数。
5. **为什么不为这 +1 个点再花一次运行**:(i) 事前判据明确没过(+1.0 < +2);
   (ii) 它现在只有 numpy 口径,`EVT` 还没有引擎表达式,要带进留出段就得先建表达式、再确认它复现 numpy 的 −3.5%/−3.3%,
   这是一次运行 + 一轮;(iii) 它改进的是**家族**,不是这条因子 —— 把它写成结论会把「F109 分辨」讲成「F109 有用」,
   归因就错了;(iv) 留出段只能读一次,5 个候选位要留给能**推翻主结论**的东西。
   → 它写进 `09_diagnosis.md` 的「已确立」(数字和 t 都在),同时写明「低于事前门槛,未推荐、未在留出段上验证」。

## 口径上的两处要注意(接手的人别踩)

- **(a) 那张残差表和引擎的 `diagnostics: neutralise` 不是同一件事**:引擎那张只对已经定好方向半衰期的交易信号中性化、
  只看 fit 段、残差不再平滑;x2 这张是把残差当一条全新因子从头走一遍(重新定方向、重新定半衰期、两段都算)。
  两张表不要互相当一致性检查。`EVT` 残差 −14.4%/−14.7%(sign 翻成 +1)就是这条流水线作用在一张 93% 是 0 的面板上的产物,
  **不可解读**,执行在结果卡里也标了「只报数字,不猜原因」。
- **(b) `EVTFLAG` 用的是 `THR=1e-4` 的近似退化判据**,不是严格浮点 `==0`;执行在结果卡里问过这件事。
  严格 `==0` 会让占比数字变小(x1 实测 `q95==0` 0.72%、`q05==0` 0.79%、\|gap_d\|>20 0.49%)。
  我的答复:**近似口径是对的**,因为 `REG` 的 NaN 条件与 `EVTFLAG` 的旗标条件必须是同一件事,才能让 (b)(c) 两张表自洽;
  而且 1e-4 ≈ 一个 tick,正是「分位数为 0」在浮点里的现实边界。占比的绝对值因此略高,**不影响配对差和 t**。

# 09_diagnosis —— 机制诊断:已确立 / 合理但未坐实 / 未决

写于主研第 5 轮(2026-10-04),留出段已读完。
分级标准:**已确立** = 两段以上数据同号、或留出段确认、或有自检过的直接测量;
**合理但未坐实** = 只有一段 / 一个读数,方向明确但没有判别性实验;**未决** = 证据不足,且本研究不再追。

这条因子**是什么**(一句话机制):它把每天 236 个 5 分钟收益的上尾超阈均值、下尾超阈均值
各自除以当天 1 分钟收益的 95% / 5% 分位数,相减,再取 20 日均值。
由于 `Ret` 的第一根恰好为 0,**涨跌停封板日的分位数精确为 0**,四个 1e-6 里有两个让那天的值炸到 10³~10⁵,
一次爆炸就占 20 日窗口 Σ|gap_d| 的 **99.9%**。所以它实际上是**「最近 20 天有没有发生过封板事件」的一个带符号的记忆**
(出处:`02_operators.md`、`03_decomposition.md`、`07x_1_anatomy.md`;numpy 重构与引擎面板 rank 相关 **1.0000**)。

## 判据(留出段出现什么结果算「我错了」)

口径说明:`final` 会按**用户口径**给数字 —— 方向与半衰期在 **utrain**(2018-01-02~2023-08-07)上定,
留出段(2023-08-08~2025-12-31)= 用户的测试段。所以下面一律指 `books_user` 的 holdout 行。
噪声尺度(playbook §4.6):多头腿净超额 ±3 个点、纯多头夏普 ±0.3。

- **判据 B(前置可信性检查,先看这一条)**:`f_fam30` 的留出段多头腿净超额落在 **+10% ~ +18%**、纯多头夏普 **≥ 1.1**
  (用户表给的区间是 +13%~+15%、1.4~1.9,这里按 ±3 点 / ±0.3 放宽)。
  → 若 `f_fam30` 自己在留出段上塌了(净超额 < +5%),则**整张表都不可比**,报告只能写
  「留出段上家族本身失效,无法据此判断这条因子的相对位置」,其余判据作废。
- **判据 A(主结论:多头腿不可用)**:预测 `f_orig` 的留出段多头腿净超额 **< +5%** 且纯多头夏普 **< 0.5**。

(+2.95% vs +2.88%)。两种写法在留出段上收敛到同一个数。**「减法是缺陷」这个判断只在样本内成立** ——
H11 的改写版(机制成立、修正无交易价值)由此从「train 单段」升级为「两段都证实」。

### 留出段最硬的一条新事实:空头腿毫发无损,多头腿两段都在 0 附近

多空口径(`by_rank['ls']`,在 **hlS** 上定,= 用户最早那张表的口径;出处 `runs/.../S_final.json`,
**注意不是 `results/R2.md` 第 3 节那张表** —— 那张表的数字是在 hlL 上算的、标签写成了 hlS,见 `08_variants.md` 第 5 条):

| 候选 | hlS | LS utrain | **LS holdout** | 空头腿毛超额 utrain | **空头腿毛超额 holdout** |
|---|---|---|---|---|---|
| `f_orig` | 1 | **+2.766** | **+2.276** | +32.71% | **+32.86%** |
| `f_sum` | 0 | +2.712 | +1.974 | +37.09% | +37.27% |
| `f_sig` | 1 | +2.475 | +1.957 | +41.47% | +43.42% |
| `f_fam30` | 0 | +2.334 | +1.942 | +24.73% | +24.93% |
| `f_lvl` | 1 | +1.390 | +0.891 | +24.90% | +22.47% |

两件事一起看,这条因子的性质就定死了:
1. **原式的空头腿在留出段一点没衰减**(+32.71% → **+32.86%**),多空夏普 **+2.276 是五条候选里最高的**,
   高于家族的 +1.942。**它是一条真实的因子 —— 只是真的那一半在空头腿,而用户做不了空头腿**
   (且据 H3,这条空头腿有一半是「次日一字开盘买不进」撑出来的,多空 2.55 → 0.35,`07x_1_anatomy.md` §4)。
2. **所有「修正结构、把多头腿做出来」的动作,在多空口径上一律把原式拉低**:utrain 2.766 → 2.475 / 2.712 / 1.390;
   holdout 2.276 → 1.957 / 1.974 / 0.891。而它们在多头口径上造出来的 +3~5%(utrain)在留出段消失或翻负。
   → **没有任何一个结构方向同时改善两本书。提纯没有产物,不是「还没找到」,是方向本身不存在。**

## 推荐(事前第一推荐,未被否定 → 维持)

**结论:分辨。** 本因子没有可推荐的提纯 / 升华产物。
**第一推荐 `f_fam30` = `cross_mean(day_std(Amt), 30)`** —— 留出段 **+14.10% / 夏普 1.509**,
八年逐年全正(最差 2020 年 +6.60%)。**它不是这条因子的产物**,它是「这条因子对纯多头的用户没有增量,
继续用你已有的成交额波动家族」这个结论的载体。

### 为什么没有更好的(playbook §5 要求回答)

1. **第一条基准都过不去**:原式 + 多头最优半衰期 = train −4.6% / 留出段 +2.88%;
   同一半衰期(hl 20)下最好的结构变体只有 +2.3%(`07_S1_nodes.md`),差家族一个数量级。
2. **留出段上三条结构候选全部败给家族 11~16 个点**(判据 C),两条翻负。
3. **对家族无增量**:秩相加显著拖累(t −2.64 / −2.52)、对家族的残差多头腿 −0.3% / −0.0%
   (`07x_2_incremental.md`);唯一正向的一块(家族 ⊕ 0.3 份事件记忆,+1.0% / +0.8%,t +3.27 / +3.03)
   **低于事前写死的 +2 点门槛**,按预注册不升级,追法转入 `12_next.md`。
4. **它本来就是别人的影子**:`a_sig` ~ 5 分钟已实现偏度 20 日均值 rank 相关 **+0.85**、~ 自己的 60 日版 +0.92(H12)。
5. **rIC 高 ≠ 能赚**:留出段 rIC 最高的是 `f_sig` **+0.0579**(高于家族的 +0.0503),它的多头腿是 **−2.33% / −0.204**。
   这是本研究留给下一条因子的最贵的一句话。

## 11. 失效模式与风险

# 11_risks —— 失效模式

写于主研第 5 轮(2026-10-04),留出段已读完。
本研究的结论是**分辨**(不推荐本因子的任何产物),所以下面分两类:

## 甲、这棵树自己的失效模式

### 1. 空头不可实现(最致命的一条)

这条因子的钱**全在空头腿**:多空夏普 utrain +2.766 / holdout +2.276(五条候选里最高),
空头腿毛超额 utrain +32.71% / holdout +32.86%;而多头腿两段都在 0 附近(−3.21% / +2.88%)。
用户做的是 **A 股纯多头**,这条腿**根本不能下单**。
把一条 2.28 夏普的多空因子拿去只做多头腿 = 拿到 +2.88%、夏普 0.71,还不如什么都不做改用家族(+14.10% / 1.509)。

### 2. 空头腿本身有一半是测量假象

换成不带「次日可买入」过滤的原始标签,多空夏普 **2.55 → 0.35**、空头腿 +34.4% → +18.1%
(`07x_1_anatomy.md` §4)。**封板日之后次日一字开盘,信号最强的那些票是建不了仓的。**
所以上面那个 2.276 的多空夏普,即使在允许做空的市场里也要先打对折。
→ 报告里引用任何多空数字,都必须带上这句话。

### 3. 数值量级不稳定(尺度污染)

四个 1e-6 里有两个落在分位数分母上。因为 `Ret` 的第一根恰好为 0(100% 的股票-日),
**封板日的分位数精确为 0、没有插值**,那天的 `gap_d` 炸到 10³~10⁵;
20 日窗口里一个这样的日子占 Σ|gap_d| 的 **99.9%**(`07x_1_anatomy.md` §2)。
后果:(a) 这条因子的数值**不是一个有量纲含义的比值**,是一个事件指示器乘以一个随机大数;
(b) 任何人改动数据频率、分位数插值方式、或 `Ret` 首根的定义,**这条因子会变成另一条因子**;
(c) 做任何线性运算(加权、取残差、相加组合)之前**必须先转秩**,否则一个爆炸日就吃掉整个组合。

### 4. 已知暴露(不是新信息)

- `a_sig`(本树最好的结构变体)~ 5 分钟已实现偏度 20 日均值 rank 相关 **+0.85**、~ 自己的 60 日版 **+0.92**。
- `a_sig` 毛多头腿 +4.3% → 对成交额取残差 **−0.5%**、对 20 日波动取残差 **−0.1%**、全套控制 +0.7%。
- `b_lvl`(「水平」写法)残差 rIC 0.0240 → **0.0005**(全套控制)/ **0.0012**(仅 `ctl_dvol20`)。
→ **谁用它,就是在用已实现偏度 / 低波低活跃暴露的一个更差写法。**
⚠ 中性化那张表**只能看毛超额和残差 rIC**:残差不再平滑,换手从 2% 跳到 13~43%,净超额只是被成本吃掉
(`07_neutralise.md` 第 4 条列了不能引用的行)。

### 5. 容量与成本不是约束(但别把这当优点)

原式换手极低(留出段 LTO **1.44%**),成本只吃掉 1.09 个点(毛 +3.97% → 净 +2.88%)。
**低换手不是优点,只是因为信号 20 天才换一次事件标签。** 家族换手 2.83%、净 +14.10%。

### 6. 制度依赖:判据 F 的后半在 2024 年被否定(事前就写了「有一年反过来就写进这里」)

| 年 | `f_fam30` | `f_sig` | `f_sum` | `f_lvl` |
|---|---|---|---|---|
| 2024 | +9.17% | **+8.84%** | **+9.99%** | **+11.06%** |
| 2025 | +14.32% | −12.66% | −1.92% | −11.97% |

**2024 年三条结构候选全部 >+5%(事前预测它们都 <+5%),其中两条还高于家族自己。2025 年全部大幅转负。**
八年逐年的正年数:家族 **8/8**(最差 2020 年 +6.60%);`f_sum` 6/8、`f_sig` 5/8、`f_lvl` 5/8、`f_orig` **3/8**
(2022 **+0.38%**、2024 +4.65%、2025 +3.32%;⚠ 原写 2/8,漏数了 2022 那个 +0.38%,由 `results/R3.md` 第 2 项(1)核对改正)。
八年算术均值(我按 `results/R2.md` 第 5 节逐年表自己加的,执行请复核):
家族 **+14.9%**、`f_sum` +3.1%、`f_sig` +2.5%、`f_lvl` +2.0%、`f_orig` −1.5%。
**风险的写法**:如果谁的持有期正好落在 2024 那样的一年,这几条结构候选看起来和家族一个量级 ——
但那是**事后才知道**的,而且紧接着的 2025 年它们是 −2%~−13%。
**年度符号不稳定本身就是「它们是风格暴露、不是 alpha」的体现**,并且它们**也不是分散工具**
(均值只有 +2~3%,留出段整段两条为负)。

### 7. 过拟合的直接证据(这条是给将来读报告的人看的)

- `f_sig`:utrain +4.76% / 0.666 → holdout **−2.33% / −0.204**。
- `f_lvl`:utrain +3.55% / 0.389 → holdout **−1.22% / −0.104**。
- `f_sum` − `f_orig`:utrain **+6.57pp** → holdout **+0.06pp**。
**在 train/valid 上「把结构修好」拿到的 +3~6 个点,在留出段上一个都没剩。**
这是本研究最值得带走的一条经验:**结构变体之间的几个点差异,在这个量级上基本都是样本内噪声。**

## 1.(最值得做)「从已知家族的多头端剔掉封板事件票」—— 独立一条研究

**要回答的**:用户已经在用的 `cross_mean(day_std(Amt), 30)`,它的多头十分位里混着一批
「最近 20 天封过板」的票;把它们换掉,能不能稳定地多赚 ≥2 个点?

**已有的证据**(全部在 `07x_2_incremental.md`,秩空间 numpy,train/valid 两段):
- 直接剔除事件票再补位:train +12.6% → **+16.1%**(配对差 +3.5%,t +2.68)、
  valid +22.3% → **+22.9%**(+0.6%,t +2.13)。
- 秩相加版 `FAM30 + 0.3·EVT`:+13.7% / +23.1%,对家族的配对差 **+1.0% / +0.8%,t +3.27 / +3.03**;
  权重邻域是驼峰(0.1 → +0.2% / t 1.04;0.3 → 顶点;1.0 → +0.1% / t 0.12)。
- 事件票在家族多头十分位里的占比:train **6.78%** / valid **1.94%**。

**为什么没在 F109 里做完**:量级 +1.0% / +0.8% 低于事前写死的 +2 点门槛(H14 的判据),
而且它改进的是**家族**、不是 F109;写进 F109 的推荐会把归因讲错。

**怎么做(省得下一个人重新推)**:
- `EVT` 的引擎写法 =
  `cross_mean(select_where(is_gt(abs_(G), create_like(day_quantile(Ret,0.95), 20)), G, create_like(day_quantile(Ret,0.95), 0)), 20)`,
  其中 `G` = 原式里 `ts_mean` 里面那一整坨(即 `gap_d`)。
- 组合用**整数权重**避开常数踩坑:`3·cs_rank(FAM30) + cs_rank(EVT)` ≡ `rank + 0.333·rank`
  (EMA 是线性的,正数缩放不改序),写成
  `add(add(add(cs_rank(FAM30),cs_rank(FAM30)),cs_rank(FAM30)), cs_rank(EVT))`。
- **第一步先自检**:它能不能复现 numpy 的 `EVT` 多头腿 −3.5% / −3.3%(hl0,多空 +3.45 / +3.39)。对不上就先停。
- **新增的一条提示(留出段给的)**:家族自己在留出段是 **+14.10% / 1.509**,2024 +9.17%、2025 +14.32%。
  所以这条研究的判据应该直接写成「剔除版在留出段 ≥ +16%」,而不是只看配对差的 t。

**什么结果算有用**:两段配对差都 ≥+2 个点且 t ≥2 → 值得带进它自己的留出段。
train 与 valid 量级差 6 倍(+3.5pp vs +0.6pp)是已知的隐患,**必须逐年看**,别被 train 的 +3.5pp 带走。

## 2.(可做可不做)对市值取残差的那条

**要回答的**:`a_sum` 毛多头腿 +2.1% → 对 `ctl_cap` 取残差后 **+8.6%**(净 +7.3%,换手仍 2.1%)——
这是整张中性化表里**唯一反方向**的读数,是真的吗?

**现状**:只有 fit 段一个读数;残差 rIC 没变(排序没变好,只是十分位换人);
`ctl_cap` 是外部 npy、**写不进表达式**;天花板 +7.3% 仍低于家族 +12.6%。四条理由在 `07_neutralise.md` 第 3 条。

**怎么做**:一次 `exec`,量 train **和 valid** 两段 + 与家族相加的配对差。
**什么结果算有用**:两段都 ≥+7% 且与家族相加不拖累 → 才值得往下走。否则就是 fit 段的一次性读数。
**优先级低的原因**:即使全对,天花板也在家族之下,而用户已经有家族了。

## 3.(低优先)原式多头腿 2023-08 之后的符号翻转

**要回答的**:原式多头腿 utrain −3.21% → holdout **+2.88%**(2024 +4.65%、2025 +3.32%),

## 4.(给总领的一条,不是实验)把 F109 的结论用在同族因子的筛选上

F109 的诊断是:**事件型(封板/涨跌停记忆)手写因子 → 钱在空头腿 → 对 A 股纯多头用户不可用**。
手写库里的其它 `erm_*` / `gap_*` / 事件记忆类因子**大概率是同一个结论**。

**建议的便宜筛法**(不必每条都走六轮全流程):
对这一族每条因子只跑一次 `S0_baseline`,只看三个数 ——
(a) 多头最优半衰期下的 train 多头腿净超额;(b) 空头腿毛超额;(c) 与 `known_stdamt_mean30` 的 rank 相关。
**(a) < +3% 且 (b) > +25%** → 直接按「钱在空头腿、纯多头不可用」归档,不必展开研究。
这样能把额度省给真正有多头腿的因子。
