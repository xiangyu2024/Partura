# Alpha 研究报告 — F102_kurt_autocorr

> 3 对分钟收益相关的日内峰度,平方后 15 日求和:主体是 4 分钟局部形态分布的形状(水平 + 日间离散),尾部是近 15 日的涨停封板事件;两条腿要的速度不同。留出段多头腿净超额:原式 hl=1 −0.7% / 原式 hl=5 +2.5% / 记忆拉到 60 日 +7.4%(修订:60 日版本对期限匹配的控制 R² 0.45,多头腿约四成是避开近 60 日封板票)

**数据**: 1942 个交易日 × 5220 只股票 (20180102–20251231) · 标签 `open_vwap15` h=1(可买入:剔除次日开盘封涨停) · 成本 15 bp/单位换手 · 前/后 10% · AlphaCube `1698296` · Partura `36543cfd8cc8`

**数据段**: train 20180102–20211231 · valid 20220104–20230807 · utrain 20180102–20230807 · holdout 20230808–20251231 · full 20180102–20251231

> 决策用的数字:方向与 EMA 半衰期在 **train** 上定,在 valid 上确认。与用户表可比的数字:方向与半衰期在 **utrain**(用户的训练段)上定;holdout = 用户的测试段,只在最后读。

## 1. 原始表达式

```
cross_sum(pow_2(day_kurt(nt_ts_autocorr_s1(Ret, 3))), 15)
```

**来历**:挖掘库 #3961(GP 搜出来的)。用户表里公布的那一行是:方向 −1、半衰期 1、扣费多空夏普 训练 3.71 / 测试 2.57、
多头腿毛超额 训练 12.8% / 测试 8.3%。S0 用 Partura 自己的求值复现了训练列(多空 +3.71、多头腿毛 +12.8%,见第 6 节的表);最后那一次留出段读取复现了测试列(+2.56、+8.3%,见第 10 节)。

**一句话说它是什么**:对每只股票每天,先在分钟收益上滚一个只有 3 对样本的"自相关"A,再取 A 在这一天里的超额峰度 K,
平方后把最近 15 个交易日加起来。按名字读是"日内自相关的尾部形状";按内核读、按数据量,它是**两样东西被平方这一步折叠到了同一头**:

- **主体(D1–D9 的排序)**:K 在 95% 的股票-日上是负的(中位数 −0.35),排序看的是 K 离 0 有多远 —— K 越负(3 对局部相关的分布越"平"、
  越对称,对应分钟价格路径上短的同向连动越多)后面越差,K 在 −0.2~0 之间的票最好。这是一个慢变量。
- **尾部(D10,空头腿)**:K≫0 只出现在价格大半天不动的日子,在 A 股里主要是**涨停封板日**(当天 K 的中位数 +2.8、p95 +94)。
  D10 里三分之二的票近 15 日封过涨停板,空头腿的负超额 train 83%、valid 96% 来自它们。

所以这条因子的多空夏普主要是"封过板的票后面跌"(做不了空就拿不到),多头腿是"分钟价格路径最不'顺'、而且 15 天里没出过事"的那一档。
读完之后的改进方向只有一个:**两条腿要的速度不一样** —— 事件衰减得快,多头腿要慢;把多头腿放慢,净超额能翻倍,代价是多空夏普略降。

**留出段(修订后的头条)**:多头腿扣费后的年化超额,原式按用户口径的半衰期(hl=1)是 **−0.7%**,原式只把半衰期换成 5 是 **+2.5%**,
记忆拉到 60 日的版本 `cross_max(pow_2(K), 60)` 是 **+7.4%**(纯多头夏普 −0.16 / +0.45 / +1.60)。8.2 个点里 3.2 个点换半衰期就拿得到,5.0 个点来自 60 日极值。

**修订后要一起读的两句话**:(1) 60 日版本的多头腿不是"已知暴露解释不了的东西" —— 对期限匹配的控制 R² 0.45,毛超额里约四成是"避开近 60 日封过板的票",约六成是桶内选股;
(2) 60 日极值比"原式放慢"多做的那件事,在 train / valid 上看是把封板记忆从 15 日拉到了 60 日,不是一个更慢的"状态"。

### 既往研究留下的先验

> **这些是既往研究的先验,不是本研究的结论。** 它们是在别的表达式、别的时间段上测出来的;本报告如果依赖其中任何一条,必须在本研究里重新测一次。

| 结论 | 证据 | 出处 | 置信 | 什么情况下会失效 |
|---|---|---|---|---|
| 保序的外层一元变换(pow_3、cs_rank、sigmoid…)单独作用时对 rank IC 与十分位多空书毫无影响,只能在乘法里改变权重 | v_C 与 v_D(= pow_3(v_C))每一个指标逐位相同;d_rank_amt 与 d_logamt_mean 同样逐位相同 | `F001_dwgated_covamtlow` (2026-09-30) | high | 只在「不平滑、直接对当天面板排序」时成立。一旦先做 EMA 再排序(半衰期 > 0,这是现在的默认口径),保序变换会改变各天之间的权重,就不再是 no-op(F103 的 X3-H 实测);进入线性组合或数值回归时同样不是 |

四个算子的内核都读过了(`study.sh src`;`_kurt` 和 `EPS` 不在注册表里,是 `x1_anatomy.py` 在服务器上用
`inspect.getsource` 打出来的)。下面只写**和名字不一样**、而且探针表里看不全的地方。

**1. `nt_ts_autocorr_s1(Ret, 3)` 不是"3 分钟自相关",是 4 个连续分钟收益上的 3 对 Pearson 相关。**
`ts_autocorr(x, d, 1)` = `ts_corr(x[1:], x[:-1], d)`,`ts_corr` 走 `rolling_pair_reduce(…, "corr")`:
窗口里是 (x_t, x_{t−1})、(x_{t−1}, x_{t−2})、(x_{t−2}, x_{t−3}) 三对。NT 面是**逐日**的 (分钟 × 股票) 面
(`apply_cube` 里 `for c in range(B)` 一天一张),所以窗口**不跨日**;每天开头用 NaN 左填充,`count.clamp(min=1)`:

- 第 0 分钟:NaN(`res[shift:]` 之前没有值);
- 第 1 分钟:只有 1 对,去均值后全 0 ⇒ `0 / (0 + EPS)` = **0**;
- 第 2 分钟:只有 2 对,两点连线 ⇒ 恰好 **±1**(任一侧不动则为 0);
- 第 3 分钟起才是 3 对。

**2. 三对的样本相关系数离"自相关"很远。** `iid_null_location`:iid 高斯输入下均值 **−0.295**、中位数 **−0.461**、
|r| > 0.9 的占 **18.7%**(同一个探针在窗口 60 上读出均值 −0.013、|r|>0.9 为 0,自检通过)。
也就是说,即使分钟收益完全没有自相关,A 也是一个在 [−1, 1] 上铺得很开、偏负、两端堆积的量。
它的日内分布形状主要由估计量本身决定,不由"这只股票的收益有没有自相关"决定。

**3. 分母是 `sqrt(var_x · var_y) + EPS`,EPS = 1e-9。两个后果:**

- **价格连续 4 分钟不动 ⇒ A 恰好等于 0**(`constant_input_value` = 0.0),不是 NaN。
  全 0 序列里放一次孤立的价格跳动(`impulse_in_zeros`):跳动后第 1、2 分钟 A = **−0.5**,其余仍是 0。
  所以对一只很少动的股票,A 的日内取值几乎只有 {0, −0.5} 两个点。
- **输出并不是零次齐次的**。内置的齐次度探针读出 k = 0,但它喂的是 O(1) 的数;分钟收益是 1e-4~1e-3,
  这时 `sqrt(var_x·var_y)` 本身只有 1e-9~1e-6。`eps_shrink_at_scale`(iid 输入缩到对应量级,输出 / O(1) 时的输出,中位数):
  1e-3 → 0.998,3e-4 → 0.974,1e-4 → **0.809**,3e-5 → **0.276**(自检:没有分母的 `nt_ts_rank` 四档全是 1.0)。
  真实数据上这件事有多大,见 `07x_1_anatomy.md` §3。

**4. `day_kurt` 是超额峰度(−3),对常数输入返回 NaN。**
`_kurt` = `nanmean((x−μ)⁴) / nanmean((x−μ)²)² − 3`,普通除法,0/0 = NaN。
所以**全天一字板 / 全天不动**的日子(A 全 0)K 是 NaN,不是"极大"。
而当输入大部分是同一个值、少数例外时,峰度量的不是"尾部形状",是**稀疏度**:
`two_point_response`(240 个 0 里放 k 个 1)读出 k=1 → 235.0、k=6 → 35.0、k=24 → 5.11、k=60 → −0.667、k=120 → −2.0,
和伯努利峰度的解析式 1/(w(1−w)) − 6 逐位相同(这是这个探针的自检)。

**5. `pow_2` 在这里不是保序变换。** `pow_(x, 2.0)`:指数 > 1 时就是 `x ** 2`,**不保号**(探针:保序 = False,取负 = even)。
K 有正有负,所以平方是一次折叠。实验室先验里"保序的外层一元变换是 no-op"那条把 `pow_2` 列在算子清单里,
它在 F001 上成立是因为那里的操作数恒正;在这棵树上不成立。

**6. `cross_sum` 用的是 `nansum_last`:NaN 当 0 加,整窗全 NaN 才返回 NaN。**
所以停牌日、一字板日对 15 日求和的贡献是 0 —— 和"当天 K 恰好为 0"的日子不可区分。
覆盖率因此接近 1(cov = 1.00)。

## 3. 数学分解

```
A = nt_ts_autocorr_s1(Ret, 3)
B = day_kurt(A)
C = pow_2(B)
D = cross_sum(C, 15)
```

| 变量 | 算子 | 计算轴 | 窗口 | 输出形状 | 被引用 | 结构角色 |
|---|---|---|---|---|---|---|
| `A` | `nt_ts_autocorr_s1` | 日内分钟轴 (M) | 3 | 每股票-日-分钟一个值 | 1× | 逐分钟的截面/日轴变换(NT 面:每分钟跨股票或跨日) |
| `B` | `day_kurt` | 日内分钟轴 (M) | — | 每股票-日一个值 | 1× | 日内事件提取(日内分布统计量,尺度不变) |
| `C` | `pow_2` | 逐元素 | — | 每股票-日一个值 | 1× | 逐元素变换(保序=False,齐次度 2.0) |
| `D` | `cross_sum` | 交易日轴 (D) | 15 | 每股票-日一个值 | 1× | 15 日记忆(日轴滚动,因果=True) |

- 节点数 5(含叶子),去重后 4 个中间量,深度 5,用到的字段: Ret
- 日轴最大单窗口 15 天;**沿路径累计的真实回看 15 天**(AlphaCube 的 `max_window` 取最大值而不是路径累加,预热行数按它算)

分解表本身没有歧义(A → B → C → D 一条直链,只用到 `Ret` 一个字段)。需要补充的是**每一层在真实数据上到底算出了什么**,
因为这条链上四个算子里有三个的名字会把人带偏。下面的数字都来自 x1 / x2(`07x_1_anatomy.md`、`07x_2_refine.md`)。

**A = `nt_ts_autocorr_s1(Ret, 3)`**,逐分钟、逐股票、不跨日:

```
A_t = corr( (r_t, r_{t−1}, r_{t−2}),  (r_{t−1}, r_{t−2}, r_{t−3}) )          # 3 对,Pearson
    = cov / ( sqrt(var_x · var_y) + 1e−9 )                                    # 任一侧不动 ⇒ 恰好 0
```

它不是一个自相关的估计量,是 **4 个连续分钟收益的形态分类器**。A 股的分钟收益贴着 1 分钱的格子跳,4 个收益的组合只有有限几种,
A 相应地只取少数几个值:四分钟都不动 → 0;一次孤立的跳动 → 两个 −0.5;连续两分钟同向 → +0.5 附近;来回跳 → −0.5 ~ −1。
训练段里一天中分钟收益非零的占比 W 的中位数是 0.65,A 非零的占比 Z 的中位数是 0.90 —— 对多数股票-日,A 在九成的分钟上有值。

**B = `day_kurt(A)`**,把一天的 A 折成一个数 K(超额峰度)。它在两个区间里是两种东西:

```
活跃度 Z:      < 0.5(2.2% 的格子)                    > 0.6(95% 的格子)
K:             ≈ 1.45 / Z − 3  ≫ 0                    −1.2 ~ +0.3,中位数 −0.35
它在量什么:    稀疏度(价格有多少分钟没动)            A 的分布形状(对称 / 平 ↔ 挤在负的一侧)
是谁:          涨停封板日、僵尸日                      正常交易日
```

- 左边:A 大部分是 0、少数例外,峰度就是稀疏度计(探针 `two_point_response` 与伯努利峰度的解析式逐位相同)。
  涨停封板日上 Z 的中位数 0.22、K 的中位数 +2.8、p95 +94。**全天一字板 K 是 NaN**(方差为 0),反而看不见。
- 右边:K 与 Z 的 rank 相关只有 −0.05,和"多少分钟在动"无关;它跟 A 的日内偏度(+0.57)和均值(−0.37)走 ——
  K 越负,A 的分布越对称、越平(正的局部相关出现得越多);K 靠近 0,A 挤在负的一侧。

**C = `pow_2(B)`** = K²。K 两头都有,所以平方是**折叠**,不是保序变换。两头极不对称:
主体一侧 K² 在 0 ~ 1.4,事件一侧可以到几千(最大的 1% 股票-日占了 K² 总量的 98.7%)。

**D = `cross_sum(C, 15)`**,最近 15 个交易日的 K² 之和。两件事:

- `nansum`:停牌日、一字板日(K = NaN)记 0,和"当天 K 恰好为 0"不可区分 —— 这是一个缺陷(x2 §1),换成均值或极值就没了。
- 和式可以拆开:**Σ K² = 15 ·(K 的 15 日均值² + K 的 15 日方差)**。前一项是"K 的水平离 0 多远",后一项是"K 稳不稳"
  (一次事件日就让它爆掉)。15 日和里最大那一天占的份额中位数是 0.22(纯求和是 0.07,纯极值是 1.0),只在最右边的 5% 才接近 1。
  S3 把这两项分开测了:两项的 rank 相关是 −0.02,各自都只在一段时期里值钱。

**所以整条表达式是**:对"4 分钟局部形态的分布"取一个形状统计量 K,再问"最近 15 天里 K 离 0 有多远、出格过几次"。
它不含收益的方向、不含成交量、不含波动的幅度(A 名义上是零次齐次的;分母里的 `+EPS` 在分钟收益的量级上会压低一部分输出,x1 §3 量过:有,但不重要)。

## 4. 结构语法

```
日内局部形态(4 分钟、与幅度无关)  →  日内分布的形状统计量  →  折叠(两种"不正常"并到同一头)  →  日轴记忆
        A = 3 对相关                         K = 峰度                    K²                        Σ 15 日
```

- **形态提取(A)**:在分钟轴上滚,窗口极小(3 对),与幅度无关 —— 只看相邻几分钟收益的相对形态,不看涨跌多少、不看成交多少。
  窗口一放大(5、10、15 对)它就退化成一个噪声很大的线性自相关估计,信息消失(S2)。
- **日内折叠成一个数(K)**:峰度在这里身兼两职 —— 正常日上它描述 A 的分布形状,不动的日子上它是稀疏度计。
  两种读数落在数轴的两侧(负 / 正),这是后面需要折叠的原因。
- **折叠(pow_2)**:把"K 很负"(主体里差的一头)和"K≫0"(封板 / 僵尸)映到同一头。**凸性无关**(换成绝对值是同一个因子),
  **折叠点必须在 0 附近**(移到 −0.3 多头腿就没了),**必须逐日折叠**(先平均再折叠,valid 上多头腿归零)。
- **记忆(cross_sum, 15)**:平均掉单日 K 的采样噪声(当天的 K² 自己 rank IC 只有 0.0195 / 0.0069),同时记住事件。
  这一层有两个可以改的地方:缺失日的处理(求和 → 均值 / 极值),和速度(15 天对空头腿最优、对多头腿偏快)。

没有门控、没有乘法、没有截面算子。整棵树只有一条链,所以"哪个节点多余"的答案是:**没有可以删的节点**,
只有两个可以换的算子(`cross_sum` → `cross_mean` / `cross_max`,`pow_2` → `abs_`)和一个可以调的速度。

- `l_k2_today` — 去掉 15 日记忆:如果预测力就在当天的 K² 里,rank IC 应保住;如果单日 K 主要是 240 个点的采样噪声(本机模拟 sd≈0.26,与截面离散同量级),它会塌、换手会爆

逐层的结论:

1. **`pow_2` = 折叠,凸性不重要。** 换成绝对值是同一个因子(rank 相关 0.99);去掉折叠(`l_nofold_lin`)多头腿直接变负。
   它的分位剖面两头都是负的(train Q1 −26.6%、Q10 −10.5%,中间 +5~+9%),和 x1 §5 的驼峰一致。
   实验室先验"保序外层变换是 no-op"在这棵树上**不适用**:K 有正有负,平方不保序,而且这次折叠恰恰是因子成立的条件。
2. **15 日求和不是极值记忆,但换成极值反而更好。** `l_max` 与原式的 rank 相关只有 0.91(不是同一个因子),
   LS、多头腿毛、多头腿净在 train 和 valid 上都不低于原式。原因在聚合器对缺失日的处理(`cross_sum` 把缺失日当 0 加,
   `cross_max` 跳过),x2 §1 专门查了这件事。
3. **空头腿是事件、多头腿是状态。** `l_med`(15 日中位数,单次封板日进不来)空头腿毛超额从 +38.8% / +31.9% 掉到
   +24.4% / +12.9%,而多头腿毛超额基本保住(+10.2% / +12.6%),半衰期被选到 5、换手降到 4.6%。
4. **没有记忆不行。** 当天的 K² 自己 rank IC 只有 0.0195 / 0.0069(原式 0.0299 / 0.0202),要靠 EMA 半衰期 10 才把换手压下来。
   单日 K 的信噪比很低(240 个点上估一个峰度),15 日聚合是在平均噪声。
5. **自相关这一层不能删。** `l_noac`(直接对分钟收益取峰度)与原式的 rank 相关 −0.02,是完全不同的因子
   (它和 `r_ar1` 0.38、和 `ctl_dvol20` 0.29,属于波动 / 活跃度那一路),valid 的 LS 只剩 +1.72。
6. **"主体 = 分钟收益一阶自相关的水平"这个读法被数据否了。** 探针上 K 是 AR(1) 系数 φ 的单调函数,
   但真实数据里 `r_ar1`(全天 AR(1) 系数的 15 日均值)与带符号的 15 日 K(`l_nofold_lin`)的 rank 相关是 **0.00**,
   与原式 0.10。`r_ar1` 自己是另一类东西:与 `ctl_turnrate` 0.50、`ctl_dvol20` 0.51,被控制变量张成 **R² = 0.504**,
   残差 rank IC 只剩 0.0050,而且 train 上多头腿只有 +3.9%。也就是说全天 AR(1) 系数基本是活跃度暴露,
   而 K 不是(原式 R² 0.219)。**K 在主体上量的是什么,要看 3 对局部相关的分布本身**,不是全天的线性自相关 —— x2 §2 接着查。
7. **按名字读(H1)也不成立。** 把 3 对换成 15 对(`l_ac15`),一个"像样的"自相关估计量,多头腿净超额变负、
   与原式的 rank 相关只有 0.27。信息是 3 对这个极小窗口特有的(S2 的 `w_a5`、`w_a10` 给出了完整的衰减曲线)。

占有标签格子的 49.6%(train)/ 64.1%(valid)。它的等权比全市场等权每年高 +7.7% / +5.2% —— 这一块是"避开事件"挣的,任何人都拿得到。
**在干净池内部**,`max(K²,60)` 的十分位剖面(相对干净池自己的等权)仍然单调:train −11.6% … +6.8% +7.3%,valid −7.6% … +4.6% +11.0%;
书:LS +2.04 / +1.63,多头腿毛 +8.4% / +11.0%、净 +5.7% / +8.8%(原式在同一个池子里:+6.3% / +11.6%、净 +1.3% / +6.7%)。
所以 `u_max60` 的多头腿 ≈ 一半是"避开近 60 日的事件票",一半是干净池内部的状态排序。

> **修订时的更正**:上面干净池内部那一行书的半衰期是在池子里按多空夏普另选的 —— `max(K²,60)` 选到 **hl=10**,原式选到 hl=5 —— 不是推荐式实际交易的 hl=0。
> 按 hl=0,干净池内部 `max(K²,60)` 的多头腿是毛 +6.9% / +8.6%、净 **+3.3% / +5.5%**(r1 §3);原式 hl=1 是净 −1.3% / +0.8%。"一半一半"这个读法不变,
> r1 §2 把它落到了实际持仓上:配置(所在的桶)+4.7% / +3.8%,选股 +9.8% / +9.7%(按干净池标记分两桶),按封板代理的五分位是 +6.4% / +5.3% 与 +8.1% / +8.1%。

  (train 0.85、valid 0.83),按它算标准误是 1.9 个点,约 **2.6σ**。留出段上的相关是不是也在 0.85 我验证不了(那需要留出段的日序列,不许再读)。
  老实的说法:**1.6σ ~ 2.6σ,取决于一个我量不到的数;同一个增量在 valid 上是 0;而且它是 10 个留出段数字里挑出来比的一对。**
- **30 对 60**:用户口径下 `f_max60` +7.4% 对 `f_max30` +4.9%;都用纯多头的半衰期是 +7.0% 对 +7.6%。先后取决于半衰期怎么选,差别在半个标准误以内。

**结构那一块是什么(只有 train / valid 的证据)**:是更长的封板记忆。把封板日从 K 里拿掉再取 60 日极值,多头腿净超额从 +11.3% / +10.1% 掉到 +6.8% / +6.7%,
比"原式 + 慢半衰期"的 +8.5% / +9.8% 还低;在没有封板票的干净股票池内部,60 日极值相对原式@hl5 的增量是 +2.0%(t 1.1)/ −1.2%(r1 §3)。
也就是说 `f_max60` 比"原式放慢"多做的那件事,是把"近 15 日封过板的票不进多头腿"换成了"近 60 日封过板的票不进多头腿"。

**为什么仍然推荐它,以及这句话的边界**:

- **它对"半衰期怎么选"不敏感,原式和 30 日版本都敏感。** `f_max60` 在两种选法下是 +7.4% / +7.0%;`f_max30` 是 +4.9% / +7.6%;原式是 −0.7% / +2.5%。
  用户口径的半衰期是按多空夏普自动选的,在这条因子上它会选到对空头腿最优的那一档 —— 把慢写进表达式,才不依赖下游改口径。这是推荐 60 而不是 30 的理由;
  如果下游愿意按纯多头夏普选半衰期,`f_max30`@hl5 与它打平,多空夏普也相近(+2.32;`f_max60` 是 +2.40 / +2.11)。
- 代价是多空夏普:用户口径下训练段低 0.36,留出段低 0.17(后者在噪声内)。
- **它不是一个"已知暴露解释不了的多头腿"**(审查意见 3,接受)。加上与它同期限的控制后 R² 是 0.45 而不是 0.19,残差的多头腿毛超额 +4.3% / +3.9% 而不是 +11.1%;
  把实际持有的多头十分位拆开(r1 §2):train / valid 上毛超额 +14.6% / +13.4% 里,**+6.4% / +5.3%(约四成)是"它所在的桶"—— 避开近 60 日封过板、日频波动最高的票**,
  +8.1% / +8.1%(约六成)是桶内选股。没有哪个朴素 60 日量能单独复现这条多头腿(train 上最好的 +6.7%),但它也不是"控制变量解释不了"的。
- **+7.4% 这个数要打折读**:基准是"所有有信号有标签的票的等权",里面含着近期封板和短历史的票。在剔掉这些票的干净池内部(基准也换成干净池的等权),
  `f_max60` 按它实际的半衰期 hl=0 算,train / valid 的多头腿净超额是 **+3.3% / +5.5%**(毛 +6.9% / +8.6%),全市场基准下是 +11.3% / +10.1%。
  (原报告这里写的 +5.7% / +8.8% 是在干净池内部另选了 hl=10 的数,不是推荐式实际交易的那个;更正见 `07x_5_revision.md`。)留出段上的对应数字没有算,也不能再算。
  如果留出段也是这个比例,+7.4% 里来自"排序本身"的大约是 +2% ~ +4%。
- 留出段的多头腿毛超额比训练段少了四分之一到四成(`f_max60` 13.9% → 10.2%,`f_orig` 12.8% → 8.3%,`f_max15` 13.7% → 8.0%;所有候选都降)。x3 §4 在读之前就指出因子的一半("水平")在 2023 年已经没有预测力;
  留出段的衰减与此一致,但我没有在留出段上把两半分开验证。

**修订后的 train / valid 证据有没有指向别的候选**:没有。train / valid 上,各自配上纯多头的半衰期之后,`f_max60`@hl0(+11.3% / +10.1%)、`f_max30`@hl5(+10.0% / +10.6%)、
`f_mean_abs15`@hl10(+10.6% / +10.3%)三者打平(r1 §3 里做了配对的两对,t = 0.5 和 1.6),比原式@hl5(+8.5% / +9.8%)高 0 ~ 3 个点;留出段把它们分开了(+7.4% / +7.6% / +3.8% / +2.5%)。
修订里新试的结构只有一个(看不见封板日的 60 日极值),它更差。**推荐仍是读之前定的 `f_max60`;没有哪个没读过留出段的候选更值得推荐。**

## 11. 失效模式与风险

- **成分漂移(最重要)**:因子里"水平"那一半的 rank IC 从 2019 年的 +0.029 降到 2023 年的 +0.001;带符号的主体 K 在 2023 年已经是负的(x3 §4)。
  train 的多头腿靠水平,valid 的多头腿靠离散。原式和极值版本因为两半都装着所以看起来稳,但如果离散那一半也开始退,没有第三样东西顶上。
- **空头腿拿不到,而且是已知的东西**:多空夏普的大头是"近 15 日封过涨停板的票后面跌"(x1 §7),A 股做不了空;对控制变量中性化后
  空头腿毛超额只剩 +11.0%(原式)/ +2.3%(`u_max60`)。任何按多空夏普给这条因子打的分都高估了它对纯多头的价值。
- **(修订)多头腿也有一大块是已知的东西**:对期限匹配的控制,推荐式 R² 0.45 / 0.46(原报告用九个短期限控制得到 0.19),残差多头腿毛超额 +4.3% / +3.9%、
  rank IC +0.0063 / +0.0038。实际持有的多头十分位里,约四成的毛超额是"避开近 60 日封过板 / 日频波动最高的票"(配置 +6.4% / +5.3%),
  这一块不需要这条因子:一个"近 60 日没有封板日"的过滤器就拿得到。剩下的六成(桶内选股 +8.1% / +8.1% 毛)扣掉成本是 +3% ~ +5%。
  valid 上它在控制变量之外的预测力已经很弱(哪怕只用原来九个控制,残差无成本多空夏普 +0.88)。
- **基准里的水分**:多头腿"超额"是相对"当天有信号有标签的全部票的等权"。这个基准里含着近期封板、复牌、短历史的票,它们年化跑输 15~40 个点。
  只是避开近 60 日的事件票就有 +7.7% / +5.2%(x3 §3);在这个干净池内部,`u_max60` 按实际的 hl=0 多头腿净超额是 **+3.3% / +5.5%**
  (全市场基准下 +11.3% / +10.1%;原报告这里写的 +5.7% / +8.8% 是在池子里另选 hl=10 的数):真正来自排序的,train 上约三成,valid 上约一半。留出段的 +7.4% 没有做过这个换算。
- **估计量特有**:信息只存在于"3 对"这个窗口(S2);5 对就掉一半,10 对归零。它依赖 A 股 1 分钱最小报价单位下分钟收益的离散结构。
  最小报价单位、涨跌停制度(科创板自 2019 年、创业板自 2020 年 8 月起涨跌幅 20%)或分钟数据的清洗方式一变,K 的分布就变。
  原式逐年的多空夏普 2019–2021 是 +5.75 / +3.55 / +2.10,我没有把这段下降和制度变化分开,这是一个没有检验的制度依赖。
- **内核细节依赖**:封板日 K≫0 靠的是相关系数分母里的 `+1e-9` 把"不动"变成恰好 0(探针 `constant_input_value`)。
  别的实现(返回 NaN)下事件日会直接消失 —— 而 r1 说明多头腿有三分之一要靠看得见封板日(去掉封板日后净超额 +11.3% / +10.1% → +6.8% / +6.7%),
  所以这个内核细节不只关系到拿不到的空头腿。`1000·Ret` 重算与原式 Spearman 0.982(x1 §3),目前不敏感,但换数据源要重测。
- **过拟合**:这是 GP 搜出来的式子。记忆窗口的邻域是平的(5~120),聚合器换五种都站得住;但"3 对 + 峰度 + 折在 0"这个组合没有邻域可言
  (峰度换一阶矩是另一个因子,折叠点移 0.3 多头腿就没了)。我把它读成"这个统计量碰巧把两种不正常分到了 0 的两侧",不是先验上该成立的东西。
- **容量**:预测力集中在小市值、高换手的票(条件 IC);valid 上大市值五分位里的多头十分位只剩 +2.7%(x3 §5)。多头腿自己偏低成交额(分位 0.33)。
- **成本敏感**:原式多头腿三分之二的毛超额被 15 bp 吃掉(单边日换手 10.4%)。`u_max60` 把换手降到 3.9%,对成本假设不那么敏感;
  但它的 dist 是 0.98、`u_max120` 是 0.96 —— 极值聚合在长窗口上会产生并列值,再长就要碰门槛。
- **(修订)半衰期口径**:这条因子的结论对"半衰期按什么选"很敏感。用户口径按多空夏普选,在原式上选到 hl=1(留出段多头腿净 −0.7%);按纯多头夏普选是 hl=5(+2.5%)。
  原报告的头条只和前者比,把"换半衰期就拿得到的 3.2 个点"也算成了升华。推荐式自己对这个选法不敏感(+7.4% / +7.0%),30 日版本敏感(+4.9% / +7.6%)。
- **(修订)选择偏差与多重比较**:`f_max60` 是在看了 x2、S3 两轮 train / valid 结果之后选的;train / valid 上它相对"原式 + hl=5"的优势是 +2.8(t 2.3)/ +0.3(t 0.2)。
  留出段上这个优势是 +5.0 个点(原式 hl=5 +2.5%,`f_max60` +7.4%)—— 这个数**就在最初那一次读取的 `final.json` 里**,原报告说"留出段没有可比的行"是错的。
  它的标准误按实测的日序列相关(0.85,train / valid)是 1.9 个点,按 0.6 是 3.0 个点;留出段上的相关没法量。
  另外,那一次读取实际产出了 10 个多头腿数字(5 个候选 × 2 种半衰期选法),修订时是看过前 5 个之后才去读后 5 个的:
  从 10 个数里挑一对来比,显著性要再打折。valid 上同一个增量是 0,这条不该被留出段的一个 +5.0 盖过去。

## 12. 下一步实验

只列能明显降低不确定性的(修订后重排;第 1、2 条是修订新加的):

1. **把"避开近 60 日封板票"和"K 的排序"拆成两个东西分别用。** r1 说推荐式的多头腿约四成是前者、约六成是后者,而 60 日极值比"原式 + 慢半衰期"多出来的那块就是更长的封板记忆。
   直接的做法:股票池先用一个朴素的过滤器(近 60 日没有封板日 / 不在 athi60 最高的五分之一),再在池子里用提纯式 `cross_mean(abs_(K),15)` 配长半衰期排序。
   如果它不差于 `f_max60`,那么"3 对 + 峰度"这个脆弱的估计量只需要负责排序,事件交给一个谁都看得懂的过滤器。这需要新的样本外数据(本研究的留出段已经用掉)。
2. **半衰期按纯多头夏普选一遍。** 用户口径按多空夏普选半衰期;在这条因子上它让原式的留出段多头腿从 +2.5% 变成 −0.7%。本批其他"空头腿是事件"的因子很可能有同样的问题,
   `final.json` 里每个候选的 `splits_at_hl_long` 已经存着这组数,只是 `digest` 和报告不打印。
3. **把"离散"那一半单独认出来。** x3 §4 说近三年值钱的是 K 的日间离散,而它在干净股票池里(没有封板、没有僵尸日)仍然有多头腿(valid +10.5%)。
   这些"出格但不是封板"的日子是什么?按 K 的符号拆(K 突然很负 = 单边趋势日?K 突然为正 = 午后封板 / 临停?),各自看次日超额。
   如果它能写成一个直接的事件定义,就不再需要"3 对 + 峰度"这个脆弱的估计量。
4. **K 在主体上的微观含义。** 现在只到"A 自己的矩张成 75%"。把 4 分钟形态(孤立跳动 / 同向连动 / 来回跳 / 不动)的频率直接数出来,
   看 K 的水平是哪几个频率的函数、哪一个频率带着预测力。这也是解释"为什么只有 3 对行"的唯一办法。
5. **水平那一半为什么退了。** 2021 年是分界。候选解释:量化资金在分钟级别的做市 / 拆单改变了局部形态的分布;逐年看 K 的截面分布和它与换手率的相关有没有漂移。
6. **换一个基准重算多头腿。** 相对"剔除近 60 日封板票与短历史票"的等权,`u_max60` 按 hl=0 的多头腿净超额是 +3.3% / +5.5%(r1 §3;x3 §3 的 +5.7% / +8.8% 是 hl=10)。
   这才是纯多头使用者实际拿到的数;本批其他因子也值得用同一个基准重算一遍。
7. **和 F001 家族的组合。** rank 相关只有 0.24~0.27,多头腿来源不同(那边是低成交额,这边在每个成交额桶里都有、且高成交额桶里最强:+26.3% / +25.5%)。
   两者合起来的多头腿是不是相加的,值得一个阶段。
