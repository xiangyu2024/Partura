# Alpha 研究报告 — F101_day_shine_retstd

> 方正「适度冒险」的日频零件:成交量激增分钟之后 5 分钟收益波动(耀眼波动率)的日均值,对截面均值取绝对偏离

**数据**: 1942 个交易日 × 5220 只股票 (20180102–20251231) · 标签 `open_vwap15` h=1(可买入:剔除次日开盘封涨停) · 成本 15 bp/单位换手 · 前/后 10% · AlphaCube `1698296` · Partura `36543cfd8cc8`

**数据段**: train 20180102–20211231 · valid 20220104–20230807 · utrain 20180102–20230807 · holdout 20230808–20251231 · full 20180102–20251231

> 决策用的数字:方向与 EMA 半衰期在 **train** 上定,在 valid 上确认。与用户表可比的数字:方向与半衰期在 **utrain**(用户的训练段)上定;holdout = 用户的测试段,只在最后读。

## 1. 原始表达式

```
abs_(cs_demean(day_mean(in_sustain_stddev(is_gt(sub(in_slice(Volume, 2, 237), in_delay(in_slice(Volume, 2, 237), 1)), add(in_mean_full(sub(in_slice(Volume, 2, 237), in_delay(in_slice(Volume, 2, 237), 1))), in_stddev_full(sub(in_slice(Volume, 2, 237), in_delay(in_slice(Volume, 2, 237), 1))))), in_slice(Ret, 2, 237), 5))))
```

**来历**:手写库 `day_shine_retstd`,是方正金工「适度冒险」因子的**日频零件**。研报的做法是:
找出成交量突然放大的分钟(「耀眼时刻」),量这些时刻之后一小段时间里收益的波动(「耀眼波动率」),
取日均,再看它**离全市场均值有多远**(「适度」= 离得近),最后在 20 个交易日上取均值和标准差。
本表达式只到「离均值多远」这一步;20 日均值那一步由回测口径里的因果 EMA(训练段选出的半衰期 10 天)代劳。

**一句话**:每只股票每天算一个数 `J` = 「成交量比上一分钟猛增的那些分钟起、连续 5 分钟收益的标准差」的日均值;
因子值是 `|J − 当天全市场 J 的均值|`;方向为负 —— **`J` 离全市场均值越远的股票,之后越差**。

用户表里公布的那一行(utrain 多空夏普 3.93、多头腿毛超额 13.6%、半衰期 10、方向 −)被 S0 逐位复现。

### 既往研究留下的先验

_(实验室里没有与这棵树相关的、来自**其他**研究的既往结论 —— 本研究自己的结论不算先验。)_

读内核源码(`study.sh src`)和为这棵树写的四个探针之后,和名字不一样、或者探针表里看不出来的地方:

1. **`in_sustain_stddev(mask, data, 5)` 是「触发型」算子,不是滚动算子**。第一个操作数是 0/1 掩码,只在 `mask == 1`
   的分钟写出一个值,其余分钟是 NaN;整行没有触发就整行 NaN。内置探针给它喂的是两列随机浮点数,`mask == 1` 永远不成立,
   所以内置读数(「有限值占比 0.0」「齐次度 None」「与分钟顺序无关」)**全是空读数**,不能用。
   本研究的探针实测:
   - `minute_offsets_read = [0, 1, 2, 3, 4]` —— 窗口是**触发分钟自己 + 之后 4 分钟**,朝后看(日内朝后看不是未来泄漏,
     因子在收盘后才用)。自检:`in_delay(x, 1)` 读出 `[-1]`,对。所以「放量之后的波动」里**含放量那一分钟自己的收益**。
   - `ramp_window_readout`:整窗 1.4142 = 5 个连续整数的**总体** std(除以 n 不是 n−1);离行尾只剩 4/3/2/1 分钟时读出
     1.118 / 0.8165 / 0.5 / 0.0 —— 窗口跑出行尾就**截短**(NaN 填充 + `nanmean`),最后一分钟触发得到 std = 0。
     自检:`in_stddev_full` 在 5 宽斜坡上读出 1.4142,对。
   - `trigger_semantics`:只有 `mask == 1.0` 触发(2.0、0.5、NaN 都不触发),整型掩码可用。
   - 注册表给它打的 `boolean_output, trivial_boolean` 标志是错的(它输出的是连续的 std),`decompose` 的结构角色栏
     也因此把它标成了「事件判定(0/1 掩码)」—— 真正的掩码是它的第一个操作数 `G`。
2. **`is_gt(a, b)` 遇到 NaN 返回 0**(`comparison_semantics`:`nan_left = nan_right = 0`,相等也是 0),输出是 int。
   `in_delay(·, 1)` 的第一格是 NaN,所以切片后的第一分钟永远不触发;全天无成交的行 ΔVolume 恒为 0、阈值也是 0,
   `0 > 0` 为假 —— **停牌 / 全天零成交的股票没有触发,`J` 是 NaN**,不是 0。
3. **`in_mean_full` / `in_stddev_full` 是「整行统计量铺满整行」**:阈值 = 当天 ΔVolume 的均值 + 1 个总体 std,
   用的是**全天**的统计量(包含触发分钟之后的数据)。这在日内是「事后」阈值:一分钟算不算耀眼,要等收盘才知道。
   对一个收盘后才使用的日频因子没有泄漏问题,但它**不是**一个盘中可以实时触发的事件。
   ΔVolume 的均值 = (最后一分钟量 − 第一分钟量)/235 ≈ 0,所以阈值实际上就是「ΔVolume > 1σ」。
4. **`in_slice(x, 2, 237)` 两端都含**(`x[:, 2:238]`),241 格里取 236 分钟:去掉开盘头两格和收盘集合竞价的三格。
5. **`cs_demean` 减的是当天有值股票的简单均值**(`cs_mean` 用 `nanmean`)。`J` 右偏,均值在中位数右边
   (具体在第几分位见 `07x_look.md`),所以「离均值最近」不是「排在中间」。
6. `day_mean` 对 NaN 分钟用 `nanmean`:`J` = 当天所有触发点的 5 分钟 std 的**等权**均值,和触发了多少次无关。

分解表之外需要说明的三件事。

**关键公式**(记 `v_j` 为切片后第 j 分钟的成交量,`r_j` 为该分钟收益,j = 0..235):

```
Δ_j   = v_j − v_{j−1}                         (j = 0 时为 NaN → 不触发)
触发集 T = { j : Δ_j > mean(Δ) + std(Δ) }      (全天的均值与总体 std;mean(Δ) ≈ 0)
σ_j   = 总体 std( r_j, r_{j+1}, …, r_{j+4} )    (跑出行尾则截短;只剩 1 分钟时为 0)
J     = (1/|T|) Σ_{j∈T} σ_j                    (T 为空 → NaN)
因子  = | J − 当天全市场 J 的均值 |
```

**容易被名字骗的地方**

- 「sustain」不是「持续」的意思,是「从触发点**往后**取一段」。窗口含触发分钟自己,所以 `J` 里混着
  放量那一分钟本身的价格冲击,不纯是「放量之后」的反应。
- 「放量」的定义是**相邻两分钟的增量**超过阈值,不是这一分钟的量大。连续高量的第二分钟不触发(增量小),
  冷清之后的第一笔大单触发。阈值按当天自己的 σ 定,所以每只票每天触发的**比例**差不多,和绝对成交量无关 ——
  掩码本身不带成交额尺度。
- `J` 的齐次度是 1(对收益),量纲是「5 分钟内分钟收益的 std」,天然和日内波动 `day_std(Ret)` 同量纲。
  整棵树只用到 Volume(定时刻)和 Ret(定数值),**没有任何价格水平或成交额尺度混进来** —— F001 那种「尺度污染」
  的嫌疑在这棵树上不成立,嫌疑转移到「它是不是就是波动」上。

**重复使用的中间量**:`A = in_slice(Volume, 2, 237)` 用 2 次、`C = ΔVolume` 用 3 次(被比较、求均值、求 std)。
整个 A..G 只是为了造一个掩码;`H..I` 才是取数。所以这棵树可以读成 `fold(day_mean(stat_at(mask, Ret)))`,
三个可以独立替换的零件:**掩码、窗口统计量、折叠**。实验就按这三个零件来拆。

## 4. 结构语法

把分解表的结构角色串起来,这棵树的语法是:

```
事件掩码(A..G): 这一分钟的成交量比上一分钟多出的部分 > 当天该差值的 均值 + 1σ      —— 每股票-日一串 0/1
    -> 挂在事件上的短窗统计量(I): 从触发分钟起 5 分钟(含触发分钟)的收益总体 std     —— 只在触发分钟有值
        -> 日内折叠(J): 当天所有触发点的等权均值                                    —— 每股票-日一个正数,带「波动」的量纲
            -> 截面折叠(K, L): |J − 当天全市场均值|                                 —— V 形变换,不保序
                -> (回测口径)因果 EMA,半衰期 10 天,作用在**折叠之后**的量上;方向取负
```

三点是这棵树特有的,F001 / F002 都没有:

1. **掩码和被统计的序列是两个字段**(Volume 定时刻,Ret 定数值)。这棵树里没有逐元素乘法,所以「门控还是两个信号」
   这个问题的形式变了:要问的是「**换一个掩码(乃至全部分钟),`J` 还是不是同一个量**」。
2. **最外层是一个不保序的截面折叠**。保序的外层变换对排名型指标无效(实验室先验 `rank-preserving-outer-map-is-a-noop`),
   但 `abs_(cs_demean(·))` 恰恰**不保序** —— 它是整棵树里唯一能改变排序的日频节点,所以研究的重心在它身上:
   收益对 `J` 到底是不是驼峰?折叠中心该不该是均值?
3. **平滑发生在折叠之后**。`EMA(|K|) ≥ |EMA(K)|`,差值是 `K` 在时间上换号 / 抖动的程度。
   所以实际交易的信号 = 「平均离均值多远」+「相对位置稳不稳」,后者是表达式里**看不见**、由口径带进来的成分。

## 5. 竞争性假设

下面的假设是在**读完源码和基线、跑任何新实验之前**写的。每条给出「它预测什么」和「哪个实验能杀死它」。
记号:`J` = 折叠之前的量(放量分钟之后 5 分钟收益 std 的日均值),`K = J − 截面均值`,原式 = `|K|`,
实际交易的信号 = `−EMA10(|K|)`。

| | 假设 | 为什么合理 | 它预测什么 | 能杀死它的实验 |
|---|---|---|---|---|
| **H1** | **事件机器是多余的**:`J` 就是日内波动,放量掩码 + 5 分钟窗口只是换了个写法 | 触发条件 ΔVolume > 均值 + 1σ 每天会命中十几到几十分钟,窗口又互相重叠,平均下来和「全天滚动 5 分钟 std」没区别 | `J` 与 `day_std(Ret)`、`day_mean(in_stddev_rolling(Ret,5))` 的日截面 rank 相关 ≥ 0.9;把 `J` 换成 `day_std(Ret)` 再做同样的折叠,rank IC 和两本书都保住 | `look.py` C/F 段;S1 的 `s1_fold_ivol` / `s1_fold_roll5` |
| **H2** | **折叠是装饰**:`J` 右偏,`|K|` 的大值几乎全是高 `J`,所以这就是「高波动 → 低收益」的单调因子,折叠只是把低波动的一半搅乱 | A 股的特质波动异象;基线空头腿 −54%、多头腿只占 24% | `|K|` 前 10% 里低侧(`J` < 均值)占比 < 10%;`J` 的 20 分位收益剖面单调下降;不折叠的 `−J` 多空夏普不低于原式 | `look.py` D/E/F 段;S1 的 `s1_nofold` |
| **H3** | **折叠是真的**(方正「适度冒险」的原意):收益对 `J` 是驼峰形,太低和太高都差,最好的在均值附近 | 原始研报的立论;基线里它与 `ctl_ivol` 的 rank 相关只有 −0.14,说明折叠确实改了排序 | `J` 的 20 分位剖面是倒 U;折叠中心扫描在均值所在分位(右偏 → 约 0.6)附近最好,往两边都掉;不折叠的 `−J` 多头腿明显更差 | `look.py` E/H 段;S1 的 `s1_nofold`、S2 的中心替换 |
| **H4** | **先折叠后平滑 ≠ 先平滑后折叠**:`EMA(|K|) = |EMA(K)| + 不稳定度`,多出来的那一项(`J` 相对截面位置在时间上的抖动,研报里的「月稳」)自己带 alpha | 半衰期 0 时原式是亏的(LS −3.14),全靠平滑;被平滑的是**折叠之后**的量 | 「先平滑后折叠」`−|EMA(K)|` 明显弱于原式;单独的不稳定度 `EMA|K| − |EMA K|` 有独立的 rank IC | `look.py` F 段;S2 用 `cross_mean` 写成表达式复核 |

| **H6** | **换手率 / 日频波动的另一种写法**:`ctl_turnrate`(R² 0.072)和 `ctl_dvol20`(0.046)是张成它最多的两个控制;对换手率中性化后扣费多空夏普 4.21 → 2.72 | 基线中性化表 | 把同样的折叠套在 `ctl_dvol20` 上就能复现;对「折叠过的控制变量」中性化后残差 rank IC 大幅下降(线性控制张不成 V 形,所以基线的 R² 0.154 是低估) | `look.py` F 段(`fold(dvol20)`);S2 加折叠版控制变量后重做中性化 |

| **H9** | **多头腿可以做得更好**:原式的多头腿是「`J` 离均值最近的 10%」。如果驼峰的峰不在均值、或者用排名折叠 / 先平滑再折叠能把「适度」的票认得更准,多头腿净超额会上去 | 基线 valid 的分位剖面 Q4..Q10 是平的(+8.6% … +5.9%),说明多头端排序在 valid 上没有信息 | 某个折叠中心 / 折叠方式在 train 和 valid 上**同时**抬高多头腿净超额,且邻域稳定 | `look.py` H 段 → S2/S3 |
| **H10** | 行业 / 板块暴露 | 高波动集中在题材板块 | — | **当前立方体没有行业数据,无法检验**,列为未决 |

**解读**

1. **折叠是必需的,但不是因为「适度最好」**。`s1_nofold` 的 rank IC 反而更高(+0.0389 / +0.0571),书却塌了:
   它的十分位剖面两头都是负的(train Q1 −39.0%、Q10 −4.9%)—— 单调版把多头腿放在了低侧悬崖上。H2 的「折叠是装饰」被杀死;
   H3 的「峰在均值」也没被支持(见 `07x_look.md` E / H 段)。折叠的真实作用是**同时避开两端**。
2. **窗口有邻域,H8 被杀死**:3 / 5 / 15 的 train 多空夏普 +4.14 / +4.21 / +4.01,窗口 3 和 15 与原式的 rank 相关 0.92 / 0.91。
   但 valid 多头腿净超额随窗口**单调**变好:−4.3% → −1.6% → +3.3%。
3. **放量掩码不是装饰,但它买到的是空头腿**。把掩码换成全部分钟(`s1_fold_roll5`)或取反(`s1_mask_quiet`),与原式的 rank 相关
   只剩 0.63 / 0.56(这两者之间 0.98),空头腿从 +53.7% 掉到 +28%~29%,train 多空夏普 +4.21 → +3.2;
   但**多头腿净超额在 train 上持平(+9.0%~+9.1%),在 valid 上从 −1.6% 变成 +10.4% / +11.0%**,纯多头夏普 +2.2~+2.9,
   换手减半(选出的半衰期是 20)。H1(「事件机器多余」)要改写成:**对多空价差不多余,对多头腿多余,而且有害**。
4. 把 2 和 3 连起来是一条阶梯:放量时刻 3 分钟 → 5 → 15 → 全天 std → 全部分钟的 5 分钟 std → 非放量分钟,
   统计量里「放量爆发」的权重越来越小,空头腿越来越弱(+53% → +28%),valid 多头腿越来越好(−4.3% → +11.0%)。
   全天 std 夹在中间是因为它对平方敏感,被最大的那几根分钟线主导,而那几根正是放量分钟。
   这提示有两个不同的量:**爆发波动**(空头腿强)和**背景波动**(多头腿稳)。S2 把阶梯补全并检验它是不是价格水平的伪装。
5. `s1_rankfold` 是另一条路:同一个事件版 `J`,只把折叠换成对称的排名折叠,空头腿减半(两端各取 5%,高端深渊只吃到一半),
   多头腿 +7.3% / +7.1%,两段一致。它过了 dist 门槛(0.87)。

**对假设的影响**:H2 死;H8 死;H1 改写;H3 未被支持;H9(多头腿可以做得更好)有了两个候选方向,但 valid 只有 386 天,
`s1_fold_roll5` 的优势需要邻域(S2)和逐年(S2 诊断)来确认,不能只凭这一行。

**后记(S2 和 `look3.py` 之后的修正)**:上面第 3、4 点把 valid 多头腿的差别全算在「放量掩码」头上,说重了。
这张表里各变体用的是各自选出的半衰期(10 或 20),折叠中心的位置也随统计量的尾巴轻重在变。按同一个半衰期、同一种折叠比
(`07x_look3.md` A 段):train 上多头腿与统计量无关(半衰期 20 时 `J` / 全天 std / 背景波动的均值折叠是 +9.4% / +9.5% / +9.1%);
valid 上 `J` 换成排名折叠就从 +1.3% 回到 +7.1%。掩码的作用是**让统计量的右尾更重**,从而 (a) 给出更强的空头腿,
(b) 把均值折叠的中心推到更高的百分位 —— 后者在 2021–2023 年是坏事(留出段里 2024–2025 年又不是了,见「提纯与升华」一节)。

**后记(修订)**:第 3 点「放量掩码不是装饰」要再收窄一次。这一阶段只把掩码换成过「全部分钟」和「非放量分钟」,从没换成另一种事件。
`SR_rivals` 把它换成不含 Volume 的「`|Ret|` 比当天均值大 1σ」:书与原式分不开(同一批格子上多空 +3.78 / +3.06 对 +3.66 / +3.05,空头腿都是 +48%)。
所以这张表量到的是「事件条件化(大波动分钟附近)的统计量」对「无条件统计量」的差别,不是成交量的作用;「放量掩码买到了空头腿」应读成「把统计量压到大波动分钟上买到了空头腿」。

1. **价格水平 / 报价单位的嫌疑被杀死**。`s2_fold_logprice` 没有任何信号(方向都定成了 +,多空 −0.14 / −1.43),

   除了最高价一档偏弱之外没有集中在低价股。
2. **切片多余**:不切片的版本与切片版 rank 相关 0.99,多空 +3.00 / +3.16 对 +3.19 / +3.33、多头净 +8.5% / +10.1% 对 +9.1% / +10.4%,
   两段都略低一点但在噪声内。开盘两格和收盘集合竞价三格不携带这条因子的信息。
3. **不折叠同样不行**:`s2_roll5_nofold` 的 rank IC 更高(+0.0282 / +0.0442)而书是空的(多空 +0.22 / +1.14),
   十分位剖面 train 两头为负(Q1 −15.0%、Q10 −7.9%)。和 S1 对事件版 `J` 的结论一样:**折叠是这条因子里唯一不能拿掉的节点**。
4. **窗口阶梯在 train 上是平的**。3 / 5 / 15 / 60 / 1(绝对值)的 train 多空夏普 +3.17 / +3.19 / +3.11 / +3.13 / +3.01,

- `sr_fold_jret` — 掩码换成不含 Volume 的事件(|Ret| > 当天 |Ret| 的均值 + 1σ),其余不动:如果 Volume 字段贡献可交易的独有内容,这个版本的空头腿和多空夏普应明显低于原式;不低于 = 放量只是大 |Ret| 分钟的代理

**解读**

1. **Volume 字段不是必需的**。把放量掩码换成「`|Ret|` 比当天自己的均值大 1σ」这个完全不看成交量的事件,`sr_fold_jret` 的多空夏普
   +3.87 / +3.12、空头腿 +49.1% / +48.9%。同口径的对照不是 `v_base` 而是 `sr_orig_nz`(`Jret` 在全天分钟收益为 0 的格子上没有触发、是 NaN,
   所以要把原式里对应的 `J == 0` 格子也拿掉):+3.65 / +3.04、+47.8% / +48.3%。**不用 Volume 的版本不低于原式**,连 valid 多头腿失效(−2.4% 对 −2.2%)
   和逐年的形状都一样(多空 2018–2023:4.03 / 5.43 / 3.76 / 2.81 / 3.69 / 2.18 对 3.72 / 4.93 / 3.32 / 2.99 / 3.51 / 2.27)。
   原式的假设 H1 被我读成「放量掩码有独有内容」是错的:原研究只把掩码换成过「全部分钟」和「非放量分钟」,从没换成另一种事件。
2. **多出来的那部分是「大波动分钟附近的局部波动」,不是放量,也不是分位数**。相对全天 std 的折叠(空头腿 +40.7% / +42.2%),
   放量掩码版和 `|Ret|` 掩码版都多出 6~8 个点空头腿(这是让着全天 std 版的比法:它的空头腿里还含着一字板日;
   把零值格子从每个统计量里都拿掉、在同一批格子上比,是放量版 +48.0% / +48.4%、`|Ret|` 版 +48.3% / +48.1% 对全天 std 版 +35.0% / +40.5%,即 13 / 8 个点,见 `rev_look.py` E 段);
   而不用触发机器、只取滚动 std 第 90 百分位的 `sr_fold_q90` 停在全天 std 的水平(+40.2% / +41.1%)。
3. **「爆发比」不是放量事件独有的信号**。三个比值作为单调因子一样强:`J ÷ roll5`(放量)、`Jret ÷ roll5`(不用 Volume)、
   全天 std ÷ `roll5`(什么掩码都不用)的 rank IC 是 +0.0285 / +0.0272 / +0.0282(train)、+0.0415 / +0.0359 / +0.0459(valid),
   最差一档 −46.6% / −48.6% / −45.8%(train)、−40.3% / −44.2% / −42.7%(valid)。这个量量的是**日内波动集中在少数几分钟里的程度**
   (全天 std 对大的那几根分钟线敏感,滚动 std 的均值不敏感),用成交量去找那几分钟只是其中一种找法。
   直接量 Volume 特有的部分 `J ÷ Jret`:rank IC +0.005 / +0.011,扣费多空 −0.62 / +0.20,最差一档只有 −11.3% / −14.2% —— 做不成书。
4. **一字板日给了多空夏普 0.56(train)/ 0.17(valid)**。把 `J == 0` 的格子(占有值格子的 0.47% / 0.21%)置 NaN:多空 +4.21 → +3.65、+3.21 → +3.04,
   空头腿 +53.7% → +47.8%、+50.1% → +48.3%,多头腿毛超额 +16.9% → +15.6%、+5.1% → +4.5%(等权基准里不再含这些连续下跌的票),
   多头净 +9.0% → +7.5%、−1.6% → −2.2%。H5 不是「死」,是「部分成立」(按收益贡献的拆分见 `rev_look.py` B 段)。
5. **F001 的「日内波动 + 极值记忆」族折叠之后就是近亲**。`cross_max(day_var(Ret), 9)` 套上同样的折叠,train 上就有 +3.83 的多空夏普、
   +7.8% 的多头净超额、+37.0% 的空头腿(原式 +4.21 / +9.0% / +53.7%);valid 上弱得多(+2.13 / −4.5% / +33.7%),逐年多头腿在 2022 / 2023 是 −3.8% / −5.9%。
   原研究写的「与 F001 的三个家族 rank 相关 ±0.05 以内」量的是折叠面板对单调变量的相关 —— 正是 V 形折叠必然给出的零。
   成交额水平那两族(`known_amt_max9`、`known_stdamt_max9`)折叠后确实没有关系(对原式交易信号的 R² 在 0.04 以内,见 `rev_look.py` D 段)。

**对假设的影响**:H1 改为「事件机器对多空价差有贡献,但贡献的是『大波动分钟附近的局部波动』,与用不用 Volume 无关」;
H5 从「死」改为「部分成立」;「与 F001 的族无关」改为「与成交额水平族无关、与日内波动 + 极值记忆族是近亲」。
这些变体都没有读留出段,不进入推荐名单。

- 先看「多头腿净超额」和 `07x_look3.md` 里的纯多头夏普,再看多空夏普。这批变体的多空夏普差别主要来自空头腿(+17% ~ +54%),

所以上面那句「族内的差别只有两个旋钮」要补第三个:**统计量有没有被压到大波动分钟上**(决定比全天 std 多不多出那 8 ~ 13 个点空头腿)。

## 9. 机制诊断

> **修订说明(两路独立审查之后重写)。** 这一节原先是「读留出段之前写的三段」加「读完之后的修正」。审查指出其中六处证据不足或措辞过头,

> 留出段没有再读:修订用到的新数字只来自 train / valid(审查员的 `audit_1.py`、我补的 `SR_rivals` 阶段和 `rev_look.py`)以及已经读出来的那一次结果(`final.json`)。

### 已确立(每条后面是它依据的实验)

1. **折叠之前它就是日内波动**。`J` 与 `day_std(Ret)` 的日截面 rank 相关 +0.90,与全部分钟的 5 分钟滚动 std 均值 +0.85(`look.py` C)。
   放量阈值按每只票当天自己的 σ 定,每天触发约 20 次(p1 = 5、p99 = 32),不带成交额尺度,也没有小样本问题(`look.py` B)。
2. **整棵树里只有截面折叠是不能拿掉的**。不折叠:rank IC 更高(+0.0389 / +0.0571)、多空夏普 +1.34 / +2.35、多头净 −9.0% / +0.2%
   (`s1_nofold`;背景版 `s2_roll5_nofold` 同样)。窗口 3 / 5 / 15 等价(`s1_win3`、`s1_win15`),切片多余(`s2_roll5_noslice`),
   放量掩码对 train 多头腿没有贡献(`look3.py` A:半衰期 20 时三种统计量的均值折叠 +9.4% / +9.5% / +9.1%)。
3. **「先折叠后平滑」和「先平滑后折叠」不是同一个因子**。先平滑后折叠:多头净 −9.5% / −10.2%(`J`,原式是 +9.0% / −1.6%)、
   −4.7% / −6.4%(背景版,先折叠后平滑是 +9.1% / +10.4%)(`look.py` F、`look2.py` F)。口径里的 EMA 作用在折叠之后,这是因子的一部分。
   (只确立到这里;`EMA|K|` 里两项「各自单调」的说法见下面「合理但没有坐实」。)
4. **它是已知暴露的非线性写法,而且是 F001「日内波动 + 极值记忆」族的近亲**。9 个线性控制 R² 0.154;一个「折叠并平滑过的日内波动」R² 0.749 / 0.764
   (`look2.py` A、`audit_1.py` A)。把 F001 的 `cross_max(day_var(Ret), 9)` 做同样的折叠:一个变量张成原式的 42% / 49%(先取对数再折叠是 57% / 64%),
   它自己在 train 上就有多空 +3.83、多头净 +7.8% 的书(valid +2.13 / −4.5%;`sr_fold_kivmax9`、`rev_look.py` D);原式的空头十分位与这一族单调书的空头十分位重叠 70% / 72%(`audit_1.py` D)。
   中性化之后原式残差的 rank IC 还有 +0.039 / +0.035,所以原式是这一族里更好的选股者,但不是新的一族。
   与 F001 的**成交额水平**两族在 V 形意义上无关(折叠版 R² 0.04 以内、折叠后没有多头腿;`rev_look.py` D、`look3.py` D、`s2_fold_logprice`);
   空头十分位与它们的单调书重叠 23% ~ 35%(随机 10%),是「热门票同时成交额大」的共同暴露。
   在 train 上,折叠任何活跃度 / 波动类变量(日内波动、20 日波动、换手率、振幅)都得到多空夏普 3.0~3.6、多头净 +8.4%~+9.7% 的书(`look3.py` D)。
5. **钱主要在空头腿;空头腿 = 换手率 / 波动因子的地盘 + 一字板附近的票**。多头腿只占毛价差的 24%;空头十分位人头 94%~97% 来自高侧,
   平均在换手率第 80、20 日波动第 82 百分位(`look.py` D / G);对线性控制中性化后空头腿 +53.7% → +19.7%,多头腿 +16.9% → +17.3%(基线中性化表)。
   **按收益贡献**(`audit_1.py` C、`rev_look.py` B):高侧的票给了空头腿的 90% / 98%;但当天 `J == 0`(一字板日)的票人头 2.2% / 1.0% 给了 13% / 6%,
   5 日内有过一字板的票人头 6.9% / 4.1% 给了 26% / 15%(20 日内:39% / 27%),上市 60 日内的次新股给了 18% / 12%。
   把 `J == 0` 的格子拿掉,多空夏普 +4.21 → +3.65、+3.21 → +3.04(`sr_orig_nz`)。标签缺失的票只贡献 +0.2 个点。
6. **原式相对全天 std 折叠多出来的是空头腿,而且用不着 Volume 字段**。同一批格子上,放量掩码版和「`|Ret|` 激增」掩码版的空头腿都是 +48%,
   比全天 std 的折叠多 13 / 8 个点;两个版本的多空夏普(+3.66 / +3.05 对 +3.78 / +3.06)、多头净、逐年的形状都分不开(`sr_fold_jret`、`sr_orig_nz`、`rev_look.py` E)。
   不用触发机器的尾部分位数(`sr_fold_q90`)做不到。「爆发比」作为单调空头信号,放量版、不用 Volume 版、完全不用掩码版(全天 std ÷ 滚动 std 均值)
   一样强(rank IC +0.0285 / +0.0272 / +0.0282、+0.0415 / +0.0359 / +0.0459);Volume 特有的部分 `J ÷ Jret` 的 rank IC 只有 +0.005 / +0.011,扣费多空 −0.62 / +0.20(`SR_rivals`)。
   原式对不用 Volume 的折叠 R² 0.792 / 0.848,残差没有空头腿(−0.5% / −5.3%)(`audit_1.py` A)。
   样本外这段空头腿还在:测试段原式 +52.2% 对 4 算子 `f_ivol` 的 +41.3%(多空 +3.70 对 +3.42,差 0.28 在噪声内)。
7. **分位剖面不是「越适中越好」,也不是两道悬崖**:高侧最后 5% 是悬崖(−59% ~ −84%);低侧在剔除一字板日之后只是一道浅坡
   (当天 `J` 最低 5%:train −41% → −9%,valid −13% → −1%;`rev_look.py` B),valid 上整条剖面向低波动倾斜;峰不在均值,最佳折叠中心两段不一致(`look.py` E / H、`look3.py` B)。
8. **原式的多头腿在 2021–2023 年是空的,前后都不是**。用户口径逐年多头腿净超额:2018–2020 +7.5% / +10.8% / +13.6%,2021–2023 +3.7% / −1.7% / −0.7%,
   2024–2025 +8.9% / +5.0%(`final.json` 逐年)。2022、2023 年它的多头十分位不比「波动水平在第 10~80 百分位的全部股票等权」好(−1.8 / +0.7 个点;2018–2020 是 +9 ~ +14;`rev_look.py` C)。
   不用 Volume 的版本同样(`rev_look.py` E 逐年)。
9. **价格水平 / 报价单位不是来源**(`s2_fold_logprice`、价格分桶条件 IC)。
10. **升华没有被样本外支持;最朴素的写法在样本外与原式不可区分**。事前推荐的 `f_roll5` 测试段多头净 +6.6% 对原式 +6.0%、纯多头夏普 +1.41 对 +1.32;
    4 个算子的 `f_ivol` 是 +6.6%、+1.43、多空 +3.42(原式 +3.70)(`S_final`)。

### 合理但没有坐实

- **「波动水平适中且相对位置稳定 → 多头腿」**。`EMA|K| = |EMA K| + 不稳定度` 是恒等式;「两项各自单调」的双重排序在 `roll5` 上两段数据都成立(`look3.py` H),
  `roll5` 版的多头十分位六年里每年都比平台等权多 +6 ~ +11.5 个点(`rev_look.py` C)。**但在被推荐的原式上只有 train 成立**:
  valid 上双重排序里多头十分位所在的那一带没有梯度(最近三分位里按不稳定度五分位 +6.2 / +2.9 / +2.2 / +7.0 / −0.4),
  多头十分位 +5.7% 对平台 +6.6%(`audit_1.py` B)。所以「原式的多头腿 = 适中且稳定的票」只能说到 2021 年为止。
- **排名折叠与均值折叠孰优**。事实:两个排名折叠版 2024 年的空头腿是 −5.3% / +3.7%、多空夏普 −0.07 / +0.82,测试段多空(+1.63 / +2.33 对 +2.97 / +3.70)的差全部来自这一年;
  其余年份排名折叠不差(`f_j_rank` 在 2020、2022、2023 年高于原式,2025 年打平;`f_roll5_rank` 在 2020、2021、2023、2025 年高于 `f_roll5`),训练段两种折叠多空 +3.19 ~ +3.60 对 +3.24 ~ +3.93。
  用户真正交易的多头腿在测试段不可区分(净 +5.0% 对 +6.0%、+5.7% 对 +6.6%,差 1 个点,小于事前写下的 ±3 个点)。
  已量到的结构:排名折叠的空头十分位四到六成人头在低侧,这一半的贡献 2018 → 2023 从 +10 ~ +11 个点缩到 0 ~ +1(`rev_look.py` A)。
  **推断(没有量)**:2024 年低侧那一半转负。它与上面的趋势相容,但 2024 年在留出段里、不能再拆,而且只有一年。
- **2021–2023 年是一段插曲还是会重复的制度**。三个统计量 × 六年的排序一致(`look3.py` A / Y),但它只发生过一次,2024–2025 年没有延续。
- **事件条件化的局部波动为什么比全天 std 多出空头腿**。解读:它量的是「波动集中在少数几分钟里」的票(脉冲式拉升 / 砸盘),无掩码的集中度比值同样强支持这个读法;
  但原式对「全天 std 的折叠 + 无掩码集中度」两个变量的残差在 train 上还有 +2.44 的无成本多空夏普,valid 上是 −0.06(`rev_look.py` F)—— 多出来的东西没有被一个简单的量说尽。
- **经济解读**:空头腿 = 被注意力和博彩需求推高的票(高换手、高波动、波动集中在少数分钟)加上一字板打开之后和次新股的回落;
  多头腿 = 波动只跟着大盘走、没有自己的事件的票。与证据相容,没有直接检验(没有散户成交、龙虎榜、新闻数据)。

### 未决

- **原式样本外的多头腿有多少来自挑选**。测试段 +6.0% 的多头净超额,有多少是「适中且稳定」挑出来的、多少只是「不在最高 20% 波动里」:平台对照在留出段没有量,也不能再量。
- **2024 年排名折叠的空头腿为什么归零**(低侧 / 高侧的拆分需要留出段)。
- **一字板附近的票和次新股在样本外给了空头腿多少**(只在 train / valid 上量过)。
- **行业 / 板块暴露**:当前立方体没有行业数据。
- **多头腿的容量**:背景版多头十分位里市值偏小的一半毛超额 +17.5% / +23.6%,偏大的一半 +8.5% / +3.4%(`look3.py` E);最大市值一档条件 IC 接近 0。
- **为什么日频的活跃度折叠(20 日波动、换手率、振幅,以及 F001 的 9 日极值记忆)在 valid 上多头腿归零,而当天的分钟级波动折叠没有**。
- **原式的多头腿为什么在 2021–2023 年是空的**:只知道它与折叠中心偏高(`J` 的截面均值在第 66 百分位)和那几年剖面向低波动倾斜同时出现。

## 11. 失效模式与风险

- **已知暴露**:这条因子是「日内波动水平」的非线性(V 形)写法。线性中性化的 R² 只有 0.154,会让人以为它与波动 / 换手率因子正交;
  对折叠并平滑过的日内波动,R² 是 0.749(valid 0.764)。它也是 F001「日内波动 + 极值记忆」族的近亲:对 `cross_max(day_var(Ret), 9)` 的折叠版 R² 0.42 / 0.49
  (取对数 0.57 / 0.64),空头十分位与这一族的单调书重叠七成 —— 「与已知家族 rank 相关 ±0.05」对折叠型因子不是分散化的证据。
  组合里如果已经有波动、换手率类因子,它的空头腿(占毛价差 76%)基本是重复的:
  对线性控制中性化后空头腿毛超额 +53.7% → +19.7%。增量在多头腿:对线性控制中性化后多头腿毛超额 +17.3%(不降);但对**折叠版**的日内波动中性化后是 train +11.4%、valid +4.6% —— 增量在 valid 上小得多。
- **钱在做不了的那条腿上**。用户口径多空夏普 3.93 / 3.70 里,多头腿毛超额 13.6% / 12.0%,空头腿 52.7% / 52.2%。
  纯多头能拿到的是净超额 +6.0% / +6.0%、夏普 1.33 / 1.32 —— 稳,但不是 3.9 那个量级。
- **多头腿有三年是空的,而且多头腿的机制没有坐实**。2021 / 2022 / 2023 年多头腿净超额 +3.7% / −1.7% / −0.7%(整年),2024–2025 恢复。原因没有坐实(见未决),
  所以不能保证不再发生;这三年里多空夏普仍有 2.8~3.7,问题只在多头一侧。
  更要紧的是:光「避开最高 20% 和最低 10% 波动」的平台等权每年就有 +5.5% ~ +8.0% 的毛超额,原式的多头十分位在 2022、2023 年并不比它好(−1.8 / +0.7 个点;
  2018–2020 年多 +9 ~ +14 个点)。「适中且稳定」的挑选在原式上只到 2021 年有证据。**测试段 +6.0% 的多头净超额里有多少是挑选、多少只是避开高波动端,没有量,也不能再量**
  (留出段已读)。全天 std 的折叠和 `roll5` 的折叠在 2022–2023 年相对平台还有 +2.5 ~ +11 个点。
- **成本与半衰期**。原始日频面板扣费后是亏的(半衰期 0:多空 −3.14、日换手 70%),全靠折叠之后的 EMA。半衰期 10 → 20 多头腿净超额还能再高 1 个点左右
  (用户训练段 +6.0% → +7.1%,测试段 +6.0% → +7.1%),代价是多空夏普降 0.3~0.6。按多空夏普选半衰期,对纯多头不是最优。
- **容量**:信号在最大市值一档基本失效(条件 IC −0.0061),背景版多头十分位里市值偏大的一半毛超额只有 +8.5% / +3.4%(train / valid),
  原式的多头腿没有单独量过,大概率相同。
- **过拟合(本研究自己的)**:本研究在 valid(386 天)上看到背景版多头腿高 12 个点、且 2021–2023 每年都更好,据此做了事前推荐,留出段里优势消失。
  教训记在实验室结论里:train 持平、只在 valid 上领先的多头腿改进,样本量其实只有「一段行情」。
  **解释上的过拟合**(审查指出的):读完留出段之后,原报告又把 2024 一年排名折叠的空头腿归零写成了「均值折叠样本外更好」的规律,
  把只在 `roll5` 上做过的双重排序套到原式头上,把从没和不含 Volume 的事件比过的空头腿归给了「放量」。三处都已降级或改写(见「机制诊断」的修订记录)。
- **排名折叠的尾部风险(只对做多空的人)**:两个排名折叠版 2024 年空头腿 −5.3% / +3.7%、多空夏普 −0.07 / +0.82,其余七年正常。这是一次观测;
  对多头腿,两种折叠在测试段不可区分。
- **泄漏**:没有发现。放量阈值用的是当天全天的均值和标准差(事后阈值),对收盘后才使用的日频因子不构成未来信息;`in_sustain_stddev` 的窗口朝后看 4 分钟,同样在当天之内。
- **数据口径 / 做不了的票**:停牌 / 全天零成交的票没有触发、因子值为 NaN(覆盖率 0.9991,过门槛)。一字板的票 `J = 0`,折叠后 `|K|` 等于截面均值,被送进空头十分位。
  原来这里写「占空头腿 2.2%,影响很小」—— 2.2% 是人头,按收益不小:当天 `J == 0` 的票给了空头腿 +7.1 个点(13%,train)/ +3.0 个点(6%,valid),
  5 日内有过一字板的票(人头 6.9% / 4.1%)给了 +13.8 个点(26%)/ +7.6 个点(15%),20 日内的是 39% / 27%;上市 60 日内的次新股占空头人头 15% / 12%、给了 18% / 12%。
  去掉当天 `J == 0` 的格子,多空夏普 +4.21 → +3.65(train)、+3.21 → +3.04(valid),多头腿毛超额 +16.9% → +15.6%、+5.1% → +4.5%(基准里不再含这些票)。
  标签缺失(次日开盘封涨停买不进)的票贡献只有 +0.2 个点。全天 std 和 `roll5` 的折叠里同样有这一块(多空各掉 0.5 ~ 0.7 / 0.1 ~ 0.2),所以候选之间的比较不受影响,
  受影响的是**公布的多空夏普的绝对水平**:3.9 里大约有 0.2 ~ 0.55 是一字板附近的票给的。样本外这一块占多少没有量。
- **行业 / 板块**:没有行业数据,无法排除空头腿集中在题材板块。

## 12. 下一步实验

只列能显著降低不确定性的(修订后重排;带「修订」的是审查之后加的或改的):

1. **(修订)原式的多头十分位在新数据上比平台好不好**。平台 = 波动水平在第 10~80 百分位的全部股票等权。train / valid 上的答案是「2018–2021 年好 +6 ~ +14 个点,2022–2023 年不好」;
   留出段(2024–2025)没有量、也不能再量。等 2026 年的数据进来,先量这一个数 —— 它决定这条因子对纯多头是「一个选股信号」还是「一个避开高波动端的过滤器」。
   如果是后者,4 个算子的全天 std 折叠、甚至「去掉最高 20% 波动」就够了。
2. **2021–2023 年原式多头腿为什么是空的**。把多头十分位按行业、市值、是否为前期强势股拆开看那三年的超额;需要行业数据。
   这决定了多头腿 +6% 的净超额是「每十年里有三年不灵」还是「一次性的」。
3. **(修订)「日内波动的集中度」单独立项,对照要选对**。原来这一条写的是「爆发比 `div(J, roll5)` 单独立项」。修订后它不该再被当成放量事件的信号:
   立项的对象应是最简单的那个写法 —— 全天 std ÷ 滚动 std 均值(`sr_ratio_ivol`,3 个算子、不用 Volume、不用掩码;train / valid rank IC +0.0282 / +0.0459、多空 +2.77 / +3.40),
   以 `Jret ÷ roll5`、`J ÷ roll5` 为对照,问的是「事件条件化有没有在无掩码的集中度之上多出东西」(train / valid 上:残差 rank IC +0.03、但做不成书)。
   三者都没有读留出段;多头腿都弱而且两段不一致(净超额 train −4.8% ~ −0.1%、valid +4.0% ~ +8.7%),只对做多空或做负向筛选的人有用。
4. **(修订)排名折叠的空头腿在低波动端反转的年份里是谁在亏**。train / valid 上已经拆过(`rev_look.py` A:低侧那一半从 +10 个点缩到 0);
   2024 年的拆分需要留出段,本研究不能做。等有新的样本外年份,把排名折叠的空头十分位按低侧 / 高侧拆开逐年看,才能判断「2024 年」是不是一个会重复的尾部。
5. **(修订)一字板附近的票和次新股**:5 日内有过一字板的票给了空头腿的 26% / 15%(train / valid),20 日内的 39% / 27%,上市 60 日内的次新股 18% / 12%。在整批因子上统一做一次「剔除上市 60 日内、剔除 20 日内有一字板的票」之后的多空夏普,
   看用户表里的排序会不会变 —— 任何「日内波动 / 收益类统计量 == 0」被折叠或排到一端的因子都有这个问题。
6. **多头腿的增量价值**:把原式的交易信号对组合里已有的波动 / 换手率因子(包括它们的折叠版)正交化之后,多头十分位还剩多少净超额。
   修订里补了一半:对折叠版日内波动中性化后,残差多头腿毛超额 train +11.4%、valid +4.6%(未扣费、残差未再平滑);样本外没有量。
7. **按纯多头夏普选半衰期**的口径在整批因子上是否系统性地更好(本因子上 +1 个点净超额,样本内外一致)。
