# 反向指引 AlphaCube:B01 的研究结论怎样改变搜索

Partura 不是 AlphaCube 的下游:研究结论在这里变成对搜索的四类干预 —— 奖励、评估、动作与子结构的先验、交给搜索的想法。证据来自 15 条因子、2794 个打过分的变体(其中 5.4% 是废品)和 154 条实验室结论;范围是这批种子的邻域,所以权重是先验,靠每一次带对照的干预实验去更新。机器读的版本是 `guidance/B01.yaml`,做法见 `docs/reverse_guidance.md`。

下面的「夏普变化」都是**成对**的:同一个动作套在每条因子上,变体减它自己的底座,训练段纯多头夏普;超过 ±0.3 才算数。

## 先说结论

1. **现在的奖励在给流动性倾斜付钱。**「只在成交额最低四成里选」这一个动作,不管套在哪条因子上都把纯多头夏普抬高 +1.12(87% 明显变好、93% 两段都升);反过来「只在成交额最高四成里选」是 -2.51 / -1.21(两个方向都试了,93% / 87% 明显变差)。所以搜索头部才会全是成交额一族 —— 要改的是奖励(桶内选股、可交易池、对池子的边际贡献),不是再多封几个结构。
2. **对自身历史做 z 分数必须封禁。** 60 例里 100% 明显变差、没有一例两段都升,夏普中位 -2.30。外层的截面折叠(-0.57)、滚动标准差(-0.74)、除以自己的历史均值(-0.79)是同一类错误:把持久的截面水平除掉了,而多头腿就在水平里。
3. **外层的慢记忆和更长的平滑半衰期是同一件事。** 半衰期网格只到 20 日时,外面再套 30~60 日的均值 / 指数平均能把夏普抬高 0.12 左右;网格放到 40 / 60 之后,同样的包裹只剩 +0.04 / +0.02(两段都升 48%~50%,明显变差 7%~15%)—— 之前看到的增益是「平滑不够长」,不是结构。评估时让半衰期自己去选,不必让搜索去套记忆。
4. **把任意因子叠到已知族上没有用。** 三个权重 × 15 条因子,两段都升的是 0% / 0% / 0%。值钱的是和池子不相关的东西融合之后的增量,所以奖励要直接量「对池子的边际贡献」。
5. **5% 的评估预算花在废品上**(门槛改算在实际交易的信号上之后;之前算在原面板上时是 10%,一半是误杀),其中有整类可以事先拒绝:截面聚合(cs_mean / cs_sum / cs_median / cs_stddev_full)当因子用 100% 是废品。

6. **样本内的成对统计不等于样本外(2026-10-06 的两次对账)。** 对已知族做筛子:通用冻结筛子样本内比已知族每年多 +3.1%(信息比 +0.92),样本外只多 +0.9%(t = +0.6);短搜找到的九个单层筛子样本外 t 最高 +0.6,按样本内挑的六个多层筛子最高 +1.1 —— 没有一条达到事先写下的 t ≥ 2(`studies/K001_known_screens/README.md`)。筛子的增益集中在 2018–2020。融合:独立升级版的融合比 15 条原式的融合样本外每年多 +6.5%(t = +1.5,幅度和样本内的 +5.5% 一样);比已知族多 +2.3%(t = +0.6)—— 2.3 年的样本分不出来。所以「比基准好」一律用同一天相减的成对差来判(规则 E9)。
(更正:上一版这里还写着「分母里的 +1e-6 删掉之后 7 例全部变好」。审查发现那 7 例里真正碰到 1e-6 的只有 4 例、其中 3 例判废,剩下 1 例的消融也不是干净的删除 —— 这句话没有证据,已删;对应的规则由封禁降为降权,理由只剩两条手写因子的机制分析。)

## 二、评估方法

| | 改什么 | 为什么 |
|---|---|---|
| E1 | 先过门槛再算任何奖励 —— 覆盖率 ≥ 0.95、取值个数比例 ≥ 0.5(截面上近似常数 / 只有几十个取值的直接判废) | 我们自己生成的变体里废品率 10.1%;「cs_demean 换成 cs_mean / cs_sum / cs_median / cs_stddev_full」100% 是废品 |
| E1b | 取值个数的门槛算在实际交易的信号上(面板过完 EMA 之后),不是原面板上;筛子 / 分段类(cs_first_* / cs_last_*)的方向锁定,不让 rank IC 去翻 | 计数 / 占比类面板(零收益分钟占比、桶内排名)任一天只有几十个取值,被机械判死,而它们平滑之后是连续的 —— 这批里最有用的几个状态变量都是这一类;方向被翻转的筛子会把「永不持有」测成「只持有」而且不报错 |
| E2 | 每个候选连同便宜的兄弟一起评、取最好的记分:自身(半衰期网格到 60 日)、排掉冻结盘口的筛子版;外面再套 cross_ema(·,30) 在网格到 60 之后已经多余 | 这三样是对几乎所有底座都安全或有益的后处理(EMA / 均值记忆 50~60% 两段都升、只有 3~16% 明显变差);让搜索去重新发现它们是浪费预算 |
| E3 | 判断「是不是已知族的同一笔钱」用三样一起:秩相关、多头书重合度、逐年净超额的形状;封禁按经济量(对已知池中性化 / 剔除后多头腿掉多少),不按结构 | 筛子把两成股票压到底,秩相关掉到 0.4~0.6 而持有的书重合 80%;反过来秩相关 0.85 的两条(已知族与它的「第二流动性十分位」版)多头书只重合 6% |

| E5 | 选拔只看多头腿(净超额、纯多头夏普),多空夏普只作参考 | 可买入标签把次日封涨停的票记成缺失,空头书里等于收益 0,集中度 / 峰度类因子的多空夏普因此虚高 0.5~0.7;15 条原式多空夏普 2.3~3.9,多头腿站得住的只有 5 条 |
| E7 | 检验「先验 / 指引有没有提高发现率」的实验,每臂至少几千次评估;几百次的短搜只用来回答「这个想法的邻域里有没有东西」 | 桶内口径下随机搜索的发现率低于 1%,每臂 124 次评估时两臂的差别全在抽样误差里(e2_I5:≥0.3 的 2 对 0,≥0 的 8 对 15,方向都不一致) |
| E10 | 一次搜索「找到了几个」按实测互不相关的个数算(交易信号两两秩相关 < 0.7),式子的族数只当上限 | 族键只认价格字段换名和最外层保序函数;一个撞对了的结构会被 GP 繁殖成一串窗口、嵌套不同的变体,每个都是一「族」。e5r1 是 27 族 / 实测 4 个;e4k 三个种子合计 44 族对 4 族,实测是 16 对 3 |

## 三、动作与子结构的先验(重点)

规则对生成器的作用是「接受-拒绝」:每棵候选树以 min(1, 权重 ÷ 最大权重) 的概率放行,封禁的永不放行 —— 生成器原来的提议分布 P 就变成 P × 权重,不需要生成器自己支持算子概率。改写在打分前做,等价的候选只评一次。
