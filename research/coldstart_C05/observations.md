# C05 运行中记下的、要进 RESULT 的观察(样本内;不是判读结论)

1. **奖励的漏洞:EMA 之前的凸变换 + 线性中性化会把被控制掉的东西重新造出来**(801 第 3 轮解剖员指出,本地合成数据复核)。
   `day_durbin_watson(X)` 的分母不去均值,≈ 日内已实现方差,与波动控制 `cross_mean(day_std(Ret), 20)` 是同一个量。
   `dw` / `signedpower(dw)` / `signedpower(signedpower(dw))` 逐日截面排序完全相同,score 却是 −1.85 → −0.21 → +1.26,单调于凸度;
   合成模拟里 signal = x^e 投影掉控制后,残差与控制的秩相关在 e = 1/2/4 时为 −0.42 / −0.68 / −0.90。sign 全是 −1 ⇒ 多头书 ≈ 低波动异象的多头腿。
   对 M、A、B0、B 一视同仁;最终读样本外时要看各组库里有多少 head 属于这类「控制变量的非线性重表述」。
2. **列序斜坡**(801、805 等多个解剖员独立指出):常数面板经 `_pct_rank` 序号排名后变成一条按面板列序的静态斜坡,
   `cs_last_high*(<常数>, X)` 这类写法借它通过 distinct 门;其样本外价值无法从样本内读出。
