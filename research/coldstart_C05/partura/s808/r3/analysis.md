## 1. alpha 的来源

本轮快照里有 **3 条像真东西的轴** 和 **3 条代理**。和上一轮比,排第一的换人了:新出现的「成交的日内时点」把 M 的那条轴挤到第二。

### 1.1 来源 D(本轮最强,而且是本组自己的):`day_centroid(Amt)` 的**慢分量** —— 成交发生在一天里的什么时候

涉及的 head:

- **+1.77** `ts_mean(cs_bucket_rank(day_centroid(Amt), ts_max(ts_max(cs_bucket_zscore(day_distinct_ratio(Ret), ts_max(cs_bucket_zscore(day_distinct_ratio(Ret), LogFloatCap), 40)), 40), 40)), 20)`(sign −1,hl 5;家族口径)
- **+1.64** `ts_mean(cs_bucket_zscore(day_centroid(Amt), cs_bucket_zscore(day_autocorr_n1(Ret), LogFloatCap)), 20)`(sign −1,hl 5;标准口径)

**被测的量是什么**(读源码,`partura/ops_ext.py:155`):
`day_centroid(x)` = `sum(t·|x[t]|) / sum(|x|) / (T−1)`,即 |x| 沿分钟轴的**质心**,归一到 [0,1]:
0 = 全在开盘,1 = 全在收盘,0.5 = 对称。注释自己写了「作用在 Volume / Amt 上:成交发生在一天的什么时候 ——
这是每一个与顺序无关的统计量(std、kurt、gini)都丢掉的信息」。
面板是 `n_minutes = 241`(240 根分钟 + 1 根,推断最后一根承载收盘集合竞价),所以这个量**很可能把收盘竞价的成交占比读进去了**(本节末「未检验的风险 1」)。
sign = −1 → 多头那一端 = 质心低 = **成交集中在早盘**;回避的是**成交压在尾盘**的那一端。

**证据(全部付费,括号里标口径):**

| 证据 | 数字 | 读法 |
|---|---|---|
| 充分性:`ts_mean(day_centroid(Amt), 20)` 单独 | **+1.2695**(train 1.2695 / valid 1.7053,标准) | 本种子**最强的单一被测量**,比 M 那条轴的最小单元(+0.58 / +0.67)高一倍 |
| 充分性:`day_centroid(Amt)` 裸日度值 | **−0.0846**(train −0.0846 / valid 0.5839,标准) | **当日值是噪声,慢分量才是信号**。1.35 个夏普全部由 20 日平均造出来 |
| 必要性(head 2,干净口径):去掉组内 z 分 → `ts_mean(day_centroid(Amt), 20)` | 1.6405 → 1.2695(**+0.371**) | 组内比较值 0.37 |
| 必要性(head 2):分组变量不再按市值去水平 → `ts_mean(cs_bucket_zscore(day_centroid(Amt), day_autocorr_n1(Ret)), 20)` | 1.6405 → 1.4471(**+0.193**) | 内层那次去水平只值 0.19 |
| 必要性(head 1,跨口径下界):去掉组内 rank | 1.767 → 1.2695(**≥ +0.498**) | 同上 |
| 字段敏感性 `Amt → Volume` | head 1:1.767 → **1.5574**;head 2:1.6405 → **1.6583** | 两种权重(金额 / 股数)几乎等价 → 读的是**时点**,不是金额水平 |
| 窗口敏感性 `ts_mean@10 / 20 / 40` | head 1:1.4865 / 1.767 / 1.2808;head 2:1.525 / 1.6405 / 1.3962 | 三档都 ≥ 1.28,峰在 20,不是窗口拟合 |
| 两段 | head 1:train 1.858 / valid 1.767;head 2:train 1.640 / valid 2.361 | 都没有「train 掉、valid 升」的降换手形状 |

**分组变量不是装饰,它是本轮最大的一笔收益。** 同一个被测量、同一个 20 日平均,只换分组:

| 分组变量 | score | 来源 |
|---|---|---|
| 不分组 | +1.2695 | 拆解 knockout |
| `LogFloatCap` 十分位(`ts_mean(cs_bucket_zscore(day_centroid(Amt), LogFloatCap), 20)`) | **+1.1194** | `Br2b` 过线者(标准口径) |
| 市值十分位内的分钟收益 lag-1 自相关(head 2) | **+1.6405** | head |

→ **按市值分桶比不分桶还差**;把被测量放进「微观结构噪声 / 栅格粒度」的同组内比较,才加 0.37–0.50 以上。
这条和上一轮 R 的读数完全一致(head 4:条件变量从 `LogFloatCap` 换成 `cross_mean(day_sum(Amt), 20)`,0.8156 → **0.9853**,+0.17,已替换),
而 `cross_mean(day_sum(Amt), 20)` 自己的 **ρ_known = −0.9764** —— 它基本就是已知族本身。
→ 可以把这件事说成一句可迁移的话:**奖励的中性化是秩空间的线性投影;把被测量放进控制变量(流动性 / 已知族 / 噪声)的十分位内做条件标准化,
等于补上一次「非线性正交化」,而这正是线性投影挡不住的那部分。** 这是本种子三轮里最硬、最可迁移的一条结构性发现。

**是不是「只是代理」?** 这一次必须诚实地说:**它有一半身子贴着已知族的墙。**

- 已知族是 `cross_mean(day_std(Amt), 30)` = 日内 Amt 剖面**离散度**的 30 日均值;`day_centroid(Amt)` 是**同一个剖面的时间维矩**。
  两者天然同源,实测 `ts_mean(day_centroid(Amt), 20)` 的 **ρ_known = −0.5113 → 单独放进库里会被判不合格**(门槛 |ρ| ≥ 0.5)。
- 包装之后:head 1 的变体 ρ_known 在 **−0.407 ~ −0.5575** 之间(`ts_mean@40` 那一支 −0.5575 **已经越线**),
  head 2 的变体在 **−0.153 ~ −0.4856**(不带 20 日平均的那一支只有 −0.1531,score 也只有 0.5027)。
- **慢化同时制造 alpha 和制造纠缠**:`cs_bucket_zscore(day_centroid(Amt), cs_bucket_zscore(day_autocorr_n1(Ret), LogFloatCap))` 不平滑时 score 0.5027 / ρ_known −0.153;
  平滑 20 日后 score 1.6405 / ρ_known ≈ −0.42(推断,介于 @10 的 −0.343 与 @40 的 −0.486 之间)。
  已知族自己就是 30 日均值,所以**平滑窗口越长,分数越高也越像已知族,0.5 这道墙正好卡在 20–40 日之间。**

三条反驳(为什么我仍判它是真来源,而不是已知族的另一种写法):
(i) 字段替换(`Amt ↔ Volume`)几乎不动分数 —— 已知族是金额离散度,如果读的是同一件事,换成股数应该明显变化;
(ii) 裸日度值 −0.08 而 20 日均值 +1.27,这个形状是「持续性的交易时点风格」,不是「成交额波动」;
(iii) 组内条件化把 |ρ_known| 从 0.51 压到 0.41 的同时**分数还升了 0.37–0.50** —— 纯粹的代理在被正交化之后分数应该掉。

**没检验、必须写下来的两个风险**:
1. **收盘集合竞价通道**。241 根分钟里最后一根(推断为收盘竞价)在 A 股对指数 / ETF 重仓股的占比极高,
   `day_centroid` 会把它读成「质心靠后」。如果多头那一端只是「没有被动资金在尾盘买的股票」,那这条轴更接近「指数成分 / 被动持股」的代理。
   → R 变体「被测量换 `day_argmax(Amt)`(成交峰值出现的时刻)」可以把这条通道分开(峰值时刻不受单根竞价的质量支配)。
2. **制度过渡**。样本从 2018-01 开始,而 A 股的收盘集合竞价是 2018 年引入的 → train 段可能横跨制度变化。这是文献题目 Q1 (v)。

### 1.2 来源 A(M 第 2 批那条「分钟收益栅格粒度」):本轮被上一轮的 R 改写了三处,降为第二

涉及的 head:+1.45 `ts_max(ts_max(cs_bucket_zscore(day_distinct_ratio(Ret), ts_max(cs_bucket_zscore(day_distinct_ratio(Ret), LogFloatCap), 40)), 40), 40)`(M2)、
+0.985 `ts_max(ts_max(cs_bucket_zscore(day_distinct_ratio(Ret), cross_mean(day_sum(Amt), 20)), 40), 40)`(M2,R 替换后的写法)、

`ts_max(ts_max(cs_bucket_zscore(day_distinct_ratio(Ret), ts_max(cs_bucket_zscore(day_distinct_ratio(Ret), LogFloatCap), 40)), 40), 40)`

(b) 在这条轴上继续堆条件化的边际价值已经很低,**本组不该再花 GP 位在它上面**(§4.1 核心 C)。

**它仍然是真来源**(M 的,不是我们的):+1.45 的那支 train 1.466 / valid 1.455、三档窗口 ≥ 1.16、ρ_known −0.15。
但本组在它旁边长东西,产出最可能被 M 自己的 head 顶掉(最终库 M 在前)。

### 1.3 来源 E(新):分钟收益 lag-1 自相关,在市值分位内 —— Roll 价差 / 微观结构噪声

涉及的 head:+0.953 `ts_max(ts_max(cs_bucket_zscore(day_autocorr_n1(Ret), LogFloatCap), 40), 40)`(sign −1,hl 0)、
+0.644 `ts_max(ts_max(cs_bucket_zscore(day_autocorr_n1(Amt), LogFloatCap), 40), 40)`(`Amt` 版),
以及 head 2 里当分组变量的 `cs_bucket_zscore(day_autocorr_n1(Ret), LogFloatCap)`。

**是什么**:`day_autocorr_n1` = `day_autocorr(x, 1)`(`alphacube/operators/dt_day.py:302`,别名见 `catalog.py:168`),
当日分钟序列的 lag-1 自相关。作用在分钟收益上,它就是 **Roll(1984)有效价差估计量的同一块材料**(买卖价差反弹 → 负自相关),
也是微观结构噪声的常用读法。

**证据(干净口径):**

| 证据 | 数字 | 读法 |
|---|---|---|
| 充分性:`day_autocorr_n1(Ret)` 裸量 | **−0.8536** | 单独是负 alpha |
| 充分性:市值分位内 z 分 | **−0.6692** | 条件化本身不够 |
| 充分性:套一层 `ts_max@40` | **+0.061**(train 0.384 / valid 0.061) | 还是不够 |
| 充分性:两层 `ts_max@40` | **+0.9525**(train 0.953 / valid 1.095) | **第二层上包络一个人贡献 +0.89**,而且 train / valid 同时升 |
| 必要性:去掉 `cs_bucket_zscore` | 0.9525 → **−0.0311**(**+0.984**) | 分位内条件化是必需的 |
| 窗口敏感性:外层 20 / 40 / 80 | 0.5744 / **0.9525** / 0.7473 | **峰在所选的 40**,敏感性一般(来源 D 那两个是三档都稳) |

**判为真来源,但比来源 D 弱一档**:从 −0.67 到 +0.95 全靠「两层 40 日上包络」,而窗口在所选值上有峰 ——
「刚好 40×40」这件事有过拟合气味。它最确定的价值反而是**当分组变量**:它把 `day_centroid(Amt)` 从 1.27 抬到 1.64(§1.1)。
→ 把它作为 E 的核心是合理的第二选择,但要先用 R 问清「lag-1 自相关 vs AR1 系数 / Durbin-Watson 是不是同一个东西」(§2.5 第 13 条)。

### 1.4 三条代理,逐条判死

**(a) 来源 B(规模杠铃)—— 上一轮的 R 已经把它判死了。** 涉及 head 7(+0.745)与 head 11(+0.562)。
上一轮我判它是「控制变量的几何残留」,R 的三条给了结论性的读数:

- 改筛最小 5%(`→ cs_last_low05`):**−0.1405**
- 三层 `ts_max → ts_mean`:**−0.6035**

断点一放宽就从 +0.74 掉到 −0.70,跨度 1.44 个夏普。这是**筛子几何**,不是机制。
head 7、head 11 是库里的两个噪声位,而 R 只能「替换」不能「删除」(PLAN 修订 10 (2)),
三个变体的分数全是负的 → **换不掉,只能留着**。这是本组账面上确定的损失。

**(b) 新代理,而且是本组自己的 N 位产出的:head 6 `ts_mean(cs_bucket_zscore(LogFloatCap, LogFloatCap), 20)`(+0.949)。**
读源码(`ops_ext.py:482`):`cs_bucket_zscore(y, x)` 把 y 按 x 的十分位分组、组内去均值除以组内标准差。
这里 y = x = `LogFloatCap` → 它就是「**市值在它自己所属十分位内的位置**」= 对 `LogFloatCap` 做一个**锯齿**变换(每个十分位内重新展开一遍)。
`LogFloatCap` 就在控制里,而中性化是秩空间线性投影 → 锯齿是它最挡不住的形状之一。
train 0.954 / valid 0.949,很稳 —— 但稳的是**几何**,不是机制。
→ 它和 (a) 是同一类东西的两种写法(一个用 5% 断点,一个用十分位锯齿),区别只是我们自己生产了后者。
**这是本轮最该写进笔记的自我批评**:N 位 5 个 head 里有 1 个是控制变量的几何残留,占了 20% 的产出。

**(c) 来源 C(`LogFloatShares` 静态簇)—— M 第 3 批自己落进来了,本组 r1 的产出大概率归零。**
head 9 = `cross_quantile_q50(cross_quantile_q50(cross_delay(cross_quantile_q50(LogFloatShares, 60), 60), 60), 60)`(+0.643,**M3**)

### 2.2 近乎 0 的那一个:head 1 内层的双重条件化

(i) 当一个新特征与一个既有的流动性 / 成交量波动类特征相关系数约 0.5 时,文献用什么办法判断**增量**(双重排序、组内标准化、正交化、增量 t 值)?
(ii) **把一个特征放进另一个变量的分组内做条件标准化**,文献里有没有被当成一种「**非线性正交化**」讨论过,和线性回归残差差多少?
特别是**分组变量怎么选**(行业、规模、流动性、价差 / 噪声水平、相对一跳)—— 有没有比较过不同分组的效果?
我们的实测很反直觉,值得对照文献:同一个被测量,**按市值十分位分组比不分组还差**(1.12 vs 1.27),
按流动性 / 微观结构噪声分组则升到 1.64–1.77,而那个流动性分组变量本身与已知族 |ρ| = 0.98。

English: within-group standardization vs regression orthogonalization, nonlinear neutralization of a control,
choice of the first-stage variable in a conditional (dependent) double sort, characteristic-matched benchmarks,
industry- or liquidity-relative characteristics, incremental information tests for correlated characteristics.

### Q3(对准核心 B:分钟收益 lag-1 自相关)

Roll(1984)式的**序列相关价差估计**与微观结构噪声度量,文献里:
(i) 怎么**构造和归一化**(用协方差还是自相关、要不要按当日波动缩放、分钟频率下的偏误);
(ii) 有没有被当成**横截面收益预测变量**(噪声 / 隐含价差高的股票未来收益更高还是更低,控制了 Amihud 之后还剩什么);
(iii) 文献里有没有用一个股票特征的**多日滚动最大值**而不是均值 —— 我们这里单层 40 日 max 只有 0.06、两层 0.95、换成平均更差,
这个「上包络」的用法有没有先例或解释(例如「近期最差的流动性状态」才是定价的那个状态);
(iv) **中国市场**(T+1、涨跌停、散户主导)的同类研究 —— 日内 lag-1 自相关在 A 股读到的是买卖价差反弹,还是别的东西。
中文关键词:Roll 有效价差估计、收益序列相关、微观结构噪声、价差与预期收益、分钟级收益自相关、日内反转、T+1。
English: Roll (1984) implied spread, serial covariance spread estimator, microstructure noise variance,
bid-ask bounce, minute-level return autocorrelation, illiquidity and expected returns, running maximum of a stock characteristic,
