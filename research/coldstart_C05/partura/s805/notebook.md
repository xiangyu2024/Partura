任务文件:`r1/missions.yaml`(E 位 = 核心 `day_centroid(Volume)`;N 位 = 日内形状统计量铺开;R 空)。校验 `c05_check.py 805 1`:ADMISSIBLE。

### 我目前对本种子 alpha 来源的信念

1. **还没有任何被证明的 alpha 来源。** 共性表 6 行(5 张核心卡)是同一个量 `day_centroid(Volume)` 的保序改写:非负输入上的 `pow_1_5` / `pow_2_5`
   经过奖励里的 z-rank 不改变任何一天的秩序(hl = 0 时是同一本书)。所以这一批真正只有一个候选核心,而且共性 +2.01 的含义是「含它的平均 0.00、不含的平均 -2.01」:
   它测到的是**不崩塌**,不是**赚钱**。我同意解剖员的「驯顺」读法:有界、无量纲、慢变的量在 train 上没有肥尾可过拟,所以 valid 不翻车;这本身不是 alpha。
2. **如果日内成交时点这一维有 alpha,它在偏离和条件化里,不在水平里。** 重心在横截面上高度持续,是一个股票属性;未被定价的属性 score 就该约等于 0,实测正是如此。
   我给「偏离 / 交互版本里有 >= 0.5 的东西」的先验大约 30%。最可能的机制是收盘段机构 / 被动资金的价格压力(美股有 Bogousslavsky-Muravyev,A 股有 Qiu 等 2023 的机构开收盘活跃),
   它应当表现为「异常晚盘 x 当日方向」的短期回吐,而不是「晚盘多」本身。
3. **这一批给出的更可靠的线索是「哪一类量不崩塌」**:有界、无量纲的日内形状统计量。与奖励里五个控制(全是水平量或收益量)在构造上最远的是**日内量价关系与带方向的成交**
   (分钟 Close-Volume 相关、Ret-Volume 相关、净买压、成交最重分钟的收益)。我对这一支的先验比对成交时点高,约 50% 能在 96 次评估里出至少 1 个 head。
4. 成交时点有 4 条代理通道(收盘竞价 / 指数成分、开盘散户、锁板与停牌的机械偏移、价格格点),本轮用 E 的 B 类种子顺带检验,不预设结论。

### 本轮各任务的事先预测(第 2 轮核对)

**E 位(slot a,核心 `day_centroid(Volume)`)**
- 产出 head 的概率约 30%。若有,最可能来自 C 类交互(`mul(cross_zscore(core, 20), day_signed_ratio(Ret, Amt))` 或与时间加权日内收益相乘)或 A 类偏离,方向为**负**(异常晚盘 + 当日上涨 -> 之后跑输,即收盘压力回吐);不会来自 B 类。
- B 类(按 `LogFloatCap` / 成交额 / 冻结报价频率分桶)的种子 score 与 0 相差不超过 0.15:分桶不会把这个属性救活,也不会让它塌得比 0 更低(它既不是有用信号,也不是被代理压住的信号)。
- A 类与 C 类种子的平均 score 高于 B 类;全部 E 候选里最好的 score 落在 [0.3, 0.7]。
- 机械嫁接的 16 个随机个体平均 score <= 0,对结果几乎没有贡献;证据里会有不少 `c05_no_core` / `c05_periphery_seen` 拒绝,但不会集中在一两个外围类上,因为 16 个种子覆盖了 16 种互不相同的外围。

**N 位(slot b,日内形状统计量)**
- 产出 head 的概率约 50%,若有,最可能是分钟量价相关的 20 日均值(`cross_mean(day_corr(Close, Volume), 20)` 或其 GP 改写)或带方向成交(`day_signed_ratio` / `day_topw_mean(Ret, Volume)`)这一支。
- 在量价关系这一支里,20 日均值版本好于自身偏离版本(偏离版本换手高,15bp 成本下净夏普更差);这和 E 位的预测方向相反,是有意的对照。
- 裸核 `day_centroid(Volume)` 的 score 落在 [-0.1, 0.2](若它活到存档里)。
- `day_at_max_ratio` / `day_at_min_ratio` / `day_distinct_ratio` 这几个(锁板 / 价格格点的代理)score <= 0.3。

**R**:本轮 0 个(快照里没有 head,R 请求必须指名快照里的 head)。

## 第 2 轮

快照 = M 第 1、2 批 + 本组 r1a(E)、r1b(N):9 个 head,303 个已评分候选,拆解 26 次,R 候选 0 个,已生效替换 0 个。
任务文件:`r2/missions.yaml` —— E 位核心 `day_corr(Ret, Volume)`(12 个种子);N 位「成交形状相对波动形状的错位,搬到时点以外的维度」(15 个种子);
R 16 个变体(head8 ×3、head1 ×4、head2 ×4、head3 ×3、head6 ×1、head4 ×1)。校验 `c05_check.py 805 2`:ADMISSIBLE。

### 我目前对本种子 alpha 来源的信念

1. **A 轴(日内成交时点相对波动时点)是唯一被证实的来源,但库里已经饱和。** head1 +1.55、head4 +0.83、head2 的那层「排除尾盘 20%」约 +0.43、head9 是 head1 的近孪生;
   充分性 + 必要性 + 敏感性 + 两种写法方向一致(尾盘集中的成交是坏的)。我信它是真来源、不是五个控制的代理:约 70%。
   两个保留:(a) 平滑把它推向已知族(窗口 10 / 20 / 40 时 |ρ_known| = 0.39 / 0.51 / 0.55),它可能有一部分是已知族的**非线性**函数 —— R 里用已知族当分桶变量直接测;
   (b) 库里这条轴已有 3–4 个 head,等权融合时再加一个同轴 head 的边际价值低。所以本轮**不给 A 轴 E 位**。
   第 3 轮只有在「已知族分桶后 A 轴仍 ≥ 1.0」且本轮两个位都落空时,才回到 `cross_mean(day_centroid(Volume), 20)` 或 `sub(day_centroid(Volume), day_centroid(Ret))`。
2. **B 轴(5 个 head)是价格水平的代理。** `LogFloatShares` 对 `LogFloatCap` 线性中性化后剩下 −log(价格);里面的 `day_pos_ratio(High)` 恒为 1、`ts_argmax(·, 1)` 恒为常量。
   它在 A 股可能是真实的低价异象,但不是新信息,本实验里只会加重库的集中度。不投 GP 预算;R 只测两件事:价格还是规模(head3 的 band 换 LogFloatCap)、head6 的「按列序分桶」是否其实是按板块。
3. **C 轴(`day_corr(Ret, Volume)`)证据最薄、但和另两条轴构造上最远,本轮的 E 位给它。** 我的读法:当天的分钟量价相关里有两块机械成分 ——
   当天方向(上涨日成交自然落在上涨分钟,所以它和当日 / 20 日收益强相关,奖励只线性控制了 20 日反转)与量-波动共动(MDH);
   若有可预测的部分,是剥掉这两块之后「成交与方向的额外对齐」。它在 head8 之外还能拿出 ≥ 0.5 的新信息:约 35–40%。
4. **N:A 轴的机制能否搬到时点以外。** 如果 head1 的机制是「不伴随价格变动的成交(可择时的流动性 / 被动交易)的过度聚集被定价」(Admati-Pfleiderer),
   那它也该出现在集中度、持续性、尖峰、量-波动共动这几维。我的先验约 30%:r1b 已证明这些形状量的裸 20 日均值都过不了线,出 head 只能靠条件化。
5. **第 1 轮学到的分工**:Partura 给对了**算子类**(`cs_bucket_*`),GP 找到了**变量**(`day_centroid(Ret)`,不在我的 16 个种子里)。本轮照这个分工写:
   种子固定「平滑后的信号 + 在其波动对应量的十分位桶里做 z 分数」这个结构,变量铺开交给 GP。
6. **负面清单(本种子实测,继续有效)**:自身时序偏离 `cross_zscore` / `cross_madz`(−4.88)、`day_signed_ratio` 裸用或轻包装(−3.46)、`day_centroid` 用在价格字段(−1.58)、
   `cs_mean(·)` 当信号(横截面常量)、`day_flat_ratio(Close)` 当信号(掩码变量)、在非负量上的保序外层(与裸核同一本书)。
