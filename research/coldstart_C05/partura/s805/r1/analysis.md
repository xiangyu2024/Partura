## 2. alpha 的来源

### 2.1 五张核心卡是同一张:`pow_1_5` / `pow_2_5` 在这里是秩不变的空操作

机械核心卡给了 5 个核心:

```
day_centroid(Volume)
pow_2_5(day_centroid(Volume))
pow_1_5(day_centroid(Volume))
pow_1_5(pow_2_5(day_centroid(Volume)))
pow_1_5(pow_1_5(pow_2_5(day_centroid(Volume))))
```

这 5 个(以及共性第 6 行 `pow_2_5(pow_1_5(pow_2_5(day_centroid(Volume))))`)在本环境下**交易的是同一本书**。三步证据:

1. `day_centroid` 的输出落在 [0, 1] 且非负(`partura/ops_ext.py:155`,`sum(t·|x|)/sum(|x|)/(T−1)`)。
2. `pow_1_5` / `pow_2_5` 是把指数烤死的 `pow_`(`alphacube/catalog.py:145-148`):`sign(x)·|x|^e` 当 `e ≤ 1`,否则 `x**e`。
   在非负输入上 `x^1.5`、`x^2.5` 都是严格单增的,所以**不改变任何一天的横截面秩序**。
3. 奖励里信号进书之前先过 `neutral_residual`,而它第一步就是 `z = dg._zrank(sm)`(`partura/steer.py:430`),`_zrank` 只用秩(`diagnose.py:190`)。
   所以 **hl = 0 时 `zrank(pow_e(x)) ≡ zrank(x)`,残差、十分位书、夏普完全一样**;hl > 0 时 EMA 在幂变换前后不可交换,但只差一点。

本地纯 Python 核对(模拟一个 [0,1] 的慢变面板,不碰数据):hl = 0 时抽查的每一天秩序完全相同;
hl = 5 / 20 时两者的日度 Spearman 为 0.99999 / 0.99993(e = 1.5)和 0.99996 / 0.99980(e = 2.5)——远在 0.7 的秩相关禁令之上。

这正是 `alphacube/mining/rankban.py` 开头记的那个病:`log(Amt)` 被禁,搜索用 `log(pow_1_5(Amt))`、`pow_05(pow_05(day_max(Amt)))` 绕过去,回测小数第四位都一样。
M 第 1 批之所以没被自己的 `RankSimilarityBan` 收掉这些重复,是因为那个禁令只对**库里的 head** 生效,而这一批库是空的,36 个重写就全留在存档里。

**推论(重要):M 第 1 批在种子 805 上掉进了一个单调改写的盆地。** 64 个候选里 36 个含这个核心,
而这 36 个的平均 score 是 0.0020,各级幂链的平均是 0.024 / 0.0793 / −0.0069 / −0.0238 / −0.1542 ——
**外围处理几乎没有移动过分数**,因为外围大半是秩保持的。名义上 64 次评估,实际上试过的「不同的书」远少于 64 本。0 个过线和这件事是一回事。

### 2.2 `day_centroid(Volume)` 这个核心到底是什么

`partura/ops_ext.py:155`:|x| 沿分钟轴的重心,缩放到 [0, 1]:`sum(t·|x[t]|)/sum(|x|)/(T−1)`。
0 = 全在开盘,1 = 全在收盘,0.5 = 对称。用在 `Volume` 上就是**这一天的成交发生在日内什么时点** —— std / kurt / gini 这些无序统计量全都丢掉的那一维信息。
分钟网格固定 241 格;缺的分钟按权重 0 处理(`v = where(ok, x, 0)`),只要 `tot > 0` 就算有效。

它有三个和这一批其他候选都不同的性质:**有界**([0, 1])、**无量纲**(分子分母同比例)、**慢变**(日内成交 U 形是普遍的,股票之间的差异高度持续)。

### 2.3 共性那个 +2.01 测的是「不崩塌」,不是「赚钱」

| 子树 | 均值差 | p | 含它 | 含它的均值 | 不含的均值 |
|---|---|---|---|---|---|
| `day_centroid(Volume)` | +2.011 | 0.0000 | 36 / 64 | **+0.0020** | **−2.0090** |

score 的定义是:方向与半衰期按 **train** 的纯多头夏普挑最优,score = **min(train, valid)**(`partura/steer.py` 的 `long_neutral` 分支)。
所以 score ≈ −2 的含义是「train 上拟合出一个方向,valid 上这本书的净夏普大约 −2」,即**样本内外彻底反向**;score ≈ 0 的含义是「两段都赚不到也亏不到」。

于是 +2.011 这个落差是 **0 对 −2**,不是 **0.6 对 −1.4**。含核心的 36 个候选平均一分钱不赚(+0.0020),发现门槛是 0.5,这一批 0 个过线。
**必须认真对待的替代解释**:共性在这里奖励的可能是「驯顺」而不是「alpha」——
有界、无量纲、慢变的量,它的 z-rank 书稳定、没有可供 train 过拟的肥尾;而 `pow_*(Amt)` 这类无界重尾的树,train 的方向往往由少数几个名字决定,valid 就翻车。
注意共性表里 6 行**全都**落在 [0, 1] 上,这一条和「驯顺假说」完全一致。
把这件事分开的检验(在同等换手 / 同等有界性的候选里再比一次)在本轮没有预算通道,只能留给第 2 轮的笔记去验。

另外两条读表时必须记住的限制:
- 共性只枚举**非根**的日频子树(`t.nodes()[1:]` 且 `collapsed and degenerate`),所以 36 个里每一个**都至少有一层外围**,表里看不到「裸核自己」有没有进过存档。
- 只有出现在 ≥ 4 个候选里的子树才上表。`pow_2_5(core)` 出现 20 次、`pow_1_5(core)` 出现 8 次,36 − 20 − 8 = **至少 8 个含核心的候选,核心头上压的不是 pow**,
  而它们的子树一个都没到 4 次 —— **推断:非 pow 的外围每种只被试过一两次,而且都没把平均分从 0 拉起来。** 我能看见的「已见外围」因此只是一个下界。

### 2.4 真来源,还是代理?

奖励已经中性化掉的 5 个控制:`cross_mean(day_sum(Amt), 30)`(流动性)、`cross_mean(day_std(Ret), 20)`(波动)、
`div(day_last(Close), ts_delay(day_last(Close), 20))`(20 日反转)、`cross_mean(day_std(Amt), 30)`(已知族)、`LogFloatCap`(市值)。
这 5 个全是**水平量或收益量**;`day_centroid(Volume)` 是**无量纲的时点统计量**,在代数上不是其中任何一个的改写。这一点上它不像「流动性 / 规模 / 波动的另一种写法」。

但「不是代数改写」离「真来源」还很远,下面四条代理通道一条都没被测过:

1. **收盘集合竞价 / 指数成分**:A 股 14:57–15:00 收盘集合竞价把成交压到最后一格,指数成分股、有 ETF 与被动资金跟踪的名字尤其明显 → 重心偏向 1。
   这会让这个因子部分变成「指数成分 / 机构持股」的代理,而这与规模相关但**不是 `LogFloatCap` 的线性函数** —— 奖励里的中性化是日度 z-rank 上的**线性**投影,非线性的那部分活下来了。
2. **开盘竞价 / 散户早盘**:散户重的小盘股集中在开盘竞价和早盘半小时 → 重心偏向 0。同样是规模 / 投资者结构的代理。
3. **涨跌停与停牌**:涨停锁板后日内不再成交,成交全在早盘 → 重心机械地偏小;半日停牌的股票成交全在 0..120 格里,重心机械地 ≤ 0.5。
   `untradable` 掩码只挡掉「近 15 日有冻结报价且排在最差五分之一」和上市太短的名字,挡不住一次普通的盘中停牌或一个非锁板的涨停日。这一条是**数据构造的人工痕迹**,不是 alpha。
4. **价格水平 / 一跳网格**:低价股分钟成交分布的粒度和高价股不同(参见 `day_distinct_ratio` 的注释),重心的噪声结构随价格变化。

**判定:`day_centroid(Volume)` 是一个「机制上说得通、但本轮完全未被证明」的候选核心。**
支持它值一个 E 位的只有机制(没有控制、没有已知族覆盖日内时点这一维)和「唯一不崩塌」这件事;
反对把它当真来源的是:平均 score 恰好 0、代理通道 4 条全未测、与已知族的相关度未测、充分性未测。

**还有一条机制层面的判断,直接决定 E 怎么写**:这个核心的横截面高度持续(更像股票属性,不像信号)。
一个未被定价的静态属性,它的分数就该是 0 —— 而实测恰好是 +0.0020。
所以如果这一维里有东西,**东西在它的偏离和条件化里,不在它的水平里**。

#### 「已见外围」在代码里的真正定义,以及它有多弱

### 5.2 R 目标

将来有了 head 之后的 R 清单(先记下来):凡 head 最外层是 §3.2 那些保序算子的,第一刀就砍它 —— 砍掉之后 score 应当几乎不变(变动 < 0.01),
这正好把「R 的 +0.1 替换规则」用成一次对本分析的校验:**如果砍掉一个保序外层让 score 变了 0.1 以上,说明我上面关于 z-rank 的推理在真数据上有漏洞,要回头查 EMA 那一步。**

### 5.3 N 的灵感

从这一批里能提炼的、不依赖任何先验择时判断的两条:

1. **同一族的其他「日内形状」统计量,而不是水平量。**
   这一批唯一不崩塌的结构有界、无量纲、慢变;崩塌的那 28 个是无界的水平与尾部统计量。
   同族的可用算子(已核对语义):`day_gini(Amt)`(集中度,0 = 均匀,→1 = 全在几分钟)、
   `day_signed_ratio(Ret, Amt)`(涨分钟成交占比减跌分钟,∈[−1,1],净买压代理)、
   `day_at_max_ratio(Close)` / `day_at_min_ratio(Close)`(钉在日高 / 日低的时间占比,锁板读近 1)、
   `day_argmax(Volume)` / `day_argmin(Volume)`(放量时点,比重心更稳健于尾部)、
   `day_distinct_ratio`、`day_es_ratio_hi` / `day_es_ratio_lo`、`energy_ratio_topm`(频谱占比)。
   这一条**不是**「我觉得日内形状会赚钱」,而是「这一批里能活下来的全是这一类,值得把这一类铺开试一次」,并且它和 M 的普通搜索不重叠(M 的随机树里这些算子只是偶然出现)。
2. **把「水平」一律换成「自身偏离」的写法。**
   `cross_zscore(·, 20..60)` / `cross_madz` 包在任何日频形状统计量外面。
   机制:横截面高度持续的属性如果没被定价就只能是 0(实测 +0.0020 正是如此),而「这只股票今天的成交比自己过去一个月异常地晚 / 异常地集中」是一个**事件**。
   这一条可以和第 1 条合成一张种子表(形状统计量 × {水平, `cross_zscore` 偏离}),正好占满 16 个种子。

PI 注意 PLAN §2.5「3 轮里至少 1 个 N 位」:本轮 E + N 的配法立刻满足这一条,而且因为 R 花不出去,本轮两个 GP 位是全部产出来源。

## 7. 给第 2 轮核对的可检验预测

1. `day_centroid(Volume)` 的裸核 score 会落在 **[−0.1, +0.2]**(如果它能被评到,见 §5.1 的 N 种子通道)。
2. `pow_1_5(day_centroid(Volume))` 这一族若被直接评分,与裸核的 score 相差 **< 0.05**,交易信号秩相关 **> 0.99**。
3. E 位里属于 A 类(`cross_zscore` 等自身偏离)和 B 类(`cs_bucket_rank` 等分桶)外围的候选,其 score 分布会**明显高于**纯保序外围的候选;
   如果不是,那么「alpha 在偏离与条件化里」这个判断错了,第 2 轮应该放弃这个核心,不要用掉它的第 2 个 E 配额。
4. 按 `LogFloatCap` 或流动性分桶之后这个核心仍然接近 0 ⇒ 它不是规模 / 流动性的代理,只是没有信息;分桶后变好 ⇒ 代理通道确实压住了信号;
   按 `day_flat_ratio(Close)` 分桶后塌掉 ⇒ 它主要是停牌 / 锁板的人工痕迹(§2.4 通道 3),应当弃掉。
5. E 位会出现相当数量的 `c05_periphery_seen` 和 `c05_no_core` 拒绝计数,但**不会**集中在少数几个外围类上 ——
   除非 PI 的 16 个种子没有覆盖 A / B / C 三类;那种情况下 96 次评估会退化成「同一个外围换窗口」(§5.1 第 3 条)。
