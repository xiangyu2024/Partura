## 第 1 轮

快照只有 M 第 1 批(c05s802M1_I0_open_search):6 个 head、77 个已评分候选、47 次拆解。之前没有任何任务。

### 我目前对本种子 alpha 来源的信念

1. **本种子的库里只有两份独立信息**,不是 6 份。
   - **S = `sigmoid(ts_regbeta(day_flat_run_max(Vwap), day_durbin_watson(Volume), 50))`**,占 5 个 head。证据三方面一致(样本内):单独 +0.80(train 0.80 / valid 1.14,rho_known −0.12);共性均值差 +1.34(p < 0.001);拆掉 regbeta 层必要性 +3.30、拆掉 sigmoid 必要性 +0.80。可信度高(只限 train / valid)。
   - **`day_mean(neg(in_delta(Volume, 60)))`**:按 in_delta 的 NaN 规则与 day_mean 的定义,它恒等于 (前 60 根分钟成交量之和 − 末 60 根之和)/181,前 60 根含 09:30 开盘竞价那一列、末 60 根含 15:00 那一分钟。即「早盘重、尾盘轻」的成交量时间分布,**未归一化**(截面上混着量级)。+0.54 / valid +1.26,从没被拆过,证据薄;但它是唯一与 S 正交的来源,对最终融合的边际价值最高。
2. **S 的信息在 beta 的符号与持续性里,不在幅度里**:裸 beta valid −0.14;sigmoid 把它压成近二值(distinct 1.00 → 0.67)后 valid +1.14;ts_decay_linear 把并列块重新拆开(distinct → 0.84 / 0.93)分数随之升到 0.96 / 1.24。
3. **价格字段必须是 Vwap**(四棵全是 Vwap→Close 变差、Volume→Amt 不变):分钟 Vwap 在没成交的分钟是 NaN,所以 S 讲的是「有成交、价格被钉在一个档位」,不是「没成交的呆滞」。机制到底是封板式的目的性钉价,还是相对最小价位(低价股)的机械效应,我**不下注**;本轮只放一个价格水平分桶的探针。
4. **ts_regbeta 窗口 50 偏短**(50→25 大跌,50→100 +0.32)。
5. 5 个 S head 是 S 的单调包装加不同的 EMA 混合(hl = 0 时单调变换是恒等;inv 是这批 GP 的逃逸出口),对最终融合的边际价值递减。
6. 共性卡上的 `inv(LogFloatShares)` 一族:零充分性证据、三个「含它的均值」到三位小数相同(同一谱系搭车),残差上剩的主要是股价水平。不投资。
7. 机制上的东西我只当假设写,不当先验:C01–C04 里凭先验写的机制几乎全错,本轮的任务全部从第 1 批的数据出发(核心取自 head、N 来自 head 的恒等式、R 来自拆解)。

### 本轮决定

- **位 a = E,核心 S**(机械卡 #2,最短的充分核心;卡 #1、#3–#6 都是 S 的单调包装,信息相同、节点更多)。家族控制 = 5 个 S head。外围走两条新轴:状态动力学(ts_rank / cross_zscore / ts_stddev / cross_flat_ratio / ts_argmin / 短长均值差 / 与 200 日版本之差 / 与「没成交的呆滞」的时间序列相关)与交互(钉在最高 / 最低均价的分钟占比、量加权分钟方向、成交量重心)。
  原想放的「板块 / 带宽 / 上市年龄 / 近 20 日涨跌分桶后的桶内秩」全部拿掉:库禁令按**原始日度秩** |ρ| ≥ 0.7 拒绝,S 的单调包装(如 `pow_1_5(inv(S))`)和 S 的秩相关是 1,桶内秩基本保留 S 的截面排序,会被拒、白花评估。只留 `cs_bucket_rank(S, day_last(Close))` 一个探针。
- **位 b = N,日内成交量的时间分布**(归一化的首末段份额差、成交量重心、开盘 / 收盘竞价占比、最大量分钟的时刻、量与时刻的相关、对数变化,及其 20 日均值与相对自身历史的 z 分数)。N 的「3 轮至少 1 个」在第 1 轮就用掉,第 2、3 轮可以按结果自由选 E。
- **R(16 个)**:A1(+1.144)窗口 100 + decay 80 / 窗口 100 / t 值;A2(+0.834)窗口 100(拆解已知 +1.1555);A3(+0.832)整层剥掉外层死重并用窗口 100 / 裸 t 值 50 / 裸 t 值 100;A4(+0.730)去掉有害的内层 inv(拆解已知 +0.9608);A5(+0.712)窗口 100 / DW→一阶自相关 / DW→Gini / flat_run_max→flat_ratio;A6(+0.537)除以当日平均分钟量 / 换 Amt / 窗口 30 / 窗口 120。

## 第 2 轮

快照:M 第 1、2 批 + 本组第 1 轮的 E(`c05s802Br1a_Ea`)与 N(`c05s802Br1b_Nb`)+ 第 1 轮 R 的 3 个替换;18 个 head、281 个已评分候选、31 次拆解。

### 我目前对本种子 alpha 来源的信念(只限 train / valid)

1. **最硬的来源换成了日内成交量的时间分布(对数口径)**:`day_mean(in_logchg(Volume, 60))` = [末 60 分钟对数成交量之和 − 首 60 分钟之和]/181,做多早盘重 / 尾盘轻。
   20 日均值 +1.668(valid 2.26),窗口 10 / 20 / 40 平顶,Volume→Amt 不变;对当日成交量的乘性缩放严格不变,所以不是换手 / 规模的代理(唯一的细通道:零成交分钟被跳过)。
   第 1 轮 R 把归一化问题答清了:对数行、份额不行(−0.067)、Amt 水平口径不合格(−1.876,rho_known −0.52)。我第 1 轮押对了族和方向,押错了归一化(押的是份额差和重心)。
   这一族在库里已有 6 个写法(对数、水平、每分钟占前一小时份额、三个收盘分钟占比),最终融合里它的权重很可能已经偏高。
2. **S(flat_run_max(Vwap) 与 DW(Volume) 的长窗口回归斜率)是真的,但信息在「长窗口的关系」里**:窗口 50 / 100 / 200 = 0.83 / 1.16 / 1.39 单调;
   第 1 轮「幅度是噪声」要改成「50 日太噪、标准化救不回来;100 日 t 值是干净的标准化」(t@100 +1.14,t@50 −0.11)。
   「必须是 Vwap」只在短窗口成立(窗口 100 上 Close 版 +1.01 对 +1.16);DW(Volume) 不能换成别的粗糙度(自相关 −1.83、Gini −0.27)。我第 1 轮写下的封板机制故事证据被削弱,不再当前提。
3. **DW(High) 的凸聚合**:x^1 / x^2 / x^2.5 / x^5 = −1.17 / +0.27 / +0.72 / +1.45,同日截面排序不变,只通过「先 EMA 后 z-rank」起作用。
   我的读法比解剖员多一步:原始 DW(High) 量级随全市场波动成倍变化,x^5 的 EMA 会被全市场同时变粗糙的那几天支配,所以它可能主要是「市场压力日上的截面位置」,而不是每只票自己的 MAX。本轮 R 用截面秩的五次方把两者分开。
4. **股价水平簇(M2 的 6 个 head)**:控制里有 `LogFloatCap`,`LogFloatShares` 的残差一阶上是 −log(价格),即低价股;本身单独过线(+0.56),筛子再抬 +0.5 ~ +0.74。
   在 train / valid 上是真的,但信息单一,最终去重会砍掉一部分。文献员提醒:A 股直接文献在截止日前没找到,「已知异象」这句话只能说「美股文献证实机制存在」。不投 E / N。
5. 我纠正解剖员的两处:(i) 「把 `sigmoid(ts_regbeta(…, 100))` 和 t@100 当种子就能进库(80%)」不成立 —— 库里有 R 替换进来的 `pow_1_5(inv(sigmoid(ts_regbeta(…, 100))))`,
   与 `sigmoid(beta@100)` 是单调关系,RankSimilarityBan 取的是日度秩相关的绝对值,等于 1,必被拒;t@100 与 beta@100 同号同窗,秩相关很可能也 ≥ 0.7。所以改成在 R 里把 t@100 挂在 S@100 的 head 下评,用 rho 决定它是替换还是第 3 轮的种子。
   (ii) 「筛子是不是通用的」库里已经部分回答了:同一个低价股 y 配 `day_max(Volume)` / `day_gini(Volume)` / `day_durbin_watson(Vwap)` 三种 x 都抬了 +0.5 以上;没答的是「搬到不是股价代理的 y 上还灵不灵」,本轮 R 只试这一点。
   另外,「`day_mean(in_delta(·))` 应与 `day_mean(neg(in_delta(·)))` 精确相等」我读源码确认了(`steer.py` 对 sign ±1 扫描、EMA 与残差都是线性的、`day_mean` 线性),不花评估。

### 本轮决定

- **位 a = E,核心 A `day_mean(in_logchg(Volume, 60))`**(不在机械卡上;B0 的这一位会按卡序落到 S@100 的单调包装上)。家族 = 1 个 head。
  15 个种子分三类:时间结构(不稳定度、稳健异常、5 对 60 漂移、20 对 240 偏离、上 / 下尾均值减均值)、噪声标准化(跨日 t 比、日内 t 比)、带第二个叶子的分解与交互
  (成交额曲线减成交量曲线 = 首末小时价格漂移、成交量曲线减高低价差曲线、与日收益 / 日总量的 60 日相关、对全市场曲线的 60 日 beta、按价格漂移分组的条件排序、乘成交量集中度)。不放任何平滑变形(必被库的秩禁令拒)。
- **位 b = N,「极值时间聚合」当成通用处理**,原料铺到不是已实现波动水平的日内统计量上(避开与 DW(High) 秩相关 ≥ 0.7 的禁令),16 个种子。
- **R(16 个)**:S 一族四个 head 都只动窗口一处(→ 200,另 A2 → 400)、S@100 挂 t@100;DW(High) 四个显式聚合;水平口径 head → 对数口径;核心 A 的 head 试窗口 120、流动性十分位内 z 分数、排除式筛子;收盘占比 head 换干净口径与对数口径。
  S 一族都换到 200 之后彼此会更像,最终去重会把它们收成一两个 —— 这是我想要的(一份信息不该占 5 个位置)。
