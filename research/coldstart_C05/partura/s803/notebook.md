# 研究笔记:种子 803,B 组(PI)

只记本种子自己看到的东西(定位输出、本种子之前各轮的任务与结果、PLAN、代码)。没有读其他种子、A / B0 组、C01–C04、测试段。

## 第 1 轮

### 看到了什么

- 快照只有 M 第 1 批的一个 head:`day_kurt(Ret)`,方向 −1,hl 20,score 0.97(train 0.97,valid 1.54,较差的是 train)。
- 共性表空、拆解 0 次(两个节点的树:根不跳,`Ret` 没有同类字段,没有窗口)、机械核心卡空、R 候选空。拆解的 48 次预算整轮作废,不能挪用。
- 所以本轮唯一的核心就是整个 head(PLAN 修订 3),唯一能买诊断的付费通道是 R 的 16 次直接评估;R 和两个 GP 位同时开跑,R 的结果第 2 轮才能用。

### 我目前对 alpha 来源的信念(都未检验)

先说一条从源码确定的事实:奖励是**先对原始值做 EMA、再排序、再对五个控制取残差**。原始分钟收益峰度极重尾(只有一分钟有成交的日子约 +236,正常日子在 0 附近),
所以 head 的 EMA20 实际是「过去一个月有没有出现过尖峰日」的**峰值记忆**,而不是平均形状。多头腿 = 一个月里一天尖峰都没有、分钟收益铺得很匀的股票。

尖峰日从哪来,四个假设,我的主观权重:

| 假设 | 机制 | 权重 |
|---|---|---|
| H1 成交稀疏 | 很多分钟没有成交 → 收益为 0 → 峰度 ≈ 241/活跃分钟数 − 3;控制里只有成交额水平,没有「有多少分钟真在交易」 | 0.30 |
| H4 价格网格(本轮新提) | 价格字段是后复权的,`Amt/Volume` 才是成交价;低名义价格的股票一跳就是 0.2%–0.3%,大于典型分钟波动,很多分钟收益落在 0 上,峰度被离散度抬高。控制里有市值、没有名义价格 | 0.25 |
| H3 彩票 / 封板 | 涨跌停封板、单分钟跳跃日;做空腿就是 MAX 效应的人群 | 0.20 |
| H2 真尾部形状 | 与成交密度和价格网格无关的波动集中度 | 0.15 |
| 其他 | | 0.10 |

H1 和 H4 很难分开(零收益分钟两者都产生),本轮 R 的 11 号(零收益比例)和 12 号(名义价格)各给一个 rho_head,第 2 轮先看这两个数。
如果 H1 + H4 + H3 合起来占主导,这个 head 就是「已知摩擦 / 彩票类特征的另一种写法」—— 仍然拿分(都不在控制里),但深挖的方向应该是把它写得更干净,而不是在它外面再长东西。

### 本轮的任务与事先预测

**E 位(核心 `day_kurt(Ret)`,用掉它 2 个 E 位中的 1 个)。** 核心自己(sign × EMA20)进控制,所以单调改写和换平滑在构造上拿不到分。16 个种子分三类外围:拿掉疑似混淆(零收益比例 / 名义价格分桶与回归残差、对自身日内波动 / 成交额的时序回归残差)、改时间轴聚合(60 日中位数、40 日下四分位尾均值、日秩的慢 EMA、cross_madz 异常度)、和成交的共动与方向(与成交额的 20 日时序相关、乘偏度、收益峰度与成交额峰度的秩差)。

预测:
1. 产出 heads 的概率约 40%;若有,1–2 个。最可能来自「今天比自己平常尖多少」一类(cross_madz / cross_regres 对自身波动或成交额的残差),选中的半衰期是 0 或 5(事件型),不是 20。
2. 分桶 / 截面回归类(种子 1、2、3、13、16)的 score 大多 < 0.3:核心进控制后,它们剩下的主要是「核心减去它被零收益 / 价格解释的部分」,符号混在一起。若其中某个反而 ≥ 0.5,说明 H2(真形状)有独立的 alpha,这是本轮最重要的一条信息。
3. GP 会往「核心 + 一条和核心无关的好分支」(add / sub 一个别的因子)漂;heads 里若出现这种形状,它是新信息但不是对核心的深挖,第 2 轮要分开记。
4. 拒绝计数:`c05_periphery_seen` 很低(< 5),`c05_no_core` 和库秩相关禁令高得多。

**N 位(分钟序列的顺序与「成交钟」)。** 峰度把 241 根分钟收益当无序样本、也不看每分钟成交了多少钱;这两样五个控制里都没有。种子:一阶自回归 / DW / Hurst(价差反弹 vs 价格延迟)、成交额加权波动 / 钟表波动、最重 10% 分钟的平均收益、成交额重心与后置、成交时点减波动时点、收益与成交额的同期 / 滞后相关、收盘价与成交量的相关、带方向的成交额占比。

预测:
1. 产出 heads 的概率约 65%,1–3 个。最可能来自量价相关一支(`day_corr(Ret, Amt)`、`cross_mean(day_corr(Close, Volume), 20)` 及其变异)和带方向的成交额占比;
2. 自相关一支(ar1 / DW)单独过线的可能小:它的主要成分(价差反弹)和流动性控制同源,中性化后剩得不多;Hurst 那条大概率是噪声(文献也这么警告)。
3. 若量价相关一支出 head,它与 `day_kurt(Ret)` 的交易信号残差相关 |ρ| < 0.3(两者读的是不同的东西)。

**R(16 个,全部是 `day_kurt(Ret)` 的换件,兼作判决)。** 预测:
1. 11 号 `cross_ema(day_zero_ratio(Ret), 10)`:过门槛,rho_head ≥ 0.5(我押 0.5–0.8)。
2. 12 号 `log(div(day_sum(Amt), day_sum(Volume)))`(名义价格):rho_head 在 0.3–0.6 之间,方向是做多高价;自身 score 能不能过 0.5 我没有把握(五五开)。
3. 1 号 `day_kurt(in_logchg(Vwap, 1))`(只在有成交的分钟上算)和 3 号 `day_kurt(in_pct(Close, 5))`(五分钟收益):score 都明显低于 0.97(我押 < 0.7)。若反而 ≥ 0.97,H1 / H4 被否,H2 成立,第 2 轮整个判读要翻。
4. 8 号 `cs_rank`、9 号 `log(kurt+5)`、10 号 `cross_med(·, 20)` 这三个「去掉峰值记忆」的换件里,至少一个 score 高于 0.97;但够 +0.1 的替换线、真替换的概率约 35%。若是 8 / 9 号替换,说明峰值记忆是有害部件;若三个都更差,说明 alpha 就在「出没出现过尖峰日」这件事上(更像 H3 / H1 的事件)。
5. 4 号 `day_gini(Ret)`:过门槛,rho_head ≥ 0.5,不够 +0.1。
6. 13 号封板占比、14 号尺度无关 MAX:rho_head < 0.5(H3 不是主成分)。
7. 16 个里 0–2 个栽在门槛上(最可能是 5 / 6 号单侧尾部的 coverage)。k/241 型比例的原子都套了 EMA10 —— 本机用价格网格模拟过,20 日均值的取值不同比例只有 0.13(过不了 distinct ≥ 0.5),EMA10 是 0.95。
8. 本轮替换数:0 或 1。

### 留给第 2、3 轮的规则

- `day_kurt(Ret)` 还剩 1 个 E 位。只有在本轮 E 出了 head、或 R 证明某个换件(比如只在有成交分钟上的峰度)本身是一个更干净的核心时,才再给它 E;否则把 E 让给 M 第 2、3 批的新核心。

## 第 2 轮

### 看到了什么

- 快照 4 个运行(M1、M2、Br1a_Ea、Br1b_Nb),6 个 heads,210 个已评分候选;拆解花了 18 / 48(两轮累计作废 78 次);r1 的 R 16 行全部过门槛,0 个替换。
- M 第 2 批带来本种子最强的来源 **核心 A `ts_skew(day_durbin_watson(Open), 50)`**(单独 1.18 / head 1.23;它的父 head 1.56)。四条轴里三条是同一运行内的对照:去掉外层 -2.13、窗口 25 / 100 与 Open->Close 都不崩、整个家族 valid 2.0-2.5、rho_known 0.19。
- 共性表本轮被「运行身份」混淆(E 任务存档 100% 含它的核心、奖励多一个控制),p 值不能当子树好坏读;核心 A 的判定不依赖它。
- r1 N 位带来 **核心 B `sub(day_centroid(Amt), day_centroid(Ret))`**(0.90,两半单独都是废的);`sub(day_centroid(Amt), LogFloatShares)`(0.53)的秩几乎全由 LogFloatShares 决定,控制掉 LogFloatCap 后约等于 -log 名义价格。
- r1 E 位产出 `cross_corr(day_kurt(Ret), day_gini(Ret), 241)`(0.73),窗口是刀锋,结构上最弱。

### 我目前对本种子 alpha 来源的信念

1. **核心 A(日方差序列的形状)是主来源。** `day_durbin_watson` 在价格上是已实现方差(源码:分母 Σx²;解剖员算术:与 day_var(Ret) 差 0.4%),全部新信息在外层 50 日偏度上,ts_skew 仿射不变所以构造上躲开一切水平控制。多头 = 两个半月里没有孤立爆波动日的股票。
2. **`day_kurt(Ret)` 是半代理。** r1 的 16 个换件说清楚了:只在有成交分钟上算就从 0.97 掉到 0.02(零质量必要),但零收益比例、名义价格、封板、最长静止段这些单一代理全是大负数且 |rho_head| <= 0.52;最像它的是尺度无关 MAX(rho 0.87)。它读的是「一分钟吃掉全天 + 其余时间躺平」这个复合;峰值记忆是好部件(去掉它的三个换件全更差)。H2(与零质量无关的真尾部形状)基本死了。
3. **核心 B(成交时点减波动时点)是第二条独立的轴**,五个控制都不含日内时点;收盘集合竞价风险没测。
4. **名义价格这条轴反复冒头**(LogFloatShares 的富集、r1 R12 的 |rho| 0.51、价格 head),它没在控制里;文献警告裸价格排序被动量与相对 tick 两条通道污染([S34][S35][S38]),本叶子集合无法排除。

一个统一的经济故事(未检验,主观权重):核心 A 与 day_kurt 都是「不爆」—— 一个在日这条轴、一个在分钟这条轴。
- 彩票 / 注意力需求使偶尔爆发的股票被高估、做多平稳的一端(Bali et al. 2011 一类):0.40;
- 价格网格 / 零质量这类微结构假象:0.20(对 day_kurt 高,对核心 A 低,因为日这条轴上零质量只影响水平、被仿射不变吃掉大半);
- vol-of-vol 的风险溢价(Baltussen et al. 2018;方向是做多不确定性低的一端,与观察一致):0.25;
- 其他:0.15。
若是第一条,换一个日频量(成交额、日收益、分钟峰度)取 50 日形状也应拿分 —— 这正是本轮 N 位要检验的。

### 本轮的任务与事先预测

**E 位(核心 A,用掉它 2 个 E 位中的 1 个)。** 两个含核心的 head 进控制。快照里见过的外围是再套 ts_skew / cross_autocorr_s1 / 换窗口;本轮 16 个种子全部写成「核心十分位内的另一个量」或「居中秩的交互项」,使它们与核心的秩相关接近 0(过 0.7 库禁令),外围分四类:爆波动日的时点(4)、方向(2)、是否放量 + vol-of-vol + 波动聚集 + 今日冲击(5)、核心的效果随价格 / 流动性 / 上市年龄 / 零收益比例变化的交互项与按市场波动状态翻向(5)。凡对日方差求二阶量都先取 log(EPS 陷阱,见下)。

预测:
1. 产出 heads 的概率 **45%**,若有 1-2 个。最可能来自「方向」或「是否放量」两类(log 日方差与日内收益 / 成交额的 50 日相关在核心十分位内),其次是 vol-of-vol;半衰期 5 或 20。
2. 四个交互项(价格、流动性、上市年龄、零收益比例)score 大多 < 0.3。若价格交互项 >= 0.5,说明核心 A 的 alpha 在价格档位上分布不均(价格网格混淆是真的),第 3 轮要改写核心。
3. `cs_flip_by_state` 那条 score 为负(核心在高低市场波动状态里都有效),概率 75%。
4. 采样计数:`c05_no_core` > 1500(核心 3 个节点带窗口,比 r1 的 2 节点更容易被变异打坏);`c05_periphery_seen` < 20;退回不含核心的最小树的候选有几个,单列。

**N 位(「形状不是水平」推广到别的日频量)。** 15 个种子:成交额的七种形状写法(矩偏度、上尾 / 中位数、变异系数、稳健 z、四分位偏度、上下行半偏差比、log 峰度)、三种日收益(收盘到收盘、隔夜、日内)的 50 日偏度、五个日内形状序列(分钟峰度、成交时点、零收益比例、带方向成交额占比、成交额集中度)的 50 日偏度。都不碰日方差本身。

预测:
1. 产出 heads 的概率 **65%**,若有 1-3 个。最可能:日收益偏度(彩票)一支和成交额的变异系数 / 偏度一支;隔夜偏度次之;分钟峰度的偏度、零收益比例的偏度大概率是噪声。
2. 若出 head,它与核心 A 家族的交易信号残差相关 |ρ| < 0.5(读的是不同的日频量)。若反而 >= 0.5,说明「形状」本身是同一个因子(注意力 / 彩票),第 3 轮不再加同类。
3. 成交额那一支里,稳健写法(四分位偏度、上尾 / 中位数)不会比矩偏度好:若核心 A 的经验可推广,alpha 恰恰在孤立的极端日上。

**R(16 个)。** 预测:
1. `ts_skew(day_var(Ret), 50)` 与头 score 差 < 0.15、rho_head >= 0.9(核对「DW(Open) = 日内方差」)。
2. `ts_skew(day_durbin_watson(Vwap), 50)`(只用成交过的分钟)score >= 0.8,概率 60% —— 核心 A 不像 day_kurt 那样吃零质量。
3. 幂次阶梯:std 版比头低 0.1-0.4,log 版低 >= 0.3(要的是孤立爆波动日的原始右尾)。若 log 版与头相当,说明不是极端值、是整体不对称。
4. 上尾 / 中位数、四分位偏度、半偏差比都过门槛、rho_head >= 0.5,但都不够 +0.1;四分位偏度最低(它天生忽略极端日)。
5. `sub(LogFloatCap, LogFloatShares)`:对核心 A 的 |rho_head| < 0.4(核心 A 不是价格);对价格 head 的 rho_head >= 0.7;自身 score 我没有把握,替换价格 head(>= 0.63)的概率 30%。
6. head 1 去掉内层 ts_skew、窗口 6:score 1.50-1.66,不替换(85%)。
7. cross_corr head 的三个换件里至少一个替换它:25%。
8. 核心 B:去掉收盘集合竞价 3 根 score 掉 <= 0.2;去掉最后 30 根掉 0.2-0.5;平方收益版在 ±0.15 内。
9. 本轮替换数 0 或 1(最可能是价格 head 或 cross_corr head)。

### 上一轮的预测对不对

(依据 r2 的定位输出与 R_prev.json;解剖员 §3 有逐条表,这里记结论。)
- **E 位**:「40% 出 heads、若有 1-2 个」—— 出 1 个,对;「最可能来自 cross_madz / 对自身波动或成交额的残差」—— 错,来自 cross_corr 共动一支(形状是我写的种子 8 / 9,搭档与窗口是 GP 换的);「半衰期 0 或 5」—— 对(5);「分桶 / 截面回归类 < 0.3」—— 对;「GP 往核心 + 无关分支漂」—— 对(漂成 div);「periphery_seen < 5、no_core 高得多」—— 对且极端(0 对 1322)。
- **N 位**:「65% 出 heads,1-3 个」—— 2 个,对;「最可能来自量价相关」—— 错,赢家是成交时点那一支(Clark / Admati-Pfleiderer 的成交钟);「ar1 / DW / Hurst 单独过线可能小」—— 对。
- **R**:8 条里对 4 条(1-分钟 Vwap 与 5 分钟收益掉分、0 个门槛废品、0 个替换),错 2 条(零收益比例 rho_head 是 -0.44 不是 0.5-0.8;去掉峰值记忆的三个换件全更差),半对 2 条。按我自己写的备选读法,第 4 条的错说明 alpha 就在「出没出现过尖峰日」上。
- **我最大的错**:N 位按算子名字把 `day_durbin_watson` 当「价差反弹 / 自相关」,判它「剩不下多少」—— 在 Ret 上对,但 M2 把它用在价格水平上,那里它是已实现方差,成了本种子最高分的两个 head。以后任何按算子名字下的先验,先过一遍「它在这个输入上算的是什么」。

### 本轮新记下的工程事实

- **EPS 陷阱**:日方差(DW 在价格上)量级 1e-6 - 1e-5,它的跨日方差约 1e-10 - 1e-12。AlphaCube 的 nankurt 要求方差 > EPS = 1e-9,所以 `ts_kurt(day_durbin_watson(·), d)` 恒为 NaN(解剖员 R 清单第 11 条若照放会是门槛废品,本轮没放);cross_corr / cross_autocorr 的分母是 sqrt(var·var) + 1e-9,对裸 DW 求相关会被压向 0 且变成波动水平的代理;滚动回归要求 var_x > EPS,DW 当自变量 beta 恒为 NaN。凡是对日方差求二阶量,一律先取 log。
- `in_slice` 不存在;砍掉当日最后 d 根分钟用 `in_delay(x, d)`(重心整体平移一个常数,截面次序不变)。

### 留给第 3 轮的规则

- 核心 A 还剩 1 个 E 位:只有本轮 E 出了 head、或 R 证明某个替换件(Vwap 版 / log 版 / 稳健写法)本身更干净时才再给;否则第 3 轮不再深挖它。
- 核心 B:R 的第 12 条(去掉收盘集合竞价)若掉分 <= 0.2,第 3 轮给它 1 个 E 位,外围试成交时点的 50 日形状与带方向的成交时点;若掉光,它就是尾盘量占比,不给。
- 若本轮 N 出了 head 且与核心 A 家族 |ρ| < 0.5,第 3 轮的 N 继续「形状」这条线到还没碰过的日频量;若 N 0 个 head,「形状」只对已实现方差成立,第 3 轮的 N 换到别的轴。
- `day_kurt(Ret)` 的第 2 个 E 位继续不用(两个条件都不硬)。
