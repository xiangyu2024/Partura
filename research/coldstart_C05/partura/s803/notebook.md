## 第 1 轮

### 看到了什么

- 快照只有 M 第 1 批的一个 head:`day_kurt(Ret)`,方向 −1,hl 20,score 0.97(train 0.97,valid 1.54,较差的是 train)。

- 所以本轮唯一的核心就是整个 head(PLAN 修订 3),唯一能买诊断的付费通道是 R 的 16 次直接评估;R 和两个 GP 位同时开跑,R 的结果第 2 轮才能用。

### 我目前对 alpha 来源的信念(都未检验)

先说一条从源码确定的事实:奖励是**先对原始值做 EMA、再排序、再对五个控制取残差**。原始分钟收益峰度极重尾(只有一分钟有成交的日子约 +236,正常日子在 0 附近),
所以 head 的 EMA20 实际是「过去一个月有没有出现过尖峰日」的**峰值记忆**,而不是平均形状。多头腿 = 一个月里一天尖峰都没有、分钟收益铺得很匀的股票。

尖峰日从哪来,四个假设,我的主观权重:

| 假设 | 机制 | 权重 |
|---|---|---|
| H1 成交稀疏 | 很多分钟没有成交 → 收益为 0 → 峰度 ≈ 241/活跃分钟数 − 3;控制里只有成交额水平,没有「有多少分钟真在交易」 | 0.30 |
| H4 价格网格(本轮新提) | 价格字段是后复权的,`Amt/Volume` 才是成交价;低名义价格的股票一跳就是 0.2%–0.3%,大于典型分钟波动,很多分钟收益落在 0 上,峰度被离散度抬高。控制里有市值、没有名义价格 | 0.25 |
| H3 彩票 / 封板 | 涨跌停封板、单分钟跳跃日;做空腿就是 MAX 效应的人群 | 0.20 |
| H2 真尾部形状 | 与成交密度和价格网格无关的波动集中度 | 0.15 |
| 其他 | | 0.10 |

H1 和 H4 很难分开(零收益分钟两者都产生),本轮 R 的 11 号(零收益比例)和 12 号(名义价格)各给一个 rho_head,第 2 轮先看这两个数。
如果 H1 + H4 + H3 合起来占主导,这个 head 就是「已知摩擦 / 彩票类特征的另一种写法」—— 仍然拿分(都不在控制里),但深挖的方向应该是把它写得更干净,而不是在它外面再长东西。

### 本轮的任务与事先预测

**E 位(核心 `day_kurt(Ret)`,用掉它 2 个 E 位中的 1 个)。** 核心自己(sign × EMA20)进控制,所以单调改写和换平滑在构造上拿不到分。16 个种子分三类外围:拿掉疑似混淆(零收益比例 / 名义价格分桶与回归残差、对自身日内波动 / 成交额的时序回归残差)、改时间轴聚合(60 日中位数、40 日下四分位尾均值、日秩的慢 EMA、cross_madz 异常度)、和成交的共动与方向(与成交额的 20 日时序相关、乘偏度、收益峰度与成交额峰度的秩差)。

预测:
1. 产出 heads 的概率约 40%;若有,1–2 个。最可能来自「今天比自己平常尖多少」一类(cross_madz / cross_regres 对自身波动或成交额的残差),选中的半衰期是 0 或 5(事件型),不是 20。
2. 分桶 / 截面回归类(种子 1、2、3、13、16)的 score 大多 < 0.3:核心进控制后,它们剩下的主要是「核心减去它被零收益 / 价格解释的部分」,符号混在一起。若其中某个反而 ≥ 0.5,说明 H2(真形状)有独立的 alpha,这是本轮最重要的一条信息。
3. GP 会往「核心 + 一条和核心无关的好分支」(add / sub 一个别的因子)漂;heads 里若出现这种形状,它是新信息但不是对核心的深挖,第 2 轮要分开记。
4. 拒绝计数:`c05_periphery_seen` 很低(< 5),`c05_no_core` 和库秩相关禁令高得多。

**N 位(分钟序列的顺序与「成交钟」)。** 峰度把 241 根分钟收益当无序样本、也不看每分钟成交了多少钱;这两样五个控制里都没有。种子:一阶自回归 / DW / Hurst(价差反弹 vs 价格延迟)、成交额加权波动 / 钟表波动、最重 10% 分钟的平均收益、成交额重心与后置、成交时点减波动时点、收益与成交额的同期 / 滞后相关、收盘价与成交量的相关、带方向的成交额占比。

预测:
1. 产出 heads 的概率约 65%,1–3 个。最可能来自量价相关一支(`day_corr(Ret, Amt)`、`cross_mean(day_corr(Close, Volume), 20)` 及其变异)和带方向的成交额占比;
2. 自相关一支(ar1 / DW)单独过线的可能小:它的主要成分(价差反弹)和流动性控制同源,中性化后剩得不多;Hurst 那条大概率是噪声(文献也这么警告)。
3. 若量价相关一支出 head,它与 `day_kurt(Ret)` 的交易信号残差相关 |ρ| < 0.3(两者读的是不同的东西)。

**R(16 个,全部是 `day_kurt(Ret)` 的换件,兼作判决)。** 预测:
1. 11 号 `cross_ema(day_zero_ratio(Ret), 10)`:过门槛,rho_head ≥ 0.5(我押 0.5–0.8)。
2. 12 号 `log(div(day_sum(Amt), day_sum(Volume)))`(名义价格):rho_head 在 0.3–0.6 之间,方向是做多高价;自身 score 能不能过 0.5 我没有把握(五五开)。
3. 1 号 `day_kurt(in_logchg(Vwap, 1))`(只在有成交的分钟上算)和 3 号 `day_kurt(in_pct(Close, 5))`(五分钟收益):score 都明显低于 0.97(我押 < 0.7)。若反而 ≥ 0.97,H1 / H4 被否,H2 成立,第 2 轮整个判读要翻。
4. 8 号 `cs_rank`、9 号 `log(kurt+5)`、10 号 `cross_med(·, 20)` 这三个「去掉峰值记忆」的换件里,至少一个 score 高于 0.97;但够 +0.1 的替换线、真替换的概率约 35%。若是 8 / 9 号替换,说明峰值记忆是有害部件;若三个都更差,说明 alpha 就在「出没出现过尖峰日」这件事上(更像 H3 / H1 的事件)。
5. 4 号 `day_gini(Ret)`:过门槛,rho_head ≥ 0.5,不够 +0.1。
6. 13 号封板占比、14 号尺度无关 MAX:rho_head < 0.5(H3 不是主成分)。
7. 16 个里 0–2 个栽在门槛上(最可能是 5 / 6 号单侧尾部的 coverage)。k/241 型比例的原子都套了 EMA10 —— 本机用价格网格模拟过,20 日均值的取值不同比例只有 0.13(过不了 distinct ≥ 0.5),EMA10 是 0.95。
8. 本轮替换数:0 或 1。

### 留给第 2、3 轮的规则

- `day_kurt(Ret)` 还剩 1 个 E 位。只有在本轮 E 出了 head、或 R 证明某个换件(比如只在有成交分钟上的峰度)本身是一个更干净的核心时,才再给它 E;否则把 E 让给 M 第 2、3 批的新核心。
- 第 2 轮先读 R 的 rho_head 表(11、12、1、3 号),据此把 H1 / H4 / H2 的权重改掉,再决定第二个 N 要不要直接去做「名义价格 / 价格网格」。
- 若 M 第 2 批的 head 又是 `day_X(field)` 两节点形状,拆解会再次是 0;连续两轮为 0 就记为 B 组在本种子的结构性损失(48 × 轮数的预算作废)。
