## 1. 它是什么(逐层,按函数定义)

`day_kurt(nt_cs_mask_top_replace_mean_neg(abs_(Amt)))`,A = Amt(分钟成交额,元):

1. **`abs_(Amt)` = 空操作**。Amt ≥ 0。`abl_A`(删掉 abs_)与 `v_base` 全列逐位相同、ρo = 1.00。
2. **`nt_cs_mask_top_replace_mean_neg`:名字三处骗人**。`face=nt / axis=S` ⇒ 每个 **(日, 分钟)** 格子沿**股票轴**做;
   `_neg` 版是 `-cs_mask_top_replace_mean(-x)`,改的是**最低** 10%(名字里的 top 反了,docstring 自己写的是
   "Bottom-band counterpart");替换值是 `_mean(x_masked)` = **当分钟全市场成交额的截面均值**,而 `-mean(-x) = mean(x)`,
   所以替换值不是什么中性值,而是一条**市场级时间序列 M[d,m] = 当分钟市场总成交额 / N**。
   Amt 的截面极度右偏,M 落在股票分布的 80~90 分位 ⇒ 对被遮的股票-分钟来说,替换是**往上插一根 10~100 倍的尖峰**。
   **这个算子实际上是一个「带巨型旗标的指示函数」**:被遮的分钟写上 M,没被遮的分钟保留自己的 A。
3. **`day_kurt`**:对混合序列 {未遮分钟 = A} ∪ {被遮分钟 = M} 取当日分钟峰度(标准化四阶矩)。
   - 从不被遮(活跃票)→ 自己日内成交额型态的峰度;
   - 只被遮几分钟(卡在底十分位门槛上的票)→ 那几分钟是 10~100 倍的离群点,四阶矩被它们统治 → **峰度极高**;
   - 大半分钟被遮(极清淡票)→ 序列≈市场型态 M + 几个很小的自有值 → 峰度回到中等。
   ⇒ 峰度是**流动性的驼峰型(非单调)函数**,峰在「正好跨在全市场底十分位门槛上」的票。
   `day_kurt` 又是尺度无关的(四阶中心矩 ÷ σ⁴),**成交额的水平被它除掉了**。
   方向 sg = −1(买低峰度)= 买驼峰的两端 ⇒ 书是成交额上的**杠铃**:最低档超配 +25.1pp、最高档 +6.1pp,中间三档 −7.3 / −12.7 / −11.1pp。
4. 一个少见的副作用:M[d,m] 是**所有股票共用**的市场序列,所以因子里混进了「这只票的死分钟与市场繁忙分钟对不对齐」——
   任何纯自身序列的统计量都没有这一条(§3 的推论 e 就是查它)。
