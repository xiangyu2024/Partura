# Partura 的工作方式:每条表达式都是一次新的研究

写在最前面,因为这是最容易做错的一件事:

> **不要把上一条因子的配置改个表达式就跑。**
> 实验计划是**从这棵树推出来的**,不是模板。探针集合也是。
> 唯一跨研究复用的东西是**结论**(`lab/findings.yaml`),而且它是先验,不是证据。

## 1. 为什么计划不能复用

F001 是「日内折叠 → 日轴极值 → 逐元素乘 → 日轴极值」。它需要的问题是:
这个量带不带尺度?取极值是在记事件还是在取幅度?乘法是门控还是两个信号?

F002 是「日内折叠 ×2 → **跨日成对协方差** → 日轴顺序统计量」。这棵树里
没有逐元素乘法,所以"门控"这个问题根本不存在;但它多了一个**成对**算子,
于是冒出两个 F001 从来不需要问的问题:

- 两个操作数是**对称**的吗?(如果是,"High 解释波动"这种读法就不被表达式支持)
- 它配的是**同期**还是**跨期**?

第二个问题在内置探针里没有答案,只能为这次研究写一个。写出来之后测到的东西是:

| | 操作数对称 | 脉冲交互随滞后 L 的衰减(相对 L=0) |
|---|---|---|
| `cross_cov(x, y, 15)` | 是 | L≠0 一律 **0.0714 = 1/(15−1)** |
| `cross_corr(x, y, 15)` | 是 | L≠0 是 **0.41~0.64** |

`cross_cov` 在 L≠0 上的那点响应**不是跨期配对**,而是窗口均值被脉冲推动造成的泄漏,

## 0. 目标:提纯、分辨、升华

| | 要回答的问题 | 算做到了 |
|---|---|---|
| **分辨** | 这东西到底是什么?是不是某个已知暴露(成交额水平、规模、换手率、波动、动量、反转)换了个写法?和这批其他因子、和已知家族是不是同一个? | 有中性化的 R² 和残差表现、有 rank 相关、有"把可疑节点换成它的朴素等价物"的直接替换实验 |
| **提纯** | 预测力在树的哪一部分?哪些节点、指数、窗口、字段是多余的? | 给出一个**更小**的结构,在 train 和 valid 上保住(或超过)原式;每删一个节点都有实验 |
| **升华** | 看懂机制之后,能不能写出一个**更好用**的版本? | 见下面的"好用" |

**"好用"的口径**(用户的真实目标是 A 股纯多头,空头腿做不了):

1. **多头腿**:纯多头夏普、多头腿**净**超额(扣 15 bp 之后)。用户表里公布的"多头腿年化超额"是**毛**的;

   一个把多头腿净超额从 +3% 做到 +8% 的版本,比一个把多空夏普从 3.5 做到 4.0 的版本有用得多。
2. 多空夏普(扣费)。
3. 换手、简单程度、邻域稳定性(窗口/指数换一档不塌)。
4. **必须过用户的两道门槛**:`cov`(有标签的格子里因子有值的比例)≥ 0.95,`dist`(取值离散度)≥ 0.5。
   过不了门槛的候选不能当结论(档位太少的因子,十分位书靠股票代码顺序破平局)。

三件事不一定都能做成。**"它 80% 是成交额水平,提纯后就是 `cross_max(day_sum(Amt), 9)`,没有升华空间"

    """Replace the top `top_ratio` fraction (by value, per row) of each
    row with that row's mean.

    The original implementation used `torch.topk` to find candidate top
    indices and then a Python `for i in range(N)` loop (`N` there is
    actually the number of ROWS/time steps, not stocks — a misleading
    variable name) to build the final replace-mask row by row. Replaced

    mask = _valid(x, valid_mask)

    # Top `n_top` largest values per row <=> rank strictly greater than
    # (count - n_top). NaN ranks (invalid entries) never satisfy this.
    top_mask = mask & (integer_rank > (count - n_top))

def _rank_rows_torch(x: np.ndarray, device: str, rows: int = 512) -> np.ndarray:
    """``rank_rows`` on an accelerator: per-row average ranks (ties averaged) of
    the finite cells, NaN elsewhere -- the same answer as the pandas version
    (locked by tests/test_partura.py), without the CPU.  The server's CPU quota
    is usually taken by a neighbouring job while its GPU sits idle, and ranking
    a 1400 x 5200 panel is the single hottest call in a study."""
    import torch
    x = np.asarray(x, dtype=np.float64)
    out = np.empty(x.shape, dtype=np.float64)
    for a in range(0, x.shape[0], rows):
        t = torch.as_tensor(x[a:a + rows], device=device)
        fin = torch.isfinite(t)
        s, order = torch.sort(torch.where(fin, t, torch.full_like(t, float("inf"))), dim=1, stable=True)
        lo = torch.searchsorted(s, s, right=False)
        hi = torch.searchsorted(s, s, right=True)
        avg = (lo + hi + 1).to(torch.float64) / 2.0
        r = torch.empty_like(t).scatter_(1, order, avg)
        r[~fin] = float("nan")
        out[a:a + rows] = r.cpu().numpy()
    return out

`day_durbin_watson` 的形式值得写成公式,因为整条 alpha 的一半解释都在这里:

```
DW(x) = Σ_{m=2..M} (x_m − x_{m−1})²  /  ( Σ_{m=1..M} x_m² + 1e−8 )
```

分母是 **Σx²,不是方差**(探针:平移不变 = False,齐次度 = 0)。把 x = Open 写成 P(1+u_m),
分子 ≈ P²·Σ r_m²,分母 ≈ M·P²,于是

```
DW(Open) ≈ (1/M) Σ r_m²  =  日内分钟收益的已实现方差
```

也就是说,这个名字叫"Durbin-Watson 自相关检验统计量"的算子,作用在**价格水平序列**上时
根本不是在检验自相关,而是在算**日内波动率的平方**。这不是猜测:把它换成 `day_var(Ret)`

@op("nd", "cs", arity=2)
def cs_regres(Y: torch.Tensor, X: torch.Tensor, valid_mask: Optional[torch.Tensor] = None) -> torch.Tensor:
    """Cross-sectional (per-row, across stocks) OLS residual of
    `Y ~ alpha + beta*X`, one independent regression per time step.
    """
    mask = torch.isfinite(X) & torch.isfinite(Y)
    if valid_mask is not None:
        mask = mask & valid_mask
    X_ = torch.where(mask, X, torch.zeros_like(X))
