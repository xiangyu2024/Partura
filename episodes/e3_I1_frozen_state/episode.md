# 研究实验 `e3_I1_frozen_state`

想法 `I1_frozen_state`;奖励 `long_screen`;每臂预算 192 个候选(种群 48,随机种子 0);搜索只看 20180102–20230807(其中 20220101 起算 valid),测试段没有打开。

## 假设

盘口冻结(封板、停牌前后、无成交)是一个持续几周的状态,处在这个状态里的票系统性跑输;哪一种「冻结度」的写法、多长的记忆最能标出它

## 干预(带指引的一臂)

- 种子进首代:`cross_max(day_zero_ratio(Ret), 15)`、`cross_mean(day_flat_ratio(Close), 15)`、`cross_max(day_flat_run_max(Close), 15)`、`cross_mean(day_zero_ratio(Amt), 30)`
- 想法里的算子采样概率 × 8.0;候选必须含这些算子之一:day_zero_ratio、day_flat_ratio、day_flat_run_max、day_distinct_ratio、day_at_max_ratio、day_at_min_ratio
- 每棵候选树过指引 `guidance/B01.yaml`:封禁的不放行,降权 / 升权按概率放行,等价写法只放行第一个

## 对照

同一个 GP、同一个奖励、同样的预算与随机种子、同一个算子库;不带种子、不过指引、均匀采样。

分数的含义:「候选改过的书」减「参照书」的逐日净超额之差在 train+valid 合并段上的信息比(任一段低于 −1 则取那一段);参照书 = 已知族;候选改过的书 = 已知族把候选最高两成(整块并列)排到最后。「分数 ≥」各列数的是互不等价的候选;「族」= 只差价格字段换名、或只在最外层多套一个保序函数的算一族。

带指引的一臂提出了 353 棵树:封禁 4、不在想法邻域 58、按权重抽掉 46、与已提过的等价 1、放行 224。

合并段的 5.6 年里 train 占 4 年,信息比被它主导;所以「发现」另外要求 train、valid 各自的成对信息比都过 0.5(`partura.steer.is_discovery`)。
**注意**:这次的信息比还不带大小 —— 每天只换掉一两只票、换得略好而且很稳的候选也会得高分;要看账面多赚了多少(各臂找到的那几行)。
**注意**:证据文件里没有 `screen_base` —— 这次跑的是旧版脚本,筛子的参照是**没做过筛子的已知族**。

## 信念更新

**(2026-10-06 14:40 更正)这次短搜的参照其实仍是「没做过筛子的已知族」;按信息比数两臂打平,按账面大小数带指引 11 族对 0 族;但这些筛子样本外没有站住(K001)。**

- **参照不是原先写的那个。** 服务器上跑的是旧版 `scripts/idea_search.py`(由服务器端的启动脚本直接起,没有先同步;没有 `--screen-base`)。
  证据:证据文件里没有 `screen_base` 字段;候选账面的水平(train +12.8% / valid +22.5%)正好是未筛的已知族(+12.6% / +22.3%),不是筛过的(+16.4% / +23.5%)。
  原先那句「参照换成已做过通用筛子的已知族之后,仍有三成候选能在两段都改善它」**不成立,作废**。
- 按成对信息比数(合并段 ≥ 1 且两段各 ≥ 0.5):带指引 26 个 / 18 族,对照 22 个 / 20 族 —— 看上去打平。
- **按账面大小数就不是打平**:「筛过之后的书比参照每年多赚 ≥ 1 个点,train、valid 都是」—— 带指引 **11 族**,对照 **0 族**(≥ 2 个点:6 对 0)。
  对照臂的「发现」是又小又稳的改动:`day_min(nt_ts_delta(Amt, 3))` 信息比 +3.36 / +1.09,账面只多 +0.8 / +0.3 个点;
  `ts_std(day_topw_mean(Volume, Close), 20)` 信息比 +2.03 / +1.60,账面 +0.2 / +0.2(K001 里它当筛子是空操作)。
  成对信息比不看大小:每天只换掉书里一两只票、换得略好而且很稳,信息比就很高。
- 带指引一臂最好的(账面每年多赚 train / valid):`cross_mean(cross_max(pow_2_5(day_flat_ratio(Vwap)), 10), 15)` +3.6 / +2.9;
  `cross_mean(day_at_max_ratio(Vwap), 15)`(封板)+3.2 / +2.6。种子本身(通用冻结筛子)是 +3.8 / +1.2。
- **样本外**(K001,按事先写下的规则读):这两个当单层筛子,对已知族的成对差是 −1.4 个点(t = −0.8)和 +0.4 个点(t = 0.2);叠在冻结筛子上 +0.6(t = 0.4)。
  连通用冻结筛子自己也只有 +0.9 个点(t = 0.6)—— 筛子的增益集中在 2018–2020。所以这次搜到的是**样本内的筛子,不是能用的因子**。
- 对「指引有没有用」:按账面大小数是第一条正面的证据,但它是**事后换尺子**得到的(两臂优化的都是不带大小的信息比)。
  确认实验 e4(`episodes/e4_PLAN.md`)用带大小的奖励、三个新种子重跑,事先写了判读标准。
