# 研究实验 `e3_I1_frozen_state`

想法 `I1_frozen_state`;奖励 `long_screen`;每臂预算 192 个候选(种群 48,随机种子 0);搜索只看 20180102–20230807(其中 20220101 起算 valid),测试段没有打开。

## 假设

盘口冻结(封板、停牌前后、无成交)是一个持续几周的状态,处在这个状态里的票系统性跑输;哪一种「冻结度」的写法、多长的记忆最能标出它

## 干预(带指引的一臂)

- 种子进首代:`cross_max(day_zero_ratio(Ret), 15)`、`cross_mean(day_flat_ratio(Close), 15)`、`cross_max(day_flat_run_max(Close), 15)`、`cross_mean(day_zero_ratio(Amt), 30)`
- 想法里的算子采样概率 × 8.0;候选必须含这些算子之一:day_zero_ratio、day_flat_ratio、day_flat_run_max、day_distinct_ratio、day_at_max_ratio、day_at_min_ratio
- 每棵候选树过指引 `guidance/B01.yaml`:封禁的不放行,降权 / 升权按概率放行,等价写法只放行第一个

## 对照

同一个 GP、同一个奖励、同样的预算与随机种子、同一个算子库;不带种子、不过指引、均匀采样。

## 信念更新

**参照换成已做过通用筛子的已知族之后,仍有三成候选能在两段都改善它 —— 已知族的书里还有可剔的票;两臂打平,找到的是两类不同的新筛子。**

- 按脚本原定的标准(合并段信息比 ≥ 1.0):带指引 50 个、对照 63 个。但合并段被 train 主导:带指引一臂的头名
  `ts_std(pow_1_5(day_flat_ratio(Vwap)), 20)` 是 train +5.06 / valid +0.08 —— 只在 2018–2021 有效(那几年的僵尸票)。
- 改成「两段的成对信息比都 ≥ 0.5」重数(存下来的前 80 个里互不等价的):带指引 **32 个**、对照 **23 个**;都 ≥ 1.0 的是 5 个对 6 个。大致打平。
- 两臂各自最稳的:
  - 带指引:`cross_mean(day_at_max_ratio(Vwap), 15)`(近 15 日「钉在当日最高价」的分钟占比,即涨停封板)train +1.46 / valid +1.41;
    `cross_mean(cross_max(pow_2_5(day_flat_ratio(Vwap)), 10), 15)` +1.33 / +1.31。
  - 对照:`ts_std(day_topw_mean(Volume, Close), 20)`(成交量最集中的那些分钟的价位,20 日里有多不稳定)+2.03 / +1.60;`ts_std(day_wmean(Volume, High), 20)` +1.59 / +1.37。
- 读法:通用的冻结盘口筛子(零收益分钟占比)没有把该剔的票剔干净。还剩两类:**近期封过涨停的**(钉在最高价,和「不动」不是一回事)、**成交在日内的分布很不稳定的**。
  这两类要进批量扫描当通用筛子,和 `k_known_xfrozen` 并排、按规则读测试段,才算数 —— 短搜只看了 train / valid。
- 对「指引有没有用」:第三次打平。192 的预算下,想法的邻域和随机搜索找到同样多的好筛子,只是类型不同。结论同 e2_I5:要大预算才能量。
- 对规则的影响:`evaluation` 加一条「成对奖励的发现 = 两段都 ≥ 0.5」;通用变体里加两个筛子(见上)。
