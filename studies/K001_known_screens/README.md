# K001_known_screens —— 已知成交额族上的筛子研究

不是用户表里的因子。底座就是已知族 `cross_mean(day_std(Amt), 30)`,研究的问题是:**它的多头书里哪些票该剔掉**。

来源:想法短搜 e2_I1 / e3_I1(`episodes/`)。两臂(带指引 / 对照)各自找到了一批「把它最高两成的票排到最后,已知族就变好」的量。
短搜只看了 2018-01 ~ 2023-08-07、每臂 192 个候选,所以它们只是候选;这里把它们当成通用筛子,在批量扫描的口径下重新量一遍,
再按下面写死的规则读一次测试段。假设在 `hypo.yaml`(45 条)。

## 假设

- H1 封板:近 15 日钉在当日最高价的分钟占比(`day_at_max_ratio(Vwap)`)标出的是涨停封板的票 —— 排在已知族前面但买不到 / 买到即回落。
  它和冻结盘口筛子(零收益分钟占比)剔的不是同一批票 ⇒ 两层叠起来比单层好。
- H2 成交分布不稳:成交最集中的那几分钟所在价位的 20 日波动(`ts_std(day_topw_mean(Volume, Close), 20)`)是对照臂找到的,
  读起来像「价格水平在动」= 近期大涨大跌过的票。若成立,它是一个便宜的「别追刚暴动过的」筛子。
- H3 档位:该剔的是一小撮(5%–10%)还是两成、四成。剔得越多越好 = 它其实是又一个低流动性倾斜;一小撮就够 = 真的是「状态」。
- H4 次新:算子改成只收整块并列之后,「上市不足 241 日」只占约 7%,以前读到的两成筛子有一大半是随便挑的老股。重新量。
- H5 不剔、只罚(`o_frz_minus_pin`):把封板占比当成一个减分项,而不是一刀切。

## 测试段读数的规则(2026-10-06,写在看任何结果之前)

1. 总是读:`v_base`(= 已知族)、`k_known`、`k_known_xfrozen`。
2. **发现的原样检验**:九个单层两成筛子全部读,不挑 ——
   `s_frozen20, s_pin20, s_flatv20, s_volprof20, s_volprof220, s_tickfrz20, s_xvol20, s_new20, s_age20`。
   回答的是「短搜找到的筛子,样本外还在不在」。
3. **按样本内挑的前 6 个**:过门槛(覆盖 ≥ 0.95、区分度 ≥ 0.5)、train 与 valid 多头腿都为正,按样本内(train+valid)纯多头夏普从高到低。
   回答的是「按样本内挑,样本外兑现多少」。

往后能用的(进融合、进指引的升权)只能是第 3 条按规则挑出来的。第 2 条的测试段数字只用来判断「发现」成不成立,**不拿来在九个里再挑**。

判读(也是事先写下的):
- 一条筛子相对已知族「成立」 = 测试段上「它的书 − 已知族的书」逐日净超额之差的 t 值 ≥ 2,且样本内同号。
- 一条筛子「在通用筛子之外还有东西」 = 对 `k_known_xfrozen` 的同一个差,测试段 t ≥ 2 且样本内同号。
- t 在 1 到 2 之间记为「方向对、证据不够」;低于 1 记为没有。测试段约 2.4 年,所以 t = 2 大约对应信息比 1.3。
- 不成对的两个年化数之间,噪声带仍是 ±3 个点 / ±0.3 夏普。

### 按事先写下的标准判

**没有一条成立。** 标准是「测试段上对已知族的成对差 t ≥ 2 且样本内同号」:

- 九个单层两成筛子(原样检验):样本内对已知族多 +1.3 ~ +3.8 个点(信息比 0.5 ~ 1.7),样本外最好的也只有 +0.9 个点、t = 0.6(就是通用的冻结筛子本身);
  四个样本外为负(`s_flatv20` −1.4、`s_new20` −1.2、`s_xvol20` −1.6、`s_age20` −0.3)。
- 按样本内挑出的六个(全是叠在冻结筛子上的多层):样本外对已知族 +0.8 ~ +2.5 个点,t 最高 1.1(`d_frz_tickfrz20`)——「方向对、证据不够」;
  对通用筛子本身,最高 +1.6 个点、t = 1.3,其余都在 ±0.6 个点以内。

### 各条假设

- **H1 封板是另一类该剔的票 —— 否。** 单层:封板筛子(`s_pin20`)样本内和冻结筛子一样强(+3.8 对 +3.1),样本外 +0.4。
  叠在冻结筛子上(`d_frz_pin20`):样本内只再多 +0.5、样本外 +0.6(t = 0.4)。它和冻结筛子剔的是同一条尾巴,是替代品不是补充。
- **H2 成交集中价位不稳 —— 否,而且是空操作。** `s_volprof20 / 220` 的书和已知族一模一样(成对差 0.0)。它最高两成的票本来就不在已知族的多头书里。
  短搜给它的成对信息比 +2.0 / +1.6 来自「每天换掉一两只、换得略好而且很稳」:信息比不看大小。奖励已改(带大小)。
- **H3 档位 —— 样本内两成最好。** 5% / 10% 的筛子弱一半以上,四成开始伤 valid(`s_frozen40` 样本内 +14.8%、夏普 2.81)。所以垃圾尾巴约占五分之一,不是一小撮。
  这是样本内的结论。
- **H4 次新(算子修正后)—— 否。** `s_new20` 样本内 +1.3、样本外 −1.2(t = −1.8);`s_age20` +2.3 / −0.3。叠在冻结筛子上(`d_frz_age20`,样本内排第一)样本外对通用筛子 +0.1。
- **H5 只罚不剔 —— 否。** `o_frz_minus_pin` 样本外对通用筛子 −0.1。

### 更大的一条:筛子的增益集中在 2018–2020

通用冻结筛子逐年比已知族多:2018 +6.5、2019 +3.4、2020 +4.8、2021 +0.5、2022 +1.3、2023 −0.4、2024 +2.7、2025 +0.5(个点)。
样本内的 +3.1 个点有四分之三来自前三年(那几年的僵尸票 / 壳股);2021 年以后平均 +0.9。所以它在样本外「没站住」不是过拟合,是那类票后来不再拖后腿了。
对已知族做筛子这条线到此为止:**筛子不进指引的升权**(U5 降为备注),`k_known_xfrozen` 继续当基准但要写明它的样本外优势是 +0.9 个点、t = 0.6。

### 对方法的三条教训(已写进代码 / 指引)

1. 成对信息比不看大小 → `partura.steer._sized`(每年多赚不到 1 个点的按比例打折)。
2. 短搜的「发现」必须进批量扫描、按规则读测试段、和基准**成对**比,才算数 → `scripts/sweep_final.py` 的成对表、`scripts/paired_table.py`。
3. 服务器端的启动脚本不会同步代码 → `scripts/study.sh code`;证据文件记代码指纹。
