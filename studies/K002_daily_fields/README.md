# K002_daily_fields —— 日频字段(流通市值、股本、板块、上市天数)带来什么

不是用户表里的因子。底座是已知族 `cross_mean(day_std(Amt), 30)`。这是 B01 批次的第五轮,也是第一轮**换了信息源**的:
前四轮和六次想法短搜都只用分钟行情(价、量、额),校准的结论是「2022 年以后的多头超额 = 躲垃圾票 + 流动性倾斜」,
桶内奖励下搜不出站得住的东西(e6)。这一轮用 AlphaCube 新加的日频叶子。

## 数据(2026-10-07 实测)

- 新引擎在服务器 `<Partura>/vendor/AlphaCube-steering`,日频库在 `<Partura>/daily_fields`(2018-01-02 ~ 2026-09-16,5220 只)。验收见 `handoff/ac_accept/ACCEPTANCE.md`。
- 九个字段:`FloatCap` 流通市值、`TotalCap` 总市值、`FloatShares` 流通股本(都是元 / 股,收盘时点可知,没有隐式滞后);`LogFloatCap`、`LogTotalCap`、`LogFloatShares`(做差分、做比值一律用 Log);
  `LimitWidth` 涨跌幅宽度、`BoardCode` 板块、`ListAge` 上市天数(这三个从代码和交易日历推出来,不用建库)。
- 2025-03-31 那天的样子:流通市值 5% / 中位 / 95% 分位 = 11.8 亿 / 47.9 亿 / 460 亿;日换手率 `day_sum(Amt) / FloatCap` = 0.5% / 2.0% / 10.4%(成交额和市值同一个单位);
  流通比例 `FloatCap / TotalCap` 中位 0.98、5% 分位 0.33;`ts_delta(LogFloatShares, 20)` 绝大多数是 0(股本只在解禁、增发、回购那几天变)。
- (20:45 PDT 补,主研读内核与引擎后指出、总领实测的)
  - 引擎把不可交易的股票日全部置空,所以**表达式里停牌日的股本也是空的**(下面那句「停牌日有股本没有市值」只对磁盘上的平面成立,在表达式里用不上);逐日差分跨不过停牌缺口。
  - 库从 2018-01-02 起、没有预热:`ts_delta(x, d)` 在 d 超过 30 ~ 40 时过不了训练段 0.95 的覆盖门槛;241 / 300 日窗口的事件量在 2018 年上半年是半成品,逐年读时 2018 年要打折。
  - 「做差分用 Log」是对的做法,但理由不是精度:float32 下两个对数相减有约 ±2e-6 的抖动,稀疏事件量不要取秩,门槛取在 1e-3 以上。
  - **后复权收盘价吃掉了现金分红**(实测:工商银行 2024-07-16 除息日,`LogTotalCap − log(day_last(Close))` 当天 −0.0513、复权收盘价不动;茅台 2024-06-19 −0.0205)。
    **送转除权日股本和价格同一天变**(比亚迪 2025-07-29:`LogFloatShares` +1.0986 = ln 3,流通市值连续,`LogTotalCap − log(复权价)` 只动了现金分红那 −0.0119)。
    所以 `sub(LogTotalCap, log(day_last(Close)))` 下降 = 现金分红,上升 = 真实增发,送转不动它 —— 主研的「净回报率 / 不分红 / 增发」那十来条读的就是这个。
  - `cross_age(day_last(Close))` 把库第一天正在停牌的老股票当成复牌那天上市的新股(以前的「次新」筛子和分档里混着这些票);`ListAge` 不会。
  - `ts_pearson(x, d)` 是这只股票的 d 日窗口与其余每只股票同期窗口的平均相关(同步性),不是与时间的相关;B 组里 F111 一系按同步性读。
- 要知道的坑:`LimitWidth` 只有 0.10(3138 只)和 0.20(1950 只)两个值,**不认 ST 的 5%**;`BoardCode` 0 / 1 / 2 = 主板 3138 / 科创板 583 / 创业板 1367;
  `ListAge` 对视窗开始前就上市的股票是一个哨兵大数(11760),只对 2018 年以后上市的有区分度;停牌日有股本没有市值(`FloatCap` 为空)。
- 哪些算子吃日频叶子:截面与日轴算子(`cs_*`、`ts_*`、`cross_*`,含 Partura 的 `cs_bucket_*`、`cs_last_*`、`cs_first_*`)、逐元素运算(对着分钟张量会把当天的值铺到每一分钟,
  所以 `day_std(div(Amt, FloatCap))` 合法);`day_*(FloatCap)`、`in_*`、`nt_*` 直接吃裸日频叶子会被拒。
- 已知族和「小市值」的秩相关(2025-03-31):已知族取负之后 +0.60;换手率 +0.40。`cs_regres(已知族, LogFloatCap)` 的残差和市值的秩相关仍有 0.43 —— 线性残差在尾部不中性,拿掉市值要用 `cs_bucket_*`。

## 规则的修订(2026-10-07 20:45 PDT;主研交回 185 条假设和意见之后,任何回测之前)

主研读完计划后指出原规则有五处会误读(`HYPOTHESES.md` 与他的交回报告;原样的假设在提交 `61e374a`)。这些都在出任何数字之前改,原规则保留在上面,**以本节末尾的「现行规则」为准**。

1. **孪生不参加挑选。** 孪生(`_twin`)是不用日频字段的旧对象,样本内夏普高,一参加排名就把名额占满。改为:父假设被读时一起读,报「父 − 孪生」的成对差 = 日频字段的边际贡献。
2. **修改型假设对自己的载体判。** 筛子、罚分、只在某个板里买,都是「在一个载体上改一点」;它的绝对夏普基本就是载体的夏普,按绝对夏普排名排的是载体。
   `hypo.yaml` 里这类假设带 `base: <载体的 id>`(没有 `base` 的是独立假设)。修改型假设按「对载体的成对差」排名、去重、判读。D 组的罚分以 `a_known_in_size` 为载体,不再和已知族直接比。
3. **筛子的去重不能用秩相关。** 两个不同的筛子让秩相关掉到 0.4 ~ 0.6 而多头书重合八成(指引 E3),按秩相关去重会把同一本书读三次,或者把不同的筛子当成一样。
   改为:修改型假设之间,看各自「对载体的成对差」这条逐日序列的相关,≥ 0.7 的只留前面的。
4. **「就是市值」改用暴露来判,不用成对差的 t。** 和市值无关的候选(B 组全部)与小市值那本书几乎不重合,跟踪误差十个点上下,每年多赚 5 个点三年也只有 t ≈ 0.9 ——
   原规则会把「和市值无关」误记成「就是市值」。改为看样本内的两个暴露:交易信号与 `a_size` 的秩相关、多头书与 `a_size` 多头书的平均重合度。对 `a_size` 的成对差照报,改叫「有没有赢过小市值」。
5. **撤掉 `a_young`、`a_board` 两把尺子。** `LimitWidth` 只有两个取值,`ListAge` 对 2018 年以前上市的全并列在哨兵值上;直接当因子时十分位书落在并列块里,由代码顺序决定,读数是排序的产物。
   板块和上市天数改由 `e_main_only`、`e_wide_only`、`e_xage1y` 来量(升为尺子,总是读,不占 E 组的名额)。
6. **多重比较写明。** 修订后按规则会读二十个上下被挑中的假设,每个单侧 2.5%,纯碰运气至少出一个 t ≥ 2 的概率约四成。只有一个、且 t 在 2 ~ 3 之间的,记「候选成立」而不是「成立」。
7. 批量扫描不生成通用变体(`--only-extra`),185 条不会被 `--max` 截掉;被截掉任何一条都要报错而不是静默。

### 现行规则(实现以这一段为准)

对象的身份(由 `hypo.yaml` 决定):
- **尺子**(总是读,不参加挑选):`v_base`、`k_known`、`k_known_xfrozen`;`a_size`、`a_tsize`、`a_turn20`、`a_amt20`、`a_known_in_size`、`a_size_in_known`、`a_known_in_turn`、`a_size_plus_known`;`e_main_only`、`e_wide_only`、`e_xage1y`。
- **独立假设**:id 以 `b_ / c_ / d_ / e_` 开头,没有 `base`。
- **修改型假设**:同上,带 `base`。
- **孪生**(`_twin`)与**载体**(`x_`):不参加挑选;被挑中的假设用到它们时一起读。

挑选(只用样本内 = train + valid;门槛对所有类型:覆盖 ≥ 0.95、区分度 ≥ 0.5):
- 独立假设:train 与 valid 的多头腿净超额都为正;按样本内纯多头夏普从高到低;同组里交易信号秩相关 ≥ 0.7 的只留排在前面的。每组最多 3 个。
- 修改型假设:对自己载体的逐日成对差(纯多头净超额,同一天相减)在 train 与 valid 的均值都为正;按样本内这条成对差的信息比从高到低;
  同组里两条成对差序列相关 ≥ 0.7 的只留排在前面的。成对差恒为 0 的(空操作)不算。每组最多 3 个。
- 所以 B、C、D、E 每组最多 6 个;不足的有几个读几个。

读:被挑中的假设,连同它的载体、它的孪生,和全部尺子,在测试段、前推段、合并段**一起读一次**,记账。半衰期按规则在样本内选;固定半衰期 10 再读一遍。

判读(成对差都是同一天相减的纯多头逐日净超额;看合并段的 t,并要求样本内同号):
- 独立假设对 `k_known`;修改型假设对自己的载体(「成立」= 这个修改让载体变好了),同时报它对 `k_known` 的差(描述)。
  t ≥ 2 = 成立(受下面多重比较那一条约束);1 ~ 2 = 方向对、证据不够;0 ~ 1 = 没有;为负 = 更差。
- 孪生:报「父 − 孪生」;t ≥ 2 才说日频字段在这条上有贡献。
- **是不是市值**(暴露,样本内量):与 `a_size` 的交易信号秩相关 ≥ 0.7,或多头书(前 10%)与 `a_size` 多头书的平均重合度 ≥ 0.5 → 「就是市值」。两个数对每个读到的对象都报。
- **有没有赢过小市值**:对 `a_size` 的成对差,同样的门槛,只作描述。
- **拿掉市值之后还剩东西**(B 组的独立假设和 `a_known_in_size`):合并段净超额为正且夏普 ≥ 1。水平读数,噪声带 ±3 个点 / ±0.3 夏普。
- 修改型假设另报「改动了载体多头书的多大比例」(1 − 与载体多头书的重合度;样本内、合并段各一个数)。
- **多重比较**:整轮里只有一个「成立」且它的 t 在 2 ~ 3 之间 → 记「候选成立」,等前推段变长再确认。t ≥ 3,或同一组里两个互不相关的都 ≥ 2,才直接写成立。
- 两种半衰期的读法结论不一致时,以固定半衰期的为准并写明。前推段只有 0.68 年,单看前推段不下结论。

## 事先的预期(写下来好对账)

- `a_size` 在样本内很强(2018 ~ 2023 的小盘溢价),回撤也大;合并段为正但夏普不到 1.5。已知族对 `a_size` 的成对差在噪声内(|t| < 1)—— 也就是「已知族大半是市值」。
- `a_known_in_size` 保住已知族样本内净超额的一半上下(+6% ~ +9%),合并段夏普 0.5 ~ 1.0:市值之外还有一点流动性的东西,但不多。
- C 组:换手率写法和成交额写法在同市值档内几乎是同一个东西(秩相关 > 0.8),成对差在噪声内。
- D 组:股本扩张(解禁 / 增发)之后跑输是文献里有的,但事件稀疏;当因子用多头腿上没有东西,当筛子用(E 组)每年能多 0.5 ~ 1 个点,3 年的样本到不了 t = 2。
- 这个项目到现在按规则挑出来读样本外的候选,没有一个对已知族到 t ≥ 2。最可能的结果仍然是「没有一条成立」;如果有,最可能出在 B / E 组(把市值拿掉或把极小市值剔掉)。

## 两个必须写明的偏差

1. 主研写假设之前已经知道前几轮的测试段读数,也可能知道 2026 年的若干读数(已知族前推段 +7.6%、冠军 +16.9% 等);所以测试段和前推段对这一轮都不算完全干净。
   能做的只有:假设一次写完、规则写在前面、读一次。
2. 流通市值在 A 股是被研究得最多的变量,这一轮的「发现」要先和 `a_size` 比,而不是只和已知族比。
