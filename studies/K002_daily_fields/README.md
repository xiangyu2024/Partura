# K002_daily_fields —— 日频字段(流通市值、股本、板块、上市天数)带来什么

不是用户表里的因子。底座是已知族 `cross_mean(day_std(Amt), 30)`。这是 B01 批次的第五轮,也是第一轮**换了信息源**的:
前四轮和六次想法短搜都只用分钟行情(价、量、额),校准的结论是「2022 年以后的多头超额 = 躲垃圾票 + 流动性倾斜」,
桶内奖励下搜不出站得住的东西(e6)。这一轮用 AlphaCube 新加的日频叶子。

## 数据(2026-10-07 实测)

- 新引擎在服务器 `<Partura>/vendor/AlphaCube-steering`,日频库在 `<Partura>/daily_fields`(2018-01-02 ~ 2026-09-16,5220 只)。验收见 `handoff/ac_accept/ACCEPTANCE.md`。
- 九个字段:`FloatCap` 流通市值、`TotalCap` 总市值、`FloatShares` 流通股本(都是元 / 股,收盘时点可知,没有隐式滞后);`LogFloatCap`、`LogTotalCap`、`LogFloatShares`(做差分、做比值一律用 Log);
  `LimitWidth` 涨跌幅宽度、`BoardCode` 板块、`ListAge` 上市天数(这三个从代码和交易日历推出来,不用建库)。
- 2025-03-31 那天的样子:流通市值 5% / 中位 / 95% 分位 = 11.8 亿 / 47.9 亿 / 460 亿;日换手率 `day_sum(Amt) / FloatCap` = 0.5% / 2.0% / 10.4%(成交额和市值同一个单位);
  流通比例 `FloatCap / TotalCap` 中位 0.98、5% 分位 0.33;`ts_delta(LogFloatShares, 20)` 绝大多数是 0(股本只在解禁、增发、回购那几天变)。
- 要知道的坑:`LimitWidth` 只有 0.10(3138 只)和 0.20(1950 只)两个值,**不认 ST 的 5%**;`BoardCode` 0 / 1 / 2 = 主板 3138 / 科创板 583 / 创业板 1367;
  `ListAge` 对视窗开始前就上市的股票是一个哨兵大数(11760),只对 2018 年以后上市的有区分度;停牌日有股本没有市值(`FloatCap` 为空)。
- 哪些算子吃日频叶子:截面与日轴算子(`cs_*`、`ts_*`、`cross_*`,含 Partura 的 `cs_bucket_*`、`cs_last_*`、`cs_first_*`)、逐元素运算(对着分钟张量会把当天的值铺到每一分钟,
  所以 `day_std(div(Amt, FloatCap))` 合法);`day_*(FloatCap)`、`in_*`、`nt_*` 直接吃裸日频叶子会被拒。
- 已知族和「小市值」的秩相关(2025-03-31):已知族取负之后 +0.60;换手率 +0.40。`cs_regres(已知族, LogFloatCap)` 的残差和市值的秩相关仍有 0.43 —— 线性残差在尾部不中性,拿掉市值要用 `cs_bucket_*`。

## 五组问题(假设在 `hypo.yaml` 里按组写;A 组是总领定的尺子,其余由主研写)

- **A 校准(尺子,不算发现)**:现有的多头超额里,多少就是小市值和换手率?
- **B 拿掉市值之后还剩什么**:前几轮独立的升级版和已知族,在流通市值十档内排名之后,多头腿还在不在。
- **C 写法替换**:成交额类的量换成换手率(除以流通市值 / 流通股本),是不是同一个东西更干净的写法。
- **D 新信息**:股本变动(解禁、增发、回购)、流通比例、市值与价格的背离、板块与涨跌幅宽度、上市天数。
- **E 筛子**:用日频字段把一类票从已知族的多头书里剔掉(极小市值、次新、股本刚扩张的)。

A 组的对象(id 写死,总是读):

| id | 表达式 | 量的是什么 |
|---|---|---|
| `a_size` | `neg(LogFloatCap)` | 小流通市值 |
| `a_tsize` | `neg(LogTotalCap)` | 小总市值 |
| `a_turn20` | `cross_mean(div(day_sum(Amt), FloatCap), 20)` | 20 日平均换手率(方向按训练段) |
| `a_amt20` | `cross_mean(day_sum(Amt), 20)` | 20 日平均成交额(方向按训练段) |
| `a_known_in_size` | `cs_bucket_rank(neg(cross_mean(day_std(Amt), 30)), LogFloatCap)` | 已知族,只在同市值档内比 |
| `a_size_in_known` | `cs_bucket_rank(neg(LogFloatCap), cross_mean(day_std(Amt), 30))` | 小市值,只在同已知族档内比 |
| `a_known_in_turn` | `cs_bucket_rank(neg(cross_mean(day_std(Amt), 30)), cross_mean(div(day_sum(Amt), FloatCap), 20))` | 已知族,只在同换手率档内比 |
| `a_size_plus_known` | `add(cs_rank(neg(LogFloatCap)), cs_rank(neg(cross_mean(day_std(Amt), 30))))` | 两者排名等权相加 |
| `a_young` | `ListAge` | 上市天数(方向按训练段) |
| `a_board` | `LimitWidth` | 20% 涨跌幅的板块对 10% 的(方向按训练段) |

A 组的方向(2026-10-07 20:20 PDT 补,仍在算任何带日频叶子的因子之前):标了「方向按训练段」的四个(`a_turn20`、`a_amt20`、`a_young`、`a_board`)按训练段的纯多头书定;
其余六个**锁定为表达式写的方向** —— 它们是尺子,含义写在表里:`a_size` 就是「小流通市值」,不因为训练段(2018 ~ 2021)大盘股占优就翻成大市值。实现:`hypo.yaml` 里这六条带 `lock: true`。

## 读数规则(2026-10-07 19:40 PDT,写在算任何一个带日频叶子的因子之前)

样本内 = 2018-01-02 ~ 2023-08-07(train 2018 ~ 2021,valid 2022-01 ~ 2023-08-07);测试段 = 2023-08-08 ~ 2025-12-31;前推段 = 2026-01-05 ~ 2026-09-16。
尺子同前:全市场十分位纯多头书,扣单边 15bp;变体的方向按训练段的纯多头书定(原式和基准按 rank IC 的符号,根是筛子的锁 +1)。

1. **总是读(描述)**:`v_base`、`k_known`、`k_known_xfrozen`,和 A 组的十个。A 组是尺子,它们的读数不拿来挑。
2. **B、C、D、E 每组按样本内挑前 3 个**:过门槛(覆盖 ≥ 0.95、区分度 ≥ 0.5)、train 与 valid 的多头腿净超额都为正,按样本内(train + valid)纯多头夏普从高到低;
   同一组里交易信号两两秩相关 ≥ 0.7 的只留排在前面的那个(指引 E10)。某组过门槛的不足 3 个就有几个读几个。
3. 测试段和前推段**一起读一次**,记账(`runs/K002_daily_fields/ledger.json` 与 `runs/_forward/ledger.json`)。读过之后不再回头改假设重读。

判读(成对:同一天相减的逐日净超额;合并段 = 测试段 + 前推段,约 3 年):

- 对已知族「成立」= 合并段成对差 t ≥ 2,且样本内同号。1 ~ 2 = 方向对、证据不够;< 1 = 没有;为负 = 更差。
- 对小市值也报同一个差:一个候选若对已知族成立、但对 `a_size` 的成对差 t < 1,记为「**就是市值**」,不算新信息。
- 「拿掉市值之后还剩东西」(B 组和 `a_known_in_size`)= 它自己的合并段纯多头净超额为正且夏普 ≥ 1。这是水平读数,不成对;噪声带 ±3 个点 / ±0.3 夏普。
- 半衰期按规则在样本内选;另外固定半衰期 10 再报一遍(指引 E12)。两种读法结论不一致的,以固定半衰期的为准并写明。
- 前推段只有 0.68 年,单看前推段不下结论。

## 事先的预期(写下来好对账)

- `a_size` 在样本内很强(2018 ~ 2023 的小盘溢价),回撤也大;合并段为正但夏普不到 1.5。已知族对 `a_size` 的成对差在噪声内(|t| < 1)—— 也就是「已知族大半是市值」。
- `a_known_in_size` 保住已知族样本内净超额的一半上下(+6% ~ +9%),合并段夏普 0.5 ~ 1.0:市值之外还有一点流动性的东西,但不多。
- C 组:换手率写法和成交额写法在同市值档内几乎是同一个东西(秩相关 > 0.8),成对差在噪声内。
- D 组:股本扩张(解禁 / 增发)之后跑输是文献里有的,但事件稀疏;当因子用多头腿上没有东西,当筛子用(E 组)每年能多 0.5 ~ 1 个点,3 年的样本到不了 t = 2。
- 这个项目到现在按规则挑出来读样本外的候选,没有一个对已知族到 t ≥ 2。最可能的结果仍然是「没有一条成立」;如果有,最可能出在 B / E 组(把市值拿掉或把极小市值剔掉)。
