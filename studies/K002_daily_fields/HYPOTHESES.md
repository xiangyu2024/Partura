## 0. 决定写法的几条实现事实(读内核和引擎得到的,不是按名字理解的)

1. **引擎把不可交易的股票日在叶子和节点输出上都置空**(默认策略只在可能泄漏的地方置空,结果与逐节点置空相同)。表达式里停牌日的 `LogFloatShares` 也是空的 —— README 的「停牌日有股本没有市值」在表达式里用不上;逐日差分跨不过停牌缺口。
2. **没有预热。** 库从 2018-01-02 起;`ts_delta(x, d)` 的前 d 天为空,训练段约 970 天,d 超过 30 ~ 40 就过不了 0.95 的覆盖门槛。所以长窗口的变化量写成「相对窗口低点 / 高点」(`cross_min` / `cross_max`)或逐日累加(`cross_sum`,缺失日记 0 —— 对事件增量是对的,对水平量不是)。
3. **取窗口极值前先 `cross_med(·, 3)`。** 送转除权日若股本与价格错开一天更新,单日尖峰会被极值记住一整个窗口;3 日中位数把单日尖峰去掉,代价是事件晚一天被认出。
4. **日轴长窗口用 `cross_*`(引擎按股票分块),不用 `ts_*`(整块 (D, S, 窗口) 进内存,241 日窗口一个节点约 10 GB)。**
5. **并列。** `cs_rank`、十分位书、`cs_bucket_*` 的分桶都按代码顺序打破并列;`cs_last_* / cs_first_*` 只收整块并列。所以两值 / 哨兵 / 大量为 0 的量(`LimitWidth`、`BoardCode`、`ListAge`、流通比例、股本变动)不直接取秩:写成门槛标记、原始幅度的罚分,或用一个载体打破并列。
6. `cs_regres(y, LimitWidth)` 在键只有两个取值时恰好是组内去均值(板块中性)。`cs_last_high40(y, LimitWidth)` 这类按分位带的写法依赖 10% 板占比 > 60%(2025-03-31 是 61.7%),会不报错地变成空操作,没有用。
7. float32 下两个对数相减有 ±1.9e-6 的抖动(合成数据上 241 日累加最大 5e-6):门槛都取在 1e-3 以上;不对稀疏事件量取秩。
8. `ts_pearson(x, 20)` 的内核是「这只股票的 20 日窗口与其余每只股票的窗口的 Pearson 相关,对其余股票取均值」= **同步性**,不是与时间的相关。市场下跌的窗口里两者符号相反(合成数据上逐日相关 −0.9 ~ −0.99)。B01 文档里 F111 的「走势越单调上行越好」是按名字读的。
9. `cross_age(day_last(Close))` 把库第一天正在停牌的老股票当成复牌那天上市的新股;`ListAge` 按生命周期算,不会。
10. `ts_rank` / `cross_rank` 在当日为空而窗口内有值时返回 0 而不是空;`ts_corr` 类在有效点不足 2 个时返回 0,且分母里的 1e-9 会把量级很小的输入(分钟换手率 ~1e-5)的相关系数压扁 —— 这几个算子这一轮没有用。

## B 拿掉市值之后还剩什么(40 条)

**市场上的道理。** log 成交额离散度 = log 流通市值 + log 换手率 + log 日内形状。校准的结论是 2022 年以后的超额 = 躲垃圾票 + 流动性倾斜。拿掉市值之后:
流动性那一半只剩「同样大小的票里更清淡的」—— 对手是为流动性付价的短线资金,溢价应当小而稳;躲垃圾票那一半(冻结盘口、典型性折叠、同步性)是「状态」,
垃圾票(壳、封板、长期停牌复牌)虽然集中在最小几档,但档内仍然分得出来。这些都是慢变量(平滑半衰期 20 ~ 60 日,日换手 2% ~ 4%),一天持有加平滑后成本吃不掉。
主对象有三类:已知族的各种拿法(分桶键、去法、记忆,13 条);12 条独立升级版逐条放进市值十档(15 条;带筛子的四条先分档再筛、方向锁定);
以「同市值档」为中心的典型性折叠和它们的融合(12 条)。

**可以对账的预测。**
- `a_known_in_size` 样本内净超额 +5% ~ +8%(README 预期 +6% ~ +9%)。流动性类(`b_f103_in_size`、`b_f106_in_size`、已知族的各记忆版)与它秩相关 > 0.7,没有一条比它高出 2 个点。
- 躲垃圾票类保住原净超额的一半以上:`b_fold_zs_sum_size` +6% ~ +9%,`b_f113_in_size` +5% ~ +9%,`b_f111_in_size` +5% ~ +8%;`b_known_xfz_in_size` 比 `a_known_in_size` 高 2 ~ 4 个点,增益集中在 2018 ~ 2020。
- `b_fuse3_in_size` +8% ~ +12%、夏普 > 2.5(是本组最可能被规则挑中的)。形状类(`b_known_in_size_turn`、`b_cv_in_size`)±2%。
- 去法:桶内排名 ≈ 对数线性残差 > 秩相减(`b_known_rkdiff_size` 两个方向的多头腿都不到 +2%)。
- 分档:最小三档最强,最大两档接近 0。板块:10% 板强于 20% 板。时期:冻结 / 封板成分在 2018 ~ 2020,之后衰减;折叠和基尼较稳;valid 弱于 train。
- 与 `a_size`:桶内排名类 |ρ| < 0.1(构造如此);`b_known_dm_size`、`b_known_res_size` 残留 0.1 ~ 0.3;`b_known_rkdiff_size` 为负。
- 合并段(测试段 + 前推段):「入选三条里至少一条净超额为正且夏普 ≥ 1」我给六成;`a_known_in_size` 自己做到这一点我给四成。

**什么算否定。** (1) `b_fold_zs_sum_size` 样本内净超额 < +3% ⇒ 典型性折叠的收益就是市值;(2) `a_known_in_size` > +10%(保住已知族的三分之二以上)⇒「已知族大半是市值」不成立;
(3) 入选三条的合并段净超额都 ≤ 0 ⇒ 拿掉市值之后什么都不剩,这条线到此为止。

**押注(事先的,不改变机械规则)。** `b_fuse3_in_size`(分散,且每个成分都是同档比较);`b_fold_zs_sum_size`(「不死水也不乱跳」与大小无关,而且中心换成同样大小的票之后对小票更公平);
`b_f113_in_size`(校准里成交额桶内两段都为正的两条之一,机制是薄盘口 / 消息驱动,不是清淡)。

## C 成交额换成换手率(48 条,其中孪生 20)

**市场上的道理。** 成交额 = 流通市值 × 换手率。按金额写的「清淡」把「小」和「没人交易」绑在一起;换手率才是字面意义上的清淡(对手:需要流动性的短线资金)和拥挤(对手:追涨的散户)。
README 实测小市值与换手率秩相关 +0.40(我的读法,见「需要实测的」第 11 条),所以全市场口径下低换手的书偏大票 —— 预期它在 2021 ~ 2023 的小票行情里跑输等权基准。预期的图景:
全市场口径下换手率写法只保住已知族的三分之一;同市值档内两种写法是一回事;已知族 ≈ 小市值排名 + 低换手率离散度排名。
孪生是同一结构的成交额写法(多数就是前几轮的对象);孪生恰好是 `v_base`、`k_known_xfrozen` 或尺子时不重复列。

**可以对账的预测。**
- `c_dturn30`(已知族的换手率写法)样本内净超额 +3% ~ +7%,比已知族低 8 ~ 12 个点;与 `a_size` 的秩相关从 +0.6 降到 0 ± 0.2;valid 弱于 train,可能为负。
- 同市值档内:`c_turn_in_size` 与孪生秩相关 > 0.9、成对差 |t| < 1、净超额都在 +5% ~ +8%;`c_dturn_in_size` 与 `a_known_in_size` 秩相关 > 0.95。
- 恒等对照 `c_turncv20` 与孪生秩相关 > 0.98、成对差为 0。**这一对若不为 0,先查数据。**
- 分解:`c_size_plus_dturn` 与已知族秩相关 > 0.9、成对差 |t| < 1;`c_cv30`(形状)±2%。
- 记忆:最大值 ≥ 均值 ≥ 中位数,相差 0 ~ 3 个点(放量日带信息)。窗口:换手率写法 10 < 30 ≤ 60,成交额写法三个窗口几乎一样。
- 前几轮对象的改写:F103、F106 掉一半以上(它们的内容是金额水平);F113 换成同换手率档后变化在 ±3 个点内;F105 的上尾均值仍高于均值版。
- `c_seg_*_turn`(只在低换手四成里选)比孪生(低成交额四成)低得多:指引 R2 那 +1.2 夏普大半是市值。
- 换手率效应在中小市值最强,最大一档(都是低换手)消失;与 `a_size` 正交或略为负相关,孪生则是「市值 + 换手率」。

**什么算否定。** (1) `c_dturn30` 保住已知族三分之二以上的净超额且与 `a_size` 的 |ρ| < 0.2 ⇒ 已知族不是市值,README 的预期和这一轮的前提都要改;
(2) `c_turn_in_size` 对孪生的成对差 |t| ≥ 2 ⇒「同档内是一回事」不成立,十档不够细;(3) `c_size_plus_dturn` 与已知族秩相关 < 0.8 ⇒ 分解漏了一项(形状或非线性)。

**押注。** `c_f113_turnkey`(基尼最直接的混淆是换手率,按换手率分档是对症的控制,我认为它不输原式);`c_turn20_max`(「一个月内没被炒过」按流通盘比例定义,是最干净的清淡);
`c_size_plus_dturn2`(少放一份市值:赌它的夏普不低于已知族而微盘尾部更小)。

## D 新信息(39 条,其中孪生 9)

**市场上的道理。** 分钟行情里看不到的四样东西:
(1) **分红 / 增发 / 解禁**。后复权价的涨幅与市值的涨幅之差 = 现金分红率 − 股本扩张(送转两边约掉);流通比例的跳升 = 解禁。没有财务数据时,「近一年有没有现金分红」是唯一看得到盈利和现金的窗口
(亏损或未分配利润为负的公司不能分红);解禁和定增是与价格无关的卖方,减持规则把卖出摊在几个季度。
(2) **悬置盘**(流通比例低 = 将来的供给)。(3) **名义股价**(流通市值 ÷ 流通股本;后复权价的水平没有截面含义):面值退市、最小报价单位。
(4) **板块限幅**:涨停、振幅、波动按各板自己的限幅归一才可比。
稀疏的事件量不能当因子直接排(README:20 日股本变动绝大多数是 0,并列块里的顺序就是代码顺序),所以写成罚分,载体是尺子 `a_known_in_size`(市值已经拿掉;成对基准也应该是它,不是已知族)。稠密的量(净回报率、名义股价、按限幅归一的波动)直接当因子,并各给一条同市值档内的版本。

**可以对账的预测。**
- 净回报率:全市场口径 −2% ~ +3%(偏大票,与 `a_size` 负相关);同市值档内 `d_netpay241_in_size` +3% ~ +6%,最小三档最强、最大两档为 0;10% 板强于 20% 板;2018 下半年和 2021 年以后强于 2019 ~ 2020(那两年不分红的成长股是赢家)。
  2018 年 6 月前窗口内没有除权日,读数是噪声。`d_paydd_in_size` 与它秩相关 > 0.8。
- 罚分对载体的增量:不分红 +1 ~ +3 个点;解禁 / 悬置 / 增发各 +0.3 ~ +1;转股 0 ~ +0.5。解禁窗口 120 ≈ 241 > 60 > 20。悬置盘的罚分在上市三年内的票上有效、三年以上接近 0。
  注意「不分红」标记的两个已知瑕疵:新股在第一次除息之前也被标上(与次新重合);分红之后又做了更大增发的票被漏标(合成数据上 43 只分红票里漏 2 只)。
- 名义股价:全市场口径方向不稳(过不了两段同号);同市值档内买高价 +2% ~ +5%,只在最小三档。名义股价与后复权价的截面秩相关预期 < 0.6(未实测)。
- 按限幅归一:`d_maxlim20`、`d_vollim20`、`d_amplim20` 买低 +3% ~ +6%,比不归一的孪生高 1 ~ 2 个点,差别只出现在 2020-08-24 之后。
  **2019-07-22(科创板开板)之前可交易的票 `LimitWidth` 全为 0.10,凡是只除以它的假设与孪生在同一个固定半衰期下的书应逐日相同、成对差恒为 0 —— 这是一条现成的正确性检查。**
- `d_smb_in_size`(同档里走势更像小票的)+1% ~ +4%。

**什么算否定。** (1) 任何一条同市值档内的新信息因子在 train 和 valid 都有 +6% 以上、夏普 > 2 ⇒ 我低估了,存在一条大的新因子(它仍要过对 `a_size` 的检验);
(2) 所有罚分对载体的增量都 ≤ 0 ⇒ 日频字段里的事件信息对纯多头书没有用;(3) 不分红的罚分只在 2018 ~ 2020 有效 ⇒ 它与冻结筛子是同一回事,不是「盈利代理」。

**押注。** `d_netpay241_in_size`(唯一的基本面窗口,而且不依赖任何门槛);`d_nonpay_pen`(把垃圾票从「盘口状态」换成「不分红」来认,机制不随盘口变化);

## E 已知族上的筛子(48 条,其中孪生 7)

**市场上的道理。** 已知族的多头书是小而清淡的票。K001:通用冻结筛子样本内比已知族多 3.1 个点,逐年看几乎全在 2018 ~ 2020(+6.5 / +3.4 / +4.8),2021 ~ 2023 三年平均约 +0.5,按规则读过之后没有成立 —— 它是用盘口状态去猜「垃圾票」。
这一组把猜换成明文规则:不分红、低于 2 元、流通市值低于 10 亿、上市不足一年、近期涨停 / 跌停、近期解禁、流通比例低、不在 10% 板。
两种写法:分位带(根是 `cs_last_*`,方向锁定,只在被剔的一端取值连续时用)和绝对门槛(`sub(cs_rank(y), 0/1 标记)`;壳价值、退市线、限售期都是绝对量,不该用分位数)。
另有四条「只在某个板里买」和一条板块中性,给没有科创板 / 创业板权限的实盘口径用。

**可以对账的预测。**
- 剔极小市值样本内是亏的:5% / 10% / 20% 分别比已知族低 0 ~ 2 / 1 ~ 3 / 3 ~ 6 个点,最大回撤更浅。绝对门槛(10 亿)在熊市年份剔得多、牛市几乎不剔。
- 明文垃圾规则:`e_xnonpay` +1 ~ +3 个点(被剔的占书的三到四成),`e_xpx2` +0.3 ~ +1,`e_xlimdn20` +0.5 ~ +1.5,`e_xlimup10` +1 ~ +3(集中在 2018 ~ 2020),`e_xjunk4` +2 ~ +4。
  不分红和低价的增益在 2021 年以后不消失;涨停的会消失。
- 次新:`ListAge` 版 0 ~ +1 个点,弱于 `cross_age` 孪生(K001 样本内 +2.3);两者的成对差集中在 2018 ~ 2019(复牌补跌的老股票)。
- 解禁 / 悬置:+0.3 ~ +1 个点,被剔的不到 5%;解禁前后的年龄窗口(`e_xpre1y` 等)被剔的不到 1%,增量在 ±0.5 个点内。
- 板块:`e_main_only` 与已知族的成对差 ±1 个点;`e_wide_only` 明显更低;`e_gem_only` 在 2020-08-24 之后下降。
- 增益集中在最小两档、10% 板。被剔的票占书的比例必须同时报:比例为 0 的筛子是空操作(K001 的 s_volprof 就是)。

**什么算否定。** (1) 明文规则的增益也全部集中在 2018 ~ 2020 ⇒ 它们和冻结筛子是同一回事,「规则不随盘口失效」不成立;(2) `e_xmicro05` / `e_xmicro10` 的样本内净超额不降反升 ⇒ 已知族的超额不在最小的票里;
(3) `e_xyoung*` 与 `cross_age` 孪生的成对差为 0 ⇒ 以前的次新筛子没有混进复牌的票,我对 2018 年的解释是错的。

**押注。** `e_xnonpay`(同 D 组的理由,而且剔的量足够大、不是空操作);`e_xlimdn20`(跌停封死的票在回测里还能按开盘价卖,实盘卖不掉 —— 这条对实盘的价值大于读数);
`e_xpx2`(面值退市是写在规则里的门槛,不依赖统计)。

按 README 的预期,这一组没有一条到得了对已知族 t ≥ 2:每年 1 ~ 3 个点、跟踪误差 2% ~ 3%、三年样本,t 最多 1 ~ 1.5。我同意这个预期。

## 想要而没有的数据

- **ST / *ST / 退市整理期标记**(带日期):修 `LimitWidth` 的 5%;直接检验「垃圾票 = ST」对我用分红、低价、跌停拼出来的代理;把退市整理期的票从书和基准里拿掉。
- **限售解禁日历**(解禁日、数量、股东类型,事前可知):现在只能事后看到流通比例跳升,或用上市天数猜首发限售的解禁日;有了它才能做真正的「解禁前」信号,并区分首发 / 定增 / 激励。
- **分红送转配股表**(公告日、除权除息日、每股金额):干净的股息率,公告到除息之间的漂移;现在只能从市值与后复权价的背离里反推除息日的效应。
- **行业代码**(申万一、二级):所有对象的行业中性版;已知族的行业倾斜(银行、公用事业对科技)占多大一块,目前完全不知道。

- **总股本、自由流通股本**(剔除持股 5% 以上的战略股东):真正的自由流通换手率;现在的流通股本是交易所口径。
- **未复权收盘价与复权因子**:现在的名义股价是 `FloatCap ÷ FloatShares` 反推的。
- **最简的基本面**:净利润的符号、营收(退市规则直接用到)、财报披露日。
- **减持 / 增持公告、股权质押比例**(2018 年的质押危机在样本内)、**两融标的标记**、**北向持股**。

## 需要实测的(我没有假设其中任何一条;结论依赖它们的假设在 why 里注明了)

1. `day_last(Close)` 的后复权是否包含现金分红(除息日后复权价连续)。净回报率、不分红标记、增发标记(`d_netpay*`、`d_paydd*`、`d_nonpay_pen`、`d_issue_pen`、`d_fexp120_pen`、`d_adjf`、`e_xnonpay`、`e_xissuer`、`e_pay_soft`、`e_xjunk4`)全靠它。检验:取几只已知除息日的票,看 `log(day_last(Close)) − (LogFloatCap − LogFloatShares)` 在除息日的跳变是否等于股息率。
2. 送转 / 配股除权日,市值文件里的股本是否与价格同日调整、流通股本与总股本是否同日更新(看 `LogTotalCap − log(day_last(Close))` 在除权日前后有没有单日尖峰)。3 日中位数挡得住错开一天,挡不住两天以上。
3. 无除权日时,`day_last(Close)` 与市值隐含的收盘价(`FloatCap ÷ FloatShares`)是否逐日成比例;比值的日间抖动有多大(合成数据上是 2e-6;若真实数据是 1e-3,0.001 的分红门槛要调)。
4. 流通比例恰为 1 的票占多大比例(逐年);A+H / A+B 公司的 `TotalCap` 含不含非 A 股部分(决定「低流通比例」是待解禁还是有 H 股)。
5. 2018-01-02(库的第一天)有多少只股票在停牌,它们 2018 年的表现(`cross_age` 把它们当新股)。
6. `Volume` 的单位、是否复权(`c_dvolsh30`)。
7. 有标签的格子里 `LogFloatCap` 有值的比例(决定带市值的假设过不过 0.95 的覆盖门槛);日频库与分钟库在上市首日、复牌日的对齐。
8. 20% 涨跌幅的票占比的时间序列(2025-03-31 是 38.3%)。
9. 样本内每天「不分红」「低于 2 元」「流通市值低于 10 / 20 亿」「上市不足一年」「近 120 日解禁超过 5%」「近 20 日跌停」各标记占全市场、占已知族多头书的比例 —— 决定这些筛子是不是空操作。
10. 名义股价与后复权收盘价的截面秩相关;ST 股票(日收益长期不超过 5%)的数量,即涨跌停筛子失明的范围。
11. README 里「换手率 +0.40」是哪两个量之间的秩相关(我按「小市值与换手率」读的)。

## 读数时请注意(对计划的意见,详见交回的报告)

- **孪生不该参加各组「样本内前 3」的排名。** 它们是不用日频字段的旧对象(F103 / F106 / F113 的升级版、已知族的各窗口版),样本内夏普高,参加排名会把 C 组的名额占满。它们只在父假设被读时一起读、做成对差。
