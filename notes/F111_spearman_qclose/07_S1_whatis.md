# 阶段 S1_whatis —— 它到底是什么?载体是价格路径、活跃度,还是实现细节?

> 事实数字见结果卡 `results/R1.md`(数字 2~7)。这一页是**主研在第 2 轮写的解读**。
> 口径:多头腿净超额 `Lnet` / 纯多头夏普 `Lshp` 都是「半衰期按纯多头书在 train 上选」(`rank_by: long`);
> 噪声尺度按 playbook §6.6:`Lnet ±3pp`、`Lshp ±0.3`、`LS ±0.3`。

## 问题

`ts_spearman` 根节点那个「对全市场每一只其他股票求 10 日 Spearman 相关再取平均」的 O(N²) 结构,
等价于什么更简单的东西?预测力的载体是**价格路径的共动**、**活跃度的共动**,还是**并列值这类实现瑕疵**?

## 结果(一句话一个变体)

| 变体 | 表达式 | Lnet tr/va | Lshp tr/va | 与 v_base 的 rank 相关 | 裁决 |
|---|---|---|---|---|---|
| `v_base` | `ts_spearman(day_quantile(Close),10)` | +10.4% / +17.0% | 1.79 / 3.07 | 1.000 | 基准 |
| `l_last` | `ts_spearman(day_last(Close),10)` | **+11.1% / +18.4%** | **1.91 / 3.26** | 0.961 | **H7 成立:日内折叠多余** |

| `l_mean` | `ts_spearman(day_mean(Close),10)` | +10.7% / +16.5% | 1.84 / 2.93 | 0.994 | **H3 被否定:并列值不承重** |

## 解读

### 1. 真正承重的不是「秩」,是「每只股票在市场路径里等权」

这一组里最有信息量的一对比较是 `m_mktcorr` 和 `s_pearson`:

- `m_mktcorr`(和**价格水平的截面均值** `cs_mean(A)` 做相关)**塌了**:valid 的 Lnet 从 +17.0% 掉到 **+4.9%**、
  纯多头夏普从 3.07 掉到 **0.74**,与原式的 rank 相关只有 **0.742**。
- `s_pearson`(保留「两两配对再平均」,只是把窗口内的秩换成原始值)**完全没塌**:
  +10.7% / +16.9%,rank 相关 **0.978**。

这两个结果合起来把承重件指认得很干净。写成代数(`04_grammar.md` 的恒等式):

```
v_base    :  mean_j spearman(x_i, x_j)  =  < x̂_i^rank ,  mean_j x̂_j^rank >      ← 先逐股归一,再平均
s_pearson :  mean_j pearson (x_i, x_j)  =  < x̂_i      ,  mean_j x̂_j      >      ← 先逐股归一,再平均
m_mktcorr :      pearson (x_i, mean_j x_j)  =  < x̂_i ,  normalize(mean_j x_j) > ← 先平均,再归一
```

`v_base` 与 `s_pearson` 共同的那一步是**先把每只股票的窗口路径各自归一化(秩 / 标准化),再对股票取平均** ——
于是市场共识路径里每只股票**等权**。`m_mktcorr` 少的正是这一步:`cs_mean` 平均的是**价格水平**,
高价股和波动大的股票主导了那条「市场路径」,它就不再是共识路径了。
⇒ **承重件是「等权的共识路径」,不是「秩」。** 秩和逐股标准化只是把 `‖路径‖` 拉平的两种手段,二者等效(0.978)。

这一条是**第 1 轮预先写下的预言被命中**:H1 的预测 (c) 原话写的就是
「`m_mktcorr` 与原式 rank 相关高,但我的先验是 0.6~0.9、不是 1.0,因为 `M` 是**秩**的截面均值〈每只股票等权〉,
而 `cs_mean(A)` 是**价格水平**的截面均值〈高价股主导〉」。实测 0.742,落在预言的区间里,
而且塌的方向和机制都对上了。

**对提纯的后果(重要)**:表达式语言里**没有**一个便宜的写法能表达这条因子。
`ts_corr(A, cs_mean(A), d)` 这条路是堵死的(它换掉了承重件);能用的只有 `ts_spearman` / `ts_pearson`
这两个本身就是 O(N²) 结构的算子。其中 `ts_pearson` 已被重写成 chunked matmul,
`ts_spearman` 还留着 `for i in range(N)` 的 Python 循环 ⇒ **`ts_pearson` 是同一本书的便宜实现**。

### 2. 叶子上的两步都可以删(H7 成立,H3 被否定)

- `l_last`(直接用当天收盘价,删掉日内中位价这一折叠)在**同一个半衰期**下和原式比
  (固定半衰期表,train:hl5 +8.3% vs +7.44%、hl10 +10.3% vs +10.23%、hl20 +11.1% vs +10.45%;
  hl0/hl2 反过来略差 0.5~0.7pp),差异 0.07~0.86pp,**全部落在 ±3pp 的噪声里**。
  valid 高 1.4pp,也在噪声里。⇒ 正确的说法是「**日内折叠是多余的**」,
  **不是**「`l_last` 更好」。它是一个更简单、不需要分钟数据的等价写法(提纯)。
- `l_mean`(分钟均价,几乎不可能产生跨日并列)与原式 rank 相关 **0.994**、各项数字几乎逐位相当。
  ⇒ 并列值造的「人工上升斜坡」不承重,H3 作为泄漏故事被否定(细节见 `07x_1_identity.md` 第 4 节)。

### 3. 载体是价格路径的共动,不是活跃度的共动(H10 被否定)

`l_amt` 把叶子换成成交额,同样的结构、同样的窗口:Lnet 掉到 +2.1% / +7.9%,Lshp 0.43 / 1.90,
与原式 rank 相关只有 0.612。⇒ 共动的载体是**价格路径**。

这条还顺手给 H4(「它就是成交额家族的另一种写法」)**提供了一个反证**:
`l_amt` 与三条 `known_*` 家族的 rank 相关(−0.238 ~ −0.252)**反而比 `v_base` 的(−0.365 ~ −0.423)更低**。
如果原式和已知家族的重叠来自「这个结构本质上在量活跃度」,那把叶子直接换成 `Amt` 应该重叠更高、表现更好 ——
两件都没发生。⇒ **原式与成交额家族的重叠不是结构性的,而是一个副产物**(低活跃度的股票路径更干净、更跟得上市场)。

### 4. 无条件动量一文不值 —— 条件化才是钱

`t_tsrank`(窗口内最后一个值的百分位 = 纯 10 日位置动量,没有「乘市场趋势方向」)
**在全部 7 个固定半衰期上多头腿净超额都是负的**(−46.3% @ hl0 … −4.1% @ hl20),
而且它的分位剖面在 train 和 valid 都在 **Q4~Q7 出峰、Q10 不是最高的一组**(非单调)。
它对 `ctl_mom20` 的 rank 相关 **−0.637**、单变量中性化 R² **0.420** —— 它确实就是个 20 日动量的变体,
而 `v_base` 对 `ctl_mom20` 的相关只有 −0.078、R² 0.056。

⇒ **原式和「动量」几乎正交,而且纯动量在这个标签口径下是亏的。**
这把 H2 的措辞钉住了:原式**不是**动量因子;它和动量的关系是**被市场方向条件化**的那一层
(实证见 `07x_1_identity.md` 第 2 节:按 `c(t)` 符号分组后相关变号 +0.47 / −0.60)。
**反例备忘**:不要用「和 `ctl_mom20` 无条件相关只有 −0.08」去论证「它和动量无关」——
条件化的因子在无条件相关上本来就会被抵消掉。

### 5. 这一阶段**没有**改变选拔结论

全部 6 个变体在 valid 上的多头腿净超额都 ≤ +18.4%,
而两条已知家族基准是 **+22.3%(`cross_mean(day_std(Amt),30)`)/ +22.2%(`cross_max(day_std(Amt),9)`)**。
⇒ **这条因子的任何等价写法,单独拿出来都输给已知家族**(valid 上差 4~5pp)。
所以 S1 回答的是「它是什么」,**没有**回答「它对纯多头用户有没有价值」——
后者由 `07x_1_identity.md` 第 3 节(增量)和 R2 接着做。
