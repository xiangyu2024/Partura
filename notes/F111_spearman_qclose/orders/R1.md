## 想回答的问题

**主问题:`ts_spearman` 那个 O(N²) 的「对全市场其他每只股票求 Spearman 相关再平均」,
到底等价于什么更简单的东西?**

我从源码推出:窗口完整时,原式的**截面排序**精确等于
`Σ_k rc_i[t,k] · M[t,k]` 的排序 —— 自己的 10 天「窗口内去均值秩路径」和**全市场平均秩路径**
的内积(推导见 `04_grammar.md`,关键一步是窗口完整时每只股票的 `rank_std` 都等于同一个常数
`sqrt((d²−1)/12)`,所以那个除法不区分股票)。再把市场路径近似成直线,就得到
**原式 ≈ (市场 10 日趋势方向) × (自己的 10 日秩动量)**,一个**条件动量**。

- **H1** 成立(恒等式在真实数据上站得住)⇒ 配对结构没有信息价值,提纯方向立刻确定。
- **H1** 被否定(rank 相关 < 0.9)⇒ 我的推导漏了东西,后面要重想,**请在结果卡里显著标出**。
- **H4**(对只能做多的用户,它是不是已知家族的另一种写法、有没有增量)是决定这条因子有没有
  价值的那一条:原式多头腿 Lnet +10.4%/+17.0%、Lshp 1.79/3.07,**已经低于**
  `known_stdamt_mean30`(+12.6%/+22.3%、1.78/3.46)和 `known_stdamt_max9`(+13.7%/+22.2%、1.99/3.59)。
  所以它唯一可能的价值在**增量**(残差 / 组合),这必须量出来。

### 第 3 项(服务器运行 2/2):自写分析脚本 `studies/F111_spearman_qclose/x1_identity.py`

四个相互独立的 block。**每个 block 用 try/except 包起来、各自 `print`**:
一个塌了另外三个还要出数。开头先做自检(见下),自检不过就打印警告但继续。

共用的量:

```
a    = st.panels({"a": "day_quantile(Close)"})["a"]                       # (D,N) 叶子面板
f    = st.panels({"f": "ts_spearman(day_quantile(Close), 10)"})["f"]      # 原式面板(有缓存,不花钱)
sig  = st.signal(f)                                                       # 实际交易的信号(方向×面板,按 hlL=20 平滑)
d    = 10
```

**窗口内秩路径(严格按 `ts_spearman` 源码复刻,这是整段的基础)**:
对每个窗口 `t`(覆盖第 `t … t+d−1` 行,结果对齐到第 `t+d−1` 行):
1. `windows[t,k,n] = a[t+k, n]`;`mask = ~isnan(windows)`
2. `x_filled = where(mask, windows, +inf)`
3. `ranks = argsort(argsort(x_filled, axis=k轴, kind="stable"), axis=k轴, kind="stable")`
   —— **两次都必须是稳定排序**,NaN 先填 `+inf` 再算、算完盖回 NaN(源码就是这个顺序)
4. `ranks = where(mask, ranks, nan)`;`rc = ranks − nanmean(ranks, axis=k轴, keepdims)`

**内存**:`rc` 是 `(T, 10, N)` float32。D≈2000、N≈5000 时约 400 MB。
请**按时间分块**(比如每次 200 个窗口)累计结果,不要一次性建整个 `rc`。

**自检(先做,用随机数组,不碰真实数据)**:
- `(30 天, 20 只)` 的随机正数数组,`d=10`:
  (i) 窗口完整时每只股票的 `nanmean(rc²)` 应该都 `== (d²−1)/12 = 8.25`(容差 1e-5);
  (ii) 用**暴力双循环**算 `mean_{j≠i} spearman(a[t:t+d,i], a[t:t+d,j])`,和下面定义的 `proj`
       做**逐日 Spearman**,应该 ≈ 1.0(容差 1e-3)。**这一条直接验证我的恒等式推导**;
       不过就说明推导错了 —— 请把两边的数都打出来。
- 再把 10% 的格子设成 NaN 重跑一次 (ii),把 rank 相关打出来(预期会掉下来,这正是 H1 的边界)。

#### block (a) — H1:恒等式在真实数据上成立吗
- `proj[t+d−1, i] = Σ_k rc[t,k,i] · M[t,k]`,其中 `M[t,k] = nanmean_n(rc[t,k,n])`(NaN 当 0 求和)。
  前 `d−1` 行填 NaN。
- 报:`proj` 与 `f`(**原始面板,都不平滑**)的**逐日 Spearman** 的 `mean / median / p05 / p95`。
- 报:把"窗口内有 NaN"的格子设成 NaN 之后,同一个逐日 Spearman 的 mean/median;
  以及**窗口完整的格子占全部有标签格子的比例**。
- 报:`st.rank_corr(sig, st.signal(proj))` 一个数(和上面的逐日分布对照,口径不同不要混)。
- 报:`proj` 当因子的书 —— `st.books(proj, fit="train", evals=("train","valid"))`:
  `Lgross / Lnet / Lshp / LTO`(train 和 valid),以及它选到的 `sign` 和半衰期。

#### block (b) — H2:它是不是「市场趋势方向 × 自己的 10 日秩动量」
- `ramp[k] = k − (d−1)/2`
- `rho_time[t+d−1, i] = Σ_k rc[t,k,i]·ramp[k] / sqrt( Σ_k rc[t,k,i]² · Σ_k ramp[k]² )`(分母加 1e-8 保护)
  —— 自己的 10 日秩趋势(纯动量,和市场无关)
- `c[t] = Σ_k M[t,k]·ramp[k] / sqrt( Σ_k M[t,k]² · Σ_k ramp[k]² )` —— 市场 10 日路径的趋势方向(每天一个标量)
- 报:`c` 的分布 —— 均值、`c>0` 的天数占比、`|c|` 的中位数。
- 报:`f` 与 `rho_time` 的逐日 Spearman 的**均值**,分三组:**全部天 / c>0 的天 / c<0 的天**。
- 报:`f` 与 `c[t]·rho_time`(逐日乘上当天的标量)的逐日 Spearman 均值。
- 报:`rho_time` 和 `c·rho_time` 各自当因子的书(同 block (a) 的指标口径)。

#### block (c) — H4:**对已知家族有没有增量**(这一段最重要)

三条已知家族,逐条做。`st.control("<名字>")` 取不到(它们写在配置的 `gates:` 里而不是 `controls:`)
就直接用表达式 `st.panels({...})`:

| 名字 | 表达式 |
|---|---|
| `known_stdamt_mean30` | `cross_mean(day_std(Amt), 30)` |
| `known_stdamt_max9` | `cross_max(day_std(Amt), 9)` |
| `known_amt_max9` | `cross_max(day_sum(Amt), 9)` |

每条做三件事:
1. **残差(主口径,可交易)**:每天在**截面**上把 `f`(原始面板)对该家族做**秩空间**一元线性回归
   (两边各自先转成当天的截面秩/百分位,再回归),取残差面板,然后
   `st.books(残差, fit="train", evals=("train","valid"))` —— **让 st.books 自己定方向和半衰期**。
   报 `Lgross / Lnet / Lshp / LTO` + 选到的 sign 和 hl,以及残差的 `st.ic(残差, "train"/"valid")`。
2. **残差(对照口径)**:同样的回归,但对象换成 `sig`(已平滑的交易信号),残差**不再平滑**。
   这一口径和 S0 §7 的中性化表可比(那张表 `all_controls` 残差毛超额只剩 +0.1%)。报同样的指标。
3. **组合**:把 `f` 和该家族各自按自己 train 段 rank IC 的符号对齐方向,各自转成当天截面百分位秩
   (0~1),再按权重相加 `w·rank(f) + (1−w)·rank(known)`,`w ∈ {0, 0.25, 0.5, 0.75, 1}`。
   每个 `w` 跑 `st.books(..., fit="train", evals=("train","valid"))`,报 `Lgross/Lnet/Lshp/LTO`。
   `w=0` 就是已知家族单独、`w=1` 是原式单独 —— **这两根是基准,必须和表里其他变体对得上**。

   (三条家族 × 5 个权重 = 15 本书,加残差 6 本。都是在已缓存的面板上做书,不是新的表达式求值,
   应该很快。若时间不够,**优先把 `known_stdamt_mean30` 这一条做完整**,另两条只做 `w=0/0.5/1`。)

#### block (d) — H3:并列值到底有多普遍、是不是集中在因子高端
- `tie[t+d−1, i]` = 窗口 `a[t:t+d, i]` 的**有效值**里是否存在**完全相等**的一对(布尔)。
- 报:`tie` 为真的格子占全部有标签格子的比例(整段,以及 train / valid 各自)。
- 报:按 `f` 当天的截面十分位分组,每组里 `tie=True` 的占比(Q1…Q10,Q10=多头端)。
  —— H3 预测**高端(Q10)的并列占比明显更高**(假上升斜坡被排到最前)。
- 报:`tie=True` 与 `tie=False` 两组格子的 `f` 截面百分位的均值。
- 报:只在 `tie=False` 的格子上保留 `f`(其余设 NaN)的书
  `st.books(..., fit="train", evals=("train","valid"))`,以及它的 `cov`(有标签格子的覆盖率)。
  —— 如果去掉并列格子之后多头腿基本不变,H3 就被否定了。
