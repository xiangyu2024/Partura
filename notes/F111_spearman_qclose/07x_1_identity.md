## 1. block (a):恒等式是**精确**的 ⇒ H1 确立

- 窗口完整的格子占全部有标签格子的 **98.70%**(train 98.32% / valid 99.46%)。
- `proj = Σ_k rc_i[t,k]·M[t,k]` 与原式面板的**逐日 Spearman**(utrain,1350 天):
  - 仅窗口完整的格子:mean **1.0000**,median 1.0000,p05 **0.9999**,p95 1.0000
  - 全部格子:mean 0.9974,p05 0.9925
- `proj` 自己当因子:hlL=20,Lnet **+10.95% / +17.09%**,Lshp **1.88 / 3.09**(原式 +10.4%/+17.0%,1.79/3.07)。

**裁决:H1 已确立,而且不是「近似」而是恒等** —— 在 98.7% 的格子上逐日截面序**完全一致**(p05 都到 0.9999)。
根节点那个 O(N²) 的「对全市场每只其他股票求 Spearman 再平均」里**没有任何配对信息**:
它精确等于「自己的 10 天窗口内秩路径」与「全市场等权平均秩路径」的内积。
`j ≠ i` 的自排除精确等于一个当天的常数,不影响截面序;`‖rc_i‖` 对每只股票是同一个常数,
所以内积序 = 相关序 = 回归 beta 序。

剩下 1.3% 的格子就是窗口里有 NaN(停牌/新股)的那些,它们上面恒等式打折(全部格子的 p05 掉到 0.9925),
原因是源码的分母口径不一致(`cov` 除两只股票**重叠**的有效天数,`rank_std` 各自除**自己**的有效天数,
见 `state.md` §2.7-7)。这也解释了为什么 `proj` 当因子比原式**略好**(+0.5pp):它少了这个瑕疵。
**这 1.3% 不值得再追**:它既不改变身份,也不改变选拔结论。

**但 H1 的「提纯」后果和第 1 轮的预期相反**(详见 `07_S1_whatis.md` 第 1 节):
恒等式成立**不等于**能在表达式语言里写出一个便宜的等价物。
`m_mktcorr = ts_corr(A, cs_mean(A), 10)` 把「先逐股归一再平均」换成了「先平均再归一」,
它 rank 相关只有 0.742、valid 多头腿塌到 +4.9%。
⇒ **恒等式里承重的是「等权共识路径」`M`,而 `cs_mean` 给不出 `M`。**
能用的便宜写法只有 `ts_pearson`(同样是「先逐股归一再平均」,chunked matmul,0.978)。

两个口径别混(结果卡"值得注意"第 3 条):「逐日截面相关取均值」(不平滑,1.0000)和
`st.rank_corr(sig, st.signal(proj))`(两边各自平滑后算一个总相关,0.9930)不是同一个数。

## 2. block (b):条件化是钱,动量本身不是 —— H2 与 H11 的裁决

读数:

| 量 | 数字 |
|---|---|
| `c(t) > 0` 的天数占比 | 47.70%(644 / 1350),mean c = −0.0426,median \|c\| = 0.5623 |
| `f` vs `ρ^time` 逐日 Spearman,**全部天** | mean **−0.0885**(p05 −0.9035,p95 +0.8669) |
| 同上,**`c>0` 的天** | **+0.4712** |
| 同上,**`c<0` 的天** | **−0.5991** |
| `f` vs `c·ρ^time`,全部天 | **+0.5381** |
| `ρ^time` 自己当因子(hlL=20) | Lnet **−5.60% / −0.71%**,Lshp −0.78/−0.08(sign 自动选到 −1) |
| `c·ρ^time` 自己当因子(hlL=20) | Lnet **+9.23% / +18.62%**,Lshp 1.57/2.99,Lgross **+14.47% / +23.75%**,LTO 6.86% |

**(i) 变号被实测到了,而且幅度中等。** 无条件相关 ≈ 0(−0.0885),按市场方向分组后 +0.47 / −0.60。
这同时解释了基线里最别扭的那个读数:`v_base` 对 `ctl_mom20` 的 rank 相关只有 −0.078 ——
**不是因为它和动量无关,而是因为条件化把无条件相关抵消掉了。**

**(ii) 事前判据没有被干净触发,这里给出裁决。** `state.md` §6 预先写的是「两边绝对值都 >0.8 ⇒ 线性斜坡很紧」
或「两边都 <0.5 ⇒ 很松」;实测 0.4712 / 0.5991,一侧压线、一侧卡在中间,两条都没触发。
**裁决:线性斜坡是一个「只描述了一半、但钱全在这一半」的近似。**
两个数字支撑这个说法:
- 「只描述了一半」:`f` 与 `c·ρ^time` 的逐日相关是 **0.5381** —— 按 playbook §6.3 的尺度(<0.8 就是另一条因子),
  `c·ρ^time` **不是** `f` 的提纯版,`M[t,·]` 的形状里有大量非线性成分。
- 「钱全在这一半」:`c·ρ^time` 单独的多头腿 **+9.23% / +18.62%**(毛 +14.47%/+23.75%)
  对比原式 +10.45%/+17.0%(毛 +13.56%/+20.01%)—— **毛超额两段都更高**,净超额 valid 更高、train 略低
  (差 1.2pp,换手 6.86% vs 4.08% 的成本差),全部在噪声内。
  ⇒ `M` 里那一半非线性形状,对多头腿**没有可测量的贡献**。

**(iii) 条件化是唯一的来源,这一条是本阶段最干净的因果证据。**
`ρ^time` 单独是**亏的**(−5.60%/−0.71%,sign 还被自动选成 −1);
乘上市场方向 `c(t)` 之后变成 +9.23%/+18.62%。同一个 `ρ^time` 面板,只多乘一个**当天的全市场标量**,
多头腿从 −5.6% 变成 +9.2%。再加上 S1 里 `t_tsrank`(另一种纯动量写法)在**全部 7 个半衰期上都是负的**,
以及它对 `ctl_mom20` 的 R² 高达 0.420(`v_base` 只有 0.056)——
**三条独立证据指向同一句话:这条因子的 alpha 在「与市场方向的交互」里,不在「自己的动量」里。**

**(iv) H11 的不变量成立,但 H11 的机制标签被否定。**
代数上 `f = c₁(t)·corr(rc_i, M) + 常数`、`c₁(t) > 0` 恒成立,所以**因子值本身不随大盘方向翻面**
(涨市跟涨的、跌市跟跌的都拿正值);会翻面的是「`f` 与自己动量的关系」。这一条没有被任何数据反对,
而且 H5 的毛超额平线(hl 0→20 只掉 0.5pp)和 `c·ρ^time` 在 hl=20 上毛超额 +14.47% 都和它一致 ——
**一个每隔几天就和动量翻一次关系的东西,被 20 天 EMA 平滑之后毛超额几乎不掉,
正是因为被平滑的那个对象(`f` 自己)从来没有翻面。**

但 H11 原话把这个暴露叫做「**反向特质波动**」,这一步**被 rank 相关表直接否定**:
`v_base` 对 `ctl_ivol`(日内已实现波动)只有 **−0.153**、对 `ctl_cap` −0.177、对 `ctl_mom20` −0.078,
而对 `ctl_amt` −0.352、`ctl_dvol20` −0.306、`known_stdamt_mean30` **−0.423**。
⇒ 真实的暴露是「**低成交额 / 低成交额离散度**(安静、小、便宜的股票)」,**不是低波动**。
H11 必须按这个改写(已改写进 `05_hypotheses.md`)。

**(v) (c4):平滑让这个暴露更集中,但不是平滑造出来的。**
`|rank_corr(f, known)|`(两边都按同一 hl 平滑)随 hl **单调上升**:
mean30 0.2323 → **0.3704**;stdamt_max9 0.3088 → 0.3869(hl10 之后走平);amt_max9 0.2953 → 0.3802。
⇒ H11 的「平滑把它转化成已知暴露」这一步**方向被支持**(单调),但 hl=0 上就已经有 0.23~0.31,
**暴露从一开始就在**。正确的说法:平滑把这个暴露**提浓**了约 0.07~0.14,不是无中生有。
(这个口径两边都平滑,和 S1 诊断表里 `rank_corr_train` 的 −0.423 口径〈只平滑 `f`〉差约 0.05,别互换引用。)

## 3. block (c):增量 —— 这是决定这条因子有没有价值的一节

### 3.1 残差:两种口径差 8~10pp,主研的裁决

| 家族 | 口径 | R² | 残差 Lgross tr/va | 残差 Lnet tr/va | 残差 LTO |
|---|---|---|---|---|---|
| mean30 | **①主口径**(残差重选 sign/半衰期,hl=20) | 0.068 | +9.04% / +11.65% | **+5.16% / +7.79%** | 5.1% |
| mean30 | ②S0 可比(对已平滑信号做残差、不再平滑) | 0.187/0.227 | +2.80% / +5.08% | −0.95% / +1.22% | 4.9% |
| stdamt_max9 | ① | 0.109 | +7.48% / +10.21% | +3.66% / +6.40% | 5.0% |
| stdamt_max9 | ② | 0.144/0.177 | −0.97% / +3.90% | −7.42% / −2.77% | 8.5% |
| amt_max9 | ① | 0.101 | +8.55% / +10.19% | +4.77% / +6.33% | 5.0% |
| amt_max9 | ② | 0.156/0.193 | +2.71% / +4.52% | −2.99% / −1.45% | 7.5% |

**裁决:两个口径都对,它们量的不是同一件事,而且差值本身就是一个结论。**
- 口径①中性化的是**原始面板**,然后重新平滑去交易;口径②中性化的是**已经平滑过的交易信号**。
- 两者 R² 相差一倍(0.068~0.109 对 0.144~0.227),原因**正是 (c4)**:
  `f` 平滑之后与已知家族的重叠**更高**(|corr| 0.23→0.37)。
  ⇒ **用户真正在交易的那个对象(EMA20 之后的 `f`),比原始面板更「像」已知家族。**
  这是一句独立成立、而且对 H4 有利的话。
- 口径②残差的换手还翻了一倍(5% → 7.5%~8.5%),净值里有一部分塌缩只是成本(playbook §1)。
- **记录在案的口径**:诊断用①(三条家族可比、换手现实),因为它回答的是「alpha 在不在某一条家族的张成里」。
  **但 H4 的裁决不靠任何残差** —— 用户的问题是「我已经在跑这条家族了,再加上它能不能多拿到净超额」,
  直接回答这个问题的是**组合书**和 R2 的**双重排序**,不是残差。

**残差的诊断结论(已确立)**:对**任何单独一条**已知家族中性化之后,都还剩 +3.7%~+5.2%(train)/
+6.3%~+7.8%(valid)的净多头腿,R² 只有 0.07~0.11。⇒ **它不是哪一条已知家族的改写。**
对照 S0 §7:对 **9 个 `ctl_*` 一起**中性化(`all_controls`,R² 0.276),残差多头腿**毛**超额从 +13.6% 掉到 **+0.1%**。
⇒ **它也不是任何单一已知暴露,但它整条躺在标准控制变量组的联合张成里。** 这两句话必须一起说,少一句就是误导。

### 3.2 组合书:增量只出现在 train,而且家族越弱增量越大

`w·pct_rank(sign_f·f) + (1−w)·pct_rank(sign_k·known)`,w=0 即家族单独、w=1 即原式单独:

| 家族 | w=0 (tr / va) | 最好的 w>0 | 相对 w=0 的变化 |
|---|---|---|---|
| `known_stdamt_mean30` | 13.26% / **22.18%**(1.86/3.44) | w=0.25:13.21% / 21.35% | **−0.05pp / −0.83pp** ⇒ 没有增量 |
| `known_stdamt_max9` | 13.37% / 21.82%(1.95/3.51) | w=0.25:**14.81%** / 21.66% | **+1.44pp / −0.16pp** ⇒ 只在 train |
| `known_amt_max9` | 10.56% / 21.72%(1.45/3.37) | w=0.25:**12.64% / 22.12%** | **+2.08pp / +0.40pp** ⇒ train 明显、valid 噪声内 |

**裁决(H4 的主要证据,已确立的部分)**:
1. **valid 上没有增量。** 三条家族单独在 valid 上几乎一样好(22.18 / 21.82 / 21.72),
   掺进 25% 的 `f` 之后变成 21.35 / 21.66 / 22.12 —— 散布 ±0.4pp,**远在 ±3pp 的噪声里**,
   而且**最强的那条家族(mean30)是变差的**。
2. **train 上的增量有一个很说明问题的形状:家族自己越弱,「增量」越大。**
   amt_max9 train 单独最弱(10.56%)、增量最大(+2.08pp);mean30 train 最强(13.26%)、增量为零。
   这正是**拟合段吸收噪声**的特征,不是真增量的特征(真增量应该对家族的强弱无所谓)。
3. 纯多头夏普的方向一致:w=0.25 在 train 上 +0.10~+0.36,在 valid 上 −0.03~+0.09(全部 ≤0.3 的噪声)。

⇒ **H4 目前是「被强烈支持、但还没钉死」**:缺口有两个,R2 补上(见 `orders/R2.md`)——
(i) 组合用的是 `v_base`,而 S1 已经证明它是这一族等价写法里最弱的一个(`l_last` valid 高 1.4pp);
(ii) 组合书只回答「把两个因子的秩加权相加」这一种用法,
**没有**回答用户真正的用法:「我已经持有家族的多头端了,`f` 能不能在这个池子里再挑一遍」。
后者要用**双重排序**量(R2 block B),而且那本书的多头腿超额**天然就是相对「持有整个家族多头端」的增量**。

## 4. block (d):并列值不承重 —— H3 被否定,并把一个表面矛盾解掉

读数:并列占比 utrain **44.01%**(train 45.19% / valid 41.69%);按 `f` 当天十分位**单调上升**
Q1 35.90% → Q10 **51.11%**;并列组的截面百分位均值 0.5241 vs 非并列组 0.4810;
剔除并列格子后:coverage 0.539/0.582,hlL=5,**Lgross +14.31% / +19.07%**(原式 +13.56%/+20.01%),
**LTO 23.44% / 21.89%**(原式 4.08%),Lnet 塌到 −3.58% / +2.52%。

**裁决:H3 被否定。** 决定性的一条是 `l_mean`(分钟均价,跨日完全并列几乎不可能):
与原式 rank 相关 **0.994**、Lnet +10.7%/+16.5%、**LTO 也是 4.1%**。
⇒ 既然一个**完全没有并列**的叶子给出同一本书、同一个换手,并列就既不承重 alpha、也不承重低换手。

**把结果卡"值得注意"第 8 条的表面矛盾解掉**(「换叶子不伤性能,但挖掉并列格子几乎摧毁换手」):
1. 剔除并列格子后 **Lgross 基本没变**(+14.31%/+19.07%,和原式同一量级)—— **毛 alpha 不在并列格子里**,
   这本身就已经否定了 H3。塌掉的只有净值,而塌的原因是换手从 4% 涨到 23%。
2. 换手暴涨是**子集选择的产物,不是因子的性质**:被保留的格子集合**每天都在变**
   (今天没并列、明天并列就被挖掉),所以持仓被迫每天换一遍。这是「在一个每天 44% 成员进出的池子里
   交易」的换手,不是 `f` 的换手。`l_mean` 的 LTO = 4.1% 就是反证。
3. 「44%」这个数本身也要看清:它量的是「窗口里**至少有一组**并列」,而 H3 设想的泄漏场景是
   「**整个 10 天窗口全部并列** ⇒ 完美上升斜坡」。前者是后者的一个很松的上界。
   `l_mean` 的 0.994 rank 相关把整个效应的幅度**一次性封死**。

**还有一个事实要进 `11_risks.md`**:并列占比按十分位单调升到 Q10 的 51%、并列组的截面百分位更高(0.524 vs 0.481),
说明「这几天估值没怎么动」的股票系统性地落在因子高端。这不是泄漏(毛 alpha 不在那里),
但它是一条**机制上的自证**:高因子值 = 路径安静、跟得上市场 —— 和 §2(iv) 的「低成交额」暴露是同一件事。

## 5. 这一节确立 / 否定 / 仍未决的

- **已确立**:H1(恒等式,98.7% 格子上逐日相关 1.0000);H3 被否定(`l_mean` 0.994);
  「alpha 在条件化里、不在动量里」(`ρ^time` −5.6% vs `c·ρ^time` +9.2%,外加 `t_tsrank` 7 个半衰期全负);
  「不是任何**单独一条**已知家族的改写」(残差 R² 0.07~0.11、残差净多头腿 +3.7%~+5.2%/+6.3%~+7.8%);
  「valid 上对已知家族没有可测的增量」(组合散布 ±0.4pp)。
- **合理但未坐实**:H11 改写后的版本(暴露是低成交额/低成交额离散度,平滑把它提浓);
  「`c·ρ^time` 是同一本书的另一种写法」(相关只有 0.54,严格说是另一条因子);
  「口径②残差更低是因为平滑让 `f` 更像家族」((c4) 支持,但没有做分解去坐实)。
- **未决**:H4 的最后一步(用更强的等价写法 + 双重排序,R2);窗口 `d` 这根轴(完全没测过,R2);
  H8(空头腿里封板票的贡献,`st.target(buyable=False)` 还没量);H9 的 valid 分段确认。
