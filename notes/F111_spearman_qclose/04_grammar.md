# 结构语法:这棵树在做什么

树只有一条链(`03_decomposition.md`),按"事件 → 记忆 → 门控 → 放大"的套路去读会读空:
**这棵树里没有门控、没有放大、没有逐元素乘法**。它只有两步,而且第二步的真实身份和算子名字差得很远。

```
Close(分钟) ──day_quantile(q=0.5)──► A = 日内中位价(带价格量纲)
A ──ts_spearman(·,10)──► B = 根(无量纲,[-1,1])
```

| 语法角色 | 节点 | 它实际在做的事 |
|---|---|---|
| **事件提取** | `A = day_quantile(Close)` | 把当天 ~240 个分钟收盘价折成一个**稳健的日内价格水平**(中位数,不是收盘价)。不是"事件",是一个位置统计量 |
| **记忆 + 去量纲 + 配对** | `B = ts_spearman(A, 10)` | 三件事挤在一个算子里:10 天记忆、窗口内秩变换(去掉价格量纲)、**跨股票两两配对再取横截面平均** |

**语法上最重要的一句**:`ts_spearman` 的第二个操作数**不在表达式里**,是股票轴本身
(`02_operators.md` 已记录)。所以这棵树的"操作数对称性""同期还是跨期"这类问题
(`docs/method.md` §1 里 F002 要问的)在这里都不适用,取而代之的是一个新问题:
**"对全市场其他每只股票取平均"这个动作,到底等价于什么更简单的东西?**

---

## 这一节的核心:把根节点的平均化**精确**解掉

下面是我(主研,第 1 轮)自己从 `./scripts/study.sh src ts_spearman` 的源码里推的,
不是探针读数,也不是经济学解释。记号按源码:窗口长 `d=10`,窗口内位置 `k=0..d-1`,
`ranks[t,k,i]` 是股票 `i` 在窗口 `t` 内第 `k` 天的序数秩,`rc = ranks − mean_k(ranks)`。

### 第 1 步:窗口完整时,每只股票的秩标准差是同一个常数

源码里 `ranks = argsort(argsort(x, stable=True), stable=True)`。窗口内 10 天都有值时,
`ranks[t,:,i]` 必然是 `{0,1,…,9}` 的一个排列,于是对**每一只**股票:

```
mean_k(ranks) = (d-1)/2 = 4.5           ← 与 i 无关
rank_var      = mean_k(rc²) = (d²-1)/12 = 8.25   ← 与 i 无关
rank_std      = σ = sqrt(8.25 + 1e-8)   ← 与 i 无关
```

**所以 `corr = cov / (std_i · std_j)` 这个除法在窗口完整的格子上不区分股票** ——
分母是同一个常数 σ²。看着像相关系数,算的其实是**按常数缩放过的协方差**。

### 第 2 步:对 j 取平均,等于和"市场秩路径"做一次内积

窗口完整时 `num_valid = d`,于是

```
corr(t,i,j) = (1/(d σ²)) · Σ_k rc_i[t,k] · rc_j[t,k]
```

`Σ_k` 只碰 `rc_i`、`rc_j`,对 `j` 求平均可以直接换到求和号里:

```
B[t,i] = mean_{j≠i} corr(t,i,j) = (1/(d σ²)) · Σ_k rc_i[t,k] · ( mean_{j≠i} rc_j[t,k] )
```

`j≠i` 这个自排除可以精确算掉:`mean_{j≠i} rc_j = (N·M[t,k] − rc_i[t,k])/(N−1)`,
其中 `M[t,k] = mean_{所有 j} rc_j[t,k]`。代回去,第二项是
`−(1/(N−1))·(1/(dσ²))·Σ_k rc_i[t,k]² = −1/(N−1)`(因为 `Σ_k rc_i² = d σ²`,还是那个常数)。于是:

> **(恒等式,窗口完整的格子上精确成立)**
> ```
> B[t,i] = (N/(N−1)) · (1/(d σ²)) · Σ_k rc_i[t,k] · M[t,k]  −  1/(N−1)
> ```
> `M[t,·]` 是**全市场平均的"窗口内去均值秩路径"**,在第 t 天对所有股票是**同一个 d 维向量**;
> 前面的系数和后面的常数项在第 t 天对所有股票也相同。

**截面含义(这才是选拔口径关心的)**:十分位书只用每天的**截面排序**。上式右边
除了 `Σ_k rc_i·M[t,k]` 之外全是当天的常数,系数为正。所以

> **原式在每一天的截面排序,与"自己的 10 天秩路径 和 市场平均秩路径 的内积"的排序完全一致。**
> 而且因为 `‖rc_i‖ = sqrt(d)·σ` 对每只股票都一样,**内积排序 = 相关系数排序 = 回归 beta 排序**,
> 这三种写法在秩空间里是同一个序。

### 第 3 步:市场秩路径近似是一条直线 ⇒ 条件动量

`M[t,·]` 是 10 天里市场平均的秩位置。市场整段单调涨时 `M` 递增、单调跌时递减。
把它一阶近似成线性斜坡 `M[t,k] ≈ c(t)·(k − (d−1)/2)`(`c(t)` 是市场这 10 天的秩路径斜率,
涨市为正、跌市为负),代入:

```
Σ_k rc_i[t,k] · M[t,k] ≈ c(t) · Σ_k rc_i[t,k]·(k − 4.5) = c(t) · d σ² · ρ_i^time
```

`ρ_i^time` = 股票 i 自己的**价格与时间下标的 Spearman 相关** = 一个抗异常值的
**10 日单调趋势强度**(纯粹的 10 日动量,秩版本)。于是

> **B[t,i] ≈ c(t) · ρ_i^time + 常数**,即 **(市场 10 日趋势方向) × (自己的 10 日秩动量)**。

一句话:**这条因子衡量的是"最近 10 天,这只股票有没有跟着大盘一起走"** ——
涨市里买涨得最齐的、跌市里买跌得最齐的(都是"跟大盘同步"的那一端)。
它不是"相关性"因子(分母是常数),而是**秩空间里对市场 10 日路径的 beta / 投影**;
它也不是无条件动量,而是**被市场自身方向定了符号的条件动量**。

这解释了基线里一个本来很别扭的读数:无条件的 `ctl_mom20` 只能张成它 R²=0.056、
rank 相关仅 −0.08(`06_baseline.md` §7/§10)。如果它是条件动量,`c(t)` 时正时负,
**无条件**地和动量比,相关性本来就应该被抵消到接近 0 —— 低相关不等于"和动量无关"。

### 第 4 步(第 1 轮重启主研补)——**因子本身不随市场方向变号**,所以"条件动量"这个说法要小心

上面第 3 步的写法容易让人读成"这个因子会跟着大盘变号",**那是错的**。
把恒等式写成「模长 × 夹角」就看得很清楚。因为 `‖rc_i‖ = sqrt(d)·σ` 对每只股票是**同一个常数**:

```
Σ_k rc_i[t,k]·M[t,k] = ‖rc_i‖ · ‖M[t,·]‖ · corr( rc_i[t,·], M[t,·] )
⇒  B[t,i] = c₁(t) · corr( rc_i[t,·], M[t,·] ) + 常数 ,   c₁(t) = (N/(N−1))·‖M[t,·]‖/(sqrt(d)·σ)
```

`c₁(t)` 是一个**模长**,**恒为正**。所以:

> **`B` 的符号只由「自己的秩路径与市场秩路径的吻合度」决定,和大盘往哪走无关。**
> 涨市里跟着涨的、跌市里跟着跌的,**两种都拿到正的高值**;两头都是"跟得齐"的那一端。

会随市场变号的是**「`B` 与自己的动量 `ρ^time` 之间的关系」**(涨市正相关、跌市负相关),
**不是 `B` 自己**。第 3 步那个 `c(t)·ρ_i^time` 的写法在代数上没错(`c(t)` 带符号,
`sign(c)·ρ_i ≈ corr(rc_i, M)`),但**容易被后面的人读成"因子会翻面"**,所以这里把不变量写出来。

**这件事有可检验的后果,而且本轮已经检验过了**:
如果被交易的信号真的每隔几天整本翻面,那么 20 天 EMA 应该把它平均掉一大块。
`05_hypotheses.md` H5 的毛超额表显示**没有**:毛超额 hl=0 的 +14.07% → hl=20 的 +13.53%,
只掉 0.5pp,而换手掉掉了 86%(29.9% → 4.1%)。
⇒ **被平滑掉的高频部分几乎不含 alpha;活下来的是跨市场方向不变的那一部分。**
那一部分按上面的式子就是「路径吻合度」= 路径干净、跟得上市场 ⇒ **特质波动低**。
这正是 `05_hypotheses.md` **H11** 的内容,也是基线里
`known_stdamt_mean30` −0.42 / `ctl_dvol20` −0.31 / `ctl_amt` −0.35 这组相关的来源
—— 而动量本身几乎正交(−0.08)。

**措辞规矩**:报告里写这棵树时,"条件动量"可以作为**原始面板瞬时含义**的描述,
但必须紧跟一句"因子值本身不随大盘方向变号";而**被交易的对象**(hl=20 的平滑信号)要按 H11 的
结论来描述,不能直接叫"条件动量"。两者是不同的东西,R1 block (b) 的三个分组相关决定措辞的强弱。

## 这套语法立刻带出的三件事(都要实验来定,见 `05_hypotheses.md`)

1. **O(N²) 的两两配对是多余的**(如果恒等式在真实数据上站得住)。它可以被
   "和一条市场路径做相关"替掉 —— 这是这棵树上最干净的**提纯**方向,而且算得快得多。
2. **并列值会造人工趋势**。`argsort(..., stable=True)` 对**相等**的值按**窗口内位置(日期)顺序**发秩。
   所以一只 10 天里日内中位价**完全不变**的股票,秩路径正好是 `0,1,…,9`,即一条**完美上升斜坡**,
   在涨市里拿到**接近最高**的因子值。`day_quantile(Close)` 落在 tick 网格上(低价股尤其容易重复),
   这个"假趋势"不是空想。换成几乎不可能并列的 `day_mean(Close)` 就能检验它有多重要。
3. **窗口不完整时恒等式失效,而且失效的方式是个瑕疵**。源码里
   `cov = sum_prod / num_valid`(用两只股票**重叠**的有效天数),而 `rank_std` 是各自在
   **自己**的有效天数上算的。两只股票缺失模式不同时分母口径不一致,"相关系数"可以超出 [-1,1]。
   停牌/新股多的格子(`cov=0.99`,约 1% 的格子)值会被扭曲。这是实现层面的瑕疵,记录在案。
