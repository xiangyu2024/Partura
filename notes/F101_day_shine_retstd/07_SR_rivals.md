**解读**

1. **Volume 字段不是必需的**。把放量掩码换成「`|Ret|` 比当天自己的均值大 1σ」这个完全不看成交量的事件,`sr_fold_jret` 的多空夏普
   +3.87 / +3.12、空头腿 +49.1% / +48.9%。同口径的对照不是 `v_base` 而是 `sr_orig_nz`(`Jret` 在全天分钟收益为 0 的格子上没有触发、是 NaN,
   所以要把原式里对应的 `J == 0` 格子也拿掉):+3.65 / +3.04、+47.8% / +48.3%。**不用 Volume 的版本不低于原式**,连 valid 多头腿失效(−2.4% 对 −2.2%)
   和逐年的形状都一样(多空 2018–2023:4.03 / 5.43 / 3.76 / 2.81 / 3.69 / 2.18 对 3.72 / 4.93 / 3.32 / 2.99 / 3.51 / 2.27)。
   原式的假设 H1 被我读成「放量掩码有独有内容」是错的:原研究只把掩码换成过「全部分钟」和「非放量分钟」,从没换成另一种事件。
2. **多出来的那部分是「大波动分钟附近的局部波动」,不是放量,也不是分位数**。相对全天 std 的折叠(空头腿 +40.7% / +42.2%),
   放量掩码版和 `|Ret|` 掩码版都多出 6~8 个点空头腿(这是让着全天 std 版的比法:它的空头腿里还含着一字板日;
   把零值格子从每个统计量里都拿掉、在同一批格子上比,是放量版 +48.0% / +48.4%、`|Ret|` 版 +48.3% / +48.1% 对全天 std 版 +35.0% / +40.5%,即 13 / 8 个点,见 `rev_look.py` E 段);
   而不用触发机器、只取滚动 std 第 90 百分位的 `sr_fold_q90` 停在全天 std 的水平(+40.2% / +41.1%)。
3. **「爆发比」不是放量事件独有的信号**。三个比值作为单调因子一样强:`J ÷ roll5`(放量)、`Jret ÷ roll5`(不用 Volume)、
   全天 std ÷ `roll5`(什么掩码都不用)的 rank IC 是 +0.0285 / +0.0272 / +0.0282(train)、+0.0415 / +0.0359 / +0.0459(valid),
   最差一档 −46.6% / −48.6% / −45.8%(train)、−40.3% / −44.2% / −42.7%(valid)。这个量量的是**日内波动集中在少数几分钟里的程度**
   (全天 std 对大的那几根分钟线敏感,滚动 std 的均值不敏感),用成交量去找那几分钟只是其中一种找法。
   直接量 Volume 特有的部分 `J ÷ Jret`:rank IC +0.005 / +0.011,扣费多空 −0.62 / +0.20,最差一档只有 −11.3% / −14.2% —— 做不成书。
4. **一字板日给了多空夏普 0.56(train)/ 0.17(valid)**。把 `J == 0` 的格子(占有值格子的 0.47% / 0.21%)置 NaN:多空 +4.21 → +3.65、+3.21 → +3.04,
   空头腿 +53.7% → +47.8%、+50.1% → +48.3%,多头腿毛超额 +16.9% → +15.6%、+5.1% → +4.5%(等权基准里不再含这些连续下跌的票),
   多头净 +9.0% → +7.5%、−1.6% → −2.2%。H5 不是「死」,是「部分成立」(按收益贡献的拆分见 `rev_look.py` B 段)。
5. **F001 的「日内波动 + 极值记忆」族折叠之后就是近亲**。`cross_max(day_var(Ret), 9)` 套上同样的折叠,train 上就有 +3.83 的多空夏普、
   +7.8% 的多头净超额、+37.0% 的空头腿(原式 +4.21 / +9.0% / +53.7%);valid 上弱得多(+2.13 / −4.5% / +33.7%),逐年多头腿在 2022 / 2023 是 −3.8% / −5.9%。
   原研究写的「与 F001 的三个家族 rank 相关 ±0.05 以内」量的是折叠面板对单调变量的相关 —— 正是 V 形折叠必然给出的零。
   成交额水平那两族(`known_amt_max9`、`known_stdamt_max9`)折叠后确实没有关系(对原式交易信号的 R² 在 0.04 以内,见 `rev_look.py` D 段)。

**对假设的影响**:H1 改为「事件机器对多空价差有贡献,但贡献的是『大波动分钟附近的局部波动』,与用不用 Volume 无关」;
H5 从「死」改为「部分成立」;「与 F001 的族无关」改为「与成交额水平族无关、与日内波动 + 极值记忆族是近亲」。
这些变体都没有读留出段,不进入推荐名单。
