**B.「`EMA|K| = |EMA K| + 不稳定度`,两项各自单调、两段一致」——只在 `roll5` 上量过。** 审查员先复现了 `look3.py` H 段的 3×3(逐位一致),
再对被推荐的原式(`J`、半衰期 10)做同样的双重排序(行 = `|EMA10 K|` 三分位,离中心近 → 远;列 = 不稳定度三分位,稳 → 不稳;年化超额,括号里是格子占比):

```
train:  +11.0 ( 0.9%)   +17.8 (11.0%)    +3.1 (22.0%)        valid:  +14.2 ( 1.0%)    +4.1 (10.5%)    +2.9 (22.9%)
        +12.8 (11.2%)    +8.9 (15.0%)   -13.8 ( 7.6%)                +11.5 (11.1%)    +9.1 (16.1%)    +0.9 ( 7.1%)
         -2.5 (21.8%)   -16.5 ( 7.9%)   -63.4 ( 4.2%)                 -2.5 (22.3%)   -14.2 ( 7.8%)   -53.9 ( 4.3%)
```

train 上成立(离中心最近的三分位里按不稳定度五分位:+16.3 / +17.3 / +15.0 / +6.1 / −14.4)。**valid 上好的那一带塌了**:
train 上 +11~+18 的四个格子在 valid 是 +4~+14;人头最多的「近 × 中等不稳」那一格从 +17.8 掉到 +4.1,不如中等距离那一行的 +9.1;
最近三分位里按不稳定度五分位是 +6.2 / +2.9 / +2.2 / +7.0 / −0.4,没有梯度。
(审查意见里写「三列里有两列离中心近不如中等距离」,按这张表是一列 —— 中间那一列;另两列 +14.2 对 +11.5、+2.9 对 +0.9 是近的略好,
但「近 × 稳」那格只占 1.0%。3×3 的大方向 —— 每行从稳到不稳递减 —— 在 valid 上还在;塌掉的是多头十分位所在的那一带里的排序。结论不受这处出入影响。)
两段都清楚的只有「又远又不稳」那一角(−63.4% / −53.9%)—— 那是空头腿。
多头十分位对它所在的平台(`EMA10(J)` 水平在第 10~80 百分位的全部股票,等权)的毛超额:train +16.7% 对 +7.0%,**valid +5.7% 对 +6.6%**(半衰期 20:+5.5% 对 +6.0%);
同一检验在 `roll5`(半衰期 20)上 valid 是 +13.5% 对 +4.0%,在全天 std(半衰期 10)上是 +10.0% 对 +5.8%。
也就是说:**原式的多头十分位在 valid 上不比「避开最高 20% 和最低 10% 波动的任意票」好**。

**C.「H5 死:空头腿不是买不到的票」——是按人头否掉的,不是按收益。** 把原式空头腿(train +53.7%、valid +50.1%)按人群拆成收益贡献:

| 人群(空头十分位内) | train 人头 | train 贡献 | 自身年化超额 | valid 人头 | valid 贡献 | 自身年化超额 |
|---|---|---|---|---|---|---|
| 高侧(`EMA10 K ≥ 0`) | 94.4% | +48.2 个点(90%) | −51.6% | 97.2% | +48.9 个点(98%) | −50.9% |
| 低侧 | 5.6% | +5.6 个点(10%) | −108.7% | 2.8% | +1.2 个点(2%) | −46.1% |
| 当天 `J == 0` | 2.2% | **+7.1 个点(13%)** | −591.7% | 1.0% | +3.0 个点(6%) | −442.7% |
| 5 日内出现过 `J == 0` | 6.9% | **+13.8 个点(26%)** | −228.8% | 4.1% | +7.6 个点(15%) | −204.2% |
| 标签 NaN(记 0) | 3.0% | +0.2 个点 | — | 2.4% | +0.2 个点 | — |

`J == 0` 就是当天触发窗口里分钟收益全为 0 的一字板日;这些票的 `|K|` 等于截面均值,被折叠送进空头十分位,次日相对等权约 −2%/天。
人头 2.2% 的票给了空头腿的八分之一,5 日内有过一字板的票(人头 6.9%)给了四分之一。标签 NaN 的票确实不重要(+0.2 个点)。
`fold(ivol)`、`fold(roll5)` 的空头腿里同样有 6~7 个点(train)来自当天统计量为 0 的票,所以候选之间的比较不受影响,受影响的是**绝对水平**和对空头腿的定性。

**D.「与 F001 的家族无关(rank 相关 ±0.05 以内)」——对折叠型因子,这个数必然接近零。** 原始折叠面板与 `known_ivol_max9`(= `cross_max(day_var(Ret), 9)`)
的 rank 相关是 −0.036,但平滑后的交易信号与 `−known_ivol_max9` 是 +0.219、与 `−EMA10(fold(known_ivol_max9))` 是 **+0.644**;
对后者的 R² 0.418 / 0.489。原式的空头十分位与单调的 `−EMA10(known_ivol_max9)` 的空头十分位重叠 70% / 72%
(共同部分 −50.4% / −50.4%,只有原式做空的 −63.6% / −51.6%,只有 `known_ivol_max9` 做空的 −3.2% / +6.8%)。
`fold(known_ivol_max9)` 自己在半衰期 10 下就有 train 多空 +3.83、多头净 +7.8%、空头 +37.0%(valid +2.13 / −4.5% / +33.7%)。
中性化之后原式的残差 rank IC 仍有 +0.038 / +0.035、无成本多空 +4.61 / +4.66,所以原式不是被它吃掉 —— 原式是更好的选股者 —— 但绝不是「无关」。
