## 3. 过程与逻辑

1. 把 s1 的每条推论写成「支持 / 否定 / 没检验到」,每条挂变体 id 和三个段的数字,不允许只写 ut。
2. 发现 s1 的窗口结论是**掩码稀释的假象**:在带触发掩码的树上做窗口扫描,窗口变长会同时稀释掩码的坏处,
   斜坡方向因此可能完全由掩码而非被测量决定。去掩码重做后 5 > 15 > 全天,与 s1 相反。
3. 发现 s1 读解剖表的方法错了:只看「段内分辨力」而忽略「段等权超额」。清淡段段等权 +15.1%、热门段 −17.8%,
   比段内分辨力(+0.7% vs +20.5%)大一个数量级 ⇒ s1 关于「剔掉清淡段 / 留住热门段」的两条推论符号全反。
4. 逐条用 `_lexi` 的源码核对分段 / 筛子变体的 sg,找出 4 条方向被 train 翻转、实际跑的是语义相反的东西。
5. 用 ρk + **逐年形状相似度**双重判定「是不是同一笔钱」:lo40 / scr 一族的逐年形状与 `k_known` 重合,
   `fld_Volume_Amt` 反相关 —— 后者才是分散化的来源,但规模不够。

## 6. 后面的思路

唯一还可能改变结论的是 A 组:把折叠中心从全市场均值换成**桶内典型值**(`cs_bucket_demean`)。
解剖里最大的那处落差一直没被修过 —— 小票段内 S+2.96 却 tilt −13.5%(只放 6% 仓位),大票 tilt +18.9% 而段内 S+0.20;
`cs_bucket_rank` 一族之所以修不上,是因为它先在全市场折叠、再在桶内排名。判据:`h3_bdem_amt241` 把小票 tilt 翻正
且 ut > 2.68、ρk 仍 ≤ 0.2。其次是 B 组短端(3 / 2 分钟):若 2 分钟也不差,整棵树能压成
`abs_(cs_demean(day_mean(abs_(in_delta(Ret)))))` 这一级,那才是真正的提纯。
D 组(`day_wstd` / `day_distinct_ratio`)是 s1 那条「清淡票的 std 是 tick 量化噪声」推论的最后一次机会 ——
`h_wmean_absret`(1.55 / −0.68 / 0.97)已经用错的量纲否证过一次。
已经可以收口、不必再提的五类:平滑 / 日轴记忆、折叠中心的位置、`cs_bucket_rank` 式中性、overlay 与残差、
非波动的投机代理(`day_centroid` / `day_signed_ratio`)—— s2 全部给了否定读数。

## 8. 工具问题(未解决的留给总领)

1. **分段 / 筛子类变体的 sg 应锁定 +1**(y 已用 `neg` 定过向),否则 train 的方向选择会把变体翻成语义相反的东西。

   ρo −0.49)、`seg_hiliq_m`、`seg_lowliq_p`。想测的两件事都没测到。
2. 乘一个铺满截面的日标量(`cs_stddev_full` / `cs_state_rank` 一类)对信号**完全无效**,因为口径先取秩
   (`h_rv_fold_state_weight` 的 ρo 0.83 与 `h_rv_fold` 逐位接近)。市场状态只能用 `select_where` / `cs_flip_by_state` 进入表达式
   —— 这一点该写进算子表的提示里。
3. `cs_bucket_rank` 的 dist 门槛已修好(s2 全部 0.99~1.00,s1 是 0.20 ✗);`*_tie` 这类 0.001 秩扰动的绕路写法
   可以从假设模板里删掉(`h_rv_fold_bk_amt20_tie` 2.16 对原版 2.17)。
4. `in_sustain_stddev` 的内核只认 `mask == 1.0`,喂浮点量会变成「恰好等于 1 的分钟」;混分钟轴宽度(236 vs 241)直接报错。
5. 数据层仍缺流通市值 / 板块字段:A 组只能用成交额和价格当代理,而这两个代理在同一棵树上给出的答案不一致。
