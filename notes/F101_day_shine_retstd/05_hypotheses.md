下面的假设是在**读完源码和基线、跑任何新实验之前**写的。每条给出「它预测什么」和「哪个实验能杀死它」。
记号:`J` = 折叠之前的量(放量分钟之后 5 分钟收益 std 的日均值),`K = J − 截面均值`,原式 = `|K|`,
实际交易的信号 = `−EMA10(|K|)`。

| | 假设 | 为什么合理 | 它预测什么 | 能杀死它的实验 |
|---|---|---|---|---|
| **H1** | **事件机器是多余的**:`J` 就是日内波动,放量掩码 + 5 分钟窗口只是换了个写法 | 触发条件 ΔVolume > 均值 + 1σ 每天会命中十几到几十分钟,窗口又互相重叠,平均下来和「全天滚动 5 分钟 std」没区别 | `J` 与 `day_std(Ret)`、`day_mean(in_stddev_rolling(Ret,5))` 的日截面 rank 相关 ≥ 0.9;把 `J` 换成 `day_std(Ret)` 再做同样的折叠,rank IC 和两本书都保住 | `look.py` C/F 段;S1 的 `s1_fold_ivol` / `s1_fold_roll5` |
| **H2** | **折叠是装饰**:`J` 右偏,`|K|` 的大值几乎全是高 `J`,所以这就是「高波动 → 低收益」的单调因子,折叠只是把低波动的一半搅乱 | A 股的特质波动异象;基线空头腿 −54%、多头腿只占 24% | `|K|` 前 10% 里低侧(`J` < 均值)占比 < 10%;`J` 的 20 分位收益剖面单调下降;不折叠的 `−J` 多空夏普不低于原式 | `look.py` D/E/F 段;S1 的 `s1_nofold` |
| **H3** | **折叠是真的**(方正「适度冒险」的原意):收益对 `J` 是驼峰形,太低和太高都差,最好的在均值附近 | 原始研报的立论;基线里它与 `ctl_ivol` 的 rank 相关只有 −0.14,说明折叠确实改了排序 | `J` 的 20 分位剖面是倒 U;折叠中心扫描在均值所在分位(右偏 → 约 0.6)附近最好,往两边都掉;不折叠的 `−J` 多头腿明显更差 | `look.py` E/H 段;S1 的 `s1_nofold`、S2 的中心替换 |
| **H4** | **先折叠后平滑 ≠ 先平滑后折叠**:`EMA(|K|) = |EMA(K)| + 不稳定度`,多出来的那一项(`J` 相对截面位置在时间上的抖动,研报里的「月稳」)自己带 alpha | 半衰期 0 时原式是亏的(LS −3.14),全靠平滑;被平滑的是**折叠之后**的量 | 「先平滑后折叠」`−|EMA(K)|` 明显弱于原式;单独的不稳定度 `EMA|K| − |EMA K|` 有独立的 rank IC | `look.py` F 段;S2 用 `cross_mean` 写成表达式复核 |
| **H5** | **空头腿是买不到 / 做不了的票**:`J = 0`(全天一字板、收益全为 0)时 `|K|` = 截面均值,会被排进空头;空头腿 −54% 有一部分是「标签 NaN 记 0」和涨跌停股 | 口径里空头腿持有标签为 NaN 的票记 0;一字板股票分钟收益全 0 | 空头十分位里标签 NaN 占比、`J==0` 占比显著高于全体 | `look.py` G 段 |
| **H6** | **换手率 / 日频波动的另一种写法**:`ctl_turnrate`(R² 0.072)和 `ctl_dvol20`(0.046)是张成它最多的两个控制;对换手率中性化后扣费多空夏普 4.21 → 2.72 | 基线中性化表 | 把同样的折叠套在 `ctl_dvol20` 上就能复现;对「折叠过的控制变量」中性化后残差 rank IC 大幅下降(线性控制张不成 V 形,所以基线的 R² 0.154 是低估) | `look.py` F 段(`fold(dvol20)`);S2 加折叠版控制变量后重做中性化 |
| **H7** | **触发次数的小样本伪影**:某一分钟成交量极端时,σ 被撑大,当天只剩 1~2 个触发点,`J` 是 1~2 个窗口的 std,噪声大 → 更容易落进 `|K|` 的两端 | 阈值是当天自己的均值 + 1σ,对重尾敏感 | 触发次数与 `|K|` 负相关;信号的 rank IC 集中在触发次数少的那一档 | `look.py` B/I 段 |
| **H8** | **窗口 5 和阈值 1σ 是幸运参数** | 手写因子照抄研报参数 | 窗口换成 3 / 10 / 15、掩码换成「全部分钟」后表现塌掉 | S1 的窗口邻域与去掩码变体 |
| **H9** | **多头腿可以做得更好**:原式的多头腿是「`J` 离均值最近的 10%」。如果驼峰的峰不在均值、或者用排名折叠 / 先平滑再折叠能把「适度」的票认得更准,多头腿净超额会上去 | 基线 valid 的分位剖面 Q4..Q10 是平的(+8.6% … +5.9%),说明多头端排序在 valid 上没有信息 | 某个折叠中心 / 折叠方式在 train 和 valid 上**同时**抬高多头腿净超额,且邻域稳定 | `look.py` H 段 → S2/S3 |
| **H10** | 行业 / 板块暴露 | 高波动集中在题材板块 | — | **当前立方体没有行业数据,无法检验**,列为未决 |
