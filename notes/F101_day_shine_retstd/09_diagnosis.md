### 已确立(每条后面是它依据的实验)

1. **折叠之前它就是日内波动**。`J` 与 `day_std(Ret)` 的日截面 rank 相关 +0.90,与全部分钟的 5 分钟滚动 std 均值 +0.85(`look.py` C)。
   放量阈值按每只票当天自己的 σ 定,每天触发约 20 次(p1 = 5、p99 = 32),不带成交额尺度,也没有小样本问题(`look.py` B)。
2. **整棵树里只有截面折叠是不能拿掉的**。不折叠:rank IC 更高(+0.0389 / +0.0571)、多空夏普 +1.34 / +2.35、多头净 −9.0% / +0.2%
   (`s1_nofold`;背景版 `s2_roll5_nofold` 同样)。窗口 3 / 5 / 15 等价(`s1_win3`、`s1_win15`),切片多余(`s2_roll5_noslice`),
   放量掩码对 train 多头腿没有贡献(`look3.py` A:半衰期 20 时三种统计量的均值折叠 +9.4% / +9.5% / +9.1%)。
3. **「先折叠后平滑」和「先平滑后折叠」不是同一个因子**。先平滑后折叠:多头净 −9.5% / −10.2%(`J`,原式是 +9.0% / −1.6%)、
   −4.7% / −6.4%(背景版,先折叠后平滑是 +9.1% / +10.4%)(`look.py` F、`look2.py` F)。口径里的 EMA 作用在折叠之后,这是因子的一部分。
   (只确立到这里;`EMA|K|` 里两项「各自单调」的说法见下面「合理但没有坐实」。)
4. **它是已知暴露的非线性写法,而且是 F001「日内波动 + 极值记忆」族的近亲**。9 个线性控制 R² 0.154;一个「折叠并平滑过的日内波动」R² 0.749 / 0.764
   (`look2.py` A、`audit_1.py` A)。把 F001 的 `cross_max(day_var(Ret), 9)` 做同样的折叠:一个变量张成原式的 42% / 49%(先取对数再折叠是 57% / 64%),
   它自己在 train 上就有多空 +3.83、多头净 +7.8% 的书(valid +2.13 / −4.5%;`sr_fold_kivmax9`、`rev_look.py` D);原式的空头十分位与这一族单调书的空头十分位重叠 70% / 72%(`audit_1.py` D)。
   中性化之后原式残差的 rank IC 还有 +0.039 / +0.035,所以原式是这一族里更好的选股者,但不是新的一族。
   与 F001 的**成交额水平**两族在 V 形意义上无关(折叠版 R² 0.04 以内、折叠后没有多头腿;`rev_look.py` D、`look3.py` D、`s2_fold_logprice`);
   空头十分位与它们的单调书重叠 23% ~ 35%(随机 10%),是「热门票同时成交额大」的共同暴露。
   在 train 上,折叠任何活跃度 / 波动类变量(日内波动、20 日波动、换手率、振幅)都得到多空夏普 3.0~3.6、多头净 +8.4%~+9.7% 的书(`look3.py` D)。
5. **钱主要在空头腿;空头腿 = 换手率 / 波动因子的地盘 + 一字板附近的票**。多头腿只占毛价差的 24%;空头十分位人头 94%~97% 来自高侧,
   平均在换手率第 80、20 日波动第 82 百分位(`look.py` D / G);对线性控制中性化后空头腿 +53.7% → +19.7%,多头腿 +16.9% → +17.3%(基线中性化表)。
   **按收益贡献**(`audit_1.py` C、`rev_look.py` B):高侧的票给了空头腿的 90% / 98%;但当天 `J == 0`(一字板日)的票人头 2.2% / 1.0% 给了 13% / 6%,
   5 日内有过一字板的票人头 6.9% / 4.1% 给了 26% / 15%(20 日内:39% / 27%),上市 60 日内的次新股给了 18% / 12%。
   把 `J == 0` 的格子拿掉,多空夏普 +4.21 → +3.65、+3.21 → +3.04(`sr_orig_nz`)。标签缺失的票只贡献 +0.2 个点。
6. **原式相对全天 std 折叠多出来的是空头腿,而且用不着 Volume 字段**。同一批格子上,放量掩码版和「`|Ret|` 激增」掩码版的空头腿都是 +48%,
   比全天 std 的折叠多 13 / 8 个点;两个版本的多空夏普(+3.66 / +3.05 对 +3.78 / +3.06)、多头净、逐年的形状都分不开(`sr_fold_jret`、`sr_orig_nz`、`rev_look.py` E)。
   不用触发机器的尾部分位数(`sr_fold_q90`)做不到。「爆发比」作为单调空头信号,放量版、不用 Volume 版、完全不用掩码版(全天 std ÷ 滚动 std 均值)
   一样强(rank IC +0.0285 / +0.0272 / +0.0282、+0.0415 / +0.0359 / +0.0459);Volume 特有的部分 `J ÷ Jret` 的 rank IC 只有 +0.005 / +0.011,扣费多空 −0.62 / +0.20(`SR_rivals`)。
   原式对不用 Volume 的折叠 R² 0.792 / 0.848,残差没有空头腿(−0.5% / −5.3%)(`audit_1.py` A)。
   样本外这段空头腿还在:测试段原式 +52.2% 对 4 算子 `f_ivol` 的 +41.3%(多空 +3.70 对 +3.42,差 0.28 在噪声内)。
7. **分位剖面不是「越适中越好」,也不是两道悬崖**:高侧最后 5% 是悬崖(−59% ~ −84%);低侧在剔除一字板日之后只是一道浅坡
   (当天 `J` 最低 5%:train −41% → −9%,valid −13% → −1%;`rev_look.py` B),valid 上整条剖面向低波动倾斜;峰不在均值,最佳折叠中心两段不一致(`look.py` E / H、`look3.py` B)。
8. **原式的多头腿在 2021–2023 年是空的,前后都不是**。用户口径逐年多头腿净超额:2018–2020 +7.5% / +10.8% / +13.6%,2021–2023 +3.7% / −1.7% / −0.7%,
   2024–2025 +8.9% / +5.0%(`final.json` 逐年)。2022、2023 年它的多头十分位不比「波动水平在第 10~80 百分位的全部股票等权」好(−1.8 / +0.7 个点;2018–2020 是 +9 ~ +14;`rev_look.py` C)。
   不用 Volume 的版本同样(`rev_look.py` E 逐年)。
9. **价格水平 / 报价单位不是来源**(`s2_fold_logprice`、价格分桶条件 IC)。
10. **升华没有被样本外支持;最朴素的写法在样本外与原式不可区分**。事前推荐的 `f_roll5` 测试段多头净 +6.6% 对原式 +6.0%、纯多头夏普 +1.41 对 +1.32;
    4 个算子的 `f_ivol` 是 +6.6%、+1.43、多空 +3.42(原式 +3.70)(`S_final`)。

### 合理但没有坐实

- **「波动水平适中且相对位置稳定 → 多头腿」**。`EMA|K| = |EMA K| + 不稳定度` 是恒等式;「两项各自单调」的双重排序在 `roll5` 上两段数据都成立(`look3.py` H),
  `roll5` 版的多头十分位六年里每年都比平台等权多 +6 ~ +11.5 个点(`rev_look.py` C)。**但在被推荐的原式上只有 train 成立**:
  valid 上双重排序里多头十分位所在的那一带没有梯度(最近三分位里按不稳定度五分位 +6.2 / +2.9 / +2.2 / +7.0 / −0.4),
  多头十分位 +5.7% 对平台 +6.6%(`audit_1.py` B)。所以「原式的多头腿 = 适中且稳定的票」只能说到 2021 年为止。
- **排名折叠与均值折叠孰优**。事实:两个排名折叠版 2024 年的空头腿是 −5.3% / +3.7%、多空夏普 −0.07 / +0.82,测试段多空(+1.63 / +2.33 对 +2.97 / +3.70)的差全部来自这一年;
  其余年份排名折叠不差(`f_j_rank` 在 2020、2022、2023 年高于原式,2025 年打平;`f_roll5_rank` 在 2020、2021、2023、2025 年高于 `f_roll5`),训练段两种折叠多空 +3.19 ~ +3.60 对 +3.24 ~ +3.93。
  用户真正交易的多头腿在测试段不可区分(净 +5.0% 对 +6.0%、+5.7% 对 +6.6%,差 1 个点,小于事前写下的 ±3 个点)。
  已量到的结构:排名折叠的空头十分位四到六成人头在低侧,这一半的贡献 2018 → 2023 从 +10 ~ +11 个点缩到 0 ~ +1(`rev_look.py` A)。
  **推断(没有量)**:2024 年低侧那一半转负。它与上面的趋势相容,但 2024 年在留出段里、不能再拆,而且只有一年。
- **2021–2023 年是一段插曲还是会重复的制度**。三个统计量 × 六年的排序一致(`look3.py` A / Y),但它只发生过一次,2024–2025 年没有延续。
- **事件条件化的局部波动为什么比全天 std 多出空头腿**。解读:它量的是「波动集中在少数几分钟里」的票(脉冲式拉升 / 砸盘),无掩码的集中度比值同样强支持这个读法;
  但原式对「全天 std 的折叠 + 无掩码集中度」两个变量的残差在 train 上还有 +2.44 的无成本多空夏普,valid 上是 −0.06(`rev_look.py` F)—— 多出来的东西没有被一个简单的量说尽。
- **经济解读**:空头腿 = 被注意力和博彩需求推高的票(高换手、高波动、波动集中在少数分钟)加上一字板打开之后和次新股的回落;
  多头腿 = 波动只跟着大盘走、没有自己的事件的票。与证据相容,没有直接检验(没有散户成交、龙虎榜、新闻数据)。

### 未决

- **原式样本外的多头腿有多少来自挑选**。测试段 +6.0% 的多头净超额,有多少是「适中且稳定」挑出来的、多少只是「不在最高 20% 波动里」:平台对照在留出段没有量,也不能再量。
- **2024 年排名折叠的空头腿为什么归零**(低侧 / 高侧的拆分需要留出段)。
- **一字板附近的票和次新股在样本外给了空头腿多少**(只在 train / valid 上量过)。
- **行业 / 板块暴露**:当前立方体没有行业数据。
- **多头腿的容量**:背景版多头十分位里市值偏小的一半毛超额 +17.5% / +23.6%,偏大的一半 +8.5% / +3.4%(`look3.py` E);最大市值一档条件 IC 接近 0。
- **为什么日频的活跃度折叠(20 日波动、换手率、振幅,以及 F001 的 9 日极值记忆)在 valid 上多头腿归零,而当天的分钟级波动折叠没有**。
- **原式的多头腿为什么在 2021–2023 年是空的**:只知道它与折叠中心偏高(`J` 的截面均值在第 66 百分位)和那几年剖面向低波动倾斜同时出现。
