# F101_day_shine_retstd — 批量扫描 s1 + 市场解剖的综合(主研)

口径:多头腿扣 15bp 净超额 `Lnet`(train / valid / utrain)+ 纯多头夏普 `Lshp`,半衰期按纯多头书在 train 上选。
基准 `k_known = cross_mean(day_std(Amt), 30)`:+12.6% / +22.3% / +15.4%,Lshp 1.78 / 3.46 / 2.22,LTO 3.4%。
噪声:净超额 ±3 个点、夏普 ±0.3。本页所有数字来自 `runs/F101_day_shine_retstd/sweep_s1.json` 与 `anatomy_s1.json`。

## 1. 它是什么(按内核定义逐层)

记 `v_j`、`r_j` 为切片后第 j 分钟(j = 0..235)的成交量与收益:

```
A = in_slice(Volume, 2, 237)          # 两端都含,241 格取 236:去掉开盘 2 格 + 收盘集合竞价 3 格
C = Δ_j = v_j − v_{j−1}               # in_delay 第一格 NaN ⇒ j=0 永不触发
D,E,F = θ = mean_全天(Δ) + std_全天(Δ) # 全天统计量铺满全天;mean(Δ) = (v_235 − v_0)/235 ≈ 0 ⇒ θ ≈ 1σ(Δ)
G = 1{Δ_j > θ}                        # is_gt 遇 NaN 返回 0,输出 int
I = σ_j = 总体std(r_j … r_{j+4})      # in_sustain_stddev:只在 G==1.0 的分钟写值,其余 NaN;窗口含触发分钟自己、朝后看、跑出行尾截短
J = nanmean_j∈T(σ_j)                  # day_mean 对 NaN 用 nanmean ⇒ 触发点等权平均,与触发次数无关;T 空则 NaN
K = J − 当天全市场 J 的均值;  因子 = |K|,方向 sg = −1(多头 = |K| 最小)
```

名字和定义不符的地方:
- **`in_sustain_stddev` 的 "sustain" 不是"持续",是"从触发点往后取一段"**;注册表给它打的 `boolean_output` 标签是错的
  (它输出连续的 std,真正的掩码是它的第一个操作数)。
- **"放量"指相邻两分钟的增量**超过当天自己的 1σ,不是"这一分钟量大";阈值按每票自己的 σ 定,所以掩码**不带成交额尺度**,
  每票每天触发约 20 次(前研究探针:p1=5 / 中位 20 / p99=32)。
- **`abs_` 单独是 no-op**:`J` 是 std ≥ 0,`abl_K`(去 cs_demean 留 abs_)与 `iso_J`(两个都去)**数字逐位相同**
  (−6.8% / +2.1%,Lshp −0.81 / +0.28)。`abs_` 唯一的作用是和 `cs_demean` 配对成一个**在当天截面均值处的 V 形折叠**。
- 折叠中心不是"中间":前研究实测截面均值落在 `J` 的**第 65.6 百分位**,所以"离均值最近"= 偏高波动那一侧。
- `abl_G`(删 `is_gt`)把掩码换成了 `Δ` 本身,而内核只认 `mask == 1.0`,**语义是"Δ 恰好等于 1 的分钟"**——
  一个几乎任意的分钟采样器(cov 1.00、dist 1.00 说明它天天都触发)。它的分数却和阈值≈0 的那一族逐位接近
  (+9.2% / +11.1%,Lshp 2.27 / 2.95),这条是"掩码不重要"的最强证据,**不能读成"删 is_gt 有用"**。

## 2. 预测力在哪

**承重的只有两个:截面 V 形折叠,和"日内收益离散度"这个被测量。**
- 折叠不能拿掉:`iso_K` / `iso_J` / `abl_K` / `sub_L_neg`(单调版)Lshp(ut) −0.49 ~ −0.52,Lnet(tr) −6.5% ~ −6.8%。
  单调版的 rank IC 方向是对的(高波动→低收益),但低波动十分位里塞满一字板 / 准停牌票,所以多头腿是负的。
- 被测量必须是**离散度**:`abl_I`(删 `in_sustain_stddev`)dist 0.01 ✗、Lshp −1.43;换 `in_corr` / `in_cov` / `in_r2`
  → −1.07 / −0.19 / −1.14。`day_mean` 换 `day_first` / `day_last` / `day_close` → −0.12 ~ −0.16(必须是**全天平均的水平**,
  不是某一次触发);换 `day_skew` / `day_gini` → −0.14 / −0.93(必须是**尺度**,不是形状)。
- `cs_demean` 换 `cs_normalize` → 1.35(≈ base 1.37,只改缩放不改中心);换 `cs_mean` / `cs_stddev_full` / `cs_quantile_q25`
  → dist 0.00(退化)。**折叠中心 = 当天截面均值,是这棵树唯一不可替换的截面参照**。

**多余的:整台"放量触发机器"。而且它不只是多余,它是样本外失效的那一部分。**
把阈值从 `μ+σ` 放宽到 ≈0(掩码从约 10% 的分钟放到约一半),train 几乎不动而 **valid 从 −1.6% 跳到 +10.6 ~ +11.6%**:

| id | 掩码变成什么 | Lnet tr / va / ut | Lshp tr / va / ut | LTO | ρo |
|---|---|---|---|---|---|
| `v_base` | Δ > μ+σ | +9.0 / −1.6 / +7.1 | 1.96 / −0.38 / 1.37 | 10.4% | 1.00 |
| `fld_Volume_Amt` | Amt_t − v_{t−1} > θ(≈ 有成交的分钟) | +10.0 / +8.9 / +9.7 | **2.71 / 2.59 / 2.68** | 5.6% | 0.72 |
| `sub_C_mul` | v_t·v_{t−1} > θ(≈ 全部分钟) | +9.3 / +11.6 / +10.0 | 2.29 / **3.10** / 2.51 | 5.2% | 0.69 |
| `abl_G` | Δ 恰好 = 1(任意采样) | +9.2 / +11.1 / +9.7 | 2.27 / 2.95 / 2.46 | 5.2% | 0.69 |
| `sub_E_in_kurt_full` / `nosc_E_in_skew_full` / `abl_F` / `sub_F_div` / `sub_F_sub` | 阈值 ≈ 0 ⇒ Δ > 0 | +9.0 ~ +9.3 / +10.6 ~ +11.1 / +9.5 ~ +9.8 | 2.21~2.29 / 2.82~2.95 / 2.38~2.46 | 5.2% | 0.66~0.71 |
| `abl_C` | v_t > θ(偏向高量分钟) | +10.3 / +1.6 / +7.8 | 2.21 / 0.39 / 1.74 | 5.9% | 0.91 |

读法:**掩码越稠密、越不挑分钟,valid 越好、换手越低、最优半衰期越长(10 → 20)**;只有 `abl_C` 这个仍然"偏向高量分钟"
的例外留在 base 一侧(ρo 0.91)。窗口同向:`win_I` 3 / 5 / 10 / 15 → Lshp(ut) 1.20 / 1.37 / 1.85 / **2.03**,
**单调上升没有峰**,15 分钟的重叠窗口已经接近"全天收益 std"。所以 5 分钟、1σ、Volume 字段三件事都是装饰。

**可以互换的叶子**:触发字段 Volume → Amt 完全等价(`leaf_Volume_amt` 1.40 ≈ base 1.37);**被测字段 Ret → 量的变化率**
仍然有效且 valid 更好(`leaf_Ret_volchg` / `leaf_Ret_amtchg` Lnet va +8.0% / +8.0%,Lshp 1.47 / 1.57,base −0.38),
但换成 `in_pct(Close,5)` / `in_pct(Vwap,1)` 就回到 base 的样本外毛病(−0.16 / +0.25)。
⇒ 它测的是"这只票日内微观结构有多粗糙",分钟收益和分钟量变化率是同一类东西(用户的提示在这棵树上成立)。

**平滑是真实的第二杠杆,但只对稠密版有效**:`rk`(先 cs_rank 再 EMA)Lshp(ut) 1.84 vs base 1.37(+0.47,F103 的教训);
`cs_winsor` 无用(1.43),因为折叠后的量本来不重尾。给 base 加日轴记忆(`mem_mean/ema/decay_linear`)train 升到 2.4~2.8
但 **valid 全在 0.4~1.3** —— 在日轴上平均一个坏的日内估计量救不回来。`cross_zscore`(去掉持久水平)是全表最差
(−4.17 / −6.23):**信息在持久的截面水平里**,不在日间变化。

## 3. 在市场的哪儿、什么时候有效

(段内 = 只在该段建书的净超额 / 夏普;tilt = 全市场多头书在该段的超配。[0]=v_base,[2]=fld_Volume_Amt,[6]=abl_F)

- **按流通市值:小票里最强、却几乎不买。** 最低20%(段等权 +6.4%):段内 [0] +16.9% S+2.96、[2] +16.5% S+2.74,
  **tilt −13.5 / −11.4**(只放了书的 6%);最高20%(段等权 −2.0%):段内 +1.2% S+0.20 / +4.0% S+0.81,**tilt +18.9 / +8.2**。
  `k_known` 正相反(最低20% tilt **+30.8%**)。原因:折叠中心是**全市场**均值,而小票的日内波动系统性高于大票,
  "离全市场均值最近"就等于"选大票"。→ **最大的一处改进:把折叠放到规模 / 流动性桶内做。**
  `bk_liq` / `res_liq`(对 20 日成交额分桶中性 / 取残差)在 base 上就把 Lshp(ut) 从 1.37 抬到 2.03 / 2.02、valid 从 −1.6% 到 +4.8% / +3.4%。
- **按成交额:只在活跃的一头有分辨力。** 20 日成交额最低20%(段等权 **+15.1%**)段内只有 +0.7% S+0.15 / +1.0% S+0.25;
  最高20%(段等权 **−17.8%**)段内 +20.5% S+2.00 / +18.0% S+2.15。而书里有 16% 仓位放在"零分辨力"的最低20% 段。
  原因:清淡票的日内收益 std 主要是最小变动价位的量化噪声和零成交分钟,不是信息;热门票那一段有真的投机溢价要躲。
  **可检验推论**:用成交额加权的日内波动(`day_wmean(|Ret|, Amt)`)或剔除零成交分钟后,最低成交额段的段内夏普应该上来。
- **科创板是唯一的失效区**:段内 [0] **−19.4% S−1.01**、[2] −10.9%、[6] −15.8%(段等权 +4.1%),而 base 还**超配** +2.2%。
  原因:20% 涨跌幅 + 机构化 ⇒ 科创板的日内波动分布整体右移,拿全市场均值当中心时,板内"最像市场平均"的是板内最安静的那批。
  **可检验推论**:按价格水平或板内分桶做折叠中心,科创板段内应该由负转正;价格最高20% 段(base tilt +13.2%、段内 S+0.84)同向。
- **次新(上市不足 250 日,占 7.1%,段等权 −28.7%)**:段内 [0] +13.8% / [2] +17.5%,tilt −5.7 / −6.2 ⇒ 既躲开又能选,不用动。
- **近 15 日有冻结盘口(封板 / 停牌,占 6.5%,段等权 −67.4%)**:所有变体都只放 1.5% 仓位(tilt −5.0)。
  但**段内只有 base 行**(+27.5% S+2.07),稠密族是负的(+8.4% / −5.3% / −6.5%)。
  解读:对一字板票,"放量触发"的那几分钟恰好是板打开的时刻,之后 5 分钟的波动告诉你板会不会炸 —— 这是触发机器**唯一**有用的地方,
  而它只占 6.5% 人头、1.5% 仓位,对多头腿贡献 ≈ 0。
- **按年份:失效是 base 独有的,不是因子的。** [0] 2018–2023 = +8.1 / +12.4 / +15.4 / **+1.6 / +1.0 / +2.0**;
  [2] = +4.3 / +13.0 / +13.4 / **+9.4 / +9.0 / +8.8**;[6] = +4.2 / +11.2 / +11.3 / +10.4 / +12.4 / +7.8。
  **2021 年之后只有稀疏触发版塌了。** 推断:2021 起 VWAP/TWAP 切单与量化成交占比上升,分钟量的"跳升"越来越多来自算法切片而不是事件,
  `Δ > 1σ` 选出的分钟从"信息时刻"退化成噪声子样本;稠密版测的是全天波动水平,不受此影响。
  **可检验推论**:每票每天的触发数及其截面离散度在 2021 后应有结构变化;以触发占比本身为因子(`day_pos_ratio(Δ)`)的逐年形状应与此一致。
- **按市场状态:稠密族是顺周期的。** 放量日 +13.6 / +14.3% vs 缩量 +6.6 / +6.0%;截面离散度高 +13.8% vs 低 +5.7%;
  市场近 20 日上涨 +12.9 / +13.5% vs 下跌 +5.9 / +5.3%。base 反而是逆周期的(上涨 +4.9%、下跌 +10.2%)。
  解读:它的空头侧是"异常日内波动 = 投机性注意力",只有在有投机的时候才会被惩罚;**它是一个投机溢价的反向暴露**,
  需要截面离散度来分辨(离散度低的日子里"离均值多远"无从区分)。

## 4. 相对已知成交额族的增量

- **相关性上是两回事**:整族 ρk 只有 +0.14 ~ +0.18;`res_known`(对已知族取秩残差)仍有 +10.2% / +3.4%、Lshp 2.37 / 0.81。
- **结构上是互补的两种赚法**:`k_known` 几乎没有段内分辨力(20 日成交额各段段内 −4.1 / −5.3 / −8.2 / −5.2 / +2.5%),
  它靠的是 **tilt**(最低成交额段 +80.3%、最低市值段 +30.8%)—— 一个纯粹的规模 / 流动性溢价收割器;
  F101 族相反,tilt 温和但**在每个市值桶、每个价格桶里都有分辨力**(S +0.8 ~ +2.8)。
- **但增量还没被坐实**:`ov_p10 / p05 / p025`(叠在已知族上)utrain 净超额 +15.4 / +15.5 / +15.4% 对已知族的 +15.4%(**完全打平**),
  夏普 2.42 / 2.33 / 2.27 对 2.22(**+0.20 在 ±0.3 噪声内**),而且 valid 净超额被拖低(18.5 / 20.9 / 20.7 对 22.3)。
  负权重更差(`ov_m10` 0.18)。
  **注意这三条叠的是 `v_base`,不是稠密族** —— 整张表最关键的空白。稠密族 2019 年之后逐年都站得住、ρk 0.16~0.18,
  重做 overlay / res_known / bk_known 是第二批的第一优先。
- 当前最诚实的结论:**按净超额,F101 任何单体都打不过已知族(9.7% vs 15.4%);按纯多头夏普,`fld_Volume_Amt` 2.68 > 2.22
  (差 0.46 > 噪声),所以"更稳但更小"。作为独立因子对用户没有增量;唯一还活着的用法是"桶内选股器叠在已知族的 tilt 上"。**
  另外两道门槛:`bk_liq` / `bk_known` 的 dist = 0.20 ✗ 是 `cs_bucket_rank` 的机械产物(十个桶各自输出 (0,1] 的百分位,
  跨桶取值大量重合),不是因子退化 —— 见"工具问题"。

## 5. 改进方向(→ `studies/F101_day_shine_retstd/hypo.yaml`,39 条)

1. **拆掉触发机器,只留 `fold(日内收益离散度)` + 长半衰期**:`abs_(cs_demean(day_std(in_slice(Ret,2,237))))` 及其
   `cs_rank` / `cross_ema(30)` / `cross_mean(60)` 版本,和 `in_stddev_rolling` 5 / 15 的窗口斜坡。同时必须跑**单调版对手**
   `cross_mean(day_std(in_slice(Ret,2,237)), 30)`——它是已知族在收益上的孪生兄弟,如果它一样好,这条因子就"是已知的波动暴露"。
2. **换折叠中心**:截面中位数 / 对数空间 / 秩中心 / 缩尾后的均值(当前中心在第 65.6 百分位,是被右尾拖上去的)。
3. **用机制替掉折叠**:低侧那道坡实测几乎全是一字板,所以"做多低波动 + 用 `day_flat_ratio` / `day_zero_ratio` 把冻结盘口票排除"
   (`cs_last_high20`)应该能复现折叠的效果而且更可解释。
4. **按规模 / 流动性 / 价格分桶做中性或分段**(`cs_bucket_rank`、`cs_first_*`、`cs_last_*`;长窗 241 日均成交额当"规模"代理,
   短窗 20 日当"换手"代理,两者在解剖里给出相反的答案,必须分开试)。
5. **重做已知族的 overlay / 残差 / 桶内排名,底座换成稠密族**。
6. **顺着"粗糙度"的互换性**:量变化率的折叠、成交额加权的 `|Ret|`、两种折叠的秩相加;以及三条大胆的新机制
   (`day_centroid(Amt)` 资金在一天里的位置、`day_signed_ratio(Ret, Amt)` 净买入代理、按当天截面离散度给 EMA 加权)。

## 6. 工具问题

- `cs_bucket_rank` 在根上必然触发 `dist ≥ 0.5` 门槛(dist 0.20),因为十个桶的百分位取值互相重合;
  第二批里同时给了"加一个 0.001·cs_rank 打破并列"的版本,但这是绕路,建议把 `distinct_fraction` 改成按日**排名**的离散度。
- `abl_*` 这一类"删节点"在触发型算子上会产生**语义意外**:`abl_G` 删掉 `is_gt` 之后掩码变成"恰好等于 1",
  `abl_I` 删掉 `in_sustain_stddev` 之后根是 0/1 掩码(dist 0.01),`abl_A` / `abl_H` 直接因分钟轴宽度 236 vs 241 报错。
  这三类都该在扫描表里标出来,否则容易把它们当成"干净的消融"读。
- 半衰期网格上限 20 对这一族是**边界解**(稠密族全部选到 20),所以"再长会不会更好"只能靠在表达式里写 `cross_ema/cross_mean` 绕开。

## 第二轮(s2)对账与结论

149 个变体(`runs/F101_day_shine_retstd/sweep_s2.json` + `anatomy_s2`),只用 train 2018–2021 / valid 2022–202308。
新门槛:`k_known_xfrozen = cs_last_high20(neg(k_known), cross_max(day_zero_ratio(Ret), 15))` +16.4 / +23.2 / **+18.5%**,
Lshp **2.81 / 3.98 / 3.15**,LTO 3.4% —— 已知族剔掉冻结盘口,比 `k_known` 整体高 0.9 个夏普。本因子没有任何用法越过它。

### 1. 对账(s1 的每条推论)

**支持**
- 折叠不可替代(s1 §2)。对手假设 `h_rv_mono_mean30`(单调日内波动 30 日均)**−7.4 / +1.5 / −4.8%,Lshp −0.91 / +0.21 / −0.61**。
  两条"用机制替掉折叠"也塌:`h_rv_neg_screen_flat` −0.15、`h_rv_neg_screen_zero` −0.35(ut)。
  ⇒ 低波动侧那道坡**不是**一字板 + 清淡票;折叠是真实的非单调结构,不是"已知的波动暴露"。
- 信息在持久的截面水平里(s1 §2)。伪证实验 `h_rv_own_rel_fold`(除自己 60 日均)0.39 / 1.37 / **0.69**,按预测塌掉。
- 阈值退化族的规范写法一致:`h_gate_dvpos`(Δ>0,约一半分钟)+9.4 / +10.9 / **+9.9%**,2.28 / 2.90 / **2.45** ≈ `abl_F` 2.44。
- "被测量必须是尺度不是形状":`h_posratio_fold`(只看上涨分钟占比)1.61 / 2.03 / 1.71,dist 0.03 ✗(折叠后只有 236 个取值,大量并列)。

**否定**
