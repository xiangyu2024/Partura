### 自己写的分析 `studies/F101_day_shine_retstd/look.py`:折叠之前的量 `J` 和折叠本身

现成诊断看的都是折叠之后的面板。这棵树的问题在折叠**之前**:`J` 是什么、收益对 `J` 长什么样、折叠改了谁的排名。
下面的数字都来自这个脚本的输出(`logs/F101_day_shine_retstd_look.log`),只读 train / valid;
书的口径与表一致(`partura.books.book_row`),半衰期固定为 10、方向固定为「折叠量越小越好」。

**A. 读对了没有。** `|J − nanmean_cs(J)|` 与引擎算出的原式面板逐格一致(最大差 6.6e-9,rank 相关 1.0000)。

**B. `J` 的截面。** 每天约 3607 只有值;有标签的格子里 99.91% 有值;`J == 0` 占 0.47%(全天分钟收益为 0 的一字板)。
截面均值落在 `J` 的 **第 65.6 百分位**(逐日 58.5%~71.9%):右偏,所以「离均值最近」的票其实是偏高波动的。
`J / 均值` 的分位:p1 0.33、p10 0.53、p50 0.85、p90 1.56、p99 3.54 —— 低侧最多离均值 1 倍(`J = 0`),高侧没有上限。
每股票-日的触发次数:p1 = 5、中位 20、p99 = 32;≤ 2 次的只有 0.10%。**H7(触发太少的小样本伪影)不成立。**

**C. `J` 是不是日内波动。** `J` 与 `day_std(Ret)` 的日截面 rank 相关 +0.902,与全部分钟的滚动 5 分钟 std 均值(`roll5`)+0.850
(后两者之间 +0.926)。折叠之后:原式与 `fold(ivol)` 0.738、与 `fold(roll5)` 0.625;平滑之后的交易信号与
`−EMA10(fold(ivol))` 0.865。**折叠之前九成是日内波动,折叠再平滑之后仍有七到八成** —— 但不到 0.95,掩码不是纯装饰(见 S1)。
(修订:把掩码换成不含 Volume 的 `|Ret|` 激增事件,交易信号与原式的相关是 0.889、书分不开 —— 「不是纯装饰」的是把统计量压到大波动分钟上这件事,不是成交量,见 `SR_rivals`。)

**D. 空头腿是谁。** 交易信号最差的 10% 里,低侧(`EMA10(K) < 0`)只占 5.6%(train)/ 2.8%(valid)。
**空头腿 94%~97% 是持续高 `J` 的票**;按特征看(G 段):`EMA10(J)` 平均在第 90 百分位、换手率第 80、20 日波动第 82、
市值第 40。标签 NaN 占 3.0%(全体 1.5%)、当天 `J == 0` 占 2.2%(全体 0.47%)。
**(修订)** 这里原来据此写「H5 不成立,它就是高波动高换手的热门票」—— 那是按人头否掉的。按收益贡献(`audit_1.py` C、`rev_look.py` B):
人头 2.2% 的当天一字板票给了空头腿的 13%,5 日内有过一字板的票(人头 6.9%)给了 26%(valid:6% / 15%);标签 NaN 的票确实不重要(+0.2 个点)。H5 是「部分成立」。

**E. 收益对 `J` 是不是驼峰**(20 分位,年化超额 %,从低到高):

```
J 当天值    train: -41  -1  -1  +5  +4 +10  +9 +10  +6  +8 +10 +10 +11 +10  +9  +7 +11  +4  -8 -74
J 当天值    valid: -13  +8  +8  +6 +12  +9  +9 +11  +8 +10 +10  +6  +5  +7  +3  +2  +1  -4 -12 -83
EMA10(J)   train:  -9  -1  +4  +6  +8  +8  +7  +8  +9 +10  +9  +8  +9  +5  +6  +1  -2  -8 -19 -59
EMA10(J)   valid:  +1  +8 +12 +14  +9 +11 +12 +10  +8  +6  +5  +3  +6  +4  -5  -2  -1  -9 -21 -70
```

不是「峰在均值」的驼峰,而是**一块平台加两道悬崖**:最高的 5%~10% 是深渊(−59 … −83),当天 `J` 最低的 5% 在 train 上
也很差(−41%,一字板 / 准停牌的票次日的逆向选择),中间十几档是平的。
(修订:低侧这道「悬崖」实测几乎全是一字板日 —— 剔除 `J == 0` 的格子后,当天 `J` 最低 5% 是 train −9%、valid −1%,见 `rev_look.py` B。
应读成「高侧悬崖 + 低侧浅坡」,一字板日是另一类东西。)平滑之后低侧悬崖基本消失(train −9%、valid +1%),
而且 **valid 上是单调的**:越低越好,最好的在第 3~4 档(+12%、+14%),不在均值(第 13~14 档)。
所以 H3(「适度最好」)只在 train 上勉强成立、valid 上不成立;H2(「只是高波动差」)对空头腿成立。

三件事:

1. **H4 成立,而且比预想的强**:先平滑后折叠把多头腿净超额从 +9.0% 打到 −9.5%,换手反而从 8.4% 升到 14.5%。
   原因是 `|EMA(K)|` 最小的那 10% 是「平均下来恰好在均值」的票,其中大量是 `K` 来回换号的;而 `EMA(|K|)` 小要求
   **最近每一天**都离均值近。交易信号的多头腿 = 「波动水平适中 **且** 相对位置稳定」
   (修订:这句话在原式上只有 train 的证据;valid 上原式的多头十分位不比平台等权好,见 `audit_1.py` B、`rev_look.py` C)。只留不稳定度那一项有 rank IC
   (+0.027 / +0.032)但没有多头腿。两项单独都做不出原式的多头腿,合起来才有。
2. **不折叠的 rank IC 更高、书更差**(+0.047 vs +0.039,多空夏普 +1.34 vs +4.21):单调版的多头腿是「`J` 最低的 10%」,
   正好踩在低侧悬崖上。折叠的作用不是「适度最好」,而是**把两道悬崖都放进空头、把多头腿从悬崖边挪到平台上**
   (修订:低侧那一道主要是一字板日,见 E 段的修订注)。
3. `fold(ivol)`、`fold(roll5)` 在这张表里已经和原式差不多(多空略低,valid 多头腿明显更好)—— S1 用正式口径复核。

**H. 折叠中心在哪最好**(排名折叠 `−EMA10(|pct(J) − q|)`):多头腿净超额 train 在 q = 0.6 最高(+7.1%)、valid 在 q = 0.3 最高
(+6.2%);多空夏普在 q = 0.5 最高(+3.39 / +3.29)。**最佳中心在两段上不一致**(train 偏高、valid 偏低,与 E 段一致),
所以「挪中心」不是一个站得住的改进方向。

**I. 触发次数。** 触发次数自己当因子很弱(rank IC +0.0165 / +0.0020)。交易信号的 rank IC 在触发次数最少的三分之一
(平均 13 次)是 +0.054 / +0.052,最多的三分之一(平均 26 次)是 +0.030 / +0.017 —— 成交量越「一阵一阵」的票信号越强。
