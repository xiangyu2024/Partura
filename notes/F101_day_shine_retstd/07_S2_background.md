**解读**

1. **价格水平 / 报价单位的嫌疑被杀死**。`s2_fold_logprice` 没有任何信号(方向都定成了 +,多空 −0.14 / −1.43),
   与背景波动折叠的 rank 相关 0.02;背景波动折叠在价格五档里的条件 IC 是 −0.018 / −0.020 / −0.022 / −0.020 / −0.010,
   除了最高价一档偏弱之外没有集中在低价股。
2. **切片多余**:不切片的版本与切片版 rank 相关 0.99,多空 +3.00 / +3.16 对 +3.19 / +3.33、多头净 +8.5% / +10.1% 对 +9.1% / +10.4%,
   两段都略低一点但在噪声内。开盘两格和收盘集合竞价三格不携带这条因子的信息。
3. **不折叠同样不行**:`s2_roll5_nofold` 的 rank IC 更高(+0.0282 / +0.0442)而书是空的(多空 +0.22 / +1.14),
   十分位剖面 train 两头为负(Q1 −15.0%、Q10 −7.9%)。和 S1 对事件版 `J` 的结论一样:**折叠是这条因子里唯一不能拿掉的节点**。
4. **窗口阶梯在 train 上是平的**。3 / 5 / 15 / 60 / 1(绝对值)的 train 多空夏普 +3.17 / +3.19 / +3.11 / +3.13 / +3.01,
   多头净 +8.7% / +9.1% / +7.4% / +7.2% / +7.8%。表里 valid 多头净 +9.5% / +10.4% / +7.5% / +3.4% / +4.2% 的落差
   **有一部分是半衰期造成的**:窗口 3、5 选了半衰期 20(换手 4.0%),15 / 60 / 1 选了 10(换手 6.7%~7.4%)。
   把半衰期统一到 20,train 多头净是 +8.7% / +9.1% / +8.9% / +8.4% / +8.7%(各变体 `books.sweep` 里 hl=20 那一行)——
   统计量之间在 train 上没有差别。valid 上按同一个半衰期比的结果见 `07x_look3.md` A 段:差别主要来自**折叠中心落在哪**,
   不是「背景」对「爆发」。S1 里「放量掩码对多头腿有害」的说法因此要收窄(见 `07x_look3.md`)。
5. **(修订)「爆发比」是一个单调的空头信号,但不是放量掩码独有的**。`s2_burst_ratio`(放量时刻波动 ÷ 背景波动,无量纲)自己的 rank IC
   +0.0285 / +0.0415,最差一档 −46.6% / −40.3%,多头腿只占毛价差的 8%;它与换手率、日内振幅的 rank 相关 +0.30 / +0.40
   (`look2.py` C 段)。原式比背景波动折叠多出来的那半条空头腿与它同向。这部分对纯多头没有用(多头净 train −1.2%)。
   这一条原来的标题是「放量掩码独有的内容」,并且写了一句对成交量的因果解读。这一阶段没有任何不含 Volume 的对照,那两处没有依据:
   `SR_rivals` 里不用 Volume 的 `Jret ÷ roll5` 和完全不用掩码的「全天 std ÷ roll5」是同样强的单调空头信号
   (rank IC +0.0272 / +0.0359、+0.0282 / +0.0459,最差一档 −48.6% / −44.2%、−45.8% / −42.7%),而 `J ÷ Jret` 没有信号。
   这个比值量的是**日内波动集中在少数几分钟里的程度**,用成交量去找那几分钟只是其中一种找法。
6. **背景波动折叠的多头腿不随年份衰减**:逐年多头腿毛超额 8.5% / 15.0% / 15.3% / 13.5% / 15.7% / 9.8%(2018–2023);
   原式是 16.1% / 18.7% / 21.5% / 11.4% / 5.2% / 4.9%。原式在 2018–2020 更好,2021 起明显更差 —— 分界在 2021,不在 train / valid 的边界上。
7. `s2_roll5_rankfold`:多头净 +7.7% / +9.8%、多头腿占 42%(空头腿只有 +17.0% / +14.2%),`dist` 0.87 过门槛。

**对假设的影响**:价格水平嫌疑死;H1 当时定稿为「事件机器对多空价差有贡献(单调的空头信号),对多头腿没有贡献」(修订:有贡献的是「大波动分钟附近的局部波动」,与用不用 Volume 无关,见 `SR_rivals`);
H9 的候选落在「背景波动 / 日内波动的折叠」这一族上,但它的 valid 优势需要拆开看(`07x_look3.md`)。
