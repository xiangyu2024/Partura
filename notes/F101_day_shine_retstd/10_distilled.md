### 读留出段之前定下的候选与理由(只凭 train / valid)

**提纯的结论**:12 个中间量里,预测力只需要其中 5 个算子 ——

```
abs_(cs_demean(day_mean(in_stddev_rolling(in_slice(Ret, 2, 237), 5))))        # 「背景波动」的均值折叠
```

放量掩码(`A..G` 七个节点)、触发型的 `in_sustain_stddev` 都可以拿掉;连 5 分钟窗口也不是必需的(窗口 3 / 5 / 15 在 train 上等价,
全天 std 的折叠 `abs_(cs_demean(day_std(·)))` 在 train 上的多头腿一样好)。**唯一不能动的是「截面折叠 + 折叠之后再平滑」**。

**升华的结论**(用户口径的目标是纯多头):没有找到比「背景波动折叠」更好的写法。试过而没有一致改进的:
换时间聚合(20 / 40 日均值、20 日最大值、研报的月均 + 月稳、均方根)、把半衰期拉到 40 / 60、挪折叠中心、对数空间折叠、
把事件版与背景版排名相加、用爆发比过滤多头(全部在 `07x_look3.md`)。所以升华版 = 提纯版。

**送去读留出段的 5 个候选**(决策口径:方向与半衰期在 train 上定):

和 `dist ≥ 0.5`(均值折叠 1.00、排名折叠 0.87)。

**事前写下的读法**(读完不改候选、不改这段话):

- 推荐 `f_roll5` 的依据是多头腿:train 持平(+9.1% 对 +9.0%)、valid 高 12 个点、纯多头夏普两段都更高、换手减半。
  它**不**在多空夏普上占优(train 3.19 对 4.21),因为它放弃了原式里放量掩码带来的那半条空头腿 —— 对纯多头的使用者这不是损失。
- 这个推荐押在「2021 年之后收益对波动水平的剖面向低波动倾斜」会延续上。**如果留出段里 `f_orig` 的多头腿净超额和纯多头夏普不低于 `f_roll5`,
  升华就没有被样本外支持,结论改为保留原式;如果所有候选的多头腿净超额都不为正,结论是这一族的多头腿不稳健。**
- 预期多空夏普仍然是 `f_orig` 最高(它的空头腿最强)。留出段约 580 个交易日,多空夏普的噪声约 ±0.3、多头腿净超额约 ±3 个点,
  小于这个幅度的排序不读。

### 留出段读出来的结果(读了一次,`runs/F101_day_shine_retstd/final.json`;以下写于读之后,上面的文字没有改)

用户口径:方向与半衰期在用户训练段(2018-01 ~ 2023-08)上定,测试段 = 2023-08 ~ 2025-12(581 个交易日)。数字见上面的「最终对比」表。

1. **原式被复现,而且很稳**。多空夏普 +3.93 / +3.70、多头腿毛超额 +13.6% / +12.0%,与用户表公布的 3.93 / 3.7、13.6% / 12% 一致;
   多头腿净超额 +6.0% / +6.0%、纯多头夏普 +1.33 / +1.32,训练段和测试段几乎是同一个数。
2. **升华没有被样本外支持**。事前推荐的 `f_roll5` 测试段多头腿净超额 +6.6%、纯多头夏普 +1.41,原式是 +6.0%、+1.32 ——
   差 0.6 个点和 0.09,远小于事前写下的噪声幅度(±3 个点)。valid 上 12 个点的优势没有延续:逐年看,原式的多头腿净超额在
   2024 / 2025 年回到 +8.9% / +5.0%(`f_roll5` 是 +9.9% / +3.6%)。**原式多头腿的失效只发生在 2021–2023 年**,
   不是一个可以外推的制度;「背景版的多头腿更好」是把那三年当成了规律。按事前写下的读法,结论是**保留原式**。
3. **原式在多空夏普上的领先是真的**:测试段 +3.70 对 `f_roll5` 的 +2.97(差 0.73,大于噪声),空头腿毛超额 +52.2% 对 +31.3%。
   **(修订)** 这里原来写的是「放量掩码带来的那个单调空头信号(爆发比)样本外仍然有效」。空头腿多出来这件事在样本外是真的,但把它归给放量掩码是错的:
   train / valid 上把掩码换成不含 Volume 的 `|Ret|` 激增事件,空头腿和多空夏普与原式分不开(`SR_rivals`:+3.87 / +3.12 对 +3.65 / +3.04,同一批格子);
   完全不用掩码的「全天 std ÷ 滚动 std 均值」也是同样强的单调空头信号。原式不能被 5 个算子的背景版替代的那部分是「大波动分钟附近的局部波动」,不是 Volume 字段。
   不用 Volume 的版本没有读留出段,所以「样本外仍然有效」这句话只对原式自己成立。相对 4 个算子的 `f_ivol`,原式测试段多空只高 0.28(在噪声内),空头腿 +52.2% 对 +41.3%。
4. **最朴素的等价物在测试段与原式不可区分**。`f_ivol`(`abs_(cs_demean(day_std(·)))`,4 个算子)测试段多空 +3.42、多头净 +6.6%、
   纯多头夏普 +1.43,三项与原式的差(−0.28、+0.6 个点、+0.11)都在噪声内;它与 `f_roll5` 的多头腿打平(+6.6% 对 +6.6%)、多空夏普更高(+3.42 对 +2.97)。
   所以 **`f_roll5` 在 valid 上相对 `f_ivol` 的优势是运气**(事前写下的判据:「若是运气,留出段里两者应持平」),5 分钟滚动窗口没有独立的价值。
5. **(修订)两个排名折叠版测试段的多空夏普最低,但差别来自 2024 一年、只在空头腿上**。`f_roll5_rank` 测试段多空 +1.63、`f_j_rank` +2.33(训练段 +3.19、+3.60)。
   逐年:2024 年它们的多空夏普是 −0.07 和 +0.82、空头腿毛超额 −5.3% 和 +3.7%;其余年份排名折叠不差 —— `f_j_rank` 对原式 2018–2025 是
   2.97 / 4.49 / 4.38 / 2.89 / 4.43 / 3.04 / 0.82 / 3.78 对 4.83 / 5.50 / 3.78 / 3.19 / 3.73 / 2.81 / 3.68 / 3.80(2020、2022、2023 年更高,2025 年打平),
   `f_roll5_rank` 对 `f_roll5` 在 2020、2021、2023、2025 年更高。所以「样本外更差」的样本量是 1 年。
   用户真正交易的**多头腿**上两种折叠在测试段不可区分:净超额 +5.7% 对 +6.6%、+5.0% 对 +6.0%,差 0.9 / 1.0 个点,小于事前写下的 ±3 个点(「小于这个幅度的排序不读」)。
   原来这里写的「多头净也低于各自的均值折叠版」违反了自己事前定的读法,删去;原来写的「排名折叠把最低波动的 5% 也放进空头,2024 年这一端大涨」是**推断**:
   train / valid 上量到的是排名折叠的空头十分位四到六成人头在低侧、这一半的贡献从 2018 年的 +10 ~ +11 个点缩到 2023 年的 0 ~ +1(`rev_look.py` A),
   2024 年转负与这个趋势相容,但没有直接拆分过(在留出段里,不能再读)。
   2 × 2 读下来能说的只有:valid 上「原式的问题在折叠、换成排名折叠就好」那个读法(`07x_look3.md` A 段第 3 点)没有被样本外支持;
   「均值折叠更好」同样没有被支持到可以当规律的程度。

**最终结论**

- **推荐:保留原式**(`recommended_kind = original_kept`)。没有任何候选在测试段的多头腿上超出原式一个噪声幅度,而原式的多空夏普比两个均值折叠的简化版高 0.3~0.7、比两个排名折叠版高 1.4~2.1
  (**修订注**:对 `f_ivol` 的 0.28 在事前写的 ±0.3 噪声内;对排名折叠版的 1.4~2.1 来自 2024 一年)。
- **提纯的结论成立一半**:这条因子的内容是「日内波动水平的截面均值折叠 + 折叠后平滑」。4 个算子的 `f_ivol` 在测试段的三项指标上与原式不可区分,
  训练段多头腿更好(净超额 +7.0% 对 +6.0%、纯多头夏普 +1.89 对 +1.33)、多空夏普低 0.46、换手 6.6% 对 8.1%。
  只做纯多头、又在意表达式简单的使用者可以拿它当等价物;但它不是「更好」,只是「更小」。原式多出来的 8 个节点买到的是空头腿(训练段 +52.7% 对 +41.1%)。
- **不要做的事**:不要因为 valid 上多头腿好看就换成背景波动版。**(修订)** 原来还有一句「不要把均值折叠换成排名折叠」,现在收窄成:
  排名折叠有**单年空头腿归零的尾部风险**(2024 年,一次观测),这只对做多空的人有意义;对只做多头的使用者,两种折叠在测试段分不开。
- **(修订)对原式的定性**:它是「日内波动水平的截面均值折叠 + 折叠后平滑」,F001「日内波动 + 极值记忆」族的近亲;相对 4 个算子的朴素版,
  它多出来的是空头腿(事件条件化的局部波动,不依赖 Volume),其中一部分来自一字板附近的票(去掉当天 `J == 0` 的格子,train / valid 多空夏普 +4.21 → +3.65、+3.21 → +3.04)。
  它的多头十分位在 2022、2023 年不比「波动水平在第 10~80 百分位的全部股票等权」好;测试段 +6.0% 的多头净超额里有多少是挑选出来的,没有量(未决)。
- 一条旁证(不改变结论):如果半衰期按纯多头夏普在训练段上选(五个候选都会选 20),测试段多头净 / 纯多头夏普是
  `f_orig` +7.1% / +1.40、`f_ivol` +8.0% / +1.66、`f_roll5` +7.0% / +1.40(`final.json` 的 `splits_at_hl_long`)—— 仍然在噪声内。
