### 自己写的分析 `studies/F101_day_shine_retstd/look3.py`:多头腿是什么做成的

S1 / S2 把「原式 → 背景波动折叠」的多头腿改善归因于「背景波动比爆发波动稳」。但这两者之间同时变了三样东西:
统计量(`J` → `roll5`)、折叠中心落在哪(`J` 的截面均值在它的第 65.6 百分位,`roll5` 的在第 59.3)、选出的半衰期(10 → 20)。
这个脚本把三样拆开,再问「先折叠后平滑」到底在为什么付钱。数字来自 `logs/F101_day_shine_retstd_look3.log`,只读 train / valid;
书的口径与表一致(其中「`roll5` 均值折叠 hl20」「`J` 均值折叠 hl10」两行与正式表里的 `s1_fold_roll5`、`v_base` 逐位相同)。

**A. 固定半衰期的配料表**(多头腿净超额 train / valid;括号里是扣费多空夏普):

| 统计量 | 均值折叠 hl10 | 均值折叠 hl20 | 排名折叠(中心 0.5)hl10 | 排名折叠 hl20 |
|---|---|---|---|---|
| `J`(放量时刻) | +9.0% / −1.6% (4.21 / 3.21) | +9.4% / +1.3% (3.76 / 3.16) | +4.8% / +3.4% (3.39 / 3.29) | +7.5% / +7.1% (3.64 / 3.46) |
| `ivol`(全天 std) | +8.6% / +3.8% (3.63 / 3.32) | +9.5% / +6.4% (3.41 / 3.23) | +5.8% / +7.9% (3.14 / 3.49) | +7.6% / +11.0% (3.35 / 3.56) |
| `roll5`(背景) | +7.5% / +7.8% (3.15 / 3.48) | +9.1% / +10.4% (3.19 / 3.33) | +4.8% / +7.8% (2.69 / 3.29) | +7.6% / +9.8% (3.08 / 3.42) |

三件事:

1. **train 上多头腿与统计量无关**:半衰期 20 时均值折叠是 +9.4% / +9.5% / +9.1%,排名折叠是 +7.5% / +7.6% / +7.6%。
   放量掩码、5 分钟窗口对 train 多头腿的贡献是零。
2. **半衰期 10 → 20 给多头腿净超额加 0.4~3 个点**(纯粹是换手省下来的成本),原式在 valid 上从 −1.6% 回到 +1.3%。
   表里按各自选出的半衰期比较变体,会把这一项算到统计量头上。
3. **valid 上的差别主要是折叠方式造成的**:均值折叠 +1.3% / +6.4% / +10.4%,统计量的尾巴越重越差;
   换成排名折叠就是 +7.1% / +11.0% / +9.8%,三者拉平(`J` 仍低 3 个点左右)。所以原式 valid 多头腿的 12 个点落差大致是:
   半衰期约 3 个点 + 「重尾统计量的均值折叠」约 6 个点 + 统计量本身约 3 个点。**S1 里「放量掩码对多头腿有害」要收窄成
   「放量掩码让 `J` 的右尾更重,把均值折叠的中心推到第 66 百分位,而 2021 年之后那个位置不再是好位置」。**

**B. 折叠中心放在哪**(`roll5`,半衰期 20;多头净 train / valid):

| 排名折叠中心 q | 0.3 | 0.4 | 0.5 | 0.6 | 0.7 |
|---|---|---|---|---|---|
| 多头净 | +3.3% / +11.5% | +5.5% / +9.3% | +7.6% / +9.8% | +8.3% / +9.9% | +8.0% / +8.8% |
| 多空夏普 | 0.89 / 2.00 | 1.50 / 2.03 | 3.08 / 3.42 | 2.02 / 1.52 | 1.56 / 0.83 |

| 水平折叠中心 = c × 截面均值(所在百分位) | 0.70(0.20) | 0.85(0.40) | 1.00(0.59) | 1.15(0.74) | 1.30(0.84) |
|---|---|---|---|---|---|
| 多头净 | +1.8% / +5.6% | +6.6% / +10.7% | +9.1% / +10.4% | +9.1% / +6.7% | +8.1% / +4.2% |

中心在第 50~60 百分位时两段都好;往左挪 train 塌(低波动端在 2018–2021 是差的),往右挪 valid 塌。
`EMA20(roll5)` 的 20 分位剖面说的是同一件事 —— train 是一块平台加两道悬崖,valid 是向低波动倾斜的:

```
train: -15  -1  +1  +1  +4  +5  +4  +5  +5  +4  +5  +3  +3  +2  +1  +3  +1  -3  -9 -21
valid:  -3  +5  +7 +12  +9  +9  +6  +5  +5  +6  +3  +2  -1  -2  -1  -1  -8 -11 -11 -29
```

平台只有 +1%~+5%,而折叠的多头腿毛超额是 +13.1% —— **多头腿的大头不是「波动水平适中」挣来的**。

**H. 双重排序**(`roll5`;行 = `|EMA20 K|` 三分位,离中心近 → 远;列 = 不稳定度 `EMA20|K| − |EMA20 K|` 三分位,稳 → 不稳;年化超额,括号里是格子占比):

```
train:  +14.1 ( 0.7%)   +13.1 (10.3%)    -0.2 (22.8%)        valid:  +21.8 ( 1.1%)   +11.4 (10.0%)    -3.4 (23.2%)
         +9.3 (10.4%)    +6.6 (16.2%)   -15.4 ( 7.2%)                +11.9 (10.4%)    +7.5 (16.6%)   -11.2 ( 7.4%)
         -0.0 (22.7%)   -12.3 ( 7.4%)   -40.1 ( 3.8%)                 +0.2 (22.9%)    -8.3 ( 7.7%)   -45.6 ( 3.7%)
```

两个轴在每一行、每一列、两段数据上都是单调的:**离中心越远越差,相对位置越不稳越差**。`EMA(|K|) = |EMA K| + 不稳定度`
把两者一比一加起来,多头十分位就是左上角那一带(+13%~+14% / +11%~+22%),空头十分位是右下角(−40% / −46%)。
不稳定度单独做因子没有多头腿(`std20(K)` 多头净 −1.9% / +2.5%),因为「稳定」里混着一直很高的票;必须和「近」合起来。

**(修订)这个双重排序只在 `roll5`、半衰期 20 上做过** —— 那是后来被留出段否定的事前候选,不是被推荐的原式。审查员对原式(`J`、半衰期 10)重做(`audit_1.py` B):
train 成立;valid 上多头十分位所在的那一带没有梯度,多头十分位 +5.7% 对它所在的平台等权 +6.6%。「两个轴各自单调、两段一致」只对 `roll5` 成立,不能套到原式头上。

多头净 +9.0% / +9.9%、+8.7% / +9.1%,换手 2.3% / 1.7%,多空夏普逐步下降 —— 半衰期 20 不是卡在网格边界上的次优解。

**D. 「适中且稳定」是不是任何变量都行**(把同样的均值折叠套在每个控制变量上,口径同表):

| 被折叠的变量 | 方向 | 多空 tr / va | 多头净 tr / va |
|---|---|---|---|
| 日内波动 `ivol` | − | 3.63 / 3.32 | +8.6% / +3.8% |
| 20 日日频波动 | − | 3.08 / 1.70 | +8.5% / +0.0% |
| 换手率 | − | 3.05 / 2.27 | +8.4% / +1.4% |
| 日内振幅 | − | 3.19 / 2.55 | +9.7% / +1.3% |
| 20 日动量 | − | 1.32 / 2.28 | +3.6% / +4.1% |
| 当日收益 | − | 2.22 / 2.92 | −0.7% / +4.8% |
| 市值 / 成交额 / 价格 | + | 0.62 / −0.32,−2.06 / −2.78,−0.14 / −1.43 | — |

**在 train 上,任何「活跃度 / 波动」类变量折叠之后都有 +8.4%~+9.7% 的多头腿和 3 以上的多空夏普;规模、价格类变量没有。**
到了 valid,日频的那几个(20 日波动、换手率、振幅)多头腿归零,只有分钟级的波动统计量还留着。
对背景波动折叠的交易信号做中性化(train):9 个线性控制 R² 0.090;`EMA20(fold(ivol))` 一个变量 R² 0.796,残差 rank IC +0.0018、
无成本多空夏普 −2.59 —— **背景波动折叠完全落在「日内波动的折叠」里**;只用日频变量的 5 个折叠(换手率 / 20 日波动 / 成交额 / 市值 / 振幅)
R² 0.331,残差 rank IC +0.0113、无成本多空夏普 +0.02、多头腿毛超额 +4.7%(原 +13.1%)。

**E. 爆发信息对多头腿有没有用。** `rank(fold J) + rank(fold roll5)`:多空 3.65 / 3.28、多头净 +10.4% / +6.2%、纯多头夏普 2.81 / 1.78 ——
train 更好、valid 更差,不是一致的改进。把背景折叠的多头十分位按爆发比对半分:低 / 高一半的年化超额 train +9.0% / +18.1%、valid +19.1% / +7.8%,方向相反。
按市值对半分则是一致的:小的一半 +17.5% / +23.6%,大的一半 +8.5% / +3.4% —— **多头腿的超额集中在十分位里市值偏小的那一半**(容量风险,见 `11_risks.md`)。

但也意味着「背景折叠的多头腿更好」这个结论是押在 2021 年之后的制度上的。
