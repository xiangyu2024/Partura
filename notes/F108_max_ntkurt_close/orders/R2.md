# 工单 R2(kind: experiment)

## 想回答的问题

**只有一个问题:§A3 那点多头增量是真的,还是三种廉价解释之一。**

R1 的 §A3 发现:在秩空间上把已知家族 `K1 = cross_mean(day_std(Amt),30)` 和 F108 的日轴记忆
`D30 = cross_mean(原式,30)` 按 **1 : 0.25** 相加,**两段都赢过家族单独** ——
Lnet +15.1%/+23.8% 对 +12.6%/+22.3%,Lshp +2.30/+3.87 对 +1.78/+3.46,而且双方半衰期都是 0
(`@famHL0` 对照行逐位相同,所以不是半衰期的功劳)。

这是整条研究里唯一一条「对只能做多的用户有增量」的证据。但它有三个**事前判据没有覆盖**的疑点,
任何一个成立,推荐就要降级或撤回:

| 疑点 | 对应假设 | 哪组变体去打 | 看到什么算它成立(= H11 被否定 / 降级) |
|---|---|---|---|
| ① 它只存在于自写脚本的秩空间里,不是一条真能跑的表达式 | — | `g_w25` | 配置里跑出来的 hl0 读数复现不了 +15.1%/+23.8%(差 >0.5pp)→ §A3 不可信,H11 回到**未决** |
| ② w=0.25 是网格上的一个尖峰,不是平台 | **H18** | `g_w15` / `g_w40` + `x3_attrib` §D | 只有 0.25 一档赢,0.15 和 0.40 掉到家族线(+12.6%/+22.3%)以下 → **H11 被否定**(靠单点权重才出现的 +2pp 不能推荐) |
| ③ 温和掺入**任何**弱相关第二信号都能抬高家族的书 | **H17** | `p_k2` / `p_ivol` / `p_cap` | 任一安慰剂的增量 ≥ `g_w25` 的增量 → **H11 被否定**,F108 不配拿这份功劳 |
| ④ 增量主要是「买不进记 0」的记账效应 | **H16** | `x3_attrib` §A | 把标签 NaN 的票从两本书里都剔掉、各自重新归一之后,增量塌到 ≤+0.5pp 或变负 → **推荐降级** |

④ 的道理要说清楚,因为它是这一轮最可能翻盘的一条:F108 的尾部就是一字板/封板(H6′ 已确立),
而口径里 t+1 开盘封涨停的票**标签是 NaN、在多头书里记 0 收益、同时被等权基准排除** ——
**持有一只买不进的票相对基准是净亏的**,所以任何封板探测器都会机械地抬高多头腿。
x1 §5 只在**空头腿**上量过这件事(+30.6% 对 +26.2%),上一轮据此写了「多头腿不受影响」——
那是对**单独使用**的 F108 说的(它多头腿本来就≈0),对一本**让 F108 主动剔票**的书完全不适用。
**没人在多头书上量过这件事。**

另外两条顺带的(不是判决性的,但报告需要):
- ⑤ **日轴记忆必须写在表达式里面吗**(`g_raw`):流水线只能给整条复合式**一个**半衰期,
  没法只平滑 F108 那一支。预期 `g_raw` 明显差于 `g_w25` —— 这是「`m_mean30` 这个升华为什么必须」的直接证据。
- ⑥ **H14 的形态能不能直接写进复合式**(`g_tail`):只罚 D30 最高的一档,不用它的完整排名。
  若不差于 `g_w25` → 推荐可以写成一条更简单的规则(「避开最差的 25%」)。

### 第 2 次运行:自写脚本 `studies/F108_max_ntkurt_close/x3_attrib.py`(tag `x3_attrib`)

**§A(最重要,放最前面)—— H16:「买不进记 0」能解释多少增量。** `train` / `valid` 各做:

1. 书 ①:`K1` 单独的多头书(前 10%,等权,方向 −1,hl=0);书 ②:`cs_rank(K1) + 0.25·cs_rank(D30)` 的多头书(同口径)。
   **先自检**:书 ① 的 Lnet 要对上 §A1 的 +12.6%/+22.3%,书 ② 要对上 §A3 的 +15.1%/+23.8%(各 ±0.5pp)。
   **对不上就先停下报出来**,后面的数不用算了。
2. 把**标签为 NaN(买不进)的票从两本书里都剔掉、各自重新归一**,再算一遍两本书和增量。
3. 再报四个数(train/valid 各一套):
   - 书 ② 相对书 ① **少持有**的票里,标签 NaN 的占比;
   - 书 ① 持有而书 ② 不持有的那些票的**次日平均超额**,用 `st.target(buyable=False)` 的真实收益,**分 NaN / 非 NaN 两组**;
   - 书 ② **新持有**的票的同样两个数。
4. 判据:剔掉 NaN 之后增量仍有 **≥ +1pp 且两段同向** → H16 死,增量是真的;
   **≤ +0.5pp 或变负** → H16 成立,推荐降级,照实写。

**§B —— 增量的来源分布。** 书 ② 对书 ① 的日度超额差,按两种切分累计(train/valid 各一张表):
- 按 `D30` 的**当天十分位**:被剔掉 / 被新纳入的票主要落在哪几档;
- 按 `r = BASE^(1/3)` 的**当天读数**分档(`[0,6)`、`[6,10)`、`[10,15)`、`[15,20)`、`[20,24.9)`、`[24.9,26)`),
  并直接量一个数:**「只用 r ≥ 24.9 这一档去罚」能拿到总增量的百分之多少** ——
  回答「用户是不是只要避开一字板就够」。

**§C —— 逐年。** 书 ①、书 ② 的多头腿净超额与纯多头夏普,按日历年(2018…2023)各一行,外加**增量**那一列。
判据:增量若只来自 1~2 年 → H11 降级为「合理但未坐实」,写进 `11_risks.md`。

**§D(便宜,放最后)—— 权重曲线细网格。** w ∈ {0, 0.1, 0.15, 0.25, 0.4, 0.6, 1.0} 各算一次书 ②,
报 Lnet / Lshp / LTO(train/valid)。这是 §A3 单峰曲线的细网格版,确认峰位和平台宽度。
**只用 train 选 w;valid 只作确认、不参与选择。**
