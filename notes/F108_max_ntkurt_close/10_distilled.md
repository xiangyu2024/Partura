**为什么第一推荐是 `z_over25`,而不是更强的 `z_fam2`:** 因为问的不是「哪本书最好」,而是

`z_fam1u` +13.9/+22.3、`z_fam2` +13.6/+22.0)高,是唯一通过了全部三道反驳(H16 记账 / H17 安慰剂 / H18 权重尖峰)的候选。

### 不进留出段的东西,以及为什么

- **`n_pow3`(提纯结果,`day_max(pow_3(nt_ts_kurt(Close,30)))`)**:对原式秩相关 1.000、头条差 ≤0.2pp。
  留出段不会给出和 `z_orig` 不同的数字,**提纯的结论不需要留出段**。省下的名额给判决性对照。
- **`m_mean30`(单独用的升华形态)**:+2.3%/+2.1%、Lshp +0.38/+0.42 —— 两段一致地「不可交易」。
  留出段无论给什么数都不会把 0.4 的夏普变成可用的书,**结论已定,不占名额**。
- **`g_tail`、全域筛子形态、H12/H13(窗口/字段)**:分别已被否定(+6.2%/+15.4%)、读不到留出段
  (`top_frac` 是配置全局的,见 `state.md` §8)、以及没有预算。

### 事前判据(留出段出现什么算被否定)

记号(都在**留出段**上):`Δ结构 = Lnet(z_over25) − Lnet(z_fam1u)`、`Δ部署 = Lnet(z_over25) − Lnet(z_fam1)`、
`Δ家族最好 = Lnet(z_over25) − Lnet(z_fam2)`;夏普同理记 `ΔLshp*`。
已测的对照值:`Δ结构` train **+1.2pp** / valid **+1.4pp**(`ΔLshp结构` +0.35/+0.41);`Δ部署` +2.5pp/+1.4pp;
`Δ家族最好` +1.5pp/+1.7pp(`ΔLshp` +0.34/+0.29)。

- **判据 1(主判据,决定推荐)。** `Δ结构 > 0` **且** `ΔLshp结构 > 0` → **过**:三段同号成立,第一推荐 `z_over25` 保留,
  结论写「叠在已知家族上有**小幅**增量(train +1.2pp / valid +1.4pp / holdout 实测),用法是给家族的书做 0.25 权重修正」。
  `Δ结构 ≤ 0` **或** `ΔLshp结构 ≤ 0` → **第一推荐被否定**,退回 `z_fam2`,结论写
  **「分辨清楚、提纯成功、对纯多头相对已知家族没有可靠增量」**。
  *(不设幅度门槛是有意的:x3 §C 的 2023 半年增量已经是 +0.0pp,留出段的现实预期就是零点几个点;
  +1.3pp 本来就落在用户给的 ±3pp 噪声带内,支撑它的是「同 universe、同半衰期、只差一个 0.25 权重」的**配对同号**,
  不是幅度。所以这里只检符号。)*
- **判据 1 的降级规则。** 若 `z_fam1u` 与 `z_over25` 在 train 上自选的半衰期**不同**(预期两者都是 hl0),
  配对不成立 → 主判据改用 `Δ部署`,并在报告里写明这处降级;**不许**拿自选半衰期的数冒充同半衰期对照。
- **判据 2(现实对照,决定「用法」怎么写)。** `Δ家族最好 > 0` → 可以写「对只能做多的用户,这条因子相对已知家族有增量」。
  `≤ 0` → 即使判据 1 过了,也必须写「增量只在 `cross_mean(day_std(Amt),30)` 这个成员上成立,
  家族里已经有更好的书(`cross_max(day_std(Amt),10)`),实际价值接近零」。
- **判据 3(原式)。** `Lnet(z_orig) < +5%` 且 `Lshp(z_orig) < +0.5` → 确认「原式单独对纯多头不可用」。
  若 `Lnet ≥ +8%` 且 `Lshp ≥ +1.0` → 这是**意外**,报告里必须写「留出段上原式本身突然可用,train/valid 的结论不成立」。
- **判据 4(底座是否还在)。** 若 `Lnet(z_fam1) < +5%` **且** `Lnet(z_fam2) < +5%`(train/valid 是 +12.6%~+22.3%)
  → 留出段上整个成交额家族失效,`Δ` 的符号是在一个塌掉的底座上测的 → 所有结论加「依赖风格」的限定,
  且不把 `Δ` 的符号当作可靠证据(判据 1 的结果照实写,但不升级为「已确立」)。
- **判据 5(复现自检)。** 五个变体的 train 行必须复现已测的数(±0.5pp):`z_orig` +0.3%、`z_fam1` +12.6%、
  `z_fam2` +13.6%、`z_over25` +15.1%、`z_fam1u` **+13.9%**(注意:是 x3 §D 的 `w=0` 行,**不是** `z_fam1` 的 +12.6% —— 
  universe 不同,这是预期不是 bug)。对不上 → 留出段的数不可信,报告里写明,**但不改推荐**。
- **门槛。** `cov ≥ 0.95`、`dist ≥ 0.5`;任一变体不过门槛,该变体的数不采用。

### 读完之后无论如何都要照实写的三件事

1. 结构增量用**配对口径**(+1.2/+1.4pp),头条 +2.5pp 只能作为「实际部署的两本书之差」出现并当场注明分解(H19)。
2. `z_over25` 对原式的秩相关只有 0.05~0.27 → 它**不是** F108 的提纯版,是已知家族的书加一点 F108。
   推荐的措辞只能是「F108 唯一可交易的用途是给已知家族的书做 0.25 权重修正」。
3. 权重写「0.15~0.4 之间都一样」,不写「最优权重 0.25」(H18 改写版)。
