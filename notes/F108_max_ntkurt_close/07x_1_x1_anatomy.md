   双峰分布 → 峰度**低**(探针:新水平持续 5 分钟就只有 1.20)。
   所以 `04_grammar.md` 里「孤立跳变探测器」这个说法要修:**它探的不是跳变,是「冻结盘口里的一个孤立价」**。
3. **多头端没有信息。** 排序最低的那一端(r ≈ 2)只拿到和中间档一样的 +7.5,而它是 10.1% 的格子。
   这解释了基线里多头腿为什么只有 +0.3% / +2.5%:**因子的多头端不是「好票」,只是「没触发警报的票」**,
   而「没触发」在这个全体里不带超额。

**解读:H8 要改写。** 合成数据上「fold-active 占比随价格单调下降(99% → 16%)」在真实数据上**不成立** ——
真实数据里它是 U 形(0.215 / 0.115 / 0.114 / 0.123 / 0.156)。真正的 EPS 伪影指标是 `Kmin < −2.5`

所以:尺度污染存在、可定位、但不是这条因子的主要机制;伪影只污染最便宜那一档约 9% 的格子。

   这是 H11 预言的那个方向:**在低成交额波动的多头池里,「上过一字板的票」明显更差。**
2. **但「剔除」能拿到多少,比条件剖面小得多。** 用打印出来的格子均值自己算一遍(**我的算术,不是读数,R1 要正式量**):
   家族多头十分位,剔掉落在 F108 底部五分位的 94/350 只(它们只有 +9.3)→ 其余 256 只约 +20.1,
   相对池 +17.2 是 **+2.9 个点(train)**;valid 同算法 +26.7 → 约 +28.5,**+1.8 个点**。**都是毛超额,还没扣剔除带来的额外换手。**
3. **F108 的多头端与已知家族的多头端是打对台的**:F108 多头十分位有 38% 落在家族的**空头**五分位,只有 8% 落在家族多头端。
   所以「两者相加」这种对称组合**必然互相抵消** —— §9b 的 `add ema20` 证实了:Lnet +11.1%/+20.3%,
   **反而低于**家族单独的 +12.6%/+22.3%(只有 Lshp 从 +1.78/+3.46 微升到 +1.80/+3.97)。
   → **对称相加这条路已经被否定了。** 剩下的只有**非对称的剔除式**叠加,而那几行恰好被守卫掐掉了。
