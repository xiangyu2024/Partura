# F108_max_ntkurt_close —— 批量扫描 s1 的综合(主研,一轮)

`day_max(pow_1_5(pow_2(nt_ts_kurt(Close, 30))))`,87 个变体 + 市场解剖一起读。
口径:多头腿扣 15bp 净超额 Lnet(train / valid / utrain)、纯多头夏普 Lshp;噪声 ±3pp / ±0.3。
基准 `k_known = cross_mean(day_std(Amt), 30)` ut **+15.4% / Lshp +2.22**。

---

## 1. 它是什么(逐层按函数定义,不按名字)

| 层 | 定义(源码) | 名字骗人的地方 |
|---|---|---|
| `nt_ts_kurt(Close, 30)` | `rolling_reduce(x, 30, nankurt_last, axis=0)`,NT 面第 0 轴是**日内分钟**:第 m 分钟 = 第 `[m−29, m]` 分钟 Close 的**超额**峰度 | **30 是 30 分钟,不是 30 日**;不跨日 |
| `nankurt_last` | `m4/(var²+1e-9) − 3`,`var ≤ EPS` 直接给 NaN | ① 价格**整窗不动(封死)→ NaN**,不是大值,被 `day_max` 跳过;② 分母的 EPS 是**绝对值**,所以这个"无量纲"统计量其实依赖价格尺度(见 §3) |
| `pow_2` | `pow_(x, 2.0)`,`e>1` 走 `x**e` 分支 | docstring 写的 "signed power" **只在 e ≤ 1 时生效**;这里就是普通平方 → 它是树里**唯一的 abs** |
| `pow_1_5` | 同上,`(K²)^1.5 = \|K\|³` | 单独作用在有符号 K 上会对负数给 NaN(`abl_B` 因此只在**正超额峰度**的分钟上取 max) |
| `day_max` | `nanmax_last`,吃当天全部 241 根分钟 | 无意外 |

合起来 `= (max_m \|K_m\|)³`,对 `max\|K\|` 严格保序 → **整棵树在秩空间里只有一个自由度:
"当天最孤立的那一分钟,相对它前 29 分钟波动的信噪比"**。`sub_C_signedpower`(ρo +0.99、ut +1.0%)、
`win`=`cs_winsor`(ρo +1.00、ut +1.0%)、`abl_C` 删 `pow_1_5`(ρo +0.97、ut +0.5%)三条都确认了这一点。

机制:30 个点里有 1 个孤立点,超额峰度上限 ≈ 25~27。**高值 = 价格被钉住 + 一次孤立跳动**(一字板/封板/极薄盘口),
不是"收益肥尾"。方向 `sg = −1`:多头腿 = 最低 max|K| = 全天价格连续变动的票。

## 2. 预测力在哪(同类放一起比)

**(a) 多头腿本身是零 —— 这是最重要的一条。** `v_base` hlL20 Lnet **+0.3 / +2.5 / +1.0%**,Lshp **+0.05 / +0.46 / +0.15**;
而底腿(最高 max|K| 十分位)毛超额 **−30.6% / −30.0%**,多空 LS +2.83 / +2.53。
**31pp 的多空差价里多头腿只拿到约 1pp** —— 内容全在空头端,对纯多头用户等于没有。

**(b) 承重节点:只有 `nt_ts_kurt` + 窗口 30 + `day_max`。**
- 换掉峰度 = 换掉因子:`sub_A_nt_ts_var` / `_std` / `_delta` 的 ρo 只 **+0.09 / +0.08 / +0.04**(≈ 不相关),
  ρk 跳到 **+0.52 / +0.55 / +0.54**,Lnet ut +8.1 / +7.3 / +7.4%。按手册 §6.3,ρo < 0.8 就**不是提纯,是另一条因子**。
- 它们变好的原因是**价格水平漏回来了**:Close 是水平量,其 30 分钟方差 ∝ 价格²。解剖里这几条多头书在
  "价格最低 20%" 的超配分别 **+71.6 / +74.4 / +75.1pp**;而 `abl_A`(把峰度整节点删掉 = `(当日最高价)³`)
  ut +6.0%、超配 **+79.9pp**。**sub_A 一族 ≈ 低价书,原式只超配 +11.7pp。** 它们也都打不过 k_known 的 +15.4%。
- 删 `pow_2`(`abl_B`):ut **−0.6%**、LTO 4.7%→7.4%、ρo +0.93 → abs 这一半有用,但它变差一部分是被 NaN 掩掉了负峰度分钟。
- 折叠算子换不得:`day_close`/`day_last` ut +0.6%(ρo +0.61);`day_first`/`day_open` **符号翻转**(sg +1)ut −6.0%、
  Lshp −1.20、dist 0.50 ✗(读的是左侧 NaN 补齐后只有 1~2 个点的伪影:2 个点的超额峰度恒为 −2);
  `day_quantile`(中位)ut **−19.3%**。→ "在哪一分钟读"是决定性的,**max 是对的折叠**。

**(c) 多余节点:`pow_1_5`、外层 `cs_winsor`、`signedpower` 全是死重**(见 §1)。

**(d) 叶子:Close ↔ Open 可互换**(`leaf_Close_open` ρo +0.96、ut +0.7%);`Low` ρo +0.76 / ut −0.6%(valid −4.5%)、
`Vwap` ρo +0.79 / ut −0.9% 都变差。Vwap 变差本身是机制证据:Vwap 只在有成交的分钟有定义,把冻结分钟抹平了。

**(e) 窗口没有平台,这是硬伤。** 10 → **符号翻转**(sg +1、ρo −0.38);15 → ut **−2.9%**(全表最差的窗口);
30 → +1.0%;60 → ut +1.0% 但 train +1.6 / valid **−0.8%**、底腿 −39.8%。相邻一档就翻符号 = 结构脆。

**(f) 平滑是本树唯一稳定的杠杆,但它不是结构。** 28 条 memory 里所有 `cross_mean/ema/decay_linear` 都 ρo +0.91~+0.99、
ut 挤在 **+2.4~+2.8%**、Lshp +0.37~+0.46,且它们的 hlL 从 20 掉到 1~3 —— **表达式内平滑与 EMA 半衰期是同一件东西的替代品**,
统一比 base 高 ~1.5pp。按手册 §6.1,这叫"改进来自平滑",不能记到结构头上。

**(g) 状态量,不是事件量 —— 这条判得最干净。** `cross_zscore` 全线崩盘:5/10/30/60 日 ut
**−21.4 / −16.2 / −8.6 / −5.0%**,LTO 最高 29.7%;`rel60`(除自己 60 日均值)train +2.7 / valid −2.3%;
`fold_rank` ut −5.3%、`fold_sq` train +2.5 / valid −2.0%。**把个股自己的历史水平去掉,信息就没了 → 载重的是
"哪些票长期是这种票"的截面水平,不是"今天异常"。** 与此一致:`cross_min` 是唯一改变了对象的记忆形状 ——
`mem_min60` ρo 只 +0.26、dist 0.54、**Lshp +0.95、LTO 仅 2.1%**(全表非成交额族最高的夏普/换手比),
读作"连最干净的一天都有孤立价"=慢性病;但 Lnet train +3.7 / valid +1.7%,**在 ±3pp 噪声内,只能算"合理但未坐实"**。
`cross_max` 一族(+0.9~+1.4%)全不如 `cross_min` → 再次是状态 > 事件。

## 3. 在市场的哪儿、什么时候有效(解剖表)

**(a) 诊断:原式把钱押在它没有能力的地方。**
流通市值五档的**段内**多头净超额 = **+5.3 / +5.4 / +6.4 / +5.7 / −0.4%**(最小四档都有 +5~6%,最大档为零),
而全市场多头书**超配最大市值档 +35.8pp、低配最小档 −16.6pp**。→ 桶内有选股力,排序把预算花在了零能力的那一桶。

**(b) 成交额方向正好相反:只有高换手里有用。** 成交额五档段内 = **−2.9 / −3.5 / −2.5 / +6.4 / +11.4%**,
书也确实超配最高档 +18.4pp。两条合起来,甜点是**小市值 × 高成交额 = 高换手率的投机票**。
原因推断:峰度要有"30 分钟里 29 根不动、1 根跳"才有意义;最低成交额档里**每只票都有大把死分钟**,
max|K| 饱和、截面上不再有区分度(段内 −2.9%)。
**可检验推论**:(i) 把"无成交分钟占比"(`day_flat_ratio(Volume)`)当条件变量,它应该能把有用/无用的票分开;
(ii) 在成交额桶内做中性化会**抹掉**信息(因为桶间符号相反),而在价格/市值代理桶内做中性化应该**保住**信息
—— 表里 `bk_liq`/`res_liq` 正是 train −0.2 / −1.0%、valid +9.2 / +9.5%(两段反号),符合这个预言。

**(c) 全部截面选股力集中在 6.5% 的病态段。** 近 15 日有冻结盘口(封板/停牌)段占 6.5%、段等权 **−67.4%**:
原式段内 **+37.3%**(全解剖最大的数),而 **k_known 在这一段是 −10.9%**;无冻结段(93.5%)原式段内 **−3.1%(负)**。
→ **原式在它和已知族唯一互补的地方有用,在其余 93.5% 的票上是有害的**;而全市场书只低配这一段 −5.6pp,
根本没有把这件事用出来。次新段(上市不足 250 日,7.1%,段等权 −28.7%)同向:原式 +5.0%、
`mem_min60` **+12.8%**、`mem_min30/10` +9.4 / +9.2%(k_known 只 +8.6%)—— 连续一字板正是次新股的事。

**(d) 板块:科创板(4.0%)段内 −13.3%,十列全负。** 沪/深主板/创业板 +1.0 / +4.5 / +2.7%。
推断:科创板 ±20% 限幅、上市前 5 日无限幅 → 没有"一字板钉住"这种状态,max|K| 读到的是真实跳跃风险,
而真实跳跃在科创板次日不被系统性惩罚。**可检验推论**:因子强度应该随价格限幅的紧度走;创业板 2020-08-24 改 ±20% 之后
应该变弱 —— 逐年看 2021 年原式 **−5.2%**(该年之前 2019/2020 是 +5.9 / +4.8%),方向对但不干净,算"未决"。

**(e) 价格最低 20% 段内 −6.7%(原式最差的价格档)**,其余四档 +1.5 / +2.1 / +4.5 / +1.2%。
推断 = §1 里的 **EPS 地板**:低价票一跳一个 tick,30 分钟价格方差 ~1e-4、var² ~1e-8,与分母的 1e-9 同量级 →
峰度被人为压向 −3,读数失真。**可检验推论**:把叶子换成尺度远大于 EPS 的量(Amt、Volume),价格档的这个坡应该消失。

**(f) 时段:只在低波动、放量、离散度高的市场里有效。** 市场波动低于中位 **+8.4%** vs 高于中位 **−6.4%**(14.8pp,
全解剖最大的时间切分);放量 +2.6 vs 缩量 −0.4%;截面离散度高 +3.3 vs 低 −1.3%;市场近 20 日涨 +2.2 vs 跌 −1.3%。
逐年 2019 +5.9 / 2020 +4.8 / 2023 +7.2 为正,2018 −4.1 / 2021 −5.2 / 2022 −0.2 为负。
推断:高波动期里真跳变满地都是,max|K| 不再是"钉住的盘口"的探测器,而变成"波动大的票"的代理,后者在 A 股次日没有稳定负超额。

## 4. 相对已知成交额族有没有增量 —— 没有(线性形态下)

- 秩相关 **ρk = −0.08**,正交;但正交在这里不值钱,因为多头腿本来就没东西。
- **六条 overlay 全部严格差于家族单独**:ov_p025 ut **+14.1%**(Lshp +2.03)、ov_p05 +13.9、ov_p10 +13.2、
  ov_m025 +10.9、ov_m05 +8.6、ov_m10 +4.7,对 k_known 的 **+15.4% / +2.22**。只有 valid 单看 ov_p10 +22.8% 比 +22.3% 高 0.5pp(噪声内),
  train 侧 +9.4% 比 +12.6% **低 3.2pp**。
- 中性化后多头腿也站不住:`res_known` train **−1.2** / valid +8.2%、`res_liq` train −1.0 / valid +9.5%,两段反号,LTO 翻倍到 8.4%。
  `bk_known` / `bk_liq` 被 dist 0.20 判掉(见 §6 工具问题)。
- **与上一轮(R2)的结论冲突,必须记一笔**:R2 用 `D30 = cross_mean(原式, 30)` 作载体、固定 hl0,量到结构增量 +1.2pp / +1.4pp;
  s1 表用的是**未平滑的原式**作载体、半衰期逐变体重选,得到 −1.3pp。**载体不同**,s1 表里没有 D30 载体那一行。
  第二批的 `h_ov_mean30_p025` / `h_ov_min60_p025` 就是去对齐这件事(这是整批里优先级最高的两条之一)。
- 结论(合格的否定结论):**对只能做多的用户,这条因子作为排序器相对已知成交额族没有增量。**
  它唯一打赢家族的地方是 6.5% 的冻结盘口段(+37.3% vs −10.9%)和 7.1% 的次新段 —— 那是**筛子**的用法,不是**混合**的用法,
  而 s1 表里**没有任何一条筛子形态的变体**(六条 overlay 全是线性混合)。这正是第二批的主攻方向。

## 5. 改进方向(→ `studies/F108_max_ntkurt_close/hypo.yaml`,32 条)

1. **筛子而不是混合**(§4):`mul(cs_rank(k_known), logical_not(cs_quantile_q25(F_slow)))` 硬剔最差 25%、
   `pow_3` 凸罚项只压最差一小段。瞄准 6.5% 病态段里家族亏 10.9% 这件事。
2. **用无 EPS、无饱和的直接状态变量替掉峰度**(§2g、§3c):`day_flat_ratio(Close)`、
   `sub(day_flat_ratio(Close), day_flat_ratio(Amt))`(=价钉住但钱在动 → 封板带队列,区别于停牌)、`day_durbin_watson(Close)`。
3. **把尺度泄漏和 EPS 地板钉死**(§2b、§3e):叶子换 Amt / Volume / High,并把 `nt_ts_std` 也换到 Amt 叶子上看 ρk 是否更高。
4. **日内折叠从"极值"换成"频率/集中度/位置"**(§2g):`day_pos_ratio`、`day_mean`、`day_gini`、`day_argmax`、`day_quantile_q75`。
5. **修规模倾斜**(§3a):在价格(市值代理)桶内做 `cs_bucket_rank` 与 `cs_regres` 残差(两种写法互为保险),
   以及"低价 ∩ 高成交额 ∩ 安静"的三重秩软 AND。
6. **把"低波动市场才有效"写进表达式**(§3f):用 `div(cross_mean(cs_mean(day_std(Ret)), 60), cs_mean(day_std(Ret)))` 当权重。
7. **慢性读数做到底**(§2g):`cross_quantile_q25(·, 60)`(比硬 min 稳)、`cross_min(·, 241)`。
