**解读(第 2 轮主研)**:这一节比 §A2 干净,而且它才是手册 §6.2 规定的检验形式。四件事:

1. **等权(w=1)相加 —— 手册的标准检验 —— 否定增量**:+11.9%/+19.9%(D_m30)、+11.1%/+20.3%(D_ema20),

2. **但 w 在 train 上是单峰的**:0 → +12.6%、**0.25 → +15.1%**、0.5 → +13.8%、1.0 → +11.9%。
   **只用 train 就能选出 w = 0.25**(不需要看 valid),而 valid 给出同一个峰位(22.3 / **23.8** / 22.9 / 19.9)。
   这是内部极值、不是网格边缘,两段峰位一致 —— 比「某一格最好」强得多。
3. **不是半衰期的功劳**:`K1+0.25*D_m30^1` 自选 hlL = 0,`@famHL0` 对照行逐位相同(+15.1%/+23.8%)。
   按手册 §6 第 1 条,这满足「同一半衰期下比」的要求。纯多头夏普 +1.78/+3.46 → **+2.30/+3.87**;
   换手 3.4% → 5.1%(净超额已扣过费)。
4. **p = 3/6 一律更差** → 有用的是 D 的**排名**,不是 D 的**数值重尾**;与 H14(尾部是单边报警)一致。

→ 这是目前唯一一条「两段都赢过已知家族」的用法。但它要求把 F108 的权重压到 1/4,是一个被调过的参数;
三个疑点没打完之前只能算**合理但未坐实**:w 是平台还是尖峰、换成别的弱相关信号是不是一样好、
增量里有多少是「买不进记 0」换来的。这三条就是 R2 的全部内容。

用「同样只数匹配的尾部」量的,不依赖线性中性化的低 R²(非单调关系上那个低 R² 本来不算证据)。

  **最接近它的已知东西是「极端收益」,不是波动、也不是成交额。**
- 但这一切都在**空头端**:r 高 = 别买。用户做不了空头,所以「它是新东西」这个结论对选拔的意义只有一条:
  §A3 那点多头增量**不是已知家族的重复计数**。
