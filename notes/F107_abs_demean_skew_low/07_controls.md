**怎么读**:这张表是**把每个控制变量 / 已知家族成员自己当成一条因子**、用和本因子完全相同的口径(方向与半衰期在 fit 段=train 上定、
扣 15bp、多头腿净超额 + 纯多头夏普)建出来的书。它**不是中性化**——「本因子被它们解释掉多少」在 `07_neutralise.md`。
来源:`runs/F107_abs_demean_skew_low/S0_baseline.json` → `diagnostics.controls`(9 个 `ctl_*` + 4 个 `known_*`,共 13 行)。

**三组要记住的事实**(数字直接取自上面那份 JSON,train / valid):

1. **已知家族这一族自己就很强,而且远高于本因子的任何候选。**
   `known_stdamt_mean30`(= `cross_mean(day_std(Amt), 30)` = 判据里的 `f_K`)多头腿净超额 **+12.6% / +22.3%**、
   纯多头夏普 1.78 / 3.46、半衰期 **0**、多头日换手 3.4%;`known_stdamt_max9`(= `cross_max(day_std(Amt), 9)`)
   **+13.7% / +22.2%**、1.99 / 3.59、半衰期 5、换手 4.5%;`known_amt_max9` +10.6% / +21.8%。
   对比本因子:原式 +1.1% / +3.0%、`m20` +4.8% / +7.3%(`07_S0_baseline.md`、`07_S2_memory.md`)。
   → 这两条就是用户点名的已知家族基准,**它们在 train/valid 上也成立**,不只是在用户给的测试段读数上成立。
   (「相对已知家族有没有增量」的结论不在这张表里,在 `09_diagnosis.md` **A4** / `10_distilled.md` 判据 0 与判据 3。)

2. **`ctl_dvol20`——也就是「低特质波动」这一维——自己当因子时,多头腿是不赚钱的。**
   多头腿净超额 **−9.0% / +0.6%**、纯多头夏普 −0.89 / +0.07(半衰期 2、换手 5.5%),而它的 fit 段 rank IC 是全表最高一档
   (**+0.0456**)。同向的还有 `ctl_ivol` −5.2% / +2.2%、`ctl_range` −4.8% / +6.9%、`ctl_turnrate` −2.3% / +8.2%:
   **rank IC 高 ≠ 多头腿赚钱**,这几条都是换手把毛超额吃掉的典型。
   → 这件事的后果写在 `11_risks.md` §7 与 `09_diagnosis.md` **C1**:拿 `ctl_dvol20` / `g_absidio20` 当「已知暴露」
   去否定别的因子时,要知道这个暴露本身在多头腿上不付钱。这里只记事实。

3. **`ctl_cap`(流通市值)几乎没有排序力**:fit 段 rank IC **+0.0016**、方向 **+**、多头腿 +0.6% / −9.0%(换手 0.3%)。
   所以 `09_diagnosis.md` A8 说「它是中小市值因子」靠的是**条件 IC 按市值分桶**(最高桶 +0.007)和多头十分位剖面,
   **不是**靠市值自己能不能赚钱——这两件事不要混。
