**为什么 `m60` 没有占一个槽位**:它和 `f_m20` 是同一族、同一归因、同一结论(两者在 train/valid 上差 ≤0.8pp),
占一个槽只能回答「兄弟窗口是不是也成立」,而这件事 train/valid 上六个窗口已经答过。
槽位给了第 4、5 两条**能回答别的问题**的候选:第 4 条回答「对用户到底有没有增量」(这是用户真正的问题),

### 判据(留出段出现什么结果算被否定)

口径:方向与半衰期在 **utrain** 上定一次(用户口径),留出段 20230808–20251231。
噪声带:**多头腿净超额 ±3 个点、纯多头夏普 ±0.3**(硬规矩 6)。

**判据 0(基准 2 自身必须成立 —— 其余判据的前提)**
`f_K` 留出段 Lnet 应落在 **+13%~+15%**、Lshp **1.4~1.9**(playbook §6.2 给的第一组测试段读数)。
- 若 `f_K` Lnet **< +5%** → 已知家族基准在测试段本身不成立,**判据 3 作废**,相对已知家族有无增量只能写「未决(测试段上无法判)」,
  train/valid 的否定证据照写,但不升级为「已确立」。

**判据 1(原式对纯多头可用吗)**
预期 `f_orig` Lnet **+1%~+4%**、Lshp **0.2~0.8**、换手约 11%。
- Lnet ≤ +4% **或** Lshp ≤ 0.8 → 「**原式照现在的样子对只能做多的用户不可用,毛超额被换手吃掉**」**已确立**。
- `f_orig` Lnet **≥ +8% 且** Lshp **≥ 1.0** → 这一条在测试段**被否定**,整条结论要重写(原式本身就可用)。

**判据 2(提纯 `f_m20` 成立吗 —— 第一推荐的判据)**
- `f_m20` Lnet **≥ f_orig + 3pp 且** Lshp **≥ f_orig + 0.3** → 「**把 20 日记忆写进表达式是真的提纯(改进来自平滑/低换手)**」**已确立**,
  第一推荐保留。预期 `f_m20` Lnet **+4%~+9%**、Lshp **0.9~1.9**、换手约 3%。
- `f_m20` Lnet **< f_orig + 3pp** → **第一推荐被否定**:记忆带来的改进只在 utrain 内部成立。
- 附带要看的:`f_m20` 的留出段**毛**超额应**不高于** `f_orig` 的毛超额(train/valid 上都是降的:+9.4→+6.9、+11.4→+9.5)。
  若留出段上 `f_m20` 的毛超额**反而明显高于** `f_orig`(> +3pp),则「归因 = 平滑」这个写法在测试段被否定,
  要改写成「结构也有贡献」—— 这会是本研究**最意外**的结果,必须照实写。

**判据 3(决定性判据:对只能做多的用户,相对已知家族有没有增量)**
- `f_m20K` Lnet **≥ f_K + 3pp 且** Lshp **≥ f_K + 0.3** → 「**有增量**」→ **本研究的主结论被推翻**,
  要改写成「它相对已知家族有增量,建议以 0.5~1 倍权重叠加在成交额波动家族上」。
- `f_m20K` 落在 `f_K` 的 ±3pp / ±0.3 内,**或更低** → 「**对只能做多的用户,这条因子相对已知家族没有增量**」**已确立**。
  （这是预期结果:train `rank F+rank K` +11.8% vs K +12.6%,valid +20.0% vs **+22.3%**,
  八条候选 × 两种权重 = 十六个组合在 valid 上无一超过 K。)
- **弱版**(只在第 4 槽位被替换成 `f_m60` 时启用):比较 `f_m20` / `f_m60` 单独与 `f_K` 单独。
  若两者都 ≤ `f_K` − 3pp → 写「**绝对水平上远不如已知家族**」(已确立),但「相加之后有没有增量」写**未决**,
  并在 `12_next.md` 里把它列为第一条下一步。

**判据 4(H14:日内路径这一维值不值钱)**
- `f_m20absret` Lnet **≥ f_m20 + 3pp** → H14 在测试段被支持 → 「**日内路径形状相对日频 \|特质收益\| 没有增量,反而更差;
  这棵树的 241 根分钟最低价是负贡献**」**已确立**。(valid 上差 6.5pp,预期在测试段重现。)
- 两者之差在 **±3pp** 内 → H14 改写为「**两者等价:日内路径既不优也不劣**」,级别降为「**合理但未坐实**」
  (valid 上的 6.5pp 差距没有外推)。
- `f_m20` **≥ f_m20absret + 3pp** → H14 在测试段**被否定** → 要写「日内路径有独立增量,valid 上的结论没有外推」,
  并在 `12_next.md` 里把「日内形状 vs 日频特质波动」列为需要重做的第一件事。

### 事前就定下的总结论框架(留出段只能确认或推翻它,不能替换它)

**分辨**:这是「**低特质波动 / 安静的中小票**」这个已知暴露的一个**日内写法**,而且是比它的日频原型**更差**的写法。
空头腿是封板/钉价事件(用户做不了);多头腿是分布主体里「安静、随当天全市场形状走」的票。
**提纯**:`f_m20`(20 日平均 + hl20),比原式好 3~4 个点,**改进全部来自换手 10.9% → 2.8%,毛超额还降了**。
**升华**:**没有**。四个结构方向在 valid 上全部不通过(H13 被否定;形状同步性与去峰度共享部分都变成了另一条因子且过不了 K)。
**对用户的净建议**:**不建议为它单开一个因子位**;若已经在跑 `cross_mean/max(day_std(Amt), 9~30)` 这一族,它不加东西。

### 判据逐条

**判据 0(前提:已知家族基准自己要成立)—— 通过,而且很准。**
`f_K` 留出段 Lnet **+14.10%**、Lshp **1.509**,正落在事前写的 **+13%~+15% / 1.4~1.9**(playbook §6.2 给的第一组读数)。
→ 已知家族基准在测试段成立,**判据 3 有效,不作废。**

**判据 1(原式对纯多头可用吗)—— 「不可用」已确立。**
`f_orig` Lnet **+1.41%**(确立支的门槛是 ≤ +4%)、Lshp **0.302**(≤ 0.8)、LTO **11.96%** ——
三项都落在事前预期区间(+1%~+4% / 0.2~0.8 / 约 11%)内;否定支(Lnet ≥ +8% **且** Lshp ≥ 1.0)差得很远。
毛超额确实在那里(**+10.45%**),成本 **9.04pp** 吃掉它的 **86%**。
→ **「原式照现在的样子对只能做多的用户不可用,毛超额被换手吃掉」已确立。这是本研究最稳的一条。**

**判据 2(提纯 `f_m20` 成立吗 —— 第一推荐的判据)—— 未过线;按事前写死的判决,第一推荐被否定。**
- **Lnet 分支**:`f_m20` − `f_orig` = **+2.9266pp**,门槛 ≥ 3pp → **差 0.0734pp,没过。**
- **Lshp 分支**:**+0.7100**,门槛 ≥ 0.3 → 过了,而且过得很多。
- 事前写的是 AND,而否定支只键在 Lnet 上(「`f_m20` Lnet < f_orig + 3pp → **第一推荐被否定**」)→ **照字面:被否定。**
- **附带条件(归因)满足,而且是留出段上最干净的一条**:`f_m20` 的留出段**毛**超额比 `f_orig` **低 2.81pp**
  (7.64% 对 10.45%),不是事前担心的「反而明显高」。分解:
  成本 9.04pp → 3.30pp(**省 5.74pp**),毛超额**让掉 2.81pp**,净得 +2.93pp;**5.74 − 2.81 = 2.93**。
  → **改进 100% 来自换手,结构那一侧是负的。** train/valid 在同一半衰期 hl20 下是同一形状
  (毛 +9.4%/+11.4% → +6.9%/+9.5%,LTO 10.9% → 2.8%)。**归因成立 ≠ 幅度被坐实,两件事分开写。**
- 诚实地记一笔:判决的间距(0.07pp)比本研究自己的噪声带(±3pp)**小两个数量级**,而两个口径指向相反

  **但不许因此改判、也不许换推荐**(playbook §6.4):本节的判决就是「被否定」。
- 它**不影响对用户的建议** —— 判据 3 才是决定性的,而判据 3 不是边界情形。

**判据 3(决定性:对只能做多的用户,相对已知家族有没有增量)—— 「没有增量」已确立,不是边界情形。**
