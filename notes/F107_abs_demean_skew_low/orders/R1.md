## 想回答的问题(对应哪条假设;看到哪种结果意味着什么)

x1 是 numpy 探路,**所有结论都还没有引擎的正式数字**。这一轮只做两件事:把 S12 收回来坐实(或推翻)x1 的读数,
以及把 x2 这个「结构还能不能救多头腿」的探针跑出来。四个判断点:

1. **H14(这一轮最要紧的一条)——「日内路径形状在特质波动之外有没有增量」。**
   对比 `m20` / `m60`(原式 + 日轴记忆)与 `m20_absret` / `m60_absret`(完全不看日内路径,只有日频 |特质收益| 配同样的记忆)。
   - 若两者多头腿净超额之差在 ±3 个点以内、且 train/valid 不同向 → **H14 成立**:这棵树读的 241 根分钟最低价白读了,
     它就是「平均绝对特质日收益」的带噪声写法,结论会往「没有增量」走。
   - 若 `m20` 比 `m20_absret` 高 3 个点以上、两段同向 → H14 被杀死,日内形状本身有东西,值得继续提纯。
2. **H11 的归因 ——「平滑」还是「结构」。** x1 说窗口 10~60 把多头腿净超额从 +1.1%/+3.0% 抬到 +5~6%/+6.6~7.5%,
   但**毛超额没升**(train 还降 1~2 个点),多出来的全部来自换手 10.9% → 3~4%。
   要用**固定半衰期表**坐实:在同一个半衰期(hl20)下比 `v_base` 与 `m10/m20/m60` 的多头腿**毛**超额。
   若固定半衰期下毛超额不升 → 改进记在「平滑」名下(这仍然是可以交易到的真改进,只是归因要写对)。
3. **H1 / H2(两条腿是两种机制)与 H6(cs_demean 必需)、H9、H10 的引擎确认。**
   看 `p_rank`、`p_cube`、`p_range`、`p_nodemean`、`m60_nodemean`、`p_close`、`r_kurtlow` 的两条腿分别怎么动。
4. **H4 —— 对只能做多的用户,相对已知家族 `cross_mean(day_std(Amt), 30)` 有没有增量。**
   x1 §7 说基本没有(残差多头腿毛 +3.9%/+1.4%,相加不升,原式多头十分位里 K 最低的三分之一 −0.6%/−4.7%)。
   要 S12 的中性化表 + conditional 表 + x2 §e 来坐实。
