> 主研第 3 轮写(Opus 5,2026-10-04),在读完留出段之后。
> 每条后面跟着能指到的实验。口径:`Lnet` 多头腿净超额(扣 15bp)、`Lgross` 多头腿毛超额、`Lshp` 纯多头夏普、
> `LTO` 多头日换手、`ρ` 与 `v_base` 可交易信号的日截面 rank 相关。噪声带 **±3pp 净超额、±0.3 夏普**。
> 没有标「留出段」的数字都是 train / valid(决策口径);留出段的数字见 `10_distilled.md`「读完留出段之后」。

**一句话**:它是一个**慢的、折叠过的「安静的中小票」读数** —— 空头腿是封板/钉价事件(用户做不了),
多头腿是分布主体里成交少、波动低、不跳的票;毛超额真实存在,但被 11% 的换手吃光;
对只能做多的用户,它**相对成交额波动家族没有增量**,叠加上去还要损失 6.1 个点。

## A. 已确立

**A1. 两条腿是两种机制,钱主要在用户做不了的那一腿。**
- 原式多头毛 +9.4% / +11.4% 对空头毛 **+32.5%**,多头只占毛价差 22% / 27%(S0,`06_baseline.md`)。
- 空头腿 = 尾部事件:`p_rank`(压平尾部)把扣费多空夏普从 2.81 压到 **1.12**、空头毛 +32.5% → +19.6%(S12);
  x1 §9 把「钉住日」换成中性值 → 空头毛只剩 **+7.8%**。
- 多头腿 = 分布主体:`p_rank` 多头毛 **+10.3% / +12.2% ≥ 原式**;`p_cube`(把权重压到尾部)降到 +7.2% / +7.5%;
  `mx20`(只记 20 日极值)Lnet 只有 +1.7% / +1.1%(S12)。
- **留出段原样重现这个分裂**:原式空头毛 **+31.28%**、扣费多空夏普 **2.459**,而多头腿净超额只有 **+1.41%**(FINAL)。

**A2. 原式照现在的样子对只能做多的用户不可用,原因是换手,不是没有毛超额。**(判据 1)
- 留出段:Lgross **+10.45%**、LTO **11.96%** → 成本 **9.04pp** → Lnet **+1.41%**、Lshp **0.302**。成本吃掉毛超额的 86%。
- 半衰期已经顶到网格上界:hl0 −63.2% / hl2 −23.5% / hl5 −10.2% / hl10 −3.1% / hl20 +1.1%(train,S0)。
  **树里没有任何日轴算子,记忆全在表达式外面。**
- 这是本研究**最稳的一条**:事前预期区间(+1%~+4% / 0.2~0.8 / ~11% 换手)三项全中,否定支差得很远。

**A3. 提纯的归因是平滑/换手,不是结构;而且结构那一侧是负的 —— 留出段坐实。**(判据 2 的附带条件)
- 留出段 `f_m20` 对 `f_orig`:毛超额 **7.64% 对 10.45%(低 2.81pp)**,成本 3.30pp 对 9.04pp(**省 5.74pp**),
  净 +4.34% 对 +1.41%(高 2.93pp)。**5.74 − 2.81 = 2.93**,改进 100% 来自换手。
- train / valid 在**同一半衰期 hl20** 下是同一形状(`v_base`/`m10`/`m20` 都选到 hl20):
  毛 +9.4% / +11.4% → **+6.9% / +9.5%(降)**,LTO 10.9% → **2.8%**(S12)。
- 所以「把 20 日记忆写进表达式」买到的是低换手,**卖掉的是一部分毛超额**。
  按 playbook §6.1 必须写「来自更长的记忆 / 更低的换手」,**不能写成结构更好**。
- (**幅度**是另一件事:+2.93pp 没过事前的 3pp 门槛,见 C2 和 `10_distilled.md` 判据 2。
  归因成立 ≠ 改进幅度被坐实,这两件事要分开写。)

**A4. 对只能做多的用户,这条因子相对已知家族没有增量 —— 这就是本研究的结论,留出段确认且不是边界情形。**(判据 3)
- 前提成立:`f_K` = `cross_mean(day_std(Amt), 30)` 留出段 Lnet **+14.10%**、Lshp **1.509**,
  正落在事前写的 +13%~+15% / 1.4~1.9(判据 0)。
- 等权秩相加 `f_m20K` 留出段 **+7.98%** / Lshp 0.973,比 K 单独 **低 6.12pp / 0.535 夏普** —— 门槛是 ±3pp / ±0.3。
- 比「没有增量」更强:**连分散化收益都没有**。两条单独的算术中点 (14.10+4.34)/2 = **+9.22%**,混合 **+7.98%**(低 1.24pp);
  而 utrain 上混合 +12.82% 比中点 +10.40% **高 2.42pp** → **混合的「额外收益」两段符号相反**,按噪声规矩是噪声。
- 与 train / valid 完全一致:八条候选 × 两种权重 = **十六个组合在 valid 上无一超过 K 单独的 +22.3%**;
  对 K 取残差的 Lnet 在 valid 上**全为负**(−0.3 ~ −9.9);「K 最高十分位内按 F 分三档」在 valid 上**翻向**
  (`m60` +27.7 / +26.9 / +25.1),「K top 落进 F 底 30%」valid 上 **+26.6% 对 +26.6%**(x2 §e)。

**A5. `cs_demean` 是唯一不能删的节点。**
- `p_nodemean` 毛 **+3.5% / +3.8%**(原式 +9.4% / +11.4%),而**空头腿几乎不动**(+32.8% 对 +32.5%)
  → 空头腿不需要去均值,**多头腿的全部内容都在「相对当天全市场的形状」这一层**。
- 慢尺度上同样:`m60_nodemean` Lnet +1.4% / +1.3%(`m60` +5.6% / +6.5%)。
- 数据基础:逐日截面均值 μ(d) 不小 —— `|μ|/σ` 中位 0.19,**37% 的交易日 > 0.25、11% > 0.5**(`03_decomposition.md`)。

**A6. 三阶矩与字段可换;`abs_` 的折点是写错的,但修不了。**
- 字段:`p_close` ρ **0.9508**、书在噪声内(H10)。三阶矩:`p_range`(有界不对称度、无厚尾)毛 +9.5% / +9.2% ≈ 原式,
  但空头毛掉到 +24.1%、LTO 升到 14.1% → **厚尾只服务于空头腿**(H9)。
- 折叠必要但折点偏左:`p_signed`(不折叠)Lnet **−30.1% / −36.6%** —— 带符号的 B 对次日收益是**倒 U**;
  x1 §1 的最优桶是 **(−0.5, −0.25]**(最优点 ≈ −0.375),不是 0(H5 被否定)。
- 但修不了:H13(`|B−c|` / `|B|+λB`)在 valid 上作废 —— train argmax c=−0.4 到 valid 只剩 +2.2%(valid 自己最好是 c=0),
  λ 在 20 日那一族上**符号翻转**;固定 hl20 下 `|B−(−0.4)|` tr +5.6% / va +2.1% 对原式 +1.1% / +3.0%(**两段反向**)。
  → **这棵树没有「删一个节点」式的提纯空间。**

**A7. 它是慢变量,没有短期 alpha 可抢。**
- 衰减 rank IC:原式 h1 0.034 → h20 0.062;`m20` h1 +0.0249 → h20 **+0.0533**,**单调上升**(S0 / S12)。

**A8. 它是中小市值因子。**
- 条件 IC 按流通市值五分组:+0.045 / +0.045 / +0.045 / +0.031 / **+0.007**(原式);`m60 | ctl_cap` 同形状(最高桶 **+0.0048**)。
- 多头十分位的日内百分位秩均值(train/valid):流通市值 0.49/0.51、成交额 **0.36/0.38**、换手率 0.36/0.36、
  20 日波动 **0.30/0.28**、分钟收益峰度 **0.27/0.29**(x1 §5)→ **多头端 = 不大不小、成交少、波动低、不跳的票。**

## B. 合理但未坐实

**B1.「它是折叠过的已知暴露(低波动 / 安静)的一个写法」—— train 段证据强,但留出段把更强的说法推翻了。**
- 支持:`m20` 对 9 个线性控制变量 R² **0.182**、残差毛 **+6.9% → +1.6%**;
  x1 §6 只用**一个同样折叠过**的日频变量(`EMA20|去均值日收益|`,完全不看日内路径)R² **0.307** → 残差毛只剩 **+2.9%**;
  加上 A8 的多头十分位剖面。(S0 当初「不被控制变量解释」是 playbook §6.5 的假象 —— 折叠过的量和单调控制变量的线性相关天然就低。)
- 为什么只到「合理」:**这些都是 fit 段(train)上的量**;而留出段上它的日频孪生 `f_m20absret` 只剩 **+1.21%**
  (utrain +7.44%),它自己还有 **+4.34%** —— 两者走散 3.13pp。
- 走散**不与识别矛盾**:R² 0.18~0.31 说的是「大部分毛超额能被解释掉」,不是「逐日等价」(ρ 仅 **0.51**)。
  但「它就是那个暴露、**而且是更差的写法**」这个更强的说法已经被判据 4 否定(见 D)。

**B2. H16:`cs_demean` 实际在量「我的日内价格水平形状跟不跟当天全市场走」(60 日尺度的形状同步性)。**
- x2 §c:只因 `cs_demean` 才进多头十分位的 3.5% / 3.6% 名字次日超额 **+13.4% / +16.2%**,
  其 `corr60(A,μ)` 百分位 **0.83 / 0.84**;只在不去均值版入选的那组 **−2.7% / −6.0%**、百分位 0.40 / 0.31。
  `Spearman(corr60, 信号)` train **+0.512**。
- 要坐实得把 `corr60(A,μ)` 做成一本打过 K 的书 —— 它过不了(对 K 残差 −2.7% / −6.8%,与 K 相加不超过 K 单独)。
  ρ(v_base) 仅 0.51 → **它是另一条因子**,不在本研究投入,写进 `12_next.md`。
- **别和 H7 混**:H7 是**分钟收益**的同步性(`r_mktcorr`,ρ 仅 **0.1325**,已被否定);H16 是**日内价格水平形状**的同步性。

**B3.「混合能降回撤」/「这条因子的价值在回撤和换手」。**
- 留出段:`f_m20` Lmdd **−2.92%**(五条里最浅)、LTO 4.37%;`f_K` Lmdd **−14.63%**、LTO 2.83%;
  `f_m20K` Lmdd −12.98%(比 K 浅 1.65pp)。按回撤口径 `f_m20` 好于 K,按收益和夏普口径差得远。
- 为什么只到「合理」:**这是读完留出段才看到的**,事前没有任何关于回撤的判据,按 playbook §6.4 不能升级。
  要用必须重新立项、重新登记判据(`12_next.md` §3),而且**不能再读这条因子的留出段**。

**B4. 2020 年混合有用。** K 最弱的一年(+6.6%),`0.5rank(m60)+rank(K)` 抬到 +9.8%(+3.2pp);
其余五年逐年 K 都更高(x2 §f)。**只有一年,而且 2020 是创业板涨跌幅放宽那一年** → 按 playbook §6.4 最多到这一档,不能翻结论。
