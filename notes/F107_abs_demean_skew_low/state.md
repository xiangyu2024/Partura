### 2.2 算子语义(`02_operators.md` + **我这一轮自己核对的源码**)

**上一位研究员确立的(`02_operators.md`,源码 + 服务器上打印的内核 + 两点路径解析核对):**

- **`day_skew(Low)` 不是收益偏度,是「价格水平占用分布」的偏度**:内核 `mean(((x−nanmean)/sqrt(nanmean((x−nanmean)²)))³)`,
  总体矩、不做小样本修正、NaN 分钟跳过;喂的是 241 根**分钟最低价的水平**。
  **负偏 = 全天大部分时间在高位、短暂下探(封涨停、探底回升后横在高位);正偏 = 大部分时间在低位、短暂冲高。**
  不看分钟顺序(打乱不变)、齐次度 0、平移不变、取负变号。两点路径解析式 `(1−2p)/sqrt(p(1−p))` 实测逐位一致
  (钉在高位 80/90/98% 的分钟 → −1.51 / −2.67 / −6.73)。
- **除法没有保护**:分母是路径自己的标准差,**全天不动的一字板得到 NaN 或恰好 ±1**(float32 舍入残差自归一化)。
  真实数据上这类格子占 0.20%(73.5% 是 NaN,其余 ±1);`|A|` 恰好等于 1 的占 0.16%。
  **一字板的读数是垃圾值而不是「极端」** —— 原式抓封板靠的是「钉住但没全天不动」的日子。
- **坑**:`study.sh src` 展不开 `C._skew`(内核通过模块别名调用,工具只追本模块全局名)。绕法:脚本里 `inspect.getsource` 在服务器上打印。

**我这一轮核对的(`study.sh src`,五个算子;本轮唯一的新事实):**

- **`cs_demean`**(`nd_cs.py:113`)= `x − cs_mean(x, valid_mask)`;`cs_mean` 先 `_valid(x, valid_mask)`
  = `isfinite(x)` 再与调用方的 mask 取与,然后 `nanmean(dim=−1)` 并广播回去。
  **证实了 `02` 的说法**:减的是当天所有**有限值**的截面均值,不看市值、不做别的过滤。
- **`cross_mean`**(`dt_cross.py:222`)= `rolling_reduce(x, d, nanmean_last, axis=0)`,其中
  `rolling_windows` 在**窗口左侧用 NaN 补齐,使每个原始位置(包括最前面的 d−1 个)都出值**,
  `nanmean_last` = `w.nanmean(dim=−1)`。
  **→ 它是沿 D 轴的因果滚动 nanmean,`min_periods` 等于 1:窗口里只要有一个有限值就出值,第 1 天就出值。**
- **`cross_delay(x, d)` 与 `ts_delay(x, d)` 在 `d > 0` 时逐行等价**(都是 `res[d:] = x[:−d]`、其余 NaN,axis=D;
  `cross_delay` 只是多了 `d == 0` 和 `d ≥ 行数` 的分支)。
  **这一条要紧**:config 里 `ctl_rev1` 用 `ts_delay` 而 `r_absret` / `m20_absret` / `m60_absret` / `g_absidio20` 用 `cross_delay`,
  **这不是 bug**,两种写法算的是同一个东西。**H14 的对手变体是忠实的**(确实是「日频 |特质收益|」),可以直接用来裁决。
  **别去统一它们** —— 改了就和 x1 的数字不可比。
  *附带的提醒*:`cross_delay` 是**裸位移,不是「上一个有效观测」**。所以停牌后复牌那一天
  `div(Close_t, Close_{t−1})` 是 NaN 而不是一个大跳 —— 这是干净的行为,但意味着
  **`r_absret`(没有记忆的那个)的缺失位置比 `day_skew(Low)` 多**(后者只需要当天的分钟)。
  `m20_absret` / `m60_absret` 过了 `cross_mean` 之后缺失基本被补上(20 天里有一天有限就出值),所以
  **H14 在 `m20` vs `m20_absret` 这一层上是干净的;在 `r_absret` 那一层上要记得它的覆盖面不同。**

**坑(还没查清,本轮把它逼到了第三条解释)**:
**引擎算出来的 `cross_mean(原式, 30)` 与「对缓存的原式面板做滚动 nanmean」不是同一个面板**
(日截面 Spearman 0.9989、有限值位置 0.27% 不一致、**最大差 12.6**)。
- **我这一轮排掉了两条解释**:不是 `min_periods` 的差别 —— 引擎 `min_periods = 1`(上面那条),
  而 x1 的 `roll_mean`(`x1_anatomy.py:104`)是 float64 cumsum 版的**同一个语义**(`k2 > 0.5` 才出值,也等于 `min_periods = 1`)。
  也不太可能是纯浮点误差:float64 cumsum 对 `|B| ≤ 15.4` 的量级不会差到 12.6。
- **所以剩下第三条解释,x2 §a 现在没有点名它**:`cross_mean(原式, …)` 里的**原式是引擎自己重算的**,
  而被滚动的是**缓存下来的原式面板** —— 如果引擎在表达式内部给 `cs_demean` 传了一个**universe / 停牌 mask**,
  而缓存面板是在另一套(或没有)mask 下算的,两边的 `B` 本身就不同,**引擎那一侧的 60 日窗口里可能只剩 1 个有限值**
  (于是 `cross_mean` = 那一个值,可以是 12 以上),而 numpy 那一侧窗口里有 ~60 个有限值(均值 ≈ 0.5)。
  这条解释同时对上了三个观测:Spearman 0.9989(主体完全一致)、0.27% 的**有限性**不一致、最大差 12.6(单观测窗口)。
- **怎么判**:x2 §a 已经把判它所需要的数全印出来了 —— 8 个最大差里的 **`finite days in window`** 和 `base today`、
  以及 `|diff| > 0.05` 那一段的 `mean finite-days-in-window`(对比 `all cells`)和 `share whose base is NaN today`。
  **若最大差的格子窗口里有限天数很少(个位数)→ 第三条解释成立**:不一致是**上市/复牌边界的伪影**,只涉及 0.27% 的格子,
  **x1 的时间尺度表(= 候选名单所依赖的那张表)在排序上是可信的**,只需把那批单观测格子当噪声处理。
  **若最大差的格子窗口里有限天数是几十天 → 两个面板真的是两个东西**,2.3d 那张表必须用引擎数字重读,候选名单可能换。
- **要紧**:x1 §4/§5 的时间尺度表正是用 numpy 滚动均值算的,所以 **x1 的 m10/m20/m60 和 S12 里引擎的 m10/m20/m60 可能不是一回事**。
  读 R1 时**必须先看 x2 §a 再下判断**。

### 2.4 分布与数据事实(`03_decomposition.md`)

`A(s,d) = mean_m(((L−L̄)/σ)³)`、`B = A − mean_s A`、`C = |B|`,交易 `EMA20(−C)`。
- A 厚尾左偏:0.1% −9.68、1% −2.57、5% −1.50、中位 −0.01、95% +1.35、99% +2.20、99.9% +4.61;`|A|` 上界 ≈ 15.4,随机游走 ≈ 0.39。
- `|B|` 中位 0.46,但 `≥1` 占 18.6% / 携带截面总和 49%,`≥2` 占 3.2% / 16.5%,`≥3` 占 0.9% / 8.2%
  → EMA 线性,一次 `|B|=5` 要 20 多天才衰减回去,**短头一端由事件决定**。
- 尾部是谁:「钉在高位」占 0.79%(平均 A −4.28,84% 当天涨超 9% = 封涨停)、「钉在低位」0.33%、全天不动 0.20%;
  **`|B|≥2` 的格子里这三类合计只占 22%,其余 78% 是「没封死但大部分时间挤在一头」的普通路径。**
- **μ(d) 不小**:逐日截面均值 5/25/50/75/95% 分位 −0.58 / −0.22 / −0.03 / +0.15 / +0.39,截面标准差中位 0.98;
  `|μ|/标准差` 中位 0.19,**37% 的交易日 > 0.25、11% > 0.5**。`|A−μ|` 与 `|A|` 逐日秩相关 0.786,各自 EMA20 之后 0.903。
- 价格是复权价(收盘落在 0.01 网格上的只有 24%),网格伪影(H8)涉及的格子 < 0.3%。
- **年份漂移**:`|B|` 截面均值 2018 年 0.55 → 2021 年 0.71,`|B|≥2` 占比 1.9% → 4.1%
  (2020 年 8 月创业板涨跌幅放宽到 20% 之后,「挤在一头但没封死」的路径变多);钉住占比 2020 最高(1.76%)。
