# F107_abs_demean_skew_low —— 批量扫描 s1 的综合(主研,2026-10-05)

口径:只看多头腿扣 15bp 的净超额 Lnet(train / valid / utrain)与纯多头夏普 Lshp;噪声带 ±3pp / ±0.3 夏普;
门槛 cov ≥ 0.95、dist ≥ 0.5。基准 `k_known = cross_mean(day_std(Amt), 30)`:+12.6 / +22.3 / **+15.4%**,Lshp **+2.22**,LTO 3.4%。
记 `A = day_skew(Low)`、`B = cs_demean(A)`,原式信号 = `abs(B)`,方向 −1。

---

## 1. 它是什么(按代码逐层)

- `Low` = 分钟 K 线的最低价,**价格水平**(正、日内相对离散度只有 0.5%~5%),不是收益。
- `day_skew(Low)` = `C._skew` 沿分钟轴 → **当天 241 个分钟最低价这个分布的偏度**。
  **名实不符 ①**:名字像「下行尾部风险」,实际是**价格路径水平分布的不对称**,与尾部风险无关,也几乎与价位无关。
- `cs_demean(x) = x − cs_mean(x)`,`cs_mean` 是**全市场当日 nanmean 再广播**(`nd_cs.py:113`)→ 中心是全市场的,不分板块、不分市值。
- `abs_(x) = |x|`。所以信号 = **「这只票今天的日内路径形状,离今天全市场的平均形状有多远」**,是个两侧对称的**异常度**。
- 方向 −1 → 买 `abs(B)` 最小的 → **多头腿买「路径形状最平庸」的票**。
  **名实不符 ②**:名字里没有一个字说它是个**折叠出来的中心度因子**,而这就是它的全部内容。

折叠这件事被三条互相独立的代码事实钉死(都是**噪声标尺**,不是三个发现):
- `sqrt(x) = sqrt(abs(x))`(`common.py:198`)→ `sub_C_sqrt` 与原式**秩等价**:+1.5% 对 +1.7%,ρo 0.97。
- `pow_2` 同样单调于 `abs(B)` → `sub_C_pow_2` +2.3%,ρo 0.92。
- `cs_normalize` 是正仿射 → `sub_B_cs_normalize` 与原式**完全秩相等**:+2.0%,ρo **0.99**。
  → 四行落在 +1.5~+2.3% 的带子里,**±3pp 的噪声带在这条因子上是对的**。
- **名实不符 ③(算子陷阱)**:`pow_05(x) = sign(x)·abs(x)^0.5`(`e ≤ 1` 保号),**不是 sqrt**;所以 `sub_C_pow_05` 其实是 iso:
  −24.4%、ρo −0.04,和 `iso_B` −31.9% 同族。而 `log(x) = log(abs(x))`,`abs(x) ≤ EPS` 时 NaN —— 它单调于 `abs(B)`,
  但**恰好把最靠近中心的票 NaN 掉了,那正是多头书**:`sub_C_log` −0.1% 对 +1.7%,就是丢掉中心票的罚金。

## 2. 预测力在哪

**承重:折叠本身,和折叠绕的那个中心。**
- 去掉 `abs_`:`iso_B = cs_demean(A)` **−31.9%**、Lshp −4.25;`iso_A = A` −31.7%;`sub_C_neg`(方向 +1)同一行。
  而 iso 的**空头腿** tr +11.0% / va −1.0% —— **原始偏度的两头都跑输,中间跑赢**:U 型是真的,左尾(低偏度)比右尾坏得多。
  这就是折叠在吃的东西。
- 去掉 `cs_demean`:`abl_B = abs_(A)` **−5.4%**,**比什么都不做更差**;`abs_(cs_winsor(A))` −6.5% 复证。绕 0 折叠没用,中心必须是当日截面的。
- 折两次就塌:`fold_sq` −1.4%、`fold_mean` −4.4%、`fold_rank` −7.9%。

**多余(删了不掉,在噪声内):** 外层所有保序变换 —— `abs_` / `pow_2` / `sqrt` 互换、`cs_normalize` 的除以标准差、
输出端 `cs_winsor`(win +1.6%)、输出端 `cs_rank`(rk +0.7%)。**最小的诚实写法就是「A 离当日截面均值的距离」,再也删不动。**

**叶子完全可换,而且都接近零:** Low +1.7 / Close +1.9 / Open +2.1 / High +0.8 / Vwap −0.5%,ρo 0.93~0.95。
**「Low」没有任何专属信息**;Vwap 最差也自洽(分钟内均价把路径磨平了)。

**窗口:原树里没有窗口。** 扫描里的 `memory` 不是视界平台而是**换手平台**:
`cross_ema` 5/10/30/60 = +6.0 / +6.0 / **+6.6** / +6.1;`cross_mean` 5/10/30/60 = +5.2 / +5.3 / +5.5 / +5.9;
`cross_decay_linear` = +5.1 / +5.7 / +5.8 / +6.1。窗口跨 12 倍、数字全平,而 LTO 从 10.9% 掉到 2.8%~5.8% —— **+4~5pp 全是省下来的成本**。
改变了对象的记忆都更差:`cross_min60` +2.4%(ρo 0.16)、`cross_max*` +1.4~+2.5%、`rel60` −5.3%(两段同号为负);
`cross_zscore` 5/10/30/60 = **−28.5 / −22.8 / −12.7 / −9.9%**(LTO 升到 35.6%)—— 把一个已经折叠过的距离再按个股自身 z 化,等于把水平量变成churn。

**唯一换了对象的替换:`day_skew → day_gini`。** 见 §3。其余路径形状替换全废:
`day_kurt` −2.7、`day_hurst` −5.0、`day_autocorr_n1` −4.9、`day_ar1` −5.7、`day_argmax` −3.4(dist 0.06 ✗)、`day_argmin` −5.2(dist 0.06 ✗)。

## 3. 在市场的哪儿、什么时候有效

**最要命的一张表是成交额五档的「段内」。** 原式 [0] 在五档里分别 **−8.1 / −6.4 / −3.7 / −1.6 / −2.4%** —— **每一档都是负的**,
而全市场多头书 +1.7%。书对最低成交额档超配 **+16.5pp**、对最高档低配 −11.4pp;那一档的**段等权超额是 +15.1%**(2018–2023 的 A 股小盘/低流动性溢价)。
→ **原式多头腿的净超额 100% 来自流动性倾斜,控住流动性之后它在每一个桶里都亏钱。**
这解释了四行中性化为什么一起翻负:`bk_liq` −2.5、`res_liq` −2.7、`bk_known` −3.3、`res_known` −3.4%(两段同号)。
也解释了倒 U:流通市值 +1.4 / +3.3 / **+5.3** / −3.3 / −6.5;价格 −3.6 / +1.9 / +1.8 / +1.9 / **−8.1**。

**原因(推断)**:`day_skew` 作用在**稀疏的分钟价格路径**上,主要读的其实是「今天在几个价位上成交过」——
薄票的分钟最低价序列是一条台阶,偏度由台阶的份额决定,和「路径形状」没关系。所以它在做一个嘈杂的**薄度排序**,
把书推向低成交额的票;一旦流动性固定,剩下的「形状最像大盘」只是「今天跟着指数走、没有特异资金」,没有理由预测明天,
还要为此付 10.9% 的日换手。
**可检验推论(→ 第二批 E 组)**:直接量薄度的原子按同样方式折叠(`day_zero_ratio` / `day_flat_run_max` / `cross_valid_count`)应复现甚至超过原式;
一条**裸的**薄度水平(`cross_mean(day_zero_ratio(Ret), 30)`,不折叠)应能复现记忆家族的 +5~6%。

**科创板是被主动毁掉的一段:段内 −24.3%**(占 4.0%,段等权 +4.1%,书还超配 +0.8pp),所有变体在那里都坏(gini −19.9、记忆 −11~−22、已知族只有 +1.4)。
科创板是 20% 涨跌幅、200 股起、价位高、票大多又新;全局 `cs_demean` 的中心由 96% 的 10% 涨跌幅票定，
**「坐在全市场平均偏度上」的科创板票其实是一只不典型的科创板票**。这是「换条件中心」(→ A 组)最硬的理由。

**冻结盘口段(6.5%,段等权 −67.4%):原式段内 +8.5%** —— 少数真选到股的地方(钉住的一天 `day_skew` 退化成极值,被排出多头书);
而**所有记忆版在那一段 −23.7% ~ −40.5%**,已知族 −10.9%。EMA 拿着一只现在已经钉住的票的「过去很平庸」评分继续持有。
**所以记忆家族那 +4~5pp 的省成本,是用唯一有选股力的那一段的爆仓换来的。大表里一个筛子形态都没有**(→ D 组)。

**时段**:原式 2018 +4.1 / 2019 +2.4 / 2020 +1.9 / 2021 **−3.9** / 2022 +0.6 / 2023 +7.1 —— 无趋势、骑在零上。
而且它是个**市场方向赌注**:近 20 日上涨 +6.2% 对下跌 **−4.1%**;放量 +5.6% 对缩量 −1.5%;高波动 +4.0% 对低波动 −0.6%。
一条超配低流动小票的多头书在涨势/放量里赚、在跌势里还回去 —— 这是流动性风险载荷的形状,不是 alpha。

**`sub_A_day_gini = abs_(cs_demean(day_gini(Low)))` 是全表唯一的例外:+10.0 / +5.4 / +8.7%,Lshp +2.39 / +1.26 / +2.07,
LTO 9.7%,ρo 只 **+0.27**、ρk +0.33,cov 1.00 / dist 0.96(过门槛)。**
按代码(`ops_ext.py:133`)`day_gini(x)` 是当天各分钟 `abs(x)` 的基尼。喂给**正的、紧的价格水平**时,
基尼 ≈ 平均绝对两两差 / (2·均值) ≈ c·(σ/μ) —— 近似高斯时恰好 σ/(μ√π);完全钉住的一天恰好得 0。
**名实不符 ④,也是本研究最有后果的一条:它根本不是集中度,是「无尺度的日内相对波动」。**
折叠 + 方向 −1 之后多头书 = **「日内相对波动最接近全市场中位水平」的票** —— 一道既不买死票(停牌/钉价/无成交)、也不买疯票(涨跌停/消息/逼空)的筛子。
它的解剖和原式**处处相反**,与这个读法一致:
- 成交额五档段内 **+5.9 / +0.6 / +0.7 / +3.0 / +10.7%** —— **全正、且随流动性上升**,倾斜很小(+5.3…−7.3pp)。流动票里每分钟成交多,相对波动**测得准**。
- 下跌市 **+7.7%**(全表唯一不塌的;原式 −4.1、记忆 −0.2~−1.6)、高波动 **+14.7%** 对低波动 +2.8%、放量 +13.3% 对缩量 +5.0%。
  高波动/放量时截面的相对波动分布被拉宽、信息量大,这正是「中位波动」这道筛子该起作用的时候。
- 上市不足 250 日段内 **+14.8%**(全表最好;原式 −3.2、已知族 +8.6);创业板段内 +10.8% 且是全表唯一超配创业板的书(+12.1pp)。
**但要诚实**:train→valid 从 +10.0% 掉到 +5.4%、夏普 2.39 → 1.26(**夏普这一侧超出 ±0.3 带**),逐年 2019 +15.7 单调降到 2022 +4.3;
valid 净超额比已知族低 **17pp**。所以**它是线索,不是候选**。它唯一值钱的点是 ρk = 0.33 —— 可能的去相关腿(→ H 组)。

## 4. 相对已知成交额族的增量:没有,四条证据彼此独立

1. ρk 只有 +0.28 —— 它**不是**已知族本身。
2. 但剥掉已知族之后多头腿**翻负**:`res_known` −3.4%、`bk_known` −3.3%(两段同号);换成裸流动性控制一样(`res_liq` −2.7、`bk_liq` −2.5)。
3. **overlay 阶梯从家族单独开始单调下坡**:+15.4(k_known)→ +13.6(w=0.25)→ +13.1(0.5)→ +12.5(1.0);
   负权重更差(+10.7 / +8.3 / +4.9)。**没有任何权重能让混合超过家族单独**;最好的那条 ov_p025 的 ρk 已经 0.96,就是家族掺了 4% 的水。
4. §3 的桶内分解说明了为什么:**家族的边就是那个流动性倾斜**(它对最低成交额档超配 **+80.3pp**!),
   原式是同一个倾斜的更弱、贵 3 倍的版本(LTO 10.9% 对 3.4%)。

→ **F107 按原式写,相对 k_known 零增量,对纯多头不可用。** 这和上一轮 −6.1pp 的留出段结论从完全不同的路径复现了一遍。
全表唯一有独立内容嫌疑的只有 gini 分支,而它是**穿着同一件外套的另一条因子**。

## 5. 改进方向(= 第二批 40 条,`studies/F107_abs_demean_skew_low/hypo.yaml`)

- **(A) 换条件中心,不换折叠**:`abs_(cs_regres(A, cs_rank(known)))`、`abs_(cs_demean(cs_bucket_rank(A, known)))`。
  大表只在**折叠之后**做中性化;「绕桶内中心折叠」从来没试过,而倒 U / 科创板 / 两头极值全指向中心错位。

  喂有符号字段(Ret / Amt)拿回**真**集中度、以及给它记忆(它 LTO 9.7%,记忆对原式白送 +4~5pp)。
- **(D) 筛子**(大表零覆盖):保住记忆的省成本、用 `cs_last_high20(·, 近 15 日零收益分钟占比)` 删掉 −40% 那一段;

- **(E) 机制反证**:薄度原子折叠后能否复现原式;裸薄度水平能否复现记忆家族。否定了也合格。
- **(F)(G) 换最小的子结构**:带顺序的路径统计量(`day_centroid` / `day_signed_ratio` / `day_pos_ratio`),
  以及把价格水平叶子换成变化率(`day_skew(Ret)`、`in_pct(Close,5)`、`in_logchg(Amt,5)`——用户提示的同类互换)。
- **(H) gini 的增量三件套**:overlay、`res_known`、与记忆版的两腿相加(ρo 只 0.27,时段互补)。

### 1. 对账(八组逐组裁决)

**(A) 条件中心 —— 前提是错的,而错法是本轮最大的发现。** `h_cc_regres_known` ρo **0.99**(+2.0%)、`h_cc_regres_price` ρo 0.99(+2.2%):
把中心换成流动性 / 价位条件均值,**交易信号一点没动** → `day_skew(Low)` 与流动性、价位几乎无截面关系,**中心没错位**。
可是先桶内百分位再折叠就翻负(`h_cc_bucket_pre` −3.1,与折叠后再中性化的 `bk_known` −3.3 同值),`h_cc_bucket_pre_gini` 从 +8.7 掉到 +0.8(→ §2)。
唯一例外 `h_cc_regres_gini_known` **+13.4/+21.7/+15.8%**、Lshp 2.13/3.56/**2.53**(utrain 净超额全表最高),但 ρk **0.71**、最低成交额档超配 **+57.9pp**、LTO 6.0%
—— 先取残差再折叠,把残差的异方差重新折成流动性代理:**是已知族的另一种写法**(对 `k_known` 持平,对 `k_known_xfrozen` −2.7pp / −0.62 夏普,还贵一倍)。

**(B) 换折叠方式 —— 四条全否、全在噪声内。** `h_fold_median` ρo **1.00**(+1.1)、`h_fold_winsor_first` ρo 0.96(+1.4)、`h_fold_rankfirst` ρo 0.88(−0.2)。
「偏度的截面分布自己偏、均值中心被尾巴拖走」**不成立**:均值与中位数在这个量上重合到秩相等。
gini 上 rank-first 明显更差(+5.2 对 +8.7,LTO 9.7→11.8%)→ gini 的**水平**带信息,秩化会丢掉。

**(C) 追 gini —— 机制确证,并找到更干净的写法(本轮最有价值的一组)。** `h_vol_cv_low = abs_(cs_demean(div(day_std(Low), day_mean(Low))))`
+11.0/+5.4/**+9.4%**、Lshp 2.65/1.28/2.26、LTO 9.7%、ρk 0.32 与 `sub_A_day_gini` +10.0/+5.4/+8.7、2.39/1.26/2.07、LTO 9.7%、ρk 0.33 **逐位相同**
→ **`day_gini` 喂正的紧的价格水平 = c·σ/μ,确证(名实不符 ④ 坐实)**。不除以价位就死(`h_vol_std_low` 方向翻成 +1,−7.5%)、喂有符号字段就死(`h_gini_ret` +2.5、`h_leaf_gini_inpct` −0.5)、
用极值写的相对振幅在 valid 塌(`h_vol_range` +10.0/**+1.4**/+7.6,Lshp va 0.31)→ 承重的恰好是「用标准差写的、无尺度的相对波动」;字段仍全可换(`h_gini_close` +8.7)。
折叠承重**只在 train 段**:`h_gini_iso` −9.2/**+5.8**/−4.9、`h_gini_iso_demean` −8.5/+5.9/−4.4(两者同值,cs_demean 是仿射)→ train 折叠值 19pp,**valid 段 U 型消失,引用必须标注**。

**(D) 筛子 —— 六条的方向全被写反了,「剔除」根本没被测到。** `cs_last_high20(y, x)` 只有在「y 高 = 要买」(sg = +1)时才是排除筛子;
通用行都包了 `neg(...)`(`scr_xhi_p`、`k_known_xfrozen` 都是 sg +1),我写的 y 是「低的好」,train 选 sg = **−1**,多头书于是变成**只买被标出的那 20%**:
`h_scr_price_mem`(本意剔最贵)= 只买最贵 20% → −1.5%;`h_scr_star_mem`(本意剔科创板代理)= 只买它 → −4.0%。
**这两条反过来确证了解剖**(价格最高档段内 −8.1%、科创板 −24.3%),但那个洞能不能靠剔除修好仍然未知。
`h_scr_frozen_mem` / `h_scr_frozen_gini` 实际是「只在最薄的 20% 里按平庸度选」(+3.7/+15.0/**+7.0** 和 +4.4/+14.8/+7.5,LTO 4.1% / 2.0%)—— utrain 持平、夏普更差、赚钱全在 valid;

### 2. 机制结论:折叠量的是异方差,不是距离

三条独立证据只允许一种读法:(a) 换中心无效(ρo 0.99 / 1.00)→ 中心没错;(b) 折叠**之后**中性化翻负(−3.3 / −3.4);(c) 把异方差抹掉**再**折叠也归零(rank-first −0.2、bucket-first −3.1)。
→ `abs_(cs_demean(x))` 的大小主要由「x 在这一类股票里方差多大」决定,而不是由这只票离中心多远决定;方向 −1 必然把书推到 **x 最稳的那一类**(对 `day_skew(Low)` 是薄票,最低成交额档超配 +16.5pp)。
**原式那 +1.7% 是折叠生出来的薄度倾斜 —— 它不是薄度的代理,是异方差的代理,而薄度恰好是异方差最大的地方。**
反面验证:`day_std(Ret)` 的截面离散度几乎不随流动性变,折叠它就**不生倾斜**(+2.2/+2.4/−0.3/−2.3/−2.0pp),段内也就全正(§3)。
同一把尺子还解释了 `h_cc_regres_gini_known` 的 ρk 0.71(残差的异方差 → 又一个流动性代理)和 `mem_zscore*` 的 −10~−28%(把水平量变成 churn)。

### 3. 定论(只凭 train / valid)

**best_own(不含已知族成分)**:① `h_gini_ema30 = cross_ema(abs_(cs_demean(day_gini(Low))), 30)` +11.7% / Lshp **2.87** / LTO 4.0% / ρk 0.35 —— 非家族里 utrain 夏普最高,但 **valid 两侧全败家族**(+7.8 对 +22.3、1.85 对 3.46),不是候选;

低配最小市值档 −12.0pp 还赚钱,下跌市 +7.0 / 上涨 +10.3、高波动 +8.1 / 低波动 +9.2(全表最平)、六年无负年、冻结盘口段内 +7.9%。**本研究唯一不靠倾斜赚钱的版本。**
③ `h_vol_cv_low` +9.4% / 2.26 —— 机制确证用,被 ① ② 支配。
**best_on_known**:`h_cc_regres_gini_known` +15.8% / 2.53(ρk 0.71)—— 对 `k_known` 持平(+0.4pp / +0.31,都在噪声边上)、对 `k_known_xfrozen` **明确更差**(−2.7pp / −0.62)且贵一倍;
筛子方向无一过关(`scr_xhi_p` +12.7、`scr_xhi_m` +5.9),overlay 阶梯仍单调下坡。→ **建在已知族上没有任何用法强于基准。**

**one_line**:原式的多头腿收益是 `abs_(cs_demean(·))` 折出来的薄度倾斜(换中心 ρo 0.99、抹掉异方差后归零),相对已知族零增量;
s2 唯一的真东西是从它身上剥出来的 `abs_(cs_demean(day_std(Ret)))`(段内全正、倾斜 ≈ 0、ρk 0.19),但净超额仍低家族 6.7pp —— 那是另一条因子,不是 F107 的提纯。

**verdict**:**原式 = 已知族的更弱更贵版本,多头腿不可用**(第三条独立路径复现,且这次说清了钱从哪来)。**不是提纯**(换中心 / 换折叠 / 桶内化 / 中性化 —— 要么零变化要么翻负);
**也当不了筛子**(给已知族当筛子 +12.7 < +15.4)。gini / 波动分支是**另一条因子穿着同一件外套**,机制坐实为「日内相对波动的截面中位度」,但相对已知族同样零增量(res_known valid −1.3)。
→ F107 本体结案(维持 `recommended_id = f_m20`、`known_family`);`abs_(cs_demean(day_std(Ret)))` 连同第三批 A / B / F 三组**另立一个研究**,不要再挂在 F107 名下。
