## 3. 研究过程与逻辑(做了什么、按什么顺序、为什么这么走)

1. **先读源码,不信表达式的字面意思**(`02_operators.md`)。字面上这是「右尾 ES/VaR 减左尾 ES/VaR」,一个无量纲的尾部形状不对称量。
   读完源码发现**两个分母都是「分位数 + 1e-6」**,而 A 股分钟收益里有大量精确的 0 → 这个 `1e-6` 是整棵树的要害。
2. **用探针在服务器内核上量出「有三个取值区间」**(`03_decomposition.md`):上涨分钟 ≥ 13 个 → 常规(读数 1.0~3);
   上涨分钟 **≤ 12 个** → **塌缩**(读数 = 尾内均值 × 10⁶,一个 0.2% 的 tick 就给 2000)。整棵树在四个角上的读数:
   只有上涨稀少 → **+2039**;只有下跌稀少 → **−2039**;两边都稀少且幅度相同 → 0;两边都不稀少 → 0;全天不动 → 0。
3. **推出「截面两端一定是塌缩日」**,并且**塌缩区间里 X 不再无量纲**(齐次度从 0 变成 1:放大收益 2 倍,X 变 2.0005 倍)。
   再加上**口径是先 EMA 再排序**:hl 20 的 EMA 里一个 +2000 的塌缩日要 **20×log₂(2000/0.3) ≈ 250 个交易日**才衰减到常规量级以下
   → 实际交易的信号 ≈「过去一年里塌缩日的带符号、按幅度加权的累计」。这是**从公式推出来的预期**,必须在真实数据上量 → 这就是 x1。
4. **先定假设表再跑实验**(`05_hypotheses.md`,H1~H9),然后 S0 复现基线、x1 在真实数据上一次性解剖(A~G 七块)。
   x1 的设计很省:它用 numpy 在本地算了九种构造的两本书(E 表),**不花服务器轮次**,只用来分辨。
5. **这一轮(主研第 1 轮)**:我核对了上面全部数字,裁决了 H1~H9,并且发现**唯一还没回答的问题**是
   「对纯多头用户,它相对已知家族有没有增量」。上一位研究员已经为此写好了 `x2_longonly.py`(211 行,带 selftest)**但没来得及跑**

### 源码里和名字不一样的地方(下一个人最容易在这里重复花时间)

1. **`day_quantile(x, q)` = `torch.nanquantile`,线性插值**。241 个分钟全有值时 q=0.95 的位置是 0.95×240 = **228.0**,恰好是一个顺序统计量
   (从小到大第 229 个 = 第 13 大),**不插值**;少一个分钟(240 个有效值)位置变成 227.05 → 两个相邻顺序统计量的 5%/95% 加权。
   所以「95% 分位数恰好为 0」的条件是 **上涨分钟 ≤ 12 个**。
2. **`is_gt` / `is_lt` 是严格不等号,NaN 比较为假 → 输出 0(不是 NaN)**。两个后果:
   (a) 与分位数**并列**的分钟不进尾部 —— 分钟收益并列极多,尾部集合可以远少于 12 个甚至是**空集**;
   (b) 缺失分钟经 `select_where` 变成 0 而不是 NaN → 整棵树对「部分分钟缺失」**没有 NaN 传播**,只有整天缺失才输出 NaN。这就是 **cov = 1.00** 的原因。
3. **计数分母上的 `+1e-6` 是纯粹的除零保护**,不改变任何非空情形的值(空集时 0/1e-6 = 0)。
   **分位数分母上的 `+1e-6` 才是要害**:它是**带量纲**的常数(收益单位),比一个 tick 的收益(10⁻³ 量级)小三个数量级 → 分位数为 0 时比值放大 10⁶ 倍。
4. **右侧分母是 `q95 + 1e-6`(没有绝对值)**,左侧是 `|q05| + 1e-6`。q95 理论上可以为负(>229 个分钟在跌),实际极少。
5. **整棵树在服务器上关于 Ret 是精确的奇函数**(探针 `max|tree(r)+tree(−r)|` = 0.0)。
   ⚠️ **本机那份 torch 把 0.95×240 算成比 228 略小**,右尾会多收进分位数本身那一个分钟(13 对 12)。
   **本机不是事实来源,以服务器为准。**
6. `create_like(x, 0)` 用的是**整数 0 → int64**;`create_like(x, 1e-06)` 是 float32。`torch.where` 类型提升后是 float32,数值没问题,只占内存。
7. **这棵树里没有任何日轴算子**:纯粹「当天 241 个分钟 → 一个数」,真实回看 **1 天**。全部时间结构来自口径里的因果 EMA(半衰期)。
