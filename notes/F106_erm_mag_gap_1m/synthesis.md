# F106_erm_mag_gap_1m —— 批量扫描 s1 + 市场解剖的综合(主研,一轮)

数据来源:`runs/F106_erm_mag_gap_1m/sweep_s1.json`(152 个有效变体)与 `anatomy_s1.json`(23 个股票段 × 14 个时段 × 10 条信号)。
口径:多头腿扣 15bp 的净超额 Lnet、纯多头夏普 Lshp,方向与半衰期在 train 上拟合。基准 `k_known = cross_mean(day_std(Amt), 30)` = **+12.6% / +22.3% / +15.4%**(tr/va/ut),Lshp +2.22。噪声 ±3pp、夏普 ±0.3。

**一句话:原式是「最近有没有一天几乎只往一个方向走、那几分钟跳多大」的一年期线性记忆,多头腿在 train/valid/utrain 三段全负(−6.9% / −3.2% / −5.8%,Lshp −1.91),152 个变体里没有一个变体的多头腿能接近基准;相对成交额族没有增量(六条 overlay 单调恶化)。结论类型 = 分辨。大表相对前几轮新增的硬事实:承重的是「分位数当分母 + 1e-6」这一个节点(删掉它 LS 从 +2.82 掉到 +0.06),以及**全市场 23 个段里它只在 6.5% 的冻结盘口段会选股(段内 +18.2%),而那个段一年亏 67.4%**。

## 1. 它是什么(按算子定义逐层;SSA 节点字母沿用 `03_decomposition.md`)

读到的函数定义(`study.sh src`):`day_quantile` = `torch.nanquantile(x, q, dim=-1)` 按分钟轴;`is_gt/is_lt` 返回 **`.int()` 的 0/1**(严格不等);`select_where` = `torch.where(x.bool(), y, z)`;`day_sum` = 分钟轴求和;`create_like` 按**第一个参数的形状**铺常数,**dtype 由常数推**(`create_like(Ret, 0)` 是 int64,`create_like(q, 1e-06)` 是 float32)。

| 层 | 节点 | 实际算什么 |
|---|---|---|
| 阈值 | A=`day_quantile(Ret,.95)`、L=`day_quantile(Ret,.05)` | 当天 241 个分钟收益的 95% / 5% 分位数 |
| 事件 | B=`is_gt(Ret,A)`、M=`is_lt(Ret,L)` | 严格越过阈值的分钟的 0/1 掩码 |
| 尾内幅度 | E=`day_sum(select_where(B,Ret,0))`、P=`day_sum(select_where(M,\|Ret\|,0))` | Σ 上尾收益、Σ 下尾收益的绝对值 |
| 计数 | F=`day_sum(B)`、Q=`day_sum(M)` | 尾内分钟数(常规约 12) |
| 尾均值 | I=E/(F+1e-6)、T=P/(Q+1e-6) | ES⁺、ES⁻ |
| 归一 | K=I/(A+1e-6)、W=T/(\|L\|+1e-6) | ES/VaR |
| 输出 | X=K−W | 右尾 ES/VaR − 左尾 ES/VaR |

**名字与定义不一致的四处:**
1. **两个 `+1e-6` 写法相同、作用相反。** 计数分母的那个(F+1e-6、Q+1e-6)只是除零保护:`|U|=0` 时 `Σ_U r` 也是 0,读数 0/1e-6=0。**分位数分母的那个是整条因子**:当天上涨分钟 ≤ 5%(约 ≤12 根)时 `A=0`,K = ES⁺ × 10⁶。证据在 §2。
2. **「mag_gap」(幅度差)在它有方差的地方恰好反了。** 常规区间里 X 是齐次度 0 的无尺度量,被钉在高斯值 1.254 附近(std ≈ 0.10),**不含任何幅度信息**;只有在塌缩区间里它变成齐次度 1,读「那几分钟平均跳了多大」。
3. **「1m」不是时间结构。** 树里**没有一个日轴算子**,真实回看 1 天;信号的全部时间结构来自口径的因果 EMA(hl 20),一个 +2000 的塌缩日要约 250 个交易日才衰减回常规量级。
4. **`day_sum` 写在该写均值的位置**(靠后面除以计数变成均值);`abs_` 对两处都是装饰(§2 乙)。

## 2. 预测力在哪

### 甲 承重:只有「分位数当分母 + 1e-6」这一个节点(一换就塌)
| id | 改了什么 | Lnet ut | Lshp ut | LS tr | ρo |
|---|---|---|---|---|---|
| `v_base` | — | −5.8% | −1.91 | **+2.82** | +1.00 |
| `abl_G` | A+1e-6 → **A+A**(只去掉塌缩,其余全留) | −3.6% | −0.82 | **+0.06** | −0.26 |
| `abl_J` | A+1e-6 → **A**(除以 0 变 ±inf) | −8.5% | −1.93 | **−1.59** | +0.46 |
| `abl_V` | \|L\|+1e-6 → **\|L\|** | −5.8% | −1.73 | **−1.14** | +0.40 |
| `abl_R` | 1e-6 → L(\|L\|+L≈0) | n/a | n/a | n/a | cov 0.00 全 NaN |

`abl_G` 是最干净的一刀:结构一点没动,只把塌缩抹平,**公布的多空夏普 +2.82 立刻变成 +0.06、ρo 变成 −0.26**。配合半衰期网格(v_base train,hl→[Lnet, Lshp, LS]):hl0 `[−67.2%, −19.51, −25.67]` → hl3 `[−25.8%, −8.16, +0.09]` → hl20 `[−6.9%, −2.15, +2.82]` —— **多空夏普在 hl ≥ 3 才转正,整条 +2.82 是线性 EMA 把稀疏大数拖成缓慢状态造出来的**,不是任何一天的信号。(对照:`k_known` 的网格单调相反,hl0 `[+12.6%, 1.78, 1.87]` → hl20 `[+8.4%, 1.21, 1.30]`,它是真的日频持续状态。)

**次承重:掩码要带幅度,不能只数事件。** `abl_D`(上尾分子 Σ 收益 → 计数)ut **−32.7%**、LS −3.56、ρo −0.52;`abl_O`(下尾同样)ut −27.6%、LS −2.49。**抹掉幅度的三种做法全部更差**:`rk`(EMA 前 cs_rank)ut −12.9%、换手 2.4%→15.3%;`win`(EMA 前缩尾)−9.6%、换手 13.1%;`rank_X`(两腿各自排名再相减)−10.4%、LS **−1.01**。→ 常规区间的尾部形状**没有多头信息**,全部内容是塌缩日的带符号幅度。

### 乙 多余:删了不掉(ρo ≥ 0.98,数字逐位相同)
- `sub_U_neg`、`sub_N_neg`(`abs_` → `neg`):**ρo +1.00,Lnet/Lshp 与 v_base 完全相同** —— 取绝对值的两处对象本来就是负的,`abs_` 不携带信息。
- `sub_H_sub`、`sub_S_sub`(计数分母 `+1e-6` → `−1e-6`):同样逐位相同;`abl_H`(整个删掉)ut −5.7%、ρo **+0.98**;`abl_S` ut −7.8%、ρo +0.84。→ **计数侧的 1e-6 是装饰**。
- `abl_N`(分子去掉 `abs_`)与 `sub_X_add`(末端 sub→add)**逐行相同**(−3.2%/−3.3%/−3.2%,ρo +0.47):代数上确实等价,也证明两条腿是严格镜像构造的。
- **计数可以整个删掉**:`only_H_R`(把 F+1e-6 换成 1e-6)、`sub_F_day_first/last/close`(计数的 `day_sum` 换成取某一分钟)ut **+1.5%**、valid **+10.4~+10.8%**、ρo +0.57 —— 这是全表非 overlay 里最好的一族,但 utrain 仍在噪声内。

## 3. 在市场的哪儿、什么时候有效

**v_base 在 23 个段里 22 个段内为负,唯一的正数是「近 15 日有冻结盘口(封板/停牌)」:段内 +18.2%**(该段占 6.5%、自身等权超额 **−67.4%**/年),而全市场多头书**超配这个段 +4.6pp**。干净段(93.5%、等权 +3.7%)段内 **−6.9%**、低配 −4.6pp。
其余各档都没有倾斜可言:流通市值五档段内 −5.8 / −7.4 / −13.1 / −11.3 / −7.8(书权重 −4.4~+4.3pp),成交额五档 −5.3 / −9.5 / −9.7 / −12.5 / −6.9,价格五档 −5.3 / −10.9 / −10.6 / −8.7 / −8.5,次新 −15.0%。板块上最差的是**科创板 −23.6%**(4.0%,而该段自身等权超额是四个板块里最好的 +4.1%)。
时间上没有任何状态救得了它:六年全负(−9.2 / −6.0 / −8.5 / −4.0 / −0.6 / −7.2),市场上涨段 −7.2% 比下跌段 −3.7% 更差,高/低波动 −5.6/−6.0,高/低离散 −6.2/−5.3,放量/缩量 −5.4/−6.1。

**机制推断。** 塌缩条件「某一侧分钟数 ≤ 5%」在 A 股的现实对应物是**封板钉价、停牌前后、以及 3 元以下股票的 tick 网格**(探针:日波动 0.6% 时 2 元股 92% 的日子右侧塌缩,5 元以上为 0)。方向 sg = −1 → 多头腿买的是**下跌侧塌缩**的票,即「几乎只往上走」的票 = 刚封过涨停板的票;空头腿(底腿 tr −27.9% / va −22.4%)是上涨侧塌缩的票。所以它本质是一条**彩票需求 / MAX 效应代理**:对多头是反的、对空头是对的,而空头那一端次日买不进(前几轮已量出:去塌缩日后多空夏普 2.82→0.42)。冻结段里 +18.2% 说明**「在已经封过板的票里挑哪一只」这件事它确实会**;干净段里 −6.9% 说明**它在正常票里是主动做错**(EMA 记忆跨 250 天,干净段的排序由几周到几个月前的封板残留决定 → 买的是封板后的反转输家)。段内数字来自各段自建的书,严格归因做不了,但符号是明确的:**它唯一的选股力在一个不该进的段里,而书的绝大部分在它做错的那个段里。**

**如果这个机制成立,还应该看到(可检验推论,已写成第二批假设):**
- (R1) 用**无 eps、有界**的状态量(`day_zero_ratio(Ret)`、`day_flat_ratio(Close)`)直接读「钉住」,应当复现底腿并且换手仍在 2% 量级 → `h_zero_m30 / h_zero_max15 / h_flat_c30`。
- (R2) 冻结段应当能按机制再分裂:**价钉住但成交额还在变 = 封板排队**,两者都冻 = 停牌/无成交;+18.2% 应只来自前者 → `h_flatdiff_m30`。
- (R3) 若常规区间真的空,**只保留非塌缩日**的 X 应当接近 0 收益 → `h_regular_gate` / `h_blown_gate`(两条相加等于原式)。
- (R4) 把分母换成不会塌的尺度(`day_std(Ret)`、`day_median(|Ret|)`)后应当什么都不剩 → `h_tail_vol / h_es_vol / h_es_mad`;ε 阶梯 1e-3 / 1e-2 应当量出「排序由塌缩决定」的强度 → `h_eps3 / h_eps2`。
- (R5) 科创板最差 + 创业板次差 ↔ 涨跌幅限制 20% 与 10% 的差别:限制越宽,钉价越少、塌缩日越多地来自真实的流动性枯竭 → 用 `h_zero_max15` 在板块段上看符号是否随限制宽度变。

## 4. 相对已知成交额族的增量:没有

- **ρk = +0.01**(近乎正交),但**六条 overlay 全部严格差于基准单独**,并且随权重单调恶化:`ov_p025` +12.6%(ΔLnet **−2.8pp**)、`ov_p05` +11.6%、`ov_p10` +10.3%、`ov_m025` +10.7%、`ov_m05` +9.0%、`ov_m10` +6.2%(ΔLnet −9.2pp)。**两个方向都伤**、幅度随 |w| 增大 → 这是稀释,不是方向搞反。
- `res_known` −12.2%(Lshp −2.26)、`bk_known` −12.3%、`res_liq` −11.7%、`bk_liq` −12.1%,换手全部从 2.4% 炸到 15.4% → 正交化之后什么都没剩(`bk_*` 还因 dist 0.20 不过门槛,见 §5)。
- **本轮新事实(解剖给出的):基准自己的多头腿是段间倾斜,不是段内选股。** `k_known` 在成交额五档的段内是 −4.1 / −5.3 / −8.2 / −5.2 / **+2.5**(四档为负),而它的书**超配最低成交额档 +80.3pp**,那一档自身等权超额 +15.1%/年。→ 想对它有增量,要加在**低成交额桶内部**(它在那儿不选股),不是加在全市场排序上。
- 同一把尺子量 `abl_M`(全表唯一多头腿稳定为正的非 overlay 变体:ut **+3.4%**、Lshp +0.59、换手 2.2%、ρo +0.34、ρk +0.06、**六年全正** +1.9/+5.5/+4.1/+0.7/+3.7/+5.6):它在成交额五档段内是 **−11.8 / −8.5 / −6.3 / −2.8 / −5.4(五档全负)**,却超配最低成交额档 +26.2pp、次新 +16.9pp、科创板 +29.5pp。→ **它的 +3.4% 是和基准同一个机制的、更弱的流动性倾斜**;ρk 只有 +0.06 是因为它在桶内是随机的,**低 ρk 在这里不等于有增量**。结构上 `abl_M` = 删掉下尾掩码,下腿变成 (Σ全天\|r\| / (\|D\|+ε)) / (\|q⁻\|+ε) ≈ 20 × 平均\|分钟收益\| / \|q⁻\|,是一个反尾肥度;值得单独写干净(见 `h_es_mad / h_gini_ret30`),但不要当候选。

## 5. 改进方向(落成 `studies/F106_erm_mag_gap_1m/hypo.yaml`,37 条)

六个方向:**A** 把塌缩换成无 eps、有界的直接读数(10 条;含把上一轮被 dist 卡死的 H11 计数构造用 `cross_mean(·,30)` 救回来);**B** 把会塌的分母换成不会塌的尺度 + ε 阶梯 + 常规/塌缩两区间的互补门控(8 条);**C** 日内形状的替代读数,用新算子做原式做不到的事(`day_gini / day_centroid / day_wmean / day_signed_ratio / in_slice` 去掉隔夜跳空,7 条);**D** 分桶中性,外面套 `cross_mean(·,5)` 把 dist 门槛绕过去(4 条);**E** 用有界状态量而不是炸掉的 X 做 overlay,并按 §4 的新事实把增量打进最低成交额桶内部(4 条);**F** 承重结构的最小改动(阈值 0.90/0.10 与 0.99/0.01 的塌缩频率阶梯、ES 比值而非差值、有界量上的 `cross_zscore`,4 条)。全部 37 条通过 `study.sh hypo`。

**工具问题(都有证据,建议交给协调者):**
1. **`dist` 门槛算在 EMA 之前的面板上**(`scripts/sweep.py:129` `distinct_fraction(p[tr])`),而实际交易的信号是 `EMA(面板)`。计数/占比类面板因此机械地被判死:`iso_F/iso_H/iso_Q/iso_S`(0/1 掩码求和)dist **0.00 ✗**、`bk_liq/bk_known` dist **0.20 ✗**,而它们的 hl20 书换手只有 2.4%、十分位完全可定。**上一轮的 H11 就是死在这里**。建议:dist 改算在 `bk.smoothed(signal, hl_long)` 上,或 hl ≥ 1 时豁免。本批的绕法是外面套 `cross_mean(·, 5~30)`。
2. `cs_bucket_rank` 在算子表里被打上 `[boolean_output,trivial_boolean]`,而它返回 (0,1] 的桶内百分位 —— 标签错了,会误导 propose/GP。
3. 三个槽位浪费在退化变体上(`iso_G`、`iso_R`、`abl_R` 返回全 NaN / cov 0.00):打分前加一个「面板全 NaN 或常数就丢掉」的过滤即可。
4. 表头的 `rank_ic_train` 存的是 `abs(rank_ic)`、方向在 `sign` 里(`sweep.py:122-129`)。读表的人会以为 v_base 是「IC 正而方向 −1」,建议在表头注明。

## 第二轮(s2)对账与结论

数据来源:`runs/F106_erm_mag_gap_1m/sweep_s2.json`(200 个有效变体,含上一轮 37 条 hypo + 2 条 screen + 8 条 segment)与 `anatomy_s2.json`(23 段 × 14 时段 × 10 条信号)。**只用 train 2018–2021 / valid 2022–202308;没有打开 `sweepfinal_s2.json`。** 新基准 `k_known_xfrozen` = `cs_last_high20(neg(k_known), cross_max(day_zero_ratio(Ret),15))`(剔掉近 15 日冻结最重的 20%)**+16.4% / +23.2%,Lshp 2.81 / 3.98**,比 `k_known`(+12.6% / +22.3%,1.78 / 3.46)高 +3.8 / +0.9pp。

### 1. 对账:上一轮的六条推论,四条被否定

| 推论 | 变体与数字(tr / va) | 判决 |
|---|---|---|

### 2. 定论(只凭 train / valid)

**best_own(不含已知族成分):三条,全部在噪声内,都不做候选。**
`abl_M` +3.1 / +4.3、Lshp 0.57 / 0.62、TO 2.4%、ρo +0.34、ρk +0.06 —— 两段同号为正,但净超额在 ±3pp 噪声内,且 s1 已量出它是流动性倾斜(成交额五档**段内全负** −11.8~−2.8、超配最低档 +26.2pp)。
`h_pin_dir30` = `cross_mean(mul(day_zero_ratio(Ret), sign(day_sum(Ret))), 30)` +1.8 / +7.6、Lshp 0.32 / 1.40、TO 2.9%、**ρk 0.00**、ρo +0.18 —— 全表唯一「与已知族正交 + 两段为正 + 低换手」的本因子式读数,train 仍在噪声内。
`h_centroid_ret30` −0.9 / +11.1、TO 1.1%、ρk +0.32 —— train 平 valid 好,两段不一致,只能当线索。

**best_on_known:没有可用用法。** 含 X 的最好三条:`ov_p025` +9.8 / +19.4(Lshp 1.40 / 2.94)、`scr_xhi_p` +8.9 / +15.3(1.34 / 2.59)、`h_ov_regular_p025` +8.9 / +19.2(1.28 / 2.91)。**全部差于 `k_known`(−2.8~−3.7pp),更远差于 `k_known_xfrozen`(−6.6~−7.5pp)。** 作为筛子两个方向都输(`scr_xhi_m` +3.1 / +14.1);解剖显示 `scr_xhi_p` 保住了基准的桶倾斜(最低成交额档 tilt +66.4%)但桶内从 −4.1% 变成 −5.0%。八条 segment 里只有 `seg_lowliq_m` 两段为正(+3.9 / +12.8),而它 TO 8.9%、**ρk +0.77**,是流动性倾斜的翻版。

**结论(verdict)= 分辨,比 s1 更硬。** 多头腿不可用(三段全负),**也不能当筛子、不能当 overlay、任何分桶中性之后段内选股力为负**。它的 LS +2.82 是「涨停板频率」的慢状态,属于空头腿资产,纯多头书用不上。唯一还值得继承的东西不是这条因子,而是它指出的**筛子口径**:`k_known_xfrozen` 用 `cross_max(day_zero_ratio(Ret),15)` 硬剔 20% 就把基准抬了 +3.8 / +0.9pp,而同一个量做成软 overlay 反而掉 3.3pp —— 第三批把筛子口径换成 `day_at_max_ratio` / `day_at_min_ratio` / `day_distinct_ratio`,功劳记给筛子,不记给 F106。

### 4. 工具问题(s1 第 1 条已被本轮证实)

`dist` 门槛算在 EMA 之前的面板上这件事确实在杀假设:外套 `cross_mean(·,5)` 后 `h_bk_liq_sm5` 的 dist 从 `bk_liq` 的 0.20 变成 **1.00**,结果是干净的否定 —— 也就是说上一轮被判死的那个格子里本来就没有东西,但**门槛没让我们知道**。本轮又有 4 条死在同一个地方(`h_blow_sgn30/60` dist 0.00、`h_blow_any30` 0.18、`h_blown_gate` 0.01、`h_zero_max15` 0.06),其中 `h_zero_max15` 正是 `k_known_xfrozen` 筛子用的那个量 —— **它当筛子有用、当因子过不了门槛**。建议照 s1 §5.1 改(dist 改算在 `bk.smoothed(signal, hl_long)` 上),或对 0/1 与计数类面板豁免。
