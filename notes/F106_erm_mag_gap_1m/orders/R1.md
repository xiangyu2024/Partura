## 想回答的问题

整条研究的事实部分已经查清:这棵树是**「最近有没有封过涨停板」的一年期记忆**,而不是日内尾部形状;
它在选拔口径下**原样不可用**(多头腿净超额在每一个半衰期、train 和 valid、毛和净全为负)。
**唯一还没回答的问题是:对只能做多的用户,它相对已知家族有没有增量。** 这张工单要裁决三条假设:

- **H10 排除性增量**:把 F106 标记的票从**已知家族** `cross_mean(day_std(Amt), 30)` 的多头十分位里剔除,多头腿会不会变好。
  → 看到「已知家族多头端里被标记票占比 ≥ 2%,且剔除后多头腿净超额在 train 和 valid **同时**提高 ≥ 1 个点」= **H10 被支持**,升华方向确定。
  → 看到「占比 < 2%,或剔除后多头腿不变 / 变差」= **H10 被杀**,这条因子对纯多头**彻底无用**,研究可以直接进入读留出段。
- **H11 记忆长度错配**:事件效应只持续约 20 天(x1 D),EMA-20 却把读数记约一年。显式的短记忆是不是更好。
  → 短记忆的 rank IC 与多头腿同时改善 = H11 被支持;两者都不优于 EMA-20(X) = H11 被杀。
- **H12 被「近期涨停」替代**(最该杀的一条):日线涨停标记与原式秩相关只有 0.06,但 rank IC 是原式的 6 倍;
  涨停日数量是塌缩涨停日的 4 倍多,而没塌缩的涨停日事后同样跑输 —— 原式只抓到了「封得死」的五分之一。
  → 中性化后残差的 rank IC 与多头腿增量塌掉 = **H12 被支持** → 结论写「有排除价值,但一个朴素的涨停标记就能拿到,这棵树没有独立增量」。
  → 残差仍有可观增量 = H12 被杀,这棵树有独立的东西。

## 要带回来的数字

全部只在 **utrain** 上,每个数字都写清**哪个构造、哪一段(train / valid)、哪种口径**。
书的行格式照脚本的 `row_str`:`Lnet`(多头腿净超额)、`Lshp`(纯多头夏普)、`Lgross`、`LTO`(多头日换手)、`LS`(多空夏普)、`short`(空头腿毛)。

1. **第 1 节**:已知家族(`cross_mean(day_std(Amt),30)` 和 `cross_max(day_std(Amt),9)` 各一行)的多头十分位里,
   **被 F106 标记的票占百分之几**;这些被标记票的次日超额 vs 同一十分位里没被标记票的次日超额(train / valid 各一组)。
2. **第 2 节**:已知家族**剔除前**的 `Lnet / Lshp / LTO`,和**剔除后**的 `Lnet / Lshp / LTO`(train / valid)。
   两个已知家族成员都要。**差值要写出来**(提高了几个点)。
3. **第 3 节**:和书 `rank(known) + w·rank(F106)` 在脚本扫到的每个 w 上的 `Lnet / Lshp`(train / valid);
   以及**已知家族对 F106 信号及其折叠中性化后**的 R² 与残差的书(这是「增量是谁给的」的反向检验)。
4. **第 4 节**:F106 信号本身的 `Lnet / Lshp / rIC`;对 `g_max30`、`g_limitup30`、`EMA20(涨停标记)`、`EMA20(塌缩标记)`、
   **以及「all four」** 各自中性化后的 **R²、残差的书、残差的 rank IC**(train / valid)。
   另外带回**折叠量**对这几组的 R²(脚本最后那几行)。
5. **第 5 节**:每个显式短记忆构造一行:名字、方向、`hlL`、`Lnet`(train / valid)、`Lshp`(train / valid)、`LS`、与原式信号的秩相关。
   **特别标出有没有哪一条的 `Lnet` 在 train 和 valid 同时为正。**
6. **异常**:任何 NaN 比例异常、并列造成的退化(十分位里全是并列)、control 替换、脚本报错和你怎么处理的,都写进结果卡。
