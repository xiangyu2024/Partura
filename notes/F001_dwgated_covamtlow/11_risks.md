| 风险 | 现在知道什么 |
|---|---|
| **数据泄漏** | 未发现。`cross_max` 的日轴因果性是探针实测的;标签 `open_vwap15` h=1 预测的是 t+1 开盘 VWAP 到 t+2 开盘 VWAP,与因子所用的 t 日数据之间隔着一整天。**但**:视图从 store 的第一天 20180102 开始,`warmed_view` 实际给了 **0 行预热**(AlphaCube 自己的 `eval_checkpoint_costs.py` 同样如此),所以前 13 个交易日的窗口是不满的;1942 天里 13 天,影响可忽略,但口径要写清楚。 |
| **预热口径** | AlphaCube 的 `max_window` 取路径上的**最大**窗口(这里 9),而两层 `cross_max` 的真实回看是 **13**。本例因为 `warmup_buffer` 有余量不受影响,但更深的滚动嵌套会被少给预热。 |
| **过拟合** | 窗口有宽邻域、字段可互换、逐年都为正、rank IC 的 t 值 12.3 —— 单因子层面不像过拟合。真正的过拟合风险在**另一头**:GP 用整段 2018–2025 的 IC 选出了这条表达式,所以本报告的"训练段"并不是干净的样本外(见第 9 节的免责)。 |
| **尺度污染** | **已确认存在且是主要成分**:量价支对成交额中性化后 rank IC 掉 56%(R² 0.579);整树对全部控制变量中性化后 R² 0.650、rank IC 掉一半。 |
| **已知因子暴露** | 成交额/流动性、日内波动、日内振幅 —— 三者合计解释了大部分。价格水平、反转无关,动量弱相关。 |
| **行业暴露(未检验)** | **立方体里没有行业数据**,H5 无法证伪。高换手、高波动在 A 股与行业(券商、题材股)高度共线,这是目前最大的未知。 |
| **规模 vs 换手不可分** | 数据里只有成交额(`Amt`),没有市值。"低换手溢价"与"小市值溢价"在这份数据上无法区分。 |
| **交易成本** | 结论对成本极其敏感:同一条 alpha 在 13.5% 换手下扣费夏普 +1.78,在 46% 换手下(纯波动支)是 **−2.51**。所有排序必须在扣费口径下做,无成本夏普会给出完全相反的排名。 |
| **容量与做空** | 因子做空的是**成交额最大**的股票、做多**最安静**的股票 —— 多头腿天然在流动性最差的一端,冲击成本与容量都在多头。A 股还有融券限制、涨跌停、T+1,本报告一概未计。 |
| **制度依赖** | 2018–2023 逐年为正且在变强,但这段样本里注册制、涨跌幅规则、量化监管都在变;"低流动性溢价"在监管收紧量化交易后是否延续是未知的。 |
| **数值伪影(H7)** | `day_durbin_watson` 的常数行判据是 `var < 1e−8`,AlphaCube 记录过它在 CUDA 上会随舍入噪声翻 NaN。本因子的覆盖率 0.6908,与不含 DW 的变体(0.6911)只差 0.0003,所以影响很小;CPU/GPU 逐面板对照见第 7 节。 |
