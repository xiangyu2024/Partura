**+12.6% / +22.3% / +15.4%(train/valid/utrain),Lshp 2.22**。原式 v_base:**+1.8% / +8.1% / +3.6%,Lshp 0.70**。

## 1. 它是什么(逐层按函数定义)

- `Ret` = 分钟收益(241 根分钟轴)。
- `day_close(x)` = `day_last` 的别名 = `last_valid_last`:**当天最后一个非 NaN 分钟的值**。喂 `Ret` 得到的是
  **当天最后一个有效分钟自己那一笔分钟收益**,`day_close` 这个名字和文件名 `q25_closeret` 都在骗人 ——
  既不是收盘价、也不是当日收益。
- `cross_quantile_q25(x, 15)` = `torch.nanquantile(rolling_windows(x, 15, axis=0), 0.25)`;`rolling_windows` 的 axis=0
  是**交易日轴**(因果、左侧 NaN 填充)。所以 = 近 15 个交易日这 15 个「收盘分钟收益」的第 25 百分位。
- 方向 sg = −1 → 交易信号 = **−q25**,多头书 = q25 最低 = 近三周里「收盘分钟跌得最深的那一天跌了多少」最大。
- 恒等式(上一轮,仍成立):`−q25 = (scl − loc)/2`,scl/loc 为该分布的四分位距与四分位中点 → 它同时是
  **尾盘分钟波动计**和**尾盘卖压计**,1:1 混比。

## 2. 预测力在哪

**(a) 载重的不是「q25」,而是「输入在 0 上有一个点质量」。** 同一槽位换分位数:q25 → +3.6%,
q50(`sub_B_cross_quantile_q50`)→ +2.4% 但 **dist 0.16、底腿从 +19.0% 掉到 +0.2%、LS 从 +2.36 掉到 −0.02**;
日内版的中位数(`sub_A_day_median` / `sub_A_day_quantile`,两者逐位相同)**dist 0.02、LTO 只 0.004** —— 截面排序
几乎冻住。中位数压在原子上就没有信息。这个 0 原子 = **封板 / 停牌 / 无收盘成交的「冻结盘口」状态**
(与 F108「峰度类算子读到的其实是 day_flat_ratio」同一个发现)。q25 的作用是**伸到原子下面去**。

**(b) 孔径与叶子都不可互换。** `day_mean` / `day_sum` → **−15.9%、Lshp −2.11、ρo 0.00、方向翻转**(整条链最彻底的
塌陷);`day_max` −3.6%、`day_min` −4.8%。把孔径从 1 分钟放宽到 5 分钟(`leaf_Ret_ret5` = `in_pct(Close, 5)`)
→ **+0.1%**;`in_pct(Vwap, 1)` → +0.7%。**用户「Ret 和量的变化率是同一类东西」在这棵树上不成立**:
`leaf_Ret_volchg` / `leaf_Ret_amtchg` **dist 0.00**(退化),`in_logchg(Volume,1)` → −4.1% 且 ρk +0.37(= 一条流动性因子)。
原因很具体:载重的是**最后一分钟价格变动的符号与幅度**,而量没有符号;原子也只在 1 分钟粒度上存在。

**(c) 日轴低通是必需的,但买到的是换手不是信息。** 不滚动的 `iso_A`(= `day_close(Ret)`)毛超额最高而
**净 −2.0%、LTO 10.5%**;任何滚动都把净超额救回来(q25 +3.6 / cross_ema +1.8 / cross_mean +1.0 /
cross_decay_linear +1.2)。q25 比 mean/ema 多 ~2pp,**在 ±3pp 噪声带内 → 对多头腿,「必须是 q25」没有被证实**;
需要下尾读数的是**空头腿**(底腿 +19.0 vs q50 的 +0.2),而用户用不上。同槽位的其他算子全塌:
`cross_max` −16.1%、`cross_argmax` −20.4%、`cross_delay` −8.8%。

**(d) 多余的节点:保序变换。** `cs_winsor` +3.4%、`cs_rank` +3.2%(≈ 原式)→ **载重的是秩,不是幅度**。
**折叠是破坏性的**:`fold_mean` +1.7%、`fold_sq` +0.4%、`fold_rank` −2.7%,底腿转负 → 信号是**方向性**的,
不是「极端性」。

**(e) 载重的是持久的截面水平,不是时序事件。** `cross_zscore` 四个窗口全塌(−7.1/−6.7/−4.8/−2.8),
`rel60`(除以自己 60 日均值)−5.4%。这是**风格/流动性暴露**的指纹,也预告了 §4 的结论。

**(f) 窗口是上坡,不是峰。** w5 +2.9 → w10 +3.4 → w15 +3.6 → w30 +4.3 → **w60 +5.1(Lshp 0.87、LTO 1.6%)**,
而 w60 的 hlL 从 20 掉到 **3** → **内窗与外记忆是同一件事的替代品**。外记忆:`mem_ema30` **+5.0%、Lshp 0.93、
LTO 1.5%**(全表最好的多头腿),`mem_mean60`/`ema60`/`decay60` ≈ +4.9%。**慢化一共值 +1.4pp / +0.23 夏普,
全部来自换手,没有一分来自新信息**(毛超额不随慢化上升)。

## 3. 在市场的哪儿、什么时候有效

**(甲) 多头腿的超额全部是跨成交额桶的倾斜,桶内是负的。** 20 日成交额五分位的**段内自建多头书**:
−0.7 / −2.7 / −6.5 / −4.2 / −5.1 —— **五个桶全负**。全市场 +3.6% 完全来自持仓倾斜:最低成交额桶
**超配 +10.7%**、次低 +4.2%、最高 **−10.2%**(段等权超额 +15.1% … −17.8%)。旁证:`bk_liq` +1.6%、
`bk_known` +1.2%(两者 dist 0.20,不算候选但方向一致)、`res_known` +1.8%、`res_liq` +1.8%
(train 只 +0.4%/+0.1%,在噪声带内)。

**(乙) 但它在病态段里非常强,而已知族在那儿亏钱。** 近 15 日有冻结盘口(封板/停牌)段占 **6.5%**、
段等权 **−67.4%**:这棵树段内 **+7.7%**(`mem_min60` **+21.6%**),**k_known −10.9%** ← **唯一打赢已知族的地方**。
上市不足 250 日段占 **7.1%**、段等权 **−28.7%**:这棵树 **+18.1%**(`mem_min60` +21.8%),k_known +8.6%。
板块上创业板 +6.8%、科创板 +5.9%、深主板 +4.8%,沪主板只 +1.3%;流通市值最低 20% 段内 **+10.9%**,
60-80% 段内 **−7.9%** —— 在中大盘活跃票上它是**负贡献**。

**(丙) 时间:只有 2021 年以后。** 2018 +0.0 / 2019 −1.3 / 2020 −2.2 / **2021 +10.4 / 2022 +9.6 / 2023 +6.0**;
k_known 六年全正(最差 +6.7)。状态切分:截面离散度**高 +7.3% vs 低 −0.0%**;放量 **+7.9% vs 缩量 +0.1%**;
市场近 20 日**上涨 +8.5% vs 下跌 −2.4%**;市场波动高 +2.7% < **低 +4.6%** —— 所以它**不是波动率交易,
是离散度 + 成交量交易**,即 2021–2023 的微盘/题材制度。

**(丁) 原因推断。** 封板、停牌、无收盘成交的票,分钟收益恰好为 0 → 15 日「收盘分钟收益」的 q25 被钉在 ≈0,
落在有符号信号的最高端 → 进空头腿/被排除。正常交易的票收盘分钟是噪声 ±,**越不流动,第 25 百分位越深**。
所以 **−q25 ≈ (收盘分钟冲击幅度) − (收盘分钟漂移)= 一个带内置「冻结状态探测器」的微观冲击计**。
它同时解释了(甲)的流动性倾斜(幅度那一半)和(乙)的病态段优势(原子那一半)。
**可检验的推论**(前四条大表已证):① q50 应该死在原子上 → dist 0.16 ✓;② 孔径放宽到 5 分钟原子溶解、
因子应该死 → +0.1% ✓;③ 优势应该集中在封板/次新段 → +7.7% / +18.1% ✓;④ 量侧叶子因无符号而退化 →
dist 0.00 ✓;⑤ **若它是冲击计,`day_flat_ratio` 应能复现原子那一半、`day_wmean`/`day_signed_ratio` 应能
做得更干净** → 未测,第二批 A/B 组;⑥ 若(丙)的制度依赖是「离散度 + 放量」,把这个状态写进表达式当权重
应该比任何结构改动更有用 → 未测,第二批 H 组。

## 4. 相对已知成交额族有没有增量

**没有,而且是负的。** ρk 只 **+0.21**、`res_known` 保住 rIC 且与家族相关 −0.04 → 它**确实是别的东西**;
但 overlay 一列**每个权重都严格差于家族单独**:k_known +12.6/+22.3/**+15.4**,
`ov_p025` +10.2/+19.7/**+12.9**、`ov_p05` +9.8/+17.7/**+12.5**、`ov_p10` +8.8/+18.3/**+11.5**,
负权一侧更差(`ov_m025` +10.4、`ov_m05` +7.3、`ov_m10` +3.9)。**两个分段同向、|w| 单调向下**,
不是噪声。残差腿 `res_known` +1.8%(train +0.4%)在噪声带内。
→ 上一轮的 H12 从「wash」**加强为「严格稀释」**,证据面从 2 个权重点扩到 6 个。
**唯一的活口**:(乙)里 6.5% 的冻结盘口段,家族 −10.9% 而这棵树 +7.7% —— 增量如果存在,
只能以**单尾筛子**的形式存在,而不是线性混合(线性混合把倾斜摊到整本书上,已被 overlay 一列否掉)。

## 5. 改进方向(→ `studies/F114_q25_closeret/hypo.yaml`,39 条)

1. **A 组(6)**:用 `day_flat_ratio` 把(丁)的「冻结盘口」状态直接写出来(全天 / 尾盘 30 分钟 / Amt 侧 /
   不同慢化),检验推论⑤。这是整批里最可能复现并超过原式的一路。
2. **B 组(6)**:`day_wmean(Ret, Amt)`、`day_signed_ratio(Ret, Amt)`、`day_pos_ratio(Ret)` —— 用资金加权和
   纯方向读数把「冲击幅度」和「卖压方向」分开;`day_mean` 塌陷的原因是等权了死分钟还是孔径,由
   `h_wmean_q25` 一条判定。
3. **C 组(5)**:无原子的尺度与顺序读数(`cross_stddev(day_close(Ret), ·)`、`day_gini(Amt)`、
   `day_centroid(Amt)`、最后一分钟成交额占比)。`sub_A_day_centroid` 以 ρo 只 +0.32 拿到 +2.6%/valid +10.6%,
   顺序信息是一条独立支线。
4. **D 组(4)**:`day_durbin_watson(Ret)` 支线 —— 大表里 **+4.9%/valid +11.1%、ρo 只 +0.36、dist 1.00**,
   比原式好且相关低,但一直没人往下做。
5. **E 组(3)**:w60 与 ema30 串联,给「慢化只值换手」钉一个上限参照。
6. **F 组(5)**:用无原子输入重做 `cs_bucket_rank`(按成交额 / 价格 / 个股量能扩张分桶),直打(甲)——
   大表的 bk_* 因输入带原子 dist 只 0.20,这个问题其实**还没被干净地问过**。
7. **G 组(6)**:把它当**筛子**叠到已知族上(`pow_3` 凸罚项、两秩相乘的软 AND),瞄准(乙)那 6.5%。
8. **H 组(3)**:把(丙)的市场状态写进表达式 —— 当日截面离散度 / 它自己 60 日均值、市场整体量能扩张
   作为原树相对已知族的**权重**(日频标量乘秩不改当日排序,所以必须与已知族相加才生效)。最大胆的一类。
9. **I 组(1)**:日内版 Amihud 做机制对照。

**不再碰**:六条纯分量、`scl − k·loc` 调混比、w241、`in_slice` 换孔径、加长 EMA 半衰期、不等权线性组合
(上一轮已排除或本轮 overlay 一列已否掉)。

**一句话结论(与上一轮同向、证据更硬)**:对纯多头用户,这棵树的多头腿**不可用**(最好 +5.1%,只有已知族
1/3),它的超额是一个被已知族做得更好的流动性倾斜;**唯一还值得花运行的不是「提纯这条因子」,
而是把它读到的「冻结盘口」状态单独做成一个已知族看不见的筛子**。
