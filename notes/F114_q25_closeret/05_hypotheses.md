## A. 「它在读什么」—— 这组假设互相竞争,S1_shape 一次裁决

### H1 尺度读法:信息来自 `scl`(尾盘分钟收益的 15 日离散度)
- **预测**:`s1_scl`(= IQR)单独跑,多头口径表现与原式**同量级或更好**;`s1_q75` 的引擎自选方向是 **+1**;
  `s1_std`(cross_stddev,非稳健版尺度)也有效。
- **杀死它**:`s1_scl` 的 Lnet/Lshp 明显低于原式**且** `s1_q75` 选到 `−1`。
- **现状**:**未验证**。基线里的间接证据**两边都有**:可交易信号与 `ctl_ivol` 的 rank 相关 `+0.17`(口径 b)说有尺度暴露;
  但 `ctl_ivol` 自己作为因子方向是 `−`(高波动 → 低收益,低波动异象成立),而本因子是**做多**高波动 —— 两者冲突,见 H3。

### H2 位置读法:信息来自 `−loc`(最近尾盘持续被砸 → 反转)
- **预测**:`s1_loc` 单独跑,引擎选到 `sign = −1`,多头口径表现与原式同量级或更好;`s1_q50`(中位数)也有效且方向是 `−1`;
  `s1_q75` 的引擎自选方向是 **−1**(与 `q25` 同向)。
- **杀死它**:`s1_loc` 与 `s1_q50` 两条都明显弱于原式。
- **现状**:**未验证**。基线旁证:`ctl_rev1`(**当日**收益)的中性化 R² 只有 0.004 —— 说明"15 日尾盘漂移反转"这件事
  **没有被现有控制变量覆盖**,所以它如果是真的,是一个没被控制住的新暴露(好事),不是旧暴露换写法。

### H3 尺度暴露是净拖累:去掉 `scl`、只留 `−loc` 会**更好**(**本研究的升华主线**)
- **预测**:对 `ctl_ivol` 中性化后残差 rank IC 上升、毛超额上升(**基线已经看到了**);
  因此 `s1_loc`(纯位置)的多头口径表现应当**高于**原式,而 `s1_scl`(纯尺度)**低于**原式。
- **杀死它**:`s1_loc` ≤ 原式,或 `s1_scl` ≥ 原式。
- **现状**:**合理但未坐实**。已有证据(基线 §7,fit = train,对象是平滑后的交易信号):
  对 `ctl_ivol` 中性化后残差 rank IC **+0.0070 → +0.0136(接近翻倍)**、残差 Lgross **+4.1% → +5.8%**,R² 仅 0.032。
  即:因子带着一个**不想要的**波动暴露,把它剥掉信号反而更强。这是基线表里最可操作的一条线索。
  (残差 Lnet 掉到 −5.2% 是成本假象:残差不再平滑,换手从 3.3% 跳到 14.3%,见 `docs/study_playbook.md` §1。所以看 rank IC 和毛超额。)

### H4 1:1 等权混比是必要的:`q25` 比任何单一分量都好
- **预测**:`s1_loc`、`s1_scl`、`s1_q50`、`s1_std` **全部**弱于原式(即两个分量确实在互补)。
- **杀死它**:任何一条打平或更好。
- **现状**:**未验证**。先验上我**不信**它(混比是机械挖掘随手选 `q25` 带来的副产品,没有理由恰好最优),但它是必须排除的零假设 ——
  否则"提纯成单分量"就是错的。

## B. 「光圈对不对」—— S2_where / S3_window 裁决

### H5 「当天最后一个有效分钟」这个取值位置是必要的(尾盘/收盘集合竞价效应)
- **预测**:把 `day_close` 换成 `day_sum`(≈ 当日收益)、`day_mean`(全天平均分钟收益)、`day_open`(当天第一个有效分钟)
  之后,多头口径表现**明显下降**。
- **杀死它**:任一替换打平或更好。
- **现状**:**未验证**。注意 `day_close` 是 `day_last` 的别名(`02_operators.md`),"收盘"是名字造成的错觉;
  真正喂进来的是单分钟收益,所以"尾盘特殊"完全可能只是巧合。

### H6 它等价于「日收益的 15 日下四分位数」—— 一个已知的 downside-risk / 反转家族,不是新东西
- **预测**:`s2_daysum`(`cross_quantile_q25(day_sum(Ret), 15)`,`day_sum(Ret)` ≈ 当日(对数)收益)与原式
  **rank 相关高(> 0.8)且表现不低于原式**。
- **杀死它**:`s2_daysum` 与原式 rank 相关低(< 0.5)**或**表现明显更差 → 尾盘那一分钟是独立信息。
- **现状**:**未验证**。这是 H5 的"坏消息版本":H5 被杀死而 H6 成立,结论就从"尾盘微观结构因子"变成
  "日收益下行分位数的一种迂回写法",分辨的答案会完全不同。`s2_daysum` 与 `s2_daymean` 只差"当天有效分钟数"
  (`day_sum` = 和,`day_mean` = 和/有效分钟数),所以两者之差**单独量出了停牌/低流动性对分母的污染**。

### H7 读的是「经常坏」而不是「曾经最坏」(稳健分位点 ≠ 极值)
- **预测**:`s1_min`(`cross_min`,被单日完全决定)明显弱于原式。
- **杀死它**:`s1_min` 打平或更好 → 这是一个**事件**因子(单日尾盘崩盘),整套"慢变特征量"的读法要推翻,
  且半衰期顶格(§H8)就变得无法解释。
- **现状**:**未验证**。解析依据见 `04_grammar.md` §3(q25 对单日的响应有界、约一个顺序统计量间距)。

### H8 记忆太短:窗口 15 天不够,加长更好
- **预测**:`s3_w30`、`s3_w60` 的多头口径表现**高于**原式,且在**固定半衰期表的同一列**上也更高(= 结构功劳,不是平滑功劳);
  `s3_w5` 明显更差。
- **杀死它**:w30/w60 不优于 15,或在固定半衰期同一列上不优于 15。
- **现状**:**合理但未坐实**。三条独立读数指向同一方向(基线 §1/§6):
  hlL = hlS = **20(网格上限)**;固定半衰期表 Lnet −4.3%(hl 0)→ +1.8%(hl 20)**单调升、到上限没掉头**;
  衰减表 rank IC +0.0092(h1)→ +0.0237(h20)**单调升 2.6 倍**。
  **重要**:EMA 网格到 20 为止,已经用尽 —— 所以这条因子**没有**"换成多头最优半衰期白捡几点"的空间
  (`hlL == hlS == 20`),加长记忆**只能靠改窗口**,那是结构。

## C. 「这些钱是真的吗」—— 这组决定结论的性质,R2 的自写脚本 + 逐年表裁决

### H9 空头腿是被「买不进的票」撑起来的
- **机制(本因子特有,比 `docs/study_playbook.md` §6.6 的通用警告更具体)**:涨停锁死的票,锁住之后每分钟收益都是 0,
  于是 `day_close(Ret) = 0`;连续几天如此,它的 15 日 q25 **≈ 0**,而正常票的 q25 是负的 —— **于是封板票被机械地送进空头腿**。
  这些票次日开盘买不进,标签 NaN 在空头里记 0 收益,空头腿因此虚高。
- **预测**:`st.target(buyable=False)` 下空头腿毛超额明显下降(≥ 几个点);Q1 桶里"q25 ≈ 0"与涨停/零收益分钟的占比
  远高于其他桶。
- **杀死它**:buyable=False 下空头腿基本不变。
- **现状**:**未验证**(需要 R2 的自写脚本)。基线旁证:空头腿毛超额 +17.4%/+23.0%,`long_share` 仅 19%~31%;
  分位剖面 Q1 = −17.8%/−23.7% 是**全剖面里唯一的极端档**,其余九档都在 ±10% 内 —— 形状上像"一小撮特殊票"而不是连续排序。
- **对用户的意义**:这条**只影响多空口径的解读**,不影响多头腿(选拔看多头腿,见 `docs/study_playbook.md` §0.3)。
  所以它决定我们怎么写 LS = +2.36 这个数,不决定推荐谁。

### H10 因子实质是「尾盘呆滞/锁死」指标:`day_close(Ret)` 有大量精确零值
- **预测**:面板上 `q25` 恰好 = 0(或 |q25| < 1 个最小跳动)的格子占比高(> 10%);这些格子集中在空头端。
- **杀死它**:零值占比很低(< 2%)→ 则 q25 是一个连续量,H9/H10 的"锁死"机制不成立。
- **现状**:**未验证**。基线里唯一相关读数是 `dist = 0.6246`(过 0.5 门槛,但不是很高)。需要 R2 的脚本直接数。

### H11 多头腿的钱是 2021–2023 小盘/高波动制度骑乘,不是稳定的横截面 alpha
- **预测**:逐年表里多头腿在小盘占优的年份好、在大盘/质量占优的年份差(**基线已经看到了**);
  条件 IC 在小市值桶最强(**基线已经看到了**);留出段(2023-08-08 起,含 2024 年初微盘股大幅回撤)多头腿会有一段明显回撤。
- **杀死它**:对 `ctl_cap` / `ctl_dvol20` 中性化后残差的多头腿毛超额仍然稳定为正且逐年分布均匀。
- **现状**:**合理但未坐实**。已有证据(基线 §5/§8,`utrain` 逐年):
  Lnet 2018 +0.0% / 2019 **−1.4%** / 2020 **−2.3%** / 2021 **+10.3%** / 2022 **+9.4%** / 2023(至 8/7)**+5.8%**;
  `long_share` 2020 **1.2%** → 2023 **31.5%**。条件 IC 按 `ctl_cap`:最小市值桶 −0.0187,单调减弱到最大桶 −0.0072(≈2.6 倍)。
- **直接推论(必须在读留出段之前写进 `10_distilled.md`)**:`valid`(2022-01 ~ 2023-08)**整段落在**这个有利制度里。
  所以 `valid` Lnet +8.1% 远高于 `train` +1.8%(Lshp +0.33 → +1.78)**不是"样本外更强"的证据,是制度**。
  任何只看 valid 的挑选都会被这件事系统性误导。

### H12 对只能做多的用户,相对已知成交额家族**没有增量**
- **预测**:对 `known_stdamt_max9` / `known_stdamt_mean30` 中性化后的残差多头腿 ≈ 0;原式与已知家族相加后的多头腿 ≈ 家族单独。
- **杀死它**:残差多头腿显著为正,或相加后明显超过家族单独。
- **现状**:**未验证**,但先验**不利**。基线附表(同口径、各自独立选半衰期):
  `known_stdamt_max9` Lnet tr/va **+9.3%/+18.5%**、`known_amt_max9` **+8.5%/+20.8%**,而原式只有 **+1.8%/+8.1%** ——
  **原式在两段上都被已知家族压过一倍以上**。有利的一面:相关不高(可交易信号口径,原式 vs `known_amt_max9` 为 −0.22
  → 乘上两者各自方向后约 **+0.22** 同向;`all_controls` R² 仅 0.162)—— 低相关 + 低独立表现,典型的"也许能当小权重补充,但当不了主力"。

### H13 多头腿本身不可用:信息集中在 Q1,长端没有排序能力
- **预测**:分位剖面在多头端平坦或掉头(**train 已经看到了**);窗口/分位数的邻域变体也改不掉这个形状。
- **杀死它**:某个变体在 train 上也把多头端做成单调上升、且 Q10 是最高档。
- **现状**:**合理但未坐实**。已有证据(基线 §4):`train` 剖面 **Q8 +4.9% > Q9 +4.7% > Q10 +4.4%** —— **最高分位不是最好的一档**;
  Q1 = −17.8% 独大。`valid` 剖面单调(Q10 +12.0% 最高)。两段不一致。
- **对用户的意义**:这是**否定性结论的主要候选**。"它只会告诉你别买哪 10%,不会告诉你买哪 10%" 对纯多头用户基本没用
  —— 按 `docs/study_playbook.md` §0,这是一个合格的结论,只要证据在。

## D. 工具/语义层面的待坐实项(不影响选拔,但影响怎么写报告)

### H14 探针读出的 `effective_memory = 0 天` 是**正脉冲造成的假象**,不是"这个算子没有记忆"
- **解析理由**:q25 在 n=15 上的插值位置是第 4~5 小;孤立正脉冲落在窗口上端,不改变第 4/5 小的位置 → 输出不动(`04_grammar.md` §3)。
- **坐实的办法**:自写探针喂**负**脉冲,应读出 15 天记忆。
- **现状**:**合理但未坐实**。优先级低(不影响任何选拔判断),如果轮次不够就在报告里按"合理但未坐实"写。

### H15 `Ret` 的精确定义(简单/对数收益、基准价、"最后一个有效分钟"对应几点)
- **现状**:**未决**。`R0.md` 异常 5 已记:本地无直接文档,只有旁证。
- **为什么要管它**:只影响两件事 ——(a)`day_sum(Ret)` 是否精确等于当日对数收益(关系到 H6 的措辞);
  (b)`day_open(Ret)` 是"隔夜跳空"还是"开盘后第一分钟"(关系到 H5 里 `s2_dayopen` 这一条怎么解读)。
  **在 R2 的脚本里顺手量**(`day_sum(Ret)` 与 `ctl_rev1` 的 rank 相关:若 ≈ 1 则 `day_sum(Ret)` 就是当日收益)。
- **已排除的担心**:不影响因果性(两个算子的 `lookahead=False`、源码级确认只看 `[t−14, t]`)。

## 新增假设(R1 的意外带出来的)

### H16 窗口加长在 60 天之后饱和(或掉头)
- **预测**:`s4_w241`(网格最后一档)不再优于 `s3_w60`,最优窗口落在 30~60。
- **杀死它**:`s4_w241` 的多头腿继续明显上升。那就意味着这条因子本质是一个**年度级的慢变股票特征量**,
  而不是「近一两个月的尾盘状态」—— 结论的性质要改:慢变特征量更可能是规模/波动的代理,
  **H12(相对已知家族没有增量)的风险会大幅上升**,而且报告里「它读的是最近的尾盘状态」这句话要删掉。
- **哪个实验**:R2 第 1 次运行 `s4_w241`。

### H17 在长窗口下,「下四分位数」这个稳健统计量不再必要
- **预测**:`s4_mean60`(`cross_mean(day_close(Ret), 60)`,最朴素的纯位置/累计漂移)与 `s3_w60` 打平。
  若成立,升华版可以简单得多,而且「为什么是 q25」这件事的答案变成「15 天窗口下才需要稳健统计量」。
- **杀死它**:`s4_mean60` 明显更差 → 读下四分位(而不是中心)在任何窗口下都是必要的,
  与 S1 的结论(H4)合起来把「为什么是 q25」说完整。
- **哪个实验**:R2 第 1 次运行 `s4_mean60`。

### H18 每个股票-日的有效分钟数是常数(⟹ 停牌/锁死的分钟是精确 0,不是 NaN)
- **证据来源**:`s2_daysum` 与 `s2_daymean` 的**全部输出逐位相同**(`results/R1.md` 异常 4)。
  `day_mean = day_sum / 有效分钟数`,逐位相同当且仅当分母是常数(或 `day_mean` 用固定分母)。
  源码只看到 `day_sum = C._sum(x)`、`day_mean = C._mean(x.float())`,`./scripts/study.sh src _mean` 查不到底层实现,
  所以两种可能分不开。
- **为什么要管它**:它是 H9 / H10 那套「封板锁死 → 每分钟收益 0 → `day_close(Ret)=0` → q25≈0 → 被机械送进空头腿」
  机制的**必要条件**。成立则 H9/H10 从猜测升级为「机制可行、待量」;不成立(即 `day_mean` 用固定分母)则 H9/H10 的
  机制还缺一环。
- **哪个实验**:R3 脚本里量 `day_sum(Ret) / day_mean(Ret)` 在有效格子上是否恒为同一个常数。
- **副产品**:它顺手回答了第 1 轮写在 H6 里的那句「两者之差单独量出停牌/低流动性对分母的污染」—— 实测**零污染**。

## 本轮新立的一条已确立事实(不是假设,是测出来的)
