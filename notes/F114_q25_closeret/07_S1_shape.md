# S1_shape:读出的 0.25 分位数,在读位置、尺度,还是两者的 1:1 混合?

主研第 2 轮写。数字全部出自 `results/R1.md`(tag `S1_shape`),口径=决策口径(方向与半衰期只在 `train` 上定一次),
多头口径的 `Lnet/Lshp` 读 `hlL` 那本纯多头书。

记号(`04_grammar.md` §2 的**精确**恒等式):`loc = q75+q25`(四分位中点×2,纯位置)、`scl = q75−q25`(IQR,纯尺度),
可交易信号 `−q25 = (scl − loc)/2`。

## 结果

| 变体 | 表达式含义 | Lnet tr/va | Lshp tr/va | 固定 hl20(train) | 原始 rIC tr/va | dist |
|---|---|---|---|---|---|---|
| v_base | `q25` | **+1.8% / +8.1%** | **+0.33 / +1.78** | **+1.8% / +0.33** | +0.0092 / +0.0145 | 0.62 |
| s1_scl | 纯尺度 IQR | +0.6% / +8.0% | +0.11 / +1.76 | +0.6% / +0.11 | +0.0087 / **+0.0174** | 0.88 |
| s1_q50 | 纯位置(中位数) | +0.9% / +6.0% | +0.26 / +1.98 | +0.9% / +0.26 | +0.0036 / +0.0085 | **0.16 掉门槛** |
| s1_loc | 纯位置(中点×2) | −0.7% / +5.9% | −0.14 / +1.43 | −0.7% / −0.14 | +0.0046 / +0.0076 | 0.89 |
| s1_std | 非稳健尺度 | −1.1% / +2.2% | −0.26 / +0.47 | −1.1% / −0.26 | +0.0007 / +0.0053 | 1.00 |
| s1_min | 极值(曾经最坏) | +2.0% / +0.0% | +0.50 / +0.00 | +2.0% / +0.50 | +0.0032 / +0.0067 | 0.66 |
| s1_q75 | `q75` | −1.4% / +2.8% | −0.33 / +0.72 | −1.4% / −0.33 | +0.0019 / +0.0029 | 0.63 |

`s1_q75` 的引擎自选方向是 **`sign = +1`**(事前判据:`+1` → 驱动是尺度,`−1` → 驱动是位置)。

## 解读

### 1. 驱动主要是**尺度**(H1 被支持),但位置分量也不是零(H2 弱支持)

三条证据同向:(a) `s1_q75` 自选 `+1`;(b) 尺度半边 `s1_scl` 的原始 rIC `+0.0087/+0.0174`,valid 上**比原式还高**
(原式 +0.0145),而位置半边 `s1_loc` 只有 `+0.0046/+0.0076`;(c) 交易信号口径的 rIC(`results/R1.md` 第 (6) 节「未中性化」行)
更悬殊 —— `s1_scl` **+0.0087**、原式 **+0.0070**、`s1_loc` 只有 **+0.0006**。

位置半边并非完全无信息(原始面板 rIC t 值 4.17/3.79 显著,valid 多头腿 +5.9%、Lshp +1.43),但它的秩相关**过不了平滑**
(原始 +0.0046 → 交易信号 +0.0006)。**合理但未坐实的解读**:位置信息是快变的(尾盘被砸之后的短期反转),
尺度信息是慢变的(一只股票尾盘有多抖是一个持续的属性)。这与 S3_window 里「加长窗口更好」同向。

### 2. 升华主线 H3(剥掉波动暴露会更好)**被否定** —— 这是本阶段最重要的一条

基线里最亮的那条线索是「对 `ctl_ivol` 中性化后残差 rIC 从 +0.0070 翻到 +0.0136、残差毛超额 +4.1%→+5.8%,而 R² 只有 0.032」,
由此推出的升华主线是:因子带着一个不想要的波动暴露,结构性地剥掉它应该更好。**实测把这条路堵死了**:

- `s1_loc` 就是「结构性地剥掉波动暴露」的那个版本 —— 它对 `ctl_ivol` 的中性化 R² 只有 **0.005**(原式 0.032、`s1_scl` 0.050),
  对 `all_controls` 的 R² 只有 **0.030**(原式 0.162),与 12 个控制变量/已知家族的 rank 相关全部在 ±0.05 以内。
  它确实是一个几乎不带任何已知暴露的干净因子。
- 但它的多头腿**全面低于原式**:`−0.7%/+5.9%` vs `+1.8%/+8.1%`;固定半衰期同一列(hl20)`−0.7%/−0.14` vs `+1.8%/+0.33`。
  所以这不是半衰期挑选的差别,是结构本身更差。

进一步:同样的「中性化后 rIC 翻倍」在 `s1_scl` 上也出现(未中性化 +0.0087 → 对 `ctl_ivol` 中性化后 **+0.0171**)。
**所以那个增益寄生在尺度分量内部,并不是「把尺度分量整块拿掉」能兑现的东西** —— 秩空间里对 `ctl_ivol` 做线性回归,
剥掉的是尺度分量里与日内波动共线的那一小块(R² 0.05),剩下的尺度分量更干净;而 `s1_loc` 做的是把整个尺度分量减掉,
连同它携带的 alpha 一起减掉了。两件事不是一回事,基线那条线索**不能**按结构替换去兑现。

### 3. 纯尺度化也不是提纯方向 —— 它是在滑向已知家族,而且多头腿更差

`s1_scl` 的横截面相关最强(valid rIC 甚至高于原式),但对只能做多的用户它更差:

- 多头腿 `+0.6%/+8.0%` 低于原式 `+1.8%/+8.1%`;固定 hl20 列 `+0.6%/+0.11` vs `+1.8%/+0.33`。
- **它比原式更像已知家族**:`all_controls` R² **0.275**(原式 0.162、`s1_loc` 0.030);
  rank 相关 `ctl_amt` **−0.30**、`known_stdamt_mean30` **−0.29**、`known_stdamt_max9` −0.24、`ctl_ivol` +0.21
  (原式对应的最高值约 0.22)。
- **钱更往空头腿跑**:train 口径 `Lgross/(Lgross+short)` 推算的 long_share 从原式的 19.1% 掉到 **13.5%**
  (`s1_scl`:Lgross +3.0%、short +19.3%)。

同一条轴上非稳健的尺度版 `s1_std`(`cross_stddev`)更差(`−1.1%/+2.2%`,`ctl_ivol` 相关 +0.32)——
说明「尺度」这件事必须用稳健统计量读,`cross_stddev` 会把尺度读成「有没有出现过极端分钟」,那个东西和日内波动高度共线、没有增量。

### 4. 1:1 混比是必要的(H4 **被支持**),而且原式就是整个 q75/q25 线性族的最优点

把可交易信号写成 `α·scl + β·(−loc)`,则这一族只有一个自由参数 `β/α`,四个已测点是:

| `β/α` | 变体 | 等于什么 | train Lnet |
|---|---|---|---|
| −1 | `s1_q75`(sign +1) | 同时做多尺度和位置 | −1.4% |
| 0 | `s1_scl` | 纯尺度 | +0.6% |
| **1** | **v_base** | **原式 `−q25`** | **+1.8%** |
| ∞ | `s1_loc`(sign −1) | 纯位置 | −0.7% |

**峰值正好落在 `β/α = 1`,也就是原式。** 这个 1:1 是机械挖掘选到 `q25` 时白捡的,不是学出来的,但它是对的。

**由此裁掉一个原计划的实验**:上一轮写在 `state.md` §6 里的「用 `mul` 配字面量造 `scl − k·loc`(k = 0.5 / 2)去调混比」
**不跑**。代数上 `scl − k·loc = (1−k)q75 − (1+k)q25`,除掉 `(1+k)` 之后正是 `β/α = k` —— k=0.5 和 k=2 就是
已测峰值 `β/α=1` 两侧的内插点,它们夹在 `+1.8%` 与 `+0.6%`/`−0.7%` 之间,**预期增益远小于噪声带(±3pp)**;
加上常数字面量在这套语言里只能放最外层(`check` 大概率不过),而且「IQR 减 2 倍四分位中点」这种表达式即便赢了也没法推荐。
**结论:q75/q25 这对的线性重组这条路已经走完了,原式是其中的最优点,不要再回来。**

### 5. 读的不是「曾经最坏」(H7 被支持,但只在 valid 侧成立)

`s1_min` 在 train 上**略高于原式**(`+2.0%/+0.50` vs `+1.8%/+0.33`),但 valid 塌到 `+0.0%/+0.00`。
train 与 valid 不同向 → 按 `docs/study_playbook.md` §6.6「不凑数」,它不是候选。
`s1_min` 也是本阶段唯一半衰期没顶到网格上限的变体(`hlS=10`)。
读法:稳健分位点(「经常坏」)能过样本外,极值(「曾经最坏」)过不去。

### 6. 一条门槛事实

`s1_q50` 的 `dist = 0.1608`,远低于用户的 0.5 门槛 —— 中位数版的取值离散度太低(尾盘分钟收益的 15 日中位数挤在零附近)。
它的多头腿本来也不如原式(+0.9%/+6.0%),所以这条门槛失败不改变任何结论,但它解释了**为什么挖掘会选 q25 而不是 q50**:
q50 根本过不了离散度门槛。

## 本阶段的净结论

- **提纯方向被堵死**:原式不能拆成任何一半,也不能在 q75/q25 这对里重新配权 —— 原式已经是这一族的最优点。
- **分辨方向有收获**:alpha 主要在尺度半边,但尺度半边单独拿出来就滑向已知成交额/波动家族(R² 0.275),
  而位置半边干净但过不了平滑。原式之所以好,是因为它把「慢变的尺度」和「快变的位置」以 1:1 绑在一起,
  得到一个既不太像已知家族(R² 0.162)又能过平滑的量。
- **升华只能换别的轴** → 窗口(见 `07_S3_window.md`)。
