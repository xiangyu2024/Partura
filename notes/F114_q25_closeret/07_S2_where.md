## 解读

### 1. H5 被支持,而且是最强的一种支持:这个取值位置不可替换

三个替换全部塌掉,没有一个打平:把日内聚合从「最后一个有效分钟那一笔收益」换成「当日全部分钟收益之和」
(≈ 当日收益)、「全天平均分钟收益」、「当天第一个有效分钟」之后,多头腿从 `+1.8%/+8.1%` 变成
`−19.1%/−7.9%`、`−19.1%/−7.9%`、退化。固定半衰期表的每一档都是同样的结论,不是半衰期挑选的问题。

### 2. H6 被**决定性否定**:它不是「日收益 15 日下四分位数」的迂回写法

这是本阶段真正的收获。H6 是这条因子最危险的一种可能性 —— 如果它只是已知的 downside-risk / 下行分位数家族
换了个写法,那整条研究的性质就变了。实测:

- **`s2_daysum` 与 `v_base` 的 rank 相关 = `+0.00`**(可交易信号口径)。两者在横截面上几乎完全无关。
  H6 的生死判据写的是「rank 相关 > 0.8 且表现不低」才算成立、「< 0.5 或表现明显更差」就被杀死 —— 它落在 0.00。
- 而且 `s2_daysum` 自己根本不是一条有效因子:原始 rIC `+0.0040` 的 **t 值只有 0.92**(原式 7.95),方向是靠一个
  不显著的 rank IC 定出来的,多头腿 `−19.1%`,train 分位剖面 Q10 = **−16.6%**(最高分位亏最多)。
  所以不是「日收益版本更弱」,是「日收益版本就是噪声」。

**结论的措辞因此可以写硬**:`cross_quantile_q25(day_close(Ret), 15)` 读的东西与「日收益的下四分位数」在横截面上正交。
「尾盘最后一分钟」不是一个无关紧要的实现细节,它就是这条因子的全部内容。

### 3. `s2_daysum ≡ s2_daymean` 逐位相同 —— 一个意外,而且是有用的意外

两个变体在主表、固定半衰期表、分位剖面、与全部控制变量的 rank 相关上**每一个数字都完全一致**(`results/R1.md` 异常 4)。
`day_mean = day_sum / 有效分钟数`,所以逐位相同(更准确地说:秩完全相同 → 十分位分桶相同 → 两本书相同)
**当且仅当每个股票-日的有效分钟数是同一个常数**(或 `day_mean` 用的是固定分母)。

源码只看到 `day_sum(x) = C._sum(x)`、`day_mean(x) = C._mean(x.float())`,`_sum`/`_mean` 这两个底层函数
`./scripts/study.sh src _mean` 查不到(不在算子目录里),所以**现在还不能断定是哪一种**。记为新假设 **H18**。

**为什么这件事重要**:上一轮把「`day_sum` 与 `day_mean` 之差单独量出停牌/低流动性对分母的污染」写成了 H5 的副产品。
实测答案是**零污染**。如果原因是「有效分钟数恒为常数」,那就意味着**停牌/涨停锁死的分钟不是 NaN,而是精确的 0** ——
这正是 H9(封板票撑空头腿)和 H10(因子是尾盘呆滞/锁死指标)那套机制的必要条件,它们因此从「猜测」升级成
「机制上可行、待量」。R3 的脚本里只要量 `day_sum(Ret) / day_mean(Ret)` 的比值是不是常数,就能定下来。

### 4. `s2_dayopen` 不是「更差」,是**退化**

`dist = 0.0003`;train/valid 的 `rank_ic`、`rank_ic_t`、`ic`、`rank_ic_traded` 在原始 JSON 里**都是 NaN**
(不是展示层留空);固定半衰期表五档数字完全相同;与一切东西的 rank 相关都是 NaN;`hlL = hlS = 0`。
即:`cross_quantile_q25(day_open(Ret), 15)` 几乎是一个常数面板。

`day_open` 是 `day_first` 的别名,所以它取的是当天**第一个有效分钟**那一笔收益。最合理的解读是:
集合竞价/开盘那一分钟的 `Ret` 在这份数据里对绝大多数股票-日取同一个值(很可能是 0 —— 如果 `Ret` 是
「本分钟收盘 / 上一分钟收盘 − 1」,那么当天第一分钟没有「上一分钟」,被填成 0 或 NaN)。
**这个读数本身就是对 H15(`Ret` 的精确定义)的一条证据**:它说明 `Ret` 是一个**日内**分钟对分钟的收益,
不跨夜 —— 否则第一分钟会是隔夜跳空,离散度会很大而不是 0.0003。

这条退化**不是实验失败**:它正好说明「第一分钟」这一端没有信息,而「最后一分钟」有 —— 日内位置是强不对称的。
但它也让 S2_where 对「位置」的扫描只剩两个有效对照点(`day_sum`/`day_mean`),所以「尾盘是不是日内唯一的特殊位置」
这个更细的问题(比如中午那一分钟)在这轮没有被回答。**决定不追**:要切具体分钟段得用手写库的 `in_slice`
(参数含字面量),而它能回答的增量问题太小,不值一次运行。

## 本阶段的净结论

- 日内取值位置(最后一个有效分钟)是这条因子的全部内容,不可替换 —— **H5 被支持**。
- 它与「日收益的 15 日下四分位数」正交(rank 相关 +0.00),**H6 被决定性否定**;所以它不是已知的下行分位数家族。
- 送回两条副产品:`Ret` 是日内不跨夜的分钟收益(H15 前进一步);有效分钟数很可能恒为常数,
  于是「锁死日的分钟收益是精确 0」在机制上可行(H18,待 R3 量)。
