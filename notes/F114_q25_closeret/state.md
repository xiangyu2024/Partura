### 2.1 语义(源码级,`02_operators.md` + 本轮新核对的)
- **`day_close` 是 `day_last` 的别名**;喂的是 `Ret`(逐分钟收益),所以 `day_close(Ret)` = **当天最后一个有效分钟自己那一笔分钟收益**,
  不是收盘价、不是当日收益。**整条链上唯一「名字骗人」的地方**,也是文件名 `q25_closeret` 骗人的地方。
- `cross_quantile_q25(x, 15)` = 交易日轴因果滚动、逐股票独立、`nanquantile` 忽略窗口内 NaN。窗口网格 `[3,5,10,15,30,60,241]`。
  齐次度 1(带尺度);`q25(−x) = −q75(x)`(取负不是奇函数);窗口变长不单调。头 14 天是真实样本数 1→15 渐增,不是 NaN。
- **本轮新读的源码**(都用 `./scripts/study.sh src` 核对过):
  - `cs_regres(Y, X)` = **逐日横截面 OLS `Y ~ α + β·X` 的残差**(`nd_cs.py:253`),mask 取两者都有限的交集,
    `var ≤ EPS` 时 `beta = 0`。→ 可以直接用来做「对已知家族中性化」,不必写 numpy 脚本。**R2 用上了。**
  - `cs_rank(x)` = 逐日横截面升序秩 / 有效数,落在 (0,1];NaN 被推到最大值一侧、不挤占有效秩;`stable=True` 做 tie-break
    (源码注释特意说明:分钟数据到处是并列值,不 stable 的话 CPU/GPU 会给并列值互换秩)。
  - `cross_argmin(x, d)` 默认 `pct=True`,返回 **(距今天数 + 1) / 窗口内有效天数 ∈ (0,1]**,靠 0 一侧 = 最坏的那天就是最近;
    NaN 被填成 `+inf` 所以永远不会赢 argmin。齐次度 0。(本轮**没有**把它排进 R2,理由见 §5 末。)
  - `day_sum(x) = C._sum(x)`、`day_mean(x) = C._mean(x.float())`;`_sum`/`_mean` 这两个底层函数
    `./scripts/study.sh src _mean` **查不到**(不在算子目录里)→ 所以 `day_mean` 的分母是「有效分钟数」还是固定常数
    **现在还不知道**(H18)。
- `ts_*` 与 `cross_*` 对「每股票-日一个值」是同一内核,但日频量**必须用 `cross_*`**(显存)。
- `cross_quantile_q25` 的探针读数 `effective_memory = 0 天` 是**正脉冲造成的假象**(正脉冲落在窗口上端,
  不动第 4/5 小的位置),**不是**「这个算子没有记忆」。解析见 `04_grammar.md` §3,记为 H14(合理但未坐实)。
