# 07 · S5_known(tag `S5_known`)—— 对只能做多的用户,这条因子相对已知成交额家族有没有增量?

主研裁决,第 3 轮(Opus 5)。数字出处:`results/R2.md` 第 10~17 项(`runs/F114_q25_closeret/S5_known.json`)。
这是本研究**决定结论的那一个阶段**。

## 问题(H12)

先验不利:基线里已知家族(`cross_max(day_std(Amt), 9)` / `cross_mean(day_std(Amt), 30)`)的多头腿净超额是原式的 3~7 倍,
但两者 rank 相关只有 0.13~0.19、原式的 `all_controls` R² 只有 0.162 —— **「弱但正交」有可能仍然值得当小权重补充。**
所以要正面量两件事:① 把家族暴露中性化掉之后,这条因子的多头腿还剩多少(**残差腿**);
② 把它加进家族里,组合的多头腿有没有超过家族单独(**组合腿**)。

## 解读

### (1) H12 **被支持(接近坐实)**:没有可用的增量。三条证据各自独立,同向。

**证据 A —— 单独比:家族压过 3.5~5 倍,而且多头端比这棵树好得多。**
家族 +12.6%/+22.3%、夏普 +1.78/+3.46,vs 最好的版本(w30/w60)+2.6%/+3.5% train、+8.3%/+8.6% valid、夏普 +0.47/+0.60 train。
更关键的是**长端的形状**:家族 train 剖面 Q8 +8.6% < Q9 +11.4% < **Q10 +15.8%** —— **严格单调**;
这棵树的**任何**版本都做不到(`results/R2.md` 第 8 项:train 上没有一行满足 Q8<Q9<Q10)。
家族的 `hlL = 0`(完全不需要 EMA 平滑)也说明它本身就是慢变量,不像这棵树要靠半衰期顶到网格上限才勉强站住。

**证据 B —— 残差腿:正、干净,但在 fit 段上约等于零,全部正收益在 2021 之后。**
残差确实是**家族之外的东西**:与家族 rank 相关 −0.04、`all_controls` R² 0.038、
保住了原始 rIC 的 **68%/67%**(+0.0092/+0.0145 → +0.0063/+0.0097)。换家族基准(max9)、换候选版本(w60),
三条残差几乎重合(+0.4%/+0.5%/+0.7% train)→ **结论对「用哪条家族、用哪个版本」都不敏感。**
**但事前判据没过**:`state.md` §6 事先写的是「残差多头腿显著为正 = train/valid 同向且 > +1pp」;
实测 train 只有 **+0.4% / +0.7%**(毛超额 +3.2% / +2.4%),**没过 +1pp**。
而逐年表把原因说透了:残差在 **2018 −2.7% / 2019 −4.1% / 2020 −1.5%**、2021 之后才转正。
→ **残差的「增量」与原式本身的病是同一个病(H11 制度骑乘),不是一块独立的新收益。**
⚠ 读残差必须读毛超额和 rIC(净值会只因成本塌陷,`state.md` §8.2 第 3 条)—— 这里即便读毛超额,train 也只有 +3.2%/+2.4%。

**证据 C —— 组合腿:等权相加是 wash,净口径上还略差;而且连毛口径上的增量都在噪声带内。**
`h12_add_best_m30` +12.0%/+21.4%、夏普 +1.78/+3.50 vs 家族单独 +12.6%/+22.3%、+1.78/+3.46
→ 净超额 **−0.6pp / −0.9pp**、夏普 **0.00 / +0.04**,全部在噪声带内(±3pp / ±0.3)。
毛超额确实略高(+16.5%/+25.3% vs +15.2%/+24.4%),但 **+1.3pp / +0.9pp 本身就在 ±3pp 噪声带内** ——
**连毛口径上都没有可辨别的增量**,而换手从 3.4% 升到 5.9%。
`h12_sub_best_m30`(引擎自选 sign=+1)+2.9%/+11.2% 明显更差 → 确认 `add` 是同向组合、`sub` 是对冲腿,事前的分支已解决。

### (2) 「小权重会不会好?」—— 用成本比例算得出来,**决定不再跑**

本研究的成本在五个变体上都稳定等于约 **0.75 × 换手**(核对:v_base 4.1−1.8 = 2.3pp / TO 3.2% → 0.72;
家族 15.2−12.6 = 2.6 / 3.4 → 0.76;w60 5.8−3.5 = 2.3 / 3.1 → 0.74;组合 16.5−12.0 = 4.5 / 5.9 → 0.76;iso 5.6−(−2.3) = 7.9 / 10.4 → 0.76)。
等权组合相对家族:Δ毛 = **+1.3pp**、Δ换手 = **+2.5pp** → Δ成本 = 0.75×2.5 = +1.9pp → Δ净 = **−0.6pp**,
与实测的 −0.6pp 精确吻合(valid 同样吻合:Δ毛 +0.9pp、Δ净 −0.9pp)。
**要有净增量,需要 Δ毛/Δ换手 > 0.75;实测 train 是 1.3/2.5 = 0.52、valid 是 0.9/2.4 ≈ 0.38,都不够。**
把权重 λ 调小,一阶上 Δ毛 与 Δ换手 同比例缩放,Δ净 = λ·(0.52−0.75)·Δ换手₁ **仍然为负** ——
没有任何机制会让更小的权重把这个比值变好。
→ **决定不跑不等权组合**(`add(cs_rank(fam), add(cs_rank(fam), add(cs_rank(fam), cs_rank(w60))))` 这类 3:1 嵌套是可写的,
  但答案已经被上面的算术定死,而额度很紧)。这条推断的等级:**合理但未坐实(有算术支撑)**;
  λ=1 的测量本身是**已确立**的。

### (3) 本研究真实的、站得住的正面结论(属于「分辨」,不属于「升华」)

**已知家族自己的 `all_controls` R² = 0.871** —— 家族 87% 被常见控制变量(成交额 / 市值 / 换手 / 波动)解释掉,
它基本上**就是**规模与流动性暴露。而这条因子只有 0.162、它的家族残差只有 0.038,
与「日收益的 15 日下四分位数」rank 相关 **+0.00**(H6,R1 决定性否定),与家族 0.13~0.19。
→ **这条因子确实不是已知暴露换了一种写法,它读的是别的东西。这一点是坐实的。**
→ **但「是别的东西」和「对纯多头用户有用」是两件事。** 后者被证据 B、C 否掉了:
  这块正交的东西在 fit 段上约等于零,只在 2021–2023 的制度里出现,加进组合里扣费后是负的。

### (4) H13(多头腿是否可用)—— 改写后定稿

扣费后的多头腿在所有版本上两段同号为正(+1.8%~+3.5% train / +8.1%~+8.6% valid),所以不是「不可用」;
但毛超额只有 +4.1%~+5.8% / +10.0%~+10.7%,长端剖面没有一个版本在 train 上严格单调,`long_share` 只有 19%~35%。
→ 定稿措辞:**多头腿「可以交易但很薄」—— 幅度只有已知家族的 1/4~1/3,强信号始终在空头端。**

## 这一阶段的产出

- **H12 被支持**:对只能做多的用户,这条因子相对已知成交额家族**没有可用的增量**。这就是本研究的结论,是一个合格的否定结论。
- **排除**所有「家族 + 本因子」的组合候选作为推荐对象;但 `h12_add_best_m30` 要**作为留出段的第 5 个候选**保留,
  因为它是对「有没有增量」最直接的样本外检验(事前判据 J4 是唯一能翻转总结论的那一条)。
- 残差腿(`h12_res_*`)**不进留出段**:它不是用户会交易的东西,净值被成本支配,且逐年表已经把它判死。
- **决定不做**:不等权组合(见 (2))、H9/H10/H15/H18 的机制脚本(不改变推荐,见 `state.md` §6)。
