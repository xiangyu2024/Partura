只列能明显降低不确定性的(修订后重排;第 1、2 条是修订新加的):

1. **把"避开近 60 日封板票"和"K 的排序"拆成两个东西分别用。** r1 说推荐式的多头腿约四成是前者、约六成是后者,而 60 日极值比"原式 + 慢半衰期"多出来的那块就是更长的封板记忆。
   直接的做法:股票池先用一个朴素的过滤器(近 60 日没有封板日 / 不在 athi60 最高的五分之一),再在池子里用提纯式 `cross_mean(abs_(K),15)` 配长半衰期排序。
   如果它不差于 `f_max60`,那么"3 对 + 峰度"这个脆弱的估计量只需要负责排序,事件交给一个谁都看得懂的过滤器。这需要新的样本外数据(本研究的留出段已经用掉)。
2. **半衰期按纯多头夏普选一遍。** 用户口径按多空夏普选半衰期;在这条因子上它让原式的留出段多头腿从 +2.5% 变成 −0.7%。本批其他"空头腿是事件"的因子很可能有同样的问题,
   `final.json` 里每个候选的 `splits_at_hl_long` 已经存着这组数,只是 `digest` 和报告不打印。
3. **把"离散"那一半单独认出来。** x3 §4 说近三年值钱的是 K 的日间离散,而它在干净股票池里(没有封板、没有僵尸日)仍然有多头腿(valid +10.5%)。
   这些"出格但不是封板"的日子是什么?按 K 的符号拆(K 突然很负 = 单边趋势日?K 突然为正 = 午后封板 / 临停?),各自看次日超额。
   如果它能写成一个直接的事件定义,就不再需要"3 对 + 峰度"这个脆弱的估计量。
4. **K 在主体上的微观含义。** 现在只到"A 自己的矩张成 75%"。把 4 分钟形态(孤立跳动 / 同向连动 / 来回跳 / 不动)的频率直接数出来,
   看 K 的水平是哪几个频率的函数、哪一个频率带着预测力。这也是解释"为什么只有 3 对行"的唯一办法。
5. **水平那一半为什么退了。** 2021 年是分界。候选解释:量化资金在分钟级别的做市 / 拆单改变了局部形态的分布;逐年看 K 的截面分布和它与换手率的相关有没有漂移。
6. **换一个基准重算多头腿。** 相对"剔除近 60 日封板票与短历史票"的等权,`u_max60` 按 hl=0 的多头腿净超额是 +3.3% / +5.5%(r1 §3;x3 §3 的 +5.7% / +8.8% 是 hl=10)。
   这才是纯多头使用者实际拿到的数;本批其他因子也值得用同一个基准重算一遍。
7. **和 F001 家族的组合。** rank 相关只有 0.24~0.27,多头腿来源不同(那边是低成交额,这边在每个成交额桶里都有、且高成交额桶里最强:+26.3% / +25.5%)。
   两者合起来的多头腿是不是相加的,值得一个阶段。
