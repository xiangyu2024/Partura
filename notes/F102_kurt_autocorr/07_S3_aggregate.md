1. **缺失日的处理是原式的一个缺陷,修掉就涨(x2 §1 的预测成立)。** `a_mean_sq15` 只把求和换成均值,和原式的 rank 相关是 1.00,
   多空夏普 +3.68/+3.88 → +3.84/+4.30,多头腿净超额 +4.9%/+4.5% → +6.3%/+5.2%。再把平方换成绝对值(`a_mean_abs15`)是同一个东西
   (rank 相关 0.98,LS +4.01/+4.28)。**同速度下的提纯结果就是 `cross_mean(abs_(K),15)`**:算子数没少,但每个算子都是它该是的那个。
2. **水平和离散各自都不稳,逐日折叠把两者绑在一起才稳(H12、H13)。** ΣK² = 15·(均值² + 方差)。只留水平(`a_level15`):
   train 很好(LS +4.23),valid 的多头腿净超额只剩 +0.3%、rank IC 从 0.0219 掉到 0.0081。只留离散(`a_disp15`):反过来,
   train 多头腿毛超额只有 +1.3%,valid 是 +10.5%、rank IC 0.0341 比原式还高。两者互相的 rank 相关是 −0.02 —— 是两个独立的成分,
   **哪一个值钱随时期在换**(x3 §4 给了逐年的 rank IC:水平从 2019 的 +0.029 一路降到 2023 的 +0.001,离散从 +0.016 升到 +0.038)。
   H12 预测的"多头腿变差"在 valid 上成立、在 train 上不成立;H13 预测的"空头腿保住、多头腿变差"在 train 上成立、在 valid 上不成立。
   所以正确的说法不是"折叠多余"或"水平多余",而是:**原式的稳健来自它同时装着两个此消彼长的成分**。
3. **两条腿要的速度不一样(H14 成立),而且到 120 天不塌。** 极值记忆 15 → 30 → 60 → 120(15 是 S1 的 `l_max`:+6.6%/+6.2%):
   多头腿净超额 +6.6%/+6.2% → +8.5%/+8.0% → +11.3%/+10.1% → +10.1%/+10.6%;纯多头夏普 +1.61/+2.22 → +2.07/+2.88 → +2.70/+3.20 → +2.49/+3.12;
   空头腿毛超额 +37.7%/+34.3% → +34.2%/+27.9% → +23.7%/+19.2% → +17.7%/+14.0%;多空夏普 +3.74/+4.40 → +3.74/+3.97 → +3.37/+3.32 → +2.93/+3.12。
   多头腿**毛**超额几乎不动(+12.0% ~ +14.3%),涨的全是省下来的成本(多空换手 7.2% → 5.2% → 3.1% → 2.0%)。
   60 不是尖点:30 和 120 在两边都站着。`u_max30` 在 train 和 valid 上**每一项都不低于原式**;`u_max60` 用 0.3~0.5 的多空夏普换来多头腿净超额翻倍。
   (修订:这里的"翻倍"是和 **hl=1** 的原式比 —— 那是按多空夏普选的半衰期。和 hl=5 的原式(+8.5% / +9.8%)比,`u_max60` 多 2.8 / 0.3 个点、`u_max30` 持平;各候选在每个固定半衰期下的表和逐日配对检验在 `07x_5_revision.md` §3。)
4. **长窗口上极值聚合略好于均值(H16),中位数明显差(H15 只成立一半)。** 同是 60 天:极值 +11.3%/+10.1%,均值 +9.0%/+8.7%,
   中位数 +7.4%/+9.3%(多空夏普只剩 +2.49/+1.94)。中位数看不见单日事件,空头腿没了是预料之中的;但它的多头腿在 train 上也低了 4 个点 ——
   多头腿要的不只是"典型的一天正常",还要"60 天里没有任何一天出格"。这和第 2 点是一回事:离散那一半也在给多头腿供货。
