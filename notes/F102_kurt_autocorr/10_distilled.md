**头条**:留出段多头腿净超额 —— **原式 hl=1 −0.7% / 原式 hl=5 +2.5% / `f_max60` +7.4%**。

**这 8.2 个点怎么分**(审查意见 1、2,接受):

- **3.2 个点是"放慢"**,表达式不用动,只要半衰期按纯多头选(5 而不是 1):成本每年省 4.4 个点,毛超额少 1.3 个点。
- **5.0 个点是 60 日极值在此之上多出来的**(毛超额 +3.2、成本 +1.8)。两本多头书都用纯多头的半衰期比(`f_max60`@hl2 对原式@hl5)是 4.5 个点。
- 同一个分法在 train 是 3.6 + 2.8(结构那块 t = 2.3),valid 是 5.3 + 0.3(t = 0.2),合起来 4.1 + 2.1(t = 2.1)(r1 §3 的逐日配对)。
  原报告写"升华的大头是慢"—— **在 train / valid 上对,在留出段上不对**:留出段上结构占了六成。三段的比例不稳定,这本身是要报告的事实。
- **留出段上那 5.0 个点有多显著**:要两条多头书日序列的相关。审查按 0.6 粗估,标准误 3.0 个点,约 1.6σ。r1 在 train / valid 上实测这个相关是 **0.85**
  (train 0.85、valid 0.83),按它算标准误是 1.9 个点,约 **2.6σ**。留出段上的相关是不是也在 0.85 我验证不了(那需要留出段的日序列,不许再读)。
  老实的说法:**1.6σ ~ 2.6σ,取决于一个我量不到的数;同一个增量在 valid 上是 0;而且它是 10 个留出段数字里挑出来比的一对。**
- **30 对 60**:用户口径下 `f_max60` +7.4% 对 `f_max30` +4.9%;都用纯多头的半衰期是 +7.0% 对 +7.6%。先后取决于半衰期怎么选,差别在半个标准误以内。

**结构那一块是什么(只有 train / valid 的证据)**:是更长的封板记忆。把封板日从 K 里拿掉再取 60 日极值,多头腿净超额从 +11.3% / +10.1% 掉到 +6.8% / +6.7%,
比"原式 + 慢半衰期"的 +8.5% / +9.8% 还低;在没有封板票的干净股票池内部,60 日极值相对原式@hl5 的增量是 +2.0%(t 1.1)/ −1.2%(r1 §3)。
也就是说 `f_max60` 比"原式放慢"多做的那件事,是把"近 15 日封过板的票不进多头腿"换成了"近 60 日封过板的票不进多头腿"。

**为什么仍然推荐它,以及这句话的边界**:

- **它对"半衰期怎么选"不敏感,原式和 30 日版本都敏感。** `f_max60` 在两种选法下是 +7.4% / +7.0%;`f_max30` 是 +4.9% / +7.6%;原式是 −0.7% / +2.5%。
  用户口径的半衰期是按多空夏普自动选的,在这条因子上它会选到对空头腿最优的那一档 —— 把慢写进表达式,才不依赖下游改口径。这是推荐 60 而不是 30 的理由;
  如果下游愿意按纯多头夏普选半衰期,`f_max30`@hl5 与它打平,多空夏普也相近(+2.32;`f_max60` 是 +2.40 / +2.11)。
- 代价是多空夏普:用户口径下训练段低 0.36,留出段低 0.17(后者在噪声内)。
- **它不是一个"已知暴露解释不了的多头腿"**(审查意见 3,接受)。加上与它同期限的控制后 R² 是 0.45 而不是 0.19,残差的多头腿毛超额 +4.3% / +3.9% 而不是 +11.1%;
  把实际持有的多头十分位拆开(r1 §2):train / valid 上毛超额 +14.6% / +13.4% 里,**+6.4% / +5.3%(约四成)是"它所在的桶"—— 避开近 60 日封过板、日频波动最高的票**,
  +8.1% / +8.1%(约六成)是桶内选股。没有哪个朴素 60 日量能单独复现这条多头腿(train 上最好的 +6.7%),但它也不是"控制变量解释不了"的。
- **+7.4% 这个数要打折读**:基准是"所有有信号有标签的票的等权",里面含着近期封板和短历史的票。在剔掉这些票的干净池内部(基准也换成干净池的等权),
  `f_max60` 按它实际的半衰期 hl=0 算,train / valid 的多头腿净超额是 **+3.3% / +5.5%**(毛 +6.9% / +8.6%),全市场基准下是 +11.3% / +10.1%。
  (原报告这里写的 +5.7% / +8.8% 是在干净池内部另选了 hl=10 的数,不是推荐式实际交易的那个;更正见 `07x_5_revision.md`。)留出段上的对应数字没有算,也不能再算。
  如果留出段也是这个比例,+7.4% 里来自"排序本身"的大约是 +2% ~ +4%。
- 留出段的多头腿毛超额比训练段少了四分之一到四成(`f_max60` 13.9% → 10.2%,`f_orig` 12.8% → 8.3%,`f_max15` 13.7% → 8.0%;所有候选都降)。x3 §4 在读之前就指出因子的一半("水平")在 2023 年已经没有预测力;
  留出段的衰减与此一致,但我没有在留出段上把两半分开验证。

**修订后的 train / valid 证据有没有指向别的候选**:没有。train / valid 上,各自配上纯多头的半衰期之后,`f_max60`@hl0(+11.3% / +10.1%)、`f_max30`@hl5(+10.0% / +10.6%)、
`f_mean_abs15`@hl10(+10.6% / +10.3%)三者打平(r1 §3 里做了配对的两对,t = 0.5 和 1.6),比原式@hl5(+8.5% / +9.8%)高 0 ~ 3 个点;留出段把它们分开了(+7.4% / +7.6% / +3.8% / +2.5%)。
修订里新试的结构只有一个(看不见封板日的 60 日极值),它更差。**推荐仍是读之前定的 `f_max60`;没有哪个没读过留出段的候选更值得推荐。**
