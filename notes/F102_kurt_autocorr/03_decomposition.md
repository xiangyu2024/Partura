分解表本身没有歧义(A → B → C → D 一条直链,只用到 `Ret` 一个字段)。需要补充的是**每一层在真实数据上到底算出了什么**,
因为这条链上四个算子里有三个的名字会把人带偏。下面的数字都来自 x1 / x2(`07x_1_anatomy.md`、`07x_2_refine.md`)。

**A = `nt_ts_autocorr_s1(Ret, 3)`**,逐分钟、逐股票、不跨日:

```
A_t = corr( (r_t, r_{t−1}, r_{t−2}),  (r_{t−1}, r_{t−2}, r_{t−3}) )          # 3 对,Pearson
    = cov / ( sqrt(var_x · var_y) + 1e−9 )                                    # 任一侧不动 ⇒ 恰好 0
```

它不是一个自相关的估计量,是 **4 个连续分钟收益的形态分类器**。A 股的分钟收益贴着 1 分钱的格子跳,4 个收益的组合只有有限几种,
A 相应地只取少数几个值:四分钟都不动 → 0;一次孤立的跳动 → 两个 −0.5;连续两分钟同向 → +0.5 附近;来回跳 → −0.5 ~ −1。
训练段里一天中分钟收益非零的占比 W 的中位数是 0.65,A 非零的占比 Z 的中位数是 0.90 —— 对多数股票-日,A 在九成的分钟上有值。

**B = `day_kurt(A)`**,把一天的 A 折成一个数 K(超额峰度)。它在两个区间里是两种东西:

```
活跃度 Z:      < 0.5(2.2% 的格子)                    > 0.6(95% 的格子)
K:             ≈ 1.45 / Z − 3  ≫ 0                    −1.2 ~ +0.3,中位数 −0.35
它在量什么:    稀疏度(价格有多少分钟没动)            A 的分布形状(对称 / 平 ↔ 挤在负的一侧)
是谁:          涨停封板日、僵尸日                      正常交易日
```

- 左边:A 大部分是 0、少数例外,峰度就是稀疏度计(探针 `two_point_response` 与伯努利峰度的解析式逐位相同)。
  涨停封板日上 Z 的中位数 0.22、K 的中位数 +2.8、p95 +94。**全天一字板 K 是 NaN**(方差为 0),反而看不见。
- 右边:K 与 Z 的 rank 相关只有 −0.05,和"多少分钟在动"无关;它跟 A 的日内偏度(+0.57)和均值(−0.37)走 ——
  K 越负,A 的分布越对称、越平(正的局部相关出现得越多);K 靠近 0,A 挤在负的一侧。

**C = `pow_2(B)`** = K²。K 两头都有,所以平方是**折叠**,不是保序变换。两头极不对称:
主体一侧 K² 在 0 ~ 1.4,事件一侧可以到几千(最大的 1% 股票-日占了 K² 总量的 98.7%)。

**D = `cross_sum(C, 15)`**,最近 15 个交易日的 K² 之和。两件事:

- `nansum`:停牌日、一字板日(K = NaN)记 0,和"当天 K 恰好为 0"不可区分 —— 这是一个缺陷(x2 §1),换成均值或极值就没了。
- 和式可以拆开:**Σ K² = 15 ·(K 的 15 日均值² + K 的 15 日方差)**。前一项是"K 的水平离 0 多远",后一项是"K 稳不稳"
  (一次事件日就让它爆掉)。15 日和里最大那一天占的份额中位数是 0.22(纯求和是 0.07,纯极值是 1.0),只在最右边的 5% 才接近 1。
  S3 把这两项分开测了:两项的 rank 相关是 −0.02,各自都只在一段时期里值钱。

**所以整条表达式是**:对"4 分钟局部形态的分布"取一个形状统计量 K,再问"最近 15 天里 K 离 0 有多远、出格过几次"。
它不含收益的方向、不含成交量、不含波动的幅度(A 名义上是零次齐次的;分母里的 `+EPS` 在分钟收益的量级上会压低一部分输出,x1 §3 量过:有,但不重要)。
