**§1 "短历史"污染(H18)不成立,但它提醒了基准的问题。** 60 日窗口里有效天数不足 60 的票占有标签格子的 14.8%(train)/ 7.2%(valid)。
它们**不在**多头腿里扎堆:

|---|---|---|---|---|---|

| 同上(valid) | 2.1% | 3.5% | 8.8% | 10.9% | 28.0% |

| 同上(valid) | +13.5% / +13.7% / +4.6% | | | | |

多头腿的超额是满历史的票挣的。把短历史的票强行排到空头一端,多头腿净超额 +10.1% / +10.3%(原来 +11.5% / +10.1%),没有变化。
但是**把这些票从股票池里整个拿掉**,多头腿毛超额从 +14.5% / +12.7% 掉到 +10.7% / +10.9% —— 多头腿自己没变,变的是基准:
短历史的票在 D5–D10 里年化跑输 15~36 个点,拿掉它们等权基准就高了。也就是说,用户口径下的"多头腿超额"里有 2~4 个点是
"基准里含着一批谁也不会去买的票"。这对本批所有因子都一样,不是这一条特有的,但读绝对数字时要记得。

**§3 多头腿不只是"60 天没封过板"。** 定义干净股票池 = 近 60 日没有封板日、满 60 天有效、没有僵尸日(最小 Z ≥ 0.5),
占有标签格子的 49.6%(train)/ 64.1%(valid)。它的等权比全市场等权每年高 +7.7% / +5.2% —— 这一块是"避开事件"挣的,任何人都拿得到。
**在干净池内部**,`max(K²,60)` 的十分位剖面(相对干净池自己的等权)仍然单调:train −11.6% … +6.8% +7.3%,valid −7.6% … +4.6% +11.0%;
书:LS +2.04 / +1.63,多头腿毛 +8.4% / +11.0%、净 +5.7% / +8.8%(原式在同一个池子里:+6.3% / +11.6%、净 +1.3% / +6.7%)。
所以 `u_max60` 的多头腿 ≈ 一半是"避开近 60 日的事件票",一半是干净池内部的状态排序。

> **修订时的更正**:上面干净池内部那一行书的半衰期是在池子里按多空夏普另选的 —— `max(K²,60)` 选到 **hl=10**,原式选到 hl=5 —— 不是推荐式实际交易的 hl=0。
> 按 hl=0,干净池内部 `max(K²,60)` 的多头腿是毛 +6.9% / +8.6%、净 **+3.3% / +5.5%**(r1 §3);原式 hl=1 是净 −1.3% / +0.8%。"一半一半"这个读法不变,
> r1 §2 把它落到了实际持仓上:配置(所在的桶)+4.7% / +3.8%,选股 +9.8% / +9.7%(按干净池标记分两桶),按封板代理的五分位是 +6.4% / +5.3% 与 +8.1% / +8.1%。

  复算是 +0.00005(train +0.01734),2022 的 +0.005 和 2023 的 −0.006 抵消了。
- **离散那一半(K 的日间标准差,事件日 + 出格日)逐年在变强。** 原式的 rank IC 2023 年掉到 +0.0140,是水平那一半归零拖的;
  `max(K²,60)` 六年都在 +0.022 ~ +0.035 之间,是这几个里最平的。

**§5 纯多头的实际问题。**

- **宽度**:`max(K²,60)` 的多头腿取前 5% / 10% / 20%,净超额 +10.0%/+13.1%、+11.5%/+10.1%、+9.9%/+8.4%,纯多头夏普 +1.88/+3.46、+2.59/+3.20、+2.76/+3.20;
  多头书自己的单边日换手 5.2% / 3.9% / 2.7%。原式同口径:+3.0%/+6.9%、+4.9%/+4.5%、+6.8%/+5.6%,换手 13.2% / 10.4% / 7.5%。不是只在某一个宽度上成立。
- **双重排序**(在控制变量的每个五分位内部各自取因子的多头十分位,相对该五分位的等权):

| 分桶变量 | 因子 | train Q1…Q5 | valid Q1…Q5 |
|---|---|---|---|
| 换手率 | `max(K²,60)` | +3.9 +5.0 +10.8 +13.6 **+31.8** | +2.1 +5.3 +9.1 +12.0 **+33.3** |
| 换手率 | 原式 | +3.0 +7.7 +9.1 +13.9 +25.2 | +1.9 +4.2 +7.2 +12.7 +46.1 |
| 成交额 | `max(K²,60)` | +6.3 +6.2 +9.8 +13.5 +26.3 | +2.4 +5.8 +4.8 +1.1 +25.5 |
| 市值 | `max(K²,60)` | +19.5 +13.4 +13.4 +12.4 +10.6 | +16.4 +16.5 +9.6 +6.7 +2.7 |

  多头腿在每个换手率桶里都是正的,而且**越是高换手的票越值钱**(Q5 里 +32% / +33%):它不是"买低换手的票"的另一种写法 ——
  恰恰相反,它是在最热闹的那批票里把"没出过事、分钟形态正常"的挑出来。按市值看,valid 上大市值一端只剩 +2.7%,容量有限。
- **"快事件 + 慢状态"的排名相加不比单用一个好**:`rank(max60) + rank(mean|K|15)` LS +3.67/+4.19、多头腿净 +6.4%/+6.1%;
  权重减半 +3.63/+4.24、+7.9%/+7.4%。落在 `u_max30`(+3.74/+3.97、+8.5%/+8.0%)附近,多一个算子没有换来东西,不进候选。
- **拉长记忆不等于多平滑几天**:原式固定 hl = 5 / 10 / 20 的多头腿净超额是 +8.5%/+9.8%、+8.8%/+10.3%、+8.1%/+8.9%,纯多头夏普 +1.84/+2.79、+1.79/+2.61、+1.56/+2.02;
  `max(K²,60)` 在 hl=0 上是 +11.5%/+10.1%、+2.59/+3.20。train 上多 3 个点、valid 上持平 —— **升华的大头是"慢"本身**,
  极值聚合在此之上的增量只在 train 上看得见。
