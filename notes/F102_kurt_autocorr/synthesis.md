# F102_kurt_autocorr —— 批量扫描 s1 的综合(主研)

`cross_sum(pow_2(day_kurt(nt_ts_autocorr_s1(Ret, 3))), 15)`,sg = −1(多头 = 低值)。
口径:多头腿扣 15bp 净超额 / 纯多头夏普,train 2018–2021、valid 20220101–20230807、utrain 两者合并。
基准 `k_known = cross_mean(day_std(Amt), 30)`:+12.6% / +22.3% / +15.4%,夏普 2.22。原式 +8.5% / +9.8% / +8.9%,夏普 2.05。
噪声:净超额 ±3 个点、夏普 ±0.3。所有数字来自 `study.sh table F102_kurt_autocorr s1 --all`(94 个变体)。

## 1. 它是什么(按函数定义逐层)

| 层 | 定义(来自 `study.sh src`,不是名字) | 实际算的东西 |
|---|---|---|
| `Ret` | 分钟收益面板 | — |
| `nt_ts_autocorr_s1(Ret, 3)` | `ts_corr(x[1:], x[:-1], 3)`,`rolling_pair_reduce` 沿分钟轴;分母 `sqrt(var_x·var_y) + EPS` | **3 个配对点**的滞后 1 相关,即只用 4 根连续分钟收益算出的「相关系数」。样本量 3 的相关是 U 形的,质量堆在 ±1;而窗口内收益全相等(封板 / 停牌 / 无成交)时 var = 0,值**恰好是 0**(EPS 在分母) |
| `day_kurt(·)` | `C._kurt`,同族内核 `nankurt_last` = `m4/(var²+EPS) − 3`,`var ≤ EPS` 时 NaN | **超额**峰度(不是原始峰度),下界 −2、上界无穷;当天这条 autocorr 序列全常数时是 NaN |
| `pow_2(·)` | `pow_(x, 2)`,`e > 1` 走 `x**e` 分支(**不是**带符号幂) | 平方 = 一个**折叠**。因为超额峰度 ≥ −2,平方把「薄尾」一侧硬顶在 ≤ 4,把「尖峰」一侧放大到无穷 → 实质是 `max(kurt,0)` 的凸版本 |
| `cross_sum(·, 15)` | `rolling_reduce(..., nansum_last)` | 近 15 个交易日求和,**NaN 当 0** |

名字和定义不一致的三处:(a)`pow_2` 在这里不是「强调大值」而是**折叠符号**;(b)`day_kurt` 是超额峰度,可以为负 —— `sub_C_pow_1_5`
(`x**1.5`,负数 → NaN)的 cov 掉到 **0.75**,直接量出**25% 的股票-日峰度为负**;(c)`cross_sum` 不是「累计」而是「求和 + 把缺失日算成 0」,
对停牌 / 次新是一个**系统性低估**,而 sg = −1 下低 = 买,所以这个缺陷是**买进**历史不全的票。

一句话:**「近 15 日里,有没有哪一天的分钟收益出现过『长段纹丝不动 + 几根孤立跳』的结构」;有 = 不买。** 这是一台封板 / 停牌 / 死盘口探测器,
不是任何意义上的「自相关」因子。

## 2. 预测力在哪

**承重(一换就塌)**

- **`pow_2` 这个折叠**:`abl_C` 去掉它 → −4.0%、夏普 −0.71,而且与原式 rank 相关 **ρo = 0.00**(`sub_C_neg` 同值)。峰度的**水平**一点信息没有,
  只有**绝对值**有。`sub_C_pow_05` / `sub_C_signedpower`(带符号幂)−4.0% / −3.1%,`sub_C_inv` +1.5% —— 凡是保号的都死。
- **非负 + 凸**这两条性质:`sub_C_abs_`(绝对值,保非负丢凸性)ρo = **0.96** 但 +7.0% / 夏普 1.48,比平方低近 2 个点;`sub_C_log`(负数变 NaN)+8.9% / 1.89;
  `sub_C_sqrt` +5.0%。排序是 平方 > log ≈ abs > sqrt > 保号 —— **凸性值约 1.5~2 个点,折叠值约 13 个点**。
- **3 分钟孔径**,而且是**刀尖**:`win_A_5` 掉到 +1.5%、`win_A_10` 到 −3.1%(valid −12.6%)。**没有平台**。这是全树最脆的地方:
  窗口一放宽,「var = 0 → 恰好 0」这个退化出口就被稀释了。
- **A 槽位(autocorr)不可替换**:同窗口换成 `nt_ts_scale` +6.6%、`argmax` +4.3%、`rank` +2.8%、`std/stddev` +3.1%、`skew` −1.4%、`kurt` −3.1%,
  ρo 全在 0.03~0.45。`abl_A`(整层删掉,峰度直接压在 Ret 上)+2.6%、ρo 0.09。
- **B 槽位(day_kurt)不可替换**:`day_std` −6.0%(ρo −0.08)、`day_gini` +3.2%、`day_skew` +2.4%、`day_pos_ratio` −1.0%、`day_q_stat_std` −6.6%、
  `day_autocorr_n1` / `day_ar1` +1.6% / +1.3%。**它读的不是离散度**(std 是反的),是尖峰。
- **叶子不可互换**:`Vwap` 的 1 分钟变化率 +5.5%(train +1.5%、valid +14.4%,不稳)、`in_pct(Close,5)` +2.9%、
  `in_logchg(Volume,1)` +0.6%、`in_pct(Volume,1)` / `in_pct(Amt,1)` ≈ 0。「分钟收益与量的变化率可互换」在这棵树上**不成立** —— 因为承重的是
  收益在 0 上的点质量,量的变化率没有这个原子。

**多余(删了不掉 / 可改良)**

- **外层 `cross_sum` 几乎只是平滑**。`iso_C`(把整个 D 层删掉,只留一天的 `pow_2(K)`,书的半衰期 hl = 20)= +8.0% / 夏普 1.61,
  只比原式(hl = 5)低 0.9 个点。而且**总平滑量守恒**:原式 hl = 5、`iso_C` hl = 20、`mem_mean60` hl = 0,都落在 +8~+11%。
- **窗口有平台**:`cross_sum` 的 D 窗口 5 / 10 / 15 / 30 / 60 → +10.0 / +9.5 / +8.9 / +7.9 / +8.7%,夏普 2.02 / 2.04 / 2.05 / 1.75 / 1.80。平的,窗口不是杠杆。
- **真正的杠杆是换手**:换聚合器(同窗口 15)就能把日换手从 5.4% 压到 2.1~2.4% 而毛超额不掉 ——
  `cross_ema` +10.8% / LTO 2.1%、`cross_decay_linear` +10.9% / 2.4%、`cross_fangzheng` +9.6% / 2.3%;外面再套 60 日记忆:
  `mem_mean60` **+10.8% / 夏普 2.31 / LTO 2.7%**、`mem_decay_linear60` +10.6% / 2.30。约 2 个点的净超额**全部来自省下来的费**。
- **`cross_sum` → `cross_mean` 是纯提纯**(`sub_D_cross_mean` +10.2% / 夏普 2.32 / ρo 0.99):同结构同速度,只是不再把缺失日算成 0。见下一节,
  这一改把两个最坏的股票段修好了。
- 伤害性的改法:`cross_zscore` −13.7%(LTO 18.4%)、`cross_scale` −10.0%(LTO 22.7%)、`cross_delta` −5.3%、截面折叠 `fold_sq` / `fold_mean` −17~−19%。

## 3. 在市场的哪儿、什么时候有效

**(a) 流动性:段内预测力随成交额单调上升,而多头书却压在最差的一端。** 成交额(20日)五分位的段内净超额 = **−2.9 / −4.3 / −0.3 / +6.1 / +12.4%**,
而全市场多头书对最低分位**超配 +21.1 个点**、对最高分位低配 −11.0 个点。把「超配 × 段等权超额」点乘:
**原式 +5.5 个点来自跨成交额桶的倾斜**(占 +8.9% 的六成),`k_known` 是 **+14.7 个点**(占 +15.4% 的 **95%**)。
推断:低成交额票的分钟收益里有大量「没成交 → Ret = 0」,`day_kurt` 在那里读到的只是「薄」,而「薄」本身已经被流动性溢价定价了,没有残差信息;
在活跃票里 Ret = 0 只可能来自**封板**,是一个真事件。**可检验推论**:把 `day_zero_ratio(Ret)` 直接写出来,它在低成交额段应与原式高度重合、在高成交额段分开;
对 `day_zero_ratio` 做残差之后,原式剩下的部分应当集中在活跃票。(h_res_zero60 / h_bk_amt_mean / h_liq_only)
注意**不能简单剔掉不活跃票**:最低成交额段的段等权超额是 **+15.1%**,只做最高分位 = +12.4% − 17.8% = **−5.4%**。流动性倾斜要留,要修的是桶内。

**(b) 板块:科创板是唯一的大坑,而且根因是 `cross_sum` 的缺失日当 0。** 科创板占 4.0%、段等权超额 +4.1%(本身不差),但原式**段内 −28.5%**,
而多头书对它**超配 +8.3 个点**(书里 12.3% 的仓位压在这里)。换成 `cross_mean`,段内 −28.5% → **+3.0%**;`cross_max` → −8.1%、`cross_fangzheng` → −9.1%。
同一个修复在次新段更明显:上市不足 250 日(7.1%、段等权 **−28.7%**)原式段内 +7.1% → `cross_mean` **+23.5%** / `cross_decay_linear` +25.5% / `cross_fangzheng` +20.5%。
推断:科创板 2019 年起陆续上市,样本内大量股票的 15 日窗口里有缺失日;`cross_sum` 把缺失日记 0 → 和数偏小 → sg = −1 下被当成「最干净」买进去。
**可检验推论**:用 `cross_valid_count` 把「近 60 日有缺失日」写进表达式并剔除,应当在 `cross_sum` 版本上大幅改善、在 `cross_mean` 版本上几乎没有改善。(h_susp_excl / h_vc_bucket)

**(c) 冻结盘口段是它真正打赢已知族的地方。** 近 15 日有冻结盘口(封板 / 停牌)的股票占 6.5%、段等权超额 **−67.4%**;原式对它低配 **−5.0 个点**,
`k_known` 只低配 −2.9 个点。按「超配 × 段等权」算:**原式从这一条拿到 +3.6 个点,已知族只拿到 +2.1 个点**。在无冻结的干净池子里原式只有 +5.5%,已知族 +14.1%。
也就是说:**它 = 流动性倾斜(+5.5)+ 封板规避(+3.6),剩下的接近 0**;而它相对已知族多出来的,就是那 1.5 个点的封板规避 + 活跃票里的桶内选股。

**(d) 市值 / 价格 / 时间。** 市值前 20% 段内只有 +1.7%、价格前 20% 只有 +3.7%,其余四个分位都 +6~+10% —— 大票上没有。
年度**异常稳定**:2018→2023 = +8.1 / +11.1 / +9.3 / +5.6 / +10.3 / +9.3%,没有衰减;`k_known` 同期 +17.3 → +6.7 → +24.7,摆动大得多。
状态:市场近 20 日上涨 +13.2% vs 下跌 +3.8%、放量 +13.3% vs 缩量 +5.4%、高波动 +10.3% vs 低波动 +7.6%、高离散 +10.1% vs 低离散 +7.9%。
推断:封板和涨停板的供给是顺周期的 —— 放量上涨的行情里涨停票最多、事后回撤也最凶,规避它们的收益就最大;缩量市里几乎没有封板可躲,因子就只剩流动性倾斜。
**可检验推论**:如果机制是「躲涨停」,那么(i)用 `day_signed_ratio(Ret, Amt)` 的 15 日极大值(封板日 ≈ +1)应该能部分复现;
(ii)在「个股自己放量」的桶内做排名,应该比全市场排名更强;(iii)把树在混合里的权重按市场放量程度调,应该优于固定权重。(h_signed_max / h_bk_expand / h_ov_state)

## 4. 相对已知成交额族有没有增量

ρk = **+0.26**,结构上不是同一条。但把已知族剥掉之后剩得不多:`res_known` +3.7% / 夏普 0.77、`bk_known` +4.0% / 0.98(dist 0.20 ✗)、
`res_liq` +4.8% / 1.01、`bk_liq` +5.0% / 1.22(dist 0.20 ✗)。**作为独立因子它输给已知族**(8.9 vs 15.4,夏普 2.05 vs 2.22),
原因如第 3 节:两者的大头是同一个流动性倾斜,而已知族吃得更彻底。

**作为小权重叠加有正增量,但在噪声边缘。** `ov_p025` / `ov_p05` / `ov_p10`(权重 0.25 / 0.5 / 1.0)= 净超额 +15.6 / +15.3 / +14.3%、
夏普 **2.51 / 2.62 / 2.57**,对比已知族 +15.4% / 2.22。净超额持平,**夏普 +0.3~0.4**(刚到噪声上沿),但三个权重同向、且反号叠加
(`ov_m025` 1.59、`ov_m05` 1.18)明确变坏 —— 符号是对的,不是碰运气。
诚实的结论:**它不是一条可以单独上的纯多头因子;它是已知族的一个减波动的配角,价值大概就是 +0.3 夏普,而且最可能的来源是那 1.5 个点的封板规避。**

## 5. 改进方向(落成 `studies/F102_kurt_autocorr/hypo.yaml`,34 条)

1. **先证伪自己**:整棵树是不是就等于 `day_zero_ratio(Ret)` / `day_flat_run_max(Close)`?两个方向的残差都跑(h_zero_* / h_res_zero60 / h_res_tree_on_zero)。
   若残差塌,结论就是「已知族 + 一个封板掩码」,这棵树可以退休。
2. **把 `cross_sum` 的缺失日缺陷修掉再谈其他**:`cross_mean` / `cross_ema(30, 60)` / `cross_decay_linear(60)` / `cross_tail_mean_q75`,
   并用 `cross_valid_count` 把停牌 / 次新显式剔除,量出科创板那 −28.5% 有多少是这一条。
3. **换掉脆的 3 分钟孔径**:`in_autocorr_s1`(严格日内,不跨日边界)和 `in_madz`(相对 EPS、尺度不变)是同一机制的稳健写法 —— 如果它们有窗口平台,
   原式的刀尖就只是估计噪声,不是信息。
4. **桶内做**:成交额桶、放量桶、历史长度桶内排名,保住流动性溢价的同时只用它在有信息的地方选股。
5. **当筛子而不是当因子**:用 `cs_first_high40` 把树标出的最「冻」40% 从已知族的多头书里剔掉,这是第 3 节(c)指向的唯一独家价值。
6. **新结构**:`day_centroid(Amt)`(封板票成交集中在开盘 —— 顺序信息,峰度 / 基尼都丢了)、`day_gini`、`day_signed_ratio(Ret, Amt)`。

**缺的算子**(见返回的 `new_operator_requests`):跨日边界的掩码、分钟级「连续为 0 的最长段」、二维分桶排名。

### 2. 定论(只凭 train / valid)

**自有最好的三个版本(不含已知族成分)**

1. `cross_max(pow_2(day_kurt(nt_ts_autocorr_s1(Ret, 3))), 60)`(`h_max60`)= +11.8 / +9.2 / **+11.3%**、夏普 2.82 / 2.79 / **2.85**、LTO **3.0%**、ρk 0.23、dist 0.98。
   相对原式:夏普 **+0.80**(远超噪声 0.3)、净超额 +2.4 点(噪声内)、换手 5.4%→3.0%。**夏普已超过 `k_known`(2.22)0.63**,净超额仍低 4 点。
2. `cs_first_low40(cross_sum(pow_2(day_kurt(nt_ts_autocorr_s1(Ret, 3))), 15), cross_valid_count(day_last(Close), 241))`(`seg_new_p`)= +11.4%、夏普 **2.67**、LTO 4.6% —— 原式加一道「永不买历史最短 40%」的筛子,次新段的坑直接清零(低配 −7.1 个点)。
3. `cross_mean(cross_mean(pow_2(day_kurt(nt_ts_autocorr_s1(Ret, 3))), 15), 60)`(`h_meanmean60`)= +11.7 / **+12.1** / +11.9%、夏普 2.52、LTO **2.4%** —— 两段净超额最均衡、换手最低的一支。

**建在已知族上最好的用法**

- `cs_last_high20(neg(cross_mean(day_std(Amt), 30)), cross_sum(pow_2(day_kurt(...)), 15))`(`scr_xhi_p`,剔除筛子)= +14.2 / +23.6 / **+16.9%**、夏普 2.57、LTO 3.2%;
- `cs_first_high40(cs_rank(cross_mean(day_std(Amt), 30)), cross_mean(pow_2(day_kurt(...)), 15))`(`h_sieve_known`)= +16.3%、夏普 **2.65**;
- `ov_p05`(权重 0.5 叠加)= +15.3%、夏普 2.62。

**比 `k_known` 强、比 `k_known_xfrozen` 弱,而且弱得超出噪声。** vs `k_known`(+15.4%/2.22):净超额 +0.9~+1.5 点(噪声内)、夏普 +0.35~0.43(刚过噪声)。
vs `k_known_xfrozen`(+18.5%/**3.15**):净超额低 **1.6~3.2 点**、夏普低 **0.50~0.58**。即:它想做的「封板规避」,用最朴素的冻结掩码当剔除器就能做得更好 —— 而那个掩码**自己做排序因子是废的**(−0.33、dist 0.06 ✗)。

**一句话**:把 `cross_sum(…,15)` 换成 `cross_max(…,60)` 让它从一条平庸因子变成一条夏普 2.85 / 换手 3.0% 的低换手小因子(提纯成立),但它在已知族之上的全部增量都被「已知族 + 冻结盘口剔除」这个通用筛子吃掉。

**完整判断**:**提纯成功、升华失败**。(i) 机制叙事(封板 / 冻结探测器)在算子层面成立(`var=0` → 相关恰好 0 → 超额峰度爆表),但八条语义替代全废、双向残差显示树严格包含掩码 —— 所以它是**一个不可替换的特定估计量**,不是「封板」这个语义。(ii) 作为独立因子它的夏普(2.85)已超过已知族(2.22)、ρk 仅 0.23、换手只有 3.0%,**可以当一条独立的低换手小因子持有**(代价:净超额 +11.3% 比已知族低 4 点,因为它不像已知族那样把 95% 的收益押在流动性倾斜上)。(iii) 作为已知族的配角 / 筛子它是**冗余的**:`k_known_xfrozen` 在净超额和夏普两个口径上都更好。(iv) 它**没有桶内选股力**(八条桶内 / 剔除变体全部不如全市场排名),收益 = 流动性倾斜 + 冻结规避,两件事都有更便宜的写法。
