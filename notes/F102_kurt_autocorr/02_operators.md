四个算子的内核都读过了(`study.sh src`;`_kurt` 和 `EPS` 不在注册表里,是 `x1_anatomy.py` 在服务器上用
`inspect.getsource` 打出来的)。下面只写**和名字不一样**、而且探针表里看不全的地方。

**1. `nt_ts_autocorr_s1(Ret, 3)` 不是"3 分钟自相关",是 4 个连续分钟收益上的 3 对 Pearson 相关。**
`ts_autocorr(x, d, 1)` = `ts_corr(x[1:], x[:-1], d)`,`ts_corr` 走 `rolling_pair_reduce(…, "corr")`:
窗口里是 (x_t, x_{t−1})、(x_{t−1}, x_{t−2})、(x_{t−2}, x_{t−3}) 三对。NT 面是**逐日**的 (分钟 × 股票) 面
(`apply_cube` 里 `for c in range(B)` 一天一张),所以窗口**不跨日**;每天开头用 NaN 左填充,`count.clamp(min=1)`:

- 第 0 分钟:NaN(`res[shift:]` 之前没有值);
- 第 1 分钟:只有 1 对,去均值后全 0 ⇒ `0 / (0 + EPS)` = **0**;
- 第 2 分钟:只有 2 对,两点连线 ⇒ 恰好 **±1**(任一侧不动则为 0);
- 第 3 分钟起才是 3 对。

**2. 三对的样本相关系数离"自相关"很远。** `iid_null_location`:iid 高斯输入下均值 **−0.295**、中位数 **−0.461**、
|r| > 0.9 的占 **18.7%**(同一个探针在窗口 60 上读出均值 −0.013、|r|>0.9 为 0,自检通过)。
也就是说,即使分钟收益完全没有自相关,A 也是一个在 [−1, 1] 上铺得很开、偏负、两端堆积的量。
它的日内分布形状主要由估计量本身决定,不由"这只股票的收益有没有自相关"决定。

**3. 分母是 `sqrt(var_x · var_y) + EPS`,EPS = 1e-9。两个后果:**

- **价格连续 4 分钟不动 ⇒ A 恰好等于 0**(`constant_input_value` = 0.0),不是 NaN。
  全 0 序列里放一次孤立的价格跳动(`impulse_in_zeros`):跳动后第 1、2 分钟 A = **−0.5**,其余仍是 0。
  所以对一只很少动的股票,A 的日内取值几乎只有 {0, −0.5} 两个点。
- **输出并不是零次齐次的**。内置的齐次度探针读出 k = 0,但它喂的是 O(1) 的数;分钟收益是 1e-4~1e-3,
  这时 `sqrt(var_x·var_y)` 本身只有 1e-9~1e-6。`eps_shrink_at_scale`(iid 输入缩到对应量级,输出 / O(1) 时的输出,中位数):
  1e-3 → 0.998,3e-4 → 0.974,1e-4 → **0.809**,3e-5 → **0.276**(自检:没有分母的 `nt_ts_rank` 四档全是 1.0)。
  真实数据上这件事有多大,见 `07x_1_anatomy.md` §3。

**4. `day_kurt` 是超额峰度(−3),对常数输入返回 NaN。**
`_kurt` = `nanmean((x−μ)⁴) / nanmean((x−μ)²)² − 3`,普通除法,0/0 = NaN。
所以**全天一字板 / 全天不动**的日子(A 全 0)K 是 NaN,不是"极大"。
而当输入大部分是同一个值、少数例外时,峰度量的不是"尾部形状",是**稀疏度**:
`two_point_response`(240 个 0 里放 k 个 1)读出 k=1 → 235.0、k=6 → 35.0、k=24 → 5.11、k=60 → −0.667、k=120 → −2.0,
和伯努利峰度的解析式 1/(w(1−w)) − 6 逐位相同(这是这个探针的自检)。

**5. `pow_2` 在这里不是保序变换。** `pow_(x, 2.0)`:指数 > 1 时就是 `x ** 2`,**不保号**(探针:保序 = False,取负 = even)。
K 有正有负,所以平方是一次折叠。实验室先验里"保序的外层一元变换是 no-op"那条把 `pow_2` 列在算子清单里,
它在 F001 上成立是因为那里的操作数恒正;在这棵树上不成立。

**6. `cross_sum` 用的是 `nansum_last`:NaN 当 0 加,整窗全 NaN 才返回 NaN。**
所以停牌日、一字板日对 15 日求和的贡献是 0 —— 和"当天 K 恰好为 0"的日子不可区分。
覆盖率因此接近 1(cov = 1.00)。
