- **常规风格量只把 R² 从 0.19 推到 0.29;把它推到 0.45、把多头腿削到三分之一的是封板代理。** 所以准确的说法不是"它是 60 日波动 / MAX 效应换了写法",
  而是"它的排序有一大块就是'近 60 日封没封过板'"—— 这是本研究自己的第 1 条结论(空头腿 = 封板事件)在 60 日窗口下的样子。

**§2 多头腿的归因:实际持有的那一档里,多少是"在哪个桶",多少是"桶里挑谁"。** 残差口径很严(残差的多头档已经不是原来那批票)。
这里换一个直接的口径:对因子实际的多头十分位,把每只票相对全市场等权的超额**恒等地**拆成
配置 =(它所在桶的等权 − 全市场等权)+ 选股 =(它 − 所在桶的等权)。毛、年化、逐日平均;两项相加等于合计(自检通过)。

- **推荐式的多头腿毛超额里,配置占 34% / 30%(严格的封板标记)到 44% / 40%(athi60 五分位),再配上一个风格量是 47% ~ 55%;选股是 +8.1% / +8.1%(配 athi60)、
  +6.4% ~ +7.4%(再配波动或换手)。** 审查从双重排序读出来的"约 45%"在实际持仓上成立。
- 它在桶里是怎么站的:多头十分位 85% / 93% 的票近 60 日没有封板日(全市场 59% / 69%;有封板日的那批票等权比全市场低 10.7% / 11.4% 每年);
  按 athi60 五分位,24% / 46% / 17% / 11% / **2%**(train)—— 它几乎不碰最高一桶(该桶等权 −18.8% / −15.6%),但**也不扎堆在最低一桶**(valid 上最低一桶等权是 −6.2%)。
- 换成别的桶:**60 日日频波动的配置也有 +5.8 / +5.3,和 athi60 差不多** —— 封板日本身就是最大的日波动,两种分桶在数据里分不开;
  日内波动 +2.8 / +4.0、换手率 +3.8 / +3.4、最大绝对日收益 +4.1 / +3.3、市值 +0.5 / +2.1 都小(成交额在 valid 上 +7.2,那是 2022–2023 低成交额票普涨)。
  所以配置这一块叫"避开近 60 日封过板的票"或"避开近 60 日日频波动最高的票"都可以,约占四成;它不是换手率或市值的配置。
  看不见封板日的那个版本(最后一行)对日频波动的配置仍有 +4.7 / +3.9:K 的水平自己就偏向低波动的票,这一块不全是事件。
- **原式也一样**:hl=1 时配置(athi60)+5.4 / +3.3,hl=5 时 +6.9 / +4.7。"避开近期封板票"不是 60 日版本带进来的新东西,原式的多头腿里本来就有三四成。
- **最后一行是直接的反事实**:把严格定义的封板日从 K 里拿掉再取 60 日极值(排序看不见封板事件),多头腿毛超额从 +14.6% / +13.4% 掉到 +9.6% / +10.3%,
  书上净超额从 +11.3% / +10.1% 掉到 +6.8% / +6.7%(逐日配对差 +4.5 / +3.5 个点,t = 4.9 / 3.2)。**多头腿有三分之一需要"看得见封板日"。**

- **train / valid 上,头条那 6 个点里 4 个点是"放慢"(换半衰期就拿得到),2 个点是结构(60 日极值),而且结构那 2 个点全在 train(逐年:2018 +0.5、2019 +2.9、2020 +2.9、2021 +5.0、2022 +0.0、2023 +0.7)。**
  这和原报告"大头是慢"一致。留出段上不是这个比例(见第 10 节:慢 3.2、结构 5.0)。
- **结构那一块是什么**:是更长的封板记忆。看不见封板日的 60 日极值不但没有增量,还比"原式 + 慢半衰期"**差** 1.7 / 3.2 个点(毛超额差 2.8 / 4.9,t = −2.0 / −2.6);
  在没有封板票的干净池内部,60 日极值相对原式@hl5 的增量是 +2.0%(t 1.1)/ −1.2%,分不出来。
  也就是说:**`max(K²,60)` 比"原式 + 慢半衰期"多出来的,是把"近 15 日封过板"换成了"近 60 日封过板"。**
- **提纯式配上长半衰期在 train / valid 上和推荐式打平**(`mean(|K|,15)`@hl10:+10.6% / +10.3%,配对差 +0.5%、t 0.5)。它在留出段上有读数(同一次读取的第二组数):+3.8%,推荐式 +7.4%。

- **两条多头书日序列的相关是 0.85**(审查估标准误时假设的是 0.6)。用法见第 10 节。

**顺带更正 x3 §3 的一个数**:那里写"干净池内部 `max(K²,60)` 的多头腿净超额 +5.7% / +8.8%"—— 那一行的半衰期是在干净池内部按多空夏普另选的 **hl=10**,不是推荐式实际用的 hl=0。
