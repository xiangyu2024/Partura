**§1 `cross_sum` 把缺失日当 0,这是一个真实的缺陷。** 15 日窗口里有效天数不足 15 的票(停牌复牌、全天一字板 K=NaN、刚上市)
占有标签格子的 5.2%(train)/ 1.9%(valid),其中 59% / 66% 窗口里有"全天价格没动"的日子。求和把这些天记成 0,
票被推向因子值低的一头(多头腿里占 5.0%),而它们在每一档里都大幅跑输:

| | D1(多头腿) | D5 | D10 |
|---|---|---|---|
| train 全部 | +12.7% | +6.0% | −41.0% |
| train 只留满 15 天的 | **+15.7%** | +6.4% | −31.4% |
| train 不满 15 天的 | **−44.7%** | −2.0% | −95.7% |
| valid 全部 | +14.7% | +2.3% | −33.6% |

| valid 不满 15 天的 | −57.8% | −38.1% | −112.6% |

把求和换成均值(缺失日跳过),别的不动:LS +3.62/+3.88 → +3.87/+4.33,多头腿净 +4.3%/+4.4% → +6.1%/+5.3%

**§2 主体(没有封板日、没有僵尸日的 78% 格子)里,K 的 15 日均值跟什么走。**

| 与主体里 K 的 15 日均值的 rank 相关 | |
|---|---|
| A 的日内偏度(15 日均值) | **+0.571** |
| A 的日内均值 | **−0.365** |
| \|A\|>0.99 的分钟占比 | +0.190 |
| 换手率 / 日内波动 / 成交额 | −0.153 / −0.145 / −0.097 |
| 全天 AR(1) 系数 / 符号自相关 | −0.097 / −0.084 |
| 活跃度 Z / W | +0.067 / +0.065 |

- A 自己的几个矩(均值、偏度、标准差、|A|>0.99 占比、Z)在秩空间张成主体 K 的 **R² = 0.748**,残差的 rank IC 只剩 +0.0011;
  全天的时序依赖(符号自相关、AR(1))只张成 0.081,活跃度 0.063,六个共享控制变量 0.107(残差 rank IC +0.0093,原来 +0.0173)。
- 所以主体里 K 低(差的一头)= **3 对局部相关的分布更对称、均值更高** —— 正的局部相关(连续几分钟同向)出现得更多;
  K 高(好的一头)= 分布挤在负的一侧(来回跳、孤立的单次跳动),偶尔才有正值。它是一个**等权的、与幅度无关的**局部形态统计量,
  这正是它和全天 AR(1) 系数(被少数大收益分钟主导)不相关的原因。
- 主体内部按带符号的 K 分十档是单调的:train −22.4% … +8.8% +9.2%,valid −10.6% … +5.5% +5.1%。**驼峰只在把事件日并进来之后才出现**
  (x1 §5),所以折叠的作用是"把事件日放到坏的一头",主体本身不需要折叠。
- 这几个描述量自己当因子都不如 K:`cross_mean(day_mean(A),15)` LS +2.62/+4.06、多头腿毛 +7.3%/+12.1%(S3 的 `r_meanA15` 复现);
  偏度 +1.69/−0.66(不稳)。K 是它们的一个特定混合,拆不成一个更简单的矩。

x2 在这里打印过一行"主体 K 的 rank IC:train +0.0173,valid +0.0000"。valid 的那个 0 在 x3 §4 里复查了(见 `07x_3_longleg.md`)。

**§3 聚合层的筛选**(半衰期在 train 上按多空夏普选;竖线后是同一个信号固定 hl=5):

| 聚合 | hl | 扣费 LS | 多头腿净 | 纯多头夏普 | 换手 | 固定 hl=5 的多头腿净 |

(x2 的"原式"一行是 numpy 重建的,和引擎的 `v_base` 差在第二位小数:+3.62 对 +3.68、多头腿净 +4.3% 对 +4.9%;
重建与引擎面板的 Spearman 是 1.00000,差别来自 0.2% 的 NaN 位置不同。下文凡是进结论的数字都取引擎口径。)

三件事:

1. **多头腿净超额的大头是"慢"**:原式什么都不改,只把半衰期从 1 换成 5,多头腿净超额就从 +4.3%/+4.4% 到 +8.0%/+9.8%。
   任何"升华"都要先扣掉这一块才算数。扣掉之后,`max(K²,60)` 在 train 上还多 3 个点(+11.1% 对 +8.0%)、在 valid 上持平(+9.5% 对 +9.8%)。
2. **折叠点放在 0 附近就行**:`mean(|K − c|,15)` 在 c = −0.15 / 0 / +0.15 上 LS 是 +4.11/+4.56、+4.06/+4.31、+4.01/+3.84;
   c = −0.30、−0.45(把折叠点移到 K 的截面中位数附近)多头腿净超额掉到 +3.6%/+2.9%、+0.2%/−1.1%。
   原式折在 0 不是巧合 —— 0 正好在主体的上沿和事件日之间。
3. **给事件日的幅度封顶没有用**:`mean(min(|K|,3),15)` LS +3.45/+3.60,不如不封顶;封到 1 就和中位数一样丢掉一半空头腿。
