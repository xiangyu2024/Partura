**已确立(每条后面是出处)**

1. **空头腿是近 15 日的涨停封板事件。** 最高一档里 66.9% / 60.5% 的票近 15 日封过涨停板,贡献该档负超额的 83% / 96%;把封板票从股票池拿掉,
   多空夏普 +3.68 / +3.88 → +2.08 / +1.26(x1 §6–§7)。封板日价格大半天不动 → A 恰好是 0 → 峰度变成稀疏度计 → K≫0(探针 `constant_input_value`、`two_point_response`)。
2. **`pow_2` 是折叠,而且是必需的;凸性无关。** 去掉折叠多头腿毛超额 −10.4% / −1.4%(`l_nofold_lin`);换成绝对值 rank 相关 0.99(`l_fold_lin`);
   折叠点移到 −0.30,多头腿净超额 +5.4% / +5.5% → +3.6% / +2.9%(x2 §3)。实验室里"保序外层变换是 no-op"那条先验在这里不适用,因为操作数有正有负。
3. **(修订)空头腿是已知暴露;整条因子对期限匹配的控制有三分之一到近一半被张成,张成它的主要是封板的朴素代理。**
   原来九个控制(全在 1 日 / 20 日期限上):原式 R² 0.219,推荐式 0.186。加上同期限的朴素量:原式 0.33 / 0.32(15 日)、推荐式 **0.45 / 0.46**(60 日),
   其中封板代理一个量单独 0.35 / 0.38,九个再加七个常规风格量(波动、MAX、振幅、换手、成交额)只到 0.29 / 0.26。残差的 rank IC 剩两到三成(推荐式 +0.0063 / +0.0038),
   残差的多头腿毛超额 +4.3% / +3.9%(推荐式)、+5.2% / +5.9%(原式)(`07_SR_horizon`、audit_1 §1、r1 §1;引擎口径与 numpy 口径一致)。
   原报告的"它不是已知暴露"只对九个短期限控制、只在 train 上成立,撤回。与 F001 家族的 rank 相关 0.24~0.27、与价格和市值 ≈ 0 这两点不变。
4. **"3 对"是核心,它不是自相关。** 自相关窗口 3 → 5 → 10 → 15,valid 多空夏普 +3.88 → +2.03 → +0.82 → +1.67(S2、`l_ac15`);
   全天 AR(1) 系数与带符号的 15 日 K 的 rank 相关 0.00,它自己被控制变量张成 R² 0.504(`r_ar1`);去掉自相关层是另一个因子(`l_noac`,rank 相关 −0.02)。
5. **`cross_sum` 把缺失日当 0 是缺陷。** 窗口里有效天数不足的票被推向多头腿,而它们在那一档里年化 −44.7% / −57.8%;换成均值,
   rank 相关 1.00,多头腿净超额 +4.9% / +4.5% → +6.3% / +5.2%(x2 §1、`a_mean_sq15`)。
6. **因子是两个独立成分之和,各自只在一段时期值钱。** ΣK² = 15·(均值² + 方差);水平与离散的 rank 相关 −0.02;
   水平 train 强 valid 塌(`a_level15`:多头腿净 +5.9% / +0.3%),离散反过来(`a_disp15`:多头腿毛 +1.3% / +10.5%);
   逐年 rank IC 水平 +0.029(2019)→ +0.001(2023),离散 +0.016(2018)→ +0.038(2023)(S3、x3 §4)。
7. **(修订)两条腿要的速度不同;把多头腿放慢 —— 不管是换半衰期还是把记忆写进表达式 —— 多头腿净超额都上升,留出段上也成立。**
   原式只把半衰期从 1 换成 5:train / valid +4.9% / +4.5% → +8.5% / +9.8%(逐日配对 t = 3.8 / 4.3),留出段 −0.7% → +2.5%。
   极值记忆 15 / 30 / 60(各自按多空夏普选的半衰期):train +6.6% / +8.5% / +11.3%,valid +6.2% / +8.0% / +10.1%,留出段 +0.2% / +4.9% / +7.4%;
   各自按纯多头夏普选的半衰期,留出段是 +4.4% / +7.6% / +7.0%。120 日不塌(+10.1% / +10.6%)(S1、S3、S_final 的两张表、r1 §3)。
   原报告这一条只写了前一种选法,并在第 10 节说"原式 + 慢半衰期在留出段上不知道"—— 那个数在 `final.json` 里,是 +2.5%。
8. **(修订)长记忆版本的多头腿不是"买冷门票";约四成是"避开近 60 日封过板 / 大波动的票",约六成是桶内选股。**
   在换手率的每个五分位内部各取多头十分位,超额都是正的且最高换手桶里最大(+31.8% / +33.3%)(x3 §5)。
   把实际持有的多头十分位的毛超额 +14.6% / +13.4% 恒等地拆开(r1 §2):按封板代理 athi60 的五分位,配置 +6.4% / +5.3%、选股 +8.1% / +8.1%;
   按严格的封板标记是 +4.9% / +4.0% 与 +9.6% / +9.4%;再配一个风格量(日内波动或换手率,25 格)选股剩 +6.4% ~ +7.4%。
   在没有封板、没有短历史的干净股票池内部,推荐式按它实际的 hl=0,多头腿净超额是 **+3.3% / +5.5%**
   (原报告写的 +5.7% / +8.8% 是在池子里另选了 hl=10 的数;r1 §3 更正)。原式的多头腿同样有三四成是配置(hl=1:+5.4% / +3.3%)。
9. **(新增)多头腿有三分之一需要排序"看得见封板日"。** 把严格定义的封板日从 K 里拿掉再取 60 日极值,多头腿毛超额 +14.3% / +12.7% → +9.8% / +9.2%,
   净 +11.3% / +10.1% → +6.8% / +6.7%(逐日配对差 +4.5 / +3.5 个点,t = 4.9 / 3.2)(r1 §2、§3)。
10. **(新增)留出段上,头条的 8.2 个点 = 放慢 3.2 + 60 日极值 5.0;train 上是 3.6 + 2.8,valid 上是 5.3 + 0.3。** 三段的比例不一样;
    "升华的大头是慢"只在 train / valid 上成立(`final.json` 的两组留出段数字、r1 §3)。

**合理但没有坐实**

- **(新增)`max(K²,60)` 比"原式 + 慢半衰期"多出来的那一块,是更长的封板记忆(60 日对 15 日)。** 证据都在 train / valid:看不见封板日的 60 日极值比原式@hl5 低 1.7 / 3.2 个点
  (毛超额低 2.8 / 4.9,t = −2.0 / −2.6);干净池内部 60 日极值相对原式@hl5 的增量是 +2.0%(t 1.1)/ −1.2%(t −0.7),分不出来。
  没有坐实的地方:干净池的检验功效不够(标准误 1.9 个点);留出段上那 5.0 个点是不是同一个来源,没法验证。
- **(降级,原来在"已确立"第 3 条里)多头腿里"桶内选股"那六成不是已知暴露。** 没有哪个朴素 60 日量能单独复现它(train 上最好的多头腿 +6.7%,推荐式 +14.3%),
  在 athi60 × 日内波动 / 换手率的 25 格内部还有 +6.4% ~ +7.4% 的毛超额;但按残差口径(十六七个控制一起回归)只剩 +4% 上下、rank IC +0.004 ~ +0.006,
  valid 上尤其弱。它是"可比的票里 K 靠近 0 且稳的更好",还是若干朴素量的非线性组合,这两种读法没有分开。
- **主体里 K 的水平量的是"分钟价格路径上短的同向连动多不多"。** 证据是间接的:K 低 ↔ A 的均值高(−0.37)、偏度低(+0.57),
  AR(1) 探针上 K 随 φ 单调下降。但没有直接去数 4 分钟形态的频率,全天的符号自相关与 K 只有 −0.08 的相关。
- **只在高换手的票上有预测力,是因为冷门票上 K 退化成了稀疏度。** 条件 IC 随换手率单调,且 Z<0.5 的格子上 K = 1.45/Z − 3 成立;
  但没有做"冷门票上换一个不退化的形态统计量是否恢复预测力"的实验。
- **封板票后面跌是彩票型 / 涨停追高的定价过高。** 这是文献里的常见解释,本研究没有区分它和别的解释(比如涨停次日买不进造成的标签选择;x1 §6 只排除了后者的大部分)。
- **水平那一半 2021 年起失效,是市场微观结构变了。** 只有时间上的吻合,没有机制证据。

**未决**

- **(修订)`f_max60` 相对"原式 + 慢半衰期"的增量在样本外有多可靠。** 现在有三个读数:train +2.8(t 2.3)、valid +0.3(t 0.2)、留出段 +5.0。
  留出段那个数的标准误取决于两条多头书日序列的相关:按 train / valid 实测的 0.85 是 1.9 个点(2.6σ),按审查假设的 0.6 是 3.0 个点(1.6σ);
  留出段上的相关量不到。它还是 10 个留出段数字里挑出来的一对。

- (新增)valid 上,哪怕只对原来九个控制中性化,推荐式残差的 rank IC 也只剩 +0.0051(未中性化 +0.0221)、无成本多空夏普 +0.88:
  2022–2023 这段它在控制变量之外的截面预测力已经很弱。留出段是不是接着这个状态,没有数。
