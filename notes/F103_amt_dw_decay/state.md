## 2. 结构事实(逐层按算子定义,不按名字;s1 + s2 的硬证据)

- **`ts_min(·,1)` 是恒等式**:`abl_E` 与 `v_base` 逐列相同、ρo 1.00。外层 `cross_max(·,5)` 近似恒等(`iso_F` +8.5%,`sub_G_*` 全在 +8.2~+8.4)。
- **`day_durbin_watson` 不是 DW**:分母 `Σx²` 不是 `Σ(x−x̄)²`。对正值序列 ≈ `var(Δx)/(mean²+var)` = **无尺度的尖峰占比**,恒 ≥ 0
  (`sub_D_abs_` 与 `abl_D` 逐列相同 = 证据)。记为 **C**。s2 已证明它只是**写错了的相对抖动**:换成 `day_std(in_pct(·,1))` 后 +0.88 夏普。
- **`cross_decay_linear(Amt,30)` 是跨日的**:对每个分钟槽做 30 日线性衰减均值 → 一条「平均日内成交曲线」(D×M),不是日内衰减。
- **C 腿完全价格盲**(s2 最干净的新事实):`h_C_leaf_vol`(只把 C 腿 Amt 换 Volume)与 `abl_D` **逐列相同**(+12.8% / 2.11 / ρo 0.66 / ρk 0.84)
  ⇒ s1 里 `leaf_Amt_vol` valid −7.4% 的死亡**全部来自 A 腿**。价格只从 A 槽进来。
- **承重的只有 A 槽的金额水平**:`iso_A = day_close(Amt)` 单独 +10.5/+20.8/**+13.4%** / 1.90(比原式好);C 腿单独 `iso_E`/`only_F_R` valid **−18.6/−17.8%**、ut Lshp 0.05/0.04。
  A 槽 close ↔ mean = sum ↔ quantile = median 全一样 ⇒ 要的是**水平**。`leaf_Amt_amtchg`(换成变化率)ut +0.2%;`rank_F`(两腿各自排名再相乘)ut −0.1% ⇒ 起作用的是重尾**量级**不是序。
- **B 槽的 30 日平滑不能删**:`abl_B` ut **−3.3% / −0.60**。但平滑方式有彩蛋:`cross_semistd_neg/pos` 版 ut 2.24 / 2.10 且 **ρk 0.65 / 0.59**(全表好变体里最低)。
- **指数阶梯 = 全表主轴,与 ρk 单调同向**:pow_05(ρk .90)+13.7% → pow_1(.84)+12.8% → pow_1.5(.73)+11.4% → pow_2(.59)+10.0% → pow_2.5(.46)+8.8% → pow_3(.34)+8.1%;
  train Lshp 走反方向(1.64→1.96)⇒ **pow_3 是拟合在 train 上的**。
- **形状层全部无用**:`rk` 7.6%、`win` 8.1%、`rel60` 0.7%、`fold_sq`/`fold_mean` −22.3/−25.6%、`mem_zscore5/10` 为负且换手 11~14%;
  `h_C_zs60`(C 去 60 日持久水平)ut **−11.3% / −1.78** ⇒ C 的价值是**持久的截面水平**,不是「相对自己异常」。

## 7. 可迁移的结论(写给别的因子)

- **「段内净超额」不是「在这段里建书能赚多少」**:F103 的 D 组七条全负、清淡半边反而优于流动半边,与解剖方向相反。解剖只能当线索,机制必须写成显式表达式再测。
- **二元状态量只能当筛子,不能当因子**:`h_frz_only` dist 0.06 ✗、`h_frzrun_only` 0.17 ✗、`h_age_only` 0.05 ✗,但同一个量套 `cs_last_high20` 之后值 +0.93 夏普。
- **筛子增量要用「同一道筛子加在两个载体上」判归因**:次新筛子对 K 和对原式各值 +0.29 / +0.30 ⇒ 与载体无关;冻结筛子各值 +0.93 / +0.15 ⇒ 原式已做掉大部分。
- **剔除型筛子之间通常不可加**:冻结 + 次新 = 3.16 ≈ 3.15。叠筛子之前先看两段的重叠。
- **`cs_bucket_rank` 会抹掉重尾量级**:凡是靠量级(而非序)吃饭的因子,桶内中性化要用 `cs_bucket_demean` / `cs_bucket_zscore`。
- **按名字读算子会读错**:`day_durbin_watson` 分母是 Σx²(尖峰占比,非 DW);`cross_*` 沿日轴、`cross_decay_linear` 不是日内衰减;`ts_min(·,1)` / 窗口 1 的滚动算子是恒等式。
