**一句话**:这棵树是「成交额水平 ×(最近 30 天平均日内成交曲线的集中度)^k」。成交额水平是已知家族;集中度这一支在已知暴露之外的成分**只在 2018–2020 年看得到**。
原式把八成权重押在集中度上:多空夏普不差,多头腿弱。多头腿能改善的部分,一块是把半衰期调慢,一块是把权重还给已知的成交额水平家族 —— 都不是集中度给的。

(本节在审查后修订过。原来的"已确立"第 1、5、8、10 条有改写或降级,新增了第 2、9 条;改动处标了"修订"。)

### 已确立(每条后面是实验)

1. **七个算子里三个可以删;删完多空更好,多头腿不因此变好。** `ts_min(·,1)` 是恒等(探针 `window_one_is_identity`;S1 `a_no_tsmin` 逐位相同)。
   `cross_max(·,5)` 只是低通(S1:删掉 +4.35 / +2.41、换成均值 +4.26 / +2.49,原式 +4.14 / +2.22),原因在 X3-H:书是对原始数值做 EMA 的,重尾的正数做 EMA 本身就是带衰减的峰值记忆 ——
   **所以它"多余"的前提是下游有半衰期 ≥ 5 的 EMA**:不平滑时 utrain 多空夏普 原式 +2.79、删掉它的 `A·C³` 是 −1.45(X4-A)。`day_close(Amt)`(收盘集合竞价那一根)换成全天成交额。
   三个一起删(`d_sum_k3`),**同一个半衰期(10)下**多空净收益比原式每年高 +3.1% / +5.4% / +3.8%(train / valid / utrain,配对 t +2.5 / +3.2 / +3.7,六年每年为正);
   多头腿净超额差 −0.6% / +2.8% / +0.4%(utrain t +0.3)(X4-B、X5-B)。**留出段多空夏普 +3.52,原式 +3.18(半衰期 2)/ +2.92(半衰期 10)。**
   (修订:原文写"换成全天成交额,多头腿两段都更好(+9.5% / +7.4% 对 +6.3% / +3.6%)",比的是半衰期 10 对半衰期 2;同半衰期下原式是 +9.4% / +4.5%,train 上没有差别。)
2. **原式的多头腿弱,有一部分只是半衰期选得太快。**(修订新增)按多空夏普选中的半衰期 2 只比 10 高 0.05(train)/ 0.14(utrain),多头腿却多付一倍换手(8.4% 对 3.6%)。
   只把半衰期换成 10、结构不动:utrain 多头腿净超额 +5.6% → +8.1%(日度配对差 +2.5% / 年,t +2.4),纯多头夏普 +1.11 → +1.49;留出段 +5.5% → +7.2%、+1.04 → +1.26;
   代价是多空夏普 +3.53 → +3.39、留出段 +3.18 → +2.92(X4、`final.json` 里按纯多头夏普选半衰期的那一行)。
3. **两条腿缺一不可,尺度也不能约掉。** 只留收盘竞价额 +1.81 / +3.69,只留粗糙度 +1.79 / **−1.75**(S1)。把 `A` 换成尺度无关的尾盘占比(`f_share`)−1.96,
   两支排名后相乘(`i_rankmul`,与成交额相关 0.04)−0.08:去掉成交额水平,剩下的在 valid 上不赚钱。
4. **`C` 是"先平均、再量粗糙度",这个顺序不能换。** 逐日独立的分钟噪声被 30 日平均压掉(探针 `noise_averaging_exponent`:DW ∝ N^−0.985),留下的是每天都出现在同一分钟的结构和大到平均不掉的尖峰。
   换成"先逐日算 DW、再平均"之后与 `C` 的相关只有 0.709、与成交额水平 −0.76,代进整树 +1.00 / +1.14(X1-6);用当日 DW 则方向都反(X2-e:−1.38 / −2.77)。窗口 10~60、线性衰减还是等权都是同一个平台(X2-e)。
5. **原式与成交额的相关只有 0.28,是因为 `C³` 把 `A` 的尺度约掉了一半多**(X1-4:`log C ~ log 成交额` 的斜率 −0.174,乘 3 是 −0.52)。所以"全部控制变量 R² 只有 0.227"不说明它新,
   只说明它把最大的已知暴露抵消了(中性化表)。
6. **交互是真的:集中度只在成交活跃的票里排得动。但那个角落不是集中度特有的。** `C` 的条件 rank IC 随成交额五分桶从 −0.0028 走到 −0.0611(S1)。5×5 依次分组里两段都深的只有一个角:
   成交最活跃、曲线又最集中的那 4% 股票,次日超额年化 −75% / −64%(用 `C`,X2-b)、−75% / −79%(用峰值占比,X3-F)。成交额低的那几行里,集中度的方向 train 和 valid 相反 —— 集中度对多头腿没有稳定贡献,这半句不变。
   (修订,降级:原文把这个角称为"集中度是一个避雷变量""这棵树最稳的发现"。替换实验说它是已知的"活跃 × 热门"效应,`C` 只是代理之一 ——
   同一行里按换手率取最高组是 −74.9% / −94.6%,日内波动 −72.0% / −91.2%,20 日动量 −64.3% / −90.3%,小市值 −67.0% / −76.2%,而且 2021–2023 年都比 `C` 稳(`C` 的组内 5 − 1 价差 2023 年是 +6.8,换手率是 −60.2);
   角落里 46% / 44% 是近 5 日涨停过的票,剔掉之后是 −34.8% / −17.7%;`C` 对全部已知暴露做组内秩残差后,组内 rank IC 是 −0.0230 / **+0.0057**,逐年 −0.023 / −0.030 / −0.028 / −0.011 / −0.002 / +0.018(X4-C)。
   当成剔除名单:全市场等权先剔掉"换手率角落 ∪ 近 5 日涨停票"(+6.7% / +5.9% 每年),再剔 `C` 角落只多 **+0.45%(train,t +4.8)/ +0.09%(valid,t +0.6)**(X5-D)。
   **`C` 特有的成分只在 2018–2020 年(GP 的样本内)存在,2021 年减半,2022–2023 年为零或反号。**)
7. **空头端是近期打过板的活跃票。** train 上空头十分位最近 5 日内有过涨停的比例 20.68%(多头十分位 1.37%),成交额 / 波动 / 动量的截面百分位都在 0.62~0.66(X1-8)。
   对全部控制变量中性化后空头腿从 +42.8% 掉到 +9.1%。空头腿没有被"封涨停买不进记 0"抬高:空头十分位的标签缺失率 1.25%,低于全市场的 1.54%(H8b 不成立)。
8. **多头腿的钱来自成交额水平这个已知家族;乘 `C` 不给多头腿加收益;而且大半是小市值倾斜。** 同一个半衰期(10)下 utrain 的多头腿净超额:纯 `day_sum` +13.9%,`day_sum·C` +14.9%,
   F001 蒸馏 +15.7%,F001 蒸馏 × `C` +15.6%,`day_sum·C²` +12.3%,`day_sum·C³` +8.4%,原式 +8.1%(X5-A)。日度配对差:`day_sum·C²` − `day_sum` 是 +1.1% / **−8.3%(t −3.1)** / −1.6%(X4-B);
   F001 蒸馏 × `C` − F001 蒸馏(同为半衰期 2)是 −1.1% / **−4.0%(t −2.8)** / −1.9%(t −2.1),半衰期 10 下是 +0.7% / −2.1% / −0.1%(X5-B)。
   成交额水平占比高的候选,多头十分位的市值百分位只有 0.19~0.31(原式 0.46 / 0.38);对市值做秩中性化后,`day_sum·C²` 的多头腿净超额从 +7.4% / +13.8% 掉到 +1.8% / +2.2%(X3-E);
   只对 `ctl_cap` 中性化,多头腿毛超额 +14.9% → +9.0%(中性化表)。对全部控制变量中性化后,`d_sum_k2` 的残差是各候选里最小的(rank IC 0.0123、无成本多空夏普 +1.81;原式 0.0172 / +2.83,`x_std9_k1` 0.0170 / +3.37)。
9. **`C` 给已知家族加的多空均值只在 2018–2020 年;两段都在的是波动降低。**(修订新增,替换原第 8 条"两条腿轮动")F001 蒸馏 × `C` − F001 蒸馏(同为半衰期 2)的多空净收益逐年
   +4.3% / +9.4% / +7.0% / −0.7% / −1.5% / −2.6%;`day_sum·C²` − `day_sum` 是 +10.2% / +18.0% / +15.2% / +4.0% / −1.1% / −4.6%(X4-E、X5-B)。这个增量与纯成交额水平收益的相关 −0.55,beta −0.15:
   乘 `C` 等于减掉一部分成交额水平暴露。对冲之后的 alpha:train +6.7% / 年(t +6.5),valid +1.9%(t +1.3)。书的年化波动 train 8.4% → 7.5%、valid 7.1% → 6.5%,单这一项给多空夏普 +0.28 / +0.38(X5-C)。
   valid(2022-01~2023-08)是成交额水平最强的一段(控制变量表),这一条不变。

### 合理但没坐实

- **经济解释**:平均日内成交曲线粗糙 / 集中、同时成交又很活跃的股票,是散户追逐的题材票,之后跑输。支持它的只有间接证据(空头端的涨停史、条件 IC 的方向);没有投资者结构的数据,不能排除别的解释。
  (修订:原文把"成交长期挤在开盘第一分钟(`day_argmax(B)` 68% / 87% 落在 9:31)"写成这棵树的描述。那是峰值占比 `p_peak` 的性质,不是原式里 `C = DW(B)` 的:
  `C` 与首根占比的 rank 相关只有 0.109、与头两根占比 0.131、与收盘竞价占比 0.422、与 `p_peak` 0.426,它 69% 被切掉首尾的内部 DW 张成(X1)。
  X2-e 里换成"收盘竞价占比"的版本(+3.51 / +3.91)也不输"头两根占比"的版本(+2.97 / +3.53)。`C` 里有预测力的更像是首尾几根和没被平均掉的尖峰(X3-D:纯内部的 DW 残差 rank IC −0.0086 对 `C` 的 −0.0253),不能说主要是 9:31。)
- **"集中度那条腿在 2024–2025 年回来了 / 两条腿轮动"**(修订:从"已确立"第 8 条降下来)。留出段多空夏普的排序是 `f_sum_k3` +3.52 > 原式 +3.18 ≈ `f_std9_k1` +3.14 ≈ `f_sum_k2` +3.10 > `f_stdamt9` +2.55,集中度权重越高越好。
  但 (a) train / valid 上 `C` 的增量是单调衰减,六年里只切换了一次,谈不上轮动;(b) `f_std9_k1` 比 `f_stdamt9` 高的 0.59 个夏普,拆开是多空年化 +24.5% → +25.7%、年化波动 9.62% → 8.19%:
  **只换波动 +0.44,均值 +0.15**(+1.2% / 年,按 utrain 上配对差的波动折算不到 1 个标准误;审查的估计是两个夏普之差本身的标准误约 0.3~0.4,+0.59 约 1.5 个标准误)。波动降低是 train / valid 上就有的效应;
  (c) 留出段没有放 `day_sum` 基准,也没有量成交额中性的集中度的 rank IC。竞争解释"乘 `C` 等于减掉一部分成交额水平暴露,在成交额水平 / 微盘股回撤的 2024 年机械地更好"没有被排除。
  这些数字都取自已经读过的 `final.json`,没有再读留出段。
- **乘 `C` 的版本留出段多头腿更稳**(多头腿最大回撤 `f_stdamt9` −15.4%、`f_std9_k1` −9.2%、`f_sum_k2` −5.2%;纯多头夏普 +0.89 / +1.55 / +2.07)。和上一条是同一件事:`C` 的权重越高,减掉的成交额水平 / 小市值暴露越多,
  2024 年那次回撤就越小。它是一次观测;train / valid 上对应的事实是波动低一成、多头腿均值不增。

### 未决

- **指数该取几,对多空夏普没有稳定答案。** k = 3 对 k = 2:train +3.93 对 +3.33,valid +2.88 对 +3.78,留出段 +3.52 对 +3.10 —— 三段里两段是 k = 3 好。S1 / X1 当时写的"指数 3 是 train 的局部最优、是在用 valid 换 train",
  留出段不支持(在多空夏普上)。多头腿则三段都是 k = 2 好或打平(同半衰期 10:+11.4% 对 +8.8%、+14.5% 对 +7.3%、留出段 +12.6% 对 +9.2%)—— 但这只是在说"成交额水平的权重越高,多头腿越好",k = 1、k = 0 更好。
- **集中度在已知暴露之外的成分,2023 年 8 月之后有没有恢复。** train / valid 上 2021 年起为零;留出段只有上面那次间接观测。要用新数据量,不能回头再读这段留出段。
- **多头腿是不是 alpha。** 市值中性之后只剩 +2% 左右(X3-E,train / valid);留出段的市值中性版本没有读。
- **DW 还是峰值占比**:train / valid 上分不出高下(S2),留出段没有放峰值占比的候选。
- **2018 年前 7 个半月的交易所倾斜**(沪市当时没有收盘集合竞价,`C` 的截面百分位沪 0.376 / 深 0.585,X2-c):交易所内部的预测力照样在(−0.0267 / −0.0415),但那段时间的数字混着一个版式伪影。
