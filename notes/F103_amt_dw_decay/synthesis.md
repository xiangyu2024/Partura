# F103_amt_dw_decay —— 批量扫描 s1 + 市场解剖的综合(主研,2026-10-05)

口径:只看多头腿扣 15bp 净超额(Lnet)与纯多头夏普(Lshp),半衰期按纯多头书选。噪声 ±3 个点 / ±0.3 夏普。
基准 `k_known = cross_mean(day_std(Amt), 30)`:tr/va/ut **+12.6% / +22.3% / +15.4%**,Lshp 1.78 / 3.46 / **2.22**,LTO 3.4%。
原式 `v_base`:**+9.4% / +4.5% / +8.1%**,Lshp 1.86 / 0.73 / **1.49**,LTO 4.0%,ρk +0.34,方向 sg = −1(做多低值)。

**一句话结论:这棵树的多头腿全部来自 `day_close(Amt)` 这个叶子,其余结构是净损害;表现是「还剩多少已知成交额族」的单调函数,
在已知族之外没有可交易的增量(`res_known` valid −2.1%、Lshp −0.27)。唯一值得带走的不是这条因子,是解剖挖出的两块没人用的钱:
冻结盘口段(占 6.5%、段等权超额 −67.4%)和次新段(占 7.1%、−28.7%)。**

## 1. 它是什么(逐层按算子定义写,不按名字)

```
cross_max( mul( day_close(Amt), ts_min( pow_3( day_durbin_watson( cross_decay_linear(Amt, 30) ) ), 1 ) ), 5 )
```

立方体是(股票,日 D,分钟 M)。`cross_*` 沿 **D 轴**逐分钟槽滚动,`day_*` 沿 **M 轴**折叠。自内向外:

1. `cross_decay_linear(Amt, 30)`:对**每一个分钟槽 m**,取近 30 个交易日该槽成交额的线性衰减加权均值 → 一条
   「30 日平均日内成交额曲线」(D×M)。**不是日内衰减**,这是全树最被名字误导的一层。
2. `day_durbin_watson(·)`:`Σ_t (x_t − x_{t−1})² / (Σ_t x_t² + 1e-8)`,行内常数时 NaN。
   **分母是 Σx² 而不是 Σ(x−x̄)²,所以这不是 Durbin–Watson 统计量**:标准 DW ∈ [0,4] 且与均值无关,这里对正值序列
   ≈ `var(Δx) / (mean² + var(x))` —— 一个**无尺度的「尖峰占比」读数**(曲线上有一根独立的尖峰 → 分子≈2×峰²、分母≈峰² → 值大;曲线平滑 → 值小)。
   它恒 ≥ 0:`sub_D_abs_`(外面套 abs\_)与 `abl_D`(删掉)**逐列完全相同**,这是表里的直接证据。
   与前期研究「C 九成是开盘第一分钟成交占比」一致。记这一层为 **C**。
3. `pow_3(·)` = `pow_(x, 3)`,e=3>1 走 `x**3` 分支(不保号,但 C ≥ 0 所以是单调的)。它不改变 C 自己的序,改的是 C 在乘法里的**权重曲线**。
4. `ts_min(·, 1)`:窗口 1 的滚动最小 = **恒等式**。`abl_E`(整层删掉)与 `v_base` 在每一列上逐位相同、ρo = 1.00。树里有一个纯摆设节点。
5. `mul(day_close(Amt), ·)`:`day_close` = `day_last` = 当天最后一个非 NaN 的分钟值 ⇒ **收盘那一分钟的成交额**(不是收盘价)。
6. `cross_max(·, 5)`:日轴 5 日滚动最大(此时 M 维已被折成 1)。对一个慢变量近似恒等。

**= 「近 5 日里 (收盘分钟成交额 × 30 日平均日内成交曲线的尖峰占比³) 的最大值」,做多它的低端。**

## 2. 预测力在哪

**承重的只有 `day_close(Amt)` 这个叶子。** `iso_A`(只留它)ut **+13.4% / 1.90**,比完整原式(+8.1% / 1.49)**更好**;
删掉它之后 C 腿单独跑是死的:`only_F_R` +7.6% / **−17.8%** / +0.4%(Lshp ut +0.04),`iso_E` +8.0% / **−18.6%** / +0.5%(+0.05)。
样本外 C 腿的多头腿**完全没有预测力**。

**指数阶梯 = 整张表的主轴,它与 ρk 单调同向**(「留下多少已知族」= 表现):

| 变体 | D 槽 | ut Lnet | ut Lshp | valid Lnet | ρk |
|---|---|---|---|---|---|
| `sub_D_pow_05` | C^0.5 | **+13.7%** | 2.08 | +19.9% | 0.90 |
| `abl_D` / `sub_D_abs_` | C^1 | +12.8% | **2.11** | +17.7% | 0.84 |
| `sub_D_pow_1_5` | C^1.5 | +11.4% | 2.09 | +13.3% | 0.73 |
| `sub_D_signedpower` | C^2 | +10.0% | 1.99 | +10.4% | 0.59 |
| `sub_D_pow_2_5` | C^2.5 | +8.8% | 1.74 | +7.4% | 0.46 |
| `v_base` | C^3 | +8.1% | 1.49 | **+4.5%** | 0.34 |

train 的 Lshp 走的是反方向(1.64 → 1.96),即 **pow_3 是拟合在 train 上的**:它买到 train 夏普、卖掉 valid。
压扁 C 的变换一律把因子推回已知族:`sub_D_sigmoid`(C≥0 ⇒ 挤进 [0.5,1))+12.9% / ρk 0.92;`sub_D_inv` +11.7% / 0.92。

**多余的节点**:`ts_min(·,1)`(恒等,见上);外层 `cross_max(·,5)` —— `iso_F`(删掉)ut +8.5% / 1.55,
`win_G_10/15` +8.5 / +8.4,`sub_G_{cross_sum, cross_decay_linear, cross_min, cross_quantile_q25}` 全在 +8.2~+8.4 / 1.54~1.55,
**整个 G 槽是自由参数**(只有 `cross_argmax/argmin` 会毁掉它,dist 0.00 ✗)。

**不能删的**:B 槽的 30 日平滑。`abl_B`(DW 直接作用在单日原始分钟曲线)ut **−3.3% / −0.60** —— 单日曲线的尖峰占比是噪声。
但平滑方式本身不敏感:`sub_B_cross_max` +8.1%、`win_B_60` +8.4%。

**叶子可互换性**:A 槽 `day_close` ↔ `day_mean` ↔ `day_sum`(后两者逐列相同,ut +10.0% / 1.99)↔ `day_quantile` = `day_median`(+10.0% / 1.94)
—— A 槽只需要「一个日成交额水平」,`day_close` 并不特殊。
**不可互换的**:`Amt → Volume`(`leaf_Amt_vol` valid **−7.4%**;`fld_Amt_Volume` −7.2%)—— 丢掉价格就死,说明这条腿是**金额水平(规模 / 流动性代理)**,不是「活跃度」;
`Amt → in_pct(Amt,1)`(`leaf_Amt_amtchg` ut +0.2%,方向翻转)—— 要的是**水平**不是变化率。
`rank_F`(两条腿各自 cs_rank 后再相乘)ut −0.1%:乘法里起作用的是 Amt 的**重尾量级**,不是它的序。

**形状层**:`rk`(cs_rank)7.6%、`win`(cs_winsor)8.1%、`rel60`(除以自身 60 日均)0.7%,`fold_sq` / `fold_mean`(截面 V 形折叠)−22.3% / −25.6%,
`mem_zscore5/10` 负且换手 11~14%。**没有一个形状变换帮得上忙。**

## 3. 在市场的哪儿、什么时候有效(解剖表)

**(a) 次新段是 C 唯一真正发力的地方,而且与指数单调同向。** 「上市不足 250 日」(占 7.1%,段等权超额 **−28.7%**)段内净超额:
`sub_D_pow_05` −2.7% < `abl_D` +4.1% < `sub_D_pow_1_5` +15.0% < `sub_D_signedpower` +19.1% < **`v_base` +25.3%**(`k_known` +8.6%)。
方向与全市场完全相反 —— 全市场里 pow_3 最差,次新段里 pow_3 最好。
**推断**:次新票第一年的日内成交曲线极端不稳(开盘巨量 + 一字板 + 炒作),尖峰占比在这群票里**有分散度也有含义**:
最尖的那批是被游资追的投机壳,跌得最多;sg = −1 正好躲开。在成熟票里这个量退化成「行业 / 市值的持久标签」,没有增量。
**可检验推论**:(i) C 的 rank IC 应集中在 `cross_valid_count(day_last(Close),241) < 241` 的子样本内;
(ii) 按上市年龄分桶中性化后,`v_base` 相对 `abl_D` 的优势应当消失(→ `h_base_bk_age` vs `h_abl_bk_age`);
(iii) 原式的书只在该段超配 +4.2pp,所以 +25.3% 被稀释到全市场几乎看不见 —— 这正是「段内很好但全市场没用」的标准形态。

**(b) 原式的选股力在流动的一半,而钱在清淡的一半。** 成交额(20 日)分档的段内净超额,`v_base`:
−6.4% / −2.0% / −0.1% / **+9.6% / +17.2%**(单调升);`k_known`:−4.1 / −5.3 / −8.2 / −5.2 / +2.5(**几乎处处为零**)。
但段等权超额是 +15.1 / +8.9 / +2.6 / −6.0 / **−17.8%**,所以 `k_known` 的 +15.4% 几乎全是**流动性倾斜**(它在最清淡档超配 **+80.3pp**、最小市值档 +30.8pp),
而 `v_base` 的书几乎不倾斜(+6.7pp / −13.2pp),**它的钱一半是倾斜、一半是流动半边的桶内分辨力**。
**推断**:成交额桶是按 20 日均分的,桶内挑「当前成交额最低」= 挑**近期缩量**的票;在流动票里缩量是真信息,在清淡票里日成交额是最小变动价位噪声,所以符号翻转。
**可检验推论**:把缩量显式写出来(`div(day_sum(Amt), cross_mean(day_sum(Amt),20))`)并限定到流动半边,应当复制出 +9.6/+17.2 这一段(→ `h_contract*`、`h_liq40_*`)。
反证:`bk_liq`(流动性桶内秩,带 pow_3)valid −1.4%、dist 0.20 ✗;`res_liq` valid −1.5% —— 带 pow_3 的版本做不到,指数 1 的桶内版还没测过。

**(c) 市值与板块**:市值分档段内 `v_base` 是平的(+7.9 / +2.9 / +1.7 / +7.5 / +5.8),`k_known` 单调降(+9.3 → **+0.7**)。
**大票那一端是原式唯一比已知族强的地方**(+5.8% 对 +0.7%),与 (b) 同源。板块上原式低配深主板 −15.9pp、超配科创板 +10.4pp,
而科创板是所有变体段内最差的板块(+6.4% / `k_known` +1.4%)—— 这是一个纯损失的倾斜。

**(d) 冻结盘口段:全表最大的一块没人用的钱。** 「近 15 日有冻结盘口(封板 / 停牌)」占 6.5%,段等权超额 **−67.4%**。
完全不碰这一段相对全市场等权约值 **+4%/年**。原式是全表低配最多的变体(−4.5pp)也是段内唯一不亏的(+0.5%,`k_known` −10.9%),
**C 腿有一部分就是在当冻结盘口的筛子**(尖峰占比对一字板敏感)。但它是顺带做到的、很弱;现在有 `day_zero_ratio / day_flat_run_max` 可以直接写。

**(e) 时间与状态:原式与已知族近乎反相。** 逐年 `v_base` +4.0 / +15.8 / +15.4 / +2.5 / +8.2 / −1.4,`k_known` +17.3 / +10.4 / +6.7 / +16.1 / +24.7 / +18.5
—— 原式的好年份(2019–2020,大票 / 成长主导)正是已知族的差年份,反之亦然。
原式还是唯一在**市场下跌**时更好的变体(+10.4% 对上涨 +6.4%;`k_known` 是 +6.0% 对 +23.0%),并偏好高波动(+10.3 / +5.9)、高截面离散(+10.0 / +6.3)。
**推断**:C 读的是投机热度的日内指纹,热度退潮(跌市 / 高波动)时它有用;而流动性溢价在涨市里兑现。这是**状态互补**,不是水平互补。

## 4. 相对已知成交额族有没有增量 —— 没有

- ρk 只有 +0.34,看起来很独立,但 **`res_known`(对 `cs_rank(k_known)` 取截面残差)valid −2.1%、Lshp −0.27、ut 0.89** ——
  正交于已知族的那一部分,样本外多头腿是负的。
- overlay 三档:`ov_p025` ut +14.3% / 2.22(ρk 0.98 = 就是 k_known)、`ov_p05` +13.6% / 2.22、`ov_p10` +12.5% / **2.25**。
  最好的一档夏普比 k_known 高 **+0.03**(噪声带 ±0.3 的十分之一),净超额低 **2.9 个点**,换手从 3.4% 翻到 **6.7%**。**不是增量。**
- 整张表没有任何一个变体的 ut Lnet 超过 k_known 的 +15.4%(最好的是 `sub_D_pow_05` +13.7%),也没有任何一个 ut Lshp 显著超过 2.22。
- 空头腿 tr/va:`v_base` +32.0% / +22.9%,`iso_E` +16.6% / −1.5% —— 原式多空夏普很高(4.14 / 2.22)但钱大半在空头腿,纯多头用不上。

**诚实结论:F103 = 「成交额水平族 × 一个在 train 上拟合的尖峰占比权重」。提纯的终点就是去掉权重,而去掉权重之后它就是已知族。**

## 5. 改进方向(→ `studies/F103_amt_dw_decay/hypo.yaml`,36 条)

1. **C 换成定义正确的读数**(A 组 10 条):相对抖动 `day_std(in_pct(·,1))`、峰值占比 `div(day_max, day_mean)`、一次方 gini、
   顺序信息 `day_centroid`、去掉持久水平的 `cross_zscore(C,60)`、叶子换 Ret / Volume、B 槽换 `cross_ema`、以及「先平滑再读形状 vs 先读形状再平滑」。
2. **把 C 用在它有效的地方**(B 组 6 条):上市年龄桶内中性化作为 (a) 的判据;`cross_valid_count` 做次新剔除器叠在 K 上。
3. **冻结盘口剔除器**(C 组 7 条):`day_zero_ratio(Ret)` / `day_flat_run_max(Ret)` + `cs_last_high20` 压到书底。**本批最可能直接超过 K 的一族。**
4. **流动半边 + 缩量**(D 组 7 条):把 (b) 的机制显式写成 `cs_first_high40` / `cs_bucket_rank`,并补上 `bk_liq` 漏掉的指数 1 版本。
5. **已知族自己的升级**(E 组 6 条):`cs_winsor + cross_ema`、`cross_tail_mean_q25/q75` 分离「哪条尾巴承重」,
   以及两条机制完全不同的低相关候选 `day_wmean(Ret, Amt)` / `day_signed_ratio(Ret, Amt)` 去占 (e) 里那个反相位置。
