### 一句话

这条因子是「成交额水平 × 近期放量事件」的一个绕了远路的写法:它用「一年水平量最近 5 天动了多少」去量近期放量,不分进入和滑出,
顺带掺进了周年回声、未满窗口放大、上市首日为 0 三个伪影。它的**空头腿和多空价差**被已知家族 `cross_max(day_std(Amt), d)` 包含;多头侧在信息上不完全被包含,但没有可交易的增量。
空头腿的钱是「高换手率的大成交额股票,加上刚放过量的股票」,多头腿的钱是「小市值里成交清淡、近期没有放量事件」的股票。
这一族的多头腿净超额取决于把换手压到多低,不取决于窗口取多长。

### 已确立(每条后面是能指到的实验)

1. **根节点 = 水平 × 事件,两半几乎不相关。** `D` 与 |`C` 的 5 日变化| 的 rank 相关 0.994;`D` 与水平 `C`、与相对变化 `D/C` 各 0.67,
   水平与相对变化之间 0.019(07x events 第 2 节)。
2. **水平那一半就是成交额水平。** `s1_level` 对 `ctl_amt` 中性化后残差 rank IC −0.0007(中性化表);它的朴素等价物 `s3_max241` 指标相同(S3)。
3. **(修订)事件那一半的信息在方向里:只有「进入」是空头信号,「滑出」(周年回声)是中性;回声是纯稀释。**
   去掉尺度、同一个 |`D/C`| 最高十分位里,`C` 上升的股票超额 −46.7% / −61.3%,`C` 下降的 +5.2% / +2.7%;`D/C` 的 rank IC 在 `C` 上升的股票里 −0.0405 / −0.0624,
   在 `C` 下降的股票里 −0.0135 / −0.0196(审查复核第 3 节)。原式空头十分位里滑出驱动的股票超额 −4.8% / −13.0%,对当天成交额配对后是 +2.3% / +6.2%(负的部分全是水平);
   进入驱动的配对后仍有 −18.7% / −24.4%(修订实验第 3 节)。剔掉滑出驱动的股票日,两条腿都变好(07x events 第 5 节)。
   原研究的「方向无信息」依据的是 `s1_signed` 多头腿为负,那是原始金额单位下的尺度效应(S1)。
4. **(修订)进入事件在每个事前水平上都有效,在事前成交清淡的小股票里最强。** 按滞后 10 天的 60 日成交额中位数分五桶,`D/C` 的桶内 rank IC 是 −0.0344 → −0.0169(训练)、
   −0.0459 → −0.0250(验证);按流通市值 −0.0371 → −0.0113、−0.0497 → −0.0219。进入事件的股票相对同桶同伴的年化超额,最清淡一桶 −95.6% / −90.0%,最大一桶 +0.1% / −20.7%;
   换成不带可买入过滤的标签是 −85.1% / −81.3% 与 +1.7% / −18.2%,梯度不变(修订实验第 4、6 节)。
   原研究的「只在大成交额股票里起作用」(桶内 IC −0.007 → −0.044)用的是当天成交额和 9 日峰值分桶,这两个变量含有事件本身:56% / 58% 的进入事件落在当天成交额最高的五分之一里。
5. **(修订,收窄)原式的空头腿与多空价差被已知家族包含。** 原式对 `known_stdamt_max9` 回归后残差无成本多空夏普 −0.55 / −0.02、空头腿毛超额 −5.1% / −9.6%,反过来还剩 +2.34 / +2.77;
   对 `max30` 回归后 +0.02 / +0.46,反过来 +1.56 / +2.01(07x events 第 6 节、07x longleg 第 1 节、审查复核第 4 节,两段)。
   删掉一年窗口(`s1_recent`)得到的就是已知家族(rank 相关 0.94),rank IC 更高(S1b)。**多头侧不在这一条里**,见下面「合理但没有坐实」第 1 条。
6. **`cross_max(·,3)` 和 `fangzheng` 里 mean / std 的区分都是多余的**;树内最小结构是 3 个算子的 `cross_stddev(cross_stddev(day_cov(Amt,Amt),241),5)`(S2),
   留出段上它的多空夏普是 +2.72 对原式的 +2.24(第 10 节)。
7. **三个伪影都量到了。** 未满窗口:次新股占截面 7%、占空头十分位 25% / 17%(07x events 第 3 节);上市首日为 0:每天约 3 只次新股被排进多头腿,
   拉低多头腿毛超额 2.3 / 1.9 个点,换成 |差分| 后训练段多头腿毛超额 +2.6 个点(S2 `s2_absdelta`);周年回声:见第 3 条。
8. **(修订)这一族的多头腿净超额是换手的函数,不是窗口的函数。** 原研究写的是「d=15~60 是平台、d=9 不在平台上」;那是因为所有成员的半衰期都被多空规则选成了 0。
   半衰期按纯多头夏普来定,d=9 / 15 / 20 / 30 / 60 的多头腿净超额是 13.7% / 13.9% / 13.6% / 14.5% / 13.5%(训练)和 22.2% / 22.1% / 21.6% / 22.3% / 20.4%(验证);
   半衰期网格上训练段多空日换手落在 2.3%~5.2% 的 21 个(d,hl)组合全部在 12.3%~14.5% / 20.4%~22.4%。`known9` 加 hl=5 的 EMA 与 `max30`(hl 0)逐项相同,
   两者 rank 相关 0.948 / 0.952、多头十分位重合 79% / 80%,回归残差「谁多一点」在两段上方向相反(审查复核第 1 节、修订实验第 1 节)。
   hl 0 口径下的多空夏普随 d 下降(d=9 / 15 / 20 / 30 / 60 / 120 / 241:+2.47 / +2.61 / +2.54 / +2.37 / +2.14 / +1.84 / +1.77,训练段)仍然成立。
   **这一条只用 train / valid 的证据**;留出段上三档的读法在下面「没有坐实」第 3 条。
9. **多头腿要的是「没放过量」,不只是「平时成交少」。** 60 日中位数的多头腿毛超额 +7.0% / +19.5%,60 日最大值 +15.9% / +22.3%(S4);
   |`D/C`| 在下半的「没有事件」的股票相对同一事前水平桶的同伴多挣 +0.8%~+8.3% / +8.3%~+10.1%(修订实验第 4 节;训练段最大的一桶只有 +0.8%)。
10. **日内成交额离散度比日成交额好。** 原式里换字段(S2 `s2_field_sum`)和已知家族里换字段(S4 `s4_summax30`)都变差,方向一致。
11. **空头腿跟着换手率走,多头腿在小市值那一侧。** 对 `ctl_turnrate` 中性化后空头腿毛超额掉到三分之一左右或更低、多头腿变大;
    对 `ctl_cap` 中性化后相反(中性化表,四个因子同一个形状);只留市值大的一半时,训练段这一族的多头腿只剩 +1.8%(07x longleg 第 4 节、审查复核第 2 节)。

### 合理但没有坐实

- **(修订,由「已确立」里拆出来)原式的多头侧有家族之外的信息,但没有可交易的增量。** 原式(和 `min3`)对家族成员回归后的残差 rank IC 在两段上都显著(t 3.2~10),
  残差多头腿毛超额 +1%~+6% / +8%~+12%;原研究把它判成「噪声」是只读了多空夏普(两条腿相抵)。但残差平滑、扣费之后训练段的多头腿净超额是 −1.5%~+1.8%,验证段 +0.5%~+10%;
  与家族成员等权秩平均,训练段比家族成员单独低 1.0~2.1 个点(六个组合无一例外),验证段 −0.6~+0.9(修订实验第 2 节)。旁证指向另一边:留出段上 `f_min3` 配 hl 10 的多头腿不输 `f_max30`(第 10 节)。
  「信息上不被包含」证据充分;「这部分信息值钱」只有验证段和留出段的间接支持,训练段不支持。
- **(修订,新增)同换手下,家族结构的多头腿比树内结构好 —— 只在样本内。** `min3` / 原式配 hl 10(换手 3.2%~3.3%)是 +11.1% / +19.1% 与 +9.3% / +18.2%,
  家族成员在同换手下是 +13.5%~+14.5% / +20.4%~+22.3%;只留成熟股票差距是 1.0~3.3 / 0.7~2.7 个点;同换手下只有 `max30` 持有的多头股票超额 +19.6% / +24.7%,只有 `min3` 持有的 +11.0% / +18.1%。
  但逐年看对 `min3` 的领先集中在 2018、2019 和 2023 上半年,2020~2022 是 0~1 个点;**留出段上没有复现**(`f_min3` hl 10:13.5%、纯多头夏普 1.74;`f_max30` hl 1:13.5%、1.47)。
- **(修订,由「已确立」降级)留出段上三个窗口的读法。** d=15 / 30 / 60 的多头腿净超额 +12.0% / +12.5% / +14.7%,都高于按多空规则定半衰期的原式(+8.9%),彼此相差不超过 2.7 个点;
  但最优档从样本内的 30 换成了 60(纯多头夏普 1.37 对 1.74,差 0.37 超过 ±0.3 的噪声带),配置里读前写下的判据「次序乱掉 → 平台只是样本内的」按字面已经触发(S_final 的修订段)。
  能说的只有:低换手的家族成员在留出段都比高换手的原式好;「d=30 最优」「平台」在样本外没有得到支持。
- **事件那一半对多头腿还有没有家族之外的增量。** `s4_pos`(hl 10)与 `max30`(hl 1)的秩平均,训练段纯多头夏普 +0.26、验证段 −0.20,方向相反。原研究的「升华只能在水平这一半里找」证据不足:
  家族成员本身就含着事件,事件单独当因子在同换手下的多头腿(+8.0% / +17.4%)与原式相当。
- **方差比标准差好**(`s2_field_std`):只有验证段支持。在已知家族里两者保序等价(max 与开平方可交换),这个问题只存在于原式这种带线性统计量的树里。
- **机制故事**:空头腿 = 放量 / 高换手之后的反转(关注度消退),在事前不活跃的小股票里最强;多头腿 = 流动性溢价里「无人问津」的那一段。实验只确认了暴露的形状,没有检验机制本身。

### 未决

- 同换手下家族成员和树内提纯版谁的多头腿更好:样本内家族领先 2~5 个点,留出段打平;原式配 hl 10 在留出段上没有读过(用户训练段上纯多头规则给原式选的是 hl 3,hl 3 / 5 / 10 的纯多头夏普是 1.964 / 1.958 / 1.959,几乎并列)。
- 多头腿在大市值股票里还有没有(训练段只留大市值一半时 +1.8%,验证段 +18.6%,两段不一致)。
- 这一族的多头腿在 2024 年明显变弱(逐年:多头腿净超额 +9.1%、纯多头夏普 +0.80),是小市值 / 低流动性溢价的制度性变化还是一次性冲击,这里分不出来。
- 最优的换手 / 半衰期 / 窗口不稳定(样本内 d=30 hl 0~1 最好,留出段 d=60 最好);长窗口上 max 与 mean 对多头腿孰优也没有定论(d=20、d=60 两处都是训练段 max 好、验证段 mean 好)。
- 可买入标签把各候选的空头腿和多空夏普抬高了多少:只知道被过滤的格子占 0.26% / 0.12%、次日平均收益 +5.5% / +4.7%,进入事件组的深度被抬高 2~11 个点;
  各候选的空头腿在不带过滤的标签下掉多少没有量到(`rev2` 在那之前被内存守卫中止)。
- 对因子池的增量:相对 F001 已有的 `cross_max(day_std(Amt), 9)`(加 EMA)为零,已经测了(第 8 条);相对池里别的成交额类结构没有测。
