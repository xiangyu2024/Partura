### 07x 审查复核:半衰期、上市天数、方向、包含关系(`studies/F105_std_fangzheng_covamt/audit_1.py`,审查员所写)

这一节不是原研究做的。两路独立审查里「机制与过拟合」那一路写了一个脚本去验四个原研究没有排除的解释,用 `study.sh exec` 跑(tag `audit1`,
日志 `logs/F105_std_fangzheng_covamt_audit1.log`;只用 train / valid,脚本里读不到留出段)。它没有建阶段、没有产出 JSON,所以结果放在这里而不是某个阶段下面。
脚本开头的自检与阶段表逐位相同(原式 hl 3:多空 +2.54 / +4.62、多头腿净超额 +8.2% / +20.7%;`max30` hl 0:+2.37 / +4.12、+13.6% / +22.2%)。
记号同前:`orig` = 原式,`min3` = 3 算子的树内提纯,`known9 / max15 / max30 / max60` = `cross_max(day_std(Amt), d)`,方向都是 −1;「成熟」= 有效观测 ≥ 247 天
(这个定义同时去掉了次新股和整个 2018 年 —— 样本头一年所有股票的一年窗口都没满)。

**(0) 语义。** `D` 在股票没有数据的格子上全是 NaN(0 个例外);`D` 恰好等于 0 的格子有 10,983 个(其中 9,466 个有标签)—— 这就是上市首日伪影的规模;
`max30` 没有恰为 0 的格子。多头十分位里没有标签(停牌或次日开盘封涨停,在多头书里当天记 0)的比例:原式 1.9% / 6.0%,`max30` 3.4% / 7.4%;
空头十分位里是 2.6% / 1.8% 对 0.8% / 0.5%。

| `known9` | **5** | +2.17 / +4.10 | **+13.7% / +22.2%** | +1.99 / +3.59 | 4.2% / 3.9% |

多头腿每年被成本吃掉 7.6 个点;把换手压下来它就在平台上。完整的网格在后面的修订实验一节。`max30` 对 `known9` 回归后的残差 rank IC 只有 0.0037(t 1.5)/ 0.0078(t 2.0)。
另一面:同样把换手压到 3% 出头,树内的两个版本(`min3`、`orig` 配 hl 10)在样本内仍然比 `max30` 低 2.5~4.3 / 3.1~4.0 个点。

- 去掉次新股和 2018 年之后,`max30` 对原式的多头腿优势在训练段从 5.4 个点缩到 4.2 个点(11.2% 对 7.0%),验证段从 1.5 个点缩到 0.3 个点(22.3% 对 22.0%)。训练段所有因子的多空夏普都掉了一截
  (原式 2.54 → 1.71,`max30` 2.37 → 1.61):2018 年和次新股贡献了训练段多空夏普的三分之一。
- **原研究留下的「`max30` 多头十分位里的次新股贡献没有单独量过」在这里量了**:验证段 `max30` 的多头十分位里次新股占 8.8%(每天 41 只),组内超额 +12.9%/年,低于成熟股票的 +26.9%,
  对多头腿毛超额的贡献是 +1.26 个点(共 25.5);只留成熟股票重建的书是 22.3%(全部股票 22.2%)。次新股不是它验证段业绩的来源。
  原式多头十分位里的次新股(0.8%,每天 3.6 只)组内超额 −226%/年,贡献 −1.84 个点 —— 上市首日伪影。
- 板块:验证段多头十分位里科创板占 14.9%(原式)/ 17.6%(`max30`)/ 19.9%(`max60`),它在有标签的截面里只占 7.4%;训练段没有这个偏(科创板 1.3%~3.5% 对截面 2.2%)。
- 市值两半:只留流通市值小的一半,`max30` / `max60` 的多头腿净超额 +13.4% / +13.2% 与 +15.4% / +14.4%,原式 +6.0% / +10.0%;只留大的一半,训练段 `max30` +1.8%、`max60` +2.4%、原式 +5.1%,
  验证段 +18.6% / +16.4% / +15.4%(与 07x longleg 第 4 节同一个结论)。

**(3) 事件的方向有没有信息。** 原研究的依据是 `s1_signed`(原始金额单位的带符号差分)多头腿为负。审查的反驳:原始金额单位下,成交额² 的尺度把大成交额股票同时推到两端,
多头腿为负是水平效应。去掉尺度(`D/C`)、只看成熟股票、在同一个 |`D/C`| 档位里按 `C` 的 5 日变化方向分开:

| \|`D/C`\| 档位 | `C` 上升(进入):每天只数 / 年化超额 train、valid / 成交额分位 | `C` 下降(滑出、回声) |
|---|---|---|
| 最高十分位 | 132、177 只 / **−46.7%、−61.3%** / 0.76、0.79 | 120、241 只 / **+5.2%、+2.7%** / 0.42、0.46 |
| 第 9 十分位 | −11.0%、−23.2% / 0.72、0.73 | +7.0%、+1.8% / 0.44、0.49 |
| 第 6~8 十分位 | −3.2%、−11.8% / 0.65、0.66 | +4.9%、−0.1% / 0.42、0.48 |
| 下半 | +6.6%、+10.3% / 0.49、0.50 | +9.8%、+11.0% / 0.35、0.40 |

`D/C` 的 rank IC:在 `C` 上升的股票里 −0.0405 / −0.0624,在 `C` 下降的股票里 −0.0135 / −0.0196;带符号的相对变化 −0.0323 / −0.0362,不带符号的 −0.0268 / −0.0363。
带符号相对变化的分位剖面(hl 0):最「升」的一档 −30.8% / −38.8%,最「降」的一档 +2.8% / +1.2%,中间 +5%~+15% —— 不单调:**进入是很深的空头信号,滑出是中性,不是利好**。
**「方向无信息」是错的**:事件这一半的信息全在方向里。同一张表还说明分桶是内生的:同一个最高十分位里,`C` 上升的股票当天成交额分位 0.76~0.79,`C` 下降的只有 0.42~0.46 ——
进入事件本身就是放量,它把股票送进了当天成交额的高分位(修订实验第 4 节用事前水平重做了条件 IC)。

只留成熟股票、hl 5 的不带符号 `D/C`:多头腿毛超额 +11.8% / +20.2%、净超额 +7.7% / +16.2%、纯多头夏普 +1.61 / +2.88;分位剖面训练段 −20.2% … +11.7%、验证段 −17.9% … +20.4%,
顶端三档是 +4.4% / +6.6% / +11.7% 和 +7.7% / +11.0% / +20.4%。同口径的原式(成熟、hl 3)是 +7.0% / +22.0%、+1.14 / +4.07。
**「事件那一半只有 Q1 深、其余九档近乎平、没有多头腿」只是训练段、而且是被 2018 年和次新股污染之后的读法。**

残差的无成本多空夏普 ≈ 0 **不是因为残差没有信息**,而是残差的多头侧为正、空头侧为负,两条腿互相抵消:残差 rank IC 在两段上 t 都大于 4,相当于原式 rank IC 的 24%~42%;

这部分多头侧的信息扣费之后还剩多少、和家族成员合起来有没有用,在修订实验第 2 节。
