## 3. 过程与逻辑

按算子源码逐层读:`day_cov(x,x)` ≡ **day_var**;`cross_fangzheng(X,241)` = mean+std = 年度上轨(**不是正规化**);
`ts_stddev(·,5)` 读"年度上轨上周动了多少"。整棵树 = 四重衰减的**成交额水平**读数,sg −1 → 买低流动性。
解剖:最低成交额桶超配 +55.2pp、段等权超额 +15.1%,而**段内**净超额 −4.7 / −2.9 / −0.0 / +4.2 / +1.2 → **钱全在段倾斜**
(k_known、iso_A 同);市值桶段内处处为正(+2.9 ~ +9.0)→ 小市值倾斜 + 同市值内选低换手。
真实身份:**一条披着流动性外衣的换手率水平因子**。

**结构缺陷(本研究最有价值的一条,s2 证实)**:损伤与"是否含 `ts_stddev(·,5)`"完全对应(s1 的 7 比 7 / 3 比 3)。
s2 用解剖的段内列做了直接检验:**次新段内 `iso_A` +6.1% vs `v_base` −23.2% = 29.3pp**,与第一轮预言的 ~30pp 一致 →
**机制成立**:次新 / 科创 / 封板段里"抖动大"恰恰是"正在被炒"的标志,抖动的排序方向与水平相反;
水平能活是因为它仍然在说"这只票有多大"。

**上一轮三条门控假设全是写法 bug,不是机制被否**(详见 §8 第一条):三条都漏了 `neg()` → 多头书**专门去买被筛掉的票**:
`h_gate_newlist` +1.1、`h_gate_frozen`(= `seg_xfrozen_p`)+1.7、`h_gate_both_atom` −4.4;正确写法 `seg_xfrozen_m` +13.3 / 2.75。
外加筛子变量退化:`cross_valid_count(·,241)` 93% 的票卡在 241(`h_count241_alone` dist 0.05 ✗),两条 `cs_first_low40`
分段假设的次新持仓因此是 **0** —— 根本没切进那一段。**第三批用 `cross_age` 把这组实验重做。**

## 8. 给接手者的提醒

- **先读 `synthesis.md` 第二轮一节(逐组对账表)+ `hypo3.yaml` 头部注释**;数字都带变体 id,不要重跑大表。
- **算子语义(两次踩到,最贵的一条)**:`cs_last_high20(y, x)` / `cs_first_low40(y, x)` 是**词典序**算子,把被标记的票压到
  y 排序的最后(或提到最前)。它们的效果因此**依赖 sg**:y 必须写成"越大越想买"(低为好就套 `neg()`),让 sg 定成 +1。
  写错方向的多头书会**专门去买被筛掉的票**。证据:同配方的 `seg_xfrozen_p`(sg −1)ut +1.7 / 0.24 vs
  `seg_xfrozen_m`(sg +1)ut +13.3 / 2.75。s2 里有 4 个变体名额被这个 bug 浪费。
- **`cross_valid_count(x, d)` 会饱和**:93% 的票卡在 d,dist 0.05,当筛子等于按并列随机切。上市时间一律用 **`cross_age`**。
- **解剖表"段内净超额"在持仓被清空的段里是垃圾读数**:筛子 / 分段变体把某段压到持仓 0 时该格是退化组合
  (`seg_xfrozen_m` 冻结段 **−153.6%**、`seg_new_p` 次新段 **−60.7%**)。判别:括号里超配 ≈ −(该段占比)即持仓 0,该格作废。
- 已修好:`cs_bucket_rank` 的 dist(s1 0.20 → s2 1.00),s2 的桶内结论可信。
- 仍然坏:**`cross_ema` 小 d 毁覆盖**(mem_ema5 cov 0.49 / valid −92.4%,mem_ema10 cov 0.90)。
- **立方体没有流通市值**,这是最大的一处手被绑住:全部分析指向"同规模内选低换手",而对成交额中性化的四行全是 +2.3 ~ +3.8%。
  第三批 B 组用**价格十分桶**替代(现有字段里唯一不由 Amt 构成的规模代理)。"加 FloatMV"仍是最高优先的数据请求。
- `ts_stddev` 与 `cross_stddev` 同一内核、逐位相同,只是窗口池不同(要 3 或 15 就写 `cross_*`)。
