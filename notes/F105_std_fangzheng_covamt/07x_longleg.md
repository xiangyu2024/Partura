### 07x 多头腿为什么变好、经不经得起几个检查(`studies/F105_std_fangzheng_covamt/longleg.py`)

S3 / S4 的阶段表说 `cross_max(day_std(Amt), d)` 在 d=15~60 上多头腿净超额比原式高 4~5 个点(训练段),验证段打平。
读留出段之前,用一个脚本直接量四件阶段表答不了的事(只用 train / valid;脚本开头先自检:它算出来的原式和 `max30` 两行与阶段表逐位相同)。
记号:`orig` = 原式(hl 3),`max15 / max30 / max60` = `cross_max(day_std(Amt), d)`(hl 0),`known9` = d=9,方向都是 −1。

**(1) 谁张成谁(train,实际交易的信号,秩空间逐日回归)。**

| | R² | 残差 rank IC | 残差无成本多空夏普 | 残差多头 / 空头毛超额 |
|---|---|---|---|---|
| `orig` 对 `max30` | 0.528 | 0.0157 | **+0.02** | +4.3% / −4.1% |
| `orig` 对 `max15` | 0.522 | 0.0102 | −0.57 | +2.1% / −5.8% |
| `max30` 对 `orig` | 0.527 | 0.0207 | **+1.56** | +9.7% / +3.6% |
| `max30` 对 `known9` | 0.719 | 0.0037 | +0.37 | +6.0% / −3.3% |
| `known9` 对 `max30` | 0.719 | 0.0283 | +1.88 | +7.0% / +7.7% |
| `max60` 对 `max30` | 0.767 | 0.0041 | −0.41 | +7.1% / −9.9% |
| `max30` 对 `max60` | 0.767 | 0.0247 | +1.87 | +12.4% / +0.9% |

原式对 `max30` 回归之后剩下的东西在多空上挣不到钱(无成本多空夏普 +0.02),反过来 `max30` 还剩 +1.56、多头腿毛超额 +9.7%。
(修订)「挣不到钱」只是多空口径:残差的多头侧是 +4.3%、空头侧 −4.1%,两条腿相抵;残差 rank IC 0.0157 的 t 值是 8.9。多头侧扣费后的情况见修订实验第 2 节。
族内是嵌套的:短窗口成员包含长窗口成员的全部信息(`max30` 对 `known9` 残差 rank IC 0.0037),多出来的那部分(`known9` 对 `max30`:0.0283 / +1.88)
是近期放量,多头 / 空头各 7 个点,换手 15.4%。原研究由此推出「这部分信息在多头腿上不够付成本,所以多头腿的最优点在更慢的成员上」。
(修订)后半句不对:多头腿的最优点在**更低的换手**上,不在更慢的窗口上。`known9` 加 hl=5 的 EMA 与 `max30` 在 train / valid 上逐项相同
(+13.7% / +22.2% 对 +13.6% / +22.2%),两者平滑到同样换手之后 rank 相关 0.95(修订实验第 1 节)。

**(2) 两个多头十分位只有一半重合,差别在不重合的那一半。**

| 多头十分位里的 | 每天只数 train / valid | 平均超额 train / valid | 成交额分位 | 流通市值分位 |
|---|---|---|---|---|
| 两边都持有 | 176 / 208 | +18.3% / +31.0% | 0.11 / 0.10 | 0.30 / 0.24 |
| 只有原式持有 | 178 / 245 | **+8.9%** / +24.4% | 0.23 / 0.23 | 0.38 / 0.36 |
| 只有 `max30` 持有 | 179 / 245 | **+18.3%** / +23.5% | 0.13 / 0.12 | 0.28 / 0.24 |

原式的多头十分位有 49.8% / 45.9% 在 `max30` 的多头十分位里(90.5% / 89.5% 在它的前三个十分位里)。
训练段的差别全部来自不重合的那一半:原式独有的股票成交额分位 0.23、超额 +8.9%;`max30` 独有的成交额分位 0.13、超额 +18.3%。
原式因为掺了「一年窗口这周动没动」的噪声,把一半的多头名额给了成交额没那么低的股票。验证段两边独有的股票挣得一样多(+24.4% 对 +23.5%)。
两个十分位的日留存率是 93.1% / 91.3%(原式)对 94.4% / 93.6%(`max30`)。
(验证段 `max30` 独有的股票里 14.2% 是上市不满 247 天的次新股,原式独有的只有 1.3%:原式的未满窗口放大把次新股挡在了多头腿外面,
`max30` 没有这道挡板,成交清淡的次新股会进它的多头腿 —— 见风险一节。)
