# F105_std_fangzheng_covamt —— 主研综合(批量扫描 s1,89 个变体 + 市场解剖)

口径:多头腿扣 15bp 净超额 Lnet / 纯多头夏普 Lshp,半衰期按纯多头书选。噪声 ±3 个点 / ±0.3 夏普。
基准 k_known = `cross_mean(day_std(Amt), 30)`,train/valid/utrain = +12.6% / +22.3% / +15.4%,Lshp +2.22。
原式 v_base = +9.3% / +18.2% / +11.8%,Lshp +1.96。**原式在两段、两条腿上都输给已知族。**

## 1. 它是什么(按函数定义逐层)

| 层 | 表达式 | 函数定义实际算什么 |
|---|---|---|
| A | `day_cov(Amt, Amt)` | 同一个参数喂进二元协方差:`Σ(Amt−mean)²/count`(除 count,总体口径,count<2 为 NaN)=**当日分钟成交额的方差**。库里本来就有 `day_var`,它 = `day_std(Amt)²`。名字里的 "cov" 是自协方差,没有任何跨变量信息 |
| B | `cross_max(A, 3)` | 日轴近 3 个交易日取最大(`rolling_windows` 左侧补 NaN,早期用现有的天数) |
| C | `cross_fangzheng(B, 241)` | 定义是 `cross_mean(B,241) + cross_stddev(B,241)` —— **近一年的均值 + 近一年的标准差**,即一条年度上轨(布林上轨),**不是**名字可能暗示的"正规化/标准化"。正数重尾序列的年度 std 与年内最大值同阶,所以 C ≈ 由**过去一年成交额方差最大的那几天**主导 |
| D | `ts_stddev(C, 5)` | 近 5 日滚动标准差(与 `cross_stddev` 同一个内核、逐位相同,见 playbook)。C 变得极慢(日增量 ≈ (B[t]−B[t−241])/241),所以根读的是"**过去一周里这条年度上轨动了多少**",是 \|ΔB\| 的四重衰减版 |

一句话:**一条绕了四层的成交额水平读数。** 方向 sg = −1 → 多头书买低端 = 低成交额 / 低流动性 / 小市值 / 低价股。

名字与定义不一致的两处:(甲) `day_cov(x, x)` ≡ `day_var(x)`,"协方差"是假的;(乙) `cross_fangzheng`
是"均值 + 标准差"的上轨,不是正规化 —— 它不去尺度,反而把尺度放大了一倍。

## 2. 预测力在哪

**承重(一换就塌)只有两件事。**

- **Amt 必须以水平进来。** 去掉水平的三族全死:`rel60`(除自身 60 日均值)+5.3% / ρo 0.36 / ρk 0.19;
  `mem_zscore` 5/10/30/60 = −4.5 / −3.0 / −2.1 / −0.1%;`leaf_Amt_amtchg`(叶子换成 `in_pct(Amt,1)`
  这个无尺度的分钟变化率)**−0.1% utrain、sg 翻成 +1**。用户提示的「Ret ↔ 量变化率可互换」这条,
  在这棵树上是**反例**:它要的不是日内动态,只是尺度。
- **根必须是幅度型归约。** `ts_stddev` +11.8 ≈ `ts_var` +12.0(单调孪生,ρo 0.99);换成有号 / 形状型全死:
  `ts_delta` −9.1%、`ts_argmax` −1.7(dist ✗)、`ts_kurt` −14.9(cov 0.39 ✗)、`ts_hurst` −17.6、
  `ts_pearson` / `ts_spearman` ≈ 0。

**多余(删了反而更好)—— isolate 阶梯全程单调下坡:**
`iso_A` day_cov 单独 **+17.8% / 2.59**(全表第一)→ `iso_B` 加 cross_max3 **+17.2 / 2.52** →
`iso_C` 再加 fangzheng241 **+12.3 / 1.98** → `v_base` 再加 ts_stddev5 **+11.8 / 1.96**。

- `cross_max(·,3)` 多余:`abl_B` 删掉它 **+13.2 / 2.15**(比原式 +1.4)。槽内所有保尺度的替代都落在 ±1:
  cross_sum 12.8 / fangzheng 12.4 / decay_linear 12.6 / q75 12.4 / q25 11.8 / med 11.1 / min 11.1;
  只有返回"下标"的 argmax / argmin 把它打死(−8.3 / −4.4)。**这个节点是自由参数。**
- `cross_fangzheng(·,241)` 多余:`abl_C` 删掉 **+13.9 / 2.13**(+2.1)。而 `sub_C_cross_mean` +12.3 ≈ 原式
  → 方正里 `+cross_stddev` 那一半**一点贡献都没有**。
- 根 `ts_stddev(·,5)` 多余:`iso_C`(留下全部下层、只删根)+12.3 / 1.98,LTO 从 3.6% 降到 **1.4%**。
  根只贡献换手。
- `cs_winsor` 是 no-op(+11.9 / 1.97)→ 书顶不是由重尾驱动的。

**叶子可互换性:不可换。** `Amt` → `Volume`(`leaf_Amt_vol`)+6.9% utrain、valid 只 +3.8%;
`day_cov(Volume, Amt)`(`fld_Amt_Volume`)+9.9%,正好在中间。Amt = 价 × 量,**价这一维贡献了约一半的多头腿**
(对应解剖里价格最低 20% 超配 +13.6pp、该段等权超额 +7.0%)。

**窗口:三个窗口都没有平台,因为窗口不重要。** win_D(根 5/10/20)= 11.8 / 11.6 / 12.0;
win_B(3/5/10)= 11.8 / 11.1 / 10.9;win_C(241/60/30)= 11.8 / 11.4 / **12.5**(30 最好,ρk 从 0.72 升到 0.83
—— 越短越像已知族、也越好)。全部在噪声内 —— 这是纯水平代理的签名:窗口只决定平滑强度。
真正的杠杆还是半衰期:`memory` 一族把 hlL 从 10 压到 1 并自带平滑,最好的 `mem_max30` +12.8 / 2.17(+1,噪声内);
`cross_min` 那一支(mem_min5/10/30/60 = +6.9 / +5.5 / −1.0 / −3.4)崩掉,因为取最小值会把承载排序的水平尖峰扔掉。

## 3. 在市场的哪儿、什么时候有效

### 钱全在"段倾斜",不在段内选股

成交额(20 日)五分桶:多头书在最低桶**超配 +55.2pp**;该段等权超额 **+15.1%/年**,最高桶 **−17.8%/年**。
而**段内**净超额 = −4.7% / −2.9% / −0.0% / +4.2% / +1.2%(低桶是负的)。
k_known 完全一样(−4.1 / −5.3 / −8.2 / −5.2 / +2.5,超配 +80.3pp),iso_A 也一样。
→ **+11.8% 全部来自"买低成交额这一段",段内排序是负贡献。整个成交额族共享这一点。**

流通市值五分桶的段内却**处处为正**(+5.4 / +4.8 / +9.0 / +5.0 / +2.9),超配 +15.4pp → −17.7pp。
所以是**两个效应叠在一起**:(i) 小市值倾斜;(ii) 同市值内选低换手(同样市值下 Amt 还随换手变化)。
(ii) 是唯一真实的段内能力,每个市值桶里值 +3 ~ +9%/年。
**诚实的读法:这是一条披着流动性水平外衣的换手率水平因子。** 要中性化的对象是市值而不是成交额 ——
而立方体没有流通市值(见 §5 算子请求)。对成交额中性化的四行全是零:`res_liq` +3.8 / 0.85、
`bk_liq` +3.0 / 0.64(dist 0.20 ✗)、`res_known` +2.3 / 0.51、`bk_known` +2.4 / 0.50(dist 0.20 ✗)。

### 结构在"没有一年历史"的股票上崩掉 —— 罪魁是根,不是 241 窗口

板块:深主板段内 +16.0(iso_A +22.5)、沪主板 +11.6、创业板 +12.1、**科创板 −15.7%**(iso_A +4.9、k_known +1.4)。
上市不足 250 日(占 7.1%,段等权超额 −28.7%):**v_base −23.2%**,而 k_known +8.6%、iso_A +6.1% —— **差 30pp**。
近 15 日有冻结盘口(占 6.5%,段等权超额 −67.4%):v_base −11.5%,iso_A +10.4% —— 差 22pp。

十个被解剖的变体里,这三段的损伤与**表达式里是否含 `ts_stddev(·,5)`** 完全对应:
含它的 [0] −23.2/−15.7、[4] −18.9/−11.7、[5] −19.7/−5.2、[6] −15.9/−16.4、[7] −13.5/−22.2、
[8] −20.4/−14.8、[9] −24.5/−10.2(7 比 7);不含它的 [1] +8.6/+1.4、[2] +6.1/+4.9、[3] +6.1/+6.9(3 比 3)。
**不是 241 窗口的锅**:`abl_C` 根本没有 241 窗口,科创板却最差(−22.2%)。

**推断的原因。** `ts_stddev(X,5)` 量的是日间**抖动**。次新股(注意力阶段的放量缩量)、科创板(20cm 涨跌幅 + 薄流通盘)、
刚封板或停过牌的票(零成交日与巨量日交替),它们的日成交额方差序列本身就是抖的 → 抖动大 → sg = −1 把它们压到书底。
但在次新 / 封板这两段里,**抖动大恰恰是"正在被炒"的标志**(A 股短期会延续),抖动小是"已经凉透还在继续凉"。
所以**在这两段里抖动的排序方向与水平相反**,而水平(iso_A)排得对。水平能活是因为它仍然主要在说"这只票有多大";
抖动只是一个把噪声放大的导数。
次要机制(解剖分不开,但一致):`rolling_windows` 左侧补 NaN、`nanmean/nanstd` 用现有的点,所以一只只有 k < 241
个有效日的票,年度上轨是用 k 个点估的,**每天都因为重新估计而跳**,而根量的正是这种跳。win_C_30(+12.5,
C 梯子里最好)和 abl_C(+13.9)都与"窗口越短 / 没有越好"一致。

**可检验推论(已写成假设):**(a) 用 `cross_valid_count(day_last(Close), 241)` 把短历史的票剔出去,
应当找回 7.1% × 30pp ≈ **+1.5 ~ +2.5 个点**(h_gate_newlist);如果一点不涨,机制说法就错了。
(b) 同一个剔除器加在 **iso_A 上**应当几乎不涨(h_gate_both_on_atom)—— 这是 (a) 的对照组;若也涨同样多,
说明剔除器只是个小盘筛子,我的机制故事不成立。(c) 在次新那一段**内部**建书:按 iso_A 排(h_newlist_tilt_atom)
应当显著好过按抖动树排(h_churn_in_newlist),差距约等于 30pp 的段内落差 —— 这是方向反转的直接检验。

### 时间:状态依赖属于小盘/流动性溢价,不属于这条因子

年:2018 +13.6 / 2019 +6.1 / 2020 **+3.2** / 2021 +9.7 / 2022 **+26.1** / 2023 +11.9。
市场近 20 日上涨 +18.0 vs 下跌 +4.2;高波动 +15.7 vs 低波动 +8.0;高离散 +15.5 vs 低离散 +8.2;放量 +16.5 vs 缩量 +7.9。
但 **k_known 的形状一模一样**(2020 +6.7 / 2022 +24.7;涨 +23.0 vs 跌 +6.0;高波 +18.5 vs 低波 +12.4;
放量 +19.9 vs 缩量 +11.8),其余八个变体也一样。2020 是核心资产年(大盘流动性好的票领涨),2022 是微盘年。
→ **这里没有 F105 专属的择时可挖**,所以这一批**不提市场状态门控**;把轮次花在状态变量上会是凑数。

## 4. 相对已知成交额族的增量:零

- ρk(v_base) = +0.72,而 v_base(+11.8 / 1.96)在 train、valid、两条腿上全面输给 k_known(+15.4 / 2.22)。
- 正交部分没有价值:`res_known` +2.3% / Lshp 0.51;`bk_known` +2.4% / 0.50(dist 0.20 ✗)。
- 叠加也不行:`ov_p025` +15.0 / 2.20、`ov_p05` +14.6 / 2.18、`ov_p10` +14.5 / 2.19,**全部 ≤ k_known 单独的 +15.4 / 2.22**;
  负权重更差(`ov_m025` +10.3、`ov_m05` +5.9、`ov_m10` −4.5)。**没有任何混合权重能改进已知族。**

**结论:F105 就是已知成交额族,而且是它被四层包装削弱后的一个读法。按选拔口径应当否掉。**
全表里唯一值得记下来的是 `iso_A = day_cov(Amt, Amt)` ≡ `day_var(Amt)` = `day_std(Amt)²`:
+15.6 / +23.3 / **+17.8%**,Lshp **+2.59**,LTO 3.8% —— 全表最好,比 k_known 高 2.4 点(在 ±3 噪声内,不构成改进),
**但 ρk = 0.97,就是同一条因子换了个写法**(一个节点 vs 30 天平滑),所以也不是候选。

唯一"钱不在空头腿"的一行:`sub_D_ts_autocorr_s1` —— +11.3 / +13.4 / +12.0%,Lshp **+2.46**,LTO 9.6%,
空头腿只 **+11.7 / +13.2**(原式 +23.6 / +28.5),ρk 0.63,**但 dist 0.46 ✗**。
按定义 `ts_autocorr_s1(X,5)` 是 5 日窗内的一阶自相关;X 是近单调的年度上轨,取值堆在 +1 → 离散度塌(dist 0.46)。
它实际分辨的是"**过去一周这条年度上轨有没有转向**",sg = +1 → 买没有转向的 —— 一个停滞/单调性探测器,不是水平,
这正是它空头腿小的原因。它没过门槛,不是候选,但是全表唯一的新线索,值一组假设(§F)。

## 5. 改进方向(落成 studies/F105_std_fangzheng_covamt/hypo.yaml,34 条)

A 钉死原子(4):day_var / day_std / log / 变异系数,确认"名字是假协方差"且分清水平与尖峰记忆。
B 最小修补(5):根降到窗口 3;把方正换成 q75 / 尾部均值(估计churn 更小、意图更直白)、以及两条尾巴的比值(无尺度)。
C 承重的否定测试(3):`in_logchg` 替 `in_pct`(排除 in_pct 不对称这个替代解释)、`day_var(Ret)`、`day_var(Close)`
(把 Amt = 价 × 量 里的价这一维单独拎出来)。
D 补 §3 的洞(6):`cross_valid_count` / `day_zero_ratio` 做剔除器与段内倾斜,含对照组。
E 段内到底有没有东西(6):`day_gini` / `day_centroid` / `day_signed_ratio` / `day_flat_run_max` 做桶内排名,
并用 `cs_first_low40` 做不受 `cs_bucket_rank` 离散度问题影响的孪生。
F 救活 autocorr 那条线索(5):换一个不那么平滑的内层、加水平 tie-break 把 dist 补上、以及把同一读法搬到 log 成交额和日内波动上。
G 大胆换原子(5):`day_gini` / `day_centroid` / `day_wmean(Ret, Amt)` / `in_madz` —— 都是无尺度的日内形状,
直接检验"日内成交额的形状里到底有没有信息"。预期多数会死(rel60 / mem_zscore 已经预言),但这是最便宜的决定性检验。
