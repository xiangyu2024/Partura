多头腿要的是「没爆过量」还是「平时成交少」?原式的「事件」那一半写干净之后有没有多头腿?

每个成员都按纯多头规则定半衰期时,d=9、15、20、30、60 是 +13.7% / +13.9% / +13.6% / +14.5% / +13.5%(训练)和 +22.2% / +22.1% / +21.6% / +22.3% / +20.4%(验证)。
所以这一节测到的不是「更慢的窗口更好」,而是「**这一族任何成员,只要把多空日换手压到 3%~5%,多头腿净超额都在 12%~14% / 21%~22%**」——
加长窗口和加 EMA 是达到同一换手的两种办法,样本内分不出高下(审查复核第 1 节、修订实验第 1 节)。d=30 之所以在 hl 0 的口径下「最高」,只是它不加平滑时的换手(4.0%)正好落在最好的区间里。

**(2) 聚合方式:多头腿要的是「没爆过量」,不是「平时成交少」。**
`s4_med60`(60 日中位数,完全不看放量日):rank IC 0.0209 / 0.0416,多空 +1.11 / +3.02,多头腿毛超额 **+7.0%** / +19.5%、净超额 +5.8% / +18.5%;
同一窗口的最大值 `s3_max60` 是 +15.9% / +22.3% 和 +13.5% / +20.4%。训练段多头腿毛超额差 **8.9 个点**,验证段差 2.8 个点,同向。
**H6 的「低成交额 ∩ 没有事件」得到支持**:只知道一只股票平时成交少,多头腿只有一半;还要知道它这两个月没有过放量日。
均值介于两者之间:`s4_mean20` 多头腿净超额 +11.9% / +22.0%(`s3_max20` +12.6% / +20.9%),多空 +1.93 / +4.00(+2.54 / +4.35)——
均值里也含放量日,所以多头腿与极值打平(d=20、d=60 两个窗口上都是训练段极值略好、验证段均值略好),但空头腿和多空夏普极值在两段上都更好。

**(3) 字段:日内离散度有贡献。** `s4_summax30`(日成交额的 30 日最大值)多空 +1.54 / +3.63、多头腿净超额 +10.1% / +22.2%、纯多头夏普 +1.40 / +3.53;
`s4_max30`(日内成交额标准差)是 +2.37 / +4.12、+13.6% / +22.2%、+2.03 / +3.69。训练段多空差 0.83、多头腿净超额差 3.5 个点,验证段多空差 0.49、多头腿持平。
与 S2 里原式换字段的结果(`s2_field_sum` 变差)同向,也与 F001 的先验一致:一天里成交额集中在少数几分钟的「放量」,比全天均匀放大的成交额更是坏消息。

**(4) 「事件」那一半写干净之后(原结论是「也没有多头腿」;修订见本点末尾)。** `s4_pos` = 最近 5 天峰值 / 一年峰值(无尺度):rank IC 0.0341 / 0.0528,多空 +2.02 / +3.20,
多头腿毛超额 +11.9% / +19.7%、**净超额 +4.6% / +12.8%**(日换手 11.8%),多头占比 26%。分位剖面和 `s1_relchg` 是同一个形状:
训练段 Q1 **−35.0%**,Q2 只有 −3.3%,Q3..Q10 从 −0.6% 缓慢升到 +12.3%。「成交量创一年新高」是一个很强的卖出信号,
「成交量远低于一年高点」几乎不是买入信号。它与原式的 rank 相关只有 0.18(原式的「事件」里一半是回声和未满窗口),与 `ctl_mom20` 0.37 ——
写干净之后它更像「近期涨过、放过量」的动量/关注度反转。原研究在这里下的结论是「升华只能在水平这一半里找,而水平这一半就是已知家族」。

**(修订)这个结论的两个前提都要改,结论降级为未坐实。**
(a)「没有多头腿」一半是半衰期造成的:`s4_pos` 被多空规则选成 hl 1、换手 11.8%;按纯多头规则是 hl 10,多头腿净超额 **+8.0% / +17.4%**、纯多头夏普 +1.53 / +3.27、换手 4.7%,
与同换手的原式(hl 10:+9.3% / +18.2%)差不多。分位剖面(hl 5)的顶端也不是平的:训练段 Q8..Q10 +6.6% / +9.0% / +11.4%,验证段 +7.4% / +14.2% / +21.2%。
(b)「水平这一半就是已知家族」不对:已知家族 `cross_max(day_std(Amt), d)` 本身就是「水平 + 近 d 天有没有放量」,它已经含着事件;
多头腿需要事件这一半(本节第 2 点:60 日中位数的多头腿只有 60 日最大值的一半;修订实验第 4 节:没有事件的股票相对同水平的同伴多挣 4~10 个点)。
(c) 直接实验:`s4_pos`(hl 10)与 `max30`(hl 1)做秩平均,训练段纯多头夏普 +2.41 对 +2.15、净超额 +14.9% 对 +14.5%,验证段 +3.46 对 +3.66、+20.2% 对 +22.3% —— 两段方向相反。
能说的是:**没有证据表明在家族成员之上再加一份事件信息能抬高多头腿**(家族已经用掉了);说不了「事件这一半对多头腿没用」。
