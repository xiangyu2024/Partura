## 机制诊断

口径:`Ln` 多头腿净超额(扣 15bp/边)· `Lshp` 纯多头夏普 · `Lg` 多头腿毛超额 · `LTO` 多头日换手 · `LS` 扣费多空夏普。
数字按 **train / valid / utrain / holdout** 四段写(缺的段说明没测)。方向与半衰期只在 fit 段定,`rank_by: long`。
出处:`[R1]` `results/R1.md`(numpy 解剖)· `[R2]` `results/R2.md`(引擎实测)· `[R3]` `results/R3.md`(留出段)·
`[05]` `05_hypotheses.md`(三轮裁决全文)· `[07x1]` `07x_01_x1_anatomy.md` · `[07S1]` `07_S1_long.md` · `[07x2]` `07x_02_x2_GHI.md`。

**一句话诊断**:这棵树里**真正带信息的只有两样东西** —— 日内开盘→收盘收益 `D`,和「把它按当天自己的幅度凸化、再做 20 日
盒式平均」这个形状。整条成交量跳变事件机器(`log(Volume)` 的 ±1σ 掩码 + `in_sustain_stddev` + `day_mean` + `abs_`)
**是纯损失**:拿它当权重比干脆不乘权重还差。原式对只能做多的用户是零,是因为它的钱全在空头腿,而多头腿的那点毛超额
正好被 10.6% 的日换手吃掉。

## 一、已确立(有实验、有独立签名、三段或四段一致)

**1. 原式对只能做多的用户是零。** `[R2][R3]`
`Ln` = **−0.0% / −0.6% / −0.2% / −0.8%**,`Lshp` = −0.00 / −0.10 / −0.03 / −0.07;
八年逐年 `Ln` 只有 2019(+6.5%)和 2022(+3.2%)为正,两个纯 holdout 年份 2024 −0.2%、2025 −2.1%。
`[R3]` 四段无一为正 ⇒ 这是本研究最硬的一条结论,**留出段按判据 J1 确认**。

**2. 钱在空头腿,而且是拿不到的那种。** `[07x1][R3]`
原式空头腿毛超额 +43.3% / +46.8% / +44.3% / **+44.9%**,`LS` +2.77 / +2.74 / +2.76 / +2.08;
多头腿只占毛价差的 16% / 14%。空头信息住在 **lag 1~3 天**(`sh` lag0 +43.7% → lag5 +6.0%)⇒ 是快反转,
**只能靠卖出兑现**,A 股纯多头拿不到。

**3. hl20 就是原式的最优点;「半衰期越长越好」那条曲线 100% 是成本的功劳。** `[R1 D段][05 H9 被否定]`
原式 hl 5~120 整张网格 train `Ln` 最高只有 +1.2%(hl30),全在 hl20 的 ±3 点噪声带内。
机制签名:hl20 往后 `Lg` 从 +8.0% 掉到 +0.6%、`LTO` 从 10.6% 掉到 2.7% —— **毛超额掉得和换手省的一样快**。
⇒ 基线里「hl 0→20 每翻倍 +6~8 点」是**纯省成本**,不是信号变好。这条挡住了「延长半衰期就能救原式」这条路。

**4. 成交量跳变事件机器是纯损失(本研究最反直觉的一条)。** `[R2 Q2][05 H2 已改写][07S1 §1]`
同窗口 20、同 hl20,四种权重的 `Ln`:
`S`(原式权重)**+4.2% / +5.7%** < **无权重** +5.2% / +7.3% < `day_std(Ret)` +7.5% / +9.5% ≈ `|D|` +7.9% / +8.1%。
**原式的权重比干脆不乘权重还差 1.0 / 1.6 点**,跨度 3.7 / 3.8 点、两段同向、超噪声带。
⇒ 正确读法:**「乘上当天自己的波动尺度」是带信息的结构;「用成交量跳变事件去估那个尺度」是纯损失。**
配套证据:`rank corr(S, day_std(Ret))` 只有 **+0.422**,而 `M~σ +0.870`、`Q~σ +0.823`、`M~Q +0.923`
⇒ `M` 与 `Q` 是同一个量(当天 5 分钟 std)的两个高度相关的估计,`S = |M−Q|` 的截面变异**主要是估计噪声**
(`(M−Q)/mean` 中位只有 +0.107)。`[07x1 B段]`

**5. 改进分两半,两半都是真的,各有独立的 `Lg`/`LTO` 签名。** `[R2][R3 J3][07S1 §2]`

| 这一步(都在 hl20、窗口 20) | `Ln` train/valid/**holdout** | `Lg` 变化 | `LTO` | 机制 |
|---|---|---|---|---|
| 原式 → `f_cmT20`(只把盒式平滑写进表达式) | +4.2 / +6.3 / **+5.08** 点 | 基本不变(−1.2 / +0.8 / **−0.35**) | 10.6%→3.4%(ho 10.31%→3.13%) | **纯省成本(平滑)** |
| `f_cmT20` → `f_cvxD20`(权重 `S` 换 `\|D\|`) | +3.7 / +2.4 / **+8.55** 点 | **真变高**(+3.8 / +2.4 / **+8.68**) | 3.4%→3.6%(ho 3.13%→3.31%) | **真 alpha(结构)** |

两步都在同一个半衰期、`LTO` 只差 0.2 点 ⇒ 第二步**不可能**是「更长的有效平滑」伪装的。
**措辞纪律**:训练段是 4.2+3.7 / 6.3+2.4(大致一半一半),留出段是 5.08+8.55(**37% 平滑 / 63% 结构**)
⇒ 报告写「两半都是真的、两半的相对大小随段变化」,**不要再写「一半一半」**。

**6. 整棵树没有任何日轴算子 ⇒ 平滑不是装饰,是这条因子能不能交易的另一半。** `[01][02][03]`
裸 `T` 日换手 **85%**,`Ln` −62.3%(hl0);必须靠口径里的 EMA 或写进表达式的 `cross_mean` 才能交易。
`cross_mean` 相对长 EMA 的优势**纯粹是换手**(H16 坐实)。

**7. `abs_` 是一次真的折叠,不是 no-op。** `[07x1 B段][R1 C段][05 H3 被否定]`
`M < Q` 占 **16.69% / 13.53%**(事前杀死判据是 >15%);去掉 `abs_` 的 `c5 D·(M−Q)` `Ln` −2.2% / −4.4%,比原式差。
⇒ `S` 量的是「两侧差多少」,不是「放量侧多出多少」。**折叠型因子的对照组也折叠过了**(`c6 D·|D|` 对 `c1 D`)。

**8. 凸化(带符号的平方)有用,不是普通日内反转的另一种写法。** `[R1 C段][R2][05 H4 坐实]`
`c1 D` 单独 `LS +2.06/+2.55` 明显弱于 `c6 D·|D|` `+2.87/+3.04`;丢掉幅度只留符号的 `c7 sign(D)·S` 塌到
`LS +1.79/+2.06`、`Ln −5.4%/−6.5%` ⇒ 起作用的是 `|D|` 的**幅度**,`T ≈ sign(D)·D²`。
长平滑下仍占优(上表第二行:换手不变、毛超额真变高)。

**9. 它不是任何单一已知暴露换了个写法。** `[R2 Q4][05 H17 被否定][R3 corr_with]`
`rank corr(w_cmD20, w_cmDcc20) = +0.669`(判据 >0.9 才算「就是 20 日反转」);
`f_cvxD20` 与 `ctl_rev1` **+0.027**、与 `ctl_mom20` **−0.223**、与 `ctl_turnrate` −0.342、与 `ctl_dvol20` −0.446、
与 `ctl_cap` **−0.013**、与 `f_known30` +0.392 ⇒ 没有一个单项控制超过 0.45。**不是教科书 20 日反转、不是规模、不是换手率。**

**10. 砍掉最近 10 天是纯损失 ⇒ 多头腿要的不是「等几天」,是「把 20 天平均起来」。** `[R2 Q3][05 H15 被否定]`
`w_cmD20lag10` 比 `w_cmD20` 的 `Lg` 低 1.6 / 2.0 点,而 `LTO` **完全相同(3.6% = 3.6%)**。
从另一侧印证:`decay` rank IC 从 h1 **+0.0291** 单调升到 h20 **+0.0888** ⇒ 本质是慢信号,被 h=1 的标签低估。
(这也推翻了 R1 lag profile 读出的「多头信息住在 lag 20~40」—— 那是单 lag 读数的噪声,train 与 valid 本来就不同向。)

**11. 升华版的多头腿在留出段上站住了。** `[R3 J2]`
`f_cvxD20` holdout `Ln` **+12.8%**(门槛 +4.9%)、`Lshp` **+1.17**(门槛 +1.02),两条都过。
四段 `Ln` +7.9 / +8.1 / +8.0 / +12.8%,`Lshp` +1.32 / +1.38 / +1.34 / +1.17。
**但**:留出段变好的是**水平**(`Lg` 也从 +10.6% 抬到 +15.3%),**风险调整后没有变好**(`Lshp` 1.34→1.17)。
⇒ 正确表述:「留出段净超额更高、夏普与训练段持平(略低)」,**不是「它在留出段上更好」**。

**12. 留出段的口径是干净的。** `[R3 J0/J6]`
`f_known30` holdout +14.1% / +1.51 **正好落在用户给的参照 +13%~+15% / 1.4~1.9 里**;
7 项 canary 全过(含 `corr(f_orig, v_base) = 1.000`);5 条候选 `cov` 全 0.9997、`dist` 全 ≥0.97;
R2 的 canary 也全过(`w_cmD20` 实测 +5.2/+7.3 vs numpy 预测 +4.9/+7.4,两个 rank corr 吻合到小数点后三位)
⇒ **R1 的 numpy 读数与 R2/R3 的引擎读数是同一把尺子**,全研究的数字可以互相引用。

## 二、合理但未坐实(证据同向但不够硬,报告里要带「未坐实」字样)

**A. 机制是「按当天自己的波动尺度给日加权」,而不是 `|D|` 这一个特定写法。** `[R3 J4][05 H4]`
**判据 J4 没有给出裁决**:|`f_cvxD20` − `f_cmDsig20`| = **3.35 点**,过关线 ≤3.0、否定线 >6.0,**两条线都没碰到**。
同向证据:两条 holdout `Lshp` 只差 +0.19(1.175 vs 0.986,噪声带内)、train rank corr +0.899、**四段 `Ln` 全部 ≥ +7.5%**。
反向证据:**两条的排序在段之间翻了**(valid 上 `cmDsig20` 更高,holdout 上 `cvxD20` 更高)。
⇒ 「用当天波动尺度加权」保持**未坐实**;「`|D|` 比 `day_std(Ret)` 更好」**不成立**(段相关,见 `11_risks.md` R3)。

**B. 「只取日内那一段」是真增量。** `[R2 Q4][05 H5]`
收盘到收盘版 `w_cmDcc20` train 低 4.1 点(+1.1% vs +5.2%,超噪声带)、valid 只低 1.2 点(带内)⇒ **两段不同向**。
隔夜版 `c11 Don·S` 方向翻成 +1、`Ln −14.7%/−15.8%` ⇒ 隔夜是反方向,这一侧是硬的。
⇒ 「日内 vs 收盘到收盘」这个差**不能当卖点写**;「日内与隔夜方向相反」可以写。

**C. 多头端的分位剖面不单调。** `[R1 E段][R3 profile][05 H6 削弱]`
`f_cvxD20` 的 Q10 − avg(Q7..Q9) = **+4.2 点(train)/ −1.0 点(valid)** —— train 顶档不再回落、valid 仍回落;
对照 `f_known30` 是 +7.3 / +11.4 点(**两段都强单调**)。**JSON 里没有 holdout 的 profile**(`results.<id>.profile`
只有 `train`/`valid` 两个 key)⇒ 这一条在留出段上**没法验**。
⇒ 意味着:顶档选票的边际信息弱于已知家族,排序能力主要来自中段。进 `11_risks.md`。

## 三、未决(本研究没有量,或量了但判据没落地)

**i. 相对已知家族的增量,在包含留出段的数据上是什么样?** —— 全研究最大的一个未决。
训练段的答案是明确的「没有增量」(30 个组合 valid 无一超过 known 单独、残差毛超额只有 +1.1~+1.6%、
组合夏普算术显示 partner 需要 `Lshp` 2.9~3.0)`[R2 Q5][07x2]`。
但留出段按设计**只读了 5 本书、一个组合都没读**,而留出段上两条**净超额几乎打平**(−1.26 点)且
**时间分布近乎互补**(2024 候选 +18.8% vs known +9.2%;2025 +12.0% vs +14.3%;推算 2023 后段 96 天 ≈0% vs ≈+26%)
⇒ 训练段那个结论**没有被推翻,但它的前提(两条水平差 5~14 点)在留出段上不成立**。`[R3 J5]`
**这是 `12_next.md` 的第一条。** 本研究不能在留出段上重开组合实验(只许读一次,已读)。

**ii. 窗口 20 是尖峰还是平台?**(H18)`w_cmD60` train 拟合到 hl5 给 +6.8%,带到 valid 只剩 +3.6%(`Lshp` +0.99→+0.44)
⇒ 窗口邻域**不稳**,但只测了 20 和 60 两点,中间(30/40)没测。明确决定不做,理由见 `state.md` 第 6 节。

**iii. 更长的平滑能不能把那 +8% 再抬高?**(H19)三个最好的变体半衰期**全顶在网格上限 20**,
固定半衰期表 hl10→hl20 还在升(`f_cvxD20` +6.1%→+7.9%)⇒ 真正的最优点**可能在网格外**。未测。

**iv. 容量下限在哪里?** 条件 IC `w_cmD20 | ctl_cap` 五档 +0.0378 → **+0.0117**(小票强、大票几乎没有),
但没有按市值分组算过**净超额**,也没有算过冲击成本 ⇒ 知道有容量问题,不知道有多大。进 `11_risks.md`。

**v. 空头腿会不会被「买不进的票」抬高?**(H7)`[07x1 B段]` 标签 NaN 占比 buyable 0.3190 vs raw 0.3172,
只差 0.002,**不像有大块封板被吞掉**;但没做过「换成不带可买入过滤的标签」那个实验。
只影响多空口径 ⇒ 对本用户无关,维持最低优先级、不做。

**vi. 制度依赖的残留。** `[05 H13 已改写/H14 被否定]` 收盘集合竞价那一格触发放量的股票-日占 45%,
且有强时间趋势(2018H1 0.242 → valid 0.600);机制探针已证会往 `M` 里掺硬零。
但实测 `Mc/M` 中位只有 **1.005**、`rank corr(|Rc|, S) = +0.963` ⇒ 伪影只把 `M` 压低 0.5%,**幅度被推翻**。
**而且推荐的升华版把 `Volume` 整条删掉了 ⇒ 这个风险对推荐不适用**,只对原式适用。

## 四、措辞纪律(写报告时必须守住的六条)

1. 原式→`f_cmT20` 的改进写「**来自平滑(省成本)**」,`f_cmT20`→`f_cvxD20` 的改进写「**来自结构**」;
   **不要**把两半混成一句「结构更好」,也**不要**继续写「一半一半」(留出段是 37/63)。
2. `f_cvxD20` 与原式 rank corr **+0.673 < 0.8** ⇒ 必须说它是**升华(换了一条因子)**,不是提纯。
   唯一能叫提纯的是 `f_cmT20`(+0.896)。
3. 留出段 `Ln` 变高、`Lshp` 没变高 ⇒ 写「净超额更高、夏普持平」,**不要**写「留出段表现更好」。
4. 「单独输给已知家族」的诚实区间是 **1~7 点**(holdout −1.3、train −4.7、utrain −7.4),
   **不是**训练段写过的「5~14 点」—— 那个「14 点」用的是 `f_known30` 在 valid 的高点 +22.3%。
5. 「没有增量」**≠**「它就是已知家族」:corr 只有 +0.39、多头十分位重叠 0.153/0.182(随机 0.10)
   ⇒ 它买的不是同一批票。没有增量的原因是**夏普量级不够**,不是同族。
6. 逐年表里 **2023 那一行是 valid+holdout 混合口径**,只有 2024、2025 是纯 holdout;
   年度 `Lshp` 与整段 `Lshp` 不是同一个口径(2024 +1.22、2025 +2.01,整段只有 +1.17,差额来自 2023 后段那 96 天约为零)。
