## 要带回来的数字

### (1) 主表:5 条候选 × 4 段 × 两种口径

每条候选都要 **holdout / train / valid / utrain** 四段(`utrain` = train+valid = 用户训练段),每段都要:

- 多头口径:`hlL`(拟合到的半衰期)、`Ln` 多头腿净超额、`Lshp` 纯多头夏普、`Lg` 多头腿毛超额、`LTO` 多头日换手
- 多空口径:`hlS`、`LS` 扣费多空夏普、`short` 空头腿毛超额
- 门槛:`cov`、`dist`

**工具的两个坑(R2 结果卡第 7 条已经踩过,这次直接绕开)**:
`digest` / `summarize.py` 打的主表里 **`LTO` 和 `short` 两列只取第一个 split(train)**,
固定半衰期表(`sweep`)**只在 fit 段算**。所以 **holdout 的 `Lg` / `LTO` / `short` 必须从
`runs/F110_ret_fair_log/S_final.json` 里直接读**(`results.<id>.books.by_rank.long.splits.holdout` 下的
`long_ann` / `long_sharpe` / `long_gross_ann` / `long_turnover`,多空那本在 `by_rank.ls` 或同级字段下 ——
**字段名以 JSON 实际结构为准**,读到什么就写什么,并在结果卡里写明你是从哪个字段路径取的)。
**如果某个量 JSON 里确实没有,就写「JSON 里没有这个字段」,不要估、不要用别段的数字顶替。**

- **rank 相关矩阵** 6×6(`corr_ids`),以及 6×12 的 `corr_with` 表 —— 外加第 2 步 canary 那 7 项的逐项对照。
