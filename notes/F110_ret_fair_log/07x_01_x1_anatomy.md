# 自写分析 x1 / x1c / x1d:`T = D·|M−Q|` 的解剖(结果与解读)

脚本 `studies/F110_ret_fair_log/x1_anatomy.py`,三次服务器运行:`x1`(exit 97,0 段 + B 段前半)、
`x1c`(exit 0,sections `0 B D`)、`x1d`(exit 0,sections `C E`)。全文读数在结果卡
`notes/F110_ret_fair_log/results/R1.md`,原始日志 `logs/F110_ret_fair_log_x1{,c,d}.log`。
口径:固定半衰期 20(把「结构」和「平滑」分开的唯一干净办法),方向按 train 的 rank IC 定;
`Ln` = 多头腿净超额(扣 15 bp),`Lshp` = 纯多头夏普,`Lg` = 多头腿毛超额,`sh` = 空头腿毛超额,`LTO` = 多头日换手。
噪声尺度(手册):`Ln` ±3 个点、`Lshp` ±0.3、多空夏普 ±0.3。

记号:`D` = 日内收益(开盘→收盘,不含隔夜),`M` / `Q` = 放量 / 缩量触发点的 5 分钟收益总体 std 的日均,
`S = |M−Q|`,`T = D·S`,`σ = day_std(Ret)`(就是 `ctl_ivol`,配置里写明),实际交易的信号 = `−EMA_hl(T)`。

## 0. 地基(x1c 的 0 段)

`T` vs 脚本自己拼的 `D·|M−Q|`:有限值占比 0.8145 三者一致,`max|diff|` 8.396e−05,**rank corr 1.00000**;
基线逐项复现 S0(train `rIC +0.0444 LS +2.77 Lg +8.0% Ln −0.0%`,valid `rIC +0.0571 LS +2.74 Lg +7.4% Ln −0.6%`)。
→ 后面所有 numpy 替换实验都是在引擎求值出来的同一张面板上做的,可信;
→ 顺带确立一件对 R2 有用的事:`mul(div(sub(day_last(Close), day_first(Open)), day_first(Open)), abs_(sub(M, Q)))`
  与原式**逐位等价**(原式的 `sub(div(Close_last, Open_first), 1)` 只是同一个量的另一种写法),
  所以可以把日轴算子(`cross_mean` 等)套在它外面而不改变被平滑的对象。

## 1. 最值钱的一问:延长半衰期救不了多头腿(H9 被否定)

事前判据(写在 R1 工单里):`hl 40 / 60` 的 `Ln` 在 train **和** valid 都 > +3% ⇒ H9 成立;
`hl 40/60/90/120` 都不高于 `hl20`(±3 点内)⇒ H9 死。

| 原式 `c0 = D·S` | hl20 | hl30 | hl40 | hl60 | hl90 | hl120 |
|---|---|---|---|---|---|---|
| train `Ln` | −0.0% | **+1.2%** | +0.2% | +0.4% | −0.9% | −1.4% |
| valid `Ln` | −0.6% | +2.4% | +3.3% | +3.3% | +3.3% | +2.4% |
| train `Lg` | +8.0% | +7.3% | +5.2% | +4.1% | +1.7% | +0.6% |
| train `LTO` | 10.6% | 8.1% | 6.6% | 4.9% | 3.4% | 2.7% |

**判决:H9 被否定。** train 侧 `Ln` 在整张网格里从未超过 +1.2%,全部落在 hl20 的 ±3 点噪声带里;
`D` 单独(`c1`)同样,train 最高 +1.8%(hl40)。只有换了结构的 `c2 = D·σ` 在 hl40(+3.9% / +3.6%)
和 hl60(+3.4% / +3.0%)两段同时过线 —— 但那是**结构替换**,不是「原式 + 更长的半衰期」。

**为什么会这样(机制,已确立)**:从 hl20 往后,**毛超额掉得和换手省下来的一样快** ——
`Lg` 从 +8.0% 一路掉到 +0.6%,`LTO` 从 10.6% 掉到 2.7%,两者相抵,净超额钉在 0 附近。
所以基线里「hl 0→20 每翻倍 +6~8 个点」那条漂亮的单调曲线**百分之百是成本的功劳,不是 alpha**:
它是把 85% 的日换手压到 10% 的过程,压到 10% 以下就没有成本可省了。
hl20 不是「网格上限」,它**正好就是最优点**——这也解释了为什么多头口径和多空口径选到了同一个半衰期。

valid 侧 hl40~90 的 +3.3% 不能用:方向和半衰期必须在 fit 段(train)上定,train 的 argmax 是 hl30(+1.2%),
它带到 valid 是 +2.4% —— 两段都在噪声带内。

## 2. 成交量事件机器整条是死重(H2 被支持;H1 要改写)

固定 hl20、只换权重支路:

| 变体 | corr(与原式) | train `rIC` / `LS` / `Lg` / `Ln` | valid 同序 |
|---|---|---|---|
| `c0` 原式 `D·S` | 1.000 | +0.0444 / +2.77 / +8.0% / −0.0% | +0.0571 / +2.74 / +7.4% / −0.6% |
| `c6` **`D·\|D\|`** | +0.733 | **+0.0465 / +2.87 / +12.5% / +4.6%** | **+0.0595 / +3.04 / +8.4% / +0.7%** |
| `c2` `D·σ` | +0.801 | +0.0460 / +2.94 / +10.1% / +1.0% | +0.0594 / +2.91 / +8.1% / −1.0% |
| `c19` `D·σ²` | +0.784 | +0.0432 / **+3.58** / +7.4% / +0.5% | +0.0553 / **+3.38** / +7.2% / +0.7% |
| `c3` `D·M` | +0.767 | +0.0390 / +2.20 / +9.4% / −0.2% | +0.0539 / +2.54 / +7.5% / −2.0% |
| `c4` `D·Q` | +0.634 | +0.0333 / +1.99 / +8.0% / −1.4% | +0.0471 / +2.33 / +5.5% / −3.8% |
| `c8` `D·(S/σ)` | +0.943 | +0.0422 / +2.16 / +9.5% / −0.0% | +0.0549 / +2.32 / +5.8% / −3.8% |
| `c7` `sign(D)·S` | +0.790 | +0.0346 / +1.79 / +5.1% / −5.4% | +0.0442 / +2.06 / +4.0% / −6.5% |
| `c1` `D` 单独 | +0.698 | +0.0423 / +2.06 / +9.7% / −1.3% | +0.0550 / +2.55 / +8.0% / −3.3% |
| `c20` `D/σ` | +0.485 | +0.0287 / +0.84 / +6.7% / −5.1% | +0.0392 / +1.64 / +5.8% / −6.6% |

**(a)`S` 不是日内波动的代理 —— H1 的第一条预测被打掉。** `rank corr(S, day_std(Ret)) = +0.422`,
事前判据要的是 > 0.7。但同一行输出里 `M~σ = +0.870`、`Q~σ = +0.823`、`M~Q = +0.923`。
正确的读法:**`M` 和 `Q` 各自都是同一个量(当天 5 分钟收益 std)的两个高度相关的估计**
(每侧触发占全天分钟 13.7%、中位 33 / 32 个触发点、各带 5 分钟窗),而 `S = |M−Q|` 是**两个估计之差**,
所以它的截面变异主要是**估计噪声**,而不是波动水平 —— 这正好解释了 0.422 为什么这么低,
以及 `(M−Q)/mean` 的中位只有 +0.107(两侧只差一成)。

**(b)但这不重要,因为整条权重支路可以删 —— H2 被支持。** 把 `S` 换成任何同尺度的东西都不差,
换成 `|D|` 自己(`c6`)**每一项都比原式好**(train `rIC`、`LS`、`Lg`、`Ln` 全面占优,valid 同向);
换成 `σ`(`c2`)或 `σ²`(`c19`)也不差,`c19` 甚至给出全表最高的多空夏普 +3.58 / +3.38。
反过来,**把波动尺度从 `S` 里除掉就变差**:`c8 = D·(S/σ)` 的 `LS` 掉到 2.16 / 2.32(低于 `c2` 的 2.94 / 2.91),
`c20 = D/σ` 塌到 0.84 / 1.64。H2 的杀死判据是「`D·(S/σ)` 好于 `D·σ`」—— 它更差,**H2 没被杀死,反而被支持**:
`S` 里超出波动尺度的那部分(也就是「放量侧比缩量侧多出多少」这个事件内容)不带信息,甚至是噪声。

**(c)提纯的终点。** 成交量事件机器(`log(Volume)`、`in_forward_valid_part`、`in_mean_full`/`in_stddev_full`、
`is_gt`/`is_lt`、`in_sustain_stddev`、两个 `day_mean`、`sub`、`abs_` —— 十几个节点,是这棵树的绝大部分)
**整条可删**,留下 `mul(D, abs_(D))`(6 个算子、只用当天的 Open / Close)就够,而且更好。
`Volume` 和 `Ret` 这两个字段对这条因子**完全多余**。

## 3. 乘法是带符号的凸化(H4 被支持);是日内、不是收盘到收盘(H5 被支持)

- `c1 D` 单独(`LS +2.06 / +2.55`)明显弱于 `c6 D·|D|`(+2.87 / +3.04)和原式(+2.77 / +2.74)⇒ **凸化有用**,不是多余的。
- `c7 sign(D)·S`(把 `D` 的幅度丢掉,只留权重)塌到 `LS +1.79 / +2.06`、`Ln −5.4% / −6.5%` ⇒
  **起作用的是 `|D|` 的幅度,不是 `S`**。两条合起来:`T ≈ sign(D)·D²` —— H4 的事前写法被证实。
- `c10 Dcc·S`(收盘到收盘)`LS +2.36 / +2.31`、`Ln −1.3% / −2.4%`,比原式低 0.4 左右(超过 0.3 的噪声带);
  `c12 Dcc` 单独 `Ln −5.7% / −5.1%`(对比 `c1 D` 的 −1.3% / −3.3%)。
- `c11 Don·S`(隔夜)**方向翻成 +1**,`Ln −14.7% / −15.8%`;`c13 Don` 单独 `Ln −21.0% / −20.2%`、`LS −0.45 / −0.19`。
→ **H5 被支持**:起作用的是「日内」这一段,隔夜那一段是反方向的。这是 A 股 T+1 下日内 / 隔夜拔河的典型形状,
  不是普通的收盘到收盘反转 —— 但差距只有 0.4 个夏普,**算「合理但未坐实」,不是铁证**。

## 4. 空头腿和多头腿住在不同的持有期上(C2 lag profile —— 事前没想到,本轮最重要的新读数)

把**未平滑**的日频面板滞后 k 天直接去打标签(`−x[t−k]`),只看毛超额:

| `−D` 的 lag | 0 | 1 | 2 | 3 | 5 | 10 | 20 | 30 | 40 | 60 |
|---|---|---|---|---|---|---|---|---|---|---|
| train `Lg` | +3.7% | −7.0% | −0.4% | −2.2% | −6.0% | −1.1% | +2.2% | −1.0% | −5.1% | −1.2% |
| valid `Lg` | −7.3% | −5.1% | −7.4% | −7.2% | −13.8% | −12.1% | +1.3% | **+5.0%** | **+6.9%** | −8.5% |
| train `sh` | **+43.7%** | +18.2% | +25.1% | +24.0% | +6.0% | +6.2% | +7.6% | +4.7% | −0.7% | −1.4% |
| valid `sh` | +39.1% | +28.1% | +30.0% | +21.5% | +20.2% | +10.2% | +13.2% | +16.5% | +16.2% | +2.9% |

`−T` 和 `−T⁺` 的形状一样(`−T⁺` lag 0 的 `sh` +35.3% / +35.2%,到 lag 5 剩 +6.7% / +21.2%)。

**解读(已确立的部分)**:
- **空头腿是一个 1~3 天的快反转**:刚刚日内大涨的票次日回落,`sh` 在 lag 0 是 +43.7%,到 lag 5 只剩 +6.0%(train)。
  这就是「钱为什么主要在空头腿」的完整答案 —— 它是个短期效应,**而且只能靠卖出来兑现**。
- **多头腿在 lag 0~10 是负的**(valid 全程 −5% ~ −14%),只有到 lag 20~40 才转正,而且主要在 valid 段。
  → 多头腿**不是空头腿的镜像**,它是另一个、慢得多、弱得多的效应。
- 这解释了基线里的两个现象:(i)为什么 `EMA` 怎么调都救不了多头腿 —— EMA 永远把最大的权重压在今天,
  而今天的多头端是负的;(ii)为什么 20 分位剖面的**顶档会回落**(见第 5 节)。

**还不确立的部分**:lag 20~40 的正多头腿在 train 侧是 −1% ~ −5%,只有 valid 侧是 +5% ~ +7% ——
**两段不同向**。所以「多头信息住在 lag 20~40」这条读法本身只是**合理但未坐实**(新假设 H15),
必须用一个显式砍掉最近若干天的变体去判(R2 的 `w_cmD20lag10`)。

## 5. 分位剖面:多头端是一块平台,顶档回落(H6 被支持;H10 被否定)

20 分位年化超额(%),短端 → 长端:

```
base −EMA20(T)   tr: -59 -28 -13 -9 -3 +3 +3 +6 +3 +7 +7 +11 +10 +10 +9 +6 +9 +11 +13 +4
base −EMA20(T)   va: -66 -29 -12 -15 -4 -1 +3 +5 +7 +8 +10 +8 +11 +10 +13 +12 +11 +13 +9 +8
c2 −EMA20(D·σ)   tr: -63 -33 -19 -7 -3 +2 +4 +8 +9 +7 +8 +8 +9 +9 +8 +8 +11 +13 +12 +9
base hl60        tr: -26 -31 -18 -9 -3 -1 +1 +5 +3 +6 +9 +7 +7 +9 +8 +8 +8 +7 +10 +1
```

- 形状是「**一道悬崖 + 一块平台**」:第 1 分位 −59% / −66%,第 2~3 分位 −28% / −12%,
  第 6 分位往后就是一块 +3% ~ +13% 的平台,**没有排序**。
- **顶档回落是普遍现象**:`base` 第 20 档 train +4%(前面三档 +9 / +11 / +13)、valid +8%(前面 +11 / +13 / +9);
  `c14 T⁺` train 顶档 **−6%**;`c15 T⁻` train 顶档 **−11%**;`c2` 顶档 +9%(前面 +11 / +13 / +12)。
  → 对只能做多的用户:**买第 15~19 档比买最顶档好**,这本身就说明多头端没有可信的排序能力。**H6 被支持。**
- **H10 被否定**:事前的解释是「`S` 的波动尺度把高波动暴跌票推到了最顶」,预测去尺度能修平。实测去尺度**更差** ——
  `c9 zr(D)·pct(S)` `Ln −4.1% / −6.2%`、`c20 D/σ` `Ln −5.1% / −6.6%`,`c16 |D|·S`、`c17 S`、`c18 σ`
  这些「只剩权重」的版本 train / valid 符号相反(train −3.5% ~ −6.1%,valid +2.2% ~ +8.6%,落差 8~13 点)。
  **顶档回落的真正原因在第 4 节**:短 lag 的多头端本身是负的(还在跌的票排在最前),不是尺度问题。
- `base hl60` 把第 1 分位从 −59% 抬到 −26%:**延长平滑主要是在毁空头腿**,顶档照样回落。

## 6. 收盘集合竞价伪影:机制在,幅度可以忽略(H13 的量化判断被推翻)

第 1 轮把它升级成「头号嫌疑」,算术估计是「`M` 被压低约 3% ⇒ 不对称被低估约 28% ⇒ `S` 里四分之一到三分之一是
241 网格的版式伪影」。x1c 的实测把这个估计**打掉了**:

| | 实测 | 第 1 轮的预测 |
|---|---|---|
| `Mc / M` 中位(切掉最后 4 格) | **1.005** | ≈ 1.03 |
| `M < Q` 占比 | 0.1669 → **0.1500** | 应明显变化 |
| `rank corr(\|Rc\|, S)` | **+0.963** | 明显低于 1 |
| `rank corr(Mc, M)` | +0.997 | — |

→ **机制是真的**(收盘竞价那一格触发放量的股票-日占 0.450,2018H1 0.242 → 2021 0.580 → valid 0.600;
窗口剩 1 分钟 ⇒ 总体 std = 0 ⇒ 往 `M` 里掺硬零),**但它只把 `M` 压低了 0.5%,不是 3%**,
切格后的权重与原权重 rank corr +0.963。**H13 的幅度判断被推翻,从「头号嫌疑」降级为「机制确认、幅度可忽略」。**

更强的一条逻辑(不需要再跑实验):第 2 节已经证明**整条权重支路都可以换成 `|D|` 或 `σ` 而不变差** ——
既然整个权重都不重要,权重内部的某个版式细节就更不可能重要。所以**「切掉最后 4 格」这个清伪影候选不值得占一个变体位**,
H14 也同样失去意义(它问的是伪影会不会污染排序)。

**代价**:基线里「多头腿逐年飘、六年里四年为负」就**没有伪影这个解释了**。按第 1、4、5 节,
更朴素的解释是:**多头腿本来就是噪声**(逐年 −7.1% ~ +6.5%,量级和 ±3 点的噪声带同阶),不需要制度性的原因。

## 7. 这一节分析留下的三件事

1. 多头腿唯一还没被打掉的改进来源:**把平滑写进表达式**(`cross_mean` 盒式平滑 + 口径里的 `EMA`)。
   D 段的 numpy 读数:`cross_mean(D,20)` + `EMA20` → `Ln` **+4.9% / +7.4%**(`Lshp` +0.75 / +0.93,`LTO` 3.6%);
   `cross_mean(D,60)` + `EMA10` → +4.6% / +6.5%;`cross_mean(T,30)` + `EMA10` → +4.4% / +4.6%;
   `cross_mean(T,20)` + `EMA20` → +3.6% / +5.7%。全部明显高于纯长 `EMA` 能做到的(`−ema(D,60)` 只有 +1.6% / +2.2%)。
   **机制(合理但未坐实)**:盒式平滑在**同样的毛超额**下换手更低(`cross_mean(D,20)+EMA20` `Lg +7.6% / LTO 3.6%`
   vs `−ema(D,30)` `Lg +9.1% / LTO 11.2%`)—— 每天只有 1/20 的窗口滚出去,而 EMA 每天都有一块新鲜权重压在今天。
   如果是这样,**这个改进同样要归因到「来自平滑」**,不是结构发现。
2. 但 `+4.9% / +7.4%`(`Lshp` 0.75 / 0.93)只有已知家族 `cross_mean(day_std(Amt),30)` 的三分之一
   (同口径 train `Ln +12.6% / Lshp +1.78`,valid `+22.3% / +3.46`,脚本 H 段的注释行)。
   **所以结论能不能是正面的,全看「相对已知家族有没有增量」** —— 必须跑 G / H 两段(R2)。
3. 新的分辨风险:`cross_mean(D,20)` 几乎就是「20 日反转」,而 `D~ctl_rev1` 的 rank corr 是 **+0.870**。
   必须直接比一条「收盘到收盘版」(`w_cmDcc20`)并看它和 `ctl_mom20` 的 rank 相关 —— 如果一样,
   这个候选就是教科书上的中期反转,不是新东西。
