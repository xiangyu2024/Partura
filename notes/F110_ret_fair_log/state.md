### 2.3 `S = |M−Q|` 到底是什么 `[x1-B]` —— 目前为止最重要的读数

- `S` 在有标签样本里有限值占 0.9992;`S == 0` 占 0.0057。
- **`M < Q` 占 16.69%(train)/ 13.53%(valid)。** → `abs_` **不是** no-op,它每六七个股票-日折叠一次(H3 被否定)。
- `(M−Q) / mean(M,Q)` 分位:p1 −0.170,p5 −0.076,p25 **+0.031**,p50 **+0.107**,p75 +0.191,p95 +0.340,p99 +0.561。
  → **两侧只差 10% 左右**。`S` 的**尺度由日内波动水平携带**,「事件」内容只是一个 ~11% 的调制。
- 触发数(每天每只票,241 格里):放量 p25 30 / **p50 33** / p75 35;缩量 p25 29 / **p50 32** / p75 35。
  → 每侧占全天分钟的 **13.7%**,各带 5 分钟窗口,覆盖面重叠地铺满大半个交易日。
  **`M` 和 `Q` 各自都近似「当天 5 分钟收益总体 std」的估计,不是少数稀有事件的统计量。**
- 「缩量触发紧跟在放量触发之后」的占比 **0.307**。→ 探针上那个「孤立脉冲 ⇒ 放量在 j、缩量在 j+1、两窗重叠 4/5」的图景
  在真实数据里只占三成,**不能**拿它当 `S` 的主要解释(这一条修正了 02/03 notes 里「成交量脉冲处的价格冲击」的读法)。
- **收盘集合竞价那一格触发放量的股票-日占比 0.450,而且有强时间趋势:2018H1 0.242 → 2021 0.580 → valid 0.600。**
  机制(探针已证):最后一格的 5 分钟窗口只剩 1 分钟 ⇒ 总体 std = 0 ⇒ 往 `M` 里掺一个硬零。
- **B 段最后两项没打出来**(守卫在这里中断):`rank corr(S, day_std(Ret))`、以及切掉最后 4 格的 `Mc/Qc` 读数。**R1 要补。**

### 2.4 由 2.3 推出来的算术(**估算,未坐实**,R1 的 `Mc/Qc` 去量)

一个触发点的窗口 std 被 0 顶替,`M` 按 `1 − 1/n_U` 缩小,`n_U` 中位 33 ⇒ **`M` 被压低约 3.0%**。
而 `M−Q` 的中位只有 `0.107 × mean` ⇒ 这 3% 的压低相当于把两侧的不对称**低估了 0.030/0.107 ≈ 28%**。
于是:(a)`S` 里有大约四分之一到三分之一是**收盘集合竞价的版式伪影**;(b)这块伪影的权重从 2018H1 的 24% 涨到
valid 段的 60%,**同一个表达式在样本前后段量的不是同一件事** —— 这是 2.1 里「多头腿逐年飘、六年里四年为负」的头号候选解释。
(制度背景:沪市 2018-08-20 才有收盘集合竞价,正好落在 train 段内。)

## 3. 研究过程与逻辑

1. 第一位研究员(Opus 5.5)先读内核源码 + 为这棵树写了 5 个带自检的探针(`probes.py`),把「名字骗人的地方」钉死在 02_operators.md。
   **源码里和名字不一样的地方(照用,不要重测)**:
   - `in_forward_valid_part(x)` **不是前向填充**,是「上一有效分钟的值」(只读 j−1;j−1 为 0 或 NaN 时跳到 j−2;首分钟 NaN)。
     「有效」= 非零且非 NaN,它吃的是 `log(Volume)`,所以被跳过的是零成交分钟和成交量恰为 1 的分钟。
   - `log(0) = NaN`(不是 −inf);`|x| ≤ EPS` 给 NaN;源码是 `log|x|`。零成交分钟的 `G` 是 NaN,**不触发**任何一侧。
   - `in_mean_full` / `in_stddev_full` 是**整行统计量铺满整行**(含当分钟之后的),阈值 `mean(G) ± 1·std(G)` 是**事后**的;
     对收盘后才用的日频因子不是泄漏。
   - `in_sustain_stddev(mask, Ret, 5)` 是**触发型**算子:只在 mask==1 处有值;窗口 = 触发分钟自己 + 之后 4 分钟;**总体** std;
     窗口跑出行尾就截短(剩 1 分钟时 **= 0.0**);整行无触发则整行 NaN。**内置探针对它全是空读数**(喂随机浮点,mask 永不成立)。
   - `day_first(Open)` / `day_last(Close)` 取当天第一个/最后一个非 NaN ⇒ `D` 是开盘→收盘,**不含隔夜**。
   - 原式的根是「日频值铺满分钟轴」(`sub(·, 1)` 的常数是退化值);想在外面套日轴算子,得把 `D` 改写成
     `div(sub(day_last(Close), day_first(Open)), day_first(Open))`(数值相同)。
2. 关键公式(`j = 0..240`,`p(j)` = j 之前最近一个有成交的分钟):
   `g_j = log v_j − log v_{p(j)}`;`U = {g_j > mean(g)+std(g)}`,`L = {g_j < mean(g)−std(g)}`;
   `σ5(j) = 总体 std(r_j..r_{j+4})`;`M = mean_{j∈U} σ5(j)`,`Q = mean_{j∈L} σ5(j)`;`S = |M−Q|`;`D = Close/Open − 1`;
   **`T = D·S`;实际交易的信号 = `−EMA_{半衰期20}(T)`**。
3. **整棵树没有任何日轴算子**(沿路径回看 1 天)。裸的 `T` 日换手 85%,不可交易;它能交易全靠口径里那个 EMA。
   所以**平滑不是外加参数,而是这条因子的另一半**:`Σ_k 0.966^k · D_{t−k}·S_{t−k}`,一个按 `S` 加权的日内收益累积。
   可独立替换的零件只有四个:**符号载体 `D`、权重 `S`(及其掩码/统计量/折叠)、乘法、口径里的 EMA**。实验按这四件拆。
