## 1. 一句话现状

**原式对只能做多的用户没用,而且已经知道为什么;研究现在只剩两问 —— ①把平滑写进表达式之后新候选能不能站住
②它相对已知家族有没有增量。工单 R2 就是去拿这两样的,拿到之后下一轮就可以读留出段。**

R1 的两次运行(`x1c` = `0 B D`、`x1d` = `C E`,都 exit 0,canary 逐项对上)确立了三件事:
(a)**原式的多头腿扣费后是零,延长半衰期救不了它** —— hl20 之后毛超额掉得和换手省的一样快,hl20 本来就是最优点,
基线里「hl 0→20 每翻倍 +6~8 个点」那条曲线 100% 是成本的功劳(H9 **被否定**);
(b)**整条成交量事件机器是死重** —— 权重 `S` 换成 `|D|` 每一项都更好、换成 `σ`/`σ²` 也不差,
把波动尺度从 `S` 里除掉反而变差(H2 **被支持**);提纯的终点是 `mul(D, abs_(D))`,6 个算子,`Volume`/`Ret` 两个字段全多余;
(c)**空头腿和多头腿住在不同的持有期上** —— 空头腿是 lag 0~3 天的快反转(`sh` 从 +43.7% 掉到 lag 5 的 +6.0%),
多头腿在 lag 0~10 全为负、只有 lag 20~40 才转正(新读数,事前没想到)。这才是「多头腿为什么不行」的真正答案。

**唯一还活着的多头腿改进来源:把平滑写进表达式**(`cross_mean` 盒式 + 口径里的 `EMA`)。
R1 的 numpy 读数:`cross_mean(D,20)+EMA20` → `Ln +4.9% / +7.4%`(`Lshp +0.75 / +0.93`,`LTO 3.6%`),
全研究最高。但它只有已知家族 `cross_mean(day_std(Amt),30)` 同口径的三分之一(train `+12.6% / +1.78`,valid `+22.3% / +3.46`)。
**所以结论能不能是正面的,全看「相对已知家族有没有增量」。**

## 3. 研究过程与逻辑

1. 第一位研究员(Opus 5.5)读内核源码 + 为这棵树写了 5 个带自检的探针(`probes.py`),把「名字骗人的地方」钉在 `02_operators.md`。
   **源码里和名字不一样的地方(照用,不要重测)**:
   - `in_forward_valid_part(x)` **不是前向填充**,是「上一有效分钟的值」(只读 j−1;j−1 为 0 或 NaN 时跳到 j−2;首分钟 NaN)。
     「有效」= 非零且非 NaN,它吃的是 `log(Volume)`,被跳过的是零成交分钟和成交量恰为 1 的分钟。
   - `log(0) = NaN`(不是 −inf);`|x| ≤ EPS` 给 NaN;源码是 `log|x|`。零成交分钟的 `G` 是 NaN,**不触发**任何一侧。
   - `in_mean_full` / `in_stddev_full` 是**整行统计量铺满整行**(含当分钟之后的),阈值 `mean(G) ± 1·std(G)` 是**事后**的;
     对收盘后才用的日频因子不是泄漏。
   - `in_sustain_stddev(mask, Ret, 5)` 是**触发型**算子:只在 mask==1 处有值;窗口 = 触发分钟自己 + 之后 4 分钟;
     **总体** std;窗口跑出行尾就截短(剩 1 分钟时 **= 0.0**);整行无触发则整行 NaN。**内置探针对它全是空读数**。
   - `day_first(Open)` / `day_last(Close)` 取当天第一个/最后一个非 NaN ⇒ `D` 是开盘→收盘,**不含隔夜**。
   - 原式的根是「日频值铺满分钟轴」(`sub(·, 1)` 的常数是退化值);要在外面套日轴算子,得把 `D` 写成
     `div(sub(day_last(Close), day_first(Open)), day_first(Open))`(**R1 的 0 段已证等价**)。
   - `cross_mean` / `cross_delay` 的内核是 `rolling_reduce(x, int(d), …)`,**窗口是普通 int 字面量**;
     `study.sh ops` 打的 `win [3,5,10,15,30,60,241]` 只是**搜索语法的菜单**,不是解析限制
     (证据:配置里 `gates` 的 `cross_max(day_std(Amt), 9)` 用的就是 9)。`ts_delay` 的菜单含 1,1 天滞后用它。
2. 关键公式(`j = 0..240`,`p(j)` = j 之前最近一个有成交的分钟):
   `g_j = log v_j − log v_{p(j)}`;`U = {g_j > mean(g)+std(g)}`,`L = {g_j < mean(g)−std(g)}`;
   `σ5(j) = 总体 std(r_j..r_{j+4})`;`M = mean_{j∈U} σ5(j)`,`Q = mean_{j∈L} σ5(j)`;`S = |M−Q|`;`D = Close/Open − 1`;
   **`T = D·S`;实际交易的信号 = `−EMA_{hl}(T)`**。
3. **整棵树没有任何日轴算子**。裸 `T` 日换手 85%,不可交易;能交易全靠口径里的 EMA ⇒ **平滑是这条因子的另一半**。
   可独立替换的零件只有四个:符号载体 `D`、权重 `S`、乘法、口径里的 EMA。实验按这四件拆。
