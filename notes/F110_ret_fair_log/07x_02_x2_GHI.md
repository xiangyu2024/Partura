## x2(G / H / I 三段):它大部分落在标准控制的张成里;对只能做多的用户,它相对已知家族**没有增量**

(`exec` tag `x2` = `studies/F110_ret_fair_log/x1_anatomy.py G H I`,exit 0 / 127s;
原始读数在 `results/R2.md` 第 9~11 项,日志 `logs/F110_ret_fair_log_x2.log`。
`Ln` 多头腿净超额 · `Lshp` 纯多头夏普 · `Lg` 多头腿毛超额 · `sh` 空头腿毛超额 · `LTO` 多头日换手。数字写 train / valid。)

### 1. G 段 + `neutralise` 诊断:H8 被支持 —— 它几乎整条落在 9 个标准控制的张成里

对**候选** `w_cmD20`(= `cross_mean(D,20)` + EMA20)做秩空间逐日截面 OLS 中性化(fit 段 = train):

| 控制集 | R²(秩空间) | 残差 rank IC | 残差 `Lg` |
|---|---|---|---|
| (未中性化) | — | **+0.0291** | +7.9% |
| **9 个控制全上** | 0.284(原始日频面板上 **0.703**) | **+0.0038** | **−2.5%** |
| `ctl_dvol20`(最强的单控制) | 0.176 | +0.0130 | +4.2% |
| `ctl_turnrate` | 0.116 | +0.0166 | +6.2% |
| `ctl_mom20` | 0.096 | +0.0214 | +2.0% |
| `ctl_ivol` / `ctl_range` | 0.092 / 0.090 | +0.0190 / +0.0196 | +6.7% / +6.7% |
| `ctl_amt` | 0.084 | +0.0194 | +1.0% |
| `ctl_rev1` / `ctl_cap` / `ctl_price` | 0.014 / 0.015 / 0.012 | +0.0299 / +0.0281 / +0.0280 | +8.9% / +5.9% / +5.3% |

**解读。**
- **没有任何单个控制能解释它**(最强的 `ctl_dvol20` 也只拿掉 R² 0.176、残差 rank IC 还有 +0.0130),
  但**九个一起上就把它清空了**:rank IC 从 +0.0291 掉到 **+0.0038(−87%)**,残差多头腿毛超额变成 **−2.5%**。
  ⇒ **H8 被支持**:它是「20 日波动 + 换手率 + 成交额水平 + 20 日动量」这一组标准暴露的一个**非线性、平滑过的组合**,
  不是其中任何一个的改写。
- **幅度的两个相反偏差(写进 `11_risks.md`)**:(a) 控制变量**没有按同口径平滑**,这会**低估**吸收程度;
  (b) 残差**不再平滑**(`LTO` 从 3.3% 跳到 16.9%),这会**高估**吸收程度。
  所以「大部分可被标准控制解释」是**已确立**的,「几乎 100%」只能算**合理但未坐实**。
- 对照原式 `v_base`:9 控制 R² 0.349、残差 rank IC +0.0444→+0.0173(−61%)。
  **候选被吸收得比原式更彻底** —— 盒式平滑把它推得更靠近标准的波动/换手家族。这是「分辨」的核心结论之一。
- 反过来看 G 段的「谁吞并谁」:把 `cm20` 从原式里中性化掉,原式还剩 `Lg +5.4% / +4.9%`、`sh +17.2% / +7.6%`;
  把原式从 `cm20` 里中性化掉,`cm20` 只剩残差 rank IC `+0.0029 / +0.0165`、`Lg −4.0% / +5.3%`。
  ⇒ **候选基本住在原式里面(是原式的一个子集方向),而原式还有候选之外的东西(主要是那条 1~3 天的空头反转)。**
  这和主表一致:候选把空头腿从 +43.3% 让到 +26~29%,换来多头腿。

### 2. H 段:对只能做多的用户,相对已知家族**没有增量** —— 这是本研究的决定性一问

已知家族单独(同口径):`known_stdamt_mean30` train `Ln +12.6% / Lshp +1.78`,valid `+22.3% / +3.46`;
`known_stdamt_max9` train `+13.7% / +1.99`,valid `+22.2% / +3.59`。

`known + w × partner`(z 分数相加,w = 0.25 / 0.5 / 1.0)**十个 partner 的 valid 侧多头腿净超额**
(已知家族单独 = **+22.3%**):

| partner | 它自己的 valid `Ln` | w=0.25 | w=0.5 | w=1.0 |
|---|---|---|---|---|
| `base hl20`(原式) | −0.6% | +21.0% | +17.6% | +15.2% |
| `base hl60` | (+3.3%,R1 numpy) | **+22.3%** | +20.4% | +18.3% |
| `c1 D hl20` | −3.3% | +17.9% | +14.3% | +10.3% |
| `c1 D hl60` | (+2.2%) | +21.6% | +18.8% | +15.9% |
| `c2 D·σ hl20` | −1.0% | +20.0% | +17.1% | +13.3% |
| `c14 T⁺ hl20` | +6.9% | +21.9% | +20.8% | +18.7% |
| `c15 T⁻ hl20` | +1.8% | **+22.5%** | +20.6% | +18.2% |
| **`cm20`(领先候选)** | **+7.3%** | +21.3% | +20.0% | +17.4% |
| `cmT20` | +5.7% | +21.5% | +19.9% | +17.6% |
| `cm20lag10` | +5.4% | +20.2% | +18.5% | +15.6% |

**解读。**
- **30 个组合里没有一个在 valid 上超过已知家族单独**(最好的两个 `+22.5%`、`+22.3%` 与 `+22.3%` 在噪声带内),
  而且**每一个 partner 都是加得越多越差**(w 从 0.25 到 1.0 单调下滑)。纯多头夏普同样:
  valid 最高 `+3.61`(`base hl60` @0.25)、`+3.52`(`c1 hl60` @0.25),与已知家族的 `+3.46` 全在 ±0.3 噪声带内。
- 领先候选 `cm20` 的事前判据(两段都高 ≥3 点,或 `Lshp` 高 ≥0.3)**明确不满足**:
  train `+13.3% / +1.97`(+0.7 点 / +0.19,低于门槛),valid `+20.0% / +3.18`(**−2.3 点 / −0.28,变差**)。
- 残差判据同样不满足:`cm20 | known` 的多头腿**毛超额**只有 train **+1.1%** / valid **+1.6%**(门槛是两段都 > +5%)。
  十个 partner 的残差毛超额全部在 −10.0% ~ +4.6% 之间,**没有一个过线**。
- 两个佐证:(i) 多头十分位重叠只有 0.153 / 0.182(随机是 0.10),顶 30% 重叠 0.368 / 0.401
  ⇒ **它和已知家族买的不是同一批票**,所以「没有增量」不是「它就是已知家族」;
  (ii) 已知家族顶 30% 池子里按原式信号分三档:train +5.7 / +13.6 / +16.6(单调,有序),
  valid +19.3 / +23.4 / +20.2(**非单调**,池子本身 +21.0)⇒ 在已知家族的池子里再按它排序,valid 上没有用。
- ⇒ **H11 的结论是负的,而且是干净的负**:**对只能做多的用户,这条因子相对已知家族(`cross_mean(day_std(Amt),30)` /
  `cross_max(day_std(Amt),9)`)没有增量 —— 既不能替代它(单独只有三分之一到一半),也不能叠加在它上面(valid 全部变差)。**

**为什么会这样(算术,不是实验)。** 两个信号 z 分数相加,权重 0.8 / 0.2,相关 ρ≈0.34,
夏普 3.46 与 1.48 ⇒ 组合夏普 ≈ (0.8·3.46 + 0.2·1.48) / √(0.8² + 0.2² + 2·0.8·0.2·0.34) ≈ **3.44**,
与 3.46 无差别。**要在一个夏普 3.5 的信号上加出东西,partner 的夏普要高得多、或者相关要低得多(≲0.1)。**
候选的夏普是 1.3~1.5、与已知家族相关 +0.34 ⇒ **结构上就不可能有增量**,换一个更好的 partner 也救不回来。
这条算术是「没有为更好的候选再花一次服务器运行」的理由(见 `orders/R3.md` 的「决定不做什么」)。

### 3. I 段逐年:候选的问题不是某一年崩,而是**从来没有哪一年赢过已知家族**

| 年 | 原式 `Ln` | `cm20` `Ln` | 已知家族 `Ln` | `known+0.5cm20` |
|---|---|---|---|---|
| 2018 | −1.8% | +7.3% | +17.3% | +20.0% |
| 2019 | +6.5% | +11.0% | +10.2% | +12.4% |
| 2020 | −1.1% | −0.9% | +6.6% | +5.9% |
| 2021 | −4.1% | +1.9% | +16.0% | +14.6% |
| 2022 | +3.2% | +11.4% | +24.6% | +22.0% |
| 2023(144 天) | −7.1% | +0.2% | +18.3% | +16.3% |

- 候选**六年里没有一年深亏**(最差 −0.9%),比原式(四年为负、最差 −7.1%)稳得多 —— 这是真的改进。
- 但**六年里五年输给已知家族**,只有 2019 赢 0.8 个点(噪声内)。
- `known + 0.5 cm20` 六年里 **2018 / 2019 赢、2020~2023 四年全输** ⇒ 组合的那点 train 改善来自 2018~2019,
  **2021 之后一致为负**,是典型的「加了个旧时代的东西」。这一条让「增量」的否定更结实:不是 valid 一段运气不好。
