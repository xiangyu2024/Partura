# F110_ret_fair_log — 批量扫描 s1 的综合(主研,2026-10-06)

口径:多头腿扣 15bp 净超额 `Lnet`(train / valid / utrain)+ 纯多头夏普 `Lshp`,半衰期按纯多头书在 train 上选。
基准 `k_known = cross_mean(day_std(Amt), 30)` = **+12.6 / +22.3 / +15.4%**,`Lshp` +1.78 / +3.46 / +2.22,换手 3.2%。
噪声 `Lnet` ±3 点、`Lshp` ±0.3。表 = `runs/F110_ret_fair_log/sweep_s1.json`(161 条有效 + base + bench)。
节点字母:A `day_last` · B `day_first` · C `div` · D `sub(·,1)` · E `log` · F `in_forward_valid_part` · G 量的差分 ·
H `in_mean_full` · I `in_stddev_full` · J 上阈 `add` · K `is_gt` · L 上腿 `in_sustain_stddev` · M `day_mean` ·
N 下阈 `sub` · O `is_lt` · P 下腿 · Q `day_mean` · R `sub(M,Q)` · S `abs_` · T 根 `mul`。

## 1. 它是什么(按函数定义逐层)

1. `day_first` / `day_last` = 当天分钟轴上**第一个 / 最后一个非 NaN 值**。`D = day_last(Close)/day_first(Open) − 1`
   = **开盘→收盘的日内收益,不含隔夜**。
2. `log(x) = log|x|`,`|x| ≤ EPS` 时为 NaN。`in_forward_valid_part(x)[j]` = **严格在 j 之前**最近一个「非 0 且非 NaN」的值
   —— 它**确实是前向填充**(上一轮 notes 说「不是前向填充」,按源码应纠正:它是「滞后一格、跳过 0 与 NaN」的前向填充)。
   于是 `G = log(Volume) − ffill(log(Volume))` ≈ `in_logchg(Volume, 1)`;副作用:Volume 恰为 1 的分钟(log = 0)被当成无效基数跳过。
3. `in_mean_full` / `in_stddev_full` 是**整天**的均值 / 标准差再广播回每一分钟 —— 不是滚动窗口。
   所以阈值是**日级常数**,且用到了当天后面的分钟(日频下不构成未来信息,但「日内因果」不成立)。
4. `K/O` 把 G 和 `H±I` 比,得到两张分钟掩码:**放量 +1σ** 与 **缩量 −1σ**。
5. `in_sustain_stddev(mask, Ret, 5)`:在每个触发分钟 j 取 `Ret[j:j+5]` 的标准差(**向前 5 分钟**,越过收盘用 NaN 补
   ⇒ 收盘前最后一分钟触发恰好得 0),非触发分钟 = NaN。
6. `M/Q = day_mean(·)` 对当天的触发点取 nan-均值;`R = M − Q`,`S = abs_(R)`。
7. 根 `T = D × S`。方向 sg = −1 ⇒ **多头 = 日内下跌 × |放量后波动 − 缩量后波动| 大**。
   即「**1 日日内反转,按一个日级波动尺度放大**」。
   **名字与定义不一致**:`ret_fair_log` 里既没有 fair value,收益也没取对数(`log` 只作用在 Volume 上);
   「log」属于成交量支,「ret」是比值减一。`in_sustain_*` 的 "sustain" 读起来像「持续」,实际是**触发型 + 向前取窗**。

## 2. 预测力在哪

**原式对纯多头是零**:`v_base` −0.0 / −0.6 / −0.2%,`Lshp` −0.03。毛超额 +7.8%、换手 10.5% ⇒ 成本约 8.0%/年正好吃光。
`LS` 夏普 +2.76、底腿 −43.3 / −46.8% ⇒ **钱全在空头腿**(做空昨天日内上涨且波动大的票),纯多头拿不到。

**承重的不是成交量机器 —— 整棵子树是惰性的。**
`abl_E`(删 log)/ `abl_G`(删差分)/ `abl_J`(删上阈加)/ `abl_K`(删 is_gt)/ `abl_N` / `abl_O` 的 utrain 落在 **−0.3 ~ +0.5%**,
与 base −0.2% 同在噪声内。更狠的证据:`sub_E_abs_`、`sub_E_pow_2`、`sub_G_add`、`sub_G_mul`、`sub_F_in_boxcox`、
`sub_F_in_demean`、`abl_E`、`abl_G` 给出**逐位相同的三段数字 −0.7 / +1.1 / −0.2%** ⇒ 把「量的异常变化」换成「量的异常水平」
掩码集合不变 ⇒ **F/G 的差分在效果上是 no-op,掩码读到的只是「当天成交量最大的那些分钟」**。

**唯一「一换就塌」的是 I = `in_stddev_full`,但塌法是算术退化,不是信息。**
`abl_I` −62.9%、换手 83.4%、cov 0.19 ✗;`sub_I_in_max` −80.9%(cov 0.19 ✗);`sub_I_in_demean` −57.2%(cov 0.43 ✗)。
删掉 σ 后两条阈值都退成均值 ⇒ 上下两腿取到几乎同一批分钟 ⇒ `R = M − Q` 变成**相减抵消后的数值噪声**。
三条都没过 cov 门槛,按规矩不算数。

**多余的节点**:`abs_`(`abl_S` / `sub_S_neg` −2.8%,只差 2.6 点 ≈ 噪声 ⇒ 符号本来没被用上);
两条腿互为冗余(`abl_L` −1.6%、`abl_P` −2.3%);`sub_H_*`、`sub_J_*`、`sub_N_*` 全在 ±0.6 点内。

**可互换的叶子**:价格字段完全无差别 —— `fld_Open_Low` / `fld_Open_High` / `leaf_Open_close` / `leaf_Close_vwap` 的
ρo = 0.99~1.00、Δ ≤ 0.6 点 ⇒ D 只需要「今天的日内收益」。流量字段 `leaf_Volume_amt` ρo 0.99。
**用户提示的那一类互换成立且方向有利**:`leaf_Ret_amtchg`(机器里的 `Ret` → `in_pct(Amt,1)`)ρo 只 0.41、ρk 0.17,
`Lnet` +1.6%、**毛超额 +9.3% > base 的 +7.8%** ⇒ 换成「量的变化率」得到的是**另一条因子且毛额更高**;
`leaf_Ret_volchg` +0.8%、`leaf_Ret_logvol` −1.2%、`leaf_Ret_ret5` −2.5%。

**窗口没有平台**:L 的 3/5/10/15 = −1.6 / −0.2 / +0.9 / +0.6;P 的 3/5/10/15 = +1.9 / −0.2 / −0.8 / −0.2。
全幅 ≤ 3.5 点,落在噪声里 ⇒ 5 分钟是任意的,**不存在一个有邻域的真效应**。

**`div` 扔掉的价格水平才是多头腿的来源。**
`abl_C`(删 div ⇒ 价格水平 × S)+4.4% / `Lshp` +0.56 / 换手 2.1%;`only_C_R` +4.4%;`sub_C_mul` +4.9%;
`nosc_B_day_centroid` +4.3%(ρo ≤ 0.20、ρk 0.49~0.54)。而 `iso_A = day_last(Close)` 单独 **+6.0% / Lshp +0.85 / 换手 1.1%**
—— 是全表最好的 isolate,也就是「低价」这一个已知效应。`iso_C`(= D 本身)−1.9%,`only_T_R`(= S 本身)−2.0%,
`iso_M` −7.1%、`iso_Q` −7.3%(事件后波动水平本身是**负**因子),`iso_R` −5.2%。

**平滑是这条因子唯一真实的杠杆,而且 100% 是省成本。**
`mem_ema30`:毛超额 **+7.9%** ≈ base 的 +7.8%,换手 10.5% → 3.3% ⇒ 净 −0.2% → **+5.4% / Lshp +0.92**;
`mem_ema60` 毛 +6.4% / 换手 1.8% → +5.0%;`mem_decay_linear60` 毛 +8.3% / 换手 4.0% → +5.3%。
⇒ **毛额一点没涨,净额全是换手**;纯平滑的天花板 ≈ +5.4%,不到 `k_known` 的四成。
`cross_zscore` 是全表最差的记忆(−12.3 ~ −19.5%):用自身 5~60 日历史标准化,把承载信号的持久水平删掉且换手翻倍。
`cross_min` 让方向翻转(sg = +1),`cross_max` / `cross_stddev` ≈ 0。
附带发现:base 在 hl 20 下只有 10.5% 换手**本身是重尾假象** —— 先 `cs_rank` 再平滑(`rk`)把换手推到 17.3%、净额 −7.3%,
说明 EMA 记的是**少数极端日的峰值**而不是水平(F103 的教训在这里复现);`cs_winsor` 先缩尾(`win`)也救不回来(+1.7%,换手 11.5%)。

## 3. 在市场的哪儿、什么时候有效

**流动性是最锐的一刀,而且与已知族的性质完全不同。**
20 日成交额五档的**段内**净超额:base −5.3 / −6.7 / −2.6 / −6.1 / **+1.5%**;`mem_ema30` −2.1 / −2.9 / −1.9 / −0.1 / **+5.0%**
(`mem_decay_linear60` +6.4%、`mem_ema10` +6.0%、`mem_ema5` +5.6%)⇒ **只在最流动的那一档里选得出股票**,而那一档的
段等权超额是 **−17.8%**(全解剖最差的一段)⇒ 它是「在输家段里挑赢家」。
对照 `k_known` 的段内:−4.1 / −5.3 / −8.2 / −5.2 / +2.5%,而它的多头书**超配最不流动的一档 +80.3%**(该段等权 +15.1%)
⇒ **已知族的 +15.4% 几乎全是段位倾斜,不是段内选股**。这是本轮最有价值的一条:两者的工作方式不同,
所以「段内选股」这一面是此因子相对已知族唯一可能的增量来源。
**推论(可检验)**:若机制是「段内选股」,按流动性秩加权(保留幅度)应当把段内 +5% 搬到全市场;
而分桶中性(排名)应当**不**提高净额,因为排名本身就把幅度删掉了。

**板块:倒贴最严重的一处。** 沪主板 +1.3 / 深主板 +2.2 / 创业板 −4.9 / **科创板 −10.6%**(`mem_ema30` +5.8 / +9.2 / +2.9 / −11.0%),
而全市场多头书**超配科创板 +11.4%(mem +10.5%)** ⇒ 它把仓位推进唯一亏钱的板块。
原因推断:科创板 20% 涨跌幅、合格投资者门槛、几乎没有零成交分钟 ⇒ 「当天 +1σ 放量」是常态,事件后 5 分钟波动整体抬高,
S 的截面含义被破坏;同时宽幅限价下 1 日日内反转本身更弱。**推论**:按价格水平分桶中性(科创 / 创业板集中在高价档)
应当把这笔倒贴抹掉而不伤水平;若抹不掉,说明问题不在板块而在波动水平。

**冻结盘口段是全解剖最大的一个数,而且已知族在那里是负的。**
近 15 日有封板 / 停牌的 6.5% 股票(段等权 **−67.4%**):base 段内 **+19.2%**、`mem_ema30` +19.7%、`mem_mean30` +24.2%、
`mem_ema10` +24.1%、`iso_A` +24.5%,而 **`k_known` −10.9%**。但多头书对该段只超配 +1.3% ⇒ **这块信息没被用上**。
机制推断:封板 / 停牌时 `Ret` 多数分钟恰为 0、Volume 冻结 ⇒ 两腿的事件后波动都 ≈ 0 ⇒ `S ≈ 0`、`D ≈ 0`,
因子被推到截面中间;所以 +19% 来自**部分**冻结的票,S 实际在量「封板松动了多少、还有多少真实成交」。
**推论**:`day_flat_ratio(Close)` 单独应当能拿到这 +19% 的相当一部分;段内优势应集中在 flat_ratio 的**中间档**而非极端档;
对 flat_ratio 分桶中性或显式倾斜,应当把多头书的超配从 +1.3% 推上去。

**其它段**:流通市值五档 base −3.7 / −1.8 / +0.0 / −3.4 / −2.3%、`mem_ema30` +2.7 / +3.5 / +4.3 / +2.0 / +1.1%
⇒ **没有市值故事**,但书超配最小一档 +8.0%(该档 base 为负)。价格五档 base +3.7 / −2.4 / −4.2 / −1.0 / −0.4% ⇒ 只在最便宜一档为正;
对照 `iso_A` 段内 −4.3 / −18.0 / −29.0 / −27.0 / −17.2% 且超配最便宜一档 **+79.9%** ⇒ **`iso_A` 是纯价格倾斜、零段内技能,
而本因子相反**。次新(上市 < 250 日,7.1%,段等权 −28.7%)base +2.6%、`k_known` +8.6% ⇒ 无特殊性。

**时间 / 状态**:年度 base −1.8 / +6.7 / −1.0 / −4.0 / +3.3 / −6.9%(**无一年稳定**);`mem_ema30` +3.9 / +10.7 / −1.8 / +2.6 / +13.5 / +1.8%
(6 年里 5 年为正);`k_known` 六年全正 +6.7 ~ +24.7%。状态:base 市场波动高于中位 **+5.6%** vs 低于中位 **−5.9%**;
缩量 +3.0% vs 放量 −4.1%;市场近 20 日上涨 +2.1% vs 下跌 −2.2%;`mem_ema30` 同向更强(波动 +9.7 vs +1.1;缩量 +7.1 vs +3.2;上涨 +9.0 vs +1.6)。
原因推断:它是「1 日反转 × 波动尺度」—— 反转在**过度反应相对漂移更大**(高波动)、且**没有放量趋势**(放量 = 动量制度)时才赚钱。
**推论**:把尺度换成显式的 `day_std(Ret)` 应当保留同样的制度画像;把尺度除掉当天的**市场**波动(相对波动)应当把高低波动段的差距压平而不掉水平。

## 4. 相对已知成交额族有没有增量:没有

- ρk(base) = **+0.35** ⇒ 不是已知族的改写,这一点成立。
- **叠加行是最干净的否定**:`ov_p025` +13.4% / `ov_p05` +12.6% / `ov_p10` +11.8% / `ov_m025` +11.3% / `ov_m05` +9.0% / `ov_m10` +6.2%,
  全部低于 `k_known` 单独的 +15.4%,且**两个方向都随 |权重| 单调变差** ⇒ 加进去只会减分。
- 残差 / 分桶:`res_known` −7.7%、`res_liq` −7.6%、`bk_known` −7.2%、`bk_liq` −7.0%(`bk_*` dist 0.20 ✗ 不算数)。
  **必须带上的保留**:这四条都先做了截面排名,而 `rk`(只排名、不中性化)单独就是 −7.3%、换手 17.3%
  ⇒ **这 −7% 是「排名」的锅,不是中性化的**。诚实版本:幅度一删,这条因子的多头腿就一文不值;
  在此之上中性化已知族不再改变任何事。另一面:`res_known` 的多头腿**毛**超额仍有 **+5.3%**,是 17.2% 的换手把它做成 −7.7%
  ⇒ 「残差 + 平滑」是唯一还没被成本污染的增量测法(本轮没人测过,已写进假设 `h_liq_res_ema` / `h_base_res_ema`)。

## 5. 改进方向(落成 `studies/F110_ret_fair_log/hypo.yaml`,36 条)

1. **删掉成交量机器,保留「日内反转 × 显式波动尺度」再平滑**,并配一条「完全不乘尺度」的对照
   (`h_cvx_ema15/30`、`h_dvol_ema15/30`、`h_dvol_dec30`、`h_cube_ema30`、`h_d_ema30`)。
2. **把 `div` 扔掉的价格水平放回来**(`h_px_vol_ema30`、`h_px_cvx_ema30`)。
3. **尺度换成同类的量**:量的变化率波动、基尼、重心、相对市场波动(`h_dvolamt_ema30`、`h_dgini_ema30`、`h_dcent_ema30`、`h_drelvol_ema30`)。
4. **事件后的「有向反应」而不是「波动」** —— 机器唯一还没被否定的读法(`h_evt_mean_up/dif/amt`、`h_evt_vol_ratio`、`h_evt_win30`)。
5. **直接量净买压**,机器想估却估不到的东西(`h_sign_amt`、`h_money_clock`、`h_d_x_sign`、`h_posratio_rev`)。
6. **流动性段**:保留幅度地加权 vs 分桶中性 vs 残差后平滑(`h_liq_w_mul`、`h_liq_gate_rev`、`h_liq_bkt`、`h_liq_res_ema`、`h_base_res_ema`)。
7. **冻结盘口段与板块倒贴**(`h_flat_alone`、`h_flat_x_rev`、`h_unfroz_x_rev`、`h_flat_bkt`、`h_flat_tilt`、`h_px_bkt`)。
8. **幅度 vs 秩**:把只对空头有用的截面尾部换掉(`h_masktop_ema`、`h_base_masktop`、`h_winsor_ema`)。
