## S1_long:把平滑写进表达式之后,多头腿站住了;而且「平滑」和「结构」两份功劳可以分开量

(阶段 `S1_long`,8 个变体,`run` exit 0;原始读数在 `notes/F110_ret_fair_log/results/R2.md` 第 1~8 项。
口径:方向与半衰期在 train 上定;`Ln` 多头腿净超额、`Lshp` 纯多头夏普、`Lg` 多头腿毛超额、`LTO` 多头日换手、
`LS` 扣费多空夏普、`sh` 空头腿毛超额。噪声尺度:`Ln` ±3 点、`Lshp` ±0.3、`LS` ±0.3。数字一律写 train / valid。)

### 问题

R1 在 numpy 里发现:把盒式平滑 `cross_mean(·, 20)` 套在原式(或它的提纯版)外面,再叠口径里的 `EMA20`,
多头腿净超额能从原式的 −0.0% / −0.6% 抬到 +4.9% / +7.4%。这一阶段把它们写成**引擎里的表达式**去验,
同时问:长平滑之下权重支路还重要吗(H2)?砍掉最近 10 天会怎样(H15)?它是不是就是普通的 20 日反转(H17)?

### 结果

**桥是通的(Q1 canary 四项全过)。** `w_cmD20` 固定 hl20 的多头腿 train +5.2%(numpy 预测 +4.9%)、
valid +7.3%(预测 +7.4%);`w_cmT20` +4.2%(+3.6%)/ +5.7%(+5.7%);
`rank corr(w_cmD20, v_base) = +0.642`、`rank corr(w_cmT20, v_base) = +0.896`,**与 numpy 预测精确吻合到小数点后三位**。
⇒ numpy 的 `roll_mean` 与引擎的 `cross_mean` 是同一件事,R1 的 D 段读数可以当真。

### 解读

**1. 本阶段最重要的新事实:权重支路**不是**死重 —— R1 的 H2 要改写。**
同一个窗口 20、同一个 hl20 下,四种权重的多头腿净超额是
`S`(原式权重)+4.2% / +5.7% < 无权重 +5.2% / +7.3% < `day_std(Ret)` +7.5% / +9.5% ≈ `|D|` +7.9% / +8.1%。
**`S` 是四者中最差的,而且比「干脆不要权重」还差 1.0 / 1.6 个点。** 跨度 train 3.7 点、valid 3.8 点,两段同向、超出噪声带。
R1 的 C 段(固定 hl20、纯 EMA)已经看到「换成 `|D|` 每一项都更好、把波动尺度除掉就更差」;
本阶段在长平滑之下把这件事量得更干净:**乘一个波动尺度是载重结构(真 alpha),而用成交量事件机器去估那个尺度是纯损失**。
H2 的正确写法是「**事件机器不带信息,但它所在的那个位置(波动尺度)带信息**」,
而不是原来那句「整条权重是死重」。提纯的终点因此不是 `cross_mean(D, 20)`,而是 `cross_mean(mul(D, abs_(D)), 20)`。

**2.「平滑的功劳」和「结构的功劳」可以分别量出来,而且两者都是真的 —— 但来源完全不同。**
全部在 **hl20、窗口 20** 这个固定条件下比(满足 playbook §6.1 的要求):

| 这一步改了什么 | `Ln` 变化 tr/va | `Lg` 变化 tr/va | `LTO` 变化 | 机制 |
|---|---|---|---|---|
| 原式 → 原式 + 盒式 20(`v_base`→`w_cmT20`) | **+4.2 / +6.3 点** | −1.2 / +0.8 点 | 10.6% → 3.4% | **毛超额基本不变,换手砍到三分之一 ⇒ 纯粹是省成本** |
| 权重 `S` → `\|D\|`(`w_cmT20`→`w_cvxD20`) | **+3.7 / +2.4 点** | +3.8 / +2.4 点 | 3.4% → 3.6% | **换手不变,毛超额真的变高 ⇒ 真 alpha** |

⇒ 归因必须这么写:`w_cvxD20` 相对原式的 +7.9 / +8.7 个点里,
**约一半(+4.2 / +6.3)来自平滑(省成本),约一半(+3.7 / +2.4)来自结构(把含噪的 `S` 换成 `|D|`,毛超额真的更高)**。
这同时**坐实了 H16**(盒式平滑胜过长 EMA 的那部分优势确实纯粹是换手:毛超额没涨,`LTO` 掉了三分之二),
也说明**不能把全部改进都写成「来自平滑」** —— 结构那一半有独立的毛超额证据。

**3. H15 被否定:多头信息不在 lag 20~40。** `w_cmD20lag10`(显式砍掉最近 10 天)比 `w_cmD20`
低 1.6 / 1.9 个点(`Lg` −1.6 / −2.0),而 `LTO` **完全相同(3.6% = 3.6%)**。
两个子判据(「毛超额不低」+「换手更低」)只满足前一半,而且换手这一半是以 0 分满足的 ⇒
**砍掉最近 10 天纯损失**,最近 10 天是带信息的。R1 lag profile 里「多头腿在 lag 20~40 才转正」那个读数
(train 侧 −1%~−5%、valid 侧 +1.3%~+6.9%,两段不同向)**不成立,是单 lag 读数的噪声**。
这一条让 R1 那个「两条腿住在不同持有期」的说法要收窄:**空头腿是 1~3 天快反转这一半是确立的**
(lag 0 的 `sh` +43.7% / +39.1%,lag 5 只剩 +6.0%,而且本阶段也印证了 —— 盒式平滑把 `sh` 从 +43.3% 压到 +26~29%);
**「多头信息住在远端 lag」这一半被否定** —— 多头腿要的不是「等几天」,而是「把 20 天平均起来」。

**4. H17 被否定:它不是教科书上的 20 日反转。** `rank corr(w_cmD20, w_cmDcc20) = +0.669`,远低于事前判据 0.9;
`w_cmD20` 与 `ctl_mom20` 的 rank corr 只有 **−0.292**、与 `ctl_rev1` 只有 **+0.020**、与 `w_known30` **+0.343**
⇒ 它不是任何单一已知暴露换了个写法。收盘到收盘版 `w_cmDcc20` 在 train 上低 4.1 点(+1.1% vs +5.2%)、
valid 上低 1.2 点(+6.1% vs +7.3%)—— **train 侧超出噪声带、valid 侧在噪声带内,两段不同向**,
所以「只取日内那一段是真增量」(H5)只能算**合理但未坐实**,不能当卖点写。
本阶段给 R3 留的活就是用凸化版的收盘到收盘对照(`x_cvxcc20`)把这一问判死。

**5. 用户口径与多空口径在这里是**对立**的,这解释了原式为什么长这样。**
从 `v_base` 到 `w_cvxD20`:多头腿 −0.0%→+7.9%,而多空夏普 +2.77→+2.35、空头腿毛超额 +43.3%→+26.4%。
**盒式平滑把那个最值钱(但用户卖不出去)的 1~3 天空头反转毁掉了,换来多头腿**。
原式之所以是「多空 2.76 / 多头 0.078」的长相,正是因为它的参数(hl 由多空口径挑、没有日轴平滑)是为空头腿优化的。
⇒ 对只能做多的用户,**原式的结构选择本身就是错的方向**,这是报告的一个结论,不是一句修辞。

**6. 顶档(Q10)还是会回落,但比原式好。** 20 分位剖面:`w_cmD20` train Q10 +8.5% 高于 Q7~Q9(+6.1/+6.4/+8.1,**没有回落**),
valid Q10 +11.1% 低于 Q7~Q9(+12.2/+12.4/+13.1,**仍有回落**);原式两段都回落(train Q10 +8.6% < Q9 +10.1%,
valid +8.6% < Q7~Q9 的 +10.7/+12.3/+12.0)。⇒ H6(多头端没有可信的排序能力)**在候选上被削弱但没有被推翻**:
买第 7~9 档仍不比买顶档差。对只能买前 10% 的用户,这是一个真实的容量/择券提醒,要进 `11_risks.md`。

**7. 逐年:候选比原式稳得多,但仍有两年打平。** `w_cmD20` 逐年 `Ln` +8.8 / +10.7 / −0.7 / +1.5 / +11.4 / +0.3
(原式 −1.8 / +6.5 / −1.1 / −4.1 / +3.2 / −7.1;已知家族 +17.3 / +10.2 / +6.6 / +16.0 / +24.6 / +18.3)。
⇒ 候选六年里没有一年深亏,但 2020 / 2021 / 2023 三年基本是零;已知家族**每年都在 +6.6% 以上**。这是「增量」那一问的另一个角度。

**8. 窗口 20 vs 60 有警报,是 R3 的第一件事。** `w_cmD60` 在 train 上拟合到 hl5、给 +6.8%,
带到 valid 只有 +3.6%(`Lshp` +0.99→+0.44);固定 hl20 下 train +4.1% 也低于 `w_cmD20` 的 +5.2%。
**窗口换一档就掉了一半,这不是一个稳的邻域。** 而三个最好的变体(`w_cmDsig20`、`w_cvxD20`、`w_cmD20`)
**全部把半衰期拟合到了官方网格的上限 20,而且在固定半衰期表上从 hl10 到 hl20 还在上升**
(`w_cvxD20` +6.1%→+7.9%,`w_cmDsig20` +5.2%→+7.5%)⇒ **EMA 这个杠杆已经顶到天花板,还没见到拐点**。
再要更长的平滑只能写进表达式(更大的盒式窗口、或者两层 `cross_mean` 叠成三角窗)。
这两件事(窗口邻域、平滑还能不能更长)直接决定留出段那一次读谁,所以 R3 就是去拿它们的。
