### 2.2 树的语义(出处:`02_operators.md` / `03_decomposition.md`,12 个算子逐个读过源码)

`r5 = Close/in_delay(Close,5) − 1`(每天 236 个值,**不跨日**);`q95`/`q05` = 当天 **1 分钟**收益 `Ret` 的分位数:

```
up_mean = Σ r5·1[r5>q95] / (#+1e-6);  up_ratio = up_mean / (q95 + 1e-6)
dn_mean = Σ|r5|·1[r5<q05] / (#+1e-6); dn_ratio = dn_mean / (|q05| + 1e-6)
gap_d   = up_ratio − dn_ratio;         因子 = nanmean(gap_d, 过去 20 日)
```

源码里和名字不一样的地方(**后面所有推理的地基**):
1. `in_delay(Close,5)` 不跨日;一天 236 个 `r5`。
2. `Ret` 的**第一根恰好是 0**(100% 股票-日)→ 241 根全有值,0.95 分位落在整数位、**没有插值**;
   `0 < q95 < 1e-4` 的占比 = 0.0000。**「全天上涨分钟 ≤ 12 根 ⇒ q95 ≡ 0」是精确开关。**
3. 四个 1e-6 干两件不同的事:计数分母上的两个是空操作(H10 前半);**分位数分母上的两个把封板日变成 10³~10⁵**。
   ⚠ **第 4 轮改写**:后者只是**幅度**开关,不是排序开关(§2.4)。
4. 阈值与分子不在同一尺度,**不是教科书的 ES/VaR 比**(规则日每侧约 34~37 根超阈 = 236 的 15%)。
5. `ts_mean(·,20)` 与 `cross_mean(·,20)` 同一个内核;**nanmean 不截尾**,窗口里一个 10⁴ 的日子占 Σ\|gap_d\| 的 99.9%。
6. `abs_` 只在下侧,不是空操作(去掉它 ε 的方向会错)。
7. **没有任何截面算子、没有量/额字段** —— 只看价格路径形状。
