### 2.2 树的语义(出处:`02_operators.md` / `03_decomposition.md`,12 个算子逐个读过源码)

四个零件(`r5 = Close/in_delay(Close,5) − 1`,每天 236 个值;`q95`、`q05` = 当天 **1 分钟**收益 `Ret` 的分位数):

```
up_mean = Σ r5·1[r5>q95] / (#+1e-6);  up_ratio = up_mean / (q95 + 1e-6)
dn_mean = Σ|r5|·1[r5<q05] / (#+1e-6); dn_ratio = dn_mean / (|q05| + 1e-6)
gap_d   = up_ratio − dn_ratio;         因子 = nanmean(gap_d, 过去 20 日)
```

源码里和名字不一样的地方(**这些是后面所有推理的地基**):

1. `in_delay(Close, 5)` **不跨日**:每天前 5 根 NaN,一天只有 236 个 `r5`,开盘第一根不和昨收比。
2. `Ret` 的**第一根恰好是 0**(x1 实测 100% 股票-日,= 首根收 / 首根开 − 1,**不含隔夜**)→ 241 根全有值,
   0.95 分位落在整数位(第 229 小),**没有插值**。`q95` 要么恰好 0,要么至少一个 tick;`0 < q95 < 1e-4` 的占比 = 0.0000。
   **所以「全天上涨分钟 ≤ 12 根 ⇒ q95 ≡ 0」是一个精确的开关,不是近似。**
3. **四个 1e-6 干两件不同的事**:计数分母上的两个只在「一次都没超阈」的日子起作用(把 0/0 变 0;上侧 0.43%、下侧 0.61% 的股票-日)
   —— 实质是空操作(**H10 已成立**);**分位数分母上的两个才是整条因子的开关**:分位数为 0 时比值从 O(1) 跳到 10³~10⁵。
4. **阈值与分子不在同一尺度**:阈值/分母是 1 分钟收益的分位数,分子是 5 分钟收益的超阈均值。**它不是教科书的 ES/VaR 比**:
   规则日每侧约 34~37 根(236 的 15%,不是 5%)超阈,比值中位数 1.88 / 1.76(高斯随机游走理论值 ≈ 1.8)。
5. `ts_mean(·,20)` 与 `cross_mean(·,20)` 是同一个内核(`rolling_reduce` + `nanmean_last`,左补 NaN,因果);**nanmean 不截尾**,
   窗口里一个 10⁴ 的日子就占 Σ|gap_d| 的 99.9%。停牌日 `Ret` 全 NaN → 当日 NaN,被 nanmean 跳过。
6. `abs_` 只在下侧,不是空操作:去掉它下侧分子分母同时变号(比值不变),但 `add(q05, 1e-6)` 的 **ε 方向会错**。
7. **没有任何截面算子、没有量/额字段** —— 只看价格路径形状。所以与成交额家族没有结构通道(实测 rank 相关 **−0.03**)。
