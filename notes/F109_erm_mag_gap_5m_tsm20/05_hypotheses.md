## 判决(主研第 1 轮,2026-10-04;证据来自 S0 + x1,**引擎口径的复核在 S1_S2 里,结果还没读**)

上面两张表的「判决」列留空是因为上一位研究员在填之前被换下了。这一节补上截至第 1 轮的状态。
完整的证据与出处见 `state.md` §4(同一张表,带「还差什么才能定」一列);原始数字在 `06_baseline.md` 与 `07x_1_anatomy.md`。

**已定,不要再花实验(3 条):**

- **H3 成立** —— 空头腿被「次日一字开盘买不进」抬高:换成原始标签,多空夏普 2.55 → **0.35**(train)、3.46 → 2.47;
  空头腿毛超额 +34.4% → +18.1%。Q1 的买不进占比 1.0%,全市场 0.26%。**多头腿几乎不受影响**(−4.6% → −5.0%)——
  这正是「选拔只看多头腿」的理由之一。(x1 §4)
- **H8 成立** —— `ts_mean(·,20)` 是事件记忆而非杠杆:窗口 5/10/40/60 的多头腿全在 −5.4%~−4.1% / +0.1%~+1.0%;
  带符号的极值记忆(20 日 max+min)与原式 rank 相关 0.94;多头口径的半衰期顶在可选上界 20。(x1 §5)
- **H10 成立** —— 计数分母上的两个 ε 是空操作(只在「一次都没超阈」的日子起作用:上侧 0.43%、下侧 0.61% 的股票-日,
  且这些日子 `gap_d` 恰为 0);分位数分母上的两个才是整条因子的开关。(x1 §2)

**改写(2 条):**

- **H5 改写** —— 方向对(Q10 里 15.6% 窗内有负爆炸、6.1% 有封跌停),但**机制说错了**:负向爆炸不是封跌停,
  而是**「一路爬升到涨停」**(`gap_d < −20` 的日子当日收益中位数 **+9.97%**;该类里 `gap_d` 为正的只占 6.9%)。
  爆炸的符号区分的是「秒封」与「爬上去」两种涨停,不是涨停与跌停。
  另外 Q6~Q9 的 +5%~+8% 不是「低价不活跃股」,画像是沿 Q1→Q9 单调的低换手 / 低波 / 较大市值。**改写后并入 H11。**(x1 §2、§3)
- **H1 部分成立,事前预测被证伪一半** —— 爆炸确实是空头腿最锋利的那一段(只留爆炸日:多空 3.45 / 3.39、Q1 −30.8%),
  **但全截面的排序主要是规则部分**:原始面板上原式与「去掉退化日」rank 相关 **0.87**、与「只留爆炸日」只 **0.45**
  (92.8% 的股票窗口里没有爆炸日)。事前写的「ε 加地板后排序大变(相关 < 0.5)、空头腿大幅下降」和
  「只留爆炸日与原式相关 > 0.9」**都不对**:ε → 1e-3 之后相关还有 0.75,rank IC 反而更高(0.0395 / 0.0435 vs 原式 0.0306 / 0.0298)。
  **待 S1 `a_eps3` / `a_sig` 的引擎口径定最终措辞。**(x1 §5)

**被支持但还没坐实(4 条):**

- **H2 成立(限于空头腿)** —— Q1 里 34.8% 窗内有正爆炸;事件研究「窗内有正爆炸」次日年化超额 −55.6% / −49.0%;
  对「上/下侧退化天数」中性化后空头腿 +17.3% → −1.6%。(x1 §3、§6)S1 `a_evt` 只作朴素计数的确认。
- **H4:空头腿上成立,多头腿上无关紧要** —— 全套控制(最大/最小涨幅 + 退化天数 + 换手 + 波动 + 价格 + 市值)R² 只 0.169,
  但空头腿 +17.3% → **−0.5%**;**多头腿中性化前后都是负的**(−3.5% → −1.4%)。
  R² 低而空头腿全没的原因:十分位书只看两端,而两端正是事件票与高换手票所在的地方。(x1 §6)
- **H6 部分成立,而且它预测的那一条被否定了** —— 「去掉退化日」与 `day_skew(Ret)` 的 20 日均值 rank 相关 0.43(接近事前说的 0.5);
  但事前写的「**如果有多头腿,就在这里**」—— 不在:去退化日的多头腿只有 −0.7% / +3.5%(纯多头夏普 −0.11 / +0.76)。(x1 §5)
- **H12 支持** —— σ 归一的尾部差 rank IC 0.0459 / 0.0574、20 日最大单日涨幅 0.0471 / 0.0621,**都高于原式** 0.0306 / 0.0298:
  朴素等价物比这棵树本身更强。待 S2 `b_skew1/b_skew5/b_max20` 对 `a_sig/a_eps3` 的引擎相关定。(x1 §5)
- **H13 强烈支持(numpy 口径)** —— 规则日 `up+dn`:+3.6% / +11.7%、纯多头夏普 0.46 / 1.60;
  而 `ctl_price` 自己当因子:+3.9% / +11.3%、0.56 / 1.59 —— **几乎一模一样**。待 S2 `b_lvl` / `b_lvlq` 的中性化表定。(x1 §5)

**机制已确立、修正效果未验证(1 条,这是本因子的关键路径):**

- **H11** —— 两种爆炸之后都大幅跑输(正爆炸 −55.6% / −49.0%,负爆炸 −35.1% / −33.1%),上、下两侧单独的方向**相同**(都是 −),
  而原式的 `sub` 做了两件对多头腿不利的事:丢掉两侧共同的水平(规则日 `up+dn` +3.6% / +11.7% vs 差值 −0.7% / +3.5%),
  并把负爆炸的票送到多头端(Q10 里 15.6%,按 −35.1% 估算拖掉约 **5.5 个点**,正是 Q10 −3.6% 与 Q9 +5.0% 差距的大半)。
  **`a_sum`(只把 `sub` 换成 `add`)是整条因子唯一可能走到「提纯」结论的路径。**
  判据(工单 R1 已写明,按**同一半衰期 hl 20** 比,避免把平滑算成结构):
  train 多头腿净超额 **≥ +5%** 且 Q10 不再为负 → H11 成立且可交易,进 S3;**< +3%** → 改写为「机制对、但修不出钱」,进读留出段。

**未验证(2 条):**

- **H7** —— 待 S1 `a_1m`(分子换 1 分钟)与 `a_q5`(阈值/分母换 5 分钟自身分位数)。先验:同批 F106 与它 rank 相关 0.44。
- **H9 / H14** —— 这是选拔口径下的**决定性问题**,x1 只给了第一眼:家族 `cross_mean(day_std(Amt),30)` 自己 +12.6% / +22.3%(1.78 / 3.46);
  加 0.3 份原式 **+10.6% / +20.0%**(拖累)、加 0.3 份规则版 +10.8% / +19.9%(拖累)、加 0.3 份「只留爆炸日」**+13.7% / +23.1%**(+1.1 点)。
  旁证:条件 IC 按成交额单调上升(最不活跃 0.0056 → 最活跃 0.0398),而家族的多头端在**最不活跃**那一组。
  **缺的是配对差、标准误、残差多头腿** —— 那 +1 个点是信号还是噪声现在说不清。工单 R1 的 x2 就是为这条设计的:
  配对差 |t| < 2 → H14 成立(增量在噪声内);t ≥ 2 且增量 ≥ +2 点且 train/valid 同向 → 「排除事件票」这个用法是真的,带进留出段。
