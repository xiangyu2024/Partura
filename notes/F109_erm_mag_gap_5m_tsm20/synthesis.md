主研 Opus 5,2026-10-05。口径:**只看多头腿扣 15bp 净超额 Lnet / 纯多头夏普 Lshp,半衰期按纯多头书选**。
基准 `k_known = cross_mean(day_std(Amt), 30)`:train/valid/utrain **+12.6% / +22.3% / +15.4%**,Lshp **+2.22**。
原式 `v_base`:**−4.6% / +0.2% / −3.2%**,Lshp **−1.24**,LTO 1.4%,多空 LS +2.55/+3.46,空头腿毛 +17.3%/+15.9%,ρk +0.03。

## 1. 它是什么(按算子定义逐层)

SSA 记号(本地重跑 `partura/decompose.py` 的后序编号,与 `R1_propose_draft.txt` 的 why 字段逐一对得上):

```
A = in_delay(Close,5)   B = div(Close,A)   C = 1   D = sub(B,C) = r5(5 分钟收益,前 5 根为 NaN)
E = day_quantile(Ret,0.95) = q95        P = day_quantile(Ret,0.05) = q05   ← 都是**1 分钟**收益的分位数
F = is_gt(D,E)  G = 0  H = select_where(F,D,G)  I = day_sum(H) = Σ r5·1[r5>q95]
J = day_sum(F) = #[r5>q95]      K = 1e-6   L = add(J,K)   M = div(I,L) = up_mean
N = add(E,K)   O = div(M,N) = up_mean/(q95+1e-6)
Q = is_lt(D,P)  R = abs_(D)  S = select_where(Q,R,G)  T = day_sum(S)  U = day_sum(Q)  V = 1e-6
W = add(U,V)   X = div(T,W) = dn_mean(**幅度**)   Y = abs_(P)   Z = add(Y,V)   AA = div(X,Z)
AB = sub(O,AA) = gap_d        AC = ts_mean(AB,20)
```

名字与定义不一致的四处:

1. **`erm_mag_gap_5m` 的「5m」只在被测量上,阈值是 1 分钟量。** 被比较的 `D` 是 5 分钟收益,阈值 `E/P` 是当天
   **1 分钟**收益的 95/5% 分位。这不是笔误而是承重件:把口径改自洽(`leaf_Ret_ret5`,阈值也用 5 分钟)
   **−6.3%**,比原式更差;本轮再从另一端验证(`h_c_r1_tail20`)。
2. **「mag(幅度)gap」只在上侧是带符号的收益、下侧是 `abs_` 后的幅度。** 两侧不对称。把下侧的 `abs_` 去掉
   (`abl_R`,用带符号 r5)**+3.4%** —— 幅度化是损害,不是必需。
3. **两个 `1e-6` 不是同一个东西。** `L = J+1e-6`、`W = U+1e-6` 完全惰性:`sub_L_sub`、`sub_W_sub`、`sub_Y_neg`、
   `sub_R_neg` 四条与原式**逐位同分、ρo = 1.00**。承重的是分位数分母上的那两个:`N = q95+1e-6`、`Z = |q05|+1e-6`。
   封板 / 一路爬升到涨停的日子分位数恰为 0,比值被放大 10³~10⁵,一天吃掉 20 日窗。
4. **`ts_mean(·,20)` 不是平滑,是记忆。** 窗口 5/10/20/30/40 → −3.7/−3.4/−3.2/−3.1/−2.8%,**完全平**;
   `mem_mean/ema/decay_linear` 全族与原式 ρo 0.92~1.00。一天的爆炸吃掉任何窗口。

## 2. 预测力在哪

**承重(一换就塌或一换就翻):**
- **D / H(5 分钟收益与掩码选择)**:`abl_D` `sub_D_{add,div,mul}` `abl_H` 一律 **−17.3~−17.4%**,Lshp −2.55。核心不可动。
- **N 上的 1e-6(上侧爆炸)**:`sub_N_sub`(q95 − 1e-6,翻转上侧爆炸符号)**−19.1%**;`abl_N`(去 ε)−4.9% 且 cov 0.94 ✗;
  `sub_N_mul/div`(爆炸改成除 0)+2.5/+2.0% 但 cov 0.94 ✗。
- **A 的 5 分钟孔径没有平台**:`win_A_3/10/15` = −8.1/−8.2/−10.4%,原式 −3.2%。尖峰、无邻域 → 过拟合的味道。

**多余(删了不掉,甚至更好 —— 这是本轮最大的一组发现):**
- **上侧计数归一化 L 是纯损害,这是全表最大的一次结构收益。** 让 L 退化成常数的四条写法同时成立:
  `only_L_R` / `sub_J_day_first`(J → day_first,首根恒为 0 → L = 1e-6)**+5.1%**(valid +14.0%,Lshp 0.58);
  `sub_L_mul`(L = J·1e-6)**+4.9%**(Lshp 0.75);`sub_W_div`(下侧同理)**+4.5%**。即:**有用的是「超阈 5 分钟收益之和」,
  除以超阈分钟数把个数信息扔了。**
- **整条下侧分支是损害**:`abl_AA` / `only_AA_R` / `sub_AA_{mul,add,sub}` **五条全部 +2.6~+2.7%、Lshp 0.41~0.43、ρo 0.72**
  —— 换哪个算子都一样,说明 AA 只是在 O 的 10⁶ 量级旁边当噪声。`abl_AB`(连 sub 一起删)同分 +2.7%。
- **`sub_Y_log` +4.9%(valid +11.3%,ρo 0.39)是「爆炸纯属损害」最干净的一条证据**:`log` 的定义是
  `|x|>EPS ? log|x| : NaN`,所以 q05 = 0 的日子整日变 NaN、被 `nanmean` 丢掉 —— **把爆炸日删掉就赚钱**。
- **上侧爆炸 vs 下侧爆炸不对称**:翻上侧符号(`sub_N_sub`)−19.1%,翻下侧符号(`sub_Z_sub`)**+2.4%**;`abl_Z` −1.5%。

**叶子互换:**
- **价格字段可互换**:`leaf_Close_{open,high,low,vwap}` ρo 0.84~0.96、数字与原式同级(−2.6~−4.7%)。信息不在「收盘价」。
  但只换分子那一个 Close(`fld_Close_{Open,High,Low,Vwap}`)ρo 0.45~0.86、−3.2~−4.1%,也没救。
- **用户的「Ret ↔ 量变化率可互换」在这棵树上不成立**:`leaf_Ret_{volchg,logvol,amtchg}` 三条 **dist 0.00 ✗、LTO 0.3%**
  —— 退化成常数。原因在定义里:`Ret` 在这里只作为**阈值**与价格收益比较,换成量的变化率后掩码恒真或恒假。
- `sub_AC_ts_quantile_q25`(外层均值 → 25% 分位)+2.9%、`nosc_J_day_gini` +3.9%:外壳换成「稳健 / 有界」统计量都小赚,
  同一方向(少吃爆炸)。

## 3. 在市场的哪儿、什么时候有效

**原式:全市场所有常规切分上一律为负,只有两个病态段为正。**

| 段 | 占比 | 段等权超额 | `v_base` 段内(持仓偏离) | `k_known` 段内(偏离) |
|---|---|---|---|---|
| 近 15 日有冻结盘口(封板/停牌) | 6.5% | **−67.4%** | **+14.3%**(**+2.3pp**) | −10.9%(−2.9pp) |
| 上市不足 250 日 | 7.1% | −28.7% | **+5.0%**(−3.4pp) | +8.6%(−0.9pp) |
| 四个板块 | — | — | −3.8 / −4.2 / −4.1 / −6.5% | +14.8 / +20.9 / +18.9 / +1.4% |
| 流通市值五档 | — | — | −1.1 / −4.5 / −11.1 / −7.1 / −2.3% | +9.3 / +9.5 / +9.2 / +3.5 / +0.7% |

→ **原式唯一独有的信息在已知族亏钱的那 6.5% 病态段里,而它还超配这个段 2.3pp** —— 这就是全市场 −3.2% 的来源。
逐年 2018~2023 = −6.9/−3.5/−5.8/−2.3/+0.5/−0.0%,市场涨 −2.7% 跌 −3.5%,高波 −3.3% 低波 −3.1%:**没有任何时段救得回来。**

**去掉爆炸后的结构变体换了一片市场。** 以 `sub_L_mul`[3] / `only_L_R`[7] 为例:

- 板块:创业板 **+9.0% / +11.6%**,深主板 +6.1/+7.7%,沪主板 +3.9/+2.8%,科创板 **+2.4% / −20.5%**。
- 流通市值:最低 20% **+9.8% / +12.0%** → 最高 20% −0.5% / +0.2%。**只在小市值。**
- 成交额(20 日):最高 20% **+10.8% / +3.6%**,最低 20% **−6.2% / −7.4%**。**只在活跃段** —— 与已知族完全相反
  (`k_known` 把 **+80.3pp** 的持仓压在成交额最低 20%,那一段段等权 +15.1%:已知族本质是「买不活跃的票」)。
- 时间:2022 +10.7/+17.1%、2023 +10.8/+9.1%,2019~2021 ≈ 0;市场近 20 日**上涨 +8.2/+13.1% vs 下跌 +0.4/−4.6%**;
  **低波 +9.4/+9.0% vs 高波 +0.4/+1.4%**(已知族相反:高波 +18.5% > 低波 +12.4%);截面离散度高 +6.4/+9.1% vs 低 +3.5/+1.3%。

**推断的原因。** 规则日上 `O ≈ Σr5·1[r5>q95]/q95` 是**尺度不变**的(高斯随机游走下约为常数),它只随三件事动:
1 分钟收益的正自相关(= 资金把价格一级一级往上推)、跳跃、以及零收益分钟过多(薄盘)。sign = −1,
所以这条因子在**卖掉「最近 20 天被日内推着走」的票**。这正是 A 股**创业板 + 小市值 + 高换手**里游资拉抬的签名:
那里价格由订单流而非信息驱动,拉抬后几天回吐;在大市值 / 科创板(20% 涨跌幅、机构持仓)这个机制弱,信号也消失。
时段上它只在**平静且上行**的市场有效 —— 那正是投机资金主导小票定价的环境;高波 / 下跌时一切被 beta 吞掉。

**可检验的推论(已写进第二批):** ① 直接读「推」的量(`day_signed_ratio(Ret, Amt)`、`day_wmean`)应同向且更干净(D 组);
② 「5 分钟为正占比 − 1 分钟为正占比」是正自相关的纯读数,应保留信息(`h_d_pos_gap20`);
③ 若只是活跃度倾斜,成交额桶内排名应全塌(`h_e_spine_bk_liq`);④ 若机制为真,只在高成交额 40% 里做应接近段内的
+10.8% 而不是全市场的 +4.9%(`h_e_spine_high40`);⑤ 冻结盘口段应能被 `day_zero_ratio` / `day_flat_run_max` 直接复现(B 组)。

## 5. 改进方向(= 第二批 40 条假设)

主线是 `SPINE = cross_mean(div(Σ r5·1[r5>q95], q95+1e-6), 20)` —— `only_L_R` 去掉死掉的下侧分支。
A 组把(甲)(乙)做成最小形并逐步拆掉除法;B 组用 `day_zero_ratio/day_flat_run_max/cross_valid_count`
把 1e-6 真正读到的状态写出来;C 组钉死「5 分钟 vs 1 分钟」错配需要的到底是什么;D 组正面检验拉升机制;
E 组把解剖写进表达式(桶内排名 / 只做高活跃段 / 剔除冻结与次新);F 组用日频市场状态调权重;
G 组把它当筛子叠在已知族上;H 组是与原式低相关的新结构。全部 40 条 `./scripts/study.sh hypo` 通过。

**本轮结论(与上一位研究员的 `status: done / 分辨` 一致,但原因更锋利):**
不是「这条因子没有方向」,而是**它身上有两件东西被 1e-6 焊在一起** —— 一个「近 20 日有没有封板」的事件标记
(信息在空头腿、买不进、且住在已知族亏钱的 6.5% 里)和一个「日内被推着走」的活跃小盘反转信号
(去掉爆炸后多头腿 +4.5~5.1%、LTO 仅 1.7%,但与已知族的活跃度倾斜共线、桶内中性后只剩 +0.4%)。
第二批就是去分别钉死这两件东西能不能各自站住。
