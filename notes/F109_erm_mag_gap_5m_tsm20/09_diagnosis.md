# 09_diagnosis —— 机制诊断:已确立 / 合理但未坐实 / 未决

写于主研第 5 轮(2026-10-04),留出段已读完。
分级标准:**已确立** = 两段以上数据同号、或留出段确认、或有自检过的直接测量;
**合理但未坐实** = 只有一段 / 一个读数,方向明确但没有判别性实验;**未决** = 证据不足,且本研究不再追。

这条因子**是什么**(一句话机制):它把每天 236 个 5 分钟收益的上尾超阈均值、下尾超阈均值
各自除以当天 1 分钟收益的 95% / 5% 分位数,相减,再取 20 日均值。
由于 `Ret` 的第一根恰好为 0,**涨跌停封板日的分位数精确为 0**,四个 1e-6 里有两个让那天的值炸到 10³~10⁵,
一次爆炸就占 20 日窗口 Σ|gap_d| 的 **99.9%**。所以它实际上是**「最近 20 天有没有发生过封板事件」的一个带符号的记忆**
(出处:`02_operators.md`、`03_decomposition.md`、`07x_1_anatomy.md`;numpy 重构与引擎面板 rank 相关 **1.0000**)。

## 一、已确立

1. **这是一条真实的因子,但真的那一半在空头腿。**
   多空口径(hlS,用户最早那张表的口径):utrain **+2.766** → holdout **+2.276**,
   **五条候选里最高**,高于已知家族的 +2.334 / +1.942;空头腿毛超额 utrain +32.71% → holdout **+32.86%**,
   **留出段一点没衰减**。出处:`runs/.../S_final.json` 的 `by_rank['ls']`、`10_distilled.md`「最硬的一条新事实」。
2. **空头腿的机制 = 封板事件之后的大幅跑输。**
   事件研究(次日年化超额,train/valid):正爆炸 −55.6% / −49.0%、负爆炸 −35.1% / −33.1%、
   无爆炸 +3.9% / +3.2%(`07x_1_anatomy.md` §3)。`a_evt`(只数过去 20 天封板天数)空头腿 **+44.9%**,全场最高。
3. **空头腿有一半是「次日一字开盘买不进」撑出来的。** 换成不带可买入过滤的原始标签,
   多空夏普 2.55 → **0.35**,空头腿 +34.4% → +18.1%,而多头腿几乎不动(−4.6% → −5.0%)。
   出处:`07x_1_anatomy.md` §4。**即使用户能做空,这条腿也只有一半是真的。**
4. **对纯多头的用户没有可用的多头腿。** 原式 + 多头最优半衰期:train −4.6%、valid +0.2%、holdout **+2.88%**
   (夏普 +0.713),比家族低 **11.2 个点**;留出段的 +2.88% 在用户给的噪声带(±3 点)内与 0 不可区分。
   逐年八年只有 2022(**+0.38%**,实质为零)、2024(+4.65%)、2025(+3.32%)三年为正 = **3/8**,其余五年全负。
   出处:`06_baseline.md`、`results/R2.md` 第 5 节;⚠ 正年数由 `results/R3.md` 第 2 项(1)核对改正(原写「只有 2024/2025 为正、六年全负」,漏数了 2022 的 +0.38%)。
5. **「半衰期拉长」带来的多头腿改善全部来自换手下降,不是信号变好。**
   train 半衰期表 hl 0 −13.5% → hl 20 −4.6%,而**毛**超额同期从 −2.4% 变到 −3.5%(更差);LTO 17% → 1.4%。
   出处:`06_baseline.md`。**平滑省得下成本,省不出一条本来不存在的多头腿。**
6. **结构修正没有产物,而且方向本身不存在。** 十个引擎变体 + 13 个 numpy 重构里,
   固定半衰期 hl 20 下最好的是 `a_sig` **+2.3%**(夏普 0.31),**同一 hl 20 上家族是 +8.4%(1.21)**;
   家族在自己的多头最优半衰期(hl 0)上是 +12.6%(1.78)。**两种口径下家族都遥遥领先**
   (⚠ 口径标签由 `results/R3.md` 第 2 项(2)核对改正:+12.6%/1.78 是 `sweep` 的 hl 0 那一行,不是 hl 20 那一行);
   留出段上三条结构候选败给家族 **11.2~16.4 个点**,两条翻负(`f_sig` −2.33%、`f_lvl` −1.22%)。
   且**每一个「把多头腿做出来」的动作都同时把多空夏普拉低**(utrain 2.766 → 2.475 / 2.712 / 1.390;
   holdout 2.276 → 1.957 / 1.974 / 0.891)。出处:`07_S1_nodes.md`、`10_distilled.md`。
7. **减法(`sub`)不是缺陷 —— 那 5~6 个点只在样本内。** `f_sum` − `f_orig`:utrain **+6.57pp** → holdout **+0.06pp**。
   两种写法在留出段收敛到同一个数(+2.95% vs +2.88%)。出处:判据 D。
8. **多头端的分位剖面翻转不是减法造成的,是这一族取极值本身的性质。**
   Q9→Q10(train):`v_base` +5.0%→−3.6%、`a_sum` +9.9%→+2.7%、`a_up` +11.2%→+1.4%、`a_eps3` +5.4%→+1.3% ——
   **十个变体没有一个把翻转修掉**。出处:`07_S1_nodes.md`。
9. **ε 只决定幅度,不决定排序。** `a_eps3`(ε→1e-3)空头腿 +39.5% / +36.3%、rIC 0.0394 / 0.0435,
   都比原式(+34.4% / +28.4%,0.0306 / 0.0298)**更高**;`a_sig` 连分母都没有,空头腿 +40.4% / +44.1%。
   起作用的是**哪天被标成事件**这个集合。出处:`07_S1_nodes.md`(H1 的改写)。
10. **尺度错配(5 分钟分子 / 1 分钟分位阈值)不是瑕疵,是必需品。**
    改成同尺度的 `a_q5` 或 1 分钟版 `a_1m`,rIC 砍一半(0.0112~0.0191 vs 原式 0.0306),多头腿更差。出处:H7。
11. **它只是已实现偏度 / 低波低活跃暴露的一个更差写法。**
    `a_sig` ~ `cross_mean(day_skew(r5),20)` rank 相关 **+0.85**、~ 自己的 60 日版 +0.92;
    `a_sig` 毛多头腿 +4.3% → 对 `ctl_amt` 取残差 **−0.5%**、对 `ctl_dvol20` **−0.1%**;
    `b_lvl` 残差 rIC 0.0240 → **0.0005**(全套控制)。出处:`07_neutralise.md`、H12。
12. **对已知家族没有实质增量。** 对家族取秩残差后多头腿 −0.3% / −0.0%(R² 0.012 / 0.022);
    秩相加**显著拖累**(+0.3·BASE 配对差 −2.0% / −2.4%,t −2.64 / −2.52)。
    条件 IC 解释了为什么:`a_sig | known_stdamt_mean30` 从低到高 0.0171 / 0.0149 / 0.0232 / 0.0332 / **0.0428** ——
    **这棵树住在活跃、波动大的票里;家族的多头腿住在最安静的票里**(家族方向为 `−`)。出处:`07x_2_incremental.md`。
13. **rIC 和这条因子的赚钱能力脱钩。** 留出段 rIC 最高的是 `f_sig` **+0.0579**(高于家族 +0.0503),
    它的多头腿是 **−2.33% / −0.204**;`b_lvlq` 的 train/valid rIC 全场最高(0.0485 / 0.0686),多头腿 −4.1%。

## 二、合理但未坐实

1. **「家族多头端里混进了封板事件票,剔掉能多赚」** —— 方向与显著性都有,量级不够。
   `FAM30 + 0.3·EVT` 对家族多头腿日收益的配对差 **+1.0% / +0.8%,t +3.27 / +3.03**(9 个权重组合里唯一两段同时显著为正,
   邻域是驼峰:w=0.1 → +0.2%、w=0.3 → 顶点、w=1 → +0.1%);
   直接剔除事件票再补位:train +12.6% → **+16.1%**(配对差 t +2.68)、valid +22.3% → +22.9%(t +2.13)。
   **低于事前写死的 +2 点门槛,按预注册不升级、没带进留出段。** 出处:`07x_2_incremental.md` §3~§5。
   没坐实的原因:只在秩空间的 numpy 组合里量过,没做成引擎表达式、没过留出段;
   而且 train 与 valid 的量级差 6 倍(+3.5pp vs +0.6pp,事件票占比 6.78% vs 1.94%)。**追法在 `12_next.md` 第 1 条。**
2. **对市值取残差后多头腿变好** —— `a_sum` 毛多头腿 +2.1% → **+8.6%**(净 +0.8% → +7.3%,换手仍 2.1%)。
   只有 fit 段一个读数;`ctl_cap` 是外部 npy、写不进表达式;天花板 +7.3% 仍低于家族 +12.6%。
   四条不追的理由在 `07_neutralise.md` 第 3 条。
3. **2024 年结构候选集体转正是「风格年」而不是信号** —— 三条结构候选 2024 全部 +8.84%~+11.06%
   (两条还高于家族自己的 +9.17%),2025 全部 −1.92%~−12.66%,而家族两年 +9.17% / +14.32%。
   把这解释成「2024 的制度对各种写法的低波/规避高波暴露都友好」是**机制猜测,没有实验**。
   已确立的只是:**结构候选的年度符号不稳定,家族八年全正。** 见 `11_risks.md` 第 6 条。

## 三、未决(本研究不再追)

1. **原式多头腿在 2023-08 之后是不是真的转成了弱正。** utrain −3.21% → holdout **+2.88%**(夏普 +0.713),
   2024 +4.65%、2025 +3.32% —— 与前六年(2018–2023 里只有 2022 的 +0.38% 勉强为正,其余五年全负)不同,是符号翻转。
   证据只有留出段这一段(**整个研究只许读一次,已经用掉**),机制没查。
   **不改变推荐**:+2.88% 在噪声带内,且比家族低 11.2 个点。
2. **封板事件之后跑输的那部分,有多少是「买不进」的测量假象、多少是真实的反转。**
   已知两头:带过滤 2.55 / 不带过滤 0.35。中间的分解需要逐笔或涨跌停板档位数据,Partura 的面板里没有。
3. **这棵树与同一来源的其它事件型手写因子(`erm_*` / `gap_*`)是不是同一条。**
   本研究只看 F109;`12_next.md` 第 4 条给了一个便宜的筛法。
