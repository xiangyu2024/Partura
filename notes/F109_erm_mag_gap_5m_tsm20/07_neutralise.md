# 07_neutralise —— 中性化表怎么读,以及它说了什么

出处:`S1_lvl.json` 的 `diagnostics.neutralise`(`a_eps3`、`a_sum`、`a_sig`、`b_lvl`、`b_lvlq`,结果卡 R1 A 组第 8 项)
+ `S0_baseline.json` 里 `v_base` 的同一张表。fit 段 = train,对象 = **实际交易的信号**(已按多头口径半衰期平滑)。

## 读这张表的硬规矩(digest 自己也印了这句话)

> 残差**不再平滑** → 残差换手更高,净值类指标可能只因成本而塌,alpha 还在不在看 **rIC / 毛超额**。

数字上这件事有多大:`b_lvlq` 未中性化换手 1.8%、对 `ctl_range` 取残差后 **43.4%**;净超额从 −4.1% 掉到 −34.2%。
那 −34.2% 里几乎全是交易成本,**不是** alpha 的消息。**所以下面只引毛多头腿(Lgross)和残差 rIC。**
(另外:这张表与 `x2_incremental` 里「残差当新因子重新定方向半衰期」的那张**不是同一件事**,不要互相对照,
见 `07x_2_incremental.md`。)

## 解读

1. **这棵树那点多头腿是活跃度 / 波动暴露,不是新东西(H4 从空头腿扩展到多头腿)。**
   最好的变体 `a_sig` 毛多头腿 +4.3%,对 `ctl_amt`(成交额水平)一个变量取残差后 **−0.5%**,
   对 `ctl_dvol20`(20 日日频波动)后 **−0.1%**,全套控制后 +0.7%、残差 rIC 从 0.0359 掉到 0.0137。
   **一个控制变量就能把它抹平** —— 这就是「它是不是已知暴露的另一种写法」的答案:在多头腿上是。
   (对照:空头腿这件事 x1 早就定了,全套控制 R² 0.169、空头腿 +17.3% → −0.5%。)
2. **`b_lvl` 更彻底**:`ctl_dvol20` 一个变量把残差 rIC 打到 **0.0012**(从 0.0240),全套控制打到 0.0005。
   它本质上就是一条低波暴露。
3. **唯一一个方向相反的读数:对 `ctl_cap` 取残差后毛多头腿反而大涨。**
   `a_sum` +2.1% → **+8.6%**(净 +0.8% → +7.3%,换手只从 1.8% 到 2.1%,LS +1.44 → +2.80);
   `a_sig` +4.3% → +6.3%;`a_eps3` +1.1% → +4.7%;`v_base` −3.5% → −1.0%。
   这一族的多头端有一个 **+0.26 ~ +0.32 的 log 流通市值正暴露**(大市值倾斜),去掉之后多头端换人、数字变好。
   **但我把它判为「合理但未坐实」,不追**,四条理由:
   - 这张表**只在 fit 段(train)算**,没有 valid 的对照数字 —— 一个单段读数;
   - **残差 rIC 几乎没变**(`a_sum` 0.0276 → 0.0285):排序质量没提高,变的只是十分位的成分,
     而这条因子的十分位本来就极不稳(`v_base` Q9 +5.0% / Q10 −3.6%);
   - `ctl_cap` 自己当因子在 train 上是 +0.6%(大市值几乎不输),所以「去掉逆风」解释不了 +6.5 个点,
     真正的解释只能是分组内选股的交互 —— 而这需要专门的实验,不是这张表能定的;
   - `ctl_cap` 是**外部控制变量**(`shared/log_float_cap.npy`),**写不进表达式**,
     所以即使成立也不是一条可直接交易的因子,而是「在规模分组内选股」的构造提示;而且 +7.3% 仍然低于家族的 +12.6%。
   → 写进 `12_next.md`:要追就是一次 exec,量「秩空间对 log 流通市值取残差之后,`a_sum`/`a_sig` 在 **train 和 valid** 上的
   多头腿,以及它与家族相加的配对差」。这一轮不花这次运行,理由是上面第四条(天花板低于基准)。
4. **`ctl_turnrate` / `ctl_range` / `ctl_ivol` 那几行的净超额不要引用**:残差换手 15%~43%,
   −10% 到 −34% 的净超额是成本,不是信息。
