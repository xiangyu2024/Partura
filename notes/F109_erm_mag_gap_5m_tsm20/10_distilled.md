## 结论先写死:这条因子判 **分辨**,没有可推荐的提纯 / 升华产物

理由(每条都指到一个实验,详见 `07_S1_nodes.md` / `07_S2_level.md` / `07_neutralise.md` / `07x_2_incremental.md`):

1. **多头腿不可用。** 第一条基准「原式 + 多头最优半衰期(hl 20)」= **−4.6% / +0.2%**(夏普 −1.76 / +0.09)。
   10 个结构变体在**同一半衰期 hl 20** 下最好的是 `a_sig` **+2.3%**(夏普 0.31),而且那 +2.3% 由 2018 一年撑起
   (2018 +11.1%、2019 +0.1%、2020 −1.0%、2021 −1.6%)。第二条基准(已知家族)是 **+12.6% / 1.78**。
2. **那点多头腿是已知暴露。** `a_sig` 毛多头腿 +4.3%,对 `ctl_amt` 取残差 −0.5%、对 `ctl_dvol20` −0.1%、全套控制 +0.7%。
3. **它是已实现偏度的一个更差写法。** `a_sig` ~ `cross_mean(day_skew(r5),20)` rank 相关 **+0.85**、~ 自己的 60 日版 +0.92。
4. **对已知家族没有实质增量。** 对家族的残差多头腿 −0.3% / −0.0%;秩相加显著**拖累**(t −2.64 / −2.52)。

   按预注册判据不升级、不带进留出段(`07x_2_incremental.md` 第 5 条)。
5. **钱在空头腿,用户做不了**,而且一半是「次日一字开盘买不进」撑出来的(多空 2.55 → 0.35)。

## 判据(留出段出现什么结果算「我错了」)

口径说明:`final` 会按**用户口径**给数字 —— 方向与半衰期在 **utrain**(2018-01-02~2023-08-07)上定,
留出段(2023-08-08~2025-12-31)= 用户的测试段。所以下面一律指 `books_user` 的 holdout 行。
噪声尺度(playbook §4.6):多头腿净超额 ±3 个点、纯多头夏普 ±0.3。

- **判据 B(前置可信性检查,先看这一条)**:`f_fam30` 的留出段多头腿净超额落在 **+10% ~ +18%**、纯多头夏普 **≥ 1.1**
  (用户表给的区间是 +13%~+15%、1.4~1.9,这里按 ±3 点 / ±0.3 放宽)。
  → 若 `f_fam30` 自己在留出段上塌了(净超额 < +5%),则**整张表都不可比**,报告只能写
  「留出段上家族本身失效,无法据此判断这条因子的相对位置」,其余判据作废。
- **判据 A(主结论:多头腿不可用)**:预测 `f_orig` 的留出段多头腿净超额 **< +5%** 且纯多头夏普 **< 0.5**。
  → **被否定的条件**:`f_orig` 留出段净超额 **≥ +10%** 且夏普 **≥ 1.0**。那就要照实写:
  原式的多头腿在 2023-08 之后变得可用,train/valid 四年半的证据(逐年六年没有一年像样)没能预见这件事。
- **判据 C(结构变体仍不如家族)**:预测 `f_sig`、`f_sum`、`f_lvl` 三条的留出段净超额**都** ≤ `f_fam30` 的留出段净超额。
  → **被否定的条件**:任一条 **> `f_fam30` + 3 个点** 且纯多头夏普 **≥ 1.4**。
  那么「它只是活跃度/波动暴露、对纯多头没有增量」这条解读要在 `09_diagnosis.md` 里改写成**未决**,
  并在 `12_next.md` 里建议下一轮专门研究它 —— **但推荐不许改**(推荐是事前写死的,这是留出段的规矩)。
- **判据 D(H11:减法只值几个点)**:预测 `f_sum` 的留出段净超额 ≤ `f_orig` + **8 个点**(train 上这个差是 5.4 点)。
  → **被否定的条件**:`f_sum` − `f_orig` > 15 个点 **且** `f_sum` 本身 ≥ +10%。那 H11 的「修正无交易价值」要改写。
- **判据 E(风格解读)**:预测 `f_lvl` 的留出段净超额 **< +8%**(它 valid 的 +12.0% 我判为 2022–23 风格)。
  → 被否定的条件:`f_lvl` 留出段 ≥ +12% 且夏普 ≥ 1.3 —— 那说明「水平」在两个不同风格段上都给 +12%,
  不能再叫风格,要写成未决。
- **判据 F(逐年,免费附带)**:`final` 带 `--holdout` 时会把所有候选的逐年都算出来(含 2024、2025)。
  预测:`f_fam30` 在 2024、2025 两年都 ≥ +8%,而三条结构候选都 < +5%。两年里有一年反过来,写进 `11_risks.md`。
- **判据 G(复现自检,执行必须先核这一条)**:`final.json` 里 `books`(train 口径)那一组数字必须复现已有的结果 ——
  `f_orig` train −4.6%、`f_sig` +2.3%、`f_sum` +0.8%、`f_lvl` +0.1%、`f_fam30` +12.6%(各 ±0.2 个点)。
  对不上说明表达式没拷对或口径错了,**那就先停下来**,不要解读留出段数字。

### A 的半个失手(必须写明,不许事后改口)

事前写的是「`f_orig` ho < +5% **且** 夏普 < 0.5」。Lnet +2.88% 过了;夏普 **+0.713** 比预测高 0.21
(噪声带是 ±0.3,所以这个失手**在噪声内**,但它确实不是我预测的那一侧)。
而原式多头腿从 utrain **−3.21%** 变成 ho **+2.88%**,是**符号翻转**:train 六年没有一年像样(`06_baseline.md`),
2024/2025 却是 +4.65% / +3.32%。所以诚实的写法是:
- **已确立**:原式多头腿**不具备竞争力** —— +2.88% 在噪声带(±3 点)内与 0 不可区分,比家族低 **11.2 个点**,
  对一个已经拿着 +14.10% / 1.509 的纯多头用户没有任何意义。**判据 A 的否定条件(≥+10% 且 ≥1.0)远未触及。**
- **未决**:原式多头腿在 2023-08 之后是不是真的转成了弱正。证据只有留出段这一段(不能再读),机制未查。
  这件事**不改变推荐**,追法写在 `12_next.md` 第 3 条。
