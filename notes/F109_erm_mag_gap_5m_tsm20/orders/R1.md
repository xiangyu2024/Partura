## 想回答的问题(对应哪条假设;看到哪种结果意味着什么)

### A 组(S1_S2,已在跑):把 numpy 口径的结论在**引擎官方口径**上复核

1. **H11 —— `a_sum`(把顶上的 `sub` 换成 `add`)能不能救出多头腿?**
   这是整条因子唯一可能走到「提纯」结论的路径。机制已经确立:两种爆炸之后都跑输(窗内有正爆炸 −55.6%,
   有负爆炸 −35.1%),而原式的减法把负爆炸的票送到了多头端(Q10 里 15.6% 是负爆炸票,约拖掉 5.5 个点)。
   - 看到 `a_sum` 在**同一半衰期(hl 20)**下 train 多头腿净超额 **≥ +5%** 且 Q10 不再为负 → H11 成立且可交易,下一轮进 S3 提纯。
   - 看到 train 多头腿仍 **< +3%** → 减法不是多头腿问题的要害(或要害被别的东西盖住),H11 改写成「机制对、但修不出钱」,
     下一轮直接进读留出段。
   - **归因必须按同一半衰期比**:`a_sum` 若自己选到更长的半衰期而多头腿变好,那部分写「来自平滑」,不算结构更好。

2. **H1 —— 排序到底主要是「规则部分」还是「事件记忆」?**
   numpy 版说 ε 换成 1e-3 之后与原式 rank 相关还有 0.75、rank IC 反而更高(0.0395/0.0435 vs 0.0306/0.0298),
   这**证伪了**事前「ε 加地板排序大变」的预测。要在引擎口径确认。
   - `a_eps3` 的空头腿若基本保住(≥ +12% 毛超额)→ 空头腿主要来自规则部分,H1 定为「部分成立」。
   - `a_eps3` 的空头腿若塌到 ≤ +5% → 空头腿主要是事件记忆,H1 的原始版本成立。
   - `a_sig`(去掉两个分位数分母、改用 `day_std(Ret)` 归一,没有 ε、不会爆炸)是同一问题的另一面:
     它若保住 rank IC 与空头腿 → 信息在尾部不对称里;若塌 → 在事件记忆里。
   - `a_evt`(只数封板天数)若空头腿不低于原式 → 事件记忆单独就够。**预期它过不了 dist 门槛,只当诊断看**,
     门槛没过也要把两本书的数字抄回来。

3. **H13 —— 「水平」(`b_lvl` / `b_lvlq`)是不是就是低价股效应?**
   numpy 版:规则日 `up+dn` 多头腿 +3.6% / +11.7%(夏普 0.46 / 1.60),而 `ctl_price` 自己当因子 +3.9% / +11.3%(0.56 / 1.59)
   —— 几乎一模一样。
   - 与 `ctl_price` 的 rank 相关 **|·| ≥ 0.5** 且对 `ctl_price` 取残差后多头腿毛超额归零(≤ +1%)→ H13 成立,水平这条路关掉。
   - 相关 < 0.3 且残差多头腿仍 ≥ +3% → H13 被否定,水平是独立的东西,要进候选池。

4. **H7 —— 尺度错配是不是要点?**(`a_1m`、`a_q5`)
   - `a_1m`(分子换成 1 分钟收益)两本书与原式相近 → 5 分钟对 1 分钟不是要点,H7 成立。
   - `a_q5`(阈值和分母都换成 5 分钟收益自己的分位数,即自洽的 ES/VaR 比)若空头腿明显下降 → 空头腿靠的是事件记忆而非尾部形状。

5. **H12 —— 规则区间是不是「偏度 / 彩票」的另一种写法?**(`b_skew1`、`b_skew5`、`b_max20` 对 `a_sig`、`a_eps3`)
   - 朴素等价物与 `a_sig` 的 rank 相关 ≥ 0.5 且两本书形状相同(空头腿重、train 多头腿 ≤ +3%)→ H12 成立。

6. **`b_sig60`(窗口 20 → 60)**:若多头腿更高,这个改进**记在平滑名下**,不是结构更好 —— 固定半衰期表要能支持这个归因。

### B 组(x2_incremental,新脚本):对只能做多的用户,这条因子相对已知家族有没有增量?(H9 / H14)

这是**选拔口径下的决定性实验**,也是写结论必须有的那张表。x1 只做了粗糙的秩相加(家族 +12.6%/+22.3%,
加 0.3 份「只留爆炸日」+13.7%/+23.1%,加 0.3 份原式反而 +10.6%/+20.0%),**没有配对差、没有标准误、没有残差多头腿**,
所以「+1 个点」到底是信号还是噪声现在说不清。
- 配对差的 t 统计量 **|t| < 2** → H14 成立(增量在噪声之内),结论就是「它就是已知家族之外的一点噪声,对纯多头没有增量」。
- 配对差 **t ≥ 2 且增量 ≥ +2 个点**(train 与 valid 同向)→ 「排除事件票」这个用法是真的,要作为升华候选带进留出段。
- 候选对家族取残差后多头腿净超额 ≤ +3% → H9 成立(它不给家族加东西)。
