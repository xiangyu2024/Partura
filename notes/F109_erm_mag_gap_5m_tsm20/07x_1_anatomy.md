### x1 `studies/F109_erm_mag_gap_5m_tsm20/x1_anatomy.py`:这棵树到底在给什么排序

脚本把原式拆成日频零件(`q95`、`q05`、上/下两侧的超阈均值与超阈分钟数、逐日的 `gap_d`),在 train + valid 上直接数;
所有带「numpy 重构」字样的变体只用这些零件重算,方向与半衰期照常只在 train 上定。留出段没有读。

**0. 读树自检**:`up_mean/(q95+1e-6) − dn_mean/(|q05|+1e-6)` 与引擎的逐日 `gap_d` 相对差中位数 3.6e-8、最大 3.3e-4;
`gap_d` 的 20 日 nanmean 与原式面板 rank 相关 1.0000,重构出的两本书是 −4.7% / +0.3%、多空 2.51 / 3.51(引擎:−4.6% / +0.2%、2.55 / 3.46)。

**1. `Ret` 的第一根恰好是 0**(100% 的股票-日),等于「首根收盘 / 首根开盘 − 1」,不含隔夜。所以一天 241 根全有值,
0.95 分位落在整数位置(第 229 小的那一根),**没有插值**:`q95` 要么恰好是 0,要么至少是一个 tick 的收益。普查里 `0 < q95 < 1e-4` 的股票-日占比是 0.0000。

**2. 分母为 0 的日子很少,但它们就是涨跌停封板日**(531 万个有值的股票-日):

| | 占全部股票-日 |
|---|---|
| `q95 == 0` / `q05 == 0` / 两个都为 0 | 0.72% / 0.79% / 0.70% |

| \|gap_d\| > 20(「爆炸日」)/ > 1000 / > 10000 | 0.49% / 0.46% / 0.29% |

- 规则日(两个分位数都不为 0)上 `gap_d` 是 O(1):中位数 +0.11,四分位 −0.14 ~ +0.40;`up_ratio` 中位数 1.88、`dn_ratio` 1.76
  (高斯随机游走下的理论值约 1.8)。规则日里 \|gap_d\| > 20 的只有 0.003%。
- 退化日里 60% 爆炸(量级 10³~10⁵),另外 40% 的 `gap_d` **恰好是 0** —— 全天一个价的一字板:两侧都没有超阈分钟,
  计数分母上的 1e-6 把 0/0 变成了 0(超阈分钟数为 0 的股票-日:上侧 0.43%、下侧 0.61%)。**H10 成立**:计数上的 ε 只在这些日子起作用。
- 爆炸日里 71.1% 当日涨幅 ≥ 9.5%,84.7% 收在全天最高价;63.7% 是「两侧都退化且涨幅 ≥ 4%」的封涨停型,8.8% 是封跌停型。
- **负向爆炸多数也是涨停日**:`gap_d < −20` 的日子当日收益中位数是 +9.97%。它们是「只有下侧退化」的那一类 ——
  一路爬升到涨停,下跌的分钟不足 5%(`q05 = 0`)而上涨的分钟超过 5%(`q95 > 0`),于是只有下侧的比值爆掉(该类 `gap_d` 中位数 −5201,为正的只占 6.9%)。
  所以**爆炸的符号区分的不是涨停与跌停,而是「秒封」与「爬上去」两种涨停**。
- 一次爆炸盖过整个窗口:20 日窗口里有爆炸日的股票-日占 7.2%(有正爆炸 5.4%、有负爆炸 2.5%);这些窗口里最大的一天占 Σ\|gap_d\| 的中位数是 99.9%
  (没有爆炸日的窗口是 15.5%)。\|原式\| 的中位数 0.15、90% 分位 0.45、99% 分位 3057。

读法:

- **H1 部分成立**。爆炸是空头腿最锋利的那一段(只留爆炸日:多空 3.45 / 3.39,Q1 −30.8%),但全截面的排序主要是规则部分:
  原始面板上原式与「去掉退化日」的 rank 相关是 0.87、与「只留爆炸日」只有 0.45(92.8% 的股票窗口里没有爆炸日)。
  事前预测的「ε 加地板后排序大变」「只留爆炸日与原式相关 > 0.9」都不对。
- **上、下两侧方向相同**(都是 −):`up_ratio` 高跑输,`dn_ratio` 高也跑输。原式相减,丢掉了两侧共同的水平 ——
  规则日的 `up + dn` 多头腿 +3.6% / +11.7%,而差值(去掉退化日)只有 −0.7% / +3.5%。
- **窗口不是杠杆**(H8 成立):5 到 60 天,原式的多头腿都在 −5.4% ~ −4.1% / +0.1% ~ +1.0%;带符号的极值记忆与原式相关 0.94。
- **没有一个变体在 train 上有像样的多头腿**:最好的是 +3.6%(纯多头夏普 0.46)。valid 上的 +7% ~ +12% 各变体都有,
  `ctl_price`(低价)、`ctl_turnrate`(低换手)自己当因子在 valid 上也是 +11.3%、+8.2% —— 那是 2022~2023 低波 / 低价风格的行情,不是这棵树的信息。
- 折叠没有用:train +3.3%、valid −6.2%。剖面中段的 +5% ~ +8% 不是「不极端」造成的。
