六点提醒:

1. **按选拔口径,这张表只有 D、E 两组有多头腿,而 E 没有比 D 好。** E 的多头腿 train 上夏普更高(2.2~2.5 对 1.15~1.99)、净超额在 D 的范围之内;valid 上净超额每一个都低于 D 的三条基准。
   拆开看,E 的多头腿在 valid 上九成是流动性位置(07x_rev2 第 5 点)。A、B、C、C′ 四组(只读集中度)的 valid 多头腿全在 +2.2% 以下。
2. **半衰期这根杠杆在这张表上起作用的地方只有两处**:逐日写法(原式、地板、`p_nat`)从 0 平滑到网格上界 20,多头腿净超额从 −55% 上下回到 0~+7%;已知家族的 `l_f001` 从多空口径的 0 换成多头口径的 5,+9.3% / +18.5% → +13.7% / +22.2%。
   其余自带 30 日窗口的写法里,提纯骨架的主成员和合成式选到的多头半衰期多数在 0~3,换不换差别在 0~2 个点;带 mask / 地板的 30 日写法(`r_base_m30`、`q_base_ramt30`、`r_addmed_ramt30`)选到 20,
   train 上比多空口径多 3~5 个点,valid 仍为负。
3. **C 组内部是同一条因子,但十分位书对成员很敏感。** 秩相关 0.90 的 `r_addmed_ramt30`、0.97 的 `q_nat_rk30`、0.91(对 `r_cv30`)的 `l_stdres30`,valid 的多空分别是 −0.53、1.20、0.76,
   而组内正常成员是 1.6~2.4。读这一组的 valid 多空时,合理的说法是「2 上下,写法不同可以差 ±1」。
4. **C 与 C′ 的差别就是流动性位置。** 可交易信号秩相关 0.97,valid 多空 1.91 对 0.59。C 组的空头十分位几乎不从最不活跃的五分之一里取(2%),C′ 取 20%;
   在同一个流动性桶内比,两者的选择能力相同(空头腿 29.0 / 12.8 对 29.8 / 13.0),C 组多出来的是位置(4.7 / 10.5 个点)。C 组的 valid 多空不能当作「同等流动性下的集中度」的读数。
5. **整张表的多空夏普和空头腿超额是可买入标签下的**:次日开盘封涨停的票在空头里记 0。B、C 两组被抬高 0.5~0.7(train / valid),C′ 被抬高 0.6~2.1,D 组不到 0.1,E 组 0.35~0.4(07x_audit 第 C 点、07x_rev1 第 1、4 点)。**多头腿各列不受影响。**
6. **A → C 只差一步条件化;B 把集中度与流动性的关系翻了过来,但它不只是条件化。** `q_nat_m30` 与 `q_nat_ramt30` 的秩相关是 0.89,valid 多空从 −1.19 到 +1.91。
   原式(B)对 C + 流动性取残差之后还剩一半以上的 rank IC,C 对 B + 流动性在 valid 上没有增量(07x_audit 第 A 点)。
