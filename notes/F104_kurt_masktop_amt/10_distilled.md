### 读留出段之前写下的:候选、理由、预测(只凭 train / valid;这一段在 `study.sh final` 之前定稿,之后没有改过)

五个候选(S_final):

| id | 表达式 | 角色 | train / valid 上的依据 |
|---|---|---|---|
| `f_orig` | `day_kurt(nt_cs_mask_top_replace_mean_neg(abs_(Amt)))` | 原式 | 多空 3.91 / 1.47,多头腿净超额 +4.8% / −5.8%,纯多头夏普 1.00 / −1.24(S0) |
| `f_kurt30` | `cs_regres(cs_rank(cross_mean(day_kurt(Amt), 30)), cs_rank(cross_mean(day_sum(Amt), 30)))` | **提纯(峰度读数)** | = `r_ref30`:3.75 / 1.91,+5.4% / +0.3%,1.08 / 0.06;与原式的可交易信号秩相关 0.52(S2、S3、x2) |
| `f_cv30` | 同上,读数换成 `div(day_std(Amt), day_mean(Amt))` | 提纯(变异系数读数) | = `r_cv30`:3.77 / 2.37,+4.1% / −0.9%,0.89 / −0.20;rank IC 两段都最高(S3) |
| `f_exclcv` | `add(cs_rank(cross_mean(day_sum(Amt), 30)), pow_3(cs_rank(<f_cv30>)))` | **升华候选(事前推荐,纯多头用)** | x2:3.94 / 4.44,+15.0% / +19.1%,2.50 / 3.55,换手 5.2%;指数 2 / 3 / 6、60 日窗口、换水平腿都不塌 |
| `f_std30` | `cross_mean(day_std(Amt), 30)` | 已知家族基准(F001 的量,写在同一时间尺度上) | = `l_std30`:1.87 / 3.70,+12.6% / +22.3%,1.78 / 3.46(S4)—— train / valid 上多头腿净超额最高的一个 |

**为什么是这五个**

- 提纯的两个读数都带上:S3 说读数不是这条因子的本质(峰度、最大一分钟占比、变异系数的书在噪声内相同)。峰度版是原式的直系(同一个统计量,只把 mask 换成显式的条件化);
  变异系数版的 rank IC 更高,而且它把这条因子与 F001 的 `day_std(Amt)` 接上了(std = 均值 × 变异系数)。留出段上两者如果在 ±0.3 以内,「读数无关」就在样本外也成立。
- 升华候选选排除式 + 变异系数读数:排除的形状是 S4 之前按分位剖面定的(指数 3),读数是 S3 里两段 rank IC 都最高的那个;x2 里它是邻域中每一项都最高的,
  而邻域(指数 2 / 3 / 6、窗口 60、水平腿换成 std30)都在 3.4~3.9 / 3.7~4.4 之间。
- 基准选 `f_std30` 而不是纯成交额水平:它是 train / valid 上多头腿净超额最高的已知家族成员,是最难赢的那个对手。
  `f_exclcv` 减去集中度那一项就是成交额水平(与 `f_std30` 秩相关 0.98),所以 {`f_std30`, `f_cv30`, `f_exclcv`} 三行正好是「只有水平 / 只有集中度 / 两者合成」。
- 没有带上的:`l_excl`(峰度读数的排除式,与 `f_exclcv` 同一个东西、各项略低)、`l_f001`(与 `f_std30` 同族,秩相关 0.87)、地板写法(valid 上不稳)。

**读之前的判断**

1. *提纯*:`f_kurt30` 是这条因子的干净写法 —— 不含 NT 面、不含排名阈值,机制是一句话(同等流动性下,成交在日内越不均匀,之后越跑输)。
   它不是原式的等价改写(秩相关 0.52),也不比原式小(7 个算子对 3 个);它去掉的是 mask 带来的那段方向时对时错的流动性暴露。
   **预测**:留出段多空夏普不比原式低 0.3 以上,多头腿净超额不低于原式。两条都不成立,提纯就只在样本内成立。
2. *它自己的多头腿做不出来*:提纯后的多头腿净超额在 valid 上是 0 上下(各读数 −2.7%~+2.3%),钱在空头腿。**预测**:留出段上 `f_kurt30` / `f_cv30` 的多头腿净超额仍然在 0 附近(|·| < 5%)。
3. *升华*:事前推荐 `f_exclcv`。**预测**:留出段多头腿净超额与纯多头夏普都高于原式;两项都不高于原式,升华失败。
4. *升华有没有超出已知家族*:train / valid 的证据是分裂的 —— 多空夏普两段都更高(3.94 / 4.44 对 1.87 / 3.70),纯多头夏普 train 更高、valid 持平(2.50 / 3.55 对 1.78 / 3.46),
   多头腿净超额 train 高 2.4 个点、valid 低 3.2 个点;x2 的逐年表说「在最不活跃的十分位里剔除最集中的一批」的增益从 2018 年的 +9.9 个点一路降到 2022~2023 年的 0。
   **预测**:留出段上 `f_exclcv` 的多空夏普不低于 `f_std30`,多头腿净超额与 `f_std30` 持平或略低。
5. **推荐规则(事前定死)**:
   - `f_exclcv` 的多头腿在留出段上好于原式,且相对 `f_std30` 没有「纯多头夏普低 0.3 以上**并且**多头腿净超额低 3 个点以上」→ 推荐 `f_exclcv`(elevated),并写明它的多头腿主要是流动性溢价;
   - `f_exclcv` 好于原式,但相对 `f_std30` 两项都明显更差 → 结论是「纯多头直接用已知家族,集中度在样本外没有给多头腿加东西」,推荐退回 `f_kurt30`(distilled);
   - `f_exclcv` 的多头腿不好于原式 → 升华失败,推荐 `f_kurt30`(若第 1 条成立)或保留原式 / 判为不稳健(若第 1 条也不成立)。

### 留出段(20230808–20251231,只读了这一次;方向与半衰期在用户训练段上定)—— 读完之后写的

上面那张「最终对比」表逐条对照事前的预测:

| 事前预测 | 留出段 | 判定 |
|---|---|---|
| 1. `f_kurt30` 多空不比原式低 0.3 以上,多头腿净超额不低于原式 | 多空 **2.13** 对 1.89;多头腿净超额 **+1.4%** 对 −2.1%;纯多头夏普 +0.28 对 −0.39 | 成立 |
| 2. 提纯式自己的多头腿在 0 附近(\|·\| < 5%) | `f_kurt30` +1.4%,`f_cv30` −1.8% | 成立 |
| 2′. 两个读数在 ±0.3 以内 | 2.13 对 2.16 | 成立 |
| 3. `f_exclcv` 的多头腿净超额与纯多头夏普都高于原式 | **+12.3%** 对 −2.1%;**1.26** 对 −0.39(多空 3.16 对 1.89) | 成立 |
| 4. `f_exclcv` 多空不低于 `f_std30`,多头腿净超额持平或略低 | 多空 3.16 对 1.94;多头腿净超额 +12.3% 对 **+14.1%**;纯多头夏普 1.26 对 **1.51** | 成立(方向与预测一致:多头腿略低) |

按事前定死的规则(第 5 条第一支):`f_exclcv` 的多头腿好于原式,相对 `f_std30` 纯多头夏普低 0.25、净超额低 1.8 个点,没有同时越过 0.3 与 3 个点的线 → **推荐 `f_exclcv`**。

```
add(cs_rank(cross_mean(day_sum(Amt), 30)),
    pow_3(cs_rank(cs_regres(cs_rank(cross_mean(div(day_std(Amt), day_mean(Amt)), 30)),
                            cs_rank(cross_mean(day_sum(Amt), 30))))))
```

**这个推荐必须连着下面三句话一起读**

1. **它的多头腿是流动性溢价,不是集中度。** 留出段上它的多头腿(+12.3% 净、夏普 1.26)没有超过只用已知家族的 `f_std30`(+14.1%、1.51);
   逐年看 2024 / 2025 的多头腿毛超额是 +11.5% / +15.7% 对 +11.3% / +16.6%,几乎相同。对全部控制变量中性化,它的 R² 是 0.774(只对 30 日成交额 0.567)。
   **如果库里已经有 F001 家族的因子(`cross_max(day_std(Amt), 9)` 或 `cross_mean(day_std(Amt), 30)`),纯多头用它们就够了,`f_exclcv` 不会让多头腿更好。**
2. **集中度加进来的东西在空头腿和稳定性上。** 多空夏普 3.16 对 1.94(用户训练段 4.06 对 2.33);逐年多空 2018~2025 没有一年低于 2.59,
   `f_std30` 有 0.66(2020)和 1.45 / 1.60(2024 / 2025)。空头腿做不了的使用者拿不到这一部分。
3. **留出段的多头腿回撤是 −18.5%**(`f_std30` −14.6%,原式 −9.0%):这是一本低流动性小票的多头书(x2 §5 在它的同胞 `l_excl` 上量到:流通市值分位约 0.25,日成交额中位数约为全市场中位数的四分之一),
   2024 年初的小微盘流动性冲击它全吃了(2024 年纯多头夏普 0.62)。

**提纯的结论(这条因子自己)**

`f_kurt30` 是原式的干净写法:去掉了空操作 `abs_` 和 NT 面的 mask,把 mask 实际在做的事(对流动性水平做条件化)写成一个显式的截面残差。
用户口径下训练段多空 3.20 对 3.20,测试段 2.13 对 1.89;多头腿净超额 +2.7% / +1.4% 对 +1.8% / −2.1%。
它没有变小(7 个算子对 3 个),与原式的可交易信号秩相关是 0.52 —— 它不是同一块面板的更短写法,是同一个机制去掉流动性污染之后的读数。
它是一条**空头腿 / 排除型**因子:多头只占毛价差的 23%~25%,多头腿净超额在训练段、测试段都只有 +1%~+3%。
(把半衰期按纯多头夏普来选是 2 而不是 0,测试段多头腿净超额 +3.9%、纯多头夏普 0.79 —— 表里没有这一行,数字在 `final.json` 的 `splits_at_hl_long` 里;仍然是一个弱的多头腿。)

两个读数在测试段上多空相同(2.13 / 2.16),多头腿是峰度版更好(+1.4% 对 −1.8%;2025 年变异系数版的多头腿 −6.6%)。提纯式用峰度版。

**为什么没有「更好的升华」**

这条因子的信息在最集中的那 10%~20% 股票上(分位剖面的 Q1),而且越来越只在活跃股票里(x2 §3:valid 上不活跃股票里五个集中度分位是平的)。
一本纯多头书要的是「该买谁」,它回答的是「别买谁」;把它当排除条件用在一本流动性多头书上,2018~2021 每年有 +2~+10 个点的增益,2022 年起是 0(x2 §3 的逐年表),
留出段确认了后一半。这是这条因子的性质,不是写法的问题。
