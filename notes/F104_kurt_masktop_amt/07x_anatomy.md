### x1 — 这棵树在真实数据上读到的是什么(`studies/F104_kurt_masktop_amt/x1_anatomy.py`,只用 utrain)

内置诊断回答不了的四个问题,在跑任何阶段之前先量了一遍。合成探针(`probes.py`)对 mask 节点的预言是
「它把被替换的分钟打成几十倍的尖峰,峰度被替换分钟数 k 钉死」;这一节是拿真实数据去核对那个预言 —— 结果是**预言被否定**,
阶段计划因此改写(H10、H11 都是这一节之后才提出来的)。

**(1) `abs_` 是空操作。** 带 / 不带 `abs_` 的两块面板有限值位置完全一致,最大差 2.9e-4(峰度本身是 10 的量级);
只有 48% 的格子逐位相同,是 float32 在不同分块大小下求和顺序不同造成的。

**(2) mask 节点不是「k 的计数器」。** k = 当天被改写的分钟数(241 根里)。

| k | 股票日占比 | 原式中位数 | 自身峰度中位数 | 两点公式预言 | 成交额截面分位 | 次日年化超额 |
|---|---|---|---|---|---|---|
| 0 | 33.6% | 11.12 | 11.12 | — | 0.799 | −10.4% |
| 1 | 6.8% | 11.49 | 11.48 | 236.0 | 0.649 | −1.1% |
| 3–5 | 7.0% | 12.21 | 12.37 | 55.3 | 0.527 | +3.1% |
| 13–30 | 12.7% | 11.64 | 13.82 | 7.1 | 0.349 | +8.2% |
| 61–120 | 11.6% | 8.57 | 17.81 | −1.6 | 0.118 | +9.7% |
| 121–180 | 3.1% | 9.62 | 23.26 | −1.9 | 0.040 | −2.7% |

- 被改写的不是「少数极不活跃的股票」:66% 的股票日至少有一分钟被改写,约四成在 12 分钟以上(逐年 38%~44%)。
- 原式的读数随 k 几乎是平的(11.1 → 12.2 → 8.6),与两点公式的日截面 Spearman 只有 **0.157**;
  而**自身**峰度随 k 从 11 升到 23(k 越大 = 越不活跃 = 成交越断续)。mask 做的事情是把不活跃股票「虚高」的峰度压回来。
- 原因:截面均值 μ(d,m) 自己在日内是 U 形的,被改写的分钟拿到的是**全市场共同的日内成交曲线**的一段,不是一个常数尖峰。
  k ≤ 5 的股票日注入的成交额不到自身的 2%;k ≥ 31 的股票日,(自身+注入)/自身 的中位数是 **3.62**。
- 净效果体现在与流动性的关系上:日截面 Spearman(自身峰度, log 成交额) = **−0.174**,过了 mask 之后 = **+0.110**。
  原式与自身峰度的 Spearman 是 0.630(全部格子)/ 0.470(k>0 的格子)。

**(3) 股票代码顺序没有泄漏进来(H6 否定)。** 零成交分钟只占全部「股票×分钟」的 3.8%~6.9%,低于 10% 的配额,并列的 0 几乎总是
全部被改写。给定「自身零成交分钟数」,k 在列下标前 / 中 / 后三分之一之间没有差别(5~19 个零成交分钟:34.8 / 34.4 / 33.9);
k 与列下标的 Spearman −0.074,原式与列下标 −0.031。

**(4) 自身峰度读的是「最大的那一根」,不是集合竞价(H5 基本否定)。** 在 k=0 的格子上,自身峰度与各个朴素读数的日截面 Spearman:
最大一分钟占比 **0.932**、偏度 **0.986**、变异系数 0.672、首根占比 0.191、末根占比 −0.015。
最大一分钟落在第一根的只有 0.3% 的股票日、落在末根的 3.7%,但落在**开盘后第 2~6 根**的有 29.4% —— 这一条留给 S3 的 `r_kurt_noopen30`。
最大一分钟占比的中位数是 3.24%(均匀分布是 0.41%)。

**(5) 两端十分位里是谁(可交易信号 = EMA-20 的 −原式)。**

| | 次日年化超额 train / valid | 成交额分位 | 换手率分位 | 日内波动分位 | 20 日动量分位 | 「EMA 自身峰度」分位 | 深度不活跃(EMA k ≥ 20)占比 |
|---|---|---|---|---|---|---|---|
| D1(空头端) | −33.5% / −24.3% | 0.62 / 0.60 | 0.59 / 0.63 | 0.63 / 0.61 | 0.55 / 0.55 | 0.83 / 0.85 | 0.25 / 0.28 |
| D10(多头端) | +10.6% / +0.6% | 0.38 / 0.53 | 0.39 / 0.46 | 0.49 / 0.53 | 0.49 / 0.47 | 0.48 / 0.29 | 0.61 / 0.40 |

- 空头端在两段上是同一批东西:自身峰度很高、成交偏活跃、波动偏高的股票。它稳定。
- **多头端在两段上不是同一批东西**:train 上它是不活跃股票(成交额分位 0.38,61% 是深度不活跃),valid 上变成了中等偏活跃的股票
  (成交额分位 0.53,深度不活跃只剩 40%)。多头腿在 valid 上归零,和这个成分漂移是同一件事。

**(6) rank IC 在哪个流动性区间里。** 按 EMA-20 的 k 分三个区间:U0 从不被改写(18%~19%)、U1 边缘(44%)、U2 深度不活跃(37%~38%)。

| 区间 | IC(可交易信号)train / valid | IC(EMA 自身峰度)train / valid | 区间整体超额 train / valid | 区间里多头十分位成员的超额 train / valid |
|---|---|---|---|---|
| U0 | 0.0154 / −0.0123 | 0.0154 / −0.0123 | −2.0% / −14.4% | +5.2% / −20.6% |
| U1 | 0.0208 / 0.0069 | 0.0187 / 0.0024 | −1.9% / −4.2% | +9.7% / −5.3% |
| U2 | **0.0341 / 0.0344** | 0.0228 / −0.0008 | +3.1% / +13.2% | **+12.9% / +24.0%** |
| 全体 | 0.0272 / 0.0134 | 0.0115 / −0.0150 | | |

- mask 的贡献**全部在 U2**:在从不被改写的股票里原式就是自身峰度(IC 相同),在深度不活跃的股票里它把 IC 从 0.0228 抬到 0.0341
  (valid:−0.0008 → 0.0344)。S0 的条件 IC(按**当天**成交额分组、用**逐日**面板)读出来的「最不活跃的一组没有信号」是时间尺度造成的假象。
- 另一半贡献在**区间之间**:全体的 IC(0.0272)高于自身峰度的全体 IC(0.0115)很多,而 U0 / U1 两个区间内部几乎没有提升 ——
  mask 改变了不活跃股票相对于活跃股票的**位置**(valid 上 U2 整体超额 +13.2%,U0 −14.4%)。
- 在 U2 里,多头十分位的成员比 U2 整体多赚 +9.8% / +10.8% —— 「不活跃且成交不爆」比「不活跃」本身好,两段都成立(H13 的出处)。
- valid 上多头腿坏在 U0:多头十分位里有 34% 是从不被改写的大成交股票,它们在 valid 上 −20.6%。

**x2 之后对这一节的两处修正**(原文保留,读的时候以这里为准):

- 第 (6) 点把区间按「被改写的分钟数 k」来分。x2 §4 发现 k 本身混着流动性:同一个 k 档里,集中度高的股票成交额也高。所以「mask 在 U2 里把 IC 从 0.0228 抬到 0.0341」
  有一大块是流动性,不是更好的集中度读数;「S0 的条件 IC 是时间尺度造成的假象」这句话说过头了 —— 按 30 日成交额分组,集中度信号确实在最活跃的一组最强。
- 「在 U2 里多头十分位的成员比 U2 整体多赚 +9.8% / +10.8%」不能读成「不活跃且成交不爆更好」:原式在 U2 里读数最低的那批,就是被改写得最多、也就是最不活跃的那批。
  x2 §3 按成交额分层之后,train 上最不活跃一层里集中度确实有排序(B1−B5 = 27.9 个点),valid 上是平的(2.4 个点)。H13 建立在这两条被混淆的读数上,S4 否定了它。

**修订时(rev1 之后)再加一处修正**:

- 第 (5) 点末尾「多头腿在 valid 上归零,和这个成分漂移是同一件事」只对了三分之一。把多头腿拆成「流动性位置 + 桶内选择」(07x_rev1 第 2 点):位置 +1.0 → −2.4,桶内选择 9.1 → 2.8。
  成分漂移是真的(最不活跃五分位的占比 54% → 29%),但 train 上多头十分位同时有 23% 在最活跃五分位,位置收益本来就不大;塌掉的大头是桶内的选择能力,所有集中度读数的多头腿都一样。
