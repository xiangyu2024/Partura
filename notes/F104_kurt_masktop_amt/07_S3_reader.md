**解读**

1. **读数不必是峰度(H4 的「单根脉冲」读法不成立)。** 最大一分钟占比(3.69 / 2.06)与峰度相当,这符合 H4;但二阶矩的变异系数
   —— 读的是「成交整体不均匀」而不是「尖峰」—— 同样好,rank IC 在两段上都是最高的(0.0281 / 0.0190),空头腿也最深(40.1% / 31.1%)。
   三个读数的扣费多空在 train 上是 3.69~3.77,valid 上 1.91~2.37(在 ±0.3 的噪声下,只能说变异系数不比峰度差)。
   这条因子读的是**「相对于同等流动性的股票,成交在日内分布得有多不均匀」**,四阶矩、最大值、二阶矩都是它的读数;不需要「事件」这个故事。
2. **幅度并不比名次重要(H12 基本否定)。** 同一窗口、同一条件化,把「原值的均值」换成「逐日截面秩的均值」(`r_rankavg30`)只从
   3.75 / 1.91 掉到 3.21 / 1.87,换手还更低(4.9%)。S2 里逐日版本(`q_nat_ramt`,1.71 / −0.27)之所以塌,是因为它拿**当天**的成交额去条件化
   再平滑,而不是因为取了秩 —— 条件化必须在与信号同样慢的时间尺度上做。极值记忆(`r_kurt_max30`)不比均值好(3.29 / 2.12,rank IC 明显更低)。
3. **窗口是平台,不是尖点。** 15 / 30 / 60 日:train 3.53 / 3.75 / 3.49,valid 1.73 / 1.91 / 1.64;60 日的换手降到 3.9%、多头腿净超额 train 最高(+6.5%)但 valid 是 0.0%。
4. **不是开盘抢筹(H5 的残余否定)。** 去掉开盘后的前 6 根和收盘的 4 根,valid 反而略好(2.19,多头腿净超额 +2.3%),train 略低(3.27)。
   29% 的股票日最大的一分钟落在开盘后第 2~6 根(x1),但预测力不靠它们。
5. **脉冲的方向无关(H14 否定)。** 只读上涨分钟的最大一根(`r_up30`)和只读下跌分钟的最大一根(`r_dn30`)拟合出来的方向都是 **−**,
   强度相当(2.71 / 1.88 对 2.49 / 2.22),都比不分方向的 `r_maxsh30` 弱。「拉升之后跑输」不是这条因子的机制 ——
   放量下跌那一分钟占比高的股票同样跑输。没有一条有符号的因子可做。(这两个变体对「成交在价格不动的分钟里」的脉冲是盲的:
   `sign(Ret) = 0` 的分钟两边都不算,封板上的成交属于这一类。)
6. **地板 / mask 没有带来更好的读数。** 地板写法做同样的条件化之后塌掉(2.13 / −0.53),尽管它与 `r_ref30` 的秩相关有 0.90;
   S2 的 `q_base_ramt30`(原式做条件化,2.23 / 0.57)是同一个现象。地板和 mask 在 valid 上的表现来自它们附带的流动性倾斜,
   把倾斜拿掉以后,被改写过的峰度不如没改写过的。
7. **记忆在树里还是树外,差别不大。** `r_base_m30`(原式的 30 日均值,半衰期 1)是 3.25 / 1.38,原式 + 外置 EMA-20 是 3.91 / 1.47。
   EMA-20 的有效记忆更长(平均滞后约 28 天,对 30 日均值的 14.5 天),train 上因此好一些;valid 相同。
8. **提纯后的骨架与原式不是同一条因子。** 在同一时间尺度上,`r_base_m30` 与 `r_ref30` 的日截面秩相关是 **0.61**(与 `r_maxsh30` 0.49、`r_cv30` 0.36),
   远低于 0.95 的同族阈值。更准确的说法是:原式是这个机制的一个被扰动过、带流动性倾斜的读数;骨架是同一机制的干净读数,不是原式的等价改写。

**值得警惕的一件事**:与 `r_ref30` 秩相关 0.90 的 `r_addmed_ramt30` 在 valid 上是 −0.53,S2 里秩相关 0.97 的 `q_nat_rk30` 只有 2.69 / 1.20。
十分位书只看两端各 10% 的成员,截面上 0.9 的秩相关并不保证两端是同一批股票 —— 这一族因子的书对「谁落在最集中的那 10%」很敏感。

**修订(审查之后)**:这一阶段的结论 —— 读数、记忆、窗口、时段、方向都不是本质 —— 说的是**线性秩残差那本十分位书**,这一点不变。要补两句:
(1) 这一族的 valid 多空(1.6~2.4)都带着同一段流动性位置(空头十分位偏在活跃股票上),分桶中性之后峰度读数是 0.39~0.59、变异系数读数 1.11(07x_rev1 第 1 点);
(2) 第 8 点「骨架是同一机制的干净读数」不成立:骨架复现的是原式空头腿的那本书,原式另有它张不成的 rank IC(07x_audit 第 A 点、07x_rev1 第 3 点)。
三个读数里只有变异系数在分桶中性之后还有两段都显著的 rank IC(0.0305 / 0.0240,t 11.8 / 5.4),峰度读数在 valid 上没有(0.0067,t 1.6)。
