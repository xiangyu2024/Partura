脚本先自检:用同一标签时逐位复现了阶段表(原式 3.91 / 1.47、`f_kurt30` 3.75 / 1.91、`f_cv30` 3.77 / 2.37、`f_exclcv` 3.94 / 4.44、`f_std30` 1.87 / 3.70)。
四件事,每一件都改了原报告里的一句话;修订时我在 rev1 / rev2 里复现并往下追(07x_rev1、07x_rev2)。

**(A) 张成检验:提纯式不是「原式去掉污染」,是原式的一部分。** 对象是可交易信号(方向 × 面板、按各自半衰期平滑),逐日在秩空间里做截面回归取残差。

| 被解释的信号 \| 控制 | R² | 残差 rank IC train / valid(t) | 保留的 rank IC | 残差无成本多空 | 残差多头 / 空头腿毛超额(train;valid) |
|---|---|---|---|---|---|

- `f_kurt30` 加上线性的流动性,拿走的是原式的**空头腿**(33.9% → 3.6%,valid 24.3% → −4.9%),rank IC 只拿走不到一半。
- 反方向:`f_kurt30` 对「原式 + 流动性」在 valid 上没有任何增量(t 0.1,无成本多空 −1.03);变异系数读数 `f_cv30` 则有(t 5.2)。
- 所以原报告里「同一机制去掉流动性污染之后的读数」这句话不成立;成立的是「`f_kurt30` 复现了原式空头腿的那本十分位书」。

**(B) 「与流动性正交(R² 0.002)」只是线性秩回归意义上的。** 秩有界:不活跃股票的峰度秩预测值高,残差的上限小;活跃股票相反。
于是残差最大的那个十分位机械地由活跃股票组成:

| 可交易信号 | 空头十分位的 `amt30` 平均分位 | 其中落在最活跃 / 最不活跃五分位 | 多头十分位的平均分位 | 其中最不活跃 / 最活跃五分位 |
|---|---|---|---|---|
| `f_kurt30` | 0.67 / 0.68 | 34% / 35%;2% / 1% | 0.45 / 0.45 | 14% / 15%;5% / 5% |
| `f_cv30` | 0.65 / 0.66 | 31% / 31%;1% / 0% | 0.49 / 0.48 | 7% / 9%;5% / 5% |
| 原式 | 0.62 / 0.60 | 26% / 26%;3% / 7% | 0.37 / 0.53 | 54% / 29%;23% / 34% |

原报告说提纯式「去掉了流动性暴露」:对多头十分位成立,对**空头十分位不成立** —— 提纯式的空头十分位比原式的还更偏活跃股票(0.67 对 0.62)。

**(C) 标签口径抬高空头腿,而且偏偏抬的是集中度类因子。** 次日开盘封涨停的格子可买入标签是 NaN,在空头里记 0;原始标签里它们平均 +5.5% / +4.7%(train / valid)。
全体格子里占 0.175% / 0.107%;各因子空头十分位里的占比与「空头腿改按原始标签计」之后的结果:

| | 空头十分位里封板占比 | 扣费多空:可买入标签 → 空头按原始标签 | 空头腿毛超额:→ |
|---|---|---|---|
| 原式 | 0.49% / 0.46% | 3.91 → **3.22** / 1.47 → **0.85** | 33.9% → 28.5% / 24.3% → 19.0% |
| `f_kurt30` | 0.49% / 0.40% | 3.75 → **3.13** / 1.91 → **1.44** | 33.7% → 28.1% / 23.3% → 18.6% |
| `f_cv30` | 0.60% / 0.48% | 3.77 → 3.16 / 2.37 → 1.87 | 40.1% → 34.1% / 31.1% → 25.8% |
| `f_exclcv` | 0.41% / 0.34% | 3.94 → 3.59 / 4.44 → 4.05 | 40.2% → 36.0% / 34.5% → 30.3% |
| `f_std30` | 0.12% / 0.09% | 1.87 → 1.79 / 3.70 → 3.62 | 21.1% → 19.7% / 33.8% → 32.7% |
| `l_amt30` | 0.07% / 0.03% | 1.20 → 1.15 / 3.19 → 3.15 | 13.4% → 12.6% / 27.7% → 27.2% |

集中度类因子的多空夏普被这个口径抬高 0.35~0.7(±0.3 噪声带的一到两倍),流动性家族不到 0.1。`f_exclcv` 相对 `f_std30` 的多空优势在 valid 上从 0.74 缩到 0.43。
对纯多头的使用者,这些封板的票本来就买不进,「避开它们」没有价值。**多头腿的各列不受这个口径影响**(可买入标签对多头是正确的)。

**(D) `f_exclcv` 的多头书不是「已知家族的多头书减去最集中的一小批」,是换了一半的书。** 它的多头十分位与 `l_amt30` 多头十分位只重合 37% / 36%、与 `f_std30` 重合 49% / 46%;
成员的集中度分位均值 0.32 / 0.31,超过 0.6 的只有 3.0% / 2.5% —— 而 `f_std30` 的多头十分位里这类占 52% / 54%。pow_3 并没有「只罚最集中的那 10%~20%」,它把已知家族多头书里集中度偏高的那一半整个换掉了;
valid 上最不活跃一层里集中度五分位是平的(x2 §3:24.4 … 22.0),换掉的那一半只是少拿了流动性溢价(07x_rev1 第 3 点把这句话量成了数字)。
