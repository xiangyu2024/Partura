## 1. 它是什么(逐层,按函数定义)

`day_kurt(nt_cs_mask_top_replace_mean_neg(abs_(Amt)))`,A = Amt(分钟成交额,元):

1. **`abs_(Amt)` = 空操作**。Amt ≥ 0。`abl_A`(删掉 abs_)与 `v_base` 全列逐位相同、ρo = 1.00。
2. **`nt_cs_mask_top_replace_mean_neg`:名字三处骗人**。`face=nt / axis=S` ⇒ 每个 **(日, 分钟)** 格子沿**股票轴**做;
   `_neg` 版是 `-cs_mask_top_replace_mean(-x)`,改的是**最低** 10%(名字里的 top 反了,docstring 自己写的是
   "Bottom-band counterpart");替换值是 `_mean(x_masked)` = **当分钟全市场成交额的截面均值**,而 `-mean(-x) = mean(x)`,
   所以替换值不是什么中性值,而是一条**市场级时间序列 M[d,m] = 当分钟市场总成交额 / N**。
   Amt 的截面极度右偏,M 落在股票分布的 80~90 分位 ⇒ 对被遮的股票-分钟来说,替换是**往上插一根 10~100 倍的尖峰**。
   **这个算子实际上是一个「带巨型旗标的指示函数」**:被遮的分钟写上 M,没被遮的分钟保留自己的 A。
3. **`day_kurt`**:对混合序列 {未遮分钟 = A} ∪ {被遮分钟 = M} 取当日分钟峰度(标准化四阶矩)。
   - 从不被遮(活跃票)→ 自己日内成交额型态的峰度;
   - 只被遮几分钟(卡在底十分位门槛上的票)→ 那几分钟是 10~100 倍的离群点,四阶矩被它们统治 → **峰度极高**;
   - 大半分钟被遮(极清淡票)→ 序列≈市场型态 M + 几个很小的自有值 → 峰度回到中等。
   ⇒ 峰度是**流动性的驼峰型(非单调)函数**,峰在「正好跨在全市场底十分位门槛上」的票。
   `day_kurt` 又是尺度无关的(四阶中心矩 ÷ σ⁴),**成交额的水平被它除掉了**。
   方向 sg = −1(买低峰度)= 买驼峰的两端 ⇒ 书是成交额上的**杠铃**:最低档超配 +25.1pp、最高档 +6.1pp,中间三档 −7.3 / −12.7 / −11.1pp。
4. 一个少见的副作用:M[d,m] 是**所有股票共用**的市场序列,所以因子里混进了「这只票的死分钟与市场繁忙分钟对不对齐」——
   任何纯自身序列的统计量都没有这一条(§3 的推论 e 就是查它)。

## 2. 预测力在哪

**多余(删了不掉)**:`abs_`(abl_A 完全相同);外层 `cs_winsor`(win +1.7% / 0.35 对 base +1.8% / 0.38,ρo 0.99);
整个 mean / ema / decay_linear 记忆族(ut +3.1~+4.9%,ρo 0.87~0.99,valid 一律为负 −1.0~−3.8%)—— 只降换手,不改对象。

**承重(一换就塌)**:
- **mask 定符号**。`abl_B` 删掉 mask → ut −5.0% / valid −19.2%,且 **ρk 从 +0.26 翻到 −0.35**。
  没有任何别的逐分钟截面算子能替代它:nt_cs_winsor −5.6%、nt_cs_demean −5.1%、nt_cs_rank −16.7%、nt_cs_quantile_q50 −28.1%。
  ⇒ 关键不是「把截面标准化」,而是「底十分位 → 一个市场尺度的大数」。
- **mask 之内的叶子压缩,是全表最大的杠杆**:ut +1.8%(Amt)→ **+14.1%(sqrt)** → +10.0%(log),
  而凸变换直接炸掉(pow_1_5 −50.6%,cov 0.23 ✗)。机制:压缩拉近了 A 与 M 的距离,被遮分钟从「统治四阶矩的尖峰」
  变成「温和的抬升」,于是峰度**重新带上了成交额水平**——ρk 单调上行 0.26 → 0.60 → 0.82。
  也就是说 sub_A_sqrt 实际是「带底部下限的流动性水平因子」,不是形态因子。
- **日轴 reducer 承重,但方向与名字相反**:换成**保尺度**的统计量(day_std:ut **+13.0% / Lshp 2.85**,全表最好)
  或**持续性**统计量(day_ar1_coefficient +11.2%、day_autocorr_n1 +11.1%、day_q_stat_std +7.6%、day_hurst +4.8%),
  多头腿是原式的 3~7 倍;留着**标准化高阶矩**(kurt +1.8%、skew +3.3%)就是死的。
  而这些好替代的 ρo 只有 +0.12 / +0.04 / +0.04 / −0.09 / −0.19 —— **它们不是同一条因子**,是换了身衣服的已知成交额族(ρk 0.60~0.85)。
  ⇒ **这棵树里唯一有多头腿价值的内容,就是 mask 漏进来的成交额水平;而 day_kurt 的工作恰恰是把它除掉。**

**叶子不自由**:Amt → Volume 保住 ρo 0.72 但 ut −2.4%(价格混淆:按股数算的底十分位偏向低价票);
Amt → `in_pct(Amt,1)` 方向翻成 +1、ρo −0.16、ut −0.5%。**这棵树要的是水平,不是变化率** —— 「Ret 与量的变化率同类可互换」
在这里不成立,因为这个装置本质是一次截面流动性比较。表里**没试** Ret / Close 叶子(§5 补上)。

**窗口**:树内没有窗口。记忆族里**核比窗口重要得多**:min 5/10/30/60 = +6.2/+6.6/+6.5/+5.8(**平台**,且是唯一 valid 为正的一族:+4.2/+8.1/+9.2/+9.3);
mean/ema/decay +3.1~+4.9(valid 全负);max +0.5~+2.2;stddev +1.0~−5.4;**zscore 崩盘 −10.8~−28.6%、换手 12~33%**
(重尾量做自身历史标准化 = 纯尖峰探测器,F103 的教训在这里再现)。
多头半衰期:大表里 base 取到网格上限 hlL = 20;state.md 的 rev2 把它放到网格外(30/40/60/120)后 train +5.5/+5.8/+5.0/+3.9、
valid −3.9/−2.8/−2.8/−1.1 —— **延长半衰期只省成本,救不活 valid**。

## 3. 在市场的哪儿、什么时候有效

原式 [0] 的分段(段内净超额;括号是书的超配):
- **板块**:沪主板 +4.9%(+2.2pp)、深主板 +6.9%(−10.0pp)**正**;创业板 −3.5%、科创板 −6.9% **负**。已知族在四个板块都正(+14.8/+20.9/+18.9/+1.4)。**原式是主板专属**。
- **成交额(20日)五档**:段内 −4.0 / −6.8 / −6.9 / −3.6 / **+7.4%**,只有最活跃档为正;而书却超配最清淡档 +25.1pp。
  清淡档自带 **+15.1% 段等权超额**,最活跃档是 **−17.8%**。⇒ **它在钱所在的段里选股是负的,唯一会选股的段自带 −17.8% 拖累** —— 这就是它只剩 +1.8% 的全部原因。
- **市值**:最低档 +4.2%、40–60 档 +3.8%,其余 −1.0~−2.5%,没有单调规律(不是规模故事)。**价格**:只有最低档 +7.9%。
- **上市不足250日**(7.1%,段等权 −28.7%):原式 **−9.7%**,而已知族 +8.6%、候选 +7.6% ⇒ 原式在次新上是**有害**的。
- **近15日有冻结盘口**(6.5%,段等权 **−67.4%**):原式 **+12.1%**,而无冻结的 93.5% 段里只有 **−0.3%**。
  ⇒ **原式几乎全部的选股力都在那 6.5% 的封板/停牌票里**(与 F108「峰度类算子读到的其实是冻结状态」一致),
  而书对那一段是低配 −3.3pp,且该段作为一个段是灾难。
- **年份**:+5.5 / +6.4 / +1.4 / +5.8 / **−3.9 / −8.7**(2018→2023)——2021 之后转负;已知族 17.3/10.4/6.7/16.1/24.7/18.5 稳定。
- **状态**:只在**缩量日**有效(+4.7% vs 放量 −1.7%),与已知族完全相反(缩量 +11.8% vs 放量 +19.9%)。

**推断的原因**:mask 的门槛是**截面相对**的(当分钟全市场最低 10%),被标记的人群随市场总成交量漂移 ——
清淡时底十分位确实是真死的盘口,放量时连中等流动性的票也掉进去,标记变成噪声;
同时替换幅度 M[d,m] 本身随市场量放大,同一只票在放量日峰度会因为**市场级的原因**上升,
而尺度无关的统计量去不掉这个**市场状态泄漏**。2022–2023 的衰减则对应人群变化:创业板/科创板占比上升、
20% 涨跌幅与注册制改了封板人群,而原式正是靠封板票吃饭、在新板上亏钱的那一条。

**可检验的推论**(若机制成立应当看到):
(a) 把相对标记换成**绝对的死分钟直读**(`day_zero_ratio(Amt)` / `day_flat_ratio` / `day_flat_run_max`)应当复现 6.5% 段的选股力,且定义不随市场量漂移;
(b) 价值集中在 M/A 最大的地方 ⇒ 前置凹变换应单调地把它推向纯水平因子 —— **已被 sqrt / log / pow_1_5 证实**;
(c) 把 Amt 先按**当分钟截面位置**标准化(`nt_cs_rank(Amt)`)再折叠,放量/缩量的不对称应消失;
(d) 若封板通道是唯一活着的通道,用死分钟做**剔除筛子**叠在已知族上应该加分,而用它**排序**不应该;
(e) 被遮分钟与市场繁忙分钟的对齐应当有信息 ⇒ `day_centroid(masked)` 不应为零信息。

## 4. 相对已知成交额族的增量

- ρk:base +0.26;整个记忆族 +0.17~+0.38;而所有**有效**的替代 +0.60~+0.85。
- **overlay 全败**:已知族 + λ·原式,λ = +0.25/+0.5/+1.0 → ut 13.1 / 12.4 / 11.5,Lshp 1.87 / 1.75 / 1.62;
  λ = −0.25/−0.5/−1.0 → 10.8 / 9.0 / 3.7。**全部严格低于基准 15.4 / 2.22,且随 |λ| 单调变差 ⇒ 任何权重、任何符号都是纯稀释。**
- **残差 / 分桶**:res_known ut −0.4%(valid −7.3%)、res_liq +0.9%、bk_known −2.0% ✗、bk_liq −1.2% ✗。
  ⇒ **原式中与成交额族正交的那一部分,在多头腿上没有价值**(确认 state.md 的 `none_robust`)。
- **但这张表里确实有增量,来自 mask,不来自 reader**:
  `sub_C_day_std` = `day_std(nt_cs_mask_top_replace_mean_neg(abs_(Amt)))`:
  Lnet +12.0 / +15.5 / +13.0(基准 +12.6 / +22.3 / +15.4,valid 低 6.8 点,超出噪声),
  **Lshp 2.49 / 3.98 / 2.85 对基准 1.78 / 3.46 / 2.22,两段都高(+0.71 / +0.52),超出 ±0.3 噪声**;ρk 0.85、ρo 0.12;逐年 18.6/13.7/6.2/9.4/16.8/13.6 **全正**。
  解剖解释了为什么:mask 把**最死的票**的 day_std 抬高(大半分钟写着 M ≫ 自身水平),买低 std 的书就把它们挤出去了 ——
  书落在成交额**第二档**(超配 +43.9pp,最低档只 +5.9pp),而基准是全押最低档(+80.3pp)。
  最低档段溢价最大(+15.1%)但波动与摩擦也最大;第二档 +8.9%。
  而且候选是解剖十列里成交额五档**段内选股最平**的一列(−1.5/+1.6/+0.3/+0.3/+1.9,最差档只 −1.5%;**注意最低档仍是负的** ——
  2026-10-05 核表更正:原稿写的「唯一都不为负」不成立,准确的说法是最差档 −1.5%、其余四档 +0.3~+1.9),基准是五档里四档为负(−4.1/−5.3/−8.2/−5.2/+2.5);
  市值五档段内 +13.6/+9.3/+13.0/+7.6/+2.0 也全正;上下行差 +17.2 vs +7.9(基准 +23.0 vs +6.0)⇒ 更少的市场 beta 味道。
  **结论:mask 是一个可交易的「流动性下限」,把它加在已知成交额族上得到的是家族里形状更好的一位成员(ρk 0.85,必须按家族成员报),不是一条新因子。**

## 5. 改进方向(落成 `studies/F104_kurt_masktop_amt/hypo.yaml`,36 条)

A 把「底十分位标记」写成连续、无漂移的量:`nt_cs_rank(Amt)` 的日内折叠、`day_pos_ratio(nt_cs_quantile_q75(Amt))`(修 sub_B 的 dist ✗)。
B 死分钟直读(绝对口径):`day_zero_ratio` / `day_flat_ratio` / `day_flat_run_max` + `cross_mean` / `cross_max`;Ret 与 Amt 的零占比之差 = 封板排队。
C 保 mask、换掉尺度无关的 reader(day_mean / day_median / day_quantile_q25 / day_centroid),以及候选 day_std 配上基准那一模一样的 30 日均值与低尾记忆。
D 压缩杠杆的平台与叠加:Amt^0.25、sqrt × day_std、sqrt × ar1、log × day_std。
E 表里没试的叶子:|Ret|(abs_ 在那里不再是空操作)、Volume 上的 sqrt、5 分钟量变化率 + 保尺度 reader。
F 把解剖的分段写进表达式(`cs_last_low20` / `cs_last_high20` / `cs_first_high40`):已知族 + 流动性下限 / 剔封板 / 剔次新;原式只在最活跃 40% 或最清淡 40% 里做。
G 新算子:`cross_tail_mean_q25`(cross_min 的去噪版)、`cross_valid_count`(次新)、`in_madz`(自身历史标准化的孤立度)、`day_gini`、`day_signed_ratio`。

**一句话**:原式本身对纯多头用户没有增量(§4),但这条树里的 mask 是一个**真的、可交易的流动性下限**;
研究产物应该是 `day_std(nt_cs_mask_top_replace_mean_neg(abs_(Amt)))`(夏普两段都高于已知族),按已知族的改良成员上报,而不是按新因子。
