### rev2 — 多头口径下才会问的五个问题(`studies/F104_kurt_masktop_amt/rev2_long.py`,只用 train / valid;数字来自 `logs/F104_kurt_masktop_amt_rev2.log`)

用户 2026-10-04 把选拔口径定为**多头腿扣费后的净超额与纯多头夏普,半衰期按纯多头书选;延长半衰期带来的多头腿净超额是真的**。

| `f_exclcv`(0) | 19.1 = 10.1 + 9.0 | 23.0 = 20.5 + 2.6 | 4.1 / 4.0 | +4.9 / −1.4 |
| `f_std30`(0) | 15.2 = 10.2 + 5.0 | 24.4 = 23.4 + 1.0 | 2.6 / 2.1 | +2.5 / −1.1 |
| F001 成员(5) | 17.1 = 10.0 + 7.1 | 25.1 = 23.0 + 2.1 | 3.4 / 2.9 | +3.7 / −0.8 |
| 成交额水平 `l_amt30`(1) | 10.4 = 10.5 − 0.1 | 23.0 = 23.4 − 0.4 | 1.9 / 1.6 | −2.0 / −2.0 |

- train 上,每一本带读数的书的桶内选择都付得起自己的成本,还剩 +2.5~+4.9 个点。
- **valid 上除了换手最低的那一本(原式的 30 日均值,+0.5)之外,没有一本的桶内选择付得起成本**(−0.8~−3.4 个点):valid 上流动性家族多头腿的 23 个点就是「站在最不活跃的那一档」,谁也没有在位置之外挑出东西来。
  合成式用 2.9 个点的位置换来 1.6 个点的选择,再多付 1.9 个点的成本。
- **`f_kurt30` 的多头腿比原式好,不是因为读数更干净。** valid 上它比原式多 5.9 个点净超额(+0.1% 对 −5.8%):位置多 5.7(3.3 对 −2.4,它的多头十分位更少落在活跃股票上),成本省 2.0(4.2 对 6.2),
  桶内选择反而**少** 1.7(1.1 对 2.8)。归因是「流动性位置 + 更低的换手」,不是结构挑得更准。留出段上它比原式多 6.0 个点(+3.9% 对 −2.1%),那一段没法拆(不能再读),按 valid 的拆法最可能也是这两样。
- 逐年的桶内选择(毛,2018~2023):`f_exclcv` 14.8、9.9、10.2、0.9、2.8、2.3;`f_std30` 7.7、3.7、6.5、2.1、1.2、0.6;F001 成员 14.7、5.7、5.9、2.0、2.4、1.6;
  原式 6.2、10.0、12.4、7.8、6.2、−3.0;`f_kurt30` 10.2、12.6、9.8、1.1、0.5、2.2。2021 年起所有集中度读数的多头侧选择都掉到 3 个点以内(原式晚两年)。

可交易信号之间的秩相关(各自用多头口径的半衰期;train / valid):`f_exclcv` 与 `f_std30` 0.84 / 0.83、与 F001 成员 0.84 / 0.83、与 `amt30` 0.75 / 0.75、**与原式 0.35 / 0.22**;
F001 成员与 `f_std30` 0.96 / 0.96;`f_kurt30` 与原式 0.51 / 0.57;`f_cv30` 与原式 0.31 / 0.34;`f_std30` 与原式 0.26 / 0.11。
(原研究结论里写的「`f_exclcv` 与原式秩相关 0.37」是它与原式 30 日均值替身的**原始面板**相关;可交易信号口径是这里的 0.35 / 0.22。)

**这一节对结论的作用**

1. 「原式 + 多头最优半衰期」不够:它已经在网格上界,放宽网格 valid 仍为负。
2. 把这条因子用到已知家族上的三种办法 —— 剔除、相加、双重排序 —— 对多头腿都没有两段都站得住的增量:提纯读数的剔除与相加是 train 正(主要在 2018、2020 年)、valid 负或零;
   原式自己,相加是 train 负、valid 不显著,剔除则几乎碰不到那本书(train +0.2~+0.6 个点,valid −0.3~+0.1)。
3. 合成式 `f_exclcv` 的多头腿相对已知家族的差在两段上都不到 1.5 个标准误,符号相反;同一半衰期下也一样。它是已知家族的成员(秩相关 0.84),不是这条因子的升华。
4. 提纯式多头腿相对原式的改善是流动性位置和成本,不是更好的读数。
