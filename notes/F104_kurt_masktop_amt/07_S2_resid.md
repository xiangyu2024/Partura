**解读**

1. **H11 的主体成立:mask 做的事可以用一个显式的「对流动性水平取截面残差」替代。** `q_nat_ramt30` 不含 NT 面、不含排名阈值,
   train 上与原式相当(3.75 对 3.91),valid 上不输(1.91 对 1.47 —— 这个差在 ±0.3 的噪声边上,不能说更好),
   多头腿净超额在 valid 上从 −5.8% 回到 +0.3%,逐年 2022 / 2023 是 +1.66 / +2.59(原式 +1.63 / +1.11)。
   `q_nat_m30` 与它的秩相关是 0.89,只差「去掉流动性成分」这一步,valid 就从 −1.19 变成 +1.91:
   自身峰度与 30 日成交额的秩相关是 **−0.46**,这个方向错了的流动性暴露在 2021 年之后(不活跃股票大幅跑赢)足以把整条因子翻过去。
2. **条件化必须在慢的时间尺度上做。** 逐日版本(`q_nat_ramt`)只有 1.71 / −0.27。当时的读法是「幅度比名次重要」(H12);
   S3 的 `r_rankavg30` 把两件事分开之后,这个读法基本被否定 —— 差别主要来自条件化的时间尺度,见 S3。
3. **原式不只是「自身峰度 + 条件化」。** 如果 mask 只是一个粗糙的条件化,原式再做一次同样的残差应该与 `q_nat_ramt30` 相同;
   实际上它更差(2.23 / 0.57),两者的秩相关只有 0.63。对 30 日成交额中性化,原式的无成本夏普从 5.15 掉到 3.56(`q_nat_ramt30` 是 4.74 → 4.71,不动)。
   所以原式 = 一个被 mask 扰动过的峰度读数 + 一小段方向对了的流动性暴露(与 `ctl_amt` 秩相关 +0.14);把那段暴露拿掉,剩下的读数不如干净的自身峰度。
   S3 的 `r_addmed_ramt30`(地板写法做同样的残差,2.13 / −0.53)是同一件事的第二次出现。
4. **预测期越长越强**:`q_nat_ramt30` 的 rank IC 从 h=1 的 0.0212 单调升到 h=20 的 0.0400。它预测的是持续几周的漂移,不是次日反转。
5. **钱仍然在空头腿。** 多头腿只占毛价差的 24%;valid 的分位剖面是 Q1 −24.1%、Q2~Q5 在 +4.6%~+8.6%、Q8 / Q9 为负(−2.9% / −7.0%)、Q10 +5.9% ——
   「避开最集中的 10%」在两段上都成立,「越不集中越好」在 valid 上不成立。多头腿毛超额 +5.6% 靠的是 Q10 这一格,旁边的 Q9 是 −7.0%,不能当成稳的多头信号。

**修订(审查之后;证据在 07x_audit、07x_rev1)—— 上面第 1、3 点各有一句话说过头了**

- 第 1 点的「可以用显式残差替代」只对**十分位书**成立,而且主要是空头腿那一本。在 rank IC 上不成立:原式对 `q_nat_ramt30` + 流动性(线性或分桶)取残差之后还剩 54%~61% / 59%~84% 的 rank IC,
  反过来 `q_nat_ramt30` 对原式 + 流动性在 valid 上没有任何增量(t 0.1;控制分桶流动性之后 t −2.4)。它自己的可交易信号 rank IC 在 valid 上是 0.0042(t 1.0),不显著。
- 「valid 上不输(1.91 对 1.47)」里有流动性位置:线性秩残差的空头十分位偏在活跃股票上(`amt30` 分位 0.67),valid 空头腿 23.3 个点里 10.5 个点是这个位置。
  改成分桶内取秩(流动性位置真正中性),同一个读数的 valid 多空是 0.39~0.59,**低于**原式;「多头腿净超额从 −5.8% 回到 +0.3%」同样有 3.3 个点(毛)来自位置。
- 第 3 点的「把那段暴露拿掉,剩下的读数不如干净的自身峰度」要反过来读:在同一个流动性桶内比选择能力,valid 上原式的两条腿合计 21.1 个点,`q_nat_ramt30` 是 15.1 个点。
  `q_base_ramt30` 之所以差(2.23 / 0.57),是线性残差把原式在不活跃股票里的那段读数连同位置一起拿掉了,不是因为原式的读数更差。
