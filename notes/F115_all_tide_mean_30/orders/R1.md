## 想回答的问题

**一个问题:`N = L × (1/M)` 这三个通道里,预测力在哪一个;把「潮汐定位」整套机械拆掉之后还剩多少?**
附带一个必须补上的缺口:用户指定的第二条已知家族基准 `cross_mean(day_std(Amt), 30)` 在 R0 的
digest 里**没有打印出来**(R0 结果卡异常第 4 条),这一轮把它变成一等变体拿到全套数字。

看到哪种结果意味着什么:

| 结果 | 结论 |
|---|---|
| `a_plain_ret`(零假设,无潮汐)rIC 与多头腿接近 `v_base`,且 `rank_corr(v_base, a_plain_ret) ≥ 0.5` | **H1 被支持**:它就是个 20 日反转,前三层潮汐机械是装饰 → 下一步直接奔「相对动量族/已知家族有没有增量」 |
| `a_width_only`(纯几何 `M`)rIC 可观且与 `v_base` rank 相关 ≥ 0.3,并且它与 `known_stdamt_*` 的相关高于 `v_base` 的 | **H2 被支持**:它是成交量形状因子 → 下一步往 day_std(Amt) 家族归并 |
| `a_no_rate`(去掉 ÷M)或 `a_rank_pre`(先截面排序去尾)把 **valid 段 Q10 重新变成全档最高**,并抬高 valid `Lnet` | **H3 被支持**:多头端是 `1/M` 重尾污染的 → 这就是提纯方向,也是唯一可能救多头腿的路 |
| `a_abs`(幅度通道)自己有多头腿,且与 `ctl_ivol`/`ctl_range`/`known_stdamt_*` 相关明显高于 `v_base` | **H4 被支持**:是日内波动暴露 |
| **所有**变体都是 train 多头腿像样、valid ≈ 0 | **H5 被支持**:多头腿是 2018–2019 的制度产物 → 不要再找升华,尽早进入读留出段 + 成文 |
| `a_win30`/`a_win60` 的多头腿不比 `a_win20`(=原式)差甚至更好 | 窗口 20 不是调出来的,且「慢变特征」读法(`04_grammar.md` 性质 5)得到支持 |
