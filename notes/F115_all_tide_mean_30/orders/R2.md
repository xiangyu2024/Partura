## 想回答的问题

R1 已经把这棵树的内部结构钉死了(`÷M` 在秩空间接近恒等、几何通道没有信息、多头端不是重尾污染、
valid 的崩塌是毛崩塌)。**只剩两个问题没有答案,而且都是用户直接要的:**

**问题一(H6,最重要):对只能做多的用户,这条因子加到已知家族上有没有增量?**
已知的一半:`k_stdamt_mean30` = `cross_mean(day_std(Amt), 30)` 单独就 `Lnet +12.6% / +22.3%`、
`Lshp 1.78 / 3.46`,全面压过原式(`+5.6% / +0.2%`)。但两者的交易信号 rank 相关只有 **+0.26**,
所以「它就是已知家族」是**假的** —— 真正要量的是:**这个弱得多、却基本正交的东西,掺进已知家族里
能不能让已知家族的多头腿变好。**

**问题二(H10):「潮汐定位」是不是只是平均意义上挑了一段更短的中段(纯装饰)?**
R1 量到:`I` 几乎总贴窗口左端(p50 = 22)、`F` 几乎总贴右端(p50 = 143)、`M` 的 p50 = 95 近常数。
而对照组给出的边际是 +1.6pp(train)/ +2.5pp(valid):`a_no_rate`(两谷)+6.4% / +2.0% 对
`a_plain_ret`(固定两端、整窗)+4.8% / −0.5% —— 两段同号但都在 ±3pp 噪声带内,没有坐实。

**附带一个必须补的缺口**:用户指定的第二条已知家族基准 `cross_max(day_std(Amt), 9)` 只有 digest
「控制变量自己当因子」那一行的 `Lnet / LS / LTO`(06 §7:`+9.3% / +18.5%`),**没有 `Lshp`、没有
`Lgross`、没有分位剖面、没有 `dist`** —— 而最终候选必须含一条已知家族基准,所以要把它提成一等变体。

### 看到哪种结果意味着什么

| 结果 | 结论 |
|---|---|
| 权重曲线上存在某个 `w > 0` 使 **valid** 的 `Lnet` 和 `Lshp` 都**不低于** `w = 0`(纯已知家族)那一端 | **H6 被否定**:有增量 → 这个混合体进最终候选,第一推荐可能是它 |
| 权重曲线在 valid 上随 `w` 增大**单调下降**(或 `w = 0` 就是最高点) | **H6 被支持**:对只做多的用户没有增量 → 结论是否定的,最终候选里混合体只作对照 |
| 残差(对已知家族中性化后)的 `Lgross` 和 rIC 基本保住、但 `Lnet` 转负 | 按 playbook §1 这是**成本效应**,不等于 alpha 没了;要写成「正交但换手太高,交易不出来」 |
| 残差的 `Lgross` 和 rIC 一起塌掉 | 它那点内容就是已知家族的影子,`+0.26` 的相关已经把能用的部分吃完了 |
| `a_fixwin95` 的多头腿追上 `a_no_rate`(+6.4% / +2.0%,两段都在 ±1.5pp 内) | **H10 被支持**:潮汐定位是纯装饰,这棵树前三层(约 90% 的复杂度)可以整段删掉 → 提纯结论要改写成「连 Volume 都不需要」 |
| `a_fixwin95` 明显差于 `a_no_rate`、落在 `a_plain_ret`(+4.8% / −0.5%)附近或更低 | **H10 被否定**:定位带来的是真的逐股票-日信息 → 提纯结论停在「只删 `÷M`」 |
| `st.target(buyable=False)` 下 `short` 毛超额 / `LS` 明显下降而多头腿一个数不变 | **H9 被支持**:用户原表里 `LS 2.29` 好看的那部分是买不进的票撑的 → 报告里必须写明 |
