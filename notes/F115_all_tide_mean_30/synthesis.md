## 1. 它是什么(按算子定义逐层)

分钟轴是 **241 列**(`in_half` 源码:第 0 列 = 09:30 集合竞价,1–120 上午,121–240 下午),`in_slice` **两端都含**:

| 层 | 式子 | 实际算的 |
|---|---|---|
| `VS` | `in_slice(Volume, 31, 211)` | 成交量,**约 10:00–14:30**(切掉开盘半小时 + 尾盘半小时)的 181 分钟 |
| `SM` | `in_local_mean(VS, 5)` | **居中 9 分钟**均值(半径 d−1=4;算子元数据 `lookahead=True`) |
| `D` | `day_argmax(SM)` | 盘中量峰的分钟下标 |
| `F` | `day_argmin(in_slice_to_end(SM, D))` | 量峰**之后**(含 D 列)量最低那一分钟 |
| `I` | `day_argmin(in_slice_from_start(SM, D))` | 量峰**之前**(含 D 列)量最低那一分钟 |
| `G` / `J` | `day_locate(in_slice(Close,31,211), F / I)` | 这两分钟的 **Close** |
| `K`/`L` | `sub(G, J)` / `div(K, J)` | 峰前谷 → 峰后谷 的价差 / **收益率** |
| `M` | `sub(F, I)` | 两谷之间的**分钟数**(≥ 0) |
| `N`/`O` | `div(L, M)` / `cross_mean(N, 20)` | 每分钟平均收益 / **20 个交易日的均值** |

方向 `sg = −1` → 多头 = 这个「谷到谷的分钟化收益」最负的十分位 = **20 日日内反转**。

**名字和定义不一致的地方**:(a) 名字写 `30`,窗口是 **20**;(b) `mean` 指**日轴**而非日内;(c) 库里有
`day_tide_change` / `day_tide_speed`,但这棵树**没用**它们(那两个算子吃三个给定下标 a/b/c,这棵树自己从量曲线找
argmax/argmin,不等价);(d) **Volume 只贡献下标**,整棵树里成交量从不进入数值,只决定在哪一分钟读 Close
(所以 `leaf_Volume_amt` 的 ρo = +0.99);(e) `to_end` 与 `from_start` **在 D 这一列重叠** → `F ≥ D ≥ I`,
`M ≥ 0` 且量曲线单调时 `M = 0` → 除零。这就是 `abl_E` / `abl_H` 一删就 cov = 0.00(+388.6 / −335.1% 的垃圾数)
的原因:**E、H 是结构必需、不携带信息**,不要读成「这两个节点载重」。

## 2. 预测力在哪

**(a) 承重的只有「峰后那个读数点」。** `sub_I_*`(把 `I` 换成 `day_autocorr_n1` / `day_hurst` / `day_ar1_coefficient`
—— 值域 [−1,1],等于把 M 塌成 ≈ F)全不掉:+5.0/+2.2、+4.9/+2.0、+4.5/+1.3%,与 `abl_M`(M := F)+4.9/+0.8% 一致。
对称位置的 `sub_F_*` 全塌且方向翻:−3.6/−12.5、−3.3/−11.8、−8.3/−4.0%。**F(峰后谷)载重,I(峰前谷)不载重。**

**(b) 分母 M 是空转。** `sub→div` +6.2/+2.3%、`sub→mul` +5.3/+0.9%(都 ≈ 原式);整条删掉(`abl_N`)
+6.4/+2.0%、LTO 从 5.1% 降到 3.7%、hl20 最佳。算术上 `abl_K` 与 `only_K_R` 都塌成 `cross_mean(1/M, 20)`
(1/M ~ 1e−2 压过 N ~ 1e−4),两者数字一致(−2.8/+7.2% 与 −2.4/+7.4%)—— 这是 M 在原式里只起缩放作用的直接证据。
**÷J 不是空转**:`abl_L`(除 M 不除 J)+3.8/−4.3% 明显差于 `abl_N`(除 J 不除 M)+6.4/+2.0% → 把价差变成**收益率**才是必需的。

**(c) 叶子基本可互换,幅度完全没用。** Close → Low/Open/High/Vwap:ut +4.2/+4.0/+4.2/+2.6%(都 ≈ 原式 +4.1);
Volume → Amt:ρo +0.99。`rk`(EMA 前先 cs_rank)+5.5/+0.3% 与原式逐位级一致 → **信息全在秩里,幅度是噪声**。
`cs_winsor` +5.5/+1.6% 略好,与此一致。唯一不能换的叶子变换是**在叶子上做变化率**:`leaf_Volume_volchg`
(`in_pct(Volume,1)` 再平滑)+4.0/−5.0%,而把平滑**替换**成 `in_pct` 的 `nosc_C_in_pct` +4.7/+3.2% —— 说明
「量的变化率」可以用,但不能叠在平滑之外。

**(d) 窗口:外层有平台,内层没有。** `cross_mean` 的 10/15/20/30/60 → ut +3.7/+4.0/+4.1/+4.4/+4.4%(**真平台**)。
内层平滑半径 3/5/10/15 → ut +4.5/+4.1/+5.2/+5.1%,而**完全不平滑**(`abl_C`)+6.5% 最好 → 非单调,
内层这个参数是噪声,方向是「越少加工越好」。

**(e) 121 个变体里只有两条真改进,而且都把 valid 的「毛」超额救回来了**(原式 valid 是**毛**崩:+9.4% → +4.1%):

| id | 改了什么 | Lnet tr/va/ut | Lshp ut | 毛 tr/va | 逐年 2018→2023 | ρo / ρk |
|---|---|---|---|---|---|---|
| `abl_C` | M 分母里的 9 分钟平滑去掉 | +6.0/**+7.4**/+6.5% | **1.49** | +9.5/**+10.8%** | +14.7/+5.3/−0.2/+4.3/+6.2/+9.7 | .79/.22 |
| `rank_K` | 两个锚点先各自 `cs_rank` 再相减 | +5.3/**+9.7**/+6.6% | **1.48** | +8.7/**+13.1%** | +9.2/+6.0/−2.3/+8.4/+8.2/+12.4 | .81/.32 |
| `v_base` | — | +5.6/+0.2/+4.1% | 0.83 | +9.4/+4.1% | +6.4/+13.6/+2.8/−0.6/−0.4/+1.6 | 1/.26 |

两条都不是换手假象(毛也好),逐年也比原式稳得多 —— 原式 2019 之后就死了,它们到 2022–2023 还有 +6~+12%。

**(f) 半衰期曲线暴露了本质问题。** 原式 hl0 = **−6.2%** → hl10 = +5.6%,而**毛**超额在 hl 0→20 走平
(+9.8…+7.3%):净超额**全部**是换手从 ~21% 压到 5% 换来的。`iso_N`(不做日轴平均)+0.0/−7.0%、LTO 14.2%、毛 +10.8%。
已知族正好相反:hl0 就 +12.6%、LTO 3.4%、越平滑越差(hl20 +8.4%)。
**它的信息是日频、薄的(毛 ~9% 封顶);已知族的信息是慢、厚的。** 这一条决定了它在扣费口径里永远打不过已知族。

**(g) 两个锚点单独看都是「低价书」。** `iso_G` +3.7/**+11.4%**、LTO 1.2%、ρo **+0.02**、ρk +0.42;`iso_J` +3.4/+10.8%。
它们就是价格水平(sg −1 = 买低价)。`K = G − J` 的作用正是**把价格水平消掉**。表里一大批
「train ≈ 0、valid +5~+11%、LTO 0.6~1.7%」的行(`sub_L_add`/`sub_K_mul`/`sub_L_sub`/`only_L_R`/`abl_K`/`fold_*`)
全是这同一条低价/低流动性慢倾斜漏出来——**不要读成「因子在 valid 有效」**,valid 段(2022–2023/8)恰好是慢倾斜大赚的一段。

## 3. 在市场的哪儿、什么时候有效

**(a) 板块:顺序与日涨跌幅上限一致。** 段内 沪主板 +3.8 / 深主板 +5.0 / 创业板 +2.0 / **科创板 −22.8%**
(段等权 −0.3/−1.1/+1.8/+4.1%),而全市场多头书**超配科创板 +6.6pp**。十个变体在科创板全是 −17.6 ~ −33.7%。
**推断**:上限 10% 的主板里,盘中放量后的价格漂移是散户驱动的、会反转;上限 20% 的创业板/科创板(科创板还有
50 万门槛、机构占比高、分钟流动性薄)里,量峰之后的漂移更接近趋势延续,而且两个「谷底分钟」几乎没有成交、
`day_locate` 读到的是噪声价。**可检验推论**:(i) 用「近 60 日单日最大毛涨幅」当上限代理分桶,段内差异应该复现
板块排序;(ii) 科创板的 `day_gini(Volume)` 应更低(量峰更不明显),`|rank IC|` 应更小。
→ 假设 `h_bk_limit` / `h_sieve_limit`。

**(b) 纯多头的死结:选股力和段溢价在相反的一侧。** 成交额五档**段内** −1.1/−4.6/−2.0/+2.7/**+7.2%** —— 选股力
只在最活跃的两档;而**段等权超额** +15.1/+8.9/+2.6/−6.0/**−17.8%** —— 溢价全在最清淡的两档。市值段内是平的
(+1.6/+1.9/+3.3/+2.2/+1.9%),所以它**不是**规模/流动性因子(`bk_liq` +5.4/+0.7% 与原式一样,中性化不掉)。
已知族正好是镜像:段内 −4.1/−5.3/−8.2/−5.2/+2.5%(几乎没有桶内选股力),却超配最低成交额档 **+80.3pp** ——
**它赚的是流动性溢价的倾斜,不是选股。** F115 的书对这个倾斜几乎是中性的(最低档只超配 +3.0pp、最高档 −2.0pp)。
**这就是任何固定权重 overlay 都失败的机制原因**,见 §4。
→ 假设 `h_bk_amt` / `h_sieve_amt` / **`h_mix_known_bk*`(整批优先级最高)**。

**(c) 段内最强的两段都不可投。** 次新(上市 < 250 日,7.1%)段内 **+12.4%**(`abl_C` +15.1、`sub_M_div` +16.7,
但 `rank_K` −3.4%),段等权 **−28.7%**;近 15 日有冻结盘口(封板/停牌,6.5%)段内 **+18.2%**(全表第一),
段等权 **−67.4%**。段内 + 段等权 = −16% / −49% → **对纯多头是净亏**。
**推断**:这两段的量曲线有真正尖锐的峰(次新的炒作、封板瞬间的放量后冻结),所以 F115 的定位机制在那里最有信息 ——
它是「盘中有没有资金事件」的读数,事件越干净越准。**可检验推论**:`day_gini` / `day_flat_ratio` 越高,段内 IC 越高;
但这笔 alpha 对纯多头不可兑现。→ 假设 `h_sieve_flat` / `h_bk_flat` / `h_bk_age`(一正一反,用来钉死这一点)。

**(d) 时间:只在高波动的市场里有效。** 市场波动高于中位 **+10.4%** vs 低于中位 **−2.2%**(十个变体一致:
+7.6~+12.5 对 −0.9~+2.0);已知族 +18.5 / +12.4%(几乎不挑)。涨跌市:原式 涨 +3.1 / 跌 +5.4%,
已知族 涨 **+23.0** / 跌 +6.0% → **两者在跌市互补**。截面离散度、放量/缩量都没有切分力。
**推断**:高波动 + 跌市时,盘中放量多是恐慌性卖出,次日反转最强;低波动时量峰只是流动性噪声。
→ 假设 `h_regime_mix` / `h_regime_mix_rk` / `h_regime_mix_dn`(用 `sigmoid(z)+sigmoid(−z)≡1` 做无常数凸组合)。

## 4. 相对已知成交额族:没有增量(证据三条)

(i) **六条 overlay 全部严格差于已知族单独**,且单调:w = +0.25/+0.5/+1.0 → ut +14.2/+12.9/+11.9%,
w = −0.25/−0.5/−1.0 → +10.9/+8.7/−3.6%,已知族 **+15.4%**。w = 0.25 的 −1.2pp 在噪声带内 →
结论是「**拿不到增量**」,不是「掺进去会亏」。
(ii) **ρk 只有 +0.26,且中性化不掉**(`bk_liq` +5.4/+0.7%、`bk_known` +5.2/−0.4% 都 ≈ 原式)→ 它**不是**已知族换个写法,
是一条独立但更弱的信息。残差化会杀掉 valid(`res_liq` +4.4/−2.6%、`res_known` +3.7/−3.3%)→ valid 里它剩下的那点东西
本来就是与已知族重叠的部分。
(iii) §3(b) 给出了机制:**倾斜方向相反** —— 已知族要的是清淡票的段溢价,F115 的选股力在活跃票里。线性混合是在同一个
秩空间里打架;**表里没试过的那一格是「倾斜交给已知族、F115 降级为桶内排序器」**(`add(cs_rank(known), mul(cs_bucket_rank(F115, Amt), w))`)。

## 9. 可迁移的结构教训(写进 `lab_findings`)

1. **「小量 ÷ 小整数下标差」这种量纲失配会吞掉整个因子**:原式 N = L/M,L ~ 1e−4 而 1/M ~ 1e−2(s1 的 `abl_K` 与 `only_K_R` 逐位一致即为证据)。此时**改动「定位这两个下标的子树」就是降污染**:未平滑的量曲线把极值分钟推到更靠两端,M 更大更分散,1/M 权重下降 —— `h_rawvol_divM_only` 的 +5.1pp valid 增益**不是信号变了**。失效条件:只在分子分母量纲差 1~2 个数量级时成立,且不能直接删掉分母(`h_pure_sm` 1.06 < 1.72)。
2. **`day_gini`(日内量)≈ 已知成交额族**:`h_gini_vol` 的 ρk = **+0.77** 而 ρo 只有 +0.10。
   想用「日内量的集中度」去跟成交额族去相关行不通。失效条件:仅验证过 20 日均值形式与 Amt 族。
3. **「train ≈ 0 / valid +6~+13% / LTO 0.6~1.7% / ρk 0.3~0.8」是 2022–2023 低价低流动性慢倾斜的指纹**:s2 里 `iso_G` +3.7/+11.4、`sub_K_div` +1.6/+10.3、`only_K_R` −2.4/+7.4、`h_gini_vol` −2.3/+12.6、`seg_lowliq_p` +1.7/+13.1、`h_posratio` −5.5/+7.9 全是同一形状。见此形状先查 LTO 和 ρk。
4. **ρk ≈ 0.26 的弱信号不值得扫混合**:9 格里最好的只是打平。省轮次的做法是只跑 `w=+0.25` 固定权重和
   `w=+0.25` 桶内两格;两格都不超基准就可以下「零增量」的定论。
5. **`cs_last_high20(y, x)` 类筛子里 `neg` 的位置决定一切**:按 `_lexi` 定义 x 最高 20% 的名字被压到 y 排序之下,复合信号的多头腿永远在顶部,所以原因子多头腿是最低十分位时必须写 `cs_last_high20(neg(core), x)`。段/筛变体必须 p/m **成对**跑,否则会把「符号条件化」误读成「这一段无效」(`seg_hiliq_p/m`、`seg_lowliq_p/m` 四格)。
