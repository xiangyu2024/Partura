## 解读


(第 3 轮主研,Opus 5。裁决的完整版在 `05_hypotheses.md` 的「R2 裁决」一节,这里只写这个阶段
自己的五条读法。)

### 1. `a_fixwin95` 的失败是**双重**的,而且第二重比第一重更有力

第一重是表现:`Lnet +4.3% / −9.7%`,比零假设 `a_plain_ret`(+4.8% / −0.5%)更差,是全部 14 个变体里
valid 最差的一个。第二重是**相关**:`rank_corr(v_base, a_fixwin95) = +0.54`,低于 playbook §6.3 的 0.8,
所以它**根本不是这棵树的一个版本**。即使它表现好,也不能当成「把前三层删掉」的提纯结论 ——
那会是「换了一条因子」。两重合起来把 H10 钉死:**潮汐定位带的是真的逐股票-日信息,前三层不能删。**

一个提醒(R1 解读里差点犯的错):`I`/`F`/`M` 的**分位数**近常数(p50 = 22 / 143 / 95)说的是
**边际分布**窄,不是说它们逐格不变。固定成中位数几何之后预测力反而更差 → 信息正好在「逐格偏离中位数」
那一部分。写报告时不要把「分位数近常数」写成「定位没用」。

### 2. 「`a_fixwin95` 与 `a_plain_ret` 的相关(+0.61)高于与 `a_no_rate` 的(+0.56)」是条有意思的旁证

两者都是「固定端点的一段日内收益」,只是窗口长度不同(95 对 181 分钟),所以它们彼此更像;
而「两个量能谷」是另一种东西。这进一步说明本因子的 `Volume` 子树不是在选长度,是在选**位置**。

### 3. `k_stdamt_max9` 现在有全套数字,它和 `k_stdamt_mean30` 在 valid 上基本打平

`k_stdamt_max9` `Lnet +13.7% / +22.2%`、`Lshp +1.99 / +3.59`、`LTO 4.5%`、`hlL=5`;
`k_stdamt_mean30` +12.6% / +22.3%、+1.78 / +3.46、`LTO 3.4%`、`hlL=0`。两段都在噪声带内打平,
两张分位剖面都干净单调、Q10 全档最高(max9 valid Q10 **+27.3%**)。
→ **「用已知家族而不是这条因子」这个建议不依赖于选哪一个成员**,这对留出段很重要:
它给了 J3 一个内置的稳健性检查(两条已知家族基准同时塌才算对照系统失效)。
`mean30` 仍作第一推荐,因为 `LTO` 更低(3.4% 对 4.5%)、`hl=0` 不需要再调参。

### 4. 两个混合体彼此几乎是同一条线(+0.9673),再一次说明 `÷M` 没有内容

`m_blend_base_k30`(原式 + K30)与 `m_blend_pure_k30`(提纯版 + K30)相关 +0.9673,
`Lnet` 差 1.3pp(train)/ 0.6pp(valid),都在噪声带内。既然掺进同一条强腿之后两者无法区分,
`÷M` 这个节点在混合口径下同样没有内容 —— 和 S1 的直接证据(`rank_corr(N,L) = +0.9582`)一致。
顺带:两个混合体与 `known_stdamt_mean30` 的相关约 **|0.83|**,高于 50/50 正交相加应有的 ~0.71,
说明混合体的截面排序其实**偏向已知家族那一边**(本因子覆盖率只有 0.69,缺值格子由另一腿主导),
这也是「增量拿不到」的一个机械原因。

### 5. 逐年表是本阶段最该进报告的一张表

`c_pure` 2018 +7.8% / 2019 +13.4% / 2020 +5.2% / **2021 −1.3% / 2022 +0.9% / 2023 +3.6%**,
对照 `k_stdamt_mean30` 同六年 +17.3 / +10.2 / +6.6 / +16.0 / +24.6 / +18.3%。
**衰减是渐进的、起点在 2021 年**,不是 train/valid 切分造成的断点,也不是环境(对照组同期在变好)。
留出段(2023.08 起)是这条下行线的自然延长 —— 这就是 J1 判据(`f_orig` 留出段 `Lnet < +3%`)
背后的全部先验。
