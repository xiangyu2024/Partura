# 结构语法:同一个三元组嵌套两层

(主研 R1 写。基于 `01_expression.md` / `02_operators.md` / `03_decomposition.md` 的源码事实,
全部是**代数推导**,不含实测。本文新增了三条 R0 没有的推导,标成 **【新】**。)

字母沿用 `01_expression.md`:
`A=day_mean(Ret)` → `B=ts_max(A,5)` → `C=sub(B,-5)` → `D=cs_demean(C)` → `E=ts_max(D,30)` →
`F=pow_2(E)` → `G=ts_max(F,20)` → `H=mul(G,5)` → `I=cs_demean(H)` → `J=pow_2(I)` →
`K=ts_max(J,30)` → `L=pow_1_5(K)`。

---

## 1. 语法骨架

这棵树不是"事件 → 记忆 → 门控 → 放大",它是**同一个三元组嵌套了两层**:

```
三元组 T(x) = 记忆(ts_max) → 相对化(cs_demean) → 折叠(pow_2)

第一层  T₁:  A --ts_max 5--> B --cs_demean--> D --ts_max 30--> E --pow_2--> F
             (收益)                    (相对收益)      (34 天相对 MAX)   (幅度²)
第二层  T₂:  F --ts_max 20--> G --cs_demean--> I --pow_2--> J --ts_max 30--> K
             (54 天最大相对极端幅度)   (离截面典型幅度的差)  (距离²)  (30 天内最远的一次)
放大:        K --pow_1_5--> L
```

| 槽位 | 第一层 | 第二层 |
|---|---|---|
| 事件原子 | 一个交易日(`day_mean` 把 241 根分钟收益压成一个数) | 一个"极端幅度读数" |
| 记忆 | `ts_max(·,5)` + `ts_max(·,30)` = 累计 34 天 | `ts_max(·,20)` + `ts_max(·,30)` = 在 F 之上再累计 49 天 |
| 相对化 | `cs_demean` 作用在**收益**上 | `cs_demean` 作用在**极端幅度**上 |
| 折叠 | `pow_2`:丢掉"涨/跌"的符号 | `pow_2`:丢掉"比典型更极端/更平静"的符号 |
| 门控 | **没有** | **没有** |

**门控这个槽位在这棵树上是空的**:`mul(G,5)` 和 `sub(B,-5)` 的第二个操作数都是裸常量
(`01_expression.md` 已指出),树里没有任何"两路数据信号相乘"。F001/F101 反复要问的
"门控还是两路信号"在这里不存在,不要套那套实验。

## 2. 两层各自在做什么(机制读法)

- **第一层的产出 `E`** = `ts_max(cs_demean(ts_max(day_mean(Ret),5)),30)` = "过去约 34 个交易日里,
  这只股票相对截面最突出的那一天有多突出"。这**就是经典的 MAX / lottery 因子**(Bali-Cakici-Whitelaw 那一类)
  的直写,只是用了"分钟收益日内均值"而不是日收益,并且先做了截面去均值。
- **`F=E²` 是第一次折叠**。`E` 可正可负:`D` 每天截面均值为 0,`E` 是 `D` 的 30 日最大值,
  对多数股票 `E>0`(均值为 0 的序列取 30 日最大值通常是正的);但对**持续疲弱**的股票,
  "连最好的一天都低于截面均值"会给出 `E<0`。平方把这两类股票折到同一端:
  **"曾经暴涨" 和 "连最好的一天都很差" 在 F 上无法区分**。
- **第二层的产出 `G`** = 54 天窗口内最大的"相对极端幅度²"。**`G` 是整棵树里最后一个单调的幅度量**
  (恒 ≥0,越大 = 越极端)。`G` 之后的一切都不再是"幅度排序"。
- **`I=cs_demean(G)`、`J=I²` 是第二次相对化 + 折叠**。这一步把因子的含义从
  "这只股票有多极端" 改成 **"这只股票的极端程度离截面典型的极端程度有多远"**。
- **`K=ts_max(J,30)`**:因为 `J≥0`,这个 max 是**合取式惩罚** —— 过去 30 天里只要偏离过一次,
  就一直被记住 30 天。要进"低 K"那一端,必须**连续 30 天都贴着截面典型值**。
- **方向 `sign=-1`** 于是读成:**做多"极端程度最接近截面典型值、且连续 30 天没偏离过"的股票;
  做空"极端程度离截面典型值最远"的股票。**

## 3. 【新】外层折叠的中心是错位的 —— 本研究的核心机制猜想

`G` 是 "平方 → max → max" 的产物,截面分布**极度右偏**(下界 0,右边是暴涨股的长尾)。
因此当天的截面均值 `mean_cs(G)` 被右尾拖到**远高于中位数**的位置。后果有两条:

1. **"离中心近" ≠ "在分布中间"**。`sign=-1` 要找的是 `(G − mean_cs G)²` 小的股票,
   也就是 `G ≈ mean_cs(G)` —— 那是一条**只有偏高分位才到得了的窄带**,不是分布的中间。
2. **大多数安静股票的 `J` 彼此几乎相等**。对 `G ≪ mean_cs(G)` 的股票,
   `J = (G − m)² ≈ m² − 2Gm`,其中 `m = mean_cs(G)` 当天对所有股票是同一个数。
   于是这些股票的 `J` 只差一个很小的 `2Gm` 项,**挤在一个几乎退化的平台上**。

这给了 `dist = 0.5847` 一个结构性的候选解释(`distinct_fraction` 的定义见
`partura/diagnose.py:136`:抽样日上"不同取值数 / 有值股票数"的中位数)。
**0.5847 意味着典型一天有约 41% 的有值股票与别的股票取值完全相同** —— 该函数自己的 docstring 写着:
取值档数少的因子,"十分位书的成员资格是由并列打破规则、也就是股票代码顺序决定的"。
如果并列集中在低 K 一端,**多头腿的成员就是按代码顺序挑的,那条腿的数字没有意义**。
这是 `05_hypotheses.md` 的 H1,也是 R1 最该先打掉的一条。

还有一个更直接的退化源:**一字板 / 全天无成交的股票,`Ret` 的 241 根分钟全是 0 → `A = 0` 精确**。
这样的股票 `B=0`、`D=−mean_cs(B)`、`E`、`F`、`G`、`I`、`J`、`K` 全部只由**市场级**的量决定,
于是**所有这类股票在同一天拿到完全相同的因子值**。A 股这类票不少,这是并列的另一个候选来源。

## 4. 【新】两处精确冗余(不是"影响很小",是恒等)

R0 只找到一处(`sub`),实际有两处,而且第二处更重要:

1. **`sub(B,-5)` 恒等**:`cs_demean(B+5) = cs_demean(B)`。R0 `03_decomposition.md` §3 已推。
2. **`mul(G,5)` 对排序是恒等的【新】**。常数 5 是正数,沿路一路提出来:
   `cs_demean(5G) = 5·cs_demean(G)`(线性)→ `pow_2` 给 `25·cs_demean(G)²`
   → `ts_max(25x,30) = 25·ts_max(x,30)`(1 次齐次)→ `pow_1_5` 给 `125·(...)^1.5`。
   所以 **`L` 恰好等于"删掉 mul 的那棵树" × 125**。EMA 是线性的,十分位排序对正尺度不变,
   因此 `mul(G,5)` 对**方向、半衰期、两本书、所有分段数字**的影响**精确为零**。
   → 工单 R1 的 `c6_nomul_nosub` 就是这条推导的审计:它应当与 `v_base` 逐项相同、rank 相关 = 1.000。

## 5. 【新】外层四个算子除了 `cs_demean`,对排序没有贡献

把第二次 `cs_demean` 删掉,外层 `mul → pow_2 → ts_max(·,30) → pow_1_5` 全部作用在**恒非负**的 `G` 上,
而它们逐个都是**单调递增**变换,且**单调递增变换与 `ts_max` 可交换**:

```
去掉 cs_demean 后:L' = ((5G)²  的 30 日 max)^1.5
                      = (25 · ts_max(G²,30))^1.5
                      = 125 · (ts_max(G,30))³        ← 因为 G≥0,平方单调,max 与单调变换可交换
                      ≡(秩相同) ts_max(G,30) = ts_max(F,49)
```

**结论:整个外层区块唯一改变排序的算子就是第二次 `cs_demean`。** 这把"提纯"的问题收得非常窄:
要么第二次 `cs_demean` 是这条因子的全部特色,要么这棵 12 节点的树可以砍掉一半。
→ 工单 R1 的 `c4_nodemean_out` 直接测这件事(写成 `ts_max(ts_max(F,20),30)`,免去 49 不在窗口池里的问题)。

顺带两条同源的代数事实,后面写变体时要用:
- **嵌套 max 可合并**:`ts_max(ts_max(x,a),b) = ts_max(x, a+b-1)`。所以删掉内层 `pow_2` 会让
  `ts_max(·,30)` 和 `ts_max(·,20)` 相邻、合并成 49 日 max(`c7_nofold_in`)。
  `ts_max` 的窗口池是 `[1,5,10,20,30,40,50]`(自己 `ops` 查过),**49 不在池里**,所以要写成嵌套形式。
- **`pow_1_5` 在非负输入上严格单调递增 → 当天截面排序完全不变**。它只能通过
  "现在的口径是先 EMA 再排序"(`study_playbook.md` §3)影响交易信号。
  所以 `c5_nopow15` 在**固定半衰期表的 hl=0 行上必须与 `v_base` 完全相同**;不同就说明我读错了。

## 6. 【新】EMA 对一个 6 次齐次量几乎不是"平滑"

`L` 对 `Ret` 是 **6 次齐次**(R0 已推)。一个 6 次幂量的截面分布跨若干个数量级,
对它做因果 EMA,结果**被窗口内最大的那一个值完全支配** —— EMA 在这里的作用更接近
"再加一层 max",而不是"抹平噪声"。这和实测的两件事吻合,也是一条可检验的读法:

- 半衰期 sweep 上 `hl=1` 是一个**尖峰而不是平台**(`Lshp`:hl=0 → 0.18、**hl=1 → 0.39**、hl=2 → 0.24、
  hl=3 → 0.23、hl=5 → 0.13、hl=10 → −0.02;`06_baseline.md` §2/§4)。真正靠平滑赚钱的因子
  在半衰期网格上是一段平台,不是一个点。
- 所以"**原式 + 多头最优半衰期**"这条必过的基准,对这条因子**已经就是 hl=1**(两种口径都选到 1),
  没有"换成 10 或 20 就多赚几个点"的余地 —— 这和第一组因子不一样,要写清楚。
  → 推论:`c9_rankfold`(把尺度压进 `[0,1]`)如果让半衰期从尖峰变成平台,就同时验证了这条读法。
