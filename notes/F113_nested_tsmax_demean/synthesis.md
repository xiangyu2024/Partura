## 1. 它是什么(按**源码定义**逐层)

节点记号取自 `iso_*` / `abl_*` 的 why 字段:

| 节点 | 表达式 | 源码说它**实际**算什么 |
|---|---|---|
| A | `day_mean(Ret)` | 当天全部分钟收益的**等权**均值(没成交的分钟 Ret=0 也算一票) |
| B | `ts_max(A, 5)` | 近 5 日 A 的最大值 → 「最近一周最强的那一天的平均分钟收益」 |
| C | `sub(B, -5)` | **= B + 5**。常数被下一层 `cs_demean` 精确抵消 → 信息上是 no-op,但见 §2(a) |
| D | `cs_demean(C)` | B − 当日**截面均值**(是 mean 不是 median:会被当日涨停群拉动) |
| E | `ts_max(D, 30)` | 近 30 日 D 的最大值 → 「近 ~34 日内相对市场最强的一次脉冲」(**带符号**) |
| F | `pow_2(E)` | `pow_(x, 2)`:e>1 走 `x**2` 分支 → **毁掉符号**。「大幅上冲」与「长期远低于市场」同值 |
| G | `ts_max(F, 20)` | 再取 20 日最大 → 实际是 ~53 日的极端幅度平方 |
| H | `mul(G, 5)` | 正常数缩放,秩上完全无用(`abl_H` 与 `sub_H_div` 与原式**逐格相同** +0.7%) |
| I | `cs_demean(H)` | 第二次去均值:「我的 53 日极端幅度离市场典型值有多远」 |
| J | `pow_2(I)` | **第二次折叠**:上面那个距离的平方(两侧都变大) |
| K | `ts_max(J, 30)` | 近 30 日这个距离的最大值 → 「30 天里偏离过多少」 |
| L | `pow_1_5(K)` | K ≥ 0 故 `x**1.5` 保序 → 秩上无用(`iso_K` +0.8% vs 原式 +0.7%) |

**最终排序 + sg = −1 ⇒ 多头腿 = 「53 日极端脉冲幅度最接近市场典型值、且 30 天里没偏离过」的股票,
即"最不起眼"的那批。** 空头腿同时拿两条尾巴 —— 这就是多空夏普 2.54 / 底腿 −25.2% 而多头腿只有 +0.7% 的原因:
钱在空头腿,多头腿是被折叠路由出来的无信息窄带(与上一轮 `07x_2` §1 的结论一致)。

**名字与定义不符的地方(全部来自 `study.sh src`)**

- `pow_2` / `pow_1_5` / `pow_2_5` / `pow_3` **不是** signed power:`pow_(x,e)` 只在 e ≤ 1 时走 `sign(x)·|x|^e`,
  e > 1 直接 `x**e` ⇒ `pow_2` 折叠符号、`pow_1_5` 对负数返回 **NaN**。而 `pow_05` / `signedpower` **保留**符号。
- `sqrt(x) = sqrt(|x|)`、`log(x) = log(|x|)`(|x| ≤ EPS 时 NaN)—— 这两个名字听着不折叠,实际都折叠。
- `sub(B, -5)`:名字是减,实际是给一个 ~1e-4 的量加上 5(见 §2a)。
- 表里的 **`dist` 不是"与已知族的距离"**,是 `diagnose.distinct_fraction`:
  逐日「不同取值数 / 有值股票数」的中位数 —— **并列/量化程度**。dist 低 = 十分位书的名单由代码序决定。

## 2. 预测力在哪(同类变体并排看)

### (a) 承重的其实是一个精度 bug:`sub(x, -5)` 砸掉 78% 的截面分辨率

`iso_B`(= B)dist **1.00**、ut −2.6%、ρk +0.50;`iso_C`(= B+5)ut **−2.6%、ρk +0.50 完全相同**,
但 dist 掉到 **0.22**;`iso_D` 同样 0.22。B 的量级 ~1e-4,float32 在 5.0 附近的分辨率是 4.8e-7,
加 5 等于把叶子量化到几百级。证据链闭合:`abl_C`(删掉这个节点)ut +0.6%(与原式 +0.7% 同格)而 **dist 回到 1.00**;
更极端的 `sub_H_add` / `sub_H_sub`(把 +5 加在 ~1e-8 的 H 上)dist **0.00**、LTO 0.2% —— 信号被彻底抹平。
**后果:整个"有信息"的子树族(`iso_D~I` dist 0.22–0.26、`abl_I` 0.28、`abl_D` 0.37)不是没信息,是被这个常数判了 dist 门槛的死刑。**
→ 第二批 `h_s1`~`h_s7`、`h_g1` 全部是"去掉 +5 再跑一遍"。

### (b) 真正多余的节点(删了不掉,秩上逐格相同)

`C`(`abl_C` +0.6)、`H`(`abl_H` +0.7、`sub_H_div` +0.7)、`L`(`iso_K` +0.8)、顶层 `cs_winsor`(`win` +0.7)、
顶层 `cs_rank`(`rk` +1.1)。**12 个节点里有 4 个在秩上完全没用。**

### (c) 第二层折叠(I + J)是损害,不是预测力

`abl_I`(删第二次 demean)ut **+8.6% / Lshp 1.21**;`abl_J`(删第二次 pow_2)ut **+12.4% / 2.38** —— 比原式多 7.9 / 11.7pp。
但两条都爆门槛:`abl_I` dist 0.28(§2a 的病),`abl_J` **cov 0.43**。
cov 0.43 的机制很干净:J 位置上**保号**的算子(`abl_J`、`sub_J_pow_1_5`、`sub_J_pow_05`、`sub_J_signedpower`、`sub_J_inv`)
让 K 可能为负 → 外层 `pow_1_5` 返回 NaN → 只剩 43% 的票;而**折叠**的算子(`sub_J_abs_` +0.8%、`sub_J_sqrt` +0.8%,cov 1.00)
全都和原式一样。**五条保号的全在 +11.8~+13.7%,两条折叠的全在 +0.8% —— 这个二分说明 abl_J 的 +12.4% 与
"把没有过上冲的 57% 股票剔出去"这个 universe 筛选完全混淆,无法从本表判断谁的功劳。** → `h_s1` / `h_s2` 就是拆这一对。

### (d) 叶子可以互换的地方

- `day_mean` → **`day_gini`**:`nosc_A_day_gini` +5.7 / +8.1 / **+6.3%**,Lshp **+1.44**,cov 1.00、**dist 0.97**、ρo +0.06 —— **全表唯一既过门槛又显著赢原式的变体**(+5.6pp,出噪声带)。
  同位置其它日内算子全不行:`day_skew` −0.8、`day_max` −3.4、`day_min` −2.8、`day_median` −5.7、`day_q25` −3.6、`day_close`/`day_last` +1.4。
- `Ret` → 量的变化率(用户提示的互换):`leaf_Ret_volchg` / `leaf_Ret_logvol` / `leaf_Ret_amtchg` = +2.8 / +2.8 / +2.3%,
  **sg 翻成 +1、ρo 只有 +0.02~+0.04、dist 0.99~1.00** —— 换了叶子就是另一条因子,数值仍在噪声带内。
  `Ret` → `in_pct(Close, 5)`(5 分钟收益)ρo **+0.81**、ut −0.2% ⇒ 和分钟收益是同一个东西。`in_pct(Vwap,1)` −2.1%、dist 0.42 ✗。

### (e) 窗口没有平台

15 条 `win_*` 全部落在 ut −2.6%~+2.1%,**没有一条出噪声带**。梯度方向:外层 K 越短越好(10→+2.1,50→−1.9),
内层 E / G 越长略好(E50 +1.1、G40 +0.9),B 的 5 日最优(1→+0.2,20→−2.6)。都是噪声级。
日轴记忆同理:28 条 `mem_*` **全部 ≤ +1.2%**,多数为负,valid 掉到 −10% 级 → 原式没有"延长半衰期"这根杠杆。

## 3. 在市场的哪儿、什么时候有效(解剖表)

**原式 [0] 的段内净超额:只有两处为正**

| 段 | 段内 Lnet | 全市场多头书超配 |
|---|---|---|
| 成交额(20日)最高 20% | **+8.8%** | +4.8pp |
| 成交额其余四档 | −7.3 / −2.9 / −3.3 / −1.3% | 最低档 −6.7pp |
| 近 15 日**有**冻结盘口(封板/停牌,6.5%) | **+11.9%** | −0.8pp |
| 近 15 日无冻结(93.5%) | **−2.3%** | +0.8pp |
| 创业板 / 科创板 | −1.5 / **−8.8%** | −3.2 / +1.1pp |
| 市值、价格五档 | 全在 −0.9~+1.0% | 最大市值 +3.1pp |
| 上市不足 250 日 | −2.3% | −1.0pp |

逐年 −3.4 / +7.0 / +4.5 / −1.7 / +1.1 / −6.3%(**6 年里 3 年为负**);市场近 20 日**下跌 +3.8% / 上涨 −1.4%**;
截面离散度高 +2.2 / 低 −0.8%;缩量 +1.3 / 放量 −0.1%。

**推断原因**:F = E² 的**截面均值**由当日那一小撮极端票(多为小市值、低价、封板)决定,所以 I =「离截面典型值的距离」
实际在问"我和今天的极端票是不是同一个活跃度等级" —— 这就是它只在成交额最高档有段内信息、而桶内中性后几乎归零的原因。
另一半来自状态:盘口冻结时几乎每分钟 Ret = 0 ⇒ A ≈ 0 ⇒ D ≈ −mean(B) ⇒ E² 稳定偏大 ⇒ J 长期远离均值 ⇒ 因子高 ⇒ sg=−1 把它做空。
**原式有相当一部分是"伪装成收益因子的冻结分钟探测器"(= `docs/new_operators.md` 记的 F108 教训)。**
可检验推论:(i) 把叶子换成 `day_flat_ratio(Ret)` 应当复现原式的大部分(`h_f1`、`h_f2`);
(ii) 在成交额十分位内做桶内排名应当把它打回零(`h_q1`、`h_r3`);(iii) 反过来用活跃度当放大器应当更好(`h_q2`)。

**day_gini 版 [2] 的段内分布完全不同**:沪/深主板 +6.1 / +6.9%、创业板 +3.2%、科创板 −7.0%;
市值最低档 +5.8% → 最高档 −1.9% 单调下滑;**上市不足 250 日 +17.9%**(全市场 +6.3% 的三倍);
**有冻结盘口 −41.4%**;逐年 +13.0 / +4.5 / −3.8 / +7.8 / +9.6 / +7.0%(**6 年里 5 年正**);上涨 +11.2% / 下跌 +0.4%。
**推断原因**:gini 有界 [0,1] 且无尺度,双层折叠在它上面不再爆量纲,剩下的是「日内波动有多集中在少数分钟」=
消息/散户脉冲的强度;"30 天里一直接近典型值"于是选出**日内行为稳定**的票,这在次新与小市值里信息最多
(报价稀疏、脉冲明显),在封板票上直接反向(gini → 1 但那是坏事)。
可检验推论:其它有界/无尺度叶子应当更像 gini 而非 day_mean(`h_b1`~`h_b3`、`h_v5`);
在冻结度桶内中性后 gini 若塌,说明它只是在躲封板票(`h_f3`)。

**对照 `k_known` [1]**:段内在所有成交额档里都是负的(−4.1 / −5.3 / −8.2 / −5.2 / +2.5%),
多头书超配最低成交额档 **+80.3pp** ⇒ **它的信息就是成交额分档本身**(小而安静的票),逐年 6 年全正。

## 4. 相对已知成交额族的增量:没有

- ρk(原式) = −0.02(正交),但正交不等于有增量。
- `overlay` 六条:`ov_p025` +14.8% / Lshp 2.27(已知族 +15.4% / 2.22 → Δ −0.6pp / +0.05,**两项都在噪声带内**);
  权重一加大就单调变差:`ov_p05` +13.0 / 2.24、`ov_p10` +10.7 / 2.19;负权同样 +14.3 → +10.8 / 2.10 → 1.78。
- 正交残差本身很弱:`res_known` +2.6% / 0.76、`bk_known` +2.8% / 0.89、`res_liq` +3.1% / 0.96、`bk_liq` +2.7% / 0.89 —— 全在 ±3pp 噪声带内、Lshp < 1。
- 另一侧:`iso_B` 与已知族 ρk = **+0.50**,`iso_E~I` 族 ρk +0.42~+0.46 ⇒ **这棵树里"有信息"的那段本身就有一半是已知族**,
  而且只有它的一半力度(+7.7% vs +15.4%)。

**结论(否定性,但有据):原式的多头腿不可用(+0.7% / Lshp 0.17,6 年 3 年为负),
且对已知成交额族无增量(任何权重的叠加都不优于单跑已知族)。与上一轮读留出段得到的"负增量"一致。**
唯一值得继续的不是这条因子,是它的一个**叶子替换** `day_gini`(+6.3% / 1.44、ρo 0.06、ρk 0.20),
那实际上是一条新因子(日内集中度),应该按新因子对待 —— 第二批假设的重心就放在它身上。

## 5. 改进方向(已落成 `studies/F113_nested_tsmax_demean/hypo.yaml`,40 条,40/40 通过 hypo 检查)

1. **把 `+5` 全部删掉再跑一遍有信息的子树**(`h_s1`~`h_s7`、`h_g1`)—— 这是零成本的:`abl_C` 已证明收益不变而 dist 回到 1.00。
   若 `h_s3` / `h_s4` 拿到 ~+7.7% 且 dist ≥ 0.5,本因子才第一次有能过门槛的候选。
2. **拆开 `abl_J` 的 +12.4%**:`h_s1`(保号、不 NaN)对 `h_s2`(abs 折叠)—— 分清"符号有用"与"NaN 筛掉 57% 的票有用"。
3. **把折叠改成秩距离**(`h_r1`~`h_r3`):`fold_rank` 已给出 +3.0% / hl 20 的苗头,秩空间不会被量纲毁掉。
4. **把 day_gini 一族做到底**:最小形 `h_g3`、水平形 `h_g4`、去水平 `h_g5`、稳定性 `h_g7`、EMA 记忆 `h_m1`~`h_m3`、
   增量四件套 `h_k1`~`h_k3`、冻结状态中性 `h_f3`。
5. **按解剖下注**:冻结状态做叶子(`h_f1`/`h_f2`)、活跃度桶内/桶乘(`h_q1`/`h_q2`/`h_g6`)、
   稳健中心替代 cs_demean(`h_q3`)、用"市场 20 日平均分钟收益"做逐日符号翻转把择时写进表达式(`h_q4`/`h_q5`)。
6. **用新算子做原来做不了的事**:`day_gini` / `day_flat_ratio` / `day_pos_ratio` / `day_centroid` / `day_wmean(Ret,Amt)` /
   `day_signed_ratio(Ret,Amt)` / `in_pct` / `in_logchg` / `cross_ema` / `cross_zscore` / `cs_bucket_rank` / `cs_winsor` 都用上了。

### 7. `h_g6` 的机制:起作用的是「按什么排」,不是「排什么」

同一个分子 `cross_mean(day_gini(Ret),30)`,三种用法:裸用 **−1.3% / −0.19**;放进成交额十分位内比(`h_g6`)**+8.1% / 2.00**;
放进已知族自己的十分位内比(`h_k1`)+6.5% / 1.39 但 **valid 只有 +2.8%**;放进冻结度十分位内比(`h_f3`)**−1.3% / −0.17**。
反方向也成立:`h_s3` +7.9% 桶内中性后 **+1.8%**。⇒ **「桶内比较」是一个会改变符号和量级的算子,不是「削弱信号的保险」;桶变量选谁决定一切。**
解剖:`h_g6` 的段内读数在成交额五档上单调上升(+1.3 / +0.3 / +2.9 / +10.5 / **+14.3%**)而多头书在最高档只超配 +1.9pp;
流通市值最低档 +14.0% → 最高档 −0.3%;**上市不足 250 日 +13.5%**(全市场 +8.1%);**有冻结盘口 −13.6%**(唯一亏钱处);
逐年 +1.0 / +10.4 / +15.7 / +6.6 / +7.2 / +7.1%(**6 年全正**,原式 3 年为负);上涨 +6.3 / 下跌 **+10.0%**、放量 +8.5 / 缩量 +7.7%
—— **状态不敏感**(`k_known` 放量 +19.9 / 缩量 +11.8%,很敏感)。
**推断**:在同活跃度的同类里,日内波动集中在少数分钟的票(gini 高)被过度关注、随后跑输;「同活跃度」这个条件是必需的,
因为 gini 的截面水平本身就是活跃度 / 报价粒度的代理(裸用 ρk +0.66、`h_v2_gini_amt` ρk +0.67)。
机制的判别实验(`day_distinct_ratio` 报价粒度、`day_wstd` 资金经历的波动、`day_topw_mean` 放量分钟收益、
`day_es_ratio_hi` 右尾形状、`in_zscore_expand` 异常集中度)是第三批组 A。

### 8. 定论(只凭 train / valid)

**`best_own`**(本因子族自己、不含已知族**信号**的最好版本,ρk 全部 ≤ 0.46):
1. **`h_g6_gini_bk_amt`** +8.1% / **2.00** / LTO 1.8% / ρk **+0.05** / dist 1.00 —— 全表唯一既过门槛、Lshp ≥ 2、又与已知族正交的变体。
   但与原式 **ρo 只有 +0.08**:它不是 F113 的提纯,是从 F113 的一次叶子替换里长出来的**新因子**,应独立立案。
   (桶变量用了 `day_sum(Amt)`,但那只是中性化维度不是信号源 —— 分子单独为 −1.3%,且 ρk 0.05。)
2. **`h_s4_isoF_nosub`** = `pow_2(ts_max(cs_demean(ts_max(day_mean(Ret),5)),30))` +7.2/+8.6/**+8.0%** / 1.17 / dist 1.00 ——
   **原式骨架自己**最好的合法版本:12 层砍到 4 层、+0.7% → +8.0%。但 ρk +0.46、桶内中性后只剩 +1.8% ⇒ **3/4 是成交额分档**。
3. `h_g1_gini_nosub`(原式骨架 + gini 叶子 + 去 +5)+6.3% / 1.44 / ρo 0.06 —— 比 `h_g6` 差 1.8pp / 0.56 夏普,保留只为结构对照。

**`best_on_known`**(建在已知族上的最好用法):**`h_k2_gini_overlay`** = `add(cs_rank(k_known), mul(cs_rank(cross_mean(day_gini,30)), 0.25))`
+14.6/+23.9/**+17.2%**、Lshp 2.19/4.04/**2.66**、ρk +0.98。对 `k_known`:+1.8pp(**带内**)/ +0.44 夏普(刚出 0.3 带);
对 `k_known_xfrozen`(+18.5% / 3.15):**−1.3pp / −0.49 夏普,输**。且它的分子单独是 −1.3% / −0.19 ⇒ 这 +0.44 夏普更像秩相加的平滑而非信息。
**筛子用法彻底不行**:`scr_xhi_p` +15.2% / 2.24、`scr_xhi_m` +15.0% / 2.18 = 与 `k_known` 逐格打平(带内),远不及通用 xfrozen 筛。
**分段用法也不行**:最好的 `seg_lowliq_m` +10.7% / 2.09 但 ρk **+0.72**(低成交额本身就是已知族的方向),不及 `k_known`;
`seg_xfrozen_m` +2.8% / 0.63。**s2 从未试过把正交的强分子 `h_g6` 叠到已知族上 —— 这是第三批组 G 的全部内容。**

**`one_line`**:删掉精度 bug 救回了一整族子树(收益一位不变、dist 0.22→1.00),但它们 3/4 是成交额分档;原式的多头腿、筛子、分段用法
全部不可用,本研究唯一值得继续的是一条与已知族正交的新因子 `h_g6`(成交额桶内的日内集中度,+8.1% / 2.00),它自己仍不及已知族。

**`verdict`**:**不是提纯,不是升华,多头腿不可用,当筛子也不可用。** 原式 +0.7% / 0.17、6 年 3 年为负;
它「有信息」的那段(`h_s4` +8.0% / 1.17)经得起 dist 门槛但经不起成交额桶内中性(→ +1.8% / 0.25),ρk +0.46 ⇒ **主要是已知成交额族的弱复制**。
`abl_J` 一族 +12.4% / 2.38 的大头(4.8pp / 1.3 夏普)是 `pow_1_5(负数)=NaN` 剔掉 57% 的票换来的,第三批 `h3_jscreen` 用显式筛做最后裁决。
