## 3. 解读

**(1) P0 不只是"没被否定",是一次很干净的口径对齐。** 已知家族在留出段拿到 `Lnet` **+14.10%**、`Lshp` **1.509**,
正落在用户给的测试段参考(+13%~+15%、1.4~1.9)的中间。**所以 holdout 这一列就是用户那张表的口径**,
下面所有"差多少 pp"都可以直接拿去和用户自己的数比。

**(2) 原式的多头腿在第三段继续不可用,而且这次连"钱在空头腿"的机制一起复现了。**
`f_orig` 三段 `Lnet` 是 +1.60% / −1.73% / −0.58%(`Lshp` +0.39 / −0.52 / −0.15):**三段全部落在噪声带内,其中两段为负**。
逐年 8 年里 4 年为负,最好的一年也只有 +6.8%。多头腿只占多空毛差价的 15.7% / 4.3% / 15.0% ——
**三段都有 ≥84% 的钱在空头腿**(用户做不了空);"几乎全在空头腿"这个措辞最贴 valid 段,holdout 段是 85%,别写成 96%。
剖面也复现了:两段的最高档都不在多头端 —— 这正是 `07x_2_increment.md` §1 量到的路由机制
(外层折叠把安静股票钉在中间档、把极端股票扫进空头端)的直接表现。

**(3) 子结构确实有一条真实的多头腿,但只剩一条,而且是 4 节点那条。**
`f_m1` 三段 `Lnet` 全正(+3.17% / +14.75% / +5.15%),holdout 的 +5.15% / +0.603 在噪声带之外 → 这是一条真实但弱的多头腿。
`f_c4` 的 holdout 只有 **+1.44% / +0.137,整条掉进噪声带**,等于在第三段上测不出来。
事前写的"两条都为正、量级 +5%~+15%"只被 `f_m1` 兑现。
**这一段最该记住的是归因不要搞反**:`f_c4` 在 train 比 `f_m1` 好 3.70pp,在 valid 差 1.49pp,在 holdout 差 3.71pp ——
三段里有两段是简单那条更好,而且 `f_c4` 的衰减(−7.27pp)是 `f_m1`(−1.33pp)的五倍多。
第 3 轮挑 `f_c4` 当族代表的唯一理由("顶档两段不塌")**在留出段没有兑现**。按 H14(族内选谁在噪声里)+ 奥卡姆:
**要用这一族就用 4 节点的 `f_m1`**,嵌套那几层没买到任何可复现的东西。

**(4) 改进来自结构,不是来自平滑 —— 这条在留出段之后依然成立,而且原式这边根本没有平滑这根杠杆。**
原式两种口径都选到 `hl=1` 且固定半衰期表 hl0~20 全程只有 +0.5%~+1.6%(`06_baseline.md` §4):
**没有平台可供"延长半衰期"**。候选的固定半衰期表 hl0~5 是 +5.6%~+6.9% 的平台,同一 `hl=1` 下 6.9% vs 1.6% ——
差距来自删掉外层折叠这个**结构**改动,不是来自换半衰期。

**(5) P3 的方向被加强了:不是"没有增量",是"有负增量"。**
`f_cb`(把候选的截面秩和已知家族的截面秩等权相加)在 train/valid/utrain 三段都和 `f_kf30` 差在噪声带内
(+12.52 vs +12.62、+22.41 vs +22.33、+15.36 vs +15.40),**到 holdout 掉到 +8.93% / 1.044,比 `f_kf30` 低 5.17pp / 0.465,
两个差都超出噪声带**。读法:holdout 上 `f_cb` ≈ 两个成分的平均(+1.44 与 +14.10 的平均是 +7.77%,`f_cb` 是 +8.93%),
也就是说**掺进一条在第三段无用的因子,等权秩相加就是按比例稀释**;utrain 上 `f_cb` 比平均值高 3.30pp
(12.06 → 15.36)看着像"互补、相加不伤",**那一段是运气**。
事前 P3 的两个否定条件都是"候选更好",所以字面上 **P3 未被否定**,事前结论"没有增量"照原样成立;
"负增量"是同方向的新事实,它不改变推荐(事前第一推荐本来就是 `f_kf30` = 这条因子任何版本都不用),
只是把给用户的那句话从"掺进去无所谓"升级为**"掺进去有害"**。
注意边界:被测的是 `c4` + 已知家族那条;**`m1` + 已知家族的秩相加从没测过**(留出段已读完,不再跑)→ `12_next.md`。

**(6) 被碾压这件事在四列里一格都没翻。**
`f_c4` − `f_kf30` 的 `Lnet` 差是 −5.75 / −9.07 / −6.69 / **−12.66** pp,`Lshp` 差 −0.86 / −1.40 / −1.01 / −1.37;
`f_m1` − `f_kf30` 是 −9.45 / −7.58 / −8.92 / **−8.95** pp,`Lshp` −1.35 / −1.06 / −1.30 / −0.91 ——
**16 格全部远超噪声带**。剖面上的对比更难看:已知家族两段 Q1→Q10 严格单调,候选的顶档在 train 段塌或打平。
**逐年只有一个例外,必须写对**:8 年里 `f_m1` 在 **2024 年反超 `f_kf30`(+12.9% vs +9.2%,+3.7pp)**,
`f_c4` 在 2024 年打平(+9.2% vs +9.2%);其余 7 年两条都低 —— `f_c4` 低 **1.9~21.8pp**(最小 2020、最大 2025),
`f_m1` 低 **4.9~16.4pp**(最小 2019、最大 2025)。
**此前 notes 里"逐年六年无一年反超"那句话是 S2_bench 的 6 年口径,现在有了 8 年,不要再那样引用。**

**(7) 候选整族的失效集中在 2025 年。** `f_c4` 2024 +9.2% → 2025 **−7.5%**(摆动 16.7pp),`f_m1` +12.9% → −2.1%;
同期 `f_kf30` 是 +9.2% → +14.3%。holdout 这一段的整体数字因此很可能被 2025 年主导 ——
`f_c4` 的 +1.44% 不该读成"它在整个第三段都是平的",而是"2024 还行、2025 转负"。
这与 `07x_2_increment.md` §5 的 **U1**(「安静股票本身赚钱」在 valid 就已经不成立:train +7.13% / valid −0.90%)方向一致;
事前就写过"若 `c4` 塌掉,U1 就是现成解释",现在拿到了弱支持,但 U1 本身仍然没有被直接量过。

**(8) 两处口径陷阱(结果卡踩过一次,报告里别再踩)。**
① holdout 只存在于 `books_user`,拿 valid(`books`,fit = train)去减 holdout(`books_user`)会把"换了一本书"
和"换了一段"混在一起 —— `results/R3.md`「没人要但值得注意的」第 2 条把 `f_m1` 的衰减写成 9.6pp,
那是 valid(+14.75)减 holdout(+5.15);**同一本书内的 utrain→holdout 只有 1.33pp,和已知家族的 1.30pp 一样小**。
"候选衰减远超基准"这句话只对 `f_c4`(−7.27pp)和 `f_cb`(−6.43pp)成立,对 `f_m1` **不成立**。
② `cov` 这道门槛取的是标签覆盖率,5 个候选之间几乎不变(0.9992~0.9997),在本研究里没有区分力;
只有 `dist` 随表达式变。
