## 没人要但值得注意的

1. **f_cb 在 holdout 上不是"打平"f_kf30,而是明显更差**:Lnet 低 5.17pp、Lshp 低 0.465,两个差都超过噪声带(±3pp/±0.3)。`10_distilled.md` §3 的 P3 判据只预先设想了"打平"(不否定)和"明显更好"(否定)两种情形,没写"明显更差"这第三种;P3 的机械判据字面上仍是"未被否定"(因为它只检测"是否更好"),但这个方向本身是工单没预料到的,建议主研确认是否需要补一条说明。
2. **候选在 holdout 上的衰减比已知家族基准剧烈得多**:`f_c4` 多头腿 valid→holdout 从 +13.3% 掉到 +1.4%(降 11.9pp),`f_m1` 从 +14.8% 掉到 +5.1%(用 utrain→holdout 比较,降 9.6pp);而 `f_kf30` 自己 utrain→holdout 只从 +15.4% 掉到 +14.1%(降 1.3pp),相对克制。降幅都远超 ±3pp 噪声带。
3. **f_c4 与 f_m1 的排序在 holdout 上反转**:train 上 `f_c4`(+6.9%)> `f_m1`(+3.2%);holdout 上 `f_m1`(+5.15%)> `f_c4`(+1.44%)。幅度(3.71pp)没到 P4 的 6pp 门槛,机械判据"未被否定",但反转这件事本身是新信息。
4. **f_orig 的 long_share 不是单调衰减**:train 15.70% → valid 4.25% → holdout(utrain-book)14.97%,holdout 反而比 valid 更接近 train。如果要写"钱几乎全在空头腿",这句话在 valid 段最成立,在 holdout 段没那么极端,建议写报告时注明是哪一段。
5. **check 的去重提示漏了一条**:`f_kf30` 的表达式与 `S2_bench/kf_mean30` 逐字相同,但 `check` 的输出只对 `f_orig/f_c4/f_m1/f_cb` 四条打了"是同一棵树只算一次"的提示,没有对 `f_kf30` 打。这不影响结果正确性(`f_kf30` 的数字与 `kf_mean30` 在 `rank_corr_train` 里相关 +1.000,数值上确认是同一条树),但工具这条提示本身不完整,如果以后要靠这条提示做自动核对,要留意它可能漏报。
6. **diagnostics.profile 没有产出 holdout**(5 个变体都只有 train/valid 两个 key),`diagnostics.by_year` 则正常产出且覆盖了全部 8 个年份(2018–2025),两个诊断在这次 `final` 里产出的 split 范围不一致。
7. **cov 门槛实际上是标签覆盖率,不是因子覆盖率**:它在 5 个变体间几乎不变(0.9992~0.9997 之间随 split 浮动),只有 `dist` 随表达式变化。如果以后要用 `cov` 区分候选,这条门槛在本次 run 里起不到区分作用。
