## 解读

### 1. 三条代数审计全过,`03`/`04` 的推导可信(H8、H9)

`c6_nomul_nosub` 与 `v_base` rank 相关 **+1.00**;`c5_nopow15` 的固定半衰期 `hl=0` 行与 `v_base`
**JSON 原文逐位相同**(`long_ann` 两边都是 `0.0071861`)。所以:

- `sub(·,−5)`、`mul(·,5)` 两个常量节点**对结果精确无影响**(恒等,不是"影响很小");
- `pow_1_5` 在恒非负输入上只能通过"先 EMA 再排序"影响交易信号 —— 实测影响也极小
  (`Lnet` +1.6%/−1.5% vs +1.6%/−1.7%)。

**提纯的第一块收获:12 个节点里有 3 个是装饰。** 但这 3 个都不改变因子是什么。

### 2. 多头腿不是噪声,是**被折叠排错了位置**(H1 被否定、H3 被否定、H2 改写成 H12)

- H1(并列噪声)三条预测全不成立(`x1` 区块 1/2,见 `07x_1_ties_longbook.md`);
- H3(多头端天生没信息)被三条变体当场杀死:`c3`/`c4`/`c8` 的多头腿 **train 和 valid 同向为正**,
  `Lshp` 分别到 +1.00/+1.57、+0.92/+2.06、+0.81/+1.82;
- H2(中心错位)只对了一半:中心确实错位(`mean_cs(G)` 在 `G` 的 0.68 分位),
  但**把中心挪正救不了多头腿** —— `c9_rankfold`(秩空间)+3.0%/+0.1%、`c10_medfold`(中位数)+3.5%/−1.7%,
  两条都没拿到 valid 段可交易的多头腿,而且 `c9` 的固定半衰期表 hl0~20 全程只有 +1.7%~+3.0%(单薄)。

**真正起作用的是"把折叠整块去掉"**:删外层 `pow_2`(`c8`)和删外层 `cs_demean`(`c4`)——
这两种写法 rank 相关 **+0.99**,是同一个东西(`08_variants.md` 有代数解释),多头腿都跳到两段正。
→ 改写出 H12:**不是中心的位置不对,是折叠本身把"安静股票"这一端(真正有多头 alpha 的一端)
扔到了中间/空头端。** 旁证:`v_base` 的 valid 剖面峰值在 **Q3(+11.5%)**而不是 Q10(+1.5%)。

### 3. 改进是**结构**,不是平滑 —— 但它不是"提纯",是换了一条因子

两件事必须一起写,否则就犯了 `study_playbook.md` §6.1 / §6.3 两条:

- **归因**:`v_base` 两种口径都选到 `hl=1`,所以"原式 + 多头最优半衰期"这条必过基准就是
  `+1.6% / −1.7%`,**没有加长半衰期的空间**(sweep 是尖峰:0.18/0.39/0.24/0.23/0.13/−0.02/0.19)。
  而 `c3`/`c4`/`c8` 在**同一个 `hl=1`** 下是 +6.8%/+6.9%/+5.9%,固定半衰期表在 hl=0~5 是
  **+5.6%~+6.9% 的平台**。→ **改进来自结构,不是来自更长的半衰期。**
- **但**:`c4`/`c8` 与 `v_base` 的 rank 相关只有 **+0.14**(`c3` 更低,−0.01)。按 playbook §6.3,
  **低于 0.8 就不是提纯,是换了一条因子。** 所以本研究的诚实说法是:
  > 原式的多头腿不可用;**在它的子结构里**能找到一条多头腿可用的因子,但那条因子和原式几乎无关
  > —— 它用的是原式**丢掉**的那一半信息。

### 4. 回看越长,越不像朴素波动,两段越一致

消融阶梯按累计回看排:`c1`(5 日)−5.8%/+5.4% → `c2`(34 日)−1.1%/+8.5% → `c3`(54 日)+6.8%/+9.6%
→ `c4`(82 日)+6.9%/+13.3%。同时与 `ctl_dvol20` 的相关从 −0.79 / −0.72 降到 −0.66 / −0.60。
`c1`/`c2` 两段**不同向**,`c3`/`c4` 两段同向。
→ 读法:短窗版本基本是朴素波动的改写(而朴素波动的多头腿是**负**的:`ctl_dvol20` −11.1%/−2.7%、
`ctl_ivol` −7.4%/+0.1%,`06_baseline.md` §8),长窗版本才"干净"。
**这条还只是相关性证据,需要直接替换检验** → R2 的 `n2_max79_plain`(79 日朴素 MAX)、
`n4_dvol50_plain`(50 日朴素波动)、`w1_c4_62`/`w2_c4_102`(邻域)。

### 5. `c9_rankfold` 这个唯一的升华候选,被三件事一起判死

① 多头腿 +3.0%/+0.1%,固定半衰期表全程单薄;② valid 剖面**不单调**(Q9 +1.3% 是 valid 的次低值,
Q10 +3.2% 也不高);③ 逐年 2018 `Lnet −1.4%`、2023 `−1.6%`,`LS` 2018 只有 +0.04。
**它比 `v_base` 好一点,但完全不是一条能交易的纯多头因子。** 排除。
(附带收获:`c9` 的 `all_controls` R² 只有 0.046,`c3` 是 0.478 —— 秩空间折叠确实把一切暴露都压掉了,
连 alpha 一起压掉了。)

### 6. 中性化那张表怎么读(别把成本塌陷当成 alpha 消失)

`c3_g_fold1`:`all_controls` R² **0.478**(一半方差是控制变量),残差 `Lgross` +10.0% → **+9.4%**(几乎不掉),
但残差 `Lnet` +6.8% → **−3.4%**,同时换手 4% → **14.8%**(3.7 倍)。
→ 按 playbook §1,净值类指标**是被成本塌掉的**,alpha 在不在要看残差的 `rIC`(+0.0425 → +0.0133,掉了但没归零)
和毛超额(几乎没掉)。**正确的说法:`c3` 的毛 alpha 大部分不是这 9 个控制变量线性张成的;
但它和它们的重叠大到让"中性化之后再交易"这条路不可行。**
`ctl_range` 单变量就把残差 `Lnet` 打到 −19.8%、换手打到 44.4% —— 这更像是中性化把信号搅碎了,
不是 `ctl_range` 解释了 alpha。

## 结论(可以指到实验的)

- **已确立**:① 3 个节点恒等/无害(c5/c6);② 多头腿不是并列噪声(x1);③ 多头端有信息,
  原式的外层折叠把它排错了位置(c3/c4/c8 两段正 + c9/c10 救不回来);④ 改进来自结构不是平滑(固定半衰期表);
  ⑤ 候选与原式 rank 相关 0.14 ≪ 0.8 → 不是提纯,是换了一条因子。
- **合理但未坐实**:H12 的机制(低 `G` 端被排到中间)—— 等 R2 区块 1 的交叉表。
- **未决**:候选到底是不是朴素长窗 MAX / 朴素低波动的改写;候选相对已知家族(`known_stdamt_*`,
  自己的多头腿 +9.3%/+18.5%,**比候选好**)有没有增量。**这两条决定整个研究的结论,是 R2 的全部内容。**
