# 机制诊断 — 这条因子到底在做什么,哪些话站得住

> 写于第 4 轮(主研,留出段读完之后)。
> 分三档:**已确立**(两段以上一致,或代数恒等 + 实测吻合)/ **合理但未坐实**(方向一致但幅度不够判决,或口径没拆干净)
> / **未决**(明确没有量过;写出来是为了不让它被当成已知)。
> 口径与噪声带:`Lnet` 多头腿净超额(扣 15bp)±3pp、`Lshp` 纯多头夏普 ±0.3;多头口径的半衰期按 `rank_by: long` 在 fit 段选。
> **每一条后面的括号就是它唯一的出处;指不到实验的话不写进这一页。**

## 一句话

这棵树的名字(`nested_tsmax`)和它真正卖的东西不是一回事:**它卖的是「个股近期振幅相对当天截面典型值的水平」,
极值记忆(MAX)只是装饰;而树的外层那次折叠 `(G − mean_cs(G))²` 把本该做多的那一端排到了中间档,
于是原式的钱全在空头腿,多头腿三段测不出来。** 把折叠删掉能得到一条真实但弱的多头腿(4 节点的 `f_m1`,
holdout +5.15% / +0.60),但它比用户已有的成交额族低 8~9pp,**而且掺进去会稀释已知家族**。

## 一、已确立

**E1 — 原式的多头腿不可用(三段)。**
`Lnet` +1.60% / −1.73% / −0.58%(train / valid / holdout),`Lshp` +0.39 / −0.52 / −0.15:三段全在噪声带内、两段为负;
逐年 8 年里 4 年为负,最好一年 +6.8%。多头腿只占多空毛差价的 15.7% / 4.3% / 15.0% → **三段都有 ≥84% 的钱在空头腿**。
用户公布表的 `long = 0.037` 是**毛**超额(utrain 毛 +3.69%),净只有 **+0.68%**。
(`06_baseline.md` §1~§5、`07_S_final.md` §2~§3,判据 P1)

**E2 — 不可用的原因是外层折叠把多头 alpha 路由走了,不是"多头端天生没信息"。**
以 `G` = 内层量(34 日相对 MAX 的平方)分档:`G` 档 10(最极端)有 **72.1% / 69.9%** 落进原式的最低档(= 空头端),
`G` 档 1(最安静)落进原式档 9/档 10 的占比**精确 0.000**、中位数档位 3.00;原式多头端成员的 `G` 分位只有 **0.655 / 0.676**,
空头端是 0.950 —— 多头腿剩下的是一条无信息窄带。剖面直接印证:原式两段的最高档都不在 Q10
(train 峰在 Q6、valid 峰在 Q3)。折叠中心本身也偏:`mean_cs(G)` 落在 `G` 当天截面的 0.680 / 0.681 分位。
(`07x_2_increment.md` §1、`results/R1.md` 区块 3、`07_S_final.md` §3(2))

**E3 — 病根在"折叠本身",不在"中心的位置"。** 把中心挪到截面中位数(`c10_medfold`)或秩空间(`c9_rankfold`)
都救不了多头腿(+3.5% / **−1.7%**、+3.0% / **+0.1%**);而把折叠整块删掉的两种不同写法
(删外层 `pow_2` 的 `c8`、删外层 `cs_demean` 的 `c4`)**互相 rank 相关 +0.99**、都跳到 +5.9%~+6.9% / +11.8%~+13.3%。
(`results/R1.md` 表 1/表 4、`08_variants.md` §一)

**E4 — 真正 load-bearing 的只有第一次 `cs_demean`;十几个算子里其余是装饰或负资产。**
`sub(·,−5)` 被 `cs_demean` 精确抵消、`mul(·,5)` 只留正尺度、`pow_1_5` 在恒非负输入上严格单调
→ `c5`/`c6` 与原式 rank 相关 **+1.00**、固定半衰期 `hl=0` 行 JSON 原文逐位相同(`0.0071861`)。
同窗口直接替换:相对 MAX 比朴素 MAX 好 **3.5pp / 6.2pp**(`m1` vs `n2`),相对振幅比朴素波动好 **7.6pp / 9.2pp`**(`m3` vs `n4`),
两段同向超噪声带 → 减截面均值这一步是有用的。而 **abs-max 与 abs-mean 只差 0.6pp / 1.3pp**(`m2` vs `m3`,噪声内)
→ **极值记忆(MAX)可以换成平均,名字误导人**。正式提纯产物 = `ts_max(ts_max(cs_demean(day_mean(Ret)), 50), 30)`(4 节点)。
(`07_S2_bench.md` §1~§3、`05_hypotheses.md` H4′/H13)

**E5 — `f_c4`/`f_m1` 不是原式的"提纯",是换了一条因子。**
与原式的 `rank_corr_train` 只有 **+0.14**(远低于 playbook §6.3 的 0.8 门槛)。
唯一改变原式排序的那个算子(第二次 `cs_demean` 所在的外层折叠块),正是毁掉多头端的那一个 ——
**"特色"和"病根"是同一个东西**,所以提纯的空间天生很小。
(`results/R1.md` 表 3、`05_hypotheses.md` H5)

**E6 — 它不是朴素长窗 MAX,也不是朴素波动、低波动或某个单一已知暴露的改写。**
除 E4 的两组直接替换外:`all_controls` 对 `c4` 的 R² 只有 **0.418**;最近的"已知亲戚"是 20 日波动 `ctl_dvol20`
(多头腿名单重合 0.39~0.40),但 `ctl_dvol20` 自己的多头腿是 **−11.1% / −2.7%** → 候选不是它的改写。
与成交额族是**两本不同的书**:候选多头腿 = 低振幅的**中大盘**(`ctl_cap` 0.55、`ctl_dvol20` 0.14),
已知家族 = 成交额波动极小的**小盘冷门**(`ctl_amt` 0.07、`ctl_cap` 0.16~0.22),名单重合率 0.25~0.29(随机基准 0.10)。
(`07_S2_bench.md` §8、`07x_2_increment.md` §2、`results/R1.md` 区块 5)

**E7 — 族内选谁在噪声里;嵌套结构没买到任何可复现的优势。**
7 个成员两两 rank 相关 +0.70~+0.95,valid `Lnet` 全在 +12.7%~+14.8%(跨度仅 2.1pp,而 train 跨度 7.2pp);
排序三段不稳:`f_c4` − `f_m1` = train **+3.70pp** / valid **−1.49pp** / holdout **−3.71pp**;
同一本书内 utrain→holdout 的衰减 `f_c4` **−7.27pp** vs `f_m1` **−1.33pp`**。
第 3 轮挑 `f_c4` 当族代表的事前理由("顶档两段不塌")在留出段没有兑现。
**推论:train 上的族内差异不能写成"结构更好";要用这一族就用最简单的 `f_m1`。**
(`07_S2_bench.md` §1、`07_S_final.md` §3(3),判据 P4)

**E8 — 改进来自结构,不是来自平滑;而且原式这边没有"延长半衰期"这根杠杆。**
原式两种口径都选到 `hl=1`,固定半衰期表 hl0~20 **全程只有 +0.5%~+1.6%**(没有平台可拉);
候选的固定半衰期表 hl0~5 是 +5.6%~+6.9% 的平台,**同一 `hl=1` 下 6.9% vs 1.6%**。
原式 `hl=1` 的尖峰本身是"EMA 作用在 6 次幂量上"的产物:把尺度压到 [0,1] 的 `c9` 的 sweep 从尖峰变平台。
(`06_baseline.md` §4、`07_S1_chain.md`、`05_hypotheses.md` H8)

**E9 — 候选被已知成交额族碾压,四列 16 格一格没翻。**
`f_c4` − `f_kf30` 的 `Lnet` 差 −5.75 / −9.07 / −6.69 / **−12.66** pp(train/valid/utrain/holdout),`Lshp` 差 −0.86 / −1.40 / −1.01 / −1.37;
`f_m1` − `f_kf30` 为 −9.45 / −7.58 / −8.92 / **−8.95** pp,`Lshp` −1.35 / −1.06 / −1.30 / −0.91。
剖面上已知家族两段 Q1→Q10 **严格单调**,候选的顶档在 train 段塌(`f_m1` Q10 比 Q9 低 3.7pp)或打平(`f_c4`)。
**逐年 8 年里唯一的例外:`f_m1` 在 2024 年反超(+12.9% vs +9.2%),`f_c4` 2024 打平,其余 7 年都低。**
(`07_S2_bench.md` §5、`07_S_final.md` §2~§3(6),判据 P3②)

**E10 — 对纯多头用户没有增量;留出段把它加强为负增量。**
四条独立口径:① **残差** —— `c4` 对 {`kf30`,`kf9`} 中性化后残差**毛**超额只有 −0.01% / +2.85%(门槛 +5%),
而残差换手只 1.7~1.8% → **不是被成本塌掉的,是真没了**;反向 `kf30` 对 `c4` 的残差仍保留自身 `Lnet` 的 66% / 75%,
两边 R² 几乎一样(0.142 / 0.132)→ **不对称**。② **名单** —— 只被候选选中的那批票(`only_c4`)超额中位数两段都为负
(−0.95% / −13.62%),只被已知家族选中的是 +2.21% / +19.24%。③ **秩相加(train/valid)** —— `f_cb` 与 `f_kf30` 四格差全在噪声带内。
④ **秩相加(留出段,新)** —— `f_cb` 掉到 +8.93% / 1.044,比 `f_kf30` 低 **5.17pp / 0.465**(两者都超噪声带),
而且 ≈ 两个成分的平均(+7.77%)→ 掺一条第三段无用的因子进去,等权秩相加就是按比例稀释。
(`07x_2_increment.md` §3、`07_S_final.md` §3(5),判据 P3①)

**E11 — 已知家族自己在三段都稳(所以"被碾压"这个比较的分母是可靠的)。**
`f_kf30` utrain +15.40% / 2.224 → holdout **+14.10% / 1.509**(只掉 1.30pp),逐年 8 年全正(+6.6%~+24.6%),
两段剖面严格单调。而且 holdout 的 +14.10% / 1.509 **正落在用户给的测试段参考(+13%~+15%、1.4~1.9)的中间**
→ 本研究 holdout 这一列与用户那张表同口径,差值可以直接拿去对照。
(`07_S_final.md` §2~§3(1),判据 P0、P5)

## 二、合理但未坐实

**U1 — 4 节点的 `f_m1` 比嵌套的 `f_c4` 更该被保留(不只是"同样好")。**
方向一致:3 段里 2 段 `f_m1` 更好、衰减小 5.9pp、表达式少十几个算子。但 holdout 的差 3.71pp 只略超噪声带(3pp)、
不到事前判据 P4 的 6pp,所以它是**奥卡姆选择**而不是实测优势。要判决需要第四段数据 —— 没有了。

**U2 — "安静股票本身赚钱"(原 H12 的后半)。**
`G` 档 1 等权超额 train **+7.13%** / valid **−0.90%**(方向就翻了)。留出段 `f_c4` 的塌陷与这条不成立方向一致
(第 3 轮事前就写了"若 `c4` 塌掉,U1 是现成解释"),算**弱支持**;但 raw `G` 档等权与"`ts_max(G,30)` 顶档 10% + 平滑 + 扣费"
的口径差一直没拆开,**从未直接量过**。候选的故事根基因此是悬的。(`07x_2_increment.md` §1、§5)

**U3 — 候选整族在 2025 年失效,像是风格/制度依赖而不是整体消失。**
`f_c4` 2024 +9.2% → 2025 −7.5%(摆动 16.7pp),`f_m1` +12.9% → −2.1%,同期 `f_kf30` +9.2% → +14.3%。
holdout 的整段数字很可能被 2025 主导。没有做分年归因实验,所以"2025 发生了什么"是空的。

**U4 — 公布的多空夏普有多少来自买不进的票。**
`buyable=False` 重算后 train 空头腿毛超额从 +25.2% 掉到 +14.3%(**−10.9pp**),封板票只占空头腿 0.75% 但那些格子的
raw 年化均值是 +1876%;valid 只降 2.5pp。**"多空夏普下降多少"这一半没有量**(只量了毛超额)。
多头腿几乎不受影响(+4.7%→+3.9%),所以不影响选拔。(`results/R1.md` 区块 6)

## 三、未决(明确没量过)

1. **`m1` + 已知家族的秩相加**从没测过。被测的负增量那条是 `c4` + `kf30`;`m1` 在留出段衰减小得多,
   它的组合不一定同样稀释。留出段已读完 → `12_next.md`。
2. **留出段的分位剖面**:这次 `final` 的 `diagnostics.profile` 只产出了 train/valid,没有 holdout
   → "候选在第三段是否仍大体单调"无数据(不值得再花一次运行)。
3. **残差的 `rIC` 没归零**(+0.027 / +0.036)但残差顶档没钱 → 对**多空**用户可能还有东西;用户做不了空,不追。
4. **顶档相对中高档的增量很薄**(`c4` train Q10 +9.2% vs Q7~Q9 +7.2~7.3%)→ 腿名额若从 10% 放宽到 20~30%,
   结论会不会变,没量。
5. **warmup**:`view.warmup_rows = 0` 而结构需要 82 天,train 开头被污染(占 train 973 天的 <9%,valid/holdout 不受影响)。
6. **空头腿的并列比多头腿多**(并列组 ≥2 占比 0.021 vs 0.000),与 `04_grammar.md` §3 的预测方向相反;
   幅度 2%,不影响任何决策。
7. **`diagnostics.by_year` 用的是哪一本书**(`books` 还是 `books_user`)在结果卡里没注明 —— 2024/2025 只落在 holdout 内,
   所以逐年表至少跨了 fit 段边界;引用逐年数字时要带这个保留。(交给第 4 轮的执行核对 JSON 字段)
