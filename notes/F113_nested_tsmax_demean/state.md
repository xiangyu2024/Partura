### 源码里和名字不一样 / 容易花重复时间的地方

- `rank_corr_train` 的**行是交易信号、列是控制变量 raw**(`partura/runner.py:332`)。符号要自己翻。
- `pow_1_5` 对**负数返回 NaN**(`common.pow_` 在 `e>1` 时走 `torch.pow` 不保号分支)。
- `cs_rank`:`pct=True` → (0,1];并列用 `argsort(stable=True)` 打破 = **按股票代码顺序**。
- `cs_median` 末尾 `expand_as` → 返回广播后的截面中位数。
- `dist` = `distinct_fraction`:抽样日(每 5 天、当天有值 ≥30)上"不同取值数/有值股票数"的**中位数**,
  **只用 fit 段**(`partura/runner.py:170`)。
- `ts_max` 窗口池 `[1,5,10,20,30,40,50]`;`cross_max/mean/stddev` 是 `[3,5,10,15,30,60,241]`。
  **49/79 不在池里 → 要写成嵌套**。两者内核相同(日频量上 `cross_*` 更省显存)。
- 生产的腿名额用 `floor(0.10×n)`(`alphacube/metrics.py:282`),R1 的脚本用了 `round` —— R2 起统一 `floor`。
- `st.books(panel, sign=1.0)` 可以固定方向(算残差时**必须**固定,否则工具会按 rank IC 重新选、把残差翻过来)。

## 5. 当前的候选

### 必过基准(所有候选要比过的)

1. **原式 + 多头最优半衰期** = `v_base` 的 `hl=1` 行 = **train +1.6% / valid −1.7%**。
   **这条因子没有"加长半衰期"的杠杆**(两种口径都选到 hl=1,sweep 是尖峰)。
2. **已知家族**:`known_stdamt_max9` **+9.3% / +18.5%**、`known_amt_max9` **+8.5% / +20.8%**
   (⚠️ 可能被低估,见 §2.2;R2 的 `kf_max9`/`kf_mean30` 会重算)。

### 第一候选(领先,但**不是**"提纯")

**`c4_nodemean_out`** = `ts_max(ts_max(pow_2(ts_max(cs_demean(ts_max(day_mean(Ret), 5)), 30)), 20), 30)`
= 「82 日内最大的(34 日相对 MAX)²」,`sign=-1`(做多"很久没出过相对极端行情"的股票)。
train/valid `Lnet +6.9% / +13.3%`、`Lshp +0.92 / +2.06`、`Lgross +8.9% / +15.3%`、**`LTO` 只有 2.7%**。
为什么是它:① 两段同向且 valid 更强;② 固定半衰期表是平台(hl=0~5 全在 +6.0%~+6.9%)→ 不依赖平滑;
③ 换手最低;④ 等价写法 `c8_nofold_out` 独立给出同样的结果(相关 +0.99)。
**必须一起写的话**:它与 `v_base` 的 rank 相关只有 **+0.14** → 按 playbook §6.3
**这不是提纯,是换了一条因子**;它用的是原式**丢掉**的那一半信息。

### 备选

- **`c3_g_fold1`** = `ts_max(pow_2(ts_max(cs_demean(ts_max(day_mean(Ret), 5)), 30)), 20)`(54 日版本),
  `+6.8% / +9.6%`、`Lshp +1.00/+1.57`、换手 4.2%、**六年 `Lnet` 全正**(逐年比 `c4` 多一项证据)。
  但 `all_controls` R² **0.478**,比 `c4` 更"像控制变量"(c4 的还没量)。
- `c8_nofold_out`:`c4` 的等价写法,**不算独立候选**。
- **R2 会产生的新候选**:`m1_rel79_max`(4 节点最小结构)、`cb_c4_kf30`(与已知家族秩相加)、
  以及如果 `n2_max79_plain` 追平 `c4`,候选就该换成那条更简单的朴素 MAX。
