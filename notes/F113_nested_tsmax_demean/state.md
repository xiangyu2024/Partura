→ 据此下 40 条第二批假设(重心转到 `day_gini` 一族 + "去掉 +5 的干净子树")。

**源码/工具里和名字不一样的地方(本轮新增,`src` 逐个核过)**

- **`dist` 不是"与已知族的距离"**,是 `diagnose.distinct_fraction`:逐日「不同取值数 / 有值股票数」的中位数,
  即**并列/量化程度**;低 dist = 十分位书名单由代码序决定(`runner.py:170`、`diagnose.py:136`)。
- `pow_(x, e)` 只在 **e ≤ 1** 时是 signed power;e > 1 走 `x**e` ⇒ **`pow_2` 折叠符号、`pow_1_5` 对负数返回 NaN**
  (后者是 cov 0.43 的唯一来源);**`pow_05` / `signedpower` 保号**。
- **`sqrt(x) = sqrt(|x|)`、`log(x) = log(|x|)`(|x| ≤ EPS → NaN)** —— 名字不像折叠,实际都折叠。
- `sub(B, -5)` 是**加** 5;`cs_demean` 用 **mean 不是 median**(会被当日涨停群拉动)。
- `create_like` 对 python int 字面量建 **int64** 张量(`mul(G, 5)` 的 5 走这条路),只影响 dtype 推断、不影响值。
- 上一轮仍成立:`rank_corr` 符号自己翻;窗口池 `ts_*` `[1,5,10,20,30,40,50]` / `cross_*` `[3,5,10,15,30,60,241]`;
  腿名额 `floor(0.10n)`;`st.slice("holdout")` 报错;`by_year`/`neutralise` 只算本次 run 的变体;**holdout 只存在于 `books_user`**。
