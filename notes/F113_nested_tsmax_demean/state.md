### 源码/代数核对出来的事实(不是实测)

上一轮主研核对的(本轮重新核对,**全部成立**):

- `ts_max` 的窗口池是 `[1,5,10,20,30,40,50]`;`cross_max` 的是 `[3,5,10,15,30,60,241]`(两者**内核相同**)。
  **49 不在池里**,所以"合并两层 max"的变体必须写成嵌套形式。(`./scripts/study.sh ops`)
- `dist` = `distinct_fraction`:抽样日(**每 5 天**,当天有值股票数 **≥30**)上"不同取值数 / 有值股票数"的
  **中位数**。(`partura/diagnose.py:136`,本轮逐行读过 —— `x1` 的抽样口径必须和它一致才能自检)

**本轮(第二次尝试的主研)新核对的三条算子语义** —— `c8`/`c9`/`c10` 的设计全靠它们,所以逐个读了内核:

- **`pow_1_5` 对负数返回 NaN(确认)。** 内核 `common.pow_` = `where(e <= 1, sign(x)*|x|^e, x^e)`;
  `e=1.5 > 1` 走 **`torch.pow(x,1.5)` 这条不保号的分支**。
  → 工单让 `c8_nofold_out` 删外层 `pow_2` 时**同时删 `pow_1_5`**,是对的。
  `c9`/`c10` 最外层 `pow_1_5` 的输入来自 `ts_max(pow_2(...))`,恒非负,**安全**。
- **`cs_median(x)` 返回"当天截面中位数广播成全形状"**(内核末尾 `med.unsqueeze(-1).expand_as(x)`,
  且当天有值数为 0 时返回 NaN)。→ `c10` 的 `sub(G, cs_median(G))` 确实是去中位数。
- **`cs_rank` 默认 `pct=True` → 取值 (0,1];并列按「列序 = 股票顺序」打破。**
  内核用 `argsort(..., stable=True)`,注释自写 "ties keep index order";NaN 先被推到 `finfo.max`
  再 mask 回 NaN,所以不挤占有效股票的名次。**这条是本轮最重要的发现,见 §3 的 H11。**
- `st.symbols()` 存在(`partura/study_tools.py:127`),所以脚本里**拿得到股票代码**,H11 可以直接量。

**R1 第一次尝试(上一轮主研,额度中断)**:没跑实验,产出是 `04_grammar.md` + `05_hypotheses.md` + `orders/R1.md`。
它的逻辑是刻意的,本轮复核后**完全采纳**:

1. **先把代数推到底,再决定花钱测什么。** 这棵树是一条**不分支的链**、只用 `Ret` 一个字段、
   输出恒非负、对 `Ret` 是 **6 次齐次**(R0 已推)。链式结构意味着"消融"就是"取前缀",
   实验设计因此非常干净。沿链逐层推出**三条 R0 没有的结论**(`04_grammar.md`),本轮我独立复核了这三条代数:
   - **`mul(G,5)` 也是精确冗余**(R0 只找到 `sub(·,-5)` 一处)。正常数 5 穿过 `cs_demean`(线性)、
     `pow_2`、`ts_max`(1 次齐次)、`pow_1_5` 之后只剩 **125× 的正尺度**;EMA 线性、十分位排序对正尺度不变,
     所以影响**精确为零**。(`04_grammar.md` §4)**复核:成立。**
   - **外层四个算子除了第二次 `cs_demean`,对排序没有任何贡献。** 删掉 `cs_demean` 后,
     `mul → pow_2 → ts_max(·,30) → pow_1_5` 全作用在恒非负的 `G` 上,逐个单调递增,
     而**单调递增变换与 `ts_max` 可交换**,整块塌成 `ts_max(G,30)` 的单调函数(秩完全相同)。
     **复核:成立**(`pow_2(5G)=25G²` 在 `G≥0` 上单调;`ts_max(25G²,30)=25·ts_max(G,30)²`)。
     → 提纯的问题被收得极窄:要么第二次 `cs_demean` 是全部特色,要么这棵 12 节点的树能砍掉一半。
   - **`pow_1_5` 在非负输入上严格单调 → 当天截面排序完全不变**,只能通过"先 EMA 再排序"影响交易信号
     → 固定半衰期表的 **hl=0 行必须等于原式**。**复核:成立。**
2. **从代数里找出一个有机制依据的"为什么多头腿差"**(`04_grammar.md` §3):
   外层折叠的中心是 `mean_cs(G)`,而 `G` 是"平方 → max → max"的产物、**截面分布极度右偏**,
   均值被右尾拖到远高于中位数的位置。两个后果:
   (a) **"离中心近" ≠ "在分布中间"** —— `sign=-1` 要找的 `G ≈ mean_cs(G)` 是一条**只有偏高分位才到得了的窄带**;
   (b) 对 `G ≪ mean_cs(G)` 的大多数安静股票,`J=(G−m)² ≈ m²−2Gm`,`m` 当天对所有股票是同一个数 ——
   它们的 `J` **挤在一个几乎退化的平台上**,正好给 `dist = 0.5847` 一个结构性解释。
   还有一个更直接的退化源:一字板/全天无成交的票 `Ret` 的 241 根分钟全是 0 → `A=0` 精确 →
   **所有这类票同一天拿到完全相同的因子值**。→ **H1**:多头腿可能不是"差",而是"按代码顺序挑出来的噪声"。
3. **写 10 条竞争性假设 + 下工单**(H1 → H3/H2 → H5/H9/H8 → H4/H7 → H6 的决策相关性排序)。

## 6. 后面的研究思路

**第 2 轮(读 `results/R1.md` 的那个主研)按这个顺序裁决:**

1. **先看 `x1` 区块 1+2+1b(H1 与 H11 一起看)。** 这决定整条路线:
   - 多头十分位并列占比 ≳30%、或切割点落在大并列组内部、或退化票显著富集
     → **H1 成立**。结论基本定了:"**多头腿不可用,原因是机械的(并列 + 代码顺序)**"。

     (一条"看起来有样本外表现、其实暴露的是上市板块"的因子),也是**否掉 `c9` 的充分理由**。
2. **再看 `c9`/`c10` 的多头腿(H2 vs H3),但 `c9` 要先过 H11 这道闸。** 判据写死在 `05_hypotheses.md`:

     (窗口 20→30、30→40、`cs_rank` 换 `cs_scale`/`cs_normalize`)+ **已知家族增量**
     (对 `known_stdamt_mean30` 中性化后的残差多头腿,以及两者相加之后的多头腿 —— 自写脚本,`st.control` 取得到)。
