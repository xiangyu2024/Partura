## 逐区块解读

### 区块 1 + 2 + 1b:**H1 和 H11 都被否定**,多头腿的数字是真的

- 多头腿里"并列组 ≥2"的名额占比中位数 **0.000**(train 和 valid),p90 只有 0.005;
  切割点同值股票数中位数 **1.0**、p90 **1.0** —— 切割点上根本没有并列可打破。
- 退化票(`day_mean(Ret)` 精确为 0,即一字板/全天无成交)在多头腿里**不富集**:
  占比 0.0026 vs 全市场 0.0030(**0.85 倍**,比全市场还低);"过去 5 天全为 0"更是 0.0000 vs 0.0005。
- 列序(= 股票代码顺序)位置分位中位数 **0.491 / 0.526**(`v_base` train/valid)、
  **0.477 / 0.500**(`c9_rankfold`)—— 全部贴着 0.50。

**→ `04_grammar.md` §3 推导的那个"低 K 端退化平台"在实际交易的信号上不存在。**
为什么推导对、现象没有:`dist=0.5847` 是 **raw 面板**上的并列,而书是用 **`sig`**(hl=1 的 EMA)建的,
EMA 把"今天取值相同、历史不同"的股票分开了。两件事都成立,不矛盾。
而且**退一步也不影响结论**:固定半衰期表的 `hl=0` 行(完全不平滑、并列最严重)多头腿只有 `+0.7%`
—— 无论哪种口径,`v_base` 的多头腿都弱,并列不是原因。

**板块占比那一条要当心一个假信号**:train 段"科创板 2.3% vs 基准 11.8%"看着是 9.5pp 的大偏离,
但**基准是静态股票列表**(执行的实现选择 5),而**科创板 2019-07 才开市** ——
train 段(2018-01 起)前一年半根本没有科创板股票。valid 段 10.2% / 11.4% ≈ 11.8% 正好印证。
创业板 train 21.0% vs 26.9% 同理(注册制扩容在 2020 年以后)。
→ **这不是板块暴露,是上市日期 artifact。** 决定不再花钱逐日重算基准:列序分位 ≈0.50 这一条已经足够。

### 区块 3:折叠中心确实错位,但**错位不是多头腿没钱的原因**

`nanmean(G)` 在当天 `G` 截面的分位中位数 **0.680 / 0.681**(四分位 0.658–0.721)——
显著高于 0.50,但没到 R1 预测的 ≳0.75。多头腿成员的 `G` 分位中位数 **0.655**、空头腿 **0.950**。
→ "`sign=-1` 选出来的不是分布中间,而是一条偏高分位的窄带"**坐实**。
→ 但 `c9`/`c10` 把中心挪正之后多头腿照样不行(`07_S1_chain.md` §2),所以**错位是症状不是病根**。
病根是折叠本身(H12):低 `G` 的安静股票和高 `G` 的暴涨股被折到同一端。

### 区块 4:**钱为什么主要在空头腿 —— 这张表给了最直接的答案**

当天截面分位中位数(全市场基准 0.50):

| | 多头腿 tr/va | 空头腿 tr/va |
|---|---|---|
| `ctl_turnrate` | 0.551 / 0.539 | **0.845 / 0.830** |
| `ctl_dvol20` | 0.594 / 0.598 | **0.836 / 0.828** |
| `ctl_ivol` | 0.539 / 0.555 | 0.725 / 0.748 |
| `known_stdamt_mean30` | 0.591 / 0.590 | 0.732 / 0.648 |
| `ctl_cap` | 0.556 / 0.559 | **0.315 / 0.285** |

**空头腿是一个教科书式的"高换手 + 高波动 + 小市值"组合**(分位 0.83~0.85 / 0.83 / 0.29),
在 A 股这正是最稳定的负收益组合 —— 所以空头腿毛超额 +25% 两段都稳,一点也不意外。
**多头腿的所有偏离都温和**(0.48~0.60),它没有站到任何已知暴露的有利一侧。
→ 这就是 `long_share` 15.7% → 4.2% 的结构解释:**这条因子的全部力量是"识别出该回避的极端股",
而回避之后剩下的那一堆股票,它没有本事排序。** 对只能做多的用户,这正是最没用的那种因子。

### 区块 5:`v_base` 和已知家族**不是同一本书**,而且是"反重合"

多头腿重合率(随机基准 0.10):`known_stdamt_mean30` **0.052 / 0.044**、
`known_stdamt_max9` **0.055 / 0.046` —— 只有随机的一半。空头腿反而 0.17~0.23(高于随机)。
→ H7 的"分辨上是新东西"**被支持**(对 `v_base`)。
→ 但请注意**这条结论只对 `v_base` 成立**。R2 的候选 `c4`/`c3` 与已知家族的**交易信号**相关是
**+0.32~+0.42**(`05_hypotheses.md` §0 的符号翻转),完全是另一回事,必须单独量。

### 区块 6:H6 在 train 段成立,valid 段几乎不成立

空头腿毛年化超额 `tgt → raw`:train **+25.2% → +14.3%(−10.9pp)**;valid +25.8% → +23.3%(−2.5pp)。
封板票只占空头腿 0.75%(train)/0.20%(valid),但这些格子的 raw 年化均值是 **+1876% / +1912%**
(即单日 7% 以上),所以 1% 的名额能搬动 11 个百分点。
多头腿几乎不受影响(+4.7%→+3.9%、+1.2%→+0.8%),符合 playbook §6.6。
→ **报告的风险一节必须写**:公布的多空夏普(2.54)在 train 段有相当一部分来自"买不进的涨停票记 0 收益"。
但这**不影响选拔**(选拔看多头腿),所以"多空夏普具体掉多少"决定不再花钱去量。
