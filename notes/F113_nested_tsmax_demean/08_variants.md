## 一、精确等价(代数 + 实测双重确认,可以合并引用)

| 这几个 id | 其实是同一个东西 | 证据 |
|---|---|---|
| `v_base`、`c5_nopow15`、`c6_nomul_nosub` | 同一条因子 | `c6` 与 `v_base` rank 相关 **+1.00**;`c5` 与 `v_base` rank 相关 **+1.00**,固定半衰期 `hl=0` 行 `long_ann` **JSON 原文逐位相同**(两边都是 `0.0071861`)。代数:`sub(·,−5)` 被 `cs_demean` 精确抵消;`mul(·,5)` 只留 125× 正尺度,穿过线性 EMA 与尺度不变的十分位排序影响为零;`pow_1_5` 在恒非负输入上严格单调递增,只能通过"先 EMA 再排序"留下极小扰动(实测 `Lnet` 差 0.2pp) |
| `c4_nodemean_out` 与 `c8_nofold_out` | **几乎是同一个东西** | rank 相关 **+0.99**;多头腿 +6.9%/+13.3% vs +5.9%/+11.8%;固定半衰期表形状几乎重合。代数:`c8 = ts_max(G − m_t, 30)`,其中 `m_t = mean_cs(G)` 是**只随日期变、对所有股票相同**的常数;`c4 ≡ ts_max(G, 30)` 的单调变换。在时间维上减掉一个逐日常数,只轻微改变 `ts_max` 取到哪一天 → 两者几乎同序。**R1 工单没有预测到这一点**(把它们当成"删 `cs_demean`"和"删 `pow_2`"两件不同的事),实际上它们是同一件事的两种写法:**把外层折叠拿掉**,因子就塌成 `ts_max(G, 30)` = 「82 日内最大的(34 日相对 MAX)²」 |

**引用规矩**:报告里凡要说"删掉外层折叠之后多头腿变好",**用 `c4_nodemean_out` 当代表**
(数字略好、换手更低 2.7% vs 2.9%),并注明 `c8_nofold_out` 是它的等价写法 —— 不要当成两条独立证据。

## 二、不等价、容易看成同一类的

| | 差别 |
|---|---|
| `c3_g_fold1` vs `c4_nodemean_out` | 回看 54 天 vs 82 天(`c4` = `c3` 再套一层 `ts_max(·,30)`)。多头腿 +6.8%/+9.6% vs +6.9%/+13.3%,`c4` 的 valid 明显更好、换手更低(2.7% vs 4.2%);但 `c3` 的 `all_controls` R² 是 0.478,`c4` 的还没量(R2 会量)。**不要混用** |
| `c7_nofold_in` vs `c8_nofold_out` | 一个删**内**层 `pow_2`(保留外层折叠),一个删**外**层 `pow_2`。前者 +4.2%/**−3.2%**(valid 翻负),后者 +5.9%/**+11.8%**。两层折叠**不是对称的**:外层那次才是毁掉多头腿的那一次 |
| `c1_b_max5` / `c2_e_rel34` vs `c3`/`c4` | 都是"同一条链上的早期节点",但 c1/c2 的多头腿 train/valid **不同向**,且与 `ctl_dvol20` 的相关(−0.79/−0.72)明显高于 c3/c4(−0.66/−0.60)。**短窗节点基本是朴素波动的改写,长窗节点才"干净"** —— R2 用直接替换检验这条 |

## 三、读总表时最容易犯的三个错(本研究已经踩到过)

1. **rank 相关表的列是控制变量的 raw 面板,行是交易信号。** 几乎所有控制变量自己的方向都是 `-1`,
   所以"候选与已知家族像不像"必须把列的符号翻过来:`c4` 那一行字面上是 `known_stdamt_mean30 −0.36`,
   翻过来是 **+0.36**。见 `05_hypotheses.md` §0 和 `partura/runner.py:332`。
2. **公布表的 `long` 列是毛超额,不是净超额**(`06_baseline.md` §1:公布 0.037 = `Lgross`,`Lnet` 只有 +0.7%)。
3. **中性化残差的 `Lnet` 塌掉 ≠ alpha 消失**:残差换手会涨 3~5 倍,净值类指标是被成本塌掉的
   (`c3`:`Lgross` +10.0%→+9.4% 几乎不掉,`Lnet` +6.8%→−3.4%,换手 4%→14.8%)。看残差的 `rIC` 和毛超额。
