# 怎么读总表、哪些变体其实是同一个东西

(第 2 轮先落了 S1_chain 的等价关系;**第 4 轮(留出段读完)补齐 S2_bench 与 S_final**。)

全研究一共 4 个阶段、26 个变体:`S0_baseline`(1)、`S1_chain`(10)、`S2_bench`(10)、`S_final`(5)。
**`S_final` 的 5 条没有一条是新结构** —— 它们是前面三个阶段里选出来的 5 条,换了 id 重跑一次以读留出段
(`rank_corr_train` 实测 +0.999~+1.000,见下表)。读总表时**不要把它们当成 5 条独立证据**。

## 一、精确等价(代数 + 实测双重确认,可以合并引用)

| 这几个 id | 其实是同一个东西 | 证据 |
|---|---|---|
| `v_base`、`c5_nopow15`、`c6_nomul_nosub`、**`f_orig`** | 同一条因子(= 原式) | `c6`×`v_base` rank 相关 **+1.00**;`c5`×`v_base` **+1.00**,固定半衰期 `hl=0` 行 `long_ann` **JSON 原文逐位相同**(两边都是 `0.0071861`);`f_orig`×`c5` **+0.999**。代数:`sub(·,−5)` 被 `cs_demean` 精确抵消;`mul(·,5)` 只留 125× 正尺度,穿过线性 EMA 与尺度不变的十分位排序影响为零;`pow_1_5` 在恒非负输入上严格单调递增,只能通过"先 EMA 再排序"留下极小扰动(实测 `Lnet` 差 0.2pp) |
| `c4_nodemean_out` 与 `c8_nofold_out` | **几乎是同一个东西** | rank 相关 **+0.99**;多头腿 +6.9%/+13.3% vs +5.9%/+11.8%;固定半衰期表形状几乎重合。代数:`c8 = ts_max(G − m_t, 30)`,其中 `m_t = mean_cs(G)` 是**只随日期变、对所有股票相同**的常数;`c4 ≡ ts_max(G, 30)` 的单调变换。在时间维上减掉一个逐日常数,只轻微改变 `ts_max` 取到哪一天 → 两者几乎同序。**R1 工单没有预测到这一点**(把它们当成"删 `cs_demean`"和"删 `pow_2`"两件不同的事),实际上是同一件事的两种写法:**把外层折叠拿掉**,因子就塌成 `ts_max(G, 30)` = 「82 日内最大的(34 日相对 MAX)²」 |
| `c4_nodemean_out` = **`f_c4`**;`m1_rel79_max` = **`f_m1`**;`kf_mean30` = **`f_kf30`**;`cb_c4_kf30` = **`f_cb`** | 逐字相同的表达式,只是 `S_final` 里换了 id | `rank_corr_train`:`f_c4`×`c4_nodemean_out` **+1.000**、`f_kf30`×`kf_mean30` **+1.000**(`results/R3.md` §7)。**引用规矩**:train/valid 的数字引 S1/S2 的 id,holdout 的数字引 `f_*` 的 id,**不要把同一条因子当两条** |
| `kf_mean30` 与 `kf_max9` | 同一个已知家族 | rank 相关 **+0.958**;多头腿 +12.6%/+22.3% vs +13.7%/+22.2%。**留一条当基准即可**(选了 `kf_mean30`,因为它是用户表里那条) |

## 二、不等价,但容易看成同一类的

| | 差别 |
|---|---|
| **`n2_max79_plain` vs `m1_rel79_max`** | **本研究最重要的一组对照,也是"rank 相关高 ≠ 可互换"的反例**:两者 rank 相关 **+0.948**,看着像同一条;但多头腿 `Lnet` 差 **3.5pp(train)/ 6.2pp(valid)**、`Lshp` 差 0.47/1.25(`n2` 的 train `Lshp` 还是 −0.04)。差别只有一个算子:`cs_demean`(减掉当天截面均值)。**读法:十分位腿只吃排序的顶端 10%,全样本 rank 相关 +0.95 完全可以配上一条废掉的多头腿。以后不要用 rank 相关当"可以替换"的依据** |
| `m2_rel50_absmax` vs `m3_rel50_absmean` | 一个取 abs **max**、一个取 abs **mean**,rank 相关 +0.808,多头腿只差 **0.6pp/1.3pp**(噪声带内)→ **极值记忆(MAX)是装饰**,这条因子卖的是"相对振幅的水平"。名字(`nested_tsmax`)误导人 |
| `m3_rel50_absmean` vs `n4_dvol50_plain` | 相对振幅 vs 朴素波动,两段差 **7.6pp / 9.2pp** → **不是低波动的改写** |
| `c3_g_fold1` vs `c4_nodemean_out` | 回看 54 天 vs 82 天(`c4` = `c3` 再套一层 `ts_max(·,30)`)。多头腿 +6.8%/+9.6% vs +6.9%/+13.3%,`c4` 的 valid 明显更好、换手更低(2.7% vs 4.2%);`all_controls` R² 0.478 vs 0.418。**不要混用** |
| `c7_nofold_in` vs `c8_nofold_out` | 一个删**内**层 `pow_2`(保留外层折叠),一个删**外**层 `pow_2`。前者 +4.2%/**−3.2%**(valid 翻负),后者 +5.9%/**+11.8%**。两层折叠**不是对称的**:外层那次才是毁掉多头腿的那一次 |
| `c1_b_max5` / `c2_e_rel34` vs `c3`/`c4` | 都是"同一条链上的早期节点",但 c1/c2 的多头腿 train/valid **不同向**(−5.8%/+5.4%、−1.1%/+8.5%),且与 `ctl_dvol20` 的相关(−0.79/−0.72)明显高于 c3/c4(−0.66/−0.60)。**短窗节点基本是朴素波动的改写,长窗节点才"干净"**(R2 的直接替换已证实) |

| **`f_c4` vs `f_m1`** | 嵌套的 82 日版 vs 4 节点的 79 日版,rank 相关 +0.70~+0.95、同属一族;但**三段排序来回翻**(`f_c4` − `f_m1` = train +3.70 / valid −1.49 / holdout **−3.71** pp),同一本书内 utrain→holdout 衰减 **−7.27pp vs −1.33pp**。**要用这一族就用 `f_m1`**(`09_diagnosis.md` E7/U1) |

## 三、一族(H14):`c4` / `m1` / `m2` / `m3` / `w1` / `w2` / `c8`

两两 rank 相关 **+0.70~+0.95**,valid `Lnet` 全在 **+12.7%~+14.8%**(跨度仅 **2.1pp**,噪声带内),
而 train 跨度是 **7.2pp**、且 **train 的族内排序与 valid 翻转**。
**引用规矩**:报告里把它们当**一条因子的不同写法**,不要拿 train 上的族内差异说"哪个结构更好";
要说结构更好,必须在同一个半衰期下比(摘要里有固定半衰期表)。族代表用 `c4_nodemean_out`
(数字略好、换手更低 2.7% vs 2.9%),并注明 `c8_nofold_out` 是它的等价写法 —— **不要当成两条独立证据**。

## 四、读总表时最容易犯的错(本研究已经踩到过的)

1. **rank 相关表的列是控制变量的 raw 面板,行是交易信号。** 几乎所有控制变量自己的方向都是 `-1`,
   所以"候选与已知家族像不像"必须把列的符号翻过来:`c4` 那一行字面上是 `known_stdamt_mean30 −0.36`,
   翻过来是 **+0.36**。见 `05_hypotheses.md` §0 和 `partura/runner.py:332`。
2. **公布表的 `long` 列是毛超额,不是净超额**(`06_baseline.md` §1:公布 0.037 = `Lgross`,`Lnet` 只有 +0.68%)。
3. **中性化残差的 `Lnet` 塌掉 ≠ alpha 消失**:对**全部控制变量**中性化时残差换手会涨 3~5 倍,净值类指标是被成本塌掉的
   (`c3`:`Lgross` +10.0%→+9.4% 几乎不掉,`Lnet` +6.8%→−3.4%,换手 4%→14.8%)。看残差的 `rIC` 和毛超额。
   **但增量检验那张表恰好相反**:`c4` 对已知家族的残差**毛**超额本身就是 −0.01%/+2.85%、换手只 1.7~1.8%
   → 那是**真没了**。两处读法不要混(`11_risks.md` R7)。
4. **`books` 与 `books_user` 不要混着做差。** train/valid 两列来自 `books`(fit = train),utrain/holdout 两列来自
   `books_user`(fit = utrain);**holdout 只存在于 `books_user`**。拿 valid 减 holdout 会把"换了一本书"
   和"换了一段"混在一起 —— 正确的衰减是**同一本书内的 utrain→holdout**
   (`f_m1` 只 −1.33pp,不是 `results/R3.md` 那条注里写的 9.6pp)。
5. **逐年表现在是 8 年(2018–2025),不要再引用"六年无一年反超"。** 8 年口径下
   **`f_m1` 在 2024 年反超了 `f_kf30`**(+12.9% vs +9.2%),`f_c4` 2024 打平,其余 7 年都低。
6. **`cov` 不是因子覆盖率**,是标签覆盖率:5 个候选之间几乎不变(0.9992~0.9997),这道门槛在本研究里没有区分力;
   只有 `dist`(JSON 字段 `distinct`)随表达式变,且只在 fit 段算。
7. **跨阶段诊断**:`runner.py` 的 `by_year` / `neutralise` 只算本次 `run` 传进去的 stage 里的变体
   (`corr_ids` / `profile` / `conditional` 走 `refs`,没这个限制)。要补算就把那个变体原本的 stage 一起传进 `run`。
