## 想回答的问题

**这棵树的最小充分结构是什么,以及它的钱为什么在空头腿?**

一阶展开(`04_grammar.md` 的 ★)把全树近似成

```
F_t − 1/30 ≈ (2/30)·[ (A_t − Ā) + (B_t − B̄) ] / C̄ ,  A=day_quantile(Close),B=day_kurt(High),sign=−1
             └ 价格通道 ┘   └ 峰度通道 ┘
```

要分辨的是:两个通道谁出力(H1/H2)、混合权重是不是 ∝1/价位(H2b)、5 个节点里哪些可删(H3/H4)、
真实视野是不是比 30 天长(H7)、空头腿是不是封板票撑的(H5)、偏离分布是不是右偏(H6)。

**看到哪种结果意味着什么**(每条的证伪判据写在 `05_hypotheses.md` 对应假设下,这里只列最关键的):

| 结果 | 意味着 |
|---|---|
| `s1_noK` 与 `v_base` 的多头腿在噪声内(±3pp)且 rank 相关 ≥0.8 | 峰度节点是装饰 ⇒ H1 成立、H2 被否定 |
| `s1_noK` 多头腿掉 ≥3pp | 峰度通道不可删 ⇒ H2 成立,H1 只是一半 |
| `s1_plain30` 拿到接近 `v_base` 的多头腿 | 三个中间节点全是装饰,提纯成 2 节点 |
| `s1_noSpow` 与 `v_base` rank 相关 ≥0.9 | `signedpower` 秩层面冗余(H3)⇒ 可删 |
| `s1_noMask` 多头腿**更好** | 截尾在帮倒忙(H4)⇒ 可删 |
| `s1_x60` / `s1_x241` 多头腿明显高于 `+3.7%/+5.3%` | 真实视野更长(H7)⇒ 升华方向;**归因看固定半衰期表** |
| `s1_x30` 与 `v_base` 数字不一致 | `cross_scale` 与 `ts_scale` 不是同一个内核 ⇒ 窗口阶梯(x60/x241)全部作废,必须告警 |
| 空头十分位在 `buyable=False` 标签下明显变弱 | H5 成立 ⇒ 用户那张表的 `ls` 虚高 |

### 第 2 件:分析脚本 `studies/F112_scale_spow_masktop/a1_channels.py`(tag 就叫 `A1_channels`)

`study.sh exec` 跑。**五个小节,各自用 try/except 包起来**:每节开头 `print("=== §N 名字 ===")`,
某节抛异常就打印 traceback 后**继续下一节**,不要让一节的失败带走整个脚本。
脚本里一律 `print` 输出(`wait` 只打印日志尾部 200 行,所以**每节的结论数字要紧凑**,不要打印大矩阵;

面板取法(`st.panels` 按表达式内容共享缓存,原式是 S0 算过的,免费):

```python
P = st.panels({
  "F":  "ts_scale(signedpower(cs_mask_top_replace_mean_neg(add(day_quantile(Close), day_kurt(High)))), 30)",
  "C":  "add(day_quantile(Close), day_kurt(High))",
  "A":  "day_quantile(Close)",
  "B":  "day_kurt(High)",
  "Fn": "ts_scale(cs_mask_top_replace_mean_neg(add(day_quantile(Close), day_kurt(High))), 30)",
})
```

**§1 重建 + 自检(是 §2 §5 的前置闸门)**
用 numpy 从面板 `C` 把因子重建一遍,严格照 `02_operators.md` 的源码语义:
- `valid = isfinite(C)`;逐交易日:`n = valid.sum()`、`n_top = ceil(n*0.1)`;
  把当天**有效股票中 `C` 升序排名最低的 `n_top` 只**替换成**当天所有有效 `C` 的 nanmean**,其余原样,NaN 保持 NaN ⇒ `D`
- `E = sign(D)*D**2`
- `F_rec[t] = E[t] / nansum(E[t-29..t])`(含当天、左侧不足 30 天就用实际可得天数);`|分母| < EPS` 时分母换成 `1`,
  `EPS` 先用 `1e-12`;如果自检不过,再试 `1e-8` 并报告哪个对得上
- **自检判据**:逐日横截面 spearman(`F_rec`, `P["F"]`) 的 train 段**均值 ≥ 0.999**。
  同时报这个 spearman 的最小值、以及 `|F_rec−F|/(|F|+1e-12)` 的中位数与 99 分位。
  **自检不过就打印「§1 自检失败,§2/§5 跳过」并跳过 §2 和 §5**(§3 §4 不依赖重建,照跑)。

**§2 公布值的出入(H9,优先级最低)** —— 只在 §1 通过时做
- 版本 `R`:`n_top = round(n*0.1)` 重建(写清用的是 python `round` 还是 `np.rint`,两者都是银行家取整)
- 版本 `W`:在 `F_rec` 基础上,把**每只股票自己最前 29 个有效交易日**置 NaN
- 对 `F_rec`、`R`、`W` 各跑 `st.books(panel, fit="utrain", evals=("utrain",))`,报 `LS`(扣费多空夏普)与 `Lgross`(多头腿毛超额)
- 另报:`ceil` 与 `round` 取值不同的交易日占比、平均相差几只
- 对照目标:引擎 `v_base` utrain `LS +2.59`/`Lgross +9.1%`;用户公布 `+2.58`/`+8.9%`

**§3 封板票与质点(H5 + H4)**
- `sig = st.signal(P["F"])`(方向 × hl20 EMA 之后的实际交易信号);每天按 `sig` 取前 10%(多头腿)与后 10%(空头腿)
- `tgt = st.target()`、`raw = st.target(buyable=False)`
- 报(train 段):两条腿在**两种标签**下的毛超额。口径不确定时**同时报两种**并注明:
  ① 组内等权收益;② 组内等权收益 − 当天「有信号且有标签」的票的等权收益
- 报:多头十分位、空头十分位、全市场里 `tgt` 为 NaN 的格子占比(这是「买不进」的直接度量)
- 质点(H4):每天 `D != C` 的股票只数与占比;其中「过去 30 个交易日每天都被替换」的只数;
  这群股票当天 `F` 的横截面百分位(均值与四分位);每天 `F` 完全相同的最大并列组有多大

**§4 通道分解(H1 / H2 / H2b / H6)** —— 本节最重要,失败了要专门告警
- `mean30X` = 对 `A`/`B`/`C` 各自按股票取过去 30 个交易日(含当天)的 nanmean
- `devA = A − mean30A`、`devB = B − mean30B`、`e = C/mean30C − 1`
- `termP = devA/mean30C`、`termK = devB/mean30C`
- 逐日横截面 spearman,报 train 段均值:`(F, termP)`、`(F, termK)`、`(F, termP+termK)`、`(F, e)`
- 幅度对比:`termP`、`termK` 的逐日横截面标准差,报 train 段中位数与两者之比
- **分桶(H2b)**:每天按 `mean30A` 的**滞后一日**值(用 t−1 日的,避免 playbook §6.7 的内生分桶)分 5 桶,
  桶内重算 `(F,termP)`、`(F,termK)` 的 spearman 与 `std(termP)`、`std(termK)`,输出 5 行 × 4 列的表(train 段均值)
- **偏度(H6)**:逐日 `e` 的横截面偏度(train 段均值与中位数);`e` 的 1/5/50/95/99 分位(train 池化)
- 排除 mask 污染:只用 `D == C` 的格子把 `(F,termP)`、`(F,termK)` 再算一遍

**§5 `signedpower` 的二阶项(H3)** —— 只在 §1 通过时做
- 逐日横截面 spearman(`P["F"]`, `P["Fn"]`) 的 train 均值 ← **H3 的直接判据**
- `Δ = F − 2*Fn`;`m2` = 过去 30 日 `e` 的二阶矩;报逐日 spearman(`Δ`, `e² − m2`) 的 train 均值
- `disp` = 过去 30 日 `C` 的标准差 / `mean30C`;报 `st.rank_corr(sig, disp)` 与
  `st.rank_corr(sig, st.control("known_stdamt_mean30"))`(train)
