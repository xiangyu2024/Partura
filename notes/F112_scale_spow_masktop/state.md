## 3. 研究过程与逻辑(做了什么、为什么这么走)

**R0(执行)**:从零建档。6 个算子逐个读服务器端源码,写了 `01_expression.md`(逐层公式)、

**R1(主研,本轮)**:没有跑任何实验,做的是**把这棵树读懂并推出计划**:
1. 先读 playbook + method + R0 的四份 notes,核对了算子窗口池(`./scripts/study.sh ops`)和 `cross_scale` 的源码。
2. 写 `04_grammar.md`:把全树化成一阶展开 ★,得到「两个通道 + 混合权重 ∝1/价位」这个唯一的非平凡结构。
3. 写 `05_hypotheses.md`:H1~H9,每条带「预测什么 / 什么能杀死它」。
4. 下工单 `orders/R1.md`:`S1_minimal`(10 变体)+ `A1_channels`(5 节脚本)。

**为什么是这个顺序**:这棵树只有 `ts_scale` 一个跨日节点,预测力必须来自「相对自身 30 日历史」这一个成形动作;
所以第一刀切在「哪个通道 + 哪个视野」,而不是常规的「门控/幅度」那套(这棵树没有门控,见 `04_grammar.md`)。

### 源码里和名字不一样的地方(别重复踩,细节在 `02_operators.md`)

- **`cs_mask_top_replace_mean_neg` 遮的是最低一成,不是最高**(`_neg` 后缀用取负-翻转把语义反过来了)。
- **`ts_scale` 不是「只调幅度」**:每只股票除以**它自己**过去 30 日的滚动和,分母不共享 ⇒ 一般**不是横截面保序**的。
  它是全树唯一的信号成形节点:把水平量变成「相对自身历史的偏离」。
- **`day_quantile(Close)` 的 `q` 没传,是中位数**;`signedpower` 的 `e` 没传,是带符号平方;
  `cs_mask_top_replace_mean_neg` 的 `top_ratio` 没传,是 10%;`add` 的 `fill_nan_with_zero` 是 False(标准 NaN 传播)。
- **`cross_scale` 与 `ts_scale` 源码逐字同公式**(都是 `rolling_windows` + `scale_last_ratio`),只是 DT 面按股票分块。
  本轮据此用 `cross_scale` 去拿 60/241 的窗口(`ts_scale` 窗口池只到 50)。窗口池:
  `ts_scale [1,5,10,20,30,40,50]`、`cross_scale [3,5,10,15,30,60,241]`。**`s1_x30` 就是用来验证这个等价性的。**
- **`day_kurt` 内部 `_kurt` 的源码没读到**(工具解析不了 `C._kurt` 这种模块属性调用);用同库 `nankurt_last`、
  `day_kurt_masked` 跨实现互证 + 探针(k=0、偶函数、平移不变)指向「总体矩 Fisher 超额峰度减 3」,但非逐字确认。
- **两套 rank 相关符号相反**(`ctl_mom20`:原始面板 `+0.49`、交易信号 `−0.29`),因为一套是未平滑原始面板、
  一套是「方向 × hl20 EMA」之后的交易信号。两个都是事实,引用时必须说清是哪套。
- **条件 IC 的符号与 `rIC` 对不上**(`rIC +0.0141` 但条件 IC 全是负数),R1 已要求执行去源码确认口径。

   ③ 候选与原式 rank 相关 < 0.8 就不是提纯,是换了一条因子,可以推荐但必须这么写。
6. **选拔口径**:只看多头腿净超额 `Lnet` 与纯多头夏普 `Lshp`(`rank_by: long`)。
   空头腿 `+28.5%`、多空夏普 `+2.78` 都是**次要信息**,用户做不了空头。噪声量级:`Lnet ±3pp`、`Lshp ±0.3`、`LS ±0.3`。
