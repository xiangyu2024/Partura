# 09 · 机制诊断(已确立 / 合理但未坐实 / 未决)

> 第 4 轮主研写于 2026-10-04,留出段已读。每条都指到一个实验。
> 口径:`rank_by: long`、扣 15bp;噪声带 `Lnet ±3pp`、`Lshp ±0.3`。
> A 卷 = fit `train`(train/valid);B 卷 = fit `utrain`(utrain/holdout,用户表口径)。

## 一句话机制

这棵树算的是「当天价位分位 + 当天 High 的分钟级尖峰度」这个混合量相对**自己**过去 N 日滚动和的偏离
(`ts_scale` 的分母是每只股票自己的,不共享),反向交易。它的多头腿**不是一个独立的 alpha,而是一条连续暴露谱上的一点**:
跨日窗口 N 就是谱上的位置旋钮 —— N 小的那端是 20 日反转,N 大的那端是低价 / 成交额水平家族。
截尾节点 `cs_mask_top_replace_mean_neg` 在这条谱上是纯损耗。

## 已确立(有实验、留出段也看过或与留出段一致)

**E1 · 多头腿可交易,不是「用不了」。** 原式配多头最优半衰期(`hlL = 20`):A 卷 `+3.66% / +5.35%`、`Lshp +0.660 / +0.914`;
B 卷 holdout `+6.89%`、`Lshp +1.031`,`cov 0.9986`、`dist 0.9751`、`sign −1` 全过门槛(`results/R3.md` §1)。
⇒ 「多头腿不可用」这个结论**不成立**,不要这么写。不推荐的理由在 P1,不在这里。

**E2 · 截尾节点在帮倒忙,而且是结构不是平滑(H4)。** 固定半衰期五档(train,`books.sweep`):
`f_nomask30 − f_orig = +2.7 / +6.2 / +4.6 / +4.1 / +3.4pp`(hl 0/2/5/10/20),换手几乎不变(6.58% → 6.84%);
`f_t50 − f_orig` 同档 `+11.6 / +13.0 / +9.8 / +7.5 / +4.4pp`(`results/R3.md` §2)。
留出段 J1 过:`+11.12%` vs `+6.89%` = `+4.23pp`。⇒ 同一半衰期下也赢,**可以写「结构更好」**。

**E3 · mask 的机制 = 把一成股票整体剔除,代价由被剔除那一成含多少信息决定(H10′)。**
反例实验 `s2_masktop`(改遮**最高**一成)五档 ≈ `s2_f30`(不遮),远好于 `v_base`(遮**最低**一成);
被替换格子按 `F` 分十桶,多头端桶 0~3 只占 `0.46%~0.65%`、桶 5~9 占 `15%~24%`(`results/R2.md` §12①)。
⇒ 不是端特异,也**不是**「饿掉多头端原料」(那个读法被自己的桶分布推翻,见下面「已否定的读法」③)。

**E4 · 跨日窗口是暴露旋钮,不是视野长度(H7′ / H1′)。** 原始面板秩相关随窗口 30→50→60→241 **四列全单调**:
`ρ(ctl_mom20) +0.554→+0.540→+0.519→+0.341`、`ρ(ctl_price) +0.257→…→+0.399`、`ρ(K1) +0.086→…→+0.335`、
`ρ(K2) +0.198→…→+0.344`;`ctl_mom20` 中性化 `R² 0.153→0.068→0.030`(`results/R2.md` §4–§5)。
留出段 J2 过(`f_t50 +10.47%`、`f_x241 +9.42%`,都在 `f_nomask30 − 3pp = +8.12%` 以上)⇒ 50~241 是**平台**,不是过拟合的尖点。

**E5 · 节点取舍无关紧要(H2′ 被否定)。** 2×2 固定 hl20 主效应:峰度 `+0.9pp`、平方 `−0.5pp`、交互 `+0.1pp`,全在噪声内
(`results/R2.md`、`07_S2_combo.md`)。⇒ **没有**「两通道显式等权」的升华版可做;它的触发条件(`s2_f30 ≫ s2_n30`)实测不成立
(`+7.1%` vs `+6.7%`、`Lshp +1.05` vs `+0.83`)。

**E6 · 候选不是原式的提纯版。** `ρ(f_orig)`:交易信号口径 `+0.784 / +0.743 / +0.509`、原始面板口径 `+0.687 / +0.611 / +0.353`
(`results/R3.md` §5 与 `results/R2.md`)。三条**都 < 0.8** ⇒ 按 playbook §6 这是**以原式为线索挖到的另一条因子**。
报告里不许出现「提纯版」。

**E7 · `signedpower` 不是折叠算子。** 默认 `e = 2`,但带符号 ⇒ `sign(x)·x²` 在实轴单调 ⇒ 审查项「折叠型因子要用同样折叠过的控制变量去量」
**对本因子不适用**(`02_operators.md`)。报告里要说明这一句,免得被当成漏做。

**E8 · 空头腿由封板票 + 尾部极端格子撑(H5 / H6,与选拔口径无关,已结案)。**
空头十分位内严格买不进 `5.12%` vs 多头 `1.10%`;空头②从 `−29.1%`(tgt)掉到 `−21.3%`(raw)。
⇒ 多空数字(`LS`)不可当成可实现收益引用。

**E9 · 留出段的比较基础可信。** `f_known` holdout `+13.23%` / `Lshp 1.402`,正落在用户任务书给的测试段家族参照
(`+13%~+15%`、`Lshp 1.4~1.9`)下沿 ⇒ 这次 holdout 的评估与用户表同一把尺子。

## 合理但未坐实

**P1 · 「对只能做多的用户,这条因子相对已知成交额家族没有增量」(H8)—— 本轮从「已确立」降级。**
支持它的三条腿,留出段之后只剩两条站得稳:
- **残差(主证,口径匹配,train/valid)**:对 `{K1, K2}` 逐日回归取残差后,`Lgross` 从 `+12.3% / +14.5%` 掉到 `+3.1% / +6.2%`
  (只剩 `25% / 43%`),`rICtraded` 剩 `55% / 62%`,16 格判据全部「无残差增量」;残差换手升到 `11%~18%`(未中性化 `4%~7%`)
  (`07x_02_a2_increment.md`)。**留出段没有重做,也不能重做。**
- **合成(旁证)**:24 格全「无增量」,12 组的 valid `Lnet` **全部低于**对应的 K 单独(最多低 `7.0pp`)⇒ 掺进去是稀释。
  只当旁证:合成 `cov 0.689` 由候选一侧决定,不是同池比较。
- **独立比(留出段上不再支持)**:J4 没达门槛 —— `f_known +13.23%` 只比最好的候选 `f_nomask30 +11.12%` 高 `2.11pp`(`<3pp`),
  `Lshp` 只高 `0.064~0.074`(`<0.3`)。train/valid 上的「家族高一倍」在用户测试段上**不成立**。
⇒ 现在这条结论**靠的是 train/valid 的残差检验,不靠留出段的独立比**。按预注册,J4 的中间区不能单独推翻它,
但也不能再说「已确立」。**推荐不变(见 `10_distilled.md`),状态降级。**

**P2 · 「共同成分虽然不占秩相关的大头,却恰好是赚钱的那一部分」。** 候选与家族的秩相关只有 `+0.34~0.37`
(原始面板 `ρ(K1)` 最高 `+0.335`;交易信号矩阵 `+0.360~0.367`),却被 `{K1, K2}` 的残差吃掉 `75% / 57%` 的毛超额。
这个解释合理,但**不是唯一解释**:残差化本身把换手从 `4%~7%` 抬到 `11%~18%`,也可能是**残差化破坏了可交易性**而非信息被吃掉。
现有证据分不开这两者,而且这套算子语法写不出逐日回归残差 ⇒ 引擎内无法构造一个可交易的残差来裁决。
**对用户这是最终的**(他拿不到那个残差),但作为**机制断言**它只是「合理」。

**P3 · 「J4 门槛没过是 2024 单年构成,不是水平追上」。** 能干净读的两个留出年:候选 2024 `+19%~+21%`、2025 `+3.1%~+4.7%`;
家族 2024 `+9.0%`、2025 `+13.5%`(2023 那一列混了 valid,不能当纯 holdout 读)。
两年合计接近(`f_t50 +24.2%` vs `f_known +22.5%`),但构成完全不同;最近一年家族是候选的三到四倍。
**事后解释、非预注册**,只说明不确定性来自哪里,不改判据、不改推荐。

**P4 · 长窗口端「滑进成交额家族」是倾向,不是身份。** `ρ(K1)` 升到 `+0.335`、`ρ(ctl_price)` 升到 `+0.399` 方向明确,
但 0.3~0.4 的秩相关**不足以**说「它就是家族」。报告里要写「往已知暴露滑」,不要写「它等于成交额家族」。

## 已被自己的实验否定、别再走的读法

1. **用 `signedpower` 的折叠项解释空头腿占比** —— 一阶项压倒折叠项,而且带符号的平方根本不折叠(E7)。
2. **把一阶展开 ★ `F_t − 1/30 ≈ (2/30)[(A_t−Ā)+(B_t−B̄)]/C̄` 当全局读法** —— 最低价位桶 `std(termK) = 0.476`,不是小量。
   ★ 只在价位中高端近似成立(`04_grammar.md`)。
3. **「mask 饿掉了多头端的原料」** —— 被替换格子集中在空头端一侧(E3 的桶分布),方向相反。
4. **「两通道显式等权」的升华版** —— 触发条件被 2×2 否掉(E5)。**是被实验否掉的,不是没来得及做。**
5. **用 `v_base` 的条件 IC Q1 低来证明 mask 的损害** —— 分桶变量 `ctl_price` 与 mask 的作用对象近乎同一群股票,
   「Q1 低」几乎是定义使然。**有信息量的是 `s2_masktop` 的 Q1 也高。**
