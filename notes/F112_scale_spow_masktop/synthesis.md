# F112_scale_spow_masktop · 批量扫描 s1 的综合(主研,2026-10-05)

口径:多头腿扣费净超额 Lnet / 纯多头夏普 Lshp,半衰期按纯多头书在 train 上选;ut = utrain(2018-01~2023-08)。
噪声 ±3pp / ±0.3。基准 `k_known = cross_mean(day_std(Amt), 30)`:ut **+15.4% / 2.22**,换手 3.4%。
原式 `v_base`:ut **+4.2% / 0.74**,换手 6.6%,ρk 0.25。证据表 = `runs/F112_scale_spow_masktop/sweep_s1.json`(113 变体)+ `anatomy_s1.json`。

## 1. 它是什么(按源码逐层)

设 P = 分钟 Close,H = 分钟 High,窗口内 = 该股自己近 30 个交易日。

| 层 | 写法 | 源码实际算的 |
|---|---|---|
| A | `day_quantile(Close)` | `nanquantile(q=0.5)` ⇒ **当天分钟价的中位数**,单位元。名字是 quantile,默认 q 就是中位数 —— `sub_A_day_median` 与 `v_base` 数字完全相同(ρo +1.00)可证 |
| B | `day_kurt(High)` | 当天分钟 High 的峰度,无量纲,量级 1~20 |
| C | `add(A, B)` | **元 + 无量纲数**。两个加数量级差一个数量级以上 ⇒ C ≈ A,B 只是扰动。`iso_A`(只有 A)ut +5.8%/0.82 vs `iso_C` +6.3%/0.89,差在噪声内 |
| D | `cs_mask_top_replace_mean_neg` | `-cs_mask_top_replace_mean(-x)` ⇒ 把每天截面**最低 10%** 换成当天均值。名字里的 top 是反的。方向 -1 下多头买低值 ⇒ **它正好抹掉多头腿自己的尾巴**,最便宜的一成被顶到中位、永远买不到,实际买的是 10%~20% 那一档 |
| E | `signedpower(e=2)` | `sign·|x|²`;C 在正值域上 ⇒ 就是平方(`sub_E_pow_2` 与 `v_base` 数字相同)。单调,**不是折叠算子** |
| F | `ts_scale(·, 30)` | `x[t] / nansum(近 30 日 x)`,分母是每只股票自己的滚动**和**(不是均值),加常数 0 |

合起来,记 r = P_t / mean₃₀(P)、cv = 窗口内价格的变异系数,则
`F(E(·)) = P_t² / Σ P² ≈ r² / (30·(1+cv²))`。所以这棵树是:

> **「这个月跌了多少」× 「这个月价格自己抖得多厉害」**,再把最便宜的一成挖掉。
> 方向 sg = -1 ⇒ 多头 = r 小(相对自己一个月的均价跌下来)且 cv 大(月内路径波动大)的票。

两处要点名:(a) **E 不是保序冗余**,它把分母从窗口算术均值变成偏向大值的幂均值,等价于多乘一个 `1/(1+cv²)`
—— 这就是 `abl_E`(删 E)掉到 ut +2.8%/0.50 的原因;`pow_3` ut +4.2%/0.74 与平方持平 ⇒ 指数上是平台。
(b) **F 的 nansum 分母是一个未被设计的暴露**:窗口里缺失日越多,分母项数越少、取值越大,方向 -1 下就被压到书底。
解剖表直接证实:带 `ts_scale` 的变体对「上市不足 250 日」一律低配 **-4.9% ~ -5.5%**(v_base -5.5%、abl_D -5.4%、
sub_D_cs_rank -4.9%),不带的一律 **-0.1% ~ -0.7%**(iso_E、iso_D、sub_F_ts_decay_linear)。次新的回避是算子实现的副产品,不是选股。

## 2. 预测力在哪

**承重的只有一个:A 这条价格叶子,外加 F 这个比值。** 其余节点都是可换或有害的。

- **A 必须压倒 B。** `only_C_R`(只留峰度)ut **-4.8% / -1.48**;`rank_C`(先把两个加数各自 cs_rank 再相加,
  强行让峰度和价格等权)ut **-10.8% / -2.72**、换手 24.4%;`sub_B_day_q_stat_std`(把峰度换成量级更大的分钟 High 标准差)
  ut **-21.9% / -3.30**。⇒ `add` 不是「组合」,是「价格 + 可忽略扰动」,一旦第二项拿到可比的量级,整棵树就反过来塌掉。
- **B 删掉不掉。** `abl_C`(去峰度)ut +3.9%/0.54 vs base +4.2%/0.74,在噪声内。B 的身份也不重要:
  `day_kurt(Close)` +4.5%/0.79、`day_kurt(Open)` +3.9%/0.67。
- **D 是有害的。** `abl_D`(删掉截尾)ut **+7.8% / 1.12**,比原式高 +3.6pp、夏普 +0.38,换手不变(6.8% vs 6.6%)。
  `sub_D_cs_winsor` +7.8%/1.13 与 abl_D 几乎同一条(ρo 都 0.78)⇒ 损失**不是**离群值问题,就是「整体剔掉最便宜的一成」。
  最好的替代是 `sub_D_cs_rank` ut **+8.8% / 1.35**(全表非 overlay、非基准里最高)。
  反面:`sub_D_cs_demean` ut -16.5%(去均值后 C 有负数,平方变成折叠)⇒ **C 的正值性是 E 能用的前提**。
- **F 换成别的时序算子就换了一条因子。** `sub_F_ts_decay_linear`(比值 → 加权均值,保留水平量)ut +8.2%/1.80、ρo 0.18;
  `iso_E`(整个删掉 F)ut +8.4%/1.85、ρo 0.17。**这不是「F 有害」,是 F 把一条价格水平因子换成了一条反转因子**(见 §3)。
  `sub_F_ts_spearman` 方向翻成 +1、ρo 0.15,是第三条因子。
- **窗口单调,没看到平台(ts_* 池最大只有 50)。** 20 → +1.0%/0.18,30 → +4.2%/0.74,40 → +4.6%/0.83,50 → **+4.9%/0.90**。
  往长走还在变好;要越过 50 必须换 `cross_scale`(窗口池到 241)。
- **可互换的叶子**:A 的字段 Close→High/Open/Vwap 全在 +3.9%/0.69~0.70;A 的算子 `day_close`/`day_last` +4.3%/0.76、
  `day_max` +4.3%/0.75、`day_median` 与原式相同 ⇒ **A 只是「当天的价格水平」,用哪个摘法都一样**。
- **外层形状全是负作用**:`cs_rank` ut +2.0%/0.40、`abs_(cs_demean(·))` +1.9%/0.31、`abs_(cs_demean(cs_rank(·)))` +1.5%/0.24。
  日轴记忆里只有平滑类能帮一点(`cross_ema60` +5.4%/0.94、`cross_decay_linear5` +5.2%/0.92);
  `cross_zscore` 5/10 日 ut -15.1% / -14.1%、`cross_min` 30/60 日 -16.4% / -15.2% ⇒ 信号要的是比值的**截面水平**,
  把它换成「对自己历史是否异常」后符号整个反过来。

## 3. 在市场的哪儿、什么时候有效

先要把两族分开 —— 解剖表证明它们是两条不同的因子:

| 分段 | `v_base` / `abl_D`(含比值) | `iso_E`(无比值,价格水平) | `k_known` |
|---|---|---|---|
| 价格五档(低→高) | -12.1 / +1.5 / +7.3 / +5.1 / +4.7;abl_D +2.3 / +5.3 / +8.0 / +5.1 / +4.7 | **+0.5 / -9.0 / -25.7 / -21.0 / -19.6** | +10.6 / +10.4 / +8.3 / +9.4 / +2.1 |
| 成交额五档(低→高) | -4.4 … **+4.8**;abl_D -0.1 / -2.1 / -0.2 / +4.2 / **+12.4** | +1.0 / -3.8 / -2.7 / -5.9 / **-14.5** | -4.1 / -5.3 / -8.2 / -5.2 / +2.5 |
| 段等权超额(同上) | — | — | 成交额档 +15.1 / +8.9 / +2.6 / -6.0 / -17.8 |

- **`iso_E` 族(无比值)在任何价格桶内部都是 -9% ~ -26%,只在最便宜那一档不亏(+0.5%),持仓 +34.7% 压在价格最低 20%、
  其余四档一律 -19.9%(几乎不持有)。** ⇒ 它**就是价格水平本身**,把价差抽掉就什么都不剩;它的 +8.4% 是低价 / 小市值 /
  低流动性的段 beta(这三段的段等权超额分别 +7.0% / +6.4% / +15.1%)。**这一族不是新东西。**
- **比值族(v_base / abl_D)在每个价格桶内都正(abl_D +2.3 ~ +8.0),持仓只温和偏低价(+15.3%)** ⇒ 比值把价格水平约掉了,
  剩下的是 r = 一个月相对自身均价的涨跌 ⇒ **一条 1 个月反转因子**。state.md 记的 ρ(mom20) = +0.554 与此一致(方向 -1 ⇒ 反转)。
- **比值族的信息集中在流动性高的一半**:abl_D 成交额最高档 **+12.4%**、60-80 档 +4.2%,而最低两档 -0.1% / -2.1%。
  `iso_E` 正好相反(最高档 -14.5%)。
- **板块**:v_base 创业板 +9.8%、深主板 +4.0%、沪主板 +0.6%、科创板 +0.8%;abl_D 创 +11.0 / 深 +9.9 / 沪 +5.6 / 科 -4.6。
- **两个被低配的富矿**:上市不足 250 日(占 7.1%,段等权 -28.7%)段内书 v_base **+11.2%**、iso_D +17.2%,持仓却 -5.5%;
  近 15 日有冻结盘口(占 6.5%,段等权 -67.4%)段内书 abl_D **+29.6%**、sub_D_cs_winsor +29.1%、v_base +14.8%,持仓 -3.2%,
  而 `k_known` 在这一段是 **-10.9%**。
- **时间 / 状态**:市场波动高于中位 v_base **+13.2%** vs 低于中位 **-4.7%**(abl_D +17.8% vs -2.0%);
  市场近 20 日下跌 +8.0% vs 上涨 +1.4%;缩量 +5.9% vs 放量 +2.0%。年度:2018 +12.3、2022 +11.8 最好,
  2020 -4.2、2023 -5.3 最差。`k_known` 在所有状态下都没有负数(+6.0% ~ +24.7%)。

**推断的原因。** 比值族是「跌下来 × 月内波动大」的反转,它要的是**错价能被交易回去**:
(a) 流动性高 ⇒ 下跌多是流动性冲击 / 情绪,做市资金愿意接,一个月内能收回;成交额最低两档里下跌往往是基本面或退市风险,
跌了不回头,所以在那里失效(-4.4% / -2.1%)。(b) 价格最低 20% 失效(-12.1%)同理 —— 便宜票的下跌是信息(ST、退市),
而且价格在 tick 网格上、比值本身也最吵。(c) 创业板好、沪主板差:创业板 ±20% 涨跌幅 + 散户换手高 ⇒ 日内情绪定价幅度大、
反转最强;沪主板有更多指数 / 机构资金,科创板又小又贵、2019 年才开板、机构持仓占比高,反转最弱(甚至负)。
(d) 冻结盘口段里 +29.6%:连板之后价格远离自己一个月的均价,r 最极端、cv 最大,正是这棵树读得最准的状态。
(e) 高波动 / 下跌 / 缩量才有效:反转的收益就是提供流动性的补偿,波动和恐慌是它的定价环境;2020 和 2021 上半年是动量年
(白酒、半导体、新能源成趋势),反转在那两年本来就该亏(2020 -4.2%、2021 +0.9%)。

**如果这些原因成立,还应该看到(可检验推论,已写进 hypo)**:
1. 换一个流动性代理把书限制在成交额高的 40%(`h_liq_first40`)应该把 ut Lnet 推上去,而把最不流动的 20% 剔掉(`h_liq_excl20`)只能拿到一部分;
2. 剔掉价格最低 20%(`h_px_excl20`)应该直接消掉 v_base 在那一档的 -12.1%;
3. 用「这只票一年里最大的单日涨幅」当涨跌幅制度代理(≈1.20 = 创业板 / 科创板,≈1.10 = 主板,≈1.05 = ST),
   把书限制在高档(`h_lim_first40`)应该复制「创业板好」的那一段;
4. 把 E 的作用显式写成「跌幅秩 × 月内 cv 秩」(`h_rev_x_cv`)应该能复制 abl_E → v_base 的 +1.4pp;
5. 把 nansum 分母换成真正的均值(`h_div_mean30`)后,对次新的 -5.5% 低配应该消失;
6. 既然信息是「相对自己近期水平的偏离」而不是水平,**把同一个比值形状套到成交额上**(`h_amt_ratio30`)应该也有信号,
   而把 `k_known` 自己去水平(`h_amtstd_ratio30`)应该把它的 +15.4% 打掉 —— 这是从另一头检验「家族是不是纯 beta」。

## 4. 相对已知成交额族的增量:**全市场口径上没有**

- ρk:v_base 0.25、abl_D 0.33、iso_E 0.41 —— 相关不高,但这不等于有增量。
- **叠加一律是减分**,而且随权重单调变坏:ov_p025 ut +13.5%/2.00、p05 +12.4%/1.89、p10 +11.3%/1.81、
  m025 +11.0%、m05 +8.7%、m10 +5.4%,全部低于 `k_known` 的 +15.4%/2.22。
- **对家族取秩残差后归零**:`res_known` ut **+0.2% / +0.03**(train -1.0%、valid +3.0%,cov 1.00 / dist 1.00 过门槛)。
  `bk_known` +0.9%、`bk_liq` +0.3% 方向一致(两行 dist 0.20 打 ✗,只作旁证)。
- 与第 4 轮 留出段 的结论一致(state.md §2:f_known +13.23% vs 最好的候选 f_nomask30 +11.12%)。**结论:不建议纳入。**

**但有一条还没被正确检验的口子。** 解剖表显示 `k_known` 自己在成交额桶内部几乎没有信息
(五档 -4.1 / -5.3 / -8.2 / -5.2 / +2.5,而它把 +80.3% 的持仓压在成交额最低 20%,那一段的段等权超额是 +15.1%)
⇒ **家族的 +15.4% 主要是一条流动性 / 微盘 beta**。而比值族的 alpha 恰好在家族最弱、且几乎不持仓的地方
(成交额最高档 abl_D +12.4% vs 家族 +2.5%;冻结盘口段 +29.6% vs 家族 -10.9%)。
全市场秩叠加(overlay)和线性秩残差(res_known)都测不到这种「分段互补」。
还没试过的是**把书限制在家族不去的那一段**(`cs_first_high40(·, 成交额)`),这是本轮留下的唯一活口。

## 5. 改进方向(→ `studies/F112_scale_spow_masktop/hypo.yaml`,36 条)

按预期收益排序:(1) 已确立的提纯 × 未试过的旋钮:删 D + 窗口 50 + `cross_ema` 平滑,和 `cross_scale` 241
(`h_nomask_w50_ema10`、`h_csrank_w50`、`h_nomask_cs241`);(2) 把比值写对:`div(·, cross_mean(·))` 去掉 nansum 暴露,
再试 `cross_med` / `cross_max` / `cross_tail_mean_q75` 当分母(`h_div_*`、`h_dd_*`);(3) 分段条件化 ——
流动性聚焦、剔低价、次新中性、涨跌幅制度代理、冻结盘口桶内中性(`h_liq_*`、`h_px_*`、`h_age_*`、`h_lim_*`、`h_frozen_*`);
(4) 机制重写:把 E 显式化成「跌幅 × cv」、把比值形状换到成交额上、用净买入压力和日内成交重心做微观结构版
(`h_rev_x_cv`、`h_amt_*`、`h_press_*`、`h_centroid_rev`);(5) 两条市场状态门(靠日轴 EMA 混日才生效,`h_state_*`)。
缺的算子写在 `new_operator_requests`(最想要的是**日轴 EMA 之前就能用的市场状态门**和**窗口内缺失日计数归一的比值**)。
