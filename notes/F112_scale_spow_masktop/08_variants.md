# 08 · 怎么读总表、哪些变体其实是同一个东西

> 第 4 轮主研写于 2026-10-04。看总表之前读这一页,否则会把同一棵树当成两个结果、把两卷的数字并排比。

## 1. 读表第一件事:确认在读哪一卷

引擎对每个阶段同时产出两套独立切分,**拟合段不同**:

| 卷 | JSON 字段 | `sign` / `hl` 在哪段拟合 | 覆盖哪几段 |
|---|---|---|---|
| **A 卷** | `books`、`ic` | `train`(2018–2021) | `train`、`valid` |
| **B 卷** | `books_user`、`ic_user`、`ic_holdout` | `utrain`(= train + valid,到 20230807) | `utrain`、**`holdout`(20230808 起)** |

- **holdout 的数字只在 B 卷**;A 卷不含 holdout。JSON 里**不存在**「用 train 拟合的 hl 去评 holdout」这第三种切法。
- B 卷不泄漏:`utrain` 结束于 20230807,holdout 从 20230808 开始。B 卷就是**用户表的口径**。
- **跨卷并排读要声明**。最不可比的是 `f_x241`:它在 A 卷选到 `hlL = 20`、在 B 卷选到 `hlL = 10`(其余四条两卷一致)。
- 本研究全部 train/valid 数字(`S0`/`S1`/`S2`)都是 A 卷;`07_F1_final.md` 的 holdout 表是 B 卷。

## 2. 同一棵树被声明过多次(引擎会去重,`check` 报 "same tree, evaluated once")

| 同一棵树 | 出现过的 id |
|---|---|
| 原式 | `v_base`(S0) ≡ `f_orig`(F1) |
| 去 mask、窗口 30 | `s1_noMask`(S1) ≡ `s2_f30`(S2) ≡ `f_nomask30`(F1) |
| 去 mask、`ts_scale` 50 | `s2_f_t50`(S2) ≡ `f_t50`(F1) |
| 去 mask、`cross_scale` 241 | `s2_f_x241`(S2) ≡ `f_x241`(F1) |
| 家族 K2 | `known_stdamt_max9`(S0 的 control / gate) ≡ `f_known`(F1 的变体) |

`results/R3.md` 对前四组做过**逐位数值核对**,train/valid 的 `Lnet`/`Lshp` diff 全为 `0.00000`;`f_known` 与
`S0_baseline.diagnostics.controls.known_stdamt_max9` 的 train/valid 也逐位相等。**所以同一棵树的不同 id 不要当成两个证据。**

## 3. 容易被名字骗的地方(全部细节在 `02_operators.md`,这里只列会读错结论的三条)

1. **`cs_mask_top_replace_mean_neg` 遮的是最低一成**,不是最高一成。池里另有 `cs_mask_top_replace_mean` 遮最高一成
   —— `s2_masktop` 用的是后者,它是**控制实验,不是候选**。
2. **`cross_scale ≡ ts_scale`**(同一实现,只是允许的窗口池不同:`ts_scale [1,5,10,20,30,40,50]`、
   `cross_scale [3,5,10,15,30,60,241]`)。所以 `f_t50`(ts,50)与 `f_x241`(cross,241)是**同一个算子的两个窗口**,
   不是两种不同的标准化。要 50 以上的窗口只能走 `cross_scale`。
3. **`ts_scale` 的分母是每只股票自己的滚动和**,不横截面共享 ⇒ 一般**不保序**,它是全树唯一的信号成形节点。
   `signedpower` 默认 `e = 2` 但带符号 ⇒ 实轴单调,**不是折叠算子**。

## 4. 哪些变体实质上是别的已知因子

- **两节点线**(`s1_plain30`、`s1_plain60`、`s2_n_t50`、`s2_n_x241`):原始面板 `ρ(ctl_mom20) = +0.898 / +0.731 / +0.786 / +0.382`。
  短窗口那几个**就是 20 日反转**:`ctl_mom20` 自己 `+5.4% / +8.0%`、`Lshp +0.66 / +0.87`,与 `s1_plain30 +6.7% / +7.9%`、
  `+0.83 / +0.81` 在噪声带内等价。**把它们当成「提纯出来的新因子」是错的。**
- **`s2_f_x60`**:`+7.8% / +8.5%`,夹在 `f_t50`(50)与 `f_x241`(241)之间,是平台上的插值点,不占候选名额。
- **三条最终候选彼此**:holdout 上 `Lnet` 跨度只有 `1.70pp`、`Lshp` 跨度 `0.010`(`+11.12/+10.47/+9.42`、`+1.328/+1.330/+1.338`)
  ⇒ **全在噪声带内,「哪一条最好」不是结论。** A 卷上 `ρ(f_nomask30, f_t50) = +0.9356`,这两条几乎是同一条。

## 5. 两套 rank 相关口径(引用必须标明)

- **交易信号口径**(`rank_corr_train` 矩阵对变体用的):`sign × panel`,并按各自**拟合半衰期 EMA 平滑**后比较。
- **原始面板口径**:未平滑的原始值。矩阵里的 **controls / gates 列用的是这一套**(字段 `rank_corr_on` 原文说明)。
- 两套对控制 / 家族列**符号相反**(交易信号全负、原始面板全正),已在 S1 + S2 全部 20 个变体上确认。
  **判「是不是同族」用原始面板口径更保守**,本研究的暴露谱结论(E4)用的就是原始面板。
- 副作用:`f_known` 与 gate `known_stdamt_max9` 字面同一棵树,矩阵却给 `−0.9224` 而非 `±1.0`
  —— 变体侧平滑过(`hlL = 5`)、gate 侧未平滑,外加 `sign = −1`。**读数口径问题,不是数据错误。**

## 6. 固定半衰期表(`books.sweep`)

- 每个变体**免费**有,档位 hl `0/1/2/3/5/10/20`,**不需要 `profile:`**。
- 它是**拟合段**的:A 卷的 sweep 是 **train** 段、B 卷(`books_user.sweep`)是 **utrain** 段。**没有 holdout 版。**
- 这张表是「结构 vs 平滑」归因的唯一合法工具:要说「结构更好」,必须在**同一档 hl** 上比(本研究 E2 就是这么做的)。

## 7. 噪声带与门槛

- 噪声带:`Lnet ±3pp`、`Lshp ±0.3`。**表里 3pp 以内的排序差别不要当结论**(第 4 节第三条、J4 都栽在这个带宽上)。
- 行级门槛:`cov ≥ 0.95`、`dist ≥ 0.5`;本研究所有行都过(`cov 0.9973~0.9997`、`dist 0.9751~1.0000`)。
- `LS`(多空)是次要信息,而且空头腿由买不进的封板票撑(`09_diagnosis.md` E8)⇒ **不可当可实现收益引用。**
- 控制 / 家族自己当因子的数字在 `diagnostics.controls.<id>`,字段名是 `train_long_ann` 这种**前缀式**,不是变体那套键名。
